# Python: PandaDev vs the outside world

Date: 2026-10-16. Repo: `main` at `e5e43cb`. Compared against [research/summary.md](../research/summary.md) and the Python sections of the five research files (written 2026-10-15). No web requests were made for this file. Paths are relative to `content/courses/python/` unless they start with `content/`. Counts come from greps and scripts run on 2026-10-16.

**What was read:** `course.yml` and all 94 EN lessons. L0–L2 core lessons were read in full. The data, ML, deep-learning and L3 lessons were read as full prose and CodeExamples, with long exercise starters and solutions skimmed. All 40 practice problems were read (frontmatter and task text, plus hints where a link looked wrong). For RU, a script compared all 94 pairs (quiz answers, exercise, quiz and hint counts), and quizzes or callouts were read side by side in at least one lesson per module (all 25 modules and 4 capstones).

**Runner:** the browser runs Pyodide `314.0.7`, which is **CPython 3.14.2** (`src/lib/runner/python-worker-source.ts` line 4, `node_modules/pyodide/pyodide-lock.json`), with pandas 3.0.2, NumPy 2.4.6, Pydantic 2.12.5, FastAPI 0.136.1, SQLAlchemy 2.0.48 and pytest 9.0.2. Python 3.15.0 came out on 2026-10-09 [official-docs S13], so the runner is one release behind. 3.15-only features (`frozendict`, `lazy import`, `re.prefixmatch`, UTF-8 `open()` by default) can't run here yet. 3.14 features (t-strings, `except A, B:`) can.

**Verdict**

1. Broad and up to date: 20 of the 34 consensus topics are covered at their level, and only 1 is missing (documentation and publishing). The 3.11–3.14 material (TaskGroup, `asyncio.timeout`, aware datetimes, the `type` statement, free-threading status, pandas 3 copy-on-write, SQLAlchemy 2.0) is current.
2. Levels 2–3 go far beyond the 7 free courses in the research: pytest with mocks and TDD, a full asyncio module, internals, profiling, architecture, security, deployment, system design and code review.
3. Classic traps arrive late: `is` vs `==`, `[[0]*n]*m` and mutable defaults are taught head-on only at L3, and `x == 1 or 2` is never taught. Generators, decorators and threads sit one level later than the consensus.
4. Lesson design is strong: worked examples, misconception-based quiz answers, and "fix the bugs" or "your tests must catch our bugs" exercises. The weak spots are L0. Its lessons have 360–522 words and one quiz each, 6 of its exercises only check printed output, and there are no predict-before-run prompts or placement checks.
5. Few errors: 3 factual or structural slips and 1 outdated callout (f-string quotes), all repeated in RU. EN/RU structure matches in all 94 pairs.

## Lesson quality findings

### Factual and structural slips (all repeated in RU)

1. **`conditions/02-comparisons-and-logic.mdx` line 35 and quiz explanation line 103** (RU lines 37 and 105): "Different types are never equal" / "Values of different types are not equal." That's false for numbers: `1 == 1.0` and `True == 1` are both `True` (checked with local Python 3.9; this is a language rule, the same in 3.14). Say "a string and a number are never equal", and add `1 == 1.0` as a "numbers compare by value" note.

## Strengths

- **Debugging from day one.** `functions/02-reading-errors-and-debugging.mdx` (L0) teaches reading tracebacks bottom-up, the common errors, `f"{x=}"`, rubber-duck debugging and `assert`, with a "fix five bugs" exercise. MDN and TOP do this early [official-docs S2; courses S5]; most Python courses don't.
- **Testing as a skill, not an afterthought.** Among the 7 Python courses only CS50P teaches writing tests [courses S9]. PandaDev has a 3-lesson pytest module, and capstones where the learner's test suite must catch broken versions of the app.
- **Async done properly.** 1 of 7 free courses covers asyncio at all [courses S27]. PandaDev teaches the modern API (TaskGroup, `asyncio.timeout`, `except*`) and the two classic mistakes (missing `await`, blocking the loop).
- **A real Level 3.** None of the 7 Python sources covers architecture, profiling, security or code review [courses, Level 3]. PandaDev has 19 L3 module lessons plus a production capstone (design doc, SLOs, load tests).
- **Current with 3.11–3.14 and the libraries.** Pandas 3, SQLAlchemy 2.0, Pydantic v2, aware datetimes, free-threading status, TaskGroup. No deprecated APIs found by grep.
- **Testability as a habit.** "Inject the clock, the random generator, `sleep`, the executor" recurs from L1 (`dates-and-times`) to L3. That's exactly the production habit industry ladders reward [industry-levels S21].
- **Honest about the browser.** `input()`, threads, pip and real servers are explained, never faked. The workarounds (command lists, `TestClient`, an inline executor) are real techniques the learner can reuse.
