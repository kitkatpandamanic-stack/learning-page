# What the outside world says: research summary

Compiled 2026-10-16 from five research files written on 2026-10-15: [official-docs.md](official-docs.md), [courses.md](courses.md), [industry-levels.md](industry-levels.md), [learning-science.md](learning-science.md) and [learner-struggles.md](learner-struggles.md). This file doesn't compare anything with PandaDev. That comes next.

Citations look like `[courses S4]`: the file name, then the source number in that file's table. Levels: **L0 Beginner, L1 Junior, L2 Middle, L3 Senior**. Languages are in the same order as `curriculum.md`.

**Overview**

1. Every language moved in 2026. Node 26 becomes LTS on 2026-10-28, Python 3.15.0 came out on 2026-10-09, TypeScript 7.0 (a native Go compiler) on 2026-07-08, and PostgreSQL is at 18.6 with 19 at RC 1. Much tutorial material is now out of date.
2. The L0–1 order is much the same everywhere: values → conditions → loops → collections and functions → objects and errors. The disputes are about where functions, arrays, joins, async and testing go.
3. Free courses are dense at L0–1, thin at L2 and nearly empty at L3. Industry ladders define L2–3 by independence, scope, code review, security and production work, not by language features.
4. Learners keep asking about the same small set of things: async results, closures and `this`, Python aliasing, TS strict nulls, joins, NULL, and SQL injection.
5. The best-backed design rules are spaced retrieval with explained feedback, worked examples that fade, tracing and predicting before writing, graduated hints, and placement checks for experienced learners. Gamification helps only a little and can backfire.

## Consensus curriculum

**How ● is counted.** There are three evidence groups: **C** = [courses.md](courses.md), **I** = [industry-levels.md](industry-levels.md), and **D** = [official-docs.md](official-docs.md) and/or [learner-struggles.md](learner-struggles.md), which together count as one group. A group backs a topic if it names it at any level. ●●● = all three groups, ●● = two, ● = one. The Level column is where most backing sources put the topic, and level conflicts are listed under "where sources disagree". Misconception research from learning-science.md isn't counted in ● (see the confusions section).

**Typical order at Levels 0–1:** values and operators → conditionals → loops, functions and arrays (order varies) → objects → DOM and events → closures and higher-order functions → classes → modules, with async after that [courses; official-docs S2].

**Where sources disagree**

- **Arrays:** MDN teaches arrays before conditionals and loops [official-docs S2], and 3/5 courses teach them before or with loops. javascript.info leaves them until much later [courses S16].
- **Level for async:** industry puts async basics at L1 [industry-levels S1, S15]. Courses treat it as L2, and fCC makes it the last module [courses S1]. Learners hit it constantly (18,840 linked), but experienced developers rank it only 10.9% as a pain point [learner-struggles S2, S6].
- **Prototypes and classes:** L1 in courses (javascript.info teaches prototypes before class syntax) [courses S16]. Industry lists them at L2 [industry-levels S1].
- **Testing:** javascript.info teaches it early. TOP and fCC teach it after async [courses S6, S16]. The roadmap.sh beginner front-end path includes a test runner [industry-levels S6].
- **Recursion:** a functions topic in javascript.info, a computer-science and algorithms topic in TOP and fCC [courses].
- **Browser-first or not:** MDN and TOP teach the DOM inside the beginner module [official-docs S2; courses S5]. javascript.info keeps the browser for Part 2 [courses S16].

**Not confirmed**

- **Courses:** Поколение Python's syllabus (Stepik returned 502). Mode's per-lesson order, which is partly "from memory of the site" plus secondary sources and should be re-checked. Whether pgexercises checks answers automatically. What CS50 SQL means by "partitioning". Hexlet's Python lesson count (the page says both 69 and 70) [courses].
- **Industry:** roadmap.sh node order and its "recommended" markers (the repo has no layout data). TS interview topics, read only through a search summary. Debounce and `Promise.all` as interview tasks. The 2026 RU article on AI and performance. The GMAC hiring survey. hh.ru (HTTP 451). progression.fyi now redirects elsewhere. The level mapping of Dropbox and Avito grades is the researcher's own inference [industry-levels].
- **Learning science:** the size of PRIMM's effect. Rowland, Adesope, and Sinha & Kapur figures come from secondary summaries. Whether Parsons distractors help learning. Independent evidence on streak freezes. No peer-reviewed study of novice misconceptions about JS async, `this`, closures or TypeScript. No study of how common the SQL NULL errors are. Several sources were read as abstracts only [learning-science].
- **Learner signals:** Reddit was blocked by a login wall. The Typed Python survey and "uv is the most-admired tool" come from search summaries. JetBrains figures came via heise. The SO 2026 raw data isn't out yet [learner-struggles].

**Weak spots in the method**

- Stack Overflow's top-voted lists come mostly from 2008–2013. New-question volume fell about 99% from 2020 to 2026, so newer features (`satisfies`, Temporal, uv, TS 7) barely show up there [learner-struggles S1, S3].
- The Habr sample is the 100 most recent titles per tag (400 in total), with no ranking. Download counts are mostly CI traffic, so they're only useful for comparing tools [learner-struggles S11, S12, S13].
- learning-science.md cites a "151 public repos" study about `any` but has no source row for it. Only the 604-project study (S53) is listed.
- The SQL "3 vs 2" split on joins vs aggregates counts Hexlet, whose free course has no JOIN [courses S23].
- TypeScript has the thinnest evidence base across all five files: two free syllabi, no roadmap.sh interview guide, and no learner misconception studies [courses; industry-levels; learning-science].

**Where the files contradict each other or pull apart**

- **Async level:** L1 in industry-levels; L2 in courses, learning-science and the MDN Guide order.
- **`is` vs `==` and NULL logic:** L1 and L0 in learner-struggles; L2 and L1 in learning-science.
- **TS as a first language:** official-docs (the Handbook's "new programmers" page) vs industry-levels and courses (JS first).
- **When to test:** industry-levels puts a test runner in the beginner set. courses mostly teach testing after async, and among Python courses only CS50P teaches writing tests.

- **Decorators:** TC39 says Stage 2.7. Node's own TS docs still say Stage 3 [official-docs S6, S11].
