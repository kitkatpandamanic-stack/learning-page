A dashboard needs the user, their bamboo stock and the weather, and loading them one after another is three times slower than it needs to be. `Promise.all` runs things in parallel but works with arrays, and an object with names is much nicer to use. Write two helpers that take an object of **loaders** (functions returning promises) and keep every result's type.

```ts
type Loaders = Record<string, () => Promise<unknown>>;
type Settled<T> = { ok: true; value: T } | { ok: false; error: unknown };
```

- `loadAll(loaders)` starts **every** loader straight away (none waits for another) and resolves with an object with the same keys, each holding its loader's result. Its type is exact: for `{ count: () => Promise<number> }` you get `{ count: number }`.
- If any loader rejects, `loadAll` rejects as soon as the first failure happens, with a `LoadError`: a subclass of `Error` with `name` `"LoadError"`, the message `"Failed to load <key>"`, a `key` property, and the original error as `cause` (pass `{ cause }` to `super`).
- `loadSettled(loaders)` also starts everything at once, but never rejects: each key holds a `Settled` result, `{ ok: true, value }` or `{ ok: false, error }`.

```ts
const data = await loadAll({
  user: async () => ({ name: "Mei" }),
  stock: () => Promise.resolve(120),
});
data.user.name; // "Mei" (typed as string)
data.stock;     // 120 (typed as number)

const report = await loadSettled({
  weather: () => Promise.reject(new Error("offline")),
});
report.weather; // { ok: false, error: Error: offline }
```

Type the two helpers with a mapped type and make them run the loaders in parallel. The `@ts-expect-error` lines are type tests: they pass only when that line **is** an error.

<Hint>

A mapped type can walk over the keys of the loaders object, and `ReturnType` plus `Awaited` unwrap each loader's promise. For speed, start every loader before you await anything.

</Hint>

<Hint>

Use one type parameter for the whole object, `loadAll<T extends Loaders>(loaders: T)`, and the result type `{ [K in keyof T]: Awaited<ReturnType<T[K]>> }` (wrapped in `Settled<…>` for `loadSettled`). Get the keys with `Object.keys(loaders)`, call every loader in one `map`, and `await Promise.all(…)`. Chain `.catch((error: unknown) => { throw new LoadError(key, error); })` onto each promise so the failure knows its key. Rebuild the object with `Object.fromEntries` and one `as` cast. `LoadError` calls `super("Failed to load " + key, { cause })` and sets `name` and `key`. `loadSettled` uses `.then(onValue, onError)` to turn each result into `{ ok: true, value }` or `{ ok: false, error }`.

</Hint>

<Solution>

```ts
type Loaders = Record<string, () => Promise<unknown>>;
type Settled<T> = { ok: true; value: T } | { ok: false; error: unknown };

type Loaded<T extends Loaders> = {
  [K in keyof T]: Awaited<ReturnType<T[K]>>;
};
type SettledAll<T extends Loaders> = {
  [K in keyof T]: Settled<Awaited<ReturnType<T[K]>>>;
};

class LoadError extends Error {
  readonly key: string;

  constructor(key: string, cause: unknown) {
    super("Failed to load " + key, { cause });
    this.name = "LoadError";
    this.key = key;
  }
}

async function loadAll<T extends Loaders>(loaders: T): Promise<Loaded<T>> {
  const keys = Object.keys(loaders);
  const values = await Promise.all(
    keys.map((key) =>
      loaders[key]().catch((error: unknown) => {
        throw new LoadError(key, error);
      }),
    ),
  );
  return Object.fromEntries(
    keys.map((key, i) => [key, values[i]]),
  ) as Loaded<T>;
}

async function loadSettled<T extends Loaders>(
  loaders: T,
): Promise<SettledAll<T>> {
  const keys = Object.keys(loaders);
  const results = await Promise.all(
    keys.map((key) =>
      loaders[key]().then(
        (value) => ({ ok: true, value }),
        (error: unknown) => ({ ok: false, error }),
      ),
    ),
  );
  return Object.fromEntries(
    keys.map((key, i) => [key, results[i]]),
  ) as SettledAll<T>;
}

// ===== Type tests: don't change these =====
async function typeTests() {
  const data = await loadAll({
    user: async () => ({ name: "Mei" }),
    count: () => Promise.resolve(3),
  });
  const name: string = data.user.name;
  // @ts-expect-error: there is no "posts" loader
  data.posts;
  // @ts-expect-error: count is a number
  const wrong: string = data.count;
  const report = await loadSettled({ n: async () => 1 });
  if (report.n.ok) {
    const n: number = report.n.value;
  }
  // @ts-expect-error: check ok before reading value
  report.n.value;
  return [name, wrong];
}

const data = await loadAll({
  user: async () => ({ name: "Mei" }),
  stock: () => Promise.resolve(120),
});
console.log(data); // { user: { name: 'Mei' }, stock: 120 }
```

Calling every loader inside one `map` starts them all before anything is awaited, so the total time is the slowest loader, not the sum. The mapped type `{ [K in keyof T]: Awaited<ReturnType<T[K]>> }` unwraps each loader's promise under its own key; the single `as` cast is needed because `Object.fromEntries` can't know which value belongs to which key. `Promise.all` rejects with the first rejection in time, which is why the fastest failure wins.

</Solution>
