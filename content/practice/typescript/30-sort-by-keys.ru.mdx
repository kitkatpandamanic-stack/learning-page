Таблица лидеров панд сортируется по очкам (сначала больше), а при равенстве — по имени. Напишите `sortBy(items, ...keys)` — переиспользуемую сортировку по нескольким ключам, типы которой отвергают бессмысленные ключи.

**Ключ сортировки** — это либо имя свойства (по возрастанию), либо `{ key, order }`, где `order` — `"asc"` или `"desc"`:

```ts
type Sortable = string | number | null | undefined;
type SortKey<T> = SortableKey<T> | { key: SortableKey<T>; order: "asc" | "desc" };
```

`SortableKey<T>` — объединение тех ключей `T`, значения которых `Sortable` (поэтому `string[]` или свойства-объекты использовать нельзя). Правила:

- Элементы сравниваются по первому ключу; только если эти значения равны — по второму, и так далее.
- Числа и строки сравниваются через `<` и `>` (поэтому `"B"` идёт раньше `"a"`).
- Значения `null` и `undefined` всегда идут **в конце**, при любом порядке.
- Элементы, равные по всем ключам, сохраняют исходный порядок (стабильная сортировка).
- `sortBy` возвращает **новый** массив и никогда не меняет `items`. Без ключей возвращает копию в исходном порядке.

```ts
const pandas = [
  { name: "Mei", score: 40, nickname: "Ace" },
  { name: "Bo", score: 55 },
  { name: "Lin", score: 40, nickname: "Lulu" },
];
sortBy(pandas, { key: "score", order: "desc" }, "name").map((p) => p.name);
// ["Bo", "Lin", "Mei"]
sortBy(pandas, "nickname").map((p) => p.name);
// ["Mei", "Lin", "Bo"]: у Bo нет прозвища, поэтому он в конце
```

<Hint>

Сначала превратите каждый ключ в `{ key, order }` (строковый ключ — это `typeof k === "object" ? k : { key: k, order: "asc" }`). Затем `[...items].sort((a, b) => …)`: для каждого ключа сравните `a[key]` и `b[key]`; сначала обработайте `== null` (отсутствующее значение — в конец, ещё до учёта `order`), потом верните `-1` / `1` (наоборот для `"desc"`) или при равенстве переходите к следующему ключу. В конце верните `0`: сортировка в JavaScript стабильная.

</Hint>

<Solution>

```ts
type Sortable = string | number | null | undefined;

type SortableKey<T> = {
  [K in keyof T]-?: T[K] extends Sortable ? K : never;
}[keyof T];

type SortKey<T> =
  | SortableKey<T>
  | { key: SortableKey<T>; order: "asc" | "desc" };

function sortBy<T>(items: readonly T[], ...keys: SortKey<T>[]): T[] {
  const rules = keys.map((k) =>
    typeof k === "object" ? k : { key: k, order: "asc" as const },
  );
  return [...items].sort((a, b) => {
    for (const { key, order } of rules) {
      const x = a[key] as Sortable;
      const y = b[key] as Sortable;
      if (x == null && y == null) continue;
      if (x == null) return 1; // отсутствующие значения всегда в конце
      if (y == null) return -1;
      if (x === y) continue;
      const result = x < y ? -1 : 1;
      return order === "desc" ? -result : result;
    }
    return 0;
  });
}

// ===== Тесты типов: не меняйте их =====
type Panda = {
  name: string;
  score: number;
  nickname?: string;
  friends: string[];
};

function typeTests(pandas: Panda[]) {
  const sorted: Panda[] = sortBy(pandas, "score", {
    key: "nickname",
    order: "desc",
  });
  // @ts-expect-error: у панд нет веса
  sortBy(pandas, "weight");
  // @ts-expect-error: массивы сравнивать нельзя
  sortBy(pandas, "friends");
  // @ts-expect-error: order — это "asc" или "desc"
  sortBy(pandas, { key: "score", order: "down" });
  return sorted;
}

const pandas = [
  { name: "Mei", score: 40 },
  { name: "Bo", score: 55 },
  { name: "Lin", score: 40 },
];
const board = sortBy(pandas, { key: "score", order: "desc" }, "name");
console.log(board.map((p) => p.name)); // [ 'Bo', 'Lin', 'Mei' ]
```

Сопоставленный тип оставляет ключ `K`, только если `T[K]` сортируемый, а остальные превращает в `never`, который исчезает из итогового объединения. Компаратор проходит по ключам по порядку и возвращает результат при первом различии, ставя отсутствующие значения в конец ещё до учёта направления. Сортировка копии стоит O(n log n · k) для k ключей, а `Array.prototype.sort` стабилен, поэтому полностью равные элементы сохраняют свой порядок.

</Solution>
