Служба доставки бамбука хранит клиентов вот так. Не каждый клиент указал адрес, а в адресе может не быть города или индекса:

```ts
interface Customer {
  name: string;
  address?: {
    city?: string;
    postcode?: string;
  };
}
```

Напишите две функции:

- `deliveryCity(customer)` возвращает город клиента или `"Unknown"`, если нет адреса или города. Пустая строка `""` считается настоящим (хоть и бесполезным) городом и возвращается как есть.
- `label(customer)` возвращает `"<name>, <city>, <postcode>"`, подставляя `"Unknown"` вместо отсутствующего города и `"no postcode"` вместо отсутствующего индекса.

Заготовка читает `customer.address.city` напрямую. TypeScript отвергает это с ошибкой "'customer.address' is possibly 'undefined'." — и правильно: для клиента без адреса код бы упал.

```ts
deliveryCity({ name: "Mei", address: { city: "Chengdu" } }); // "Chengdu"
deliveryCity({ name: "Bao" });                                // "Unknown"
label({ name: "Bao", address: { postcode: "EH12" } });        // "Bao, Unknown, EH12"
```

Исправьте `deliveryCity` и напишите `label`, чтобы обе функции справлялись с любой недостающей частью.

<Hint>

И `address`, и `city` могут отсутствовать. Посмотрите на опциональную цепочку (`?.`) и оператор значения по умолчанию. Осторожно: пустой город `""` нужно сохранить, а не заменить.

</Hint>

<Hint>

`customer.address?.city` останавливается и даёт `undefined`, если `address` нет. Дальше `?? "Unknown"` заменяет только `null` или `undefined`, поэтому пустая строка сохраняется (`||` заменил бы и её). Для `label` получите индекс так же, с запасным значением `"no postcode"`, город возьмите из `deliveryCity` и соедините имя, город и индекс через `", "`.

</Hint>

<Solution>

```ts
interface Customer {
  name: string;
  address?: {
    city?: string;
    postcode?: string;
  };
}

function deliveryCity(customer: Customer): string {
  return customer.address?.city ?? "Unknown";
}

function label(customer: Customer): string {
  const postcode = customer.address?.postcode ?? "no postcode";
  return `${customer.name}, ${deliveryCity(customer)}, ${postcode}`;
}

console.log(deliveryCity({ name: "Bao" })); // Unknown
```

Опциональная цепочка (optional chaining) `?.` превращает «падение на отсутствующем объекте» в «вернуть `undefined`», и TypeScript это отслеживает: тип `customer.address?.city` — `string | undefined`. `?? "Unknown"` убирает `undefined`, поэтому функция может обещать вернуть обычный `string`.

</Solution>

</Exercise>
