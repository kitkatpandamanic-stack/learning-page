Мастер бамбуковых вывесок берёт плату за каждый символ, а клиенты присылают текст двумя способами: одной строкой `string` или массивом строк (по одной на каждую строку вывески).

Напишите `letterCount(text)`, где `text` имеет тип `string | string[]` — это объединение типов (union type). Функция возвращает количество символов, которые **не являются пробелами**:

- Для строки посчитайте её непробельные символы.
- Для массива сложите результаты по всем его строкам.
- Пустая строка или пустой массив дают `0`.

Пропускается только символ пробела `" "`; буквы, цифры и знаки препинания считаются.

```ts
letterCount("Fresh bamboo");          // 11
letterCount(["Fresh", "bamboo!"]);    // 12
letterCount([]);                      // 0
```

<Solution>

```ts
function countOne(line: string): number {
  return line.replaceAll(" ", "").length;
}

function letterCount(text: string | string[]): number {
  if (Array.isArray(text)) {
    let total = 0;
    for (const line of text) total += countOne(line);
    return total;
  }
  return countOne(text);
}

function typeTests() {
  letterCount(["Fresh", "bamboo"]);
  // @ts-expect-error
  letterCount(42);
}

console.log(letterCount("Fresh bamboo")); // 11
```

`Array.isArray` — это проверка, которая сужает тип: в каждой ветке TypeScript точно знает, каким членом объединения является `text`, поэтому вызов `.replaceAll` у массива (или случайный цикл по обычной строке) ловится ещё до запуска кода.

</Solution>
