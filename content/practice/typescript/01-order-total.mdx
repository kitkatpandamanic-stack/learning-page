A shop describes each line of an order with this interface:

```ts
interface LineItem {
  name: string;
  price: number;    // price of one item
  quantity: number;
}
```

Write a function `orderTotal(items, discountCode?)` that returns the total price: `price * quantity` for every item, added up. If `discountCode` is `"PANDA10"`, take 10% off the total. Any other code (or no code) gives no discount. Round the result to 2 decimal places with `Math.round(total * 100) / 100`.

Give the parameters proper types: `items` is an array of `LineItem`, `discountCode` is an optional `string`, and the function returns a `number`.

```ts
orderTotal([{ name: "tea", price: 2.5, quantity: 2 }]);            // 5
orderTotal([{ name: "tea", price: 2.5, quantity: 2 }], "PANDA10"); // 4.5
orderTotal([]);                                                   // 0
```

<Solution>

```ts
interface LineItem {
  name: string;
  price: number;
  quantity: number;
}

function orderTotal(items: LineItem[], discountCode?: string): number {
  let total = 0;
  for (const item of items) {
    total += item.price * item.quantity;
  }
  if (discountCode === "PANDA10") total *= 0.9;
  return Math.round(total * 100) / 100;
}

console.log(orderTotal([{ name: "tea", price: 2.5, quantity: 2 }])); // 5
```

The `?` in `discountCode?: string` makes the parameter optional: inside the function its type is `string | undefined`, so comparing it with `"PANDA10"` is safe.

</Solution>
