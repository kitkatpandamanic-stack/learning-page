The pandas are voting for their favourite snack. Each vote is a string, but the pandas are not careful typists: `"Bamboo"`, `" bamboo"` and `"BAMBOO "` are all the same vote.

Write `tallyVotes(votes)` that takes an array of strings and returns a `Record<string, number>`: each key is a snack in **lower case with spaces trimmed from both ends**, and its value is how many votes it got.

- Votes that are empty after trimming are ignored.
- No votes gives an empty object `{}`.
- Keys appear in the order the snacks are first seen.

```ts
tallyVotes(["Bamboo", " apple", "BAMBOO "]); // { bamboo: 2, apple: 1 }
tallyVotes(["  ", ""]);                      // {}
```

<Solution>

```ts
function tallyVotes(votes: string[]): Record<string, number> {
  const counts: Record<string, number> = {};
  for (const vote of votes) {
    const key = vote.trim().toLowerCase();
    if (key === "") continue;
    counts[key] = (counts[key] ?? 0) + 1;
  }
  return counts;
}

function typeTests() {
  const counts: Record<string, number> = tallyVotes(["tea"]);
  // @ts-expect-error
  tallyVotes([1, 2]);
}

console.log(tallyVotes(["Bamboo", " apple", "BAMBOO "]));
```

`Record<string, number>` says "any string key, always a number value", which is exactly a tally. Reading a key that isn't there yet gives `undefined` at runtime, so `?? 0` supplies the starting count.

</Solution>
