The zoo's admin table lets keepers sort by more than one column, like "oldest first, then by name". Write `sortBy(items, keys)` where `keys` is a list of sort keys:

```ts
type SortKey<T> = { key: keyof T; direction: "asc" | "desc" };
```

Rules:

- Compare two items by the **first** sort key. If they're equal on it, compare by the second key, and so on.
- `"asc"` puts smaller values first, `"desc"` larger values first. Values are numbers or strings, compared with `<` and `>` (so strings compare by character code: `"Z"` comes before `"a"`).
- Items that are equal on every key keep their original order. An empty `keys` list keeps the original order.
- Return a **new** array; the input is not changed.

```ts
const pandas = [
  { name: "Mei", age: 4 },
  { name: "Bao", age: 7 },
  { name: "Lin", age: 4 },
];
sortBy(pandas, [{ key: "age", direction: "desc" }, { key: "name", direction: "asc" }]);
// Bao (7), Lin (4), Mei (4)
```

Types: `SortKey<T>` is generic, so only real property names are accepted for `key` (a typo like `"agee"` is a compile error) and the direction is `"asc" | "desc"`, not any string. `sortBy` returns `T[]` with the same item type it was given.

<Solution>

```ts
type SortKey<T> = { key: keyof T; direction: "asc" | "desc" };

function sortBy<T>(items: readonly T[], keys: readonly SortKey<T>[]): T[] {
  return [...items].sort((a, b) => {
    for (const { key, direction } of keys) {
      const sign = direction === "asc" ? 1 : -1;
      if (a[key] < b[key]) return -sign;
      if (a[key] > b[key]) return sign;
    }
    return 0;
  });
}

interface Panda {
  name: string;
  age: number;
}
function typeTests(pandas: Panda[]) {
  const sorted: Panda[] = sortBy(pandas, [
    { key: "age", direction: "desc" },
    { key: "name", direction: "asc" },
  ]);
  // @ts-expect-error: no such property
  sortBy(pandas, [{ key: "agee", direction: "asc" }]);
  // @ts-expect-error: the direction is "asc" or "desc"
  sortBy(pandas, [{ key: "age", direction: "up" }]);
  // @ts-expect-error: the result is still Panda[]
  const names: string[] = sortBy(pandas, []);
}

const pandas: Panda[] = [
  { name: "Mei", age: 4 },
  { name: "Bao", age: 7 },
  { name: "Lin", age: 4 },
];
const byAge = sortBy(pandas, [
  { key: "age", direction: "desc" },
  { key: "name", direction: "asc" },
]);
console.log(byAge.map((p) => p.name)); // [ 'Bao', 'Lin', 'Mei' ]
```

`keyof T` ties the sort keys to the item type that TypeScript infers from `items`, so the column names are checked against the real data. The compare function stops at the first key that tells two items apart, which is what "then by" means. Sorting is O(n log n) comparisons, each costing up to one check per sort key.

</Solution>
