Дашборду нужны пользователь, его запасы бамбука и погода, а загрузка по очереди втрое медленнее, чем нужно. `Promise.all` запускает всё параллельно, но работает с массивами, а объектом с именами пользоваться гораздо удобнее. Напишите два помощника, которые принимают объект **загрузчиков** (функций, возвращающих промисы) и сохраняют тип каждого результата.

```ts
type Loaders = Record<string, () => Promise<unknown>>;
type Settled<T> = { ok: true; value: T } | { ok: false; error: unknown };
```

- `loadAll(loaders)` сразу запускает **каждый** загрузчик (никто никого не ждёт) и выполняется с объектом с теми же ключами, где под каждым ключом лежит результат его загрузчика. Тип точный: для `{ count: () => Promise<number> }` получается `{ count: number }`.
- Если какой-то загрузчик отклоняется, `loadAll` отклоняется сразу при первой неудаче с ошибкой `LoadError`: это подкласс `Error` с `name`, равным `"LoadError"`, сообщением `"Failed to load <key>"`, свойством `key` и исходной ошибкой в `cause` (передайте `{ cause }` в `super`).
- `loadSettled(loaders)` тоже запускает всё сразу, но никогда не отклоняется: под каждым ключом лежит результат `Settled` — `{ ok: true, value }` или `{ ok: false, error }`.

```ts
const data = await loadAll({
  user: async () => ({ name: "Mei" }),
  stock: () => Promise.resolve(120),
});
data.user.name; // "Mei" (тип string)
data.stock;     // 120 (тип number)

const report = await loadSettled({
  weather: () => Promise.reject(new Error("offline")),
});
report.weather; // { ok: false, error: Error: offline }
```

Типизируйте оба помощника сопоставленным типом и заставьте их запускать загрузчики параллельно. Строки с `@ts-expect-error` — это тесты типов: они проходят, только когда в этой строке **есть** ошибка.

<Hint>

Сопоставленный тип (mapped type) может пройти по ключам объекта с загрузчиками, а `ReturnType` вместе с `Awaited` разворачивают промис каждого загрузчика. Для скорости запустите все загрузчики до того, как что-либо ждать.

</Hint>

<Hint>

Используйте один параметр типа для всего объекта: `loadAll<T extends Loaders>(loaders: T)`, а тип результата — `{ [K in keyof T]: Awaited<ReturnType<T[K]>> }` (для `loadSettled` оберните его в `Settled<…>`). Получите ключи через `Object.keys(loaders)`, вызовите все загрузчики в одном `map` и сделайте `await Promise.all(…)`. К каждому промису прицепите `.catch((error: unknown) => { throw new LoadError(key, error); })`, чтобы ошибка знала свой ключ. Соберите объект обратно через `Object.fromEntries` и одно приведение `as`. `LoadError` вызывает `super("Failed to load " + key, { cause })` и задаёт `name` и `key`. `loadSettled` через `.then(onValue, onError)` превращает каждый результат в `{ ok: true, value }` или `{ ok: false, error }`.

</Hint>

type Loaded<T extends Loaders> = {
  [K in keyof T]: ...; // тип, с которым выполняется загрузчик T[K]

async function loadAll<T extends Loaders>(loaders: T): Promise<Loaded<T>> {
  const keys = Object.keys(loaders);
  const values = await Promise.all(

        // превратите ошибку в LoadError для этого ключа

<Solution>

```ts
type Loaders = Record<string, () => Promise<unknown>>;
type Settled<T> = { ok: true; value: T } | { ok: false; error: unknown };

type Loaded<T extends Loaders> = {
  [K in keyof T]: Awaited<ReturnType<T[K]>>;
};
type SettledAll<T extends Loaders> = {
  [K in keyof T]: Settled<Awaited<ReturnType<T[K]>>>;
};

class LoadError extends Error {
  readonly key: string;

  constructor(key: string, cause: unknown) {
    super("Failed to load " + key, { cause });
    this.name = "LoadError";
    this.key = key;
  }
}

async function loadAll<T extends Loaders>(loaders: T): Promise<Loaded<T>> {
  const keys = Object.keys(loaders);
  const values = await Promise.all(
    keys.map((key) =>
      loaders[key]().catch((error: unknown) => {
        throw new LoadError(key, error);
      }),
    ),
  );
  return Object.fromEntries(
    keys.map((key, i) => [key, values[i]]),
  ) as Loaded<T>;
}

async function loadSettled<T extends Loaders>(
  loaders: T,
): Promise<SettledAll<T>> {
  const keys = Object.keys(loaders);
  const results = await Promise.all(
    keys.map((key) =>
      loaders[key]().then(
        (value) => ({ ok: true, value }),
        (error: unknown) => ({ ok: false, error }),
      ),
    ),
  );
  return Object.fromEntries(
    keys.map((key, i) => [key, results[i]]),
  ) as SettledAll<T>;
}

// ===== Тесты типов: не меняйте их =====
async function typeTests() {
  const data = await loadAll({
    user: async () => ({ name: "Mei" }),
    count: () => Promise.resolve(3),
  });
  const name: string = data.user.name;
  // @ts-expect-error: загрузчика "posts" нет
  data.posts;
  // @ts-expect-error: count — число
  const wrong: string = data.count;
  const report = await loadSettled({ n: async () => 1 });
  if (report.n.ok) {
    const n: number = report.n.value;
  }
  // @ts-expect-error: проверьте ok, прежде чем читать value
  report.n.value;
  return [name, wrong];
}

const data = await loadAll({
  user: async () => ({ name: "Mei" }),
  stock: () => Promise.resolve(120),
});
console.log(data); // { user: { name: 'Mei' }, stock: 120 }
```

Вызов всех загрузчиков внутри одного `map` запускает их до первого `await`, поэтому общее время равно времени самого медленного загрузчика, а не сумме. Сопоставленный тип `{ [K in keyof T]: Awaited<ReturnType<T[K]>> }` разворачивает промис каждого загрузчика под его собственным ключом; единственное приведение `as` нужно потому, что `Object.fromEntries` не знает, какое значение какому ключу принадлежит. `Promise.all` отклоняется первой по времени ошибкой — поэтому и побеждает самая быстрая неудача.

</Solution>
