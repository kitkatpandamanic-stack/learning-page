A sign-up form should tell people about **all** their mistakes at once, not one per submit. Build a small schema library: you describe the data once, TypeScript **infers** the type from the description, and `parse` checks unknown data and lists every problem with its path.

```ts
type Result<T> = { ok: true; value: T } | { ok: false; errors: string[] };
type Schema<T> = {
  check(value: unknown, path: string, errors: string[]): void;
  parse(value: unknown): Result<T>;
};
```

`check` adds a message `"<path>: <problem>"` to `errors` for every problem it finds. `parse(value)` runs `check` with the path `"$"` and returns `{ ok: true, value }` (the same value it was given) if there were no errors, otherwise `{ ok: false, errors }`. The building blocks:

- `str()` accepts strings, otherwise `"expected string"`. `num()` accepts numbers that aren't `NaN`, otherwise `"expected number"`.
- `literal(...values)` accepts exactly one of the given strings, numbers or booleans, otherwise `"expected one of a | b | c"`. Its type is the union of those literals: `literal("bamboo", "apples")` is a `Schema<"bamboo" | "apples">`.
- `arr(item)` needs an array (otherwise `"expected array"`), then checks each element at path `<path>.<index>`.
- `obj(shape)` needs an object that isn't `null` or an array (otherwise `"expected object"`), then checks each key of the shape, in the shape's order, at path `<path>.<key>`. Extra keys are allowed.
- `optional(inner)` accepts `undefined`, and otherwise whatever `inner` accepts. In an `obj`, its key becomes an **optional property** (`nickname?: string`).

`Infer<S>` gives the type a schema lets through.

```ts
const Panda = obj({
  name: str(),
  diet: literal("bamboo", "apples"),
  friends: arr(obj({ name: str(), age: num() })),
  nickname: optional(str()),
});
type Panda = Infer<typeof Panda>;
// { name: string; diet: "bamboo" | "apples";
//   friends: { name: string; age: number }[]; nickname?: string }

Panda.parse({ name: 7, diet: "fish", friends: [{ name: "Bo", age: "3" }] });
// { ok: false, errors: [
//   "$.name: expected string",
//   "$.diet: expected one of bamboo | apples",
//   "$.friends.0.age: expected number" ] }
```

T : never`. <Solution>

```ts
// ===== Type-test helpers: don't change =====
type Expect<T extends true> = T;
type Equal<A, B> =
  (<X>() => X extends A ? 1 : 2) extends
  (<X>() => X extends B ? 1 : 2) ? true : false;

type Result<T> = { ok: true; value: T } | { ok: false; errors: string[] };
type Schema<T> = {
  check(value: unknown, path: string, errors: string[]): void;
  parse(value: unknown): Result<T>;
};

type Infer<S> = S extends Schema<infer T> ? T : never;

type Shape = Record<string, Schema<unknown>>;
type Simplify<X> = { [K in keyof X]: X[K] };
type OptionalKeys<S extends Shape> = {
  [K in keyof S]: undefined extends Infer<S[K]> ? K : never;
}[keyof S];
type ObjectOf<S extends Shape> = Simplify<
  { [K in Exclude<keyof S, OptionalKeys<S>>]: Infer<S[K]> } &
  { [K in OptionalKeys<S>]?: Infer<S[K]> }
>;

function schema<T>(check: Schema<T>["check"]): Schema<T> {
  return {
    check,
    parse(value) {
      const errors: string[] = [];
      check(value, "$", errors);
      return errors.length > 0
        ? { ok: false, errors }
        : { ok: true, value: value as T };
    },
  };
}

function str(): Schema<string> {
  return schema((value, path, errors) => {
    if (typeof value !== "string") errors.push(path + ": expected string");
  });
}

function num(): Schema<number> {
  return schema((value, path, errors) => {
    if (typeof value !== "number" || Number.isNaN(value)) {
      errors.push(path + ": expected number");
    }
  });
}

function literal<const V extends readonly (string | number | boolean)[]>(
  ...values: V
): Schema<V[number]> {
  return schema((value, path, errors) => {
    if (!values.some((v) => v === value)) {
      errors.push(path + ": expected one of " + values.join(" | "));
    }
  });
}

function arr<T>(item: Schema<T>): Schema<T[]> {
  return schema((value, path, errors) => {
    if (!Array.isArray(value)) {
      errors.push(path + ": expected array");
      return;
    }
    value.forEach((el, i) => item.check(el, path + "." + i, errors));
  });
}

function obj<S extends Shape>(shape: S): Schema<ObjectOf<S>> {
  return schema((value, path, errors) => {
    if (typeof value !== "object" || value === null || Array.isArray(value)) {
      errors.push(path + ": expected object");
      return;
    }
    const record = value as Record<string, unknown>;
    for (const key of Object.keys(shape)) {
      shape[key].check(record[key], path + "." + key, errors);
    }
  });
}

function optional<T>(inner: Schema<T>): Schema<T | undefined> {
  return schema((value, path, errors) => {
    if (value !== undefined) inner.check(value, path, errors);
  });
}

// ===== Type tests: don't change these =====
function typeTests() {
  const Panda = obj({
    name: str(),
    diet: literal("bamboo", "apples"),
    friends: arr(obj({ name: str(), age: num() })),
    nickname: optional(str()),
  });
  type Panda = Infer<typeof Panda>;
  type cases = [
    Expect<Equal<Panda, {
      name: string;
      diet: "bamboo" | "apples";
      friends: { name: string; age: number }[];
      nickname?: string;
    }>>,
    Expect<Equal<Infer<ReturnType<typeof num>>, number>>,
  ];
  const result = Panda.parse({});
  if (result.ok) {
    const diet: "bamboo" | "apples" = result.value.diet;
  }
  // @ts-expect-error: value only exists when ok is true
  result.value;
}

const Point = obj({ x: num(), y: num() });
console.log(Point.parse({ x: 1, y: "2" }));
```

Each builder returns a `Schema<T>` whose `T` is built from its parts (`arr` wraps it in an array, `obj` maps the shape, `literal` keeps the exact values thanks to the `const` type parameter), so `Infer` just reads `T` back out. Errors are collected into one shared array while the check walks the data with a growing path, which visits each value once: O(size of the data).

</Solution>
