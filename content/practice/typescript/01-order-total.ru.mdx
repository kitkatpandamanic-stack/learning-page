Магазин описывает каждую строку заказа вот таким интерфейсом (interface):

```ts
interface LineItem {
  name: string;
  price: number;    // цена одного товара
  quantity: number;
}
```

Напишите функцию (function) `orderTotal(items, discountCode?)`, которая возвращает итоговую стоимость: `price * quantity` для каждой позиции, всё вместе. Если `discountCode` равен `"PANDA10"`, вычтите из суммы 10%. Любой другой код (или его отсутствие) скидки не даёт. Округлите результат до 2 знаков после запятой: `Math.round(total * 100) / 100`.

Задайте параметрам (parameter) правильные типы: `items` — массив `LineItem`, `discountCode` — необязательная строка `string`, а функция возвращает `number`.

```ts
orderTotal([{ name: "tea", price: 2.5, quantity: 2 }]);            // 5
orderTotal([{ name: "tea", price: 2.5, quantity: 2 }], "PANDA10"); // 4.5
orderTotal([]);                                                   // 0
```

<Solution>

```ts
interface LineItem {
  name: string;
  price: number;
  quantity: number;
}

function orderTotal(items: LineItem[], discountCode?: string): number {
  let total = 0;
  for (const item of items) {
    total += item.price * item.quantity;
  }
  if (discountCode === "PANDA10") total *= 0.9;
  return Math.round(total * 100) / 100;
}

console.log(orderTotal([{ name: "tea", price: 2.5, quantity: 2 }])); // 5
```

Знак `?` в `discountCode?: string` делает параметр необязательным: внутри функции его тип — `string | undefined`, поэтому сравнивать его с `"PANDA10"` безопасно.

</Solution>
