Инструмент командной строки PandaDev принимает аргументы вроде `serve --port 8080 --open notes.md`. Напишите `parseArgs(spec, argv)`: **спецификация** (spec) говорит, какие опции существуют и какого вида каждая, а тип результата выводится из неё, так что `flags.port` имеет тип `number | undefined`, хотя никто не писал этот тип вручную.

```ts
type Kind = "string" | "number" | "boolean";
type Spec = Record<string, Kind>;
type Parsed<S extends Spec> =
  | { ok: true; flags: Flags<S>; positional: string[] }
  | { ok: false; error: string };
```

В `Flags<S>` есть каждый ключ спецификации: опции `"boolean"` имеют тип `boolean`; опции `"string"` и `"number"` — `string | undefined` и `number | undefined`. В результате присутствует каждый ключ спецификации: логические по умолчанию равны `false`, остальные — `undefined`.

Правила чтения `argv` (массива строк) слева направо:

- `--name value` и `--name=value` задают строковую или числовую опцию. Без `=` значением становится следующий аргумент, если только его нет или он начинается с `--`: тогда это ошибка `"--name needs a value"`.
- Числа преобразуются через `Number(value)`; пустой или не конечный результат — ошибка `` `--port expects a number, got "abc"` `` (исходное значение в двойных кавычках).
- `--flag` устанавливает логическую опцию в `true`, а `--no-flag` — в `false`. Логическая опция со значением (`--flag=yes`) — ошибка `"--flag doesn't take a value"`.
- Опция, которой нет в спецификации, — ошибка `"Unknown option --name"`. Если опция встречается дважды, побеждает последняя.
- Всё, что не начинается с `--`, — позиционный аргумент (поэтому `-` и `-5` — позиционные аргументы или значения). После одиночного `--` все оставшиеся аргументы позиционные.
- Остановитесь на первой ошибке и верните `{ ok: false, error }`.

```ts
const spec = { port: "number", open: "boolean", host: "string" } as const;
parseArgs(spec, ["serve", "--port", "8080", "--open", "notes.md"]);
// { ok: true,
//   flags: { port: 8080, open: true, host: undefined },
//   positional: ["serve", "notes.md"] }
parseArgs(spec, ["--port=abc"]);
// { ok: false, error: '--port expects a number, got "abc"' }
```

<Hint>

Для типов основную работу делает тип-таблица от названий видов к типам TypeScript, сопоставленная по ключам спецификации. Во время выполнения проходите по `argv` с индексом, чтобы можно было забрать следующий аргумент как значение, когда опции оно нужно.

</Hint>

Напишите `type KindType = { string: string; number: number; boolean: boolean }`, а затем `Flags<S> = { -readonly [K in keyof S]: S[K] extends "boolean" ? boolean : KindType[S[K]] | undefined }`. Используйте `const`-параметр типа, чтобы спецификация, переданная прямо в вызов, сохранила литеральные виды: `parseArgs<const S extends Spec>(spec: S, argv: readonly string[]): Parsed<S>`. Он же делает ключи `readonly`, поэтому `Flags` убирает модификатор через `-readonly`. Внутри работайте с простыми типами (`const flags: Record<string, unknown> = {}`, сначала заполненный значениями по умолчанию) и приведите тип один раз в конце. В цикле: одиночный `--` делает все оставшиеся аргументы позиционными; всё, что не начинается с `--`, — позиционное; `--x=y` разбивайте по **первому** `=` через `indexOf`. Пробуйте `no-` только если точного имени нет в спецификации, и только для логических опций. Недостающее значение — это следующий аргумент (`i++`), если он есть и не начинается с `--`. При любой ошибке сразу возвращайте `{ ok: false, error }`.

</Hint>

function parseArgs<const S extends Spec>(spec: S, argv: readonly string[]): Parsed<S> {
  const flags: Record<string, unknown> = {};
  for (const [name, kind] of Object.entries(spec)) {
    flags[name] = kind === "boolean" ? false : undefined;
  }
  const positional: string[] = [];
  for (let i = 0; i < argv.length; i++) {
    const arg = argv[i];
    if (arg === "--") {
      positional.push(...argv.slice(i + 1));
      break;

    if (!arg.startsWith("--")) {
      positional.push(arg);
      continue;

    const name = eq === -1 ? arg.slice(2) : arg.slice(2, eq);

<Solution>

```ts
// ===== Помощники для тестов типов: не меняйте =====
type Expect<T extends true> = T;
type Equal<A, B> =
  (<X>() => X extends A ? 1 : 2) extends
  (<X>() => X extends B ? 1 : 2) ? true : false;

type Kind = "string" | "number" | "boolean";
type Spec = Record<string, Kind>;

type KindType = { string: string; number: number; boolean: boolean };
type Flags<S extends Spec> = {
  -readonly [K in keyof S]: S[K] extends "boolean"
    ? boolean
    : KindType[S[K]] | undefined;
};

type Parsed<S extends Spec> =
  | { ok: true; flags: Flags<S>; positional: string[] }
  | { ok: false; error: string };

function parseArgs<const S extends Spec>(
  spec: S,
  argv: readonly string[],
): Parsed<S> {
  const flags: Record<string, unknown> = {};
  for (const [name, kind] of Object.entries(spec)) {
    flags[name] = kind === "boolean" ? false : undefined;
  }
  const positional: string[] = [];
  const fail = (error: string): Parsed<S> => ({ ok: false, error });

  for (let i = 0; i < argv.length; i++) {
    const arg = argv[i];
    if (arg === "--") {
      positional.push(...argv.slice(i + 1));
      break;
    }
    if (!arg.startsWith("--")) {
      positional.push(arg);
      continue;
    }
    const eq = arg.indexOf("=");
    let name = eq === -1 ? arg.slice(2) : arg.slice(2, eq);
    let value = eq === -1 ? undefined : arg.slice(eq + 1);
    let kind: Kind | undefined = spec[name];
    let negated = false;
    if (kind === undefined && name.startsWith("no-")) {
      const base = name.slice(3);
      if (spec[base] === "boolean") {
        name = base;
        kind = "boolean";
        negated = true;
      }
    }
    if (kind === undefined) return fail("Unknown option --" + name);
    if (kind === "boolean") {
      if (value !== undefined) {
        return fail("--" + name + " doesn't take a value");
      }
      flags[name] = !negated;
      continue;
    }
    if (value === undefined) {
      const next = argv[i + 1];
      if (next === undefined || next.startsWith("--")) {
        return fail("--" + name + " needs a value");
      }
      value = next;
      i++;
    }
    if (kind === "number") {
      const n = Number(value);
      if (value.trim() === "" || !Number.isFinite(n)) {
        return fail(
          "--" + name + ' expects a number, got "' + value + '"',
        );
      }
      flags[name] = n;
    } else {
      flags[name] = value;
    }
  }
  return { ok: true, flags: flags as Flags<S>, positional };
}

// ===== Тесты типов: не меняйте их =====
function typeTests() {
  const r = parseArgs(
    { port: "number", open: "boolean", host: "string" },
    [],
  );
  if (r.ok) {
    type cases = [
      Expect<Equal<typeof r.flags, {
        port: number | undefined;
        open: boolean;
        host: string | undefined;
      }>>,
    ];
    // @ts-expect-error: опции "debug" нет
    r.flags.debug;
  }
  // @ts-expect-error: "date" — не Kind
  parseArgs({ when: "date" }, []);
}

const spec = { port: "number", open: "boolean", host: "string" } as const;
console.log(parseArgs(spec, ["serve", "--port", "8080", "--open"]));
```

`Flags<S>` сопоставляет каждому имени опции TypeScript-тип её вида через таблицу `KindType`, а `const`-параметр типа не даёт `"number"` расшириться до `string`, поэтому спецификация — единственный источник истины и для разбора, и для типов. Разборщик делает один проход слева направо с индексом, который можно продвинуть, чтобы забрать значение: O(n) от числа аргументов.

</Solution>
