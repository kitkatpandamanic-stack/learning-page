Заказы бамбукового магазина хранятся одним рыхлым объектом с кучей необязательных полей, поэтому «оплаченный» заказ без времени оплаты легко проскакивает. Замените рыхлые типы **размеченными объединениями** (discriminated unions), а затем напишите конечный автомат, который переводит заказ из состояния в состояние.

`Order` — одна из четырёх форм, которые различаются по `status`. В каждой форме есть `items: string[]`:

- `"cart"`: больше ничего.
- `"paid"`: ещё `paidAt: number`.
- `"shipped"`: ещё `paidAt: number` и `tracking: string`.
- `"cancelled"`: ещё `reason: string`.

`OrderEvent` — одно из `{ type: "add"; item: string }`, `{ type: "pay"; at: number }`, `{ type: "ship"; tracking: string }` или `{ type: "cancel"; reason: string }`.

`transition(order, event)` возвращает следующий заказ, **не изменяя** переданный:

- `add` работает с корзиной: новая корзина с товаром, добавленным в конец.
- `pay` работает с корзиной, в которой есть хотя бы один товар: оплаченный заказ с `paidAt`, равным `event.at`.
- `ship` работает с оплаченным заказом: отправленный заказ с трек-номером (`items` и `paidAt` сохраняются).
- `cancel` работает с корзиной или оплаченным заказом: отменённый заказ с причиной (`items` сохраняются).
- Любая другая комбинация игнорируется: верните **тот же самый** объект заказа.

`describe(order)` возвращает `"cart: N items"`, `"paid at <paidAt>"`, `"shipped: <tracking>"` или `"cancelled: <reason>"`. Используйте `switch` по `status` с исчерпывающей проверкой через `never` в ветке `default`.

```ts
const cart: Order = { status: "cart", items: [] };
const one = transition(cart, { type: "add", item: "tea" });
const paid = transition(one, { type: "pay", at: 1700 });
describe(paid);                                    // "paid at 1700"
transition(cart, { type: "pay", at: 5 }) === cart; // true: пустую корзину оплатить нельзя
transition(paid, { type: "ship", tracking: "PD-7" });
// { status: "shipped", items: ["tea"], paidAt: 1700, tracking: "PD-7" }
```

<Solution>

```ts
type Order =
  | { status: "cart"; items: string[] }
  | { status: "paid"; items: string[]; paidAt: number }
  | {
      status: "shipped";
      items: string[];
      paidAt: number;
      tracking: string;
    }
  | { status: "cancelled"; items: string[]; reason: string };

type OrderEvent =
  | { type: "add"; item: string }
  | { type: "pay"; at: number }
  | { type: "ship"; tracking: string }
  | { type: "cancel"; reason: string };

function assertNever(value: never): never {
  throw new Error("Unexpected value: " + JSON.stringify(value));
}

function transition(order: Order, event: OrderEvent): Order {
  switch (event.type) {
    case "add":
      if (order.status !== "cart") return order;
      return { status: "cart", items: [...order.items, event.item] };
    case "pay":
      if (order.status !== "cart" || order.items.length === 0) {
        return order;
      }
      return { status: "paid", items: order.items, paidAt: event.at };
    case "ship":
      if (order.status !== "paid") return order;
      return { ...order, status: "shipped", tracking: event.tracking };
    case "cancel":
      if (order.status !== "cart" && order.status !== "paid") {
        return order;
      }
      return {
        status: "cancelled",
        items: order.items,
        reason: event.reason,
      };
    default:
      return assertNever(event);
  }
}

function describe(order: Order): string {
  switch (order.status) {
    case "cart":
      return "cart: " + order.items.length + " items";
    case "paid":
      return "paid at " + order.paidAt;
    case "shipped":
      return "shipped: " + order.tracking;
    case "cancelled":
      return "cancelled: " + order.reason;
    default:
      return assertNever(order);
  }
}

// ===== Тесты типов: не меняйте их =====
// @ts-expect-error: оплаченному заказу нужен paidAt
const noDate: Order = { status: "paid", items: ["tea"] };
// @ts-expect-error: "lost" — не статус
const lost: Order = { status: "lost", items: [] };
// @ts-expect-error: событию ship нужен трек-номер
const badEvent: OrderEvent = { type: "ship" };

const cart: Order = { status: "cart", items: ["tea"] };
console.log(describe(transition(cart, { type: "pay", at: 1700 })));
```

Каждый `case` по `event.type` сужает тип события, а каждая проверка `order.status` сужает тип заказа, поэтому `event.item`, `order.paidAt` и прочие поля доступны только там, где они действительно есть. Невозможные заказы (оплаченный без времени, статус, который никто не обрабатывает) больше не компилируются, а `assertNever` превращает забытый `case` в ошибку типов вместо тихого бага.

</Solution>
