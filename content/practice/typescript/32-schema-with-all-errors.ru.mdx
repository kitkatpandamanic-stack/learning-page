Форма регистрации должна сообщать обо **всех** ошибках сразу, а не по одной за каждую отправку. Напишите маленькую библиотеку схем: вы описываете данные один раз, TypeScript **выводит** из этого описания тип, а `parse` проверяет неизвестные данные и перечисляет каждую проблему вместе с её путём.

```ts
type Result<T> = { ok: true; value: T } | { ok: false; errors: string[] };
type Schema<T> = {
  check(value: unknown, path: string, errors: string[]): void;
  parse(value: unknown): Result<T>;
};
```

`check` добавляет в `errors` сообщение `"<path>: <problem>"` для каждой найденной проблемы. `parse(value)` запускает `check` с путём `"$"` и возвращает `{ ok: true, value }` (то же самое значение, которое получил), если ошибок не было, иначе `{ ok: false, errors }`. Строительные блоки:

- `str()` принимает строки, иначе `"expected string"`. `num()` принимает числа, кроме `NaN`, иначе `"expected number"`.
- `literal(...values)` принимает ровно одно из переданных значений (строк, чисел или логических значений), иначе `"expected one of a | b | c"`. Её тип — объединение этих литералов: `literal("bamboo", "apples")` — это `Schema<"bamboo" | "apples">`.
- `arr(item)` требует массив (иначе `"expected array"`), затем проверяет каждый элемент по пути `<path>.<index>`.
- `obj(shape)` требует объект, который не `null` и не массив (иначе `"expected object"`), затем проверяет каждый ключ формы в порядке формы по пути `<path>.<key>`. Лишние ключи разрешены.
- `optional(inner)` принимает `undefined`, а в остальном — то же, что `inner`. Внутри `obj` его ключ становится **необязательным свойством** (`nickname?: string`).

`Infer<S>` даёт тип, который пропускает схема.

```ts
const Panda = obj({
  name: str(),
  diet: literal("bamboo", "apples"),
  friends: arr(obj({ name: str(), age: num() })),
  nickname: optional(str()),
});
type Panda = Infer<typeof Panda>;
// { name: string; diet: "bamboo" | "apples";
//   friends: { name: string; age: number }[]; nickname?: string }

Panda.parse({ name: 7, diet: "fish", friends: [{ name: "Bo", age: "3" }] });
// { ok: false, errors: [
//   "$.name: expected string",
//   "$.diet: expected one of bamboo | apples",
//   "$.friends.0.age: expected number" ] }
```

Для `literal` литералы сохраняет `const`-параметр типа: `literal<const V extends readonly (string | number | boolean)[]>(...values: V): Schema<V[number]>`. `arr` и `obj` добавляют одну ошибку и останавливаются, если контейнер не тот; иначе проверяют каждого потомка по пути `path + "." + i` или `path + "." + key`. `optional` пропускает `undefined`. </Hint>

<Solution>

```ts
// ===== Помощники для тестов типов: не меняйте =====
type Expect<T extends true> = T;
type Equal<A, B> =
  (<X>() => X extends A ? 1 : 2) extends
  (<X>() => X extends B ? 1 : 2) ? true : false;

type Result<T> = { ok: true; value: T } | { ok: false; errors: string[] };
type Schema<T> = {
  check(value: unknown, path: string, errors: string[]): void;
  parse(value: unknown): Result<T>;
};

type Infer<S> = S extends Schema<infer T> ? T : never;

type Shape = Record<string, Schema<unknown>>;
type Simplify<X> = { [K in keyof X]: X[K] };
type OptionalKeys<S extends Shape> = {
  [K in keyof S]: undefined extends Infer<S[K]> ? K : never;
}[keyof S];
type ObjectOf<S extends Shape> = Simplify<
  { [K in Exclude<keyof S, OptionalKeys<S>>]: Infer<S[K]> } &
  { [K in OptionalKeys<S>]?: Infer<S[K]> }
>;

function schema<T>(check: Schema<T>["check"]): Schema<T> {
  return {
    check,
    parse(value) {
      const errors: string[] = [];
      check(value, "$", errors);
      return errors.length > 0
        ? { ok: false, errors }
        : { ok: true, value: value as T };
    },
  };
}

function str(): Schema<string> {
  return schema((value, path, errors) => {
    if (typeof value !== "string") errors.push(path + ": expected string");
  });
}

function num(): Schema<number> {
  return schema((value, path, errors) => {
    if (typeof value !== "number" || Number.isNaN(value)) {
      errors.push(path + ": expected number");
    }
  });
}

function literal<const V extends readonly (string | number | boolean)[]>(
  ...values: V
): Schema<V[number]> {
  return schema((value, path, errors) => {
    if (!values.some((v) => v === value)) {
      errors.push(path + ": expected one of " + values.join(" | "));
    }
  });
}

function arr<T>(item: Schema<T>): Schema<T[]> {
  return schema((value, path, errors) => {
    if (!Array.isArray(value)) {
      errors.push(path + ": expected array");
      return;
    }
    value.forEach((el, i) => item.check(el, path + "." + i, errors));
  });
}

function obj<S extends Shape>(shape: S): Schema<ObjectOf<S>> {
  return schema((value, path, errors) => {
    if (typeof value !== "object" || value === null || Array.isArray(value)) {
      errors.push(path + ": expected object");
      return;
    }
    const record = value as Record<string, unknown>;
    for (const key of Object.keys(shape)) {
      shape[key].check(record[key], path + "." + key, errors);
    }
  });
}

function optional<T>(inner: Schema<T>): Schema<T | undefined> {
  return schema((value, path, errors) => {
    if (value !== undefined) inner.check(value, path, errors);
  });
}

// ===== Тесты типов: не меняйте их =====
function typeTests() {
  const Panda = obj({
    name: str(),
    diet: literal("bamboo", "apples"),
    friends: arr(obj({ name: str(), age: num() })),
    nickname: optional(str()),
  });
  type Panda = Infer<typeof Panda>;
  type cases = [
    Expect<Equal<Panda, {
      name: string;
      diet: "bamboo" | "apples";
      friends: { name: string; age: number }[];
      nickname?: string;
    }>>,
    Expect<Equal<Infer<ReturnType<typeof num>>, number>>,
  ];
  const result = Panda.parse({});
  if (result.ok) {
    const diet: "bamboo" | "apples" = result.value.diet;
  }
  // @ts-expect-error: value есть, только когда ok равно true
  result.value;
}

const Point = obj({ x: num(), y: num() });
console.log(Point.parse({ x: 1, y: "2" }));
```

Каждый построитель возвращает `Schema<T>`, где `T` собирается из частей (`arr` оборачивает его в массив, `obj` проходит по форме, `literal` сохраняет точные значения благодаря `const`-параметру типа), поэтому `Infer` просто достаёт `T` обратно. Ошибки собираются в один общий массив, пока проверка обходит данные с растущим путём; каждое значение посещается один раз — O(размер данных).

</Solution>
