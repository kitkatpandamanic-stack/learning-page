The leaderboard keeps its scores in a `readonly number[]`, so nobody can change the original list by accident. The display code wants the scores **sorted from lowest to highest**.

Write `sortedCopy(scores)` that returns a **new** array with the scores in ascending numeric order. The original array must stay exactly as it was.

The starter already has the right types, but its body calls `scores.sort(...)`. TypeScript rejects that: `sort` changes the array in place, so it doesn't exist on a read-only array. Fix the body, not the types.

Watch out for the classic JavaScript trap: `.sort()` with no compare function sorts as **text**, so `[10, 9, 1]` would become `[1, 10, 9]`.

```ts
const scores: readonly number[] = [10, 9, 1];
sortedCopy(scores);   // [1, 9, 10]
scores;               // still [10, 9, 1]
```

Return a sorted copy of `scores` without mutating it.

<Hint>

TypeScript complains because `sort` changes the array in place, and a `readonly` array doesn't allow that. There's also a second bug: what does `[10, 9, 1].sort()` return?

</Hint>

<Hint>

Make a copy first with `[...scores]`; the copy is a normal, mutable `number[]`. Sort the copy and return it, so the original stays as it was. Give `sort` a compare function that subtracts one number from the other, so it compares numbers instead of text (by default `10` comes before `9`).

</Hint>

<Hint>

```ts
function sortedCopy(scores: readonly number[]): number[] {
  const copy = [...scores];
  return copy.sort(...); // compare as numbers
}
```

</Hint>

<Solution>

```ts
function sortedCopy(scores: readonly number[]): number[] {
  return [...scores].sort((a, b) => a - b);
}

const scores: readonly number[] = [10, 9, 1];
console.log(sortedCopy(scores)); // [ 1, 9, 10 ]
```

`readonly number[]` hides every mutating method (`sort`, `push`, `splice`…), so the bug of sorting someone else's array in place is caught at compile time. Spreading into a new array gives you a copy you're allowed to change. (Modern runtimes also have `scores.toSorted((a, b) => a - b)`, which returns a copy for you.)

</Solution>
