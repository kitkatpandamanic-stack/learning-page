Малые панды ходят между бамбуковыми рощами по тропам с односторонним движением, и каждая тропа занимает сколько-то минут. Напишите `shortestPath(graph, from, to)`, которая находит самый быстрый маршрут.

Граф — это объект, сопоставляющий имени каждого узла его исходящие рёбра `{ [сосед]: минуты }`:

```ts
const forest = {
  den: { river: 4, meadow: 1 },
  meadow: { river: 2, hill: 7 },
  river: { hill: 3 },
  hill: {},
};
shortestPath(forest, "den", "hill");
// { distance: 6, path: ["den", "meadow", "river", "hill"] }
```

- Верните `{ distance, path }` для кратчайшего маршрута: `distance` — суммарный вес, а `path` перечисляет узлы от `from` до `to`. Если несколько маршрутов одинаково коротки, верните любой из них.
- Если `from` и `to` — один и тот же узел, верните `{ distance: 0, path: [from] }`. Если до `to` нельзя добраться, верните `null`.
- Веса могут быть равны `0`, но не могут быть отрицательными: если у какого-либо ребра графа отрицательный вес, выбросьте `RangeError` с сообщением `"Negative edge weight: a -> b"`.
- Решение должно быть быстрым: используйте **алгоритм Дейкстры** (Dijkstra's algorithm) с двоичной кучей (binary heap) в качестве очереди с приоритетом, чтобы граф из 20 000 узлов обрабатывался за миллисекунды, а не за секунды.

Типы проверяют имена: рёбра могут указывать только на узлы графа, `from` и `to` должны быть узлами графа, а `path` типизирован именами узлов.

<Hint>

**Типы:** `function shortestPath<N extends string>(graph: Record<N, Partial<Record<NoInfer<N>, number>>>, from: NoInfer<N>, to: NoInfer<N>)`. `N` выводится только из ключей графа; `NoInfer` заставляет TypeScript **проверять** по нему цели рёбер и оба имени, а не расширять `N`, включая их.

</Hint>

<Hint>

**Алгоритм:** храните `dist` (лучшее известное расстояние до узла) и `prev` (узел, из которого вы пришли) в `Map`, а также min-кучу пар `[distance, node]`. Извлекайте ближайший узел; пропускайте его, если он уже завершён; останавливайтесь, когда это `to`. Для каждого ребра, если `d + weight` лучше, чем `dist.get(next)`, обновите обе карты и добавьте в кучу `[d + weight, next]`. Восстановите путь, идя по `prev` назад от `to` (добавляйте в конец, затем один раз разверните). Куча — это массив, где потомки `i` — это `2i + 1` и `2i + 2`: добавление — положить в конец и поднимать обменами вверх; извлечение — перенести последний элемент наверх и опускать обменами вниз.

</Hint>

<Solution>

```ts
// ===== Помощники для тестов типов: не меняйте =====
type Expect<T extends true> = T;
type Equal<A, B> =
  (<X>() => X extends A ? 1 : 2) extends
  (<X>() => X extends B ? 1 : 2) ? true : false;

class MinHeap<T> {
  private items: [number, T][] = [];

  get size(): number {
    return this.items.length;
  }

  push(priority: number, value: T): void {
    const items = this.items;
    items.push([priority, value]);
    let i = items.length - 1;
    while (i > 0) {
      const parent = (i - 1) >> 1;
      if (items[parent][0] <= items[i][0]) break;
      [items[parent], items[i]] = [items[i], items[parent]];
      i = parent;
    }
  }

  pop(): [number, T] | undefined {
    const items = this.items;
    const top = items[0];
    const last = items.pop();
    if (items.length > 0 && last) {
      items[0] = last;
      let i = 0;
      while (true) {
        const left = 2 * i + 1;
        const right = left + 1;
        let min = i;
        if (left < items.length && items[left][0] < items[min][0]) {
          min = left;
        }
        if (right < items.length && items[right][0] < items[min][0]) {
          min = right;
        }
        if (min === i) break;
        [items[min], items[i]] = [items[i], items[min]];
        i = min;
      }
    }
    return top;
  }
}

function shortestPath<N extends string>(
  graph: Record<N, Partial<Record<NoInfer<N>, number>>>,
  from: NoInfer<N>,
  to: NoInfer<N>,
): { distance: number; path: N[] } | null {
  const edges = (node: N) =>
    Object.entries(graph[node] ?? {}) as [N, number][];
  for (const node of Object.keys(graph) as N[]) {
    for (const [next, weight] of edges(node)) {
      if (weight < 0) {
        throw new RangeError(
          "Negative edge weight: " + node + " -> " + next,
        );
      }
    }
  }
  const dist = new Map<N, number>([[from, 0]]);
  const prev = new Map<N, N>();
  const done = new Set<N>();
  const heap = new MinHeap<N>();
  heap.push(0, from);
  while (heap.size > 0) {
    const [d, node] = heap.pop()!;
    if (done.has(node)) continue;
    done.add(node);
    if (node === to) break;
    for (const [next, weight] of edges(node)) {
      const candidate = d + weight;
      if (candidate < (dist.get(next) ?? Infinity)) {
        dist.set(next, candidate);
        prev.set(next, node);
        heap.push(candidate, next);
      }
    }
  }
  if (!done.has(to)) return null;
  const path: N[] = [to];
  while (path[path.length - 1] !== from) {
    path.push(prev.get(path[path.length - 1])!);
  }
  return { distance: dist.get(to)!, path: path.reverse() };
}
```

Алгоритм Дейкстры всегда следующим завершает ближайший незавершённый узел, и при неотрицательных весах расстояние до этого узла позже улучшиться уже не может — поэтому отрицательные веса отвергаются заранее. Куча делает выбор «ближайшего следующего» за O(log n), что в сумме даёт O((V + E) log V) вместо O(V²) при переборе всех узлов каждый раз; устаревшие записи в куче просто пропускаются при извлечении.
