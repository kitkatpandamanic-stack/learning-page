Панды голосуют за любимое лакомство. Каждый голос — строка, но печатают панды небрежно: `"Bamboo"`, `" bamboo"` и `"BAMBOO "` — это один и тот же голос.

Напишите `tallyVotes(votes)`, которая принимает массив строк и возвращает `Record<string, number>`: каждый ключ — лакомство **в нижнем регистре и без пробелов по краям**, а значение (value) — сколько голосов оно набрало.

- Голоса, которые после обрезки пробелов оказались пустыми, не учитываются.
- Если голосов нет, получается пустой объект `{}`.
- Ключи идут в том порядке, в котором лакомства встретились впервые.

```ts
tallyVotes(["Bamboo", " apple", "BAMBOO "]); // { bamboo: 2, apple: 1 }
tallyVotes(["  ", ""]);                      // {}
```

Типизируйте `tallyVotes` и соберите очищенные голоса в объект.

<Hint>

Начните с `const counts: Record<string, number> = {};`. Каждый голос очистите через `.trim().toLowerCase()`, пропустите, если он пустой, и прибавьте единицу: `counts[key] = (counts[key] ?? 0) + 1`.

</Hint>

<Solution>

```ts
function tallyVotes(votes: string[]): Record<string, number> {
  const counts: Record<string, number> = {};
  for (const vote of votes) {
    const key = vote.trim().toLowerCase();
    if (key === "") continue;
    counts[key] = (counts[key] ?? 0) + 1;
  }
  return counts;
}

function typeTests() {
  const counts: Record<string, number> = tallyVotes(["tea"]);
  // @ts-expect-error
  tallyVotes([1, 2]);
}

console.log(tallyVotes(["Bamboo", " apple", "BAMBOO "]));
```

`Record<string, number>` означает «любой строковый ключ, значение всегда число» — это и есть таблица подсчёта. Чтение ключа, которого ещё нет, во время выполнения даёт `undefined`, поэтому `?? 0` задаёт начальное значение счётчика.

</Solution>
