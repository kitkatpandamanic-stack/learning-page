The zoo shop sells in three currencies: `"GBP"`, `"EUR"` and `"USD"`. Write `formatPrice(amount, currency)` that turns a number into a price tag:

- Start with the currency symbol: `£` for GBP, `€` for EUR, `$` for USD.
- Always show exactly **2 decimal places**.
- Group the whole part in thousands with commas: `1234567.5` → `1,234,567.50`.
- Negative amounts get a minus sign **before** the symbol: `-5` in GBP → `-£5.00`.

Types first: make `Currency` a union of the three codes (not `string`), and type the symbol table as `Record<Currency, string>`, so forgetting a currency, or asking for one the shop doesn't sell, is a compile error.

```ts
formatPrice(4.5, "GBP");       // "£4.50"
formatPrice(1234567.5, "EUR"); // "€1,234,567.50"
formatPrice(-5, "USD");        // "-$5.00"
formatPrice(5, "JPY");         // ❌ compile error
```

Tighten the types, then build the price tag string. The `@ts-expect-error` lines are type tests: they pass only when that line **is** an error.

<Hint>

`Math.abs(amount).toFixed(2)` gives `"1234567.50"`. Split it at the `"."`, add commas to the whole part (a loop from the right works, or the regex `/\B(?=(\d{3})+(?!\d))/g` replaced with `","`), then glue the sign, symbol and parts together.

</Hint>

<Solution>

```ts
type Currency = "GBP" | "EUR" | "USD";

const symbols: Record<Currency, string> = {
  GBP: "£",
  EUR: "€",
  USD: "$",
};

function formatPrice(amount: number, currency: Currency): string {
  const [whole, cents] = Math.abs(amount).toFixed(2).split(".");
  const grouped = whole.replace(/\B(?=(\d{3})+(?!\d))/g, ",");
  const sign = amount < 0 ? "-" : "";
  return `${sign}${symbols[currency]}${grouped}.${cents}`;
}

function typeTests() {
  formatPrice(1, "EUR");
  // @ts-expect-error: the shop doesn't sell in yen
  formatPrice(5, "JPY");
  // @ts-expect-error: the table has no yen symbol either
  symbols.JPY;
}

console.log(formatPrice(1234567.5, "EUR")); // €1,234,567.50
```

`Record<Currency, string>` must have a key for every currency, so adding `"CNY"` to the union later makes TypeScript point at the table until you add its symbol. The regex inserts a comma at every position that is followed by a multiple of three digits up to the end of the whole part.

</Solution>
