Журнал кормления хранит имена панд в одном массиве, а килограммы съеденного бамбука — в другом. Напишите два дженерик-помощника:

- `zip(as, bs)` возвращает массив пар `[as[i], bs[i]]`. Если длины массивов разные, она **останавливается на более коротком**.
- `unzip(pairs)` делает обратное: возвращает кортеж из двух массивов — первые элементы всех пар и вторые. Если пар нет, получается `[[], []]`.

Ни одна из функций не изменяет входные данные.

```ts
zip(["Mei", "Bao", "Lin"], [12, 9]);   // [["Mei", 12], ["Bao", 9]]
unzip([["Mei", 12], ["Bao", 9]]);      // [["Mei", "Bao"], [12, 9]]
unzip([]);                             // [[], []]
```

Типы: используйте два параметра типа, `A` и `B`. `zip` принимает `readonly A[]` и `readonly B[]` и возвращает `[A, B][]` — массив **кортежей** (tuples), а не `(A | B)[][]`. `unzip` принимает `readonly (readonly [A, B])[]` и возвращает кортеж `[A[], B[]]`. Тогда у `zip(names, kilos)` будет тип `[string, number][]`, а вызывающий код сможет написать `const [names, kilos] = unzip(log)` и получить `string[]` и `number[]`.

Сделайте `zip` и `unzip` дженериками с типами-кортежами и реализуйте их. Строки с `@ts-expect-error` проходят, только если в этой строке **есть** ошибка.

<Hint>

`function zip<A, B>(as: readonly A[], bs: readonly B[]): [A, B][]`: пройдите циклом по `i` до `Math.min(as.length, bs.length)` и добавляйте `[as[i], bs[i]]`. Для `unzip` заведите два массива, `const firsts: A[] = []` и `const seconds: B[] = []`, а затем `return [firsts, seconds]`.

</Hint>

<Solution>

```ts
function zip<A, B>(as: readonly A[], bs: readonly B[]): [A, B][] {
  const pairs: [A, B][] = [];
  const length = Math.min(as.length, bs.length);
  for (let i = 0; i < length; i++) {
    pairs.push([as[i], bs[i]]);
  }
  return pairs;
}

function unzip<A, B>(pairs: readonly (readonly [A, B])[]): [A[], B[]] {
  const firsts: A[] = [];
  const seconds: B[] = [];
  for (const [a, b] of pairs) {
    firsts.push(a);
    seconds.push(b);
  }
  return [firsts, seconds];
}

function typeTests() {
  const log: [string, number][] = zip(["Mei", "Bao"], [12, 9]);
  const [names, kilos]: [string[], number[]] = unzip(log);
  // @ts-expect-error: пары имеют тип [string, number], а не [number, string]
  const flipped: [number, string][] = zip(["Mei"], [12]);
  // @ts-expect-error: unzip нужны пары, а не отдельные значения
  unzip([1, 2, 3]);
}

console.log(zip(["Mei", "Bao", "Lin"], [12, 9])); // [ [ 'Mei', 12 ], [ 'Bao', 9 ] ]
```

Тип-кортеж `[A, B]` помнит, какой тип стоит на какой позиции, а `(A | B)[]` это знание потерял бы. Аннотация `pairs` как `[A, B][]` тоже важна: без неё `[as[i], bs[i]]` был бы выведен как массив `A | B`. Обе функции делают один проход за O(n).

</Solution>
