Админская таблица зоопарка позволяет смотрителям сортировать сразу по нескольким столбцам, например «сначала старшие, затем по имени». Напишите `sortBy(items, keys)`, где `keys` — список ключей сортировки:

```ts
type SortKey<T> = { key: keyof T; direction: "asc" | "desc" };
```

Правила:

- Сравнивайте два элемента по **первому** ключу сортировки. Если по нему они равны, сравнивайте по второму ключу и так далее.
- `"asc"` ставит меньшие значения первыми, `"desc"` — бо́льшие. Значения — числа или строки, их сравнивают операторами `<` и `>` (поэтому строки сравниваются по кодам символов: `"Z"` идёт раньше `"a"`).
- Элементы, равные по всем ключам, сохраняют исходный порядок. Пустой список `keys` сохраняет исходный порядок.
- Возвращайте **новый** массив; входной не меняется.

```ts
const pandas = [
  { name: "Mei", age: 4 },
  { name: "Bao", age: 7 },
  { name: "Lin", age: 4 },
];
sortBy(pandas, [{ key: "age", direction: "desc" }, { key: "name", direction: "asc" }]);
// Bao (7), Lin (4), Mei (4)
```

Типы: `SortKey<T>` — дженерик, поэтому в `key` принимаются только настоящие имена свойств (опечатка вроде `"agee"` — ошибка компиляции), а направление — это `"asc" | "desc"`, а не любая строка. `sortBy` возвращает `T[]` с тем же типом элементов, что ей передали.

<Solution>

```ts
type SortKey<T> = { key: keyof T; direction: "asc" | "desc" };

function sortBy<T>(items: readonly T[], keys: readonly SortKey<T>[]): T[] {
  return [...items].sort((a, b) => {
    for (const { key, direction } of keys) {
      const sign = direction === "asc" ? 1 : -1;
      if (a[key] < b[key]) return -sign;
      if (a[key] > b[key]) return sign;
    }
    return 0;
  });
}

interface Panda {
  name: string;
  age: number;
}
function typeTests(pandas: Panda[]) {
  const sorted: Panda[] = sortBy(pandas, [
    { key: "age", direction: "desc" },
    { key: "name", direction: "asc" },
  ]);
  // @ts-expect-error: такого свойства нет
  sortBy(pandas, [{ key: "agee", direction: "asc" }]);
  // @ts-expect-error: направление — "asc" или "desc"
  sortBy(pandas, [{ key: "age", direction: "up" }]);
  // @ts-expect-error: результат по-прежнему Panda[]
  const names: string[] = sortBy(pandas, []);
}

const pandas: Panda[] = [
  { name: "Mei", age: 4 },
  { name: "Bao", age: 7 },
  { name: "Lin", age: 4 },
];
const byAge = sortBy(pandas, [
  { key: "age", direction: "desc" },
  { key: "name", direction: "asc" },
]);
console.log(byAge.map((p) => p.name)); // [ 'Bao', 'Lin', 'Mei' ]
```

`keyof T` связывает ключи сортировки с типом элементов, который TypeScript выводит из `items`, поэтому имена столбцов проверяются по настоящим данным. Функция сравнения останавливается на первом ключе, который различает два элемента, — это и есть смысл слов «а затем по». Сортировка требует O(n log n) сравнений, и каждое стоит не больше одной проверки на каждый ключ сортировки.

</Solution>
