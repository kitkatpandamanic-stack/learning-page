Пересчитывать бамбук в большом лесу долго, поэтому хочется запоминать уже найденные ответы. Напишите `memoize(fn, keyOf?)`: она возвращает функцию, которая ведёт себя как `fn`, но кэширует результаты. У возвращаемой функции должны быть **те же типы параметров и возвращаемого значения**, что у `fn` (без `any`), плюс два метода:

```ts
type Memo<A extends unknown[], R> = {
  (...args: A): R;
  size(): number; // сколько результатов в кэше
  clear(): void;  // забыть всё
};
```

- Ключ кэша — `keyOf(...args)`, если `keyOf` передан, иначе `JSON.stringify(args)`.
- Вызов с уже встречавшимся ключом возвращает результат из кэша без вызова `fn`, даже если этот результат был `undefined`.
- Если `fn` выбрасывает исключение, ничего не кэшируется, ошибка доходит до вызывающего кода, и следующий вызов пробует снова.
- Если `fn` возвращает промис, который потом **отклоняется**, его запись удаляется из кэша, и следующий вызов пробует снова. Выполнившиеся промисы остаются в кэше.

```ts
let calls = 0;
const area = memoize((w: number, h: number) => {
  calls++;
  return w * h;
});
area(3, 4); // 12
area(3, 4); // 12 из кэша: calls всё ещё 1
area.size(); // 1

const byName = memoize(
  (name: string) => name.length,
  (name) => name.toLowerCase(),
);
byName("Mei"); byName("MEI"); // один вызов: ключ один и тот же — "mei"
```

<Solution>

```ts
type Memo<A extends unknown[], R> = {
  (...args: A): R;
  size(): number;
  clear(): void;
};

function memoize<A extends unknown[], R>(
  fn: (...args: A) => R,
  keyOf?: (...args: A) => string,
): Memo<A, R> {
  const cache = new Map<string, R>();
  const memo = (...args: A): R => {
    const key = keyOf ? keyOf(...args) : JSON.stringify(args);
    if (cache.has(key)) return cache.get(key) as R;
    const result = fn(...args); // если тут исключение, в кэш ничего не попадёт
    cache.set(key, result);
    if (result instanceof Promise) {
      result.catch(() => cache.delete(key));
    }
    return result;
  };
  return Object.assign(memo, {
    size: () => cache.size,
    clear: () => cache.clear(),
  });
}

// ===== Тесты типов: не меняйте их =====
function typeTests() {
  const add = memoize((a: number, b: number) => a + b);
  const sum: number = add(1, 2);
  // @ts-expect-error: add принимает числа
  add("1", 2);
  // @ts-expect-error: add возвращает число
  const text: string = add(1, 2);
  // @ts-expect-error: keyOf должен принимать те же аргументы, что и fn
  memoize((id: number) => id, (id: string) => id);
  return [sum, text, add.size()];
}

let calls = 0;
const area = memoize((w: number, h: number) => {
  calls++;
  return w * h;
});
console.log(area(3, 4), area(3, 4), calls); // 12 12 1
```

`A extends unknown[]` захватывает весь список параметров как кортеж (`[w: number, h: number]`), а `R` — тип возвращаемого значения, поэтому мемоизированная функция типизирована точно как исходная. `Object.assign` возвращает функцию вместе с добавленными методами как одно значение типа `typeof memo & { size…; clear… }`, и оно подходит под `Memo<A, R>`. Попадание в кэш стоит O(1) плюс стоимость построения ключа.

</Solution>
