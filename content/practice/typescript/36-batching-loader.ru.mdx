Страница показывает 50 комментариев, и каждый загружает своего автора: 50 запросов ради, может быть, 6 разных пользователей. **Пакетный загрузчик** (batching loader — идея, лежащая в основе популярной библиотеки DataLoader) собирает все `load`, сделанные в один и тот же момент, один раз запрашивает у сервера все эти ключи и отдаёт каждому вызывающему его собственный результат. Напишите типизированную версию.

```ts
type BatchFn<K, V> = (keys: readonly K[]) => Promise<readonly (V | Error)[]>;
```

`new Loader<K, V>(batch, options?)`, где `options` может содержать `maxBatchSize`:

- `load(key)` возвращает `Promise<V>`. Все вызовы `load`, сделанные друг за другом без `await` (в одном и том же обороте цикла событий), отправляются **одним** вызовом `batch`, причём каждый ключ — один раз, в порядке первого запроса.
- `batch` должен выполниться с одним результатом на ключ, в том же порядке. Результат, который является `Error`, отклоняет промис этого ключа этой ошибкой. Если `batch` отклоняется, каждый ключ этого пакета отклоняется той же ошибкой. Если он вернул неверное число результатов, каждый ключ этого пакета отклоняется с `TypeError`: `"Batch returned 2 results for 3 keys"`.
- Результаты **кэшируются** по ключу: загрузка ключа, который уже загружен или ещё в пути, возвращает тот же промис без нового пакета. Ключи, загрузка которых провалилась (по любой из причин выше), удаляются из кэша, поэтому повторная загрузка пробует снова.
- С `maxBatchSize` пакет с большим числом ключей разбивается на несколько вызовов `batch` не больше чем по стольку ключей, и все они запускаются сразу.
- `loadMany(keys)` загружает несколько ключей и выполняется со всеми значениями по порядку (отклоняется, если хоть один провалился). `clear(key)` удаляет ключ из кэша и возвращает загрузчик.

```ts
const calls: number[][] = [];
const users = new Loader<number, string>(async (ids) => {
  calls.push([...ids]);
  return ids.map((id) => "panda " + id);
});
const [a, b, c] = await Promise.all([users.load(1), users.load(2), users.load(1)]);
// a = "panda 1", b = "panda 2", c = "panda 1", calls = [[1, 2]]
await users.load(2); // из кэша: calls всё ещё [[1, 2]]
```

<Solution>

```ts
type BatchFn<K, V> = (
  keys: readonly K[],
) => Promise<readonly (V | Error)[]>;

type Pending<K, V> = {
  key: K;
  resolve: (value: V) => void;
  reject: (error: unknown) => void;
};

class Loader<K, V> {
  private cache = new Map<K, Promise<V>>();
  private queue: Pending<K, V>[] = [];
  private readonly batch: BatchFn<K, V>;
  private readonly maxBatchSize: number;

  constructor(
    batch: BatchFn<K, V>,
    options: { maxBatchSize?: number } = {},
  ) {
    this.batch = batch;
    this.maxBatchSize = options.maxBatchSize ?? Infinity;
  }

  load(key: K): Promise<V> {
    const cached = this.cache.get(key);
    if (cached) return cached;
    const promise = new Promise<V>((resolve, reject) => {
      this.queue.push({ key, resolve, reject });
    });
    this.cache.set(key, promise);
    if (this.queue.length === 1) queueMicrotask(() => this.dispatch());
    return promise;
  }

  loadMany(keys: readonly K[]): Promise<V[]> {
    return Promise.all(keys.map((key) => this.load(key)));
  }

  clear(key: K): this {
    this.cache.delete(key);
    return this;
  }

  private dispatch(): void {
    const queue = this.queue;
    this.queue = [];
    for (let i = 0; i < queue.length; i += this.maxBatchSize) {
      this.run(queue.slice(i, i + this.maxBatchSize));
    }
  }

  private async run(items: Pending<K, V>[]): Promise<void> {
    const fail = (item: Pending<K, V>, error: unknown) => {
      this.cache.delete(item.key);
      item.reject(error);
    };
    let results: readonly (V | Error)[];
    try {
      results = await this.batch(items.map((item) => item.key));
    } catch (error) {
      for (const item of items) fail(item, error);
      return;
    }
    if (results.length !== items.length) {
      const error = new TypeError(
        `Batch returned ${results.length} results for ${items.length} keys`,
      );
      for (const item of items) fail(item, error);
      return;
    }
    items.forEach((item, i) => {
      const result = results[i];
      if (result instanceof Error) fail(item, result);
      else item.resolve(result);
    });
  }
}

// ===== Тесты типов: не меняйте их =====
type User = { id: number; name: string };

function typeTests() {
  const users = new Loader<number, User>(async (ids) =>
    ids.map((id) => ({ id, name: "panda " + id })),
  );
  const user: Promise<User> = users.load(1);
  // @ts-expect-error: ключи — числа
  users.load("1");
  // @ts-expect-error: load выполняется с User
  const count: Promise<number> = users.load(1);
  // @ts-expect-error: batch должен возвращать User (или Error)
  new Loader<number, User>(async (ids) => ids.map((id) => id));
  return [user, count];
}

const calls: number[][] = [];
const users = new Loader<number, string>(async (ids) => {
  calls.push([...ids]);
  return ids.map((id) => "panda " + id);
});
const names = await Promise.all([users.load(1), users.load(2), users.load(1)]);
console.log(names, calls); // [ 'panda 1', 'panda 2', 'panda 1' ] [ [ 1, 2 ] ]
```

Первый `load` за оборот планирует микрозадачу, и каждый `load` до её запуска попадает в ту же очередь, поэтому один оборот синхронных вызовов превращается в один пакет. Кэш хранит промисы, а не значения, что бесплатно убирает повторы ключей и внутри пакета, и между пакетами; удаление проваленных ключей не даёт ошибкам «прилипнуть». Постановка каждого ключа в очередь стоит O(1), а `batch` вызывается ⌈n / maxBatchSize⌉ раз за оборот.
