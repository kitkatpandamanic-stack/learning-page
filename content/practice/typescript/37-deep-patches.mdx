The PandaDev editor saves user settings as **patches**: only what changed, at any depth. `Partial<Settings>` isn't enough, because it only makes the top level optional. Write `DeepPartial<T>` and the two functions that make patches useful.

`DeepPartial<T>` makes every property optional at every depth of plain objects. Arrays, functions and `Date`s are **leaves**: their type stays exactly as it is (a patch replaces a whole array, it doesn't patch items).

- `mergeDeep(base, patch)` returns a new value: for every key of `patch` whose value isn't `undefined`, if both sides are **plain objects** (made with `{}`, not arrays, `null`, dates…), merge them recursively; otherwise the patch's value replaces the base's. `undefined` in a patch means "leave it alone"; `null` is a real value. Neither argument is changed.
- `diff(before, after)` returns the **smallest** patch that turns `before` into `after`: it keeps only keys whose values differ, recursing into plain objects on both sides (a nested object with no differences is left out, so equal inputs give `{}`). Arrays are equal when they have the same length and the same items (`Object.is`, item by item); other values are compared with `Object.is`. Keys that only exist in `before` are ignored.

`mergeDeep(before, diff(before, after))` gives back an object deeply equal to `after`.

```ts
const settings = {
  theme: { mode: "light", accent: "green" },
  fontSize: 14,
  plugins: ["git"],
};
mergeDeep(settings, { theme: { mode: "dark" }, plugins: ["git", "vim"] });
// { theme: { mode: "dark", accent: "green" }, fontSize: 14, plugins: ["git", "vim"] }
diff(settings, { ...settings, theme: { mode: "light", accent: "red" } });
// { theme: { accent: "red" } }
```

Write `DeepPartial`, `mergeDeep` and `diff`. The `Expect<Equal<…>>` line and the `@ts-expect-error` line are type tests; the second kind passes only when that line **is** an error. With the starter's `Partial`, a nested patch like `{ theme: { mode: "dark" } }` doesn't even compile.

<Hint>

In the type, check for leaves (arrays, dates, functions) **before** recursing into objects. At runtime, everything depends on telling a plain object apart from an array, `null` or a `Date`; `Object.getPrototypeOf` can help.

</Hint>

<Hint>

`DeepPartial<T>` is `T extends readonly unknown[] | Date | ((...args: never[]) => unknown) ? T : T extends object ? { [K in keyof T]?: DeepPartial<T[K]> } : T`. Write a type guard `isPlainObject(value: unknown): value is Record<string, unknown>` that checks `typeof value === "object"`, `value !== null` and `Object.getPrototypeOf(value) === Object.prototype` (arrays and dates fail it). `mergeDeep` copies the base, walks `Object.entries(patch)`, skips `undefined`, recurses when both sides are plain objects and otherwise takes the patch's value. `diff` walks `Object.entries(after)`: recurse when both sides are plain objects (keep the result only if it has keys), compare arrays by length and item by item, and use `Object.is` for everything else. Cast once at the end (`as T` / `as DeepPartial<T>`): TypeScript can't follow the recursion.

</Hint>

<Hint>

```ts
type DeepPartial<T> = T extends readonly unknown[] | Date | ((...args: never[]) => unknown)
  ? T
  : ...; // plain objects: every key optional, recursively; anything else stays T

function isPlainObject(value: unknown): value is Record<string, unknown> {
  return typeof value === "object" && value !== null &&
    Object.getPrototypeOf(value) === Object.prototype;
}

function merge(base: unknown, patch: Record<string, unknown>): Record<string, unknown> {
  const result: Record<string, unknown> = isPlainObject(base) ? { ...base } : {};
  for (const [key, value] of Object.entries(patch)) {
    if (value === undefined) continue;
    result[key] = ...; // merge again if both sides are plain objects, else value
  }
  return result;
}
```

`mergeDeep` calls `merge` and casts the result; `diff` walks `after` in a similar loop.

</Hint>

<Solution>

```ts
// ===== Type-test helpers: don't change =====
type Expect<T extends true> = T;
type Equal<A, B> =
  (<X>() => X extends A ? 1 : 2) extends
  (<X>() => X extends B ? 1 : 2) ? true : false;

type Leaf = readonly unknown[] | Date | ((...args: never[]) => unknown);

type DeepPartial<T> = T extends Leaf
  ? T
  : T extends object
    ? { [K in keyof T]?: DeepPartial<T[K]> }
    : T;

type Bag = Record<string, unknown>;

function isPlainObject(value: unknown): value is Bag {
  return (
    typeof value === "object" &&
    value !== null &&
    Object.getPrototypeOf(value) === Object.prototype
  );
}

function merge(base: unknown, patch: Bag): Bag {
  const result: Bag = isPlainObject(base) ? { ...base } : {};
  for (const [key, value] of Object.entries(patch)) {
    if (value === undefined) continue;
    result[key] =
      isPlainObject(value) && isPlainObject(result[key])
        ? merge(result[key], value)
        : value;
  }
  return result;
}

function mergeDeep<T>(base: T, patch: DeepPartial<T>): T {
  return merge(base, patch as Bag) as T;
}

function sameArray(a: unknown[], b: unknown[]): boolean {
  return a.length === b.length && a.every((x, i) => Object.is(x, b[i]));
}

function changes(before: Bag, after: Bag): Bag {
  const patch: Bag = {};
  for (const [key, value] of Object.entries(after)) {
    const old = before[key];
    if (isPlainObject(old) && isPlainObject(value)) {
      const inner = changes(old, value);
      if (Object.keys(inner).length > 0) patch[key] = inner;
    } else if (Array.isArray(old) && Array.isArray(value)) {
      if (!sameArray(old, value)) patch[key] = value;
    } else if (!Object.is(old, value)) {
      patch[key] = value;
    }
  }
  return patch;
}

function diff<T>(before: T, after: T): DeepPartial<T> {
  return changes(before as Bag, after as Bag) as DeepPartial<T>;
}

// ===== Type tests: don't change these =====
type Mode = "light" | "dark";
type Settings = {
  theme: { mode: Mode; accent: string };
  fontSize: number;
  plugins: string[];
  savedAt: Date;
  onSave: (text: string) => void;
};

type cases = [
  Expect<Equal<DeepPartial<Settings>, {
    theme?: { mode?: Mode; accent?: string };
    fontSize?: number;
    plugins?: string[];
    savedAt?: Date;
    onSave?: (text: string) => void;
  }>>,
];

function typeTests(settings: Settings) {
  const next: Settings = mergeDeep(settings, { theme: { mode: "dark" } });
  // @ts-expect-error: "blue" is not a Mode
  mergeDeep(settings, { theme: { mode: "blue" } });
  return next;
}

const settings = {
  theme: { mode: "light", accent: "green" },
  fontSize: 14,
  plugins: ["git"],
};
console.log(mergeDeep(settings, { theme: { mode: "dark" } }));
```

`DeepPartial` stops at leaves before recursing, otherwise arrays would turn into objects with optional numeric keys and functions would lose their call signature. Both runtime functions walk only the keys that are present and copy just the objects they visit, so they're O(size of the patch or the new value). The `isPlainObject` test is what keeps dates, arrays and class instances from being merged key by key.

</Solution>
