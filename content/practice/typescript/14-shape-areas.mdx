The zoo is planning new enclosures, drawn from three kinds of shape. Each shape is an object with a `kind` tag and the measurements that kind needs:

| `kind` | other properties | area |
| --- | --- | --- |
| `"circle"` | `radius` | π × radius² |
| `"rect"` | `width`, `height` | width × height |
| `"triangle"` | `base`, `height` | base × height ÷ 2 |

1. Replace `type Shape = unknown` with a **discriminated union** of the three object types, so a circle with a `width`, or a `"hexagon"`, doesn't compile.
2. `area(shape)` returns the shape's area **rounded to 2 decimal places** (`Math.round(x * 100) / 100`). Use `Math.PI` for π.
3. `totalArea(shapes)` returns the sum of the **unrounded** areas, rounded to 2 decimal places at the end. No shapes gives `0`.

All measurements are positive numbers.

```ts
area({ kind: "circle", radius: 1 });                // 3.14
area({ kind: "rect", width: 2, height: 3.5 });      // 7
area({ kind: "triangle", base: 4, height: 5 });     // 10
totalArea([{ kind: "circle", radius: 1 }, { kind: "circle", radius: 1 }]); // 6.28
area({ kind: "circle", width: 2 });                 // ❌ compile error
```

<Hint>

Write one object type per shape, each with a literal `kind` (`{ kind: "circle"; radius: number }` and so on), and join them with `|`. In `area`, `switch (shape.kind)`: inside each `case`, TypeScript knows which properties exist. Keep an unrounded helper so `totalArea` can add exact values.

</Hint>

<Solution>

```ts
type Circle = { kind: "circle"; radius: number };
type Rect = { kind: "rect"; width: number; height: number };
type Triangle = { kind: "triangle"; base: number; height: number };
type Shape = Circle | Rect | Triangle;

const round2 = (x: number): number => Math.round(x * 100) / 100;

function exactArea(shape: Shape): number {
  switch (shape.kind) {
    case "circle":
      return Math.PI * shape.radius ** 2;
    case "rect":
      return shape.width * shape.height;
    case "triangle":
      return (shape.base * shape.height) / 2;
    default: {
      const unreachable: never = shape;
      return unreachable;
    }
  }
}

function area(shape: Shape): number {
  return round2(exactArea(shape));
}

function totalArea(shapes: readonly Shape[]): number {
  let total = 0;
  for (const shape of shapes) total += exactArea(shape);
  return round2(total);
}

function typeTests() {
  area({ kind: "circle", radius: 1 });
  area({ kind: "rect", width: 2, height: 3 });
  area({ kind: "triangle", base: 4, height: 5 });
  // @ts-expect-error: circles have a radius, not a width
  area({ kind: "circle", width: 2 });
  // @ts-expect-error: rectangles need a height
  area({ kind: "rect", width: 2 });
  // @ts-expect-error: there are no hexagons
  area({ kind: "hexagon", side: 1 });
}

console.log(area({ kind: "circle", radius: 1 })); // 3.14
```

The `kind` tag lets the `switch` narrow `shape` to one member, so `shape.radius` only type-checks in the circle case. The `never` line in `default` is an exhaustiveness check: add a `"square"` to the union and forget its case, and TypeScript reports that a `Square` is not assignable to `never`. Rounding once at the end avoids adding up rounding errors: seven unit circles cover 21.99, but adding seven rounded 3.14s gives 21.98.

</Solution>
