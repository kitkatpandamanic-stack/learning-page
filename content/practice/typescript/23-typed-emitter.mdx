String-named events are easy to get wrong: a typo in `"sael"` or a price sent as a string fails silently. Write a class `Emitter<Events>` whose type parameter is an **event map**: an object type from event names to payload types. Then TypeScript knows every event and its payload.

```ts
type ShopEvents = {
  sale: { item: string; price: number };
  visitors: number;
};
const shop = new Emitter<ShopEvents>();
```

- `on(name, handler)` subscribes `handler` to the event and returns an **unsubscribe** function. Subscribing the same function twice makes two subscriptions; each unsubscribe function removes only its own, and calling it again does nothing.
- `once(name, handler)` is like `on`, but the subscription is removed right before its first call. It also returns an unsubscribe function.
- `emit(name, payload)` calls the event's handlers in the order they subscribed and returns how many it called. Handlers added or removed **during** an emit don't change who is called by that emit.
- `listenerCount(name)` returns the number of current subscriptions to that event.

```ts
const off = shop.on("sale", (sale) => console.log(sale.item, sale.price));
shop.once("visitors", (n) => console.log(n + " visitors"));
shop.emit("sale", { item: "tea", price: 2.5 }); // prints "tea 2.5", returns 1
shop.emit("visitors", 12);                      // prints "12 visitors", returns 1
shop.emit("visitors", 13);                      // returns 0
off();
shop.listenerCount("sale");                     // 0
```

Type the methods with the event map and make the emitter work. The `@ts-expect-error` lines are type tests: they pass only when that line **is** an error.

<Hint>

Give each method its own key parameter: `on<K extends keyof Events>(name: K, handler: (payload: Events[K]) => void)`. Then `name` can only be a real event, and `Events[K]` is that event's payload. `emit` and `once` work the same way.

</Hint>

<Hint>

Store a list per event in a mapped type: `private subs: { [K in keyof Events]?: Sub<Events[K]>[] } = {};`, where each `Sub` is a small object like `{ handler, once }`. Wrapping the handler in a fresh object lets the same function be subscribed twice, and each unsubscribe removes its own object (find it with `indexOf`). In `emit`, loop over a copy (`[...list]`) and skip subscriptions that were removed meanwhile.

</Hint>

<Solution>

```ts
type Handler<P> = (payload: P) => void;
type Sub<P> = { handler: Handler<P>; once: boolean };

class Emitter<Events extends Record<string, unknown>> {
  private subs: { [K in keyof Events]?: Sub<Events[K]>[] } = {};

  on<K extends keyof Events>(
    name: K,
    handler: Handler<Events[K]>,
  ): () => void {
    return this.add(name, { handler, once: false });
  }

  once<K extends keyof Events>(
    name: K,
    handler: Handler<Events[K]>,
  ): () => void {
    return this.add(name, { handler, once: true });
  }

  emit<K extends keyof Events>(name: K, payload: Events[K]): number {
    const list = this.subs[name] ?? [];
    let called = 0;
    for (const sub of [...list]) {
      if (!list.includes(sub)) continue; // removed meanwhile
      if (sub.once) this.remove(name, sub);
      sub.handler(payload);
      called++;
    }
    return called;
  }

  listenerCount(name: keyof Events): number {
    return this.subs[name]?.length ?? 0;
  }

  private add<K extends keyof Events>(
    name: K,
    sub: Sub<Events[K]>,
  ): () => void {
    const list = (this.subs[name] ??= []);
    list.push(sub);
    return () => this.remove(name, sub);
  }

  private remove<K extends keyof Events>(
    name: K,
    sub: Sub<Events[K]>,
  ): void {
    const list = this.subs[name] ?? [];
    const i = list.indexOf(sub);
    if (i !== -1) list.splice(i, 1);
  }
}

// ===== Type tests: don't change these =====
type ShopEvents = {
  sale: { item: string; price: number };
  visitors: number;
};

function typeTests(shop: Emitter<ShopEvents>) {
  shop.on("sale", (sale) => sale.price.toFixed(2));
  // @ts-expect-error: there is no "opened" event
  shop.on("opened", () => {});
  // @ts-expect-error: price must be a number
  shop.emit("sale", { item: "tea", price: "2" });
  // @ts-expect-error: the visitors payload is a number
  shop.on("visitors", (n: string) => n);
}

const shop = new Emitter<ShopEvents>();
shop.on("sale", (sale) => console.log(sale.item, sale.price));
console.log(shop.emit("sale", { item: "tea", price: 2.5 })); // 1
```

Each method has a type parameter `K extends keyof Events`, so the event name picks the payload type `Events[K]`, and the mapped type `{ [K in keyof Events]?: Sub<Events[K]>[] }` keeps every list matched to its event. Wrapping handlers in their own `Sub` objects makes two subscriptions of the same function distinct, and looping over a copy keeps one emit stable while handlers come and go. `emit` is O(n) in the number of handlers; removal is O(n) too because of `indexOf`.

</Solution>
