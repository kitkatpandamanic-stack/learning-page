В событиях со строковыми именами легко ошибиться: опечатка `"sael"` или цена, переданная строкой, ломаются молча. Напишите класс `Emitter<Events>`, параметр типа которого — **карта событий**: объектный тип, сопоставляющий именам событий типы их данных (payload). Тогда TypeScript знает каждое событие и его данные.

```ts
type ShopEvents = {
  sale: { item: string; price: number };
  visitors: number;
};
const shop = new Emitter<ShopEvents>();
```

- `on(name, handler)` подписывает `handler` на событие и возвращает функцию **отписки**. Если подписать одну и ту же функцию дважды, получатся две подписки; каждая функция отписки удаляет только свою, а повторный вызов ничего не делает.
- `once(name, handler)` работает как `on`, но подписка удаляется прямо перед первым вызовом. Тоже возвращает функцию отписки.
- `emit(name, payload)` вызывает обработчики события в порядке подписки и возвращает, сколько их вызвано. Обработчики, добавленные или удалённые **во время** `emit`, не меняют список вызываемых в этом `emit`.
- `listenerCount(name)` возвращает число текущих подписок на это событие.

```ts
const off = shop.on("sale", (sale) => console.log(sale.item, sale.price));
shop.once("visitors", (n) => console.log(n + " visitors"));
shop.emit("sale", { item: "tea", price: 2.5 }); // печатает "tea 2.5", возвращает 1
shop.emit("visitors", 12);                      // печатает "12 visitors", возвращает 1
shop.emit("visitors", 13);                      // возвращает 0
off();
shop.listenerCount("sale");                     // 0
```

Типизируйте методы картой событий и заставьте эмиттер работать. Строки с `@ts-expect-error` — это тесты типов: они проходят, только когда в этой строке **есть** ошибка.

<Hint>

Дайте каждому методу свой параметр-ключ: `on<K extends keyof Events>(name: K, handler: (payload: Events[K]) => void)`. Тогда `name` может быть только настоящим событием, а `Events[K]` — это данные этого события. `emit` и `once` устроены так же.

</Hint>

<Hint>

Храните список для каждого события в сопоставленном типе (mapped type): `private subs: { [K in keyof Events]?: Sub<Events[K]>[] } = {};`, где каждый `Sub` — маленький объект вроде `{ handler, once }`. Обёртка обработчика в новый объект позволяет подписать одну функцию дважды, а каждая отписка удаляет свой объект (найдите его через `indexOf`). В `emit` перебирайте копию (`[...list]`) и пропускайте подписки, которые тем временем удалили.

</Hint>

<Solution>

```ts
type Handler<P> = (payload: P) => void;
type Sub<P> = { handler: Handler<P>; once: boolean };

class Emitter<Events extends Record<string, unknown>> {
  private subs: { [K in keyof Events]?: Sub<Events[K]>[] } = {};

  on<K extends keyof Events>(
    name: K,
    handler: Handler<Events[K]>,
  ): () => void {
    return this.add(name, { handler, once: false });
  }

  once<K extends keyof Events>(
    name: K,
    handler: Handler<Events[K]>,
  ): () => void {
    return this.add(name, { handler, once: true });
  }

  emit<K extends keyof Events>(name: K, payload: Events[K]): number {
    const list = this.subs[name] ?? [];
    let called = 0;
    for (const sub of [...list]) {
      if (!list.includes(sub)) continue; // удалили тем временем
      if (sub.once) this.remove(name, sub);
      sub.handler(payload);
      called++;
    }
    return called;
  }

  listenerCount(name: keyof Events): number {
    return this.subs[name]?.length ?? 0;
  }

  private add<K extends keyof Events>(
    name: K,
    sub: Sub<Events[K]>,
  ): () => void {
    const list = (this.subs[name] ??= []);
    list.push(sub);
    return () => this.remove(name, sub);
  }

  private remove<K extends keyof Events>(
    name: K,
    sub: Sub<Events[K]>,
  ): void {
    const list = this.subs[name] ?? [];
    const i = list.indexOf(sub);
    if (i !== -1) list.splice(i, 1);
  }
}

// ===== Тесты типов: не меняйте их =====
type ShopEvents = {
  sale: { item: string; price: number };
  visitors: number;
};

function typeTests(shop: Emitter<ShopEvents>) {
  shop.on("sale", (sale) => sale.price.toFixed(2));
  // @ts-expect-error: события "opened" нет
  shop.on("opened", () => {});
  // @ts-expect-error: price должна быть числом
  shop.emit("sale", { item: "tea", price: "2" });
  // @ts-expect-error: данные visitors — это число
  shop.on("visitors", (n: string) => n);
}

const shop = new Emitter<ShopEvents>();
shop.on("sale", (sale) => console.log(sale.item, sale.price));
console.log(shop.emit("sale", { item: "tea", price: 2.5 })); // 1
```

У каждого метода есть параметр типа `K extends keyof Events`, поэтому имя события выбирает тип данных `Events[K]`, а сопоставленный тип `{ [K in keyof Events]?: Sub<Events[K]>[] }` держит каждый список в соответствии со своим событием. Обёртка обработчиков в отдельные объекты `Sub` делает две подписки одной и той же функции разными, а перебор копии сохраняет один `emit` стабильным, пока обработчики появляются и исчезают. `emit` работает за O(n) от числа обработчиков; удаление — тоже O(n) из-за `indexOf`.
