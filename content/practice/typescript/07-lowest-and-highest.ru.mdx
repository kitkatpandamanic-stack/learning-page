Панда-метеоролог каждый час записывает температуру и хочет знать её разброс за день. Напишите `minMax(temps)`, которая возвращает **кортеж** (tuple) `[lowest, highest]`.

Два требования к типам делают эту функцию безопасной:

- Возвращаемый тип — кортеж `[number, number]`, а не `number[]`, поэтому вызывающий код может написать `const [lo, hi] = minMax(...)`, и про обе переменные известно, что это числа.
- У пустого массива нет ни наименьшего, ни наибольшего значения, поэтому вызов `minMax([])` вообще не должен компилироваться. Используйте для параметра **тип непустого массива**: `readonly [number, ...number[]]` означает «одно число, а за ним сколько угодно ещё».

```ts
minMax([12, 7, 19, 7]);   // [7, 19]
minMax([-3]);             // [-3, -3]
minMax([]);               // ❌ ошибка компиляции
```

Задайте `minMax` параметр-кортеж непустого массива и возвращаемый тип `[number, number]`, затем вычислите разброс.

<Hint>

Сигнатура такая: `function minMax(temps: readonly [number, ...number[]]): [number, number]`. Начните и `lo`, и `hi` с `temps[0]` (теперь он всегда существует), затем пройдите циклом и обновляйте их.

</Hint>

<Solution>

```ts
function minMax(
  temps: readonly [number, ...number[]],
): [number, number] {
  let lo = temps[0];
  let hi = temps[0];
  for (const t of temps) {
    if (t < lo) lo = t;
    if (t > hi) hi = t;
  }
  return [lo, hi];
}

function typeTests() {
  const [lo, hi]: [number, number] = minMax([12, 7, 19]);
  // @ts-expect-error: у пустого массива нет разброса
  minMax([]);
}

console.log(minMax([12, 7, 19, 7])); // [ 7, 19 ]
```

Тип кортежа гарантирует наличие первого элемента, поэтому `temps[0]` — это `number`, а пограничный случай «что вернуть для пустого списка?» исчезает: компилятор просто не пропустит такой вызов. Один проход по массиву — это O(n).

</Solution>
