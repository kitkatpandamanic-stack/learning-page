Counting the bamboo in a big forest is slow, so we want to remember answers we've already worked out. Write `memoize(fn, keyOf?)`, which returns a function that behaves like `fn` but caches its results. The returned function must have **the same parameter and return types** as `fn` (no `any`), plus two methods:

```ts
type Memo<A extends unknown[], R> = {
  (...args: A): R;
  size(): number; // how many results are cached
  clear(): void;  // forget everything
};
```

- The cache key is `keyOf(...args)` if `keyOf` is given, otherwise `JSON.stringify(args)`.
- A call with a key seen before returns the cached result without calling `fn`, even if that result was `undefined`.
- If `fn` throws, nothing is cached and the error reaches the caller, so the next call tries again.
- If `fn` returns a promise that later **rejects**, its cache entry is removed, so the next call tries again. Promises that resolve stay cached.

```ts
let calls = 0;
const area = memoize((w: number, h: number) => {
  calls++;
  return w * h;
});
area(3, 4); // 12
area(3, 4); // 12, from the cache: calls is still 1
area.size(); // 1

const byName = memoize(
  (name: string) => name.length,
  (name) => name.toLowerCase(),
);
byName("Mei"); byName("MEI"); // one call: same key "mei"
```

Make `memoize` generic and return a working `Memo<A, R>`. The `@ts-expect-error` lines are type tests: they pass only when that line **is** an error.

<Hint>

Capture the whole parameter list as one tuple type parameter, `A extends unknown[]`, and the return type as another, `R`. A `Map` from key strings to results makes a good cache.

</Hint>

<Hint>

Build the key with `keyOf ? keyOf(...args) : JSON.stringify(args)`. If `cache.has(key)`, return the cached result: check `has`, not the value, so a cached `undefined` still counts. Otherwise call `fn` (if it throws, you never reach the line that caches), store the result, and if it's a promise, add `result.catch(() => cache.delete(key))`. Finally attach `size` and `clear` to the function with `Object.assign`.

</Hint>

```ts
function memoize<A extends unknown[], R>(
  fn: (...args: A) => R,
  keyOf?: (...args: A) => string,
): Memo<A, R> {
  const cache = new Map<string, R>();
  const memo = (...args: A): R => {
    const key = keyOf ? keyOf(...args) : JSON.stringify(args);
    if (cache.has(key)) return cache.get(key) as R;
    const result = fn(...args);
    cache.set(key, result);
    // forget the entry if result is a promise that rejects
    return result;
  };
  return Object.assign(memo, ...); // add size and clear
}
```

<Solution>

```ts
type Memo<A extends unknown[], R> = {
  (...args: A): R;
  size(): number;
  clear(): void;
};

function memoize<A extends unknown[], R>(
  fn: (...args: A) => R,
  keyOf?: (...args: A) => string,
): Memo<A, R> {
  const cache = new Map<string, R>();
  const memo = (...args: A): R => {
    const key = keyOf ? keyOf(...args) : JSON.stringify(args);
    if (cache.has(key)) return cache.get(key) as R;
    const result = fn(...args); // if this throws, nothing is cached
    cache.set(key, result);
    if (result instanceof Promise) {
      result.catch(() => cache.delete(key));
    }
    return result;
  };
  return Object.assign(memo, {
    size: () => cache.size,
    clear: () => cache.clear(),
  });
}

// ===== Type tests: don't change these =====
function typeTests() {
  const add = memoize((a: number, b: number) => a + b);
  const sum: number = add(1, 2);
  // @ts-expect-error: add takes numbers
  add("1", 2);
  // @ts-expect-error: add returns a number
  const text: string = add(1, 2);
  // @ts-expect-error: keyOf must take the same arguments as fn
  memoize((id: number) => id, (id: string) => id);
  return [sum, text, add.size()];
}

let calls = 0;
const area = memoize((w: number, h: number) => {
  calls++;
  return w * h;
});
console.log(area(3, 4), area(3, 4), calls); // 12 12 1
```

`A extends unknown[]` captures the whole parameter list as a tuple (`[w: number, h: number]`), and `R` the return type, so the memoized function is typed exactly like the original. `Object.assign` returns the function and the added methods as one value of type `typeof memo & { size…; clear… }`, which fits `Memo<A, R>`. A cache hit is O(1) plus the cost of building the key.

</Solution>
