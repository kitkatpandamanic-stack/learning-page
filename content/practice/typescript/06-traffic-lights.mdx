The panda crossing outside the zoo has a traffic light with three colours: `"red"`, `"amber"` and `"green"`. Right now the code types a colour as plain `string`, so a typo like `"gren"` or a nonsense colour like `"blue"` slips through.

1. Replace `type Light = string` with a **union of string literals**, so only the three real colours are allowed.
2. Write `nextLight(light: Light): Light`. The light cycles `red → green → amber → red`.
3. Write `stepsUntilGreen(light: Light): number`: how many calls to `nextLight` it takes to reach green (`0` if it's already green).

```ts
nextLight("red");         // "green"
nextLight("amber");       // "red"
stepsUntilGreen("amber"); // 2   (amber → red → green)
nextLight("blue");        // ❌ compile error once Light is a union
```

Turn `Light` into a union and implement both functions. The `@ts-expect-error` lines are type tests: they pass only when that line **is** an error.

<Hint>

`type Light = "red" | "amber" | "green";`. A `switch (light)` with one `case` per colour fits `nextLight`. For `stepsUntilGreen`, keep calling `nextLight` in a `while` loop and count, or use a `switch` too.

</Hint>

<Solution>

```ts
type Light = "red" | "amber" | "green";

function nextLight(light: Light): Light {
  switch (light) {
    case "red":
      return "green";
    case "green":
      return "amber";
    case "amber":
      return "red";
  }
}

function stepsUntilGreen(light: Light): number {
  let steps = 0;
  let current = light;
  while (current !== "green") {
    current = nextLight(current);
    steps++;
  }
  return steps;
}

function typeTests() {
  const ok: Light = "amber";
  // @ts-expect-error
  const typo: Light = "gren";
  // @ts-expect-error
  nextLight("blue");
}

console.log(nextLight("red")); // green
```

Because the `switch` covers every member of the union, TypeScript knows the function always returns, so no `default` is needed (add a fourth colour and it reports a missing return). An `enum Light { Red, Amber, Green }` would also work, but a literal union needs no extra runtime object and lets callers pass plain strings like `"red"`.

</Solution>
