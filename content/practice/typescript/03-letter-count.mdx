The bamboo sign maker charges by the character, and customers send their text in two ways: a single `string`, or an array of strings (one per line of the sign).

Write `letterCount(text)` where `text` is `string | string[]`. It returns the number of characters that are **not spaces**:

- For a string, count its non-space characters.
- For an array, add up the counts of all its strings.
- An empty string or an empty array gives `0`.

Only the space character `" "` is skipped; letters, digits and punctuation all count.

```ts
letterCount("Fresh bamboo");          // 11
letterCount(["Fresh", "bamboo!"]);    // 12
letterCount([]);                      // 0
```

Type `letterCount` with a union and return the number of non-space characters. The `@ts-expect-error` line is a type test: it passes only when that line **is** an error, so `text: any` won't do.

<Hint>

`Array.isArray(text)` narrows the union: inside the `if`, `text` is `string[]`; after it, TypeScript knows it's a `string`. For one string, `text.replaceAll(" ", "").length` does the counting.

</Hint>

<Solution>

```ts
function countOne(line: string): number {
  return line.replaceAll(" ", "").length;
}

function letterCount(text: string | string[]): number {
  if (Array.isArray(text)) {
    let total = 0;
    for (const line of text) total += countOne(line);
    return total;
  }
  return countOne(text);
}

function typeTests() {
  letterCount(["Fresh", "bamboo"]);
  // @ts-expect-error
  letterCount(42);
}

console.log(letterCount("Fresh bamboo")); // 11
```

`Array.isArray` is a narrowing check: in each branch TypeScript knows exactly which member of the union `text` is, so calling `.replaceAll` on an array (or looping over a plain string by mistake) is caught before the code runs.

</Solution>

</Exercise>
