A game sends its input log as JSON text. Most entries are fine, but some are broken, and `JSON.parse` hands you `any`, which TypeScript can't check for you. Treat the data as `unknown` and **prove** each entry's shape before using it.

```ts
type AppEvent =
  | { type: "click"; x: number; y: number }
  | { type: "key"; key: string; shift: boolean }
  | { type: "scroll"; delta: number };
```

Write three functions:

- `isAppEvent(value: unknown): value is AppEvent`: `true` only for a non-null, non-array object whose `type` is one of the three, with every field of that kind present and of the right type. Numbers must be finite (`Number.isFinite`). Extra fields are allowed.
- `parseEvents(json: string)` returns `{ events, skipped }`: the valid entries in their original order and how many entries were skipped. If the text isn't valid JSON, or isn't a JSON array, return `null`.
- `countByType(events: AppEvent[])` returns `{ click, key, scroll }` counts, with all three keys always present. Its return type must be `Record<AppEvent["type"], number>`.

```ts
parseEvents('[{"type":"click","x":1,"y":2},{"type":"key","key":"a"},7]');
// { events: [ { type: 'click', x: 1, y: 2 } ], skipped: 2 }
parseEvents("not json");  // null
parseEvents('{"type":"scroll","delta":3}'); // null: not an array
countByType([{ type: "scroll", delta: -40 }]);
// { click: 0, key: 0, scroll: 1 }
```

<Solution>

```ts
type AppEvent =
  | { type: "click"; x: number; y: number }
  | { type: "key"; key: string; shift: boolean }
  | { type: "scroll"; delta: number };

const isNumber = (v: unknown): v is number =>
  typeof v === "number" && Number.isFinite(v);

function isAppEvent(value: unknown): value is AppEvent {
  if (typeof value !== "object" || value === null) return false;
  if (Array.isArray(value)) return false;
  const v = value as Record<string, unknown>;
  switch (v.type) {
    case "click":
      return isNumber(v.x) && isNumber(v.y);
    case "key":
      return typeof v.key === "string" && typeof v.shift === "boolean";
    case "scroll":
      return isNumber(v.delta);
    default:
      return false;
  }
}

function parseEvents(
  json: string,
): { events: AppEvent[]; skipped: number } | null {
  let data: unknown;
  try {
    data = JSON.parse(json);
  } catch {
    return null;
  }
  if (!Array.isArray(data)) return null;
  const events = data.filter(isAppEvent);
  return { events, skipped: data.length - events.length };
}

function countByType(
  events: AppEvent[],
): Record<AppEvent["type"], number> {
  const counts = { click: 0, key: 0, scroll: 0 };
  for (const event of events) counts[event.type]++;
  return counts;
}

// ===== Type tests: don't change these =====
function typeTests(input: unknown) {
  if (isAppEvent(input)) {
    const kind: "click" | "key" | "scroll" = input.type;
    if (input.type === "click") {
      const x: number = input.x;
    }
  }
  const counts = countByType([]);
  const clicks: number = counts.click;
  // @ts-expect-error: there is no "drag" event
  counts.drag;
}

console.log(parseEvents('[{"type":"scroll","delta":3},"oops"]'));
```

The guard's return type `value is AppEvent` tells TypeScript what a `true` result proves, and passing it to `filter` turns an `any[]` into an `AppEvent[]` in one step. `Record<AppEvent["type"], number>` derives the keys from the union, so adding a fourth event kind would make `countByType` fail to compile until its counts include it. Parsing is O(n) in the number of entries.

</Solution>
