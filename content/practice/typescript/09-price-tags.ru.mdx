Магазин зоопарка продаёт товары в трёх валютах: `"GBP"`, `"EUR"` и `"USD"`. Напишите `formatPrice(amount, currency)`, которая превращает число в ценник:

- В начале — символ валюты: `£` для GBP, `€` для EUR, `$` для USD.
- Всегда ровно **2 знака после точки**.
- Целую часть разбейте на группы по три цифры запятыми: `1234567.5` → `1,234,567.50`.
- У отрицательных сумм знак минус стоит **перед** символом: `-5` в GBP → `-£5.00`.

Сначала типы: сделайте `Currency` объединением трёх кодов (а не `string`) и задайте таблице символов тип `Record<Currency, string>`. Тогда забытая валюта — или валюта, в которой магазин не торгует, — станет ошибкой компиляции.

```ts
formatPrice(4.5, "GBP");       // "£4.50"
formatPrice(1234567.5, "EUR"); // "€1,234,567.50"
formatPrice(-5, "USD");        // "-$5.00"
formatPrice(5, "JPY");         // ❌ ошибка компиляции
```

<Solution>

```ts
type Currency = "GBP" | "EUR" | "USD";

const symbols: Record<Currency, string> = {
  GBP: "£",
  EUR: "€",
  USD: "$",
};

function formatPrice(amount: number, currency: Currency): string {
  const [whole, cents] = Math.abs(amount).toFixed(2).split(".");
  const grouped = whole.replace(/\B(?=(\d{3})+(?!\d))/g, ",");
  const sign = amount < 0 ? "-" : "";
  return `${sign}${symbols[currency]}${grouped}.${cents}`;
}

function typeTests() {
  formatPrice(1, "EUR");
  // @ts-expect-error: магазин не торгует в иенах
  formatPrice(5, "JPY");
  // @ts-expect-error: и символа иены в таблице тоже нет
  symbols.JPY;
}

console.log(formatPrice(1234567.5, "EUR")); // €1,234,567.50
```

В `Record<Currency, string>` обязан быть ключ для каждой валюты, поэтому если позже добавить `"CNY"` в объединение, TypeScript будет указывать на таблицу, пока вы не добавите её символ. Регулярное выражение вставляет запятую в каждую позицию, за которой до конца целой части идёт количество цифр, кратное трём.

</Solution>
