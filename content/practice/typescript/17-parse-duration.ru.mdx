Таймер панды-соньки позволяет смотрителям вводить длительность в виде `"1h 30m"` или `"45s"`. Напишите `parseDuration(text)`, которая возвращает длительность в **секундах** или `null`, если текст не является правильной длительностью.

Правильная длительность — это одна или несколько **частей**, разделённых пробелами (пробелов может быть сколько угодно; пробелы в начале и в конце игнорируются). Каждая часть — это:

- целое число из одной или нескольких цифр (`0` допустим),
- сразу за которым идёт единица: `h` (часы), `m` (минуты) или `s` (секунды), строчными буквами.

Каждая единица может встречаться **не больше одного раза**, в любом порядке. Всё остальное даёт `null`: пустая строка или строка из пробелов, отсутствующее число (`"h"`), отсутствующая или неизвестная единица (`"10"`, `"3d"`), дробное число (`"1.5h"`), пробел внутри части (`"10 m"`) или повторяющаяся единица (`"5m 5m"`).

```ts
parseDuration("1h 30m");     // 5400
parseDuration("  45s ");     // 45
parseDuration("30m 1h");     // 5400
parseDuration("1.5h");       // null
parseDuration("5m 5m");      // null
```

Возвращаемый тип — `number | null`, поэтому вызывающий код не сможет использовать результат как число, не проверив сначала на `null`. Это и проверяет тест типов ниже.

<Solution>

```ts
const SECONDS: Record<string, number> = { h: 3600, m: 60, s: 1 };

function parseDuration(text: string): number | null {
  const trimmed = text.trim();
  if (trimmed === "") return null;
  const seen = new Set<string>();
  let total = 0;
  for (const part of trimmed.split(/\s+/)) {
    const match = /^(\d+)([hms])$/.exec(part);
    if (!match) return null;
    const unit = match[2];
    if (seen.has(unit)) return null;
    seen.add(unit);
    total += Number(match[1]) * SECONDS[unit];
  }
  return total;
}

function typeTests() {
  const maybe: number | null = parseDuration("5m");
  // @ts-expect-error: результат может быть null, сначала проверьте его
  const sure: number = parseDuration("5m");
}

console.log(parseDuration("1h 30m")); // 5400
```

Регулярное выражение принимает ровно одну правильную часть, так что любой другой ввод доходит до `return null`. Возврат `number | null` вместо «магического» значения вроде `-1` или `0` переносит неудачу в тип: если вызывающий код напишет `parseDuration(input) * 1000`, он получит ошибку компиляции, пока не обработает `null`. Работа занимает O(длина текста).

</Solution>
