Data from outside your program (JSON, local storage, another team's API) arrives as `unknown`. Before you use it as a `User` you have to check it:

```ts
interface User {
  name: string;
  age: number;
  email?: string;
}
```

Write a **type guard** `isUser(value: unknown): value is User`. It returns `true` only when:

- `value` is an object and not `null` (and not an array),
- `name` is a string and `age` is a number,
- `email` is either missing or a string.

Extra properties are fine. Then write `adults(values: unknown[]): User[]` that keeps only the values that are users **and** at least 18 years old, in their original order.

```ts
isUser({ name: "Mei", age: 30 });           // true
isUser({ name: "Bao", age: "7" });          // false: age is a string
isUser(null);                               // false
adults([{ name: "Mei", age: 30 }, { name: "Lin", age: 12 }, 42]); // [{ name: "Mei", age: 30 }]
```

<Solution>

```ts
interface User {
  name: string;
  age: number;
  email?: string;
}

function isUser(value: unknown): value is User {
  if (typeof value !== "object" || value === null) return false;
  if (Array.isArray(value)) return false;
  if (!("name" in value) || typeof value.name !== "string") {
    return false;
  }
  if (!("age" in value) || typeof value.age !== "number") {
    return false;
  }
  if ("email" in value && typeof value.email !== "string") {
    return false;
  }
  return true;
}

function adults(values: unknown[]): User[] {
  return values.filter(isUser).filter((u) => u.age >= 18);
}

function typeTests() {
  const users: User[] = [1, { name: "Mei", age: 3 }].filter(isUser);
}

console.log(isUser({ name: "Mei", age: 30 })); // true
```

A plain `boolean` return tells TypeScript nothing, so `filter` would still give `unknown[]`. The `value is User` predicate makes every `true` narrow the value, which is why `filter(isUser)` returns `User[]` and `u.age` type-checks in the second `filter`.

</Solution>
