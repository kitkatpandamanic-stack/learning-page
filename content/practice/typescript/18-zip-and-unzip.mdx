The feeding log keeps panda names in one array and the kilograms of bamboo they ate in another. Write two generic helpers:

- `zip(as, bs)` returns an array of pairs `[as[i], bs[i]]`. If the arrays have different lengths, it **stops at the shorter one**.
- `unzip(pairs)` does the reverse: it returns a tuple of two arrays, the first items of every pair and the second items. No pairs gives `[[], []]`.

Neither function changes its inputs.

```ts
zip(["Mei", "Bao", "Lin"], [12, 9]);   // [["Mei", 12], ["Bao", 9]]
unzip([["Mei", 12], ["Bao", 9]]);      // [["Mei", "Bao"], [12, 9]]
unzip([]);                             // [[], []]
```

Types: use two type parameters `A` and `B`. `zip` takes `readonly A[]` and `readonly B[]` and returns `[A, B][]`, an array of **tuples**, not `(A | B)[][]`. `unzip` takes `readonly (readonly [A, B])[]` and returns the tuple `[A[], B[]]`. Then `zip(names, kilos)` is typed `[string, number][]`, and a caller can destructure `const [names, kilos] = unzip(log)` and get a `string[]` and a `number[]`.

Make `zip` and `unzip` generic with tuple types, and implement them. The `@ts-expect-error` lines pass only when that line **is** an error.

<Hint>

`function zip<A, B>(as: readonly A[], bs: readonly B[]): [A, B][]`: loop `i` up to `Math.min(as.length, bs.length)` and push `[as[i], bs[i]]`. For `unzip`, build two arrays `const firsts: A[] = []` and `const seconds: B[] = []`, then `return [firsts, seconds]`.

</Hint>

<Solution>

```ts
function zip<A, B>(as: readonly A[], bs: readonly B[]): [A, B][] {
  const pairs: [A, B][] = [];
  const length = Math.min(as.length, bs.length);
  for (let i = 0; i < length; i++) {
    pairs.push([as[i], bs[i]]);
  }
  return pairs;
}

function unzip<A, B>(pairs: readonly (readonly [A, B])[]): [A[], B[]] {
  const firsts: A[] = [];
  const seconds: B[] = [];
  for (const [a, b] of pairs) {
    firsts.push(a);
    seconds.push(b);
  }
  return [firsts, seconds];
}

function typeTests() {
  const log: [string, number][] = zip(["Mei", "Bao"], [12, 9]);
  const [names, kilos]: [string[], number[]] = unzip(log);
  // @ts-expect-error: the pairs are [string, number], not [number, string]
  const flipped: [number, string][] = zip(["Mei"], [12]);
  // @ts-expect-error: unzip needs pairs, not plain values
  unzip([1, 2, 3]);
}

console.log(zip(["Mei", "Bao", "Lin"], [12, 9])); // [ [ 'Mei', 12 ], [ 'Bao', 9 ] ]
```

A tuple type `[A, B]` remembers which type sits at which position, whereas `(A | B)[]` would lose it. Annotating `pairs` as `[A, B][]` matters too: without it, `[as[i], bs[i]]` would be inferred as an array of `A | B`. Both functions are a single O(n) pass.

</Solution>
