Напишите дженерик (generic) `groupBy(items, keyOf)`. Функция вызывает `keyOf(item)` для каждого элемента и собирает элементы в объект из массивов — по одному массиву на ключ:

- Группы идут в том порядке, в котором их ключ **встретился впервые**, а внутри каждой группы элементы сохраняют исходный порядок.
- Пустой массив даёт `{}`.
- Входной массив не изменяется.

```ts
const pandas = [
  { name: "Mei", zoo: "Chengdu" },
  { name: "Bao", zoo: "Edinburgh" },
  { name: "Lin", zoo: "Chengdu" },
];
groupBy(pandas, (p) => p.zoo);
// { Chengdu: [Mei, Lin], Edinburgh: [Bao] }
```

Теперь типы. Когда колбэк (callback) для ключа возвращает объединение литералов, например `"Chengdu" | "Edinburgh"`, результат должен знать возможные имена групп:

- У функции два параметра типа: `T` для элементов и `K extends string` для ключей, которые возвращает колбэк.
- Она возвращает `Partial<Record<K, T[]>>`. `Partial` — потому что группа существует, только если в неё попал хотя бы один элемент. Поэтому чтение группы даёт `T[] | undefined` и заставляет вызывающий код обработать случай, когда её нет.
- Опечатка в имени группы (`byZoo.Paris`) и колбэк, который возвращает не строку (`(p) => p.age`), — ошибки компиляции.

Сделайте `groupBy` дженериком, чтобы тесты типов проходили, и сгруппируйте элементы. Строки с `@ts-expect-error` проходят, только если в этой строке **есть** ошибка.

<Hint>

Сигнатура такая: `function groupBy<T, K extends string>(items: readonly T[], keyOf: (item: T) => K): Partial<Record<K, T[]>>`. Начните с `const groups: Partial<Record<K, T[]>> = {};`, затем для каждого элемента прочитайте `groups[key]`: если группа есть, добавьте в неё элемент через `push`, иначе создайте `[item]`.

</Hint>

<Solution>

```ts
function groupBy<T, K extends string>(
  items: readonly T[],
  keyOf: (item: T) => K,
): Partial<Record<K, T[]>> {
  const groups: Partial<Record<K, T[]>> = {};
  for (const item of items) {
    const key = keyOf(item);
    const group = groups[key];
    if (group) group.push(item);
    else groups[key] = [item];
  }
  return groups;
}

type Zoo = "Chengdu" | "Edinburgh";
function typeTests(pandas: { name: string; zoo: Zoo; age: number }[]) {
  const byZoo = groupBy(pandas, (p) => p.zoo);
  const first: string | undefined = byZoo.Chengdu?.[0].name;
  // @ts-expect-error: группы может не быть, сначала проверьте её
  byZoo.Edinburgh.length;
  // @ts-expect-error: такого зоопарка нет
  byZoo.Paris;
  // @ts-expect-error: ключи должны быть строками
  groupBy(pandas, (p) => p.age);
}

console.log(groupBy(["apple", "avocado", "kiwi"], (w) => w[0]));
```

TypeScript выводит `K` из того, что возвращает колбэк: `p.zoo` даёт объединение `Zoo`, а `w[0]` — обычный `string`. Так одна и та же функция выдаёт точные ключи, когда это возможно, и обычную таблицу поиска в остальных случаях. Один проход по элементам — это O(n). (Обычные объекты перечисляют целочисленные ключи вроде `"2"` раньше остальных, поэтому если для числовых ключей нужен порядок первого появления, используйте `Map`.)

</Solution>
