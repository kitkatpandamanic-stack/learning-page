Данные извне программы (JSON, локальное хранилище, API другой команды) приходят с типом `unknown`. Прежде чем использовать их как `User`, их нужно проверить:

```ts
interface User {
  name: string;
  age: number;
  email?: string;
}
```

Напишите **защитник типа** (type guard) `isUser(value: unknown): value is User`. Он возвращает `true`, только если:

- `value` — объект, а не `null` (и не массив),
- `name` — строка, а `age` — число,
- `email` либо отсутствует, либо является строкой.

Лишние свойства не мешают. Затем напишите `adults(values: unknown[]): User[]`, которая оставляет только те значения, которые являются пользователями **и** уже достигли 18 лет, в исходном порядке.

```ts
isUser({ name: "Mei", age: 30 });           // true
isUser({ name: "Bao", age: "7" });          // false: age — строка
isUser(null);                               // false
adults([{ name: "Mei", age: 30 }, { name: "Lin", age: 12 }, 42]); // [{ name: "Mei", age: 30 }]
```

Превратите `isUser` в настоящий защитник типа и используйте его в `adults`.

<Hint>

Сначала проверьте «снаружи»: `typeof value === "object" && value !== null && !Array.isArray(value)`. После этого `"name" in value` позволяет безопасно читать `value.name`. В `adults` у `values.filter(isUser)` уже тип `User[]`, так что можно продолжить цепочку `.filter((u) => u.age >= 18)`.

</Hint>

<Solution>

```ts
interface User {
  name: string;
  age: number;
  email?: string;
}

function isUser(value: unknown): value is User {
  if (typeof value !== "object" || value === null) return false;
  if (Array.isArray(value)) return false;
  if (!("name" in value) || typeof value.name !== "string") {
    return false;
  }
  if (!("age" in value) || typeof value.age !== "number") {
    return false;
  }
  if ("email" in value && typeof value.email !== "string") {
    return false;
  }
  return true;
}

function adults(values: unknown[]): User[] {
  return values.filter(isUser).filter((u) => u.age >= 18);
}

function typeTests() {
  const users: User[] = [1, { name: "Mei", age: 3 }].filter(isUser);
}

console.log(isUser({ name: "Mei", age: 30 })); // true
```

Возвращаемый тип `boolean` ничего не говорит TypeScript, и `filter` по-прежнему дал бы `unknown[]`. Предикат типа (type predicate) `value is User` превращает каждый `true` в сужение типа значения — поэтому `filter(isUser)` возвращает `User[]`, а `u.age` проходит проверку типов во втором `filter`.

</Solution>
