API доставки бамбука иногда ненадолго падает, а через секунду снова работает. Напишите `retry(task, options)`: функция вызывает асинхронную `task`, пока та не завершится успешно, и с каждым разом ждёт между попытками всё дольше.

```ts
type RetryOptions = {
  attempts: number; // общее число попыток, не меньше 1
  delayMs: number;  // пауза перед 2-й попыткой; дальше удваивается
  sleep?: (ms: number) => Promise<void>;
  shouldRetry?: (error: unknown) => boolean;
};
```

- `task` получает номер попытки (1, 2, 3…) и возвращает промис (promise). `retry` выполняется с первым значением, с которым выполнилась задача, и его тип совпадает с типом задачи: повтор задачи `Promise<number>` даёт `Promise<number>`.
- После неудачной попытки, если попытки ещё остались, подождите `delayMs`, затем `2 * delayMs`, затем `4 * delayMs`… перед следующей. После последней попытки не ждите никогда.
- Для ожидания используется `options.sleep(ms)`, если он передан (тесты передают подделку, которая записывает паузы), иначе настоящий `setTimeout`.
- Если `shouldRetry(error)` вернул `false`, сразу остановитесь и отклоните промис **той же самой** ошибкой. Без `shouldRetry` повторяется любая ошибка.
- Когда все попытки провалились, отклоните промис ошибкой `RetryError`: это подкласс `Error` с сообщением `"Failed after N attempts"`, `name`, равным `"RetryError"`, полем `attempts` (сколько было попыток) и `lastError` (то, что выбросила последняя попытка, с типом `unknown`).

```ts
const waits: number[] = [];
const sleep = async (ms: number) => { waits.push(ms); };

await retry(async (n) => {
  if (n < 3) throw new Error("busy");
  return "delivered on try " + n;
}, { attempts: 5, delayMs: 100, sleep });
// "delivered on try 3", а waits равен [100, 200]

await retry(() => Promise.reject(new Error("down")), {
  attempts: 3, delayMs: 100, sleep,
});
// отклоняется с RetryError: "Failed after 3 attempts", lastError.message — "down"
```

```ts
async function retry<T>(
  task: (attempt: number) => Promise<T>,
  options: RetryOptions,
): Promise<T> {
  const sleep = options.sleep ?? ((ms: number) => new Promise<void>((r) => setTimeout(r, ms)));
  const shouldRetry = options.shouldRetry ?? (() => true);
  let lastError: unknown;
  for (let attempt = 1; attempt <= options.attempts; attempt++) {
    try {
      return await task(attempt);
    } catch (error) {
      // остановитесь, если shouldRetry говорит «нет»; иначе запомните ошибку
      // и подождите перед следующей попыткой (но не после последней)
    }
  }
  throw new RetryError(options.attempts, lastError);
}
```

<Solution>

```ts
type RetryOptions = {
  attempts: number;
  delayMs: number;
  sleep?: (ms: number) => Promise<void>;
  shouldRetry?: (error: unknown) => boolean;
};

class RetryError extends Error {
  readonly attempts: number;
  readonly lastError: unknown;

  constructor(attempts: number, lastError: unknown) {
    super("Failed after " + attempts + " attempts");
    this.name = "RetryError";
    this.attempts = attempts;
    this.lastError = lastError;
  }
}

const realSleep = (ms: number) =>
  new Promise<void>((resolve) => setTimeout(resolve, ms));

async function retry<T>(
  task: (attempt: number) => Promise<T>,
  options: RetryOptions,
): Promise<T> {
  const sleep = options.sleep ?? realSleep;
  const shouldRetry = options.shouldRetry ?? (() => true);
  let lastError: unknown;
  for (let attempt = 1; attempt <= options.attempts; attempt++) {
    try {
      return await task(attempt);
    } catch (error) {
      if (!shouldRetry(error)) throw error;
      lastError = error;
      if (attempt < options.attempts) {
        await sleep(options.delayMs * 2 ** (attempt - 1));
      }
    }
  }
  throw new RetryError(options.attempts, lastError);
}

// ===== Тесты типов: не меняйте их =====
async function typeTests() {
  const n: number = await retry(async () => 5, {
    attempts: 2,
    delayMs: 1,
  });
  // @ts-expect-error: retry выполняется с тем же, с чем выполняется задача
  const s: string = await retry(async () => 5, {
    attempts: 2,
    delayMs: 1,
  });
  // @ts-expect-error: attempts обязателен
  await retry(async () => 1, { delayMs: 10 });
  return [n, s];
}

const waits: number[] = [];
const result = await retry(async (n) => {
  if (n < 3) throw new Error("busy");
  return "delivered on try " + n;
}, { attempts: 5, delayMs: 100, sleep: async (ms) => { waits.push(ms); } });
console.log(result, waits); // delivered on try 3 [ 100, 200 ]
```

Параметр типа `T` переходит из `Promise<T>` задачи в результат самого `retry`, поэтому вызывающий код сохраняет настоящие типы вместо `any`. Ошибки на всём пути остаются `unknown` (именно это даёт `catch`), а `RetryError` несёт последнюю из них тому, кто будет её обрабатывать. При n попытках будет не больше n вызовов и n − 1 пауз, а подмена `sleep` позволяет тестировать тайминги без настоящих задержек.

</Solution>
