Зоопарк планирует новые вольеры, и их чертят из фигур трёх видов. Каждая фигура — объект с меткой `kind` и теми размерами, которые нужны этому виду:

| `kind` | другие свойства | площадь |
| --- | --- | --- |
| `"circle"` | `radius` | π × radius² |
| `"rect"` | `width`, `height` | width × height |
| `"triangle"` | `base`, `height` | base × height ÷ 2 |

1. Замените `type Shape = unknown` на **размеченное объединение** (discriminated union) трёх объектных типов, чтобы круг с `width` или `"hexagon"` не компилировались.
2. `area(shape)` возвращает площадь фигуры, **округлённую до 2 знаков после запятой** (`Math.round(x * 100) / 100`). Для π используйте `Math.PI`.
3. `totalArea(shapes)` возвращает сумму **неокруглённых** площадей, округлённую до 2 знаков в самом конце. Если фигур нет — `0`.

Все размеры — положительные числа.

```ts
area({ kind: "circle", radius: 1 });                // 3.14
area({ kind: "rect", width: 2, height: 3.5 });      // 7
area({ kind: "triangle", base: 4, height: 5 });     // 10
totalArea([{ kind: "circle", radius: 1 }, { kind: "circle", radius: 1 }]); // 6.28
area({ kind: "circle", width: 2 });                 // ❌ ошибка компиляции
```

<Hint>

Напишите по объектному типу на каждую фигуру, у каждого — литеральный `kind` (`{ kind: "circle"; radius: number }` и так далее), и объедините их через `|`. В `area` используйте `switch (shape.kind)`: внутри каждого `case` TypeScript знает, какие свойства есть у фигуры. Заведите вспомогательную функцию без округления, чтобы `totalArea` складывала точные значения.

</Hint>

<Solution>

```ts
type Circle = { kind: "circle"; radius: number };
type Rect = { kind: "rect"; width: number; height: number };
type Triangle = { kind: "triangle"; base: number; height: number };
type Shape = Circle | Rect | Triangle;

const round2 = (x: number): number => Math.round(x * 100) / 100;

function exactArea(shape: Shape): number {
  switch (shape.kind) {
    case "circle":
      return Math.PI * shape.radius ** 2;
    case "rect":
      return shape.width * shape.height;
    case "triangle":
      return (shape.base * shape.height) / 2;
    default: {
      const unreachable: never = shape;
      return unreachable;
    }
  }
}

function area(shape: Shape): number {
  return round2(exactArea(shape));
}

function totalArea(shapes: readonly Shape[]): number {
  let total = 0;
  for (const shape of shapes) total += exactArea(shape);
  return round2(total);
}

function typeTests() {
  area({ kind: "circle", radius: 1 });
  area({ kind: "rect", width: 2, height: 3 });
  area({ kind: "triangle", base: 4, height: 5 });
  // @ts-expect-error: у круга есть radius, а не width
  area({ kind: "circle", width: 2 });
  // @ts-expect-error: прямоугольнику нужна height
  area({ kind: "rect", width: 2 });
  // @ts-expect-error: шестиугольников нет
  area({ kind: "hexagon", side: 1 });
}

console.log(area({ kind: "circle", radius: 1 })); // 3.14
```

Метка `kind` позволяет `switch` сузить `shape` до одного члена объединения, поэтому `shape.radius` проходит проверку типов только в ветке круга. Строка с `never` в `default` — проверка на исчерпываемость: добавьте в объединение `"square"`, забудьте про его `case` — и TypeScript сообщит, что `Square` нельзя присвоить `never`. Округление один раз в конце не даёт ошибкам округления накапливаться: семь единичных кругов занимают 21.99, а сумма семи округлённых 3.14 даёт 21.98.
