Web frameworks read `"/users/:id"` and hand your handler `params.id`, typed. Build a small router that does both halves: the **types** come from the pattern string, and the **matching** picks the right route for a path.

First the type. `Params<P>` turns a pattern into an object type with one `string` property per `:name` segment:

```ts
Params<"/users/:id/posts/:postId"> // { id: string; postId: string }
Params<"/about">                   // {}
```

Then the class `Router<R>`, where `R` is what every handler returns:

- `add(pattern, handler)` registers a route and returns the router (so calls can be chained). The handler gets `Params<typeof pattern>`.
- `handle(path)` finds the best matching route, calls its handler with the params and returns the result, or returns `undefined` if no route matches.

Matching rules:

- Split patterns and paths on `/` and ignore empty pieces, so `"/users/7/"`, `"users/7"` and `"//users//7"` are the same path. Anything from a `?` on is ignored.
- A route matches when it has the same number of segments, every static segment is equal (case-sensitive), and every `:name` segment gets that piece of the path, decoded with `decodeURIComponent`.
- If several routes match, compare their segments from left to right: at the first position where one has a static segment and the other a param, the static one wins. If that never happens, the route added first wins.

```ts
const router = new Router<string>()
  .add("/users/:id", (p) => "user " + p.id)
  .add("/users/me", () => "my profile")
  .add("/", () => "home");
router.handle("/users/42");      // "user 42"
router.handle("/users/me");      // "my profile": static beats :id
router.handle("/users/mei%20li"); // "user mei li"
router.handle("/users");         // undefined
router.handle("/?tab=new");      // "home"
```

<Hint>

There are two separate halves. For the type, template literal types with `infer` can split the pattern at `/` and pick out the `:name` pieces, one recursive step at a time. For matching, compare the route and the path segment by segment.

</Hint>

<Hint>

Collect the names first, then map them. `ParamNames<P>` checks whether `P` is a template literal of `Seg`, a slash and `Rest` (both inferred): if so, it's `Name<Seg> | ParamNames<Rest>`, otherwise `Name<P>`. `Name<S>` is the part after the colon when `S` starts with `:`, and `never` otherwise. Then `Params<P> = { [K in ParamNames<P>]: string }`, which is `{}` when there are no names. The method is `add<P extends string>(pattern: P, handler: (params: Params<P>) => R): this`. At runtime, split with `path.split("?")[0].split("/").filter((s) => s !== "")`, and store each route as its segments plus the handler (cast once to `(params: Record<string, string>) => R`). In `handle`, try every route and keep the best match, replacing it only when the new one is **more specific**: at the first index where exactly one of the two segments starts with `:`, the static one wins.

</Hint>

Matching one route is a loop over its segments: same length, equal static parts, and `decodeURIComponent` for each param.

<Solution>

```ts
// ===== Type-test helpers: don't change =====
type Expect<T extends true> = T;
type Equal<A, B> =
  (<X>() => X extends A ? 1 : 2) extends
  (<X>() => X extends B ? 1 : 2) ? true : false;

type Name<S extends string> = S extends `:${infer N}` ? N : never;
type ParamNames<P extends string> =
  P extends `${infer Seg}/${infer Rest}`
    ? Name<Seg> | ParamNames<Rest>
    : Name<P>;
type Params<P extends string> = { [K in ParamNames<P>]: string };

type Route<R> = {
  segments: string[];
  handler: (params: Record<string, string>) => R;
};

const split = (path: string) =>
  path.split("?")[0].split("/").filter((s) => s !== "");
const isParam = (segment: string) => segment.startsWith(":");

function matchRoute(
  segments: string[],
  parts: string[],
): Record<string, string> | null {
  if (segments.length !== parts.length) return null;
  const params: Record<string, string> = {};
  for (let i = 0; i < segments.length; i++) {
    if (isParam(segments[i])) {
      params[segments[i].slice(1)] = decodeURIComponent(parts[i]);
    } else if (segments[i] !== parts[i]) {
      return null;
    }
  }
  return params;
}

// Is a more specific than b? (both matched the same path)
function moreSpecific(a: string[], b: string[]): boolean {
  for (let i = 0; i < a.length; i++) {
    if (isParam(a[i]) !== isParam(b[i])) return !isParam(a[i]);
  }
  return false;
}

class Router<R> {
  private routes: Route<R>[] = [];

  add<P extends string>(
    pattern: P,
    handler: (params: Params<P>) => R,
  ): this {
    this.routes.push({
      segments: split(pattern),
      handler: handler as (params: Record<string, string>) => R,
    });
    return this;
  }

  handle(path: string): R | undefined {
    const parts = split(path);
    let best: { route: Route<R>; params: Record<string, string> } | null =
      null;
    for (const route of this.routes) {
      const params = matchRoute(route.segments, parts);
      if (!params) continue;
      if (!best || moreSpecific(route.segments, best.route.segments)) {
        best = { route, params };
      }
    }
    return best ? best.route.handler(best.params) : undefined;
  }
}

// ===== Type tests: don't change these =====
type cases = [
  Expect<Equal<
    Params<"/users/:id/posts/:postId">,
    { id: string; postId: string }
  >>,
  Expect<Equal<Params<"/about/team">, {}>>,
  Expect<Equal<Params<":lang/docs">, { lang: string }>>,
];

function typeTests(router: Router<string>) {
  router.add("/users/:id", (p) => p.id.toUpperCase());
  // @ts-expect-error: this route has no "name" param
  router.add("/users/:id", (p) => p.name);
  // @ts-expect-error: handlers of a Router<string> return strings
  router.add("/count", () => 42);
}

const router = new Router<string>()
  .add("/users/:id", (p) => "user " + p.id)
  .add("/users/me", () => "my profile");
console.log(router.handle("/users/42"), router.handle("/users/me"));
```

`ParamNames` walks the pattern one `/` at a time with `infer`, keeping only the `:name` pieces, and the mapped type turns that union into an object, so each handler sees exactly its own params. At runtime every route is tried once and compared with the best so far, O(routes × segments) per request. Real routers build a tree of segments to skip most routes, but the specificity rule is the same idea.

</Solution>
