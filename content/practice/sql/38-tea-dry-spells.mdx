The panda shop's tea buyer worries about **dry spells**: weeks when no tea sells at all 🍵. Build a weekly report for **every week** from the week starting **Monday 6 January 2025** to the week starting **Monday 16 June 2025** (24 weeks), **including the weeks with no sales**.

For each week show:

- **`week_start`**: the Monday the week starts on (a `date`),
- **`tea_units`**: how many items of the `tea` category were sold that week, counting the `quantity` of order lines in orders that **aren't cancelled** (0 if none),
- **`dry_weeks`**: how many weeks in a row, up to and including this one, have sold **no tea**. A week with tea sales resets it to 0.

Weeks start on Monday, so an order on Sunday 20 April belongs to the week starting 14 April. Sort by `week_start`.

```sql
-- week_start | tea_units | dry_weeks
-- 2025-01-06 |         0 |         1
-- 2025-01-13 |         0 |         2
-- 2025-01-20 |         0 |         3
-- 2025-01-27 |         0 |         4
-- 2025-02-03 |         2 |         0
-- 2025-02-10 |         0 |         1
-- …
```

Build the weekly tea report with a row for every week and the running count of dry weeks.

<Hint>

First make a CTE with the tea sold per week (`date_trunc('week', ordered_at)` gives the Monday). Then walk the weeks with `WITH RECURSIVE`: the anchor is the week of 2025-01-06, and each step adds 7 days, `LEFT JOIN`s that week's sales and carries the counter: `CASE WHEN … IS NULL THEN dry_weeks + 1 ELSE 0 END`. Stop when you reach 2025-06-16.

</Hint>

<Solution>

```sql
WITH RECURSIVE tea AS (
  SELECT date_trunc('week', o.ordered_at)::date AS week_start,
    sum(oi.quantity) AS units
  FROM orders AS o
  JOIN order_items AS oi ON oi.order_id = o.id
  JOIN products AS p ON p.id = oi.product_id
  WHERE p.category = 'tea' AND o.status <> 'cancelled'
  GROUP BY 1
),
weeks AS (
  SELECT first.week_start,
    coalesce(t.units, 0) AS tea_units,
    CASE WHEN t.units IS NULL THEN 1 ELSE 0 END AS dry_weeks
  FROM (SELECT date '2025-01-06' AS week_start) AS first
  LEFT JOIN tea AS t ON t.week_start = first.week_start
  UNION ALL
  SELECT w.week_start + 7,
    coalesce(t.units, 0),
    CASE WHEN t.units IS NULL THEN w.dry_weeks + 1 ELSE 0 END
  FROM weeks AS w
  LEFT JOIN tea AS t ON t.week_start = w.week_start + 7
  WHERE w.week_start < date '2025-06-16'
)
SELECT week_start, tea_units, dry_weeks
FROM weeks
ORDER BY week_start;
```

Without recursion it's a "gaps and islands" puzzle: build the weeks with `generate_series`, mark each week with tea, number the streaks with a running `count(*) FILTER (WHERE tea_units > 0) OVER (ORDER BY week_start) AS streak` and then count the tea-less weeks so far inside each streak (`count(*) FILTER (WHERE tea_units = 0) OVER (PARTITION BY streak ORDER BY week_start)`).

</Solution>
