The panda shop's manager wants a wall chart 📊: **one row per month**, with the order statuses spread out as columns. Show:

- `month`: the month of `ordered_at`, written like `2025-01`,
- `orders`: how many orders were placed that month,
- `delivered`: how many of them are `'delivered'`,
- `in_progress`: how many are `'paid'` or `'shipped'`,
- `cancelled`: how many are `'cancelled'`,
- `revenue`: `quantity * unit_price` added up over the month's orders that were **not cancelled**, and **`0`** (not NULL) when every order that month was cancelled.

Sort by `month`.

```sql
-- month   | orders | delivered | in_progress | cancelled | revenue
-- 2025-01 |      6 |         3 |           2 |         1 |  518.30
-- …
```

Careful: once you join `order_items` to get the revenue, an order with three items turns into three rows. Your order counts must still count **orders**, not items.

Group by month and use filtered aggregates to turn each status into its own column.

<Hint>

You need several counts in one row, each over a different slice of the month's orders. PostgreSQL lets you attach a condition to a single aggregate: do you know the keyword? And remember that joining `order_items` gives several rows per order.

</Hint>

<Hint>

Build it piece by piece:

- group by `to_char(o.ordered_at, 'YYYY-MM') AS month` and sort by `month`;
- count orders with `count(DISTINCT o.id)`, so an order with three items still counts once;
- for each status column, add `FILTER (WHERE …)` to that count, for example `o.status IN ('paid', 'shipped')` for `in_progress`;
- revenue is `sum(oi.quantity * oi.unit_price) FILTER (WHERE o.status <> 'cancelled')`, wrapped in `coalesce(…, 0)` so a month with only cancelled orders gives 0.

</Hint>

<Hint>

```sql
SELECT to_char(o.ordered_at, 'YYYY-MM') AS month,
  count(DISTINCT o.id) AS orders,
  count(DISTINCT o.id) FILTER (WHERE o.status = 'delivered') AS delivered,
  ... AS in_progress,
  ... AS cancelled,
  coalesce(..., 0) AS revenue  -- non-cancelled orders only
FROM orders AS o
JOIN order_items AS oi ON oi.order_id = o.id
GROUP BY month
ORDER BY month;
```

</Hint>

<Solution>

```sql
SELECT to_char(o.ordered_at, 'YYYY-MM') AS month,
  count(DISTINCT o.id) AS orders,
  count(DISTINCT o.id) FILTER (WHERE o.status = 'delivered') AS delivered,
  count(DISTINCT o.id) FILTER (WHERE o.status IN ('paid', 'shipped')) AS in_progress,
  count(DISTINCT o.id) FILTER (WHERE o.status = 'cancelled') AS cancelled,
  coalesce(sum(oi.quantity * oi.unit_price) FILTER (WHERE o.status <> 'cancelled'), 0) AS revenue
FROM orders AS o
JOIN order_items AS oi ON oi.order_id = o.id
GROUP BY month
ORDER BY month;
```

You could also total each order in a CTE first (one row per order), then pivot that with plain `count(*) FILTER (…)`.

</Solution>
