Магазин панды печатает новые ценники для полок 🏷️. Покупатели любят цены, которые заканчиваются на **.99**, поэтому у владельца есть правило: взять цену **с 20% НДС**, **округлить её вверх** до целого числа, а потом вычесть **0.01**.

Для каждого товара, который стоит **меньше 20** (без НДС), выведите:

- **`name`**;
- **`price`**: цену как есть;
- **`with_vat`**: цену, умноженную на 1.2 и **округлённую до 2 знаков после запятой**;
- **`price_tag`**: цену с НДС, **округлённую вверх** до целого, **минус 0.01**.

Отсортируйте по **`price_tag`**, от самых дешёвых; если ценники одинаковые, отсортируйте по названию.

```sql
-- name          | price | with_vat | price_tag
-- Rice Crackers | 2.50  | 3.00     | 2.99
-- Bamboo Crisps | 2.99  | 3.59     | 3.99
-- …
```

Посчитайте цену с НДС и ценник на .99 для каждого товара дешевле 20.

<Hint>

`round(x, 2)` округляет до двух знаков после запятой, а `ceil(x)` округляет **вверх** до следующего целого. С результатом можно делать арифметику, например `ceil(…) - 0.01`.

</Hint>

<Solution>

```sql
SELECT
  name,
  price,
  round(price * 1.2, 2) AS with_vat,
  ceil(price * 1.2) - 0.01 AS price_tag
FROM products
WHERE price < 20
ORDER BY price_tag, name;
```
