В оргструктуре компании панды один CEO (сотрудник без руководителя), а все остальные подчиняются кому-то через `employees.manager_id`. Каждый, кто находится **непосредственно под CEO**, возглавляет **ветвь** дерева 🌳.

Для **каждого сотрудника, кроме CEO**, выведите:

- **`name`**: имя сотрудника,
- **`branch`**: имя того непосредственного подчинённого CEO, в чьей ветви находится сотрудник (непосредственные подчинённые CEO находятся в своей собственной ветви),
- **`level`**: на сколько шагов ниже CEO он находится (1 для руководителей ветвей, 2 для их подчинённых и так далее).

Отсортируйте по `branch`, затем по `level`, затем по `name`.

```sql
-- name           | branch      | level
-- Alan Turing    | Alan Turing |     1
-- Ada Lovelace   | Alan Turing |     2
-- Barbara Liskov | Alan Turing |     2
-- Ken Thompson   | Alan Turing |     3
-- …
```

Идите по руководителям, а не по столбцу `department_id`: команду можно перевести в другую ветвь, не меняя её отдел, а дерево может разрастись на любое число уровней.

Напишите рекурсивный запрос, который даёт каждому сотруднику ниже CEO его `branch` и `level`.

<Hint>

Используйте `WITH RECURSIVE`. Якорь выбирает руководителей ветвей (тех, у чьего руководителя нет руководителя) с `name AS branch` и `1 AS level`. Рекурсивная часть присоединяет `employees AS e ON e.manager_id = tree.id` и просто **переносит** `tree.branch` вниз, прибавляя 1 к уровню.

</Hint>

<Solution>

```sql
WITH RECURSIVE tree AS (
  SELECT e.id, e.name, e.name AS branch, 1 AS level
  FROM employees AS e
  JOIN employees AS boss ON boss.id = e.manager_id
  WHERE boss.manager_id IS NULL
  UNION ALL
  SELECT e.id, e.name, tree.branch, tree.level + 1
  FROM employees AS e
  JOIN tree ON e.manager_id = tree.id
)
SELECT name, branch, level
FROM tree
ORDER BY branch, level, name;
```

Можно также начать рекурсию с CEO, у которого `level` равен 0, а ветвь — `NULL`, и задавать ветвь по пути вниз через `coalesce(tree.branch, e.name)`; тогда в конце нужно отфильтровать CEO.

</Solution>
