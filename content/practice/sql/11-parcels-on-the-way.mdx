The panda shop's courier desk wants to know who is waiting for a parcel 📦. Every order in `orders` only has a `customer_id`, so you'll need the `customers` table to get the person behind it.

Show every order whose `status` is **`'shipped'`**, with these columns:

- `order_id`: the order's `id`,
- `customer`: the customer's name,
- `city`: the customer's city.

Sort by **`order_id`**, smallest first.

```sql
-- order_id | customer     | city
--        2 | Diego López  | Mexico City
--        7 | Emma Wilson  | Sydney
-- …
```

>

Join `orders` to `customers` and keep only the shipped orders, sorted by `order_id`.

<Hint>

The order lives in `orders`, but the customer's name and city live in `customers`. Which column links the two tables?

</Hint>

<Hint>

Give each table a short alias and join them with `JOIN customers AS c ON c.id = o.customer_id`. Select `o.id AS order_id`, `c.name AS customer` and `c.city`. Keep only `WHERE o.status = 'shipped'` and sort with `ORDER BY o.id`.

</Hint>

<Hint>

```sql
SELECT o.id AS order_id,
  c.name AS customer,
  c.city
FROM orders AS o
JOIN customers AS c ON ...  -- match each order to its customer
WHERE ...                   -- only shipped orders
ORDER BY o.id;
```

</Hint>

<Solution>

```sql
SELECT o.id AS order_id,
  c.name AS customer,
  c.city
FROM orders AS o
JOIN customers AS c ON c.id = o.customer_id
WHERE o.status = 'shipped'
ORDER BY o.id;
```

</Solution>
