Компания думает открыть новый офис 🏢 поближе к своим покупателям. Найдите города, где есть **покупатели**, но пока **нет офиса** (офис — это `location` отдела).

Выведите:

- `city`: город,
- `customers`: сколько покупателей в нём живёт.

Покупатели без города (`NULL`) за город не считаются. Поставьте город с **наибольшим числом покупателей первым**; если у двух городов число одинаковое, отсортируйте их по названию.

```sql
-- city       | customers
-- Moscow     |         2
-- Manchester |         1
-- …
```

Найдите города с помощью `EXCEPT`, а затем посчитайте покупателей в каждом из них.

<Hint>

«Города, которые есть в одном списке, но нет в другом» — это операция над множествами. Какая из них оставляет строки первого запроса, которых нет во втором? Не забудьте про покупателей, у которых город `NULL`.

</Hint>

<Hint>

`SELECT city FROM customers EXCEPT SELECT location FROM departments` даёт города без офиса (и ещё `NULL`). Поместите это в CTE, снова соедините с `customers` по городу и сгруппируйте по городу с `count(*)`. Соединение по `NULL` никогда не находит совпадений, поэтому строка с `NULL` выпадает сама собой. Отсортируйте по количеству, от большего к меньшему, затем по городу.

</Hint>

<Hint>

```sql
WITH no_office AS (
  SELECT city FROM customers
  EXCEPT
  ...  -- города, где есть офис
)
SELECT n.city, count(*) AS customers
FROM no_office AS n
JOIN customers AS c ON ...
GROUP BY n.city
ORDER BY customers DESC, n.city;
```

</Hint>

<Solution>

```sql
WITH no_office AS (
  SELECT city FROM customers
  EXCEPT
  SELECT location FROM departments
)
SELECT n.city, count(*) AS customers
FROM no_office AS n
JOIN customers AS c ON c.city = n.city
GROUP BY n.city
ORDER BY customers DESC, n.city;
```

</Solution>
