Закупщик чая в магазине панды беспокоится о **засухах** — неделях, когда чай не продаётся вовсе 🍵. Постройте недельный отчёт за **каждую неделю**, начиная с недели, которая начинается в **понедельник 6 января 2025 года**, и заканчивая неделей, которая начинается в **понедельник 16 июня 2025 года** (24 недели), **включая недели без продаж**.

Для каждой недели выведите:

- **`week_start`**: понедельник, с которого начинается неделя (тип `date`),
- **`tea_units`**: сколько единиц товаров категории `tea` продано за эту неделю — сумму `quantity` позиций в **неотменённых** заказах (0, если продаж не было),
- **`dry_weeks`**: сколько недель подряд, включая текущую, **чай не продавался**. Неделя с продажами чая сбрасывает счётчик в 0.

Недели начинаются с понедельника, поэтому заказ в воскресенье 20 апреля относится к неделе, которая начинается 14 апреля. Отсортируйте по `week_start`.

```sql
-- week_start | tea_units | dry_weeks
-- 2025-01-06 |         0 |         1
-- 2025-01-13 |         0 |         2
-- 2025-01-20 |         0 |         3
-- 2025-01-27 |         0 |         4
-- 2025-02-03 |         2 |         0
-- 2025-02-10 |         0 |         1
-- …
```

Постройте недельный отчёт по чаю со строкой на каждую неделю и нарастающим счётчиком недель без чая.

<Hint>

В неделях без продаж чая нет заказов с чаем, поэтому из одних продаж их не получить: список недель придётся построить самим. А счётчик недель без чая зависит от значения прошлой недели.

</Hint>

<Hint>

1. В CTE сложите `quantity` чая по неделям для неотменённых заказов; `date_trunc('week', ordered_at)::date` даёт понедельник.
2. Пройдите по неделям с помощью `WITH RECURSIVE`: якорь — `date '2025-01-06'`, а каждый шаг прибавляет 7 дней, пока не дойдёт до 2025-06-16.
3. На каждом шаге присоединяйте продажи чая этой недели через `LEFT JOIN`. Для `tea_units` используйте `coalesce(…, 0)`, а счётчик переносите так: `CASE WHEN … IS NULL THEN dry_weeks + 1 ELSE 0 END`. В якоре счётчик начинается с 1 или 0.

</Hint>

<Hint>

```sql
WITH RECURSIVE tea AS (
  ...  -- week_start и проданные штуки чая, без отменённых заказов
),
weeks AS (
  SELECT first.week_start,
    coalesce(t.units, 0) AS tea_units,
    CASE WHEN t.units IS NULL THEN 1 ELSE 0 END AS dry_weeks
  FROM (SELECT date '2025-01-06' AS week_start) AS first
  LEFT JOIN tea AS t ON t.week_start = first.week_start
  UNION ALL
  SELECT w.week_start + 7,
    coalesce(t.units, 0),
    ...  -- прибавьте 1 к счётчику или сбросьте его в 0
  FROM weeks AS w
  LEFT JOIN tea AS t ON t.week_start = w.week_start + 7
  WHERE ...  -- остановитесь на 2025-06-16
)
SELECT week_start, tea_units, dry_weeks
FROM weeks
ORDER BY week_start;
```

</Hint>

<Solution>

```sql
WITH RECURSIVE tea AS (
  SELECT date_trunc('week', o.ordered_at)::date AS week_start,
    sum(oi.quantity) AS units
  FROM orders AS o
  JOIN order_items AS oi ON oi.order_id = o.id
  JOIN products AS p ON p.id = oi.product_id
  WHERE p.category = 'tea' AND o.status <> 'cancelled'
  GROUP BY 1
),
weeks AS (
  SELECT first.week_start,
    coalesce(t.units, 0) AS tea_units,
    CASE WHEN t.units IS NULL THEN 1 ELSE 0 END AS dry_weeks
  FROM (SELECT date '2025-01-06' AS week_start) AS first
  LEFT JOIN tea AS t ON t.week_start = first.week_start
  UNION ALL
  SELECT w.week_start + 7,
    coalesce(t.units, 0),
    CASE WHEN t.units IS NULL THEN w.dry_weeks + 1 ELSE 0 END
  FROM weeks AS w
  LEFT JOIN tea AS t ON t.week_start = w.week_start + 7
  WHERE w.week_start < date '2025-06-16'
)
SELECT week_start, tea_units, dry_weeks
FROM weeks
ORDER BY week_start;
```

Без рекурсии это задача «пробелов и островов» (gaps and islands): постройте недели с помощью `generate_series`, отметьте недели с чаем, пронумеруйте серии нарастающим `count(*) FILTER (WHERE tea_units > 0) OVER (ORDER BY week_start) AS streak`, а затем посчитайте недели без чая, накопившиеся внутри каждой серии (`count(*) FILTER (WHERE tea_units = 0) OVER (PARTITION BY streak ORDER BY week_start)`).

</Solution>
