Владелец магазина панды хочет одну строку для верхней части панели 🐼. По таблице `products` верните **ровно одну строку** со столбцами:

- `products`: сколько товаров продаёт магазин,
- `cheapest`: самая низкая цена,
- `priciest`: самая высокая цена,
- `avg_price`: средняя цена, **округлённая до 2 знаков после запятой**,
- `total_stock`: сумма всех значений `stock`.

```sql
-- products | cheapest | priciest | avg_price | total_stock
--       15 |     2.50 |    89.90 |     18.13 |         585
```

Замените столбцы агрегатными функциями, чтобы запрос возвращал одну итоговую строку.

<Hint>

Каждый столбец — одно число для всей таблицы. Какие агрегатные функции дают количество, наименьшее значение, наибольшее, среднее и сумму?

</Hint>

<Hint>

Без `GROUP BY` агрегатные функции сжимают всю таблицу в одну строку. Используйте `count(*)`, `min(price)`, `max(price)`, `avg(price)` и `sum(stock)` и дайте каждой псевдоним из задания. Округлите среднее с помощью `round(avg(price), 2)`.

</Hint>

<Hint>

```sql
SELECT count(*) AS products,
  min(price) AS cheapest,
  ... AS priciest,
  ... AS avg_price,  -- 2 знака после запятой
  ... AS total_stock
FROM products;
```

</Hint>

<Solution>

```sql
SELECT count(*) AS products,
  min(price) AS cheapest,
  max(price) AS priciest,
  round(avg(price), 2) AS avg_price,
  sum(stock) AS total_stock
FROM products;
```

</Solution>
