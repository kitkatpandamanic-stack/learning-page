The panda shop's owner wants a single line for the top of the dashboard 🐼. Using the `products` table, return **exactly one row** with:

- `products`: how many products the shop sells,
- `cheapest`: the lowest price,
- `priciest`: the highest price,
- `avg_price`: the average price, **rounded to 2 decimal places**,
- `total_stock`: all the `stock` added up.

```sql
-- products | cheapest | priciest | avg_price | total_stock
--       15 |     2.50 |    89.90 |     18.13 |         585
```

Replace the columns with aggregate functions so the query returns one summary row.

<Hint>

Each column is one number for the whole table. Which aggregate functions give you a count, a smallest value, a largest value, an average and a total?

</Hint>

<Hint>

Without `GROUP BY`, aggregates squash the whole table into one row. Use `count(*)`, `min(price)`, `max(price)`, `avg(price)` and `sum(stock)`, each with the alias from the task. Round the average with `round(avg(price), 2)`.

</Hint>

<Hint>

```sql
SELECT count(*) AS products,
  min(price) AS cheapest,
  ... AS priciest,
  ... AS avg_price,  -- 2 decimals
  ... AS total_stock
FROM products;
```

</Hint>

<Solution>

```sql
SELECT count(*) AS products,
  min(price) AS cheapest,
  max(price) AS priciest,
  round(avg(price), 2) AS avg_price,
  sum(stock) AS total_stock
FROM products;
```

</Solution>
