К магазину панды только что подъехал фургон 🚚. Заготовка сохраняет его накладную в таблицу `delivery`: одна строка на **коробку**, с названием товара (`name`), `category`, `price` и количеством единиц в коробке (`items`). Некоторые товары пришли **в нескольких коробках**.

Разложите поставку по полкам **одним `INSERT … ON CONFLICT`** в `products`:

- У товара, который магазин **уже продаёт** (с тем же `name`), `stock` **увеличивается** на все доставленные для него единицы. Его `price` и `category` остаются прежними, даже если в накладной написано другое.
- Товар, который магазин **ещё не продаёт**, добавляется, и доставленные единицы становятся его запасом.

В `products` пока нет правила, что названия уникальны, а `ON CONFLICT (name)` без него не работает, поэтому **сначала добавьте ограничение уникальности на `products.name`**. Завершите upsert на `RETURNING name, stock`. Порядок возвращённых строк не важен.

```sql
-- name         | stock
-- Jasmine Tea  |    60   -- 40 на полке + 12 + 8 в поставке
-- Lychee Tea   |    25   -- новый
-- …
```

Используйте строки из `delivery`, а не список значений, набранный вручную: завтрашний фургон привезёт другую накладную.

Сделайте названия товаров уникальными, затем добавьте поставку в `products` одним upsert, который возвращает `name` и `stock`.

<Hint>

Первым идёт `ALTER TABLE products ADD CONSTRAINT … UNIQUE (name)`. Из-за товара в двух коробках `ON CONFLICT` затронул бы одну и ту же строку дважды (это ошибка), поэтому сначала сложите коробки: `INSERT INTO products (…) SELECT name, …, sum(items) FROM delivery GROUP BY …`. В `DO UPDATE` `products.stock` — это старое значение, а `EXCLUDED.stock` — то, что вы пытались вставить.

</Hint>

<Solution>

```sql
CREATE TABLE delivery (
  name text NOT NULL,
  category text NOT NULL,
  price numeric(8, 2) NOT NULL,
  items integer NOT NULL
);

INSERT INTO delivery (name, category, price, items) VALUES
  ('Jasmine Tea', 'tea', 6.50, 12),
  ('Earl Grey', 'tea', 5.25, 20),
  ('Lychee Tea', 'tea', 7.20, 15),
  ('Kite', 'toys', 14.00, 6),
  ('Jasmine Tea', 'tea', 6.50, 8),
  ('Bamboo Yo-yo', 'toys', 3.40, 30),
  ('Lychee Tea', 'tea', 7.20, 10);

ALTER TABLE products ADD CONSTRAINT products_name_key UNIQUE (name);

INSERT INTO products (name, category, price, stock)
SELECT name, min(category), min(price), sum(items)
FROM delivery
GROUP BY name
ON CONFLICT (name) DO UPDATE
SET stock = products.stock + EXCLUDED.stock
RETURNING name, stock;
```

В списке `SET` только `stock`, поэтому Kite сохраняет магазинную цену 15.00, хотя в накладной написано 14.00. `min(category)` и `min(price)` просто выбирают одно значение для каждого названия; подойдёт и `GROUP BY name, category, price`, если у всех коробок одного товара одинаковая цена.

</Solution>
