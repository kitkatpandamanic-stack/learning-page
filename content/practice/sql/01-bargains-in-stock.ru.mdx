Магазин панды хочет сделать «полку выгодных покупок» 🐼. По таблице `products` выведите **`name`** и **`price`** всех товаров, которые стоят **меньше 10** и есть **в наличии** (`stock` больше 0).

Отсортируйте их по цене, от самых дешёвых. Если у двух товаров одинаковая цена, отсортируйте их по названию.

```sql
-- name              | price
-- Rice Crackers     | 2.50
-- Bamboo Crisps     | 2.99
-- …
```

<Exercise
  language="sql"
  title="Выгодные товары в наличии"
  starter={`-- name и price товаров дешевле 10, которые есть в наличии,
-- от самых дешёвых
SELECT name, price, stock
FROM products;
`}
  tests={[
    { name: "Столбцы: name, price", check: "columns.join() === 'name,price'" },
    { name: "Только товары дешевле 10, которые есть в наличии", check: "rows.map(r => r.name).sort().join() === 'Bamboo Chopsticks,Bamboo Crisps,Jasmine Tea,Panda Cookies,Rice Crackers'" },
    { name: "Сначала самые дешёвые", check: "rows.map(r => r.price).join() === '2.5,2.99,3.75,4.2,6.5'" },
    { name: "Earl Grey нет в наличии, поэтому его нет в списке", check: "!rows.some(r => r.name === 'Earl Grey')" },
    { name: "Работает, когда меняется наличие", check: "(r => r.map(x => x.name).join() === 'Bamboo Crisps,Panda Cookies,Bamboo Chopsticks,Earl Grey,Jasmine Tea')(await rerun(\"UPDATE products SET stock = 5 WHERE name = 'Earl Grey'; UPDATE products SET stock = 0 WHERE name = 'Rice Crackers'\"))" },
  ]}
>

Допишите запрос, чтобы он показывал только выгодные товары в наличии, от самых дешёвых.

<Hint>

Объедините оба условия через `AND`: `WHERE price < 10 AND stock > 0`. Затем отсортируйте с помощью `ORDER BY price, name`.

</Hint>

<Solution>

```sql
SELECT name, price
FROM products
WHERE price < 10 AND stock > 0
ORDER BY price, name;
```

</Solution>

</Exercise>
