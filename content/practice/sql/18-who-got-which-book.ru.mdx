Книжный уголок магазина панды хочет отправить записку «Как вам книга?» 📚 всем, кто **получил** книгу. Выведите все книги, проданные в заказах со статусом **`'delivered'`**, со столбцами:

- `order_id`,
- `customer`: имя покупателя,
- `book`: название товара,
- `quantity`: сколько экземпляров было в этом заказе.

Книга — это товар, у которого `category` равна **`'books'`**. Отсортируйте по `order_id`, затем по `book`.

```sql
-- order_id | customer     | book                   | quantity
--        1 | Sofia Rossi  | Algorithms in Pictures |        3
--        5 | Sam Ortiz    | Clean Python           |        2
-- …
```

Пройдите от `customers` к `orders`, от них к `order_items` и к `products`, оставив только книги из доставленных заказов.

<Hint>

Четыре столбца берутся из четырёх разных таблиц. Набросайте путь между ними: какой столбец связывает каждую таблицу со следующей?

</Hint>

<Hint>

Начните с `customers` и соедините по цепочке три раза: `orders` по `o.customer_id = c.id`, `order_items` по `oi.order_id = o.id` и `products` по `p.id = oi.product_id`. Отфильтруйте сразу по двум таблицам: `p.category = 'books' AND o.status = 'delivered'`. Переименуйте столбцы (`o.id AS order_id`, `c.name AS customer`, `p.name AS book`) и отсортируйте по `o.id, book`.

</Hint>


<Solution>

```sql
SELECT o.id AS order_id,
  c.name AS customer,
  p.name AS book,
  oi.quantity
FROM customers AS c
JOIN orders AS o ON o.customer_id = c.id
JOIN order_items AS oi ON oi.order_id = o.id
JOIN products AS p ON p.id = oi.product_id
WHERE p.category = 'books'
  AND o.status = 'delivered'
ORDER BY o.id, book;
```

</Solution>
