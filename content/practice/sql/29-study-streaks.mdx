PandaDev wants to give a badge 🔥 for **study streaks**: days in a row on which a learner studied. The starter creates a `study_days` log with one row per lesson finished, so a learner who did **two lessons on one day** has that day in the log **twice**.

For each learner, find their **longest streak** of consecutive days. Show:

- `learner`: the learner's name,
- `streak_start` and `streak_end`: the first and last day of the streak,
- `days`: how many days the streak lasted.

If a learner has two equally long streaks, show the **earlier** one. Sort by learner.

```sql
-- learner | streak_start | streak_end | days
-- Ada     | 2025-02-27   | 2025-03-02 |    4
-- …
```

Group each learner's days into streaks, then pick the longest streak per learner.

<Hint>

This is the **gaps-and-islands** trick. First remove repeated days with `SELECT DISTINCT learner, studied_on`. Then number each learner's days with `row_number() OVER (PARTITION BY learner ORDER BY studied_on)`: on consecutive days, `studied_on - row_number::int` gives the **same date**, so it labels the streak. Group by learner and that label to get each streak, and finally use `row_number()` again (longest first, then earliest) to keep one streak per learner.

</Hint>

<Solution>

```sql
CREATE TABLE study_days (
  learner text NOT NULL,
  studied_on date NOT NULL
);

INSERT INTO study_days (learner, studied_on) VALUES
  ('Mei', '2025-03-01'), ('Mei', '2025-03-02'), ('Mei', '2025-03-03'),
  ('Mei', '2025-03-05'), ('Mei', '2025-03-06'), ('Mei', '2025-03-06'),
  ('Mei', '2025-03-07'), ('Mei', '2025-03-08'), ('Mei', '2025-03-10'),
  ('Sam', '2025-03-04'), ('Sam', '2025-03-01'), ('Sam', '2025-03-02'),
  ('Sam', '2025-03-05'), ('Sam', '2025-03-07'),
  ('Ada', '2025-02-27'), ('Ada', '2025-02-28'), ('Ada', '2025-02-28'),
  ('Ada', '2025-03-01'), ('Ada', '2025-03-02'), ('Ada', '2025-03-09');

WITH days AS (
  SELECT DISTINCT learner, studied_on
  FROM study_days
),
labelled AS (
  SELECT learner, studied_on,
    studied_on - (row_number() OVER (PARTITION BY learner ORDER BY studied_on))::int AS streak
  FROM days
),
streaks AS (
  SELECT learner, min(studied_on) AS streak_start,
    max(studied_on) AS streak_end, count(*) AS days
  FROM labelled
  GROUP BY learner, streak
),
ranked AS (
  SELECT *,
    row_number() OVER (PARTITION BY learner ORDER BY days DESC, streak_start) AS pick
  FROM streaks
)
SELECT learner, streak_start, streak_end, days
FROM ranked
WHERE pick = 1
ORDER BY learner;
```

Without the `DISTINCT`, Mei's second 6 March would shift the numbering and glue days from different streaks together.

</Solution>
