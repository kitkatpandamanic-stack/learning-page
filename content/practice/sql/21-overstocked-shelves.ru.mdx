На складе магазина панды становится тесно 📦. По таблице `products` выведите **`name`** и **`stock`** всех товаров, остаток которых **больше среднего остатка** по всем товарам.

Вычислите среднее **внутри запроса**. Не вписывайте число, посчитанное вручную: остатки меняются каждый день.

Поставьте **самые большие остатки первыми**. Если у двух товаров одинаковый остаток, отсортируйте их по названию.

```sql
-- name              | stock
-- Bamboo Chopsticks |   200
-- Bamboo Crisps     |   120
-- …
```

<Exercise
  language="sql"
  title="Переполненные полки"
  starter={`-- name и stock товаров, остаток которых больше среднего,
-- от самого большого остатка
SELECT name, stock
FROM products
ORDER BY stock DESC;
`}
  tests={[

    { name: "Сначала самые большие остатки", check: "rows.map(r => r.stock).join() === '200,120,85,60,40'" },
    { name: "Earl Grey (нет в наличии) в списке нет", check: "!rows.some(r => r.name === 'Earl Grey')" },
    { name: "Работает, когда меняются данные", check: "(await rerun(\"UPDATE products SET stock = 500 WHERE name = 'Kite'\")).map(r => r.name).join() === 'Kite,Bamboo Chopsticks,Bamboo Crisps,Panda Cookies'" },
  ]}
>

Добавьте `WHERE`, который сравнивает остаток каждого товара со средним остатком по всем товарам.

<Hint>

**Скалярный подзапрос (scalar subquery)** возвращает одно значение, поэтому его можно использовать как число: `WHERE stock > (SELECT avg(…) FROM products)`. Затем отсортируйте с помощью `ORDER BY stock DESC, name`.

</Hint>

<Solution>

```sql
SELECT name, stock
FROM products
WHERE stock > (SELECT avg(stock) FROM products)
ORDER BY stock DESC, name;
```

</Solution>

</Exercise>
