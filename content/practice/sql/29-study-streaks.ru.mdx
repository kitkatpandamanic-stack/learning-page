PandaDev хочет выдавать значок 🔥 за **серии занятий**: дни подряд, в которые ученик занимался. Стартовый код создаёт журнал `study_days`, где одна строка соответствует одному пройденному уроку, поэтому если ученик прошёл **два урока за один день**, этот день записан в журнале **дважды**.

Для каждого ученика найдите его **самую длинную серию** дней подряд. Выведите:

- `learner`: имя ученика,
- `streak_start` и `streak_end`: первый и последний день серии,
- `days`: сколько дней длилась серия.

Если у ученика две одинаково длинные серии, покажите **более раннюю**. Отсортируйте по ученику.

```sql
-- learner | streak_start | streak_end | days
-- Ada     | 2025-02-27   | 2025-03-02 |    4
-- …
```

Разбейте дни каждого ученика на серии, а затем выберите для каждого ученика самую длинную.

<Hint>

Это приём **«пропуски и острова» (gaps and islands)**. Сначала уберите повторяющиеся дни с помощью `SELECT DISTINCT learner, studied_on`. Затем пронумеруйте дни каждого ученика через `row_number() OVER (PARTITION BY learner ORDER BY studied_on)`: для дней подряд `studied_on - row_number::int` даёт **одну и ту же дату**, и она служит меткой серии. Сгруппируйте по ученику и этой метке, чтобы получить каждую серию, и в конце снова используйте `row_number()` (сначала самая длинная, затем самая ранняя), чтобы оставить одну серию на ученика.

</Hint>

<Solution>

```sql
CREATE TABLE study_days (
  learner text NOT NULL,
  studied_on date NOT NULL
);

INSERT INTO study_days (learner, studied_on) VALUES
  ('Mei', '2025-03-01'), ('Mei', '2025-03-02'), ('Mei', '2025-03-03'),
  ('Mei', '2025-03-05'), ('Mei', '2025-03-06'), ('Mei', '2025-03-06'),
  ('Mei', '2025-03-07'), ('Mei', '2025-03-08'), ('Mei', '2025-03-10'),
  ('Sam', '2025-03-04'), ('Sam', '2025-03-01'), ('Sam', '2025-03-02'),
  ('Sam', '2025-03-05'), ('Sam', '2025-03-07'),
  ('Ada', '2025-02-27'), ('Ada', '2025-02-28'), ('Ada', '2025-02-28'),
  ('Ada', '2025-03-01'), ('Ada', '2025-03-02'), ('Ada', '2025-03-09');

WITH days AS (
  SELECT DISTINCT learner, studied_on
  FROM study_days
),
labelled AS (
  SELECT learner, studied_on,
    studied_on - (row_number() OVER (PARTITION BY learner ORDER BY studied_on))::int AS streak
  FROM days
),
streaks AS (
  SELECT learner, min(studied_on) AS streak_start,
    max(studied_on) AS streak_end, count(*) AS days
  FROM labelled
  GROUP BY learner, streak
),
ranked AS (
  SELECT *,
    row_number() OVER (PARTITION BY learner ORDER BY days DESC, streak_start) AS pick
  FROM streaks
)
SELECT learner, streak_start, streak_end, days
FROM ranked
WHERE pick = 1
ORDER BY learner;
```

Без `DISTINCT` второе 6 марта у Mei сдвинуло бы нумерацию и склеило бы дни из разных серий.

</Solution>
