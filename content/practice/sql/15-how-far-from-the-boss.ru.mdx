Отдел кадров компании панды пересматривает зарплаты 💼. Для **каждого** сотрудника выведите, кому он подчиняется и насколько больше зарабатывает его руководитель:

- `employee`: имя сотрудника,
- `manager`: имя его руководителя,
- `pay_gap`: `salary` руководителя минус `salary` сотрудника.

У CEO нет руководителя, но она **всё равно должна попасть в результат**, с NULL и в `manager`, и в `pay_gap`.

Отсортируйте по `pay_gap`, **от большего к меньшему**, а строку CEO поставьте **в самый конец**. Если разница одинаковая, отсортируйте по `employee`.

```sql
-- employee     | manager      | pay_gap
-- Hana Sato    | Grace Hopper |   80000
-- Mary Kay     | Grace Hopper |   60000
-- …
-- Grace Hopper | NULL         |    NULL
```

Соедините `employees` саму с собой, чтобы найти руководителя каждого сотрудника, и не потеряйте CEO.

<Hint>

Каждый руководитель — это тоже строка в `employees`. Как соединить таблицу саму с собой? И какое соединение сохранит CEO, у которой нет руководителя?

</Hint>

<Hint>

Возьмите `employees` дважды под двумя псевдонимами: `e` для сотрудника и `m` для руководителя, и соедините их `ON m.id = e.manager_id`. Сделайте это `LEFT JOIN`, чтобы CEO осталась, а `m.name` и `m.salary - e.salary` для неё были NULL. В PostgreSQL `DESC` ставит NULL в начало, поэтому сортируйте через `pay_gap DESC NULLS LAST, employee`.

</Hint>

<Hint>

```sql
SELECT e.name AS employee,
  m.name AS manager,
  ... AS pay_gap
FROM employees AS e
LEFT JOIN employees AS m ON ...
ORDER BY pay_gap DESC ..., employee;  -- CEO в конце
```

</Hint>

<Solution>

```sql
SELECT e.name AS employee,
  m.name AS manager,
  m.salary - e.salary AS pay_gap
FROM employees AS e
LEFT JOIN employees AS m ON m.id = e.manager_id
ORDER BY pay_gap DESC NULLS LAST, employee;
```

</Solution>
