The panda shop wants customers to leave reviews ⭐. Create a table called **`reviews`** with these columns, in this order, and let the database enforce the rules:

| column | rules |
| --- | --- |
| `id` | an identity primary key the database numbers itself |
| `product_id` | required, must be a real product (`products.id`) |
| `customer_id` | required, must be a real customer (`customers.id`) |
| `stars` | required, a whole number from **1 to 5** |
| `comment` | text, optional |
| `helpful_votes` | required, **0 by default**, never negative |

On top of that, **a customer can review each product only once**.

Then add these four reviews and finish with a report: one row per reviewed product with **`product`** (the product's name), **`reviews`** (how many) and **`avg_stars`** (the average, rounded to 1 decimal). Best average first; ties by product name.

| product_id | customer_id | stars | comment |
| --- | --- | --- | --- |
| 5 | 2 | 5 | Crunchy and cute |
| 5 | 3 | 4 | *(none)* |
| 15 | 2 | 3 | Great rice, loud beep |
| 10 | 6 | 5 | My new best friend |

```sql
-- product       | reviews | avg_stars
-- Plush Panda   |       1 |       5.0
-- Panda Cookies |       2 |       4.5
-- …
```

<Solution>

```sql
CREATE TABLE reviews (
  id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  product_id integer NOT NULL REFERENCES products (id),
  customer_id integer NOT NULL REFERENCES customers (id),
  stars integer NOT NULL CHECK (stars BETWEEN 1 AND 5),
  comment text,
  helpful_votes integer NOT NULL DEFAULT 0 CHECK (helpful_votes >= 0),
  UNIQUE (product_id, customer_id)
);

INSERT INTO reviews (product_id, customer_id, stars, comment) VALUES
  (5, 2, 5, 'Crunchy and cute'),
  (5, 3, 4, NULL),
  (15, 2, 3, 'Great rice, loud beep'),
  (10, 6, 5, 'My new best friend');

SELECT p.name AS product,
  count(*) AS reviews,
  round(avg(r.stars), 1) AS avg_stars
FROM reviews AS r
JOIN products AS p ON p.id = r.product_id
GROUP BY p.name
ORDER BY avg_stars DESC, product;
```

`NOT NULL` matters on the foreign keys: `REFERENCES` alone still lets a review without a product through, because a `NULL` key isn't checked against anything.
