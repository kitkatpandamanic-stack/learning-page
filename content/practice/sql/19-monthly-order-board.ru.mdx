Управляющий магазином панды хочет настенную сводку 📊: **по одной строке на месяц**, а статусы заказов разложены по столбцам. Выведите:

- `month`: месяц из `ordered_at` в виде `2025-01`,
- `orders`: сколько заказов сделано в этом месяце,
- `delivered`: сколько из них в статусе `'delivered'`,
- `in_progress`: сколько в статусе `'paid'` или `'shipped'`,
- `cancelled`: сколько в статусе `'cancelled'`,
- `revenue`: сумма `quantity * unit_price` по **неотменённым** заказам месяца, причём **`0`** (а не NULL), если в этом месяце отменены все заказы.

Отсортируйте по `month`.

```sql
-- month   | orders | delivered | in_progress | cancelled | revenue
-- 2025-01 |      6 |         3 |           2 |         1 |  518.30
-- …
```

Осторожно: когда вы присоедините `order_items`, чтобы посчитать выручку, заказ с тремя позициями превратится в три строки. Счётчики при этом всё равно должны считать **заказы**, а не позиции.

Сгруппируйте по месяцу и с помощью агрегатов с фильтром превратите каждый статус в отдельный столбец.

<Hint>

`count(*) FILTER (WHERE status = 'delivered')` считает только часть строк группы. После присоединения `order_items` считайте заказы через `count(DISTINCT o.id)` (с `FILTER` это тоже работает). Выручку сложите с помощью `sum(…) FILTER (WHERE o.status <> 'cancelled')` и оберните в `coalesce(…, 0)`.

</Hint>

<Solution>

```sql
SELECT to_char(o.ordered_at, 'YYYY-MM') AS month,
  count(DISTINCT o.id) AS orders,
  count(DISTINCT o.id) FILTER (WHERE o.status = 'delivered') AS delivered,
  count(DISTINCT o.id) FILTER (WHERE o.status IN ('paid', 'shipped')) AS in_progress,
  count(DISTINCT o.id) FILTER (WHERE o.status = 'cancelled') AS cancelled,
  coalesce(sum(oi.quantity * oi.unit_price) FILTER (WHERE o.status <> 'cancelled'), 0) AS revenue
FROM orders AS o
JOIN order_items AS oi ON oi.order_id = o.id
GROUP BY month
ORDER BY month;
```

Можно также сначала посчитать сумму каждого заказа в CTE (по одной строке на заказ), а затем развернуть результат обычным `count(*) FILTER (…)`.

</Solution>

</Exercise>
