Магазин панды хочет, чтобы покупатели оставляли отзывы ⭐. Создайте таблицу **`reviews`** с этими столбцами, в этом порядке, и поручите базе данных следить за соблюдением правил:

| столбец | правила |
| --- | --- |
| `id` | первичный ключ, столбец идентификации (identity), который база нумерует сама |
| `product_id` | обязательный, должен ссылаться на существующий товар (`products.id`) |
| `customer_id` | обязательный, должен ссылаться на существующего покупателя (`customers.id`) |
| `stars` | обязательный, целое число от **1 до 5** |
| `comment` | текст, необязательный |
| `helpful_votes` | обязательный, **по умолчанию 0**, никогда не бывает отрицательным |

Кроме того, **покупатель может оставить отзыв на каждый товар только один раз**.

Затем добавьте эти четыре отзыва и завершите решение отчётом: одна строка на каждый товар с отзывами, со столбцами **`product`** (название товара), **`reviews`** (сколько отзывов) и **`avg_stars`** (средняя оценка, округлённая до 1 знака после запятой). Сначала лучшая средняя оценка; при равенстве — по названию товара.

| product_id | customer_id | stars | comment |
| --- | --- | --- | --- |
| 5 | 2 | 5 | Crunchy and cute |
| 5 | 3 | 4 | *(нет)* |
| 15 | 2 | 3 | Great rice, loud beep |
| 10 | 6 | 5 | My new best friend |

```sql
-- product       | reviews | avg_stars
-- Plush Panda   |       1 |       5.0
-- Panda Cookies |       2 |       4.5
-- …
```

Создайте `reviews` со всеми правилами, добавьте четыре отзыва и напишите отчёт.

<Hint>

Правила пишутся сразу после типа столбца: `NOT NULL`, `DEFAULT 0`, `CHECK (stars BETWEEN 1 AND 5)`, `REFERENCES products (id)`. «Один отзыв от покупателя на товар» — это правило уровня таблицы для двух столбцов: `UNIQUE (product_id, customer_id)`. Для отчёта присоедините `products`, затем используйте `GROUP BY` и `round(avg(stars), 1)`.

</Hint>

<Solution>

```sql
CREATE TABLE reviews (
  id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  product_id integer NOT NULL REFERENCES products (id),
  customer_id integer NOT NULL REFERENCES customers (id),
  stars integer NOT NULL CHECK (stars BETWEEN 1 AND 5),
  comment text,
  helpful_votes integer NOT NULL DEFAULT 0 CHECK (helpful_votes >= 0),
  UNIQUE (product_id, customer_id)
);

INSERT INTO reviews (product_id, customer_id, stars, comment) VALUES
  (5, 2, 5, 'Crunchy and cute'),
  (5, 3, 4, NULL),
  (15, 2, 3, 'Great rice, loud beep'),
  (10, 6, 5, 'My new best friend');

SELECT p.name AS product,
  count(*) AS reviews,
  round(avg(r.stars), 1) AS avg_stars
FROM reviews AS r
JOIN products AS p ON p.id = r.product_id
GROUP BY p.name
ORDER BY avg_stars DESC, product;
```

`NOT NULL` на внешних ключах важен: один только `REFERENCES` всё равно пропустит отзыв без товара, потому что ключ со значением `NULL` ни с чем не сверяется.
