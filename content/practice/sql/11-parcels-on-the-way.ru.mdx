Курьерская служба магазина панды хочет знать, кто ждёт посылку 📦. В каждом заказе в `orders` есть только `customer_id`, поэтому, чтобы узнать, кто стоит за заказом, вам понадобится таблица `customers`.

Выведите все заказы со `status` **`'shipped'`** со следующими столбцами:

- `order_id`: `id` заказа,
- `customer`: имя покупателя,
- `city`: город покупателя.

Отсортируйте по **`order_id`**, по возрастанию.

```sql
-- order_id | customer     | city
--        2 | Diego López  | Mexico City
--        7 | Emma Wilson  | Sydney
-- …
```

Соедините `orders` с `customers` и оставьте только отправленные заказы, отсортированные по `order_id`.

<Hint>

Дайте каждой таблице короткий псевдоним (alias) и сопоставьте строки с помощью `JOIN customers AS c ON c.id = o.customer_id`. Переименуйте столбцы через `AS`, например `o.id AS order_id`, а затем отфильтруйте с помощью `WHERE o.status = 'shipped'`.

</Hint>

<Solution>

```sql
SELECT o.id AS order_id,
  c.name AS customer,
  c.city
FROM orders AS o
JOIN customers AS c ON c.id = o.customer_id
WHERE o.status = 'shipped'
ORDER BY o.id;
```

</Solution>
