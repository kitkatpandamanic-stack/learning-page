The film club is printing a "Best of the decade" poster 🎬, with **exactly three films per decade** (fewer only if a decade has fewer films).

Rank the films in each decade by **rating, highest first**. Ties need a clear rule, because the poster only has three spots:

1. if two films have the same rating, the **shorter** film (fewer `minutes`) wins,
2. if they're the same length too, sort them by **title**.

Show:

- `decade`: the decade as text, like `'2010s'` (2019 is in the 2010s, 2020 in the 2020s),
- `place`: 1, 2 or 3 within the decade,
- `title` and `rating`.

Sort by decade, then place.

```sql
-- decade | place | title                  | rating
-- 2010s  |     1 | Midnight in the Forest |    8.1
-- 2010s  |     2 | Mountain of Echoes     |    7.9
-- …
```

Number the films within each decade, then keep the first three of every decade.

<Hint>

This is "top 3 in each group". `LIMIT` works on the whole result, so look for a window function that numbers the rows inside each decade. And how do you turn a year into its decade?

</Hint>

<Hint>

1. Integer division finds the decade: `year / 10 * 10` turns 2019 into 2010, and `|| 's'` makes it text like `'2010s'`.
2. In a CTE, number the films with `row_number() OVER (PARTITION BY … ORDER BY rating DESC, minutes, title)`. The extra sort columns are the tie rules, so every decade gets 1, 2, 3 and so on, with no shared places.
3. In the outer query, keep the rows with `place <= 3` and sort by decade, then place.

</Hint>

<Hint>

```sql
WITH ranked AS (
  SELECT (year / 10 * 10) || 's' AS decade, title, rating,
    row_number() OVER (
      PARTITION BY ...
      ORDER BY ...  -- rating, then the two tie rules
    ) AS place
  FROM movies
)
SELECT decade, place, title, rating
FROM ranked
WHERE ...
ORDER BY decade, place;
```

</Hint>

<Solution>

```sql
WITH ranked AS (
  SELECT (year / 10 * 10) || 's' AS decade, title, rating,
    row_number() OVER (
      PARTITION BY year / 10
      ORDER BY rating DESC, minutes, title
    ) AS place
  FROM movies
)
SELECT decade, place, title, rating
FROM ranked
WHERE place <= 3
ORDER BY decade, place;
```

Why `row_number()` and not `rank()`? `rank()` gives tied films the same number, so if you forgot a tie rule, two films could share third place and the poster would get four. `row_number()` always hands out 1, 2, 3, and the extra sort columns decide who gets which.

</Solution>
