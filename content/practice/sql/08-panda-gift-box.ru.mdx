Магазин панды собирает подарочный набор 🎁. Товар может попасть в набор, когда выполняются **все** эти условия:

- он **в тему**: в его названии есть **«bamboo»** или **«panda»** (в **любом** регистре), **или** он из категории **`tea`**;
- он стоит **от 3 до 20**, включая оба конца;
- он **в наличии** (`stock` больше 0);
- он **не** из категории **`kitchen`** (кастрюли и палочки бьются при пересылке).

Выведите **`name`**, **`category`** и **`price`** подходящих товаров, **от самых дорогих**, затем по названию.

```sql
-- name          | category | price
-- Plush Panda   | toys     | 18.00
-- Matcha Powder | tea      | 14.00
-- …
```

Осторожно: `AND` выполняется раньше, чем `OR`, поэтому условие «в тему» нужно взять в скобки.

SELECT name, category, price

    { name: "Работает, когда меняются данные", check: "(r => r.map(x => x.name).join() === 'Plush Panda,Matcha Powder,The Bamboo Code,Jasmine Tea,Earl Grey,Panda Cookies,bamboo straws')(await rerun(\"INSERT INTO products (name, category, price, stock) VALUES ('bamboo straws', 'home', 3.00, 50), ('Panda Apron', 'kitchen', 9.00, 10); UPDATE products SET stock = 10 WHERE name = 'Earl Grey'\"))" },

>

Объедините четыре правила так, чтобы остались только товары, которые действительно подходят для набора.

<Hint>

`ILIKE '%bamboo%'` находит совпадения в любом регистре. Возьмите правила «в тему» в скобки: `(… OR … OR …) AND …`. `BETWEEN 3 AND 20` включает оба конца, а `<>` или `NOT IN (…)` исключает категорию.

</Hint>

<Solution>

```sql
SELECT name, category, price
FROM products
WHERE (name ILIKE '%bamboo%' OR name ILIKE '%panda%' OR category = 'tea')
  AND price BETWEEN 3 AND 20
  AND stock > 0
  AND category NOT IN ('kitchen')
ORDER BY price DESC, name;
```

</Solution>

Без скобок `category = 'tea' AND price BETWEEN …` сгруппировались бы вместе, и любой бамбуковый товар проскользнул бы в набор, какой бы ни была его цена.

</Exercise>
