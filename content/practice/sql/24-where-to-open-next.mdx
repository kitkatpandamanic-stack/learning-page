The company is thinking about opening a new office 🏢, close to its customers. Find the cities that have **customers** but **no office** yet (an office is a department's `location`).

Show:

- `city`: the city,
- `customers`: how many customers live there.

Customers without a city (`NULL`) don't count as a city. Put the city with the **most customers first**; if two cities have the same number, sort them by name.

```sql
-- city       | customers
-- Moscow     |         2
-- Manchester |         1
-- …
```

>

Find the cities with `EXCEPT`, then count the customers in each of them.

<Hint>

"Cities in one list but not in the other" is a set operation. Which one keeps the rows of the first query that don't appear in the second? Watch out for customers whose city is `NULL`.

</Hint>

<Hint>

`SELECT city FROM customers EXCEPT SELECT location FROM departments` gives the cities without an office, plus a `NULL`. Put it in a CTE, join it back to `customers` on the city, and `GROUP BY` the city with `count(*)`. A join on `NULL` never matches, so the `NULL` row drops out by itself. Sort by the count, highest first, then by city.

</Hint>

<Hint>

```sql
WITH no_office AS (
  SELECT city FROM customers
  EXCEPT
  ...  -- the cities that have an office
)
SELECT n.city, count(*) AS customers
FROM no_office AS n
JOIN customers AS c ON ...
GROUP BY n.city
ORDER BY customers DESC, n.city;
```

</Hint>

<Solution>

```sql
WITH no_office AS (
  SELECT city FROM customers
  EXCEPT
  SELECT location FROM departments
)
SELECT n.city, count(*) AS customers
FROM no_office AS n
JOIN customers AS c ON c.city = n.city
GROUP BY n.city
ORDER BY customers DESC, n.city;
```

</Solution>
