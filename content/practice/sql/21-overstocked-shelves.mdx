The panda shop's storeroom is getting crowded 📦. Using the `products` table, show the **`name`** and **`stock`** of every product whose stock is **above the average stock** of all products.

Work the average out **inside the query**. Don't type in a number you calculated by hand: the stock changes every day.

Put the **biggest stock first**. If two products have the same stock, sort them by name.

```sql
-- name              | stock
-- Bamboo Chopsticks |   200
-- Bamboo Crisps     |   120
-- …
```

<Exercise
  language="sql"
  title="Overstocked shelves"
  starter={`-- name and stock of products with more stock than the average,
-- biggest stock first
SELECT name, stock
FROM products
ORDER BY stock DESC;
`}
  tests={[
    { name: "Columns are name, stock", check: "columns.join() === 'name,stock'" },
    { name: "Only the 5 products above the average stock of 39", check: "rows.map(r => r.name).sort().join() === 'Bamboo Chopsticks,Bamboo Crisps,Jasmine Tea,Panda Cookies,Rice Crackers'" },
    { name: "Biggest stock first", check: "rows.map(r => r.stock).join() === '200,120,85,60,40'" },
    { name: "Earl Grey (out of stock) isn't there", check: "!rows.some(r => r.name === 'Earl Grey')" },
    { name: "Works when the data changes", check: "(await rerun(\"UPDATE products SET stock = 500 WHERE name = 'Kite'\")).map(r => r.name).join() === 'Kite,Bamboo Chopsticks,Bamboo Crisps,Panda Cookies'" },
  ]}
>

Add a `WHERE` that compares each product's stock with the average stock of all products.

<Hint>

You need the average stock, but you can't type it in by hand. Is there a way to work out a single number right inside the `WHERE`?

</Hint>

<Hint>

A **scalar subquery** returns one value, so you can use it like a number: `WHERE stock > (SELECT avg(…) FROM products)`. It runs as part of the query, so the average follows the data when the stock changes. Then sort with `ORDER BY stock DESC, name`, so equal stocks go by name.

</Hint>

<Hint>

```sql
SELECT name, stock
FROM products
WHERE stock > (...)  -- the average stock of all products
ORDER BY stock DESC, name;
```

</Hint>

<Solution>

```sql
SELECT name, stock
FROM products
WHERE stock > (SELECT avg(stock) FROM products)
ORDER BY stock DESC, name;
```

</Solution>

</Exercise>
