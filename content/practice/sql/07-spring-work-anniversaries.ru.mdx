Каждую весну компания печёт торт на **годовщину работы** каждого сотрудника 🎂. Офис-менеджеру нужен список в том порядке, в каком подходят сроки тортов.

По таблице `employees` выведите всех, кого **приняли на работу в марте, апреле или мае** (любого года):

- **`name`**;
- **`hire_month`**: **название месяца**, например `March` (без пробелов в конце);
- **`hire_year`**: **год**, когда сотрудника приняли на работу, в виде числа.

PostgreSQL по умолчанию выводит названия месяцев по-английски, поэтому в результате будут `March`, `April` и `May`.

Отсортируйте строки в **календарном порядке** годовщин: по месяцу, затем по дню месяца, **без учёта года**. Если у двух человек годовщина в один день, отсортируйте их по имени.

```sql
-- name         | hire_month | hire_year
-- Grace Hopper | March      | 2015
-- Dieter Rams  | March      | 2023
-- …
```

Выберите сотрудников, принятых весной, выведите название месяца и отсортируйте как в календаре.

<Hint>

Понадобятся части даты: номер месяца для фильтра, название месяца для вывода и год. Какая функция достаёт из даты одну часть? И почему сортировка по всей дате `hired_on` даст неверный порядок?

</Hint>

<Hint>

Отфильтруйте через `extract(month FROM hired_on) IN (3, 4, 5)`. Месяц выведите через `to_char(hired_on, 'FMMonth')`: `FM` не даёт дополнять название пробелами. Год получите через `extract(year FROM hired_on)`. Сортируйте по месяцу, затем по дню и по `name`, чтобы годовщины шли как в календаре, независимо от года.

</Hint>

<Hint>

```sql
SELECT
  name,
  to_char(hired_on, 'FMMonth') AS hire_month,
  extract(year FROM hired_on) AS hire_year
FROM employees
WHERE ...            -- март, апрель или май
ORDER BY ..., name;  -- месяц, затем день
```

</Hint>

<Solution>

```sql
SELECT
  name,
  to_char(hired_on, 'FMMonth') AS hire_month,
  extract(year FROM hired_on) AS hire_year
FROM employees
WHERE extract(month FROM hired_on) IN (3, 4, 5)
ORDER BY extract(month FROM hired_on), extract(day FROM hired_on), name;
```

</Solution>

`ORDER BY to_char(hired_on, 'MM-DD'), name` сортирует точно так же.

</Exercise>
