The film club's website shows its chart of films **four at a time**, best rated first ⭐. Page one is done; you're building **page two**.

Using the `movies` table, show the **`title`** and **`rating`** of the films in places **5 to 8** of the chart. The chart is sorted by **rating, highest first**; films with the same rating are sorted **by title**, so the pages never shuffle between visits.

```sql
-- title               | rating
-- Snow Leopard Summer | 7.6
-- …
```

<Exercise
  language="sql"
  title="Film chart, page two"
  starter={`-- title and rating of chart places 5 to 8
-- (highest rating first, then by title)
SELECT title, rating
FROM movies
ORDER BY rating DESC
LIMIT 4;
`}
  tests={[
    { name: "Columns are title, rating", check: "columns.join() === 'title,rating'" },
    { name: "Exactly four films on the page", check: "rows.length === 4" },
    { name: "Places 5 to 8 of the chart", check: "rows.map(r => r.title).join() === 'Snow Leopard Summer,The Last Dumpling,Bug in the Machine,Panda Express to Mars'" },
    { name: "Highest rating first", check: "rows.map(r => r.rating).join() === '7.6,7.2,7.1,6.9'" },
    { name: "Works when a new film joins the chart", check: "(r => r.map(x => x.title).join() === 'A Bamboo Story,Snow Leopard Summer,The Last Dumpling,Bug in the Machine')(await rerun(\"INSERT INTO movies (title, year, director, genre, rating, minutes) VALUES ('A Bamboo Story', 2025, 'Mei Lin', 'drama', 7.6, 99)\"))" },
  ]}
>

Skip the first page and show the next four films, in a fixed order.

<Hint>

`OFFSET` skips rows and `LIMIT` keeps a few. To skip one page of four, use `LIMIT 4 OFFSET 4`. Add `title` after `rating DESC` in the `ORDER BY` so ties always come out the same way.

</Hint>

<Solution>

```sql
SELECT title, rating
FROM movies
ORDER BY rating DESC, title
LIMIT 4 OFFSET 4;
```

</Solution>

For page `n`, the offset is `(n - 1) * 4`.

</Exercise>
