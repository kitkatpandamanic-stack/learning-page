The panda shop wants a "bargain shelf" 🐼. Using the `products` table, show the **`name`** and **`price`** of every product that costs **less than 10** and is **in stock** (`stock` above 0).

Sort them by price, cheapest first. If two products cost the same, sort them by name.

```sql
-- name              | price
-- Rice Crackers     | 2.50
-- Bamboo Crisps     | 2.99
-- …
```

<Exercise
  language="sql"
  title="Bargains in stock"
  starter={`-- name and price of products under 10 that are in stock,
-- cheapest first
SELECT name, price, stock
FROM products;
`}
  tests={[
    { name: "Columns are name, price", check: "columns.join() === 'name,price'" },
    { name: "Only products under 10 that are in stock", check: "rows.map(r => r.name).sort().join() === 'Bamboo Chopsticks,Bamboo Crisps,Jasmine Tea,Panda Cookies,Rice Crackers'" },
    { name: "Cheapest first", check: "rows.map(r => r.price).join() === '2.5,2.99,3.75,4.2,6.5'" },
    { name: "Earl Grey is out of stock, so it's not there", check: "!rows.some(r => r.name === 'Earl Grey')" },
    { name: "Works when stock changes", check: "(r => r.map(x => x.name).join() === 'Bamboo Crisps,Panda Cookies,Bamboo Chopsticks,Earl Grey,Jasmine Tea')(await rerun(\"UPDATE products SET stock = 5 WHERE name = 'Earl Grey'; UPDATE products SET stock = 0 WHERE name = 'Rice Crackers'\"))" },
  ]}
>

Finish the query so it shows only the bargains that are in stock, cheapest first.

<Hint>

You need two conditions at once: the product is cheap **and** it's in stock. Which keyword joins two `WHERE` conditions so that both must be true?

</Hint>

<Hint>

Show only `name` and `price` after `SELECT`. Filter with `price < 10` and `stock > 0`, joined by `AND`, so Earl Grey (stock 0) drops out. Then sort with `ORDER BY price, name`, cheapest first.

</Hint>

<Hint>

```sql
SELECT name, price
FROM products
WHERE ... AND ...  -- cheap and in stock
ORDER BY price, name;
```

</Hint>

<Solution>

```sql
SELECT name, price
FROM products
WHERE price < 10 AND stock > 0
ORDER BY price, name;
```

</Solution>

</Exercise>
