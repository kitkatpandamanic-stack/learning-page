The panda film club is planning a season of themed nights 🎬 and wants to know which genres have enough films. Using the `movies` table, show one row per **genre** with:

- `genre`,
- `films`: how many films the catalogue has in that genre.

Sort by `films`, **most first**. When two genres have the same number of films, sort them by `genre`, A to Z.

```sql
-- genre    | films
-- comedy   |     2
-- drama    |     2
-- …
```

<Exercise
  language="sql"
  title="Films per genre"
  starter={`-- genre and films (how many in each genre),
-- most films first, ties by genre
SELECT title, genre
FROM movies;
`}
  tests={[
    { name: "Columns are genre, films", check: "columns.join() === 'genre,films'" },
    { name: "One row for each of the 8 genres", check: "rows.length === 8" },
    { name: "Most films first, ties by genre", check: "rows.map(r => r.genre).join() === 'comedy,drama,sci-fi,thriller,action,adventure,family,romance'" },
    { name: "Counts are right", check: "rows.map(r => r.films).join() === '2,2,2,2,1,1,1,1'" },
    { name: "Works when the data changes", check: "(r => r.map(x => x.genre + ':' + x.films).join() === 'drama:3,sci-fi:2,thriller:2,action:1,adventure:1,comedy:1,family:1,romance:1')(await rerun(\"INSERT INTO movies (title, year, director, genre, rating, minutes) VALUES ('Rain on Bamboo', 2025, 'Mei Lin', 'drama', 7.0, 101); UPDATE movies SET genre = 'family' WHERE title = 'The Last Dumpling'; DELETE FROM movies WHERE title = 'The Great Bamboo Race'\"))" },
  ]}
>

Group the films by genre and count them, biggest genre first.

<Hint>

Use `GROUP BY genre` and `count(*) AS films`. You can sort by the alias: `ORDER BY films DESC, genre`.

</Hint>

<Solution>

```sql
SELECT genre, count(*) AS films
FROM movies
GROUP BY genre
ORDER BY films DESC, genre;
```

</Solution>

</Exercise>
