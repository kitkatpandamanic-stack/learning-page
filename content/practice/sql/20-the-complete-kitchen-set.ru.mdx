Магазин панды дарит золотой фартук 🐼 каждому покупателю, у которого есть **полный кухонный набор**: он купил **все товары** категории `'kitchen'`.

Выведите таких покупателей со столбцами `name` и `email`, отсортировав по `name`.

Задачу усложняют несколько правил:

- Учитываются только **неотменённые** заказы.
- Покупка **одного и того же товара дважды** не заменяет недостающий.
- Магазин будет добавлять новые кухонные товары, поэтому **не зашивайте в код** их количество: когда появится новый кухонный товар, ни у кого не будет полного набора, пока его тоже не купят.

```sql
-- name       | email
-- Ravi Patel | ravi@pandadev.test
```

Оставьте покупателей, у которых число разных кухонных товаров совпадает с размером всего кухонного ассортимента.

<Hint>

Сведите задачу к подсчёту: у покупателя полный набор, когда число **разных** кухонных товаров, которые он купил, равно числу кухонных товаров в магазине. Откуда взять второе число, не вписывая его вручную?

</Hint>

<Hint>

Соедините `customers` с `orders`, `order_items` и `products`, оставив только неотменённые заказы и товары из категории `'kitchen'`. Сделайте `GROUP BY c.id, c.name, c.email`. В `HAVING` сравните `count(DISTINCT p.id)` с подзапросом `(SELECT count(*) FROM products WHERE category = 'kitchen')`. `DISTINCT` не даёт повторным покупкам считаться дважды, а подзапрос учитывает новые кухонные товары.

</Hint>

<Solution>

```sql
SELECT c.name, c.email
FROM customers AS c
JOIN orders AS o
  ON o.customer_id = c.id AND o.status <> 'cancelled'
JOIN order_items AS oi ON oi.order_id = o.id
JOIN products AS p
  ON p.id = oi.product_id AND p.category = 'kitchen'
GROUP BY c.id, c.name, c.email
HAVING count(DISTINCT p.id) =
  (SELECT count(*) FROM products WHERE category = 'kitchen')
ORDER BY c.name;
```

Работает и «двойное отрицание»: оставьте покупателя, если `NOT EXISTS` такого кухонного товара, для которого `NOT EXISTS` позиции в его неотменённом заказе.

</Solution>
