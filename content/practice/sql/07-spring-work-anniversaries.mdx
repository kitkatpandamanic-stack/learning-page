Every spring the company bakes a cake for each person's **work anniversary** 🎂. The office manager needs the list in the order the cakes are due.

Using `employees`, show everyone **hired in March, April or May** (of any year):

- **`name`**;
- **`hire_month`**: the **month's name**, like `March` (no padding spaces);
- **`hire_year`**: the **year** they were hired, as a number.

Sort the rows in **calendar order** of the anniversary: by month, then by day of the month, **ignoring the year**. If two people share an anniversary day, sort them by name.

```sql
-- name         | hire_month | hire_year
-- Grace Hopper | March      | 2015
-- Dieter Rams  | March      | 2023
-- …
```

<Exercise
  language="sql"
  title="Spring work anniversaries"
  starter={`-- name, hire_month (e.g. March) and hire_year of staff hired in
-- March, April or May, in calendar order of the anniversary
SELECT name, hired_on
FROM employees
ORDER BY hired_on;
`}
  tests={[
    { name: "Columns are name, hire_month, hire_year", check: "columns.join() === 'name,hire_month,hire_year'" },
    { name: "Only spring hires, in calendar order", check: "rows.map(r => r.name).join() === 'Grace Hopper,Dieter Rams,Paul Allen,Margaret Hamilton,Don Norman,Max Planck'" },
    { name: "Month names without padding", check: "rows.map(r => r.hire_month).join() === 'March,March,April,April,May,May'" },
    { name: "Years are numbers", check: "rows.map(r => r.hire_year).join() === '2015,2023,2024,2019,2017,2021' && typeof rows[0].hire_year === 'number'" },
    { name: "Works when the staff change", check: "(r => r.map(x => x.name + ' ' + x.hire_year).join() === 'Anita Borg 2025,Grace Hopper 2015,Dieter Rams 2023,Paul Allen 2024,Margaret Hamilton 2019,Don Norman 2017')(await rerun(\"INSERT INTO employees (name, department_id, manager_id, job_title, salary, hired_on) VALUES ('Anita Borg', 1, 3, 'Engineer', 74000, '2025-03-01'); UPDATE employees SET hired_on = '2020-06-01' WHERE name = 'Max Planck'\"))" },
  ]}
>

Pick out the spring hires and name their month, sorted like a calendar.

<Hint>

`extract(month FROM hired_on)` gives the month number (and `extract(year …)` and `extract(day …)` work the same way). `to_char(hired_on, 'FMMonth')` gives the month's name; the `FM` stops it padding the name with spaces. Sort by month and day, not by the whole date.

</Hint>

<Solution>

```sql
SELECT
  name,
  to_char(hired_on, 'FMMonth') AS hire_month,
  extract(year FROM hired_on) AS hire_year
FROM employees
WHERE extract(month FROM hired_on) IN (3, 4, 5)
ORDER BY extract(month FROM hired_on), extract(day FROM hired_on), name;
```

</Solution>

`ORDER BY to_char(hired_on, 'MM-DD'), name` sorts the same way.

</Exercise>
