HR is reviewing pay at the company and wants every employee sorted into a **band** 💼:

- **`top`**: a salary of **100000 or more**;
- **`middle`**: **70000 up to 99999**;
- **`entry`**: **below 70000**.

Show **`name`**, **`salary`** and **`band`** for every employee. List the **`top`** band first, then **`middle`**, then **`entry`** (not alphabetical!). Inside each band, sort **by name**.

```sql
-- name           | salary | band
-- Alan Turing    | 130000 | top
-- Barbara Liskov | 105000 | top
-- …
-- Ada Lovelace   | 98000  | middle
-- …
```

>

Label each salary with a band, then sort the bands in the order HR wants.

<Hint>

Each salary needs a label based on a range. Which SQL expression picks a value by checking conditions in order? Also ask yourself: would sorting by salary keep the names in alphabetical order inside each band?

</Hint>

<Hint>

Build `band` with `CASE`: `salary >= 100000` is `'top'`, `salary >= 70000` is `'middle'`, and everything else is `'entry'`. `CASE` takes the first branch that matches, so check the highest band first; exactly 70000 is middle. To sort, put a second `CASE` in `ORDER BY` that turns the bands into 1, 2 and 3, then sort by `name`.

</Hint>

<Hint>

```sql
SELECT
  name,
  salary,
  CASE
    WHEN salary >= 100000 THEN 'top'
    WHEN ... THEN 'middle'
    ELSE 'entry'
  END AS band
FROM employees
ORDER BY
  CASE ... END,  -- top = 1, middle = 2, entry = 3
  name;
```

</Hint>

<Solution>

```sql
SELECT
  name,
  salary,
  CASE
    WHEN salary >= 100000 THEN 'top'
    WHEN salary >= 70000 THEN 'middle'
    ELSE 'entry'
  END AS band
FROM employees
ORDER BY
  CASE
    WHEN salary >= 100000 THEN 1
    WHEN salary >= 70000 THEN 2
    ELSE 3
  END,
  name;
```

</Solution>

`ORDER BY salary DESC, name` would get the bands in the right order, but not the names inside each band: that's why the sort needs its own `CASE`.

</Exercise>
