It's pouring outside, and the film club wants a proper long watch 🍿. Using the `movies` table, show the **`title`**, **`director`** and **`minutes`** of every film that runs **longer than 110 minutes**.

Show **only those three columns**, in that order. Put the **longest film first**; if two films are the same length, sort them by title.

```sql
-- title                 | director   | minutes
-- The Quiet Algorithm   | Ravi Patel | 131
-- Panda Express to Mars | Sam Ortiz  | 121
-- …
```

<Exercise
  language="sql"
  title="Long films for a rainy Sunday"
  starter={`-- title, director and minutes of films longer than 110 minutes,
-- longest first
SELECT *
FROM movies;
`}
  tests={[
    { name: "Columns are title, director, minutes", check: "columns.join() === 'title,director,minutes'" },
    { name: "Only films longer than 110 minutes", check: "rows.map(r => r.title).sort().join() === 'Midnight in the Forest,Mountain of Echoes,Panda Express to Mars,The Quiet Algorithm'" },
    { name: "Longest first", check: "rows.map(r => r.minutes).join() === '131,121,118,112'" },
    { name: "A film of exactly 110 minutes is not long enough", check: "(r => !r.some(x => x.title === 'Code Red'))(await rerun(\"UPDATE movies SET minutes = 110 WHERE title = 'Code Red'\"))" },
    { name: "Works when the films change", check: "(r => r.map(x => x.title).join() === 'The Quiet Algorithm,Bug in the Machine,Panda Express to Mars,Mountain of Echoes,Midnight in the Forest')(await rerun(\"UPDATE movies SET minutes = 125 WHERE title = 'Bug in the Machine'\"))" },
  ]}
>

List the three columns, keep only the long films, and put the longest first.

<Hint>

Name the columns after `SELECT` instead of using `*`. "Longer than 110" is `minutes > 110`, and `ORDER BY minutes DESC, title` gives the longest first with a tie-breaker.

</Hint>

<Solution>

```sql
SELECT title, director, minutes
FROM movies
WHERE minutes > 110
ORDER BY minutes DESC, title;
```

</Solution>

</Exercise>
