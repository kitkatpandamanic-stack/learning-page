The engineering team is off to a conference, and the company needs badges and Wi-Fi logins for everyone 🎫. Every name in `employees` is a first name and a last name separated by one space.

For the employees in **department 1** (Engineering), show:

- **`name`**: the full name, as it is;
- **`badge`**: the **last name in capitals**, a comma and a space, then the first name, e.g. `LOVELACE, Ada`;
- **`login`**: the **first letter** of the first name followed by the **last name**, all in **lower case**, e.g. `alovelace`.

Sort the rows **by `login`**.

```sql
-- name         | badge         | login
-- Ada Lovelace | LOVELACE, Ada | alovelace
-- Alan Turing  | TURING, Alan  | aturing
-- …
```

Cut each name into its first and last name and glue the pieces back together.

<Hint>

Each name is a first name and a last name with one space between them. Is there a function that cuts text at a separator and hands you one of the pieces?

</Hint>

<Hint>

`split_part(name, ' ', 1)` is the first name and `split_part(name, ' ', 2)` is the last name. For `badge`, put the last name through `upper(…)` and join it to `', '` and the first name with `||`. For `login`, take `left(name, 1)`, add the last name with `||`, and wrap the whole thing in `lower(…)`. Sort with `ORDER BY login`.

</Hint>

<Hint>

```sql
SELECT
  name,
  upper(split_part(name, ' ', 2)) || ', ' || ... AS badge,
  lower(...) AS login  -- first letter + last name
FROM employees
WHERE department_id = 1
ORDER BY login;
```

</Hint>

<Solution>

```sql
SELECT
  name,
  upper(split_part(name, ' ', 2)) || ', ' || split_part(name, ' ', 1) AS badge,
  lower(left(name, 1) || split_part(name, ' ', 2)) AS login
FROM employees
WHERE department_id = 1
ORDER BY login;
```

</Solution>

`concat(…)` works instead of `||` too.
