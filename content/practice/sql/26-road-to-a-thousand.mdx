The panda shop opened in January and promised itself a party 🎉 when its revenue reached **1,000**. Which orders got it there?

Take the orders that **weren't cancelled**, in the order they were placed, and keep a **running total** of their value. Show every order **up to and including** the one that takes the running total to **1,000 or more**, and nothing after it.

Show:

- `order_id`: the order's id,
- `ordered_on`: the date of the order (a `date`, without the time),
- `total`: the order's value (quantity × unit price, summed over its items),
- `running_total`: the revenue so far, including this order.

Sort by the time the order was placed.

```sql
-- order_id | ordered_on | total  | running_total
--        1 | 2025-01-07 | 102.00 |        102.00
--        2 | 2025-01-11 | 200.17 |        302.17
-- …
```

<Exercise

  title="The road to 1,000"
  starter={`-- Orders that weren't cancelled, with a running total,

SELECT o.id AS order_id, o.ordered_at::date AS ordered_on,
  sum(oi.quantity * oi.unit_price) AS total
FROM orders AS o
JOIN order_items AS oi ON oi.order_id = o.id
GROUP BY o.id
ORDER BY o.ordered_at;
`}

>

Add the running total and keep only the orders up to the one that reaches 1,000.

<Hint>

Put the order totals in a CTE (without cancelled orders). In a second step, add `sum(total) OVER (ORDER BY ordered_at, order_id)` as the running total. A window can't go in a `WHERE` of the same query, so filter in an outer query: an order belongs on the list if the total **before** it, `running_total - total`, was still under 1,000.

</Hint>

<Solution>

```sql
WITH order_totals AS (
  SELECT o.id AS order_id, o.ordered_at,
    sum(oi.quantity * oi.unit_price) AS total
  FROM orders AS o
  JOIN order_items AS oi ON oi.order_id = o.id
  WHERE o.status <> 'cancelled'
  GROUP BY o.id
),
running AS (
  SELECT order_id, ordered_at, total,
    sum(total) OVER (ORDER BY ordered_at, order_id) AS running_total
  FROM order_totals
)
SELECT order_id, ordered_at::date AS ordered_on, total, running_total
FROM running
WHERE running_total - total < 1000
ORDER BY ordered_at;
```

</Solution>
