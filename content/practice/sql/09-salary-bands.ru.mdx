Отдел кадров пересматривает зарплаты в компании и хочет распределить всех сотрудников по **уровням** 💼:

- **`top`**: зарплата **100000 или больше**;
- **`middle`**: **от 70000 до 99999**;
- **`entry`**: **меньше 70000**.

Выведите **`name`**, **`salary`** и **`band`** для каждого сотрудника. Сначала уровень **`top`**, затем **`middle`**, затем **`entry`** (не по алфавиту!). Внутри каждого уровня отсортируйте **по имени**.

```sql
-- name           | salary | band
-- Alan Turing    | 130000 | top
-- Barbara Liskov | 105000 | top
-- …
-- Ada Lovelace   | 98000  | middle
-- …
```

Присвойте каждой зарплате уровень, а затем отсортируйте уровни в том порядке, который нужен отделу кадров.

<Hint>

`CASE WHEN salary >= 100000 THEN 'top' WHEN … THEN … ELSE … END` выбирает первую подходящую ветку. В `ORDER BY` можно поставить второй `CASE`, который превращает каждый уровень в число (1, 2, 3), — так получится собственный порядок.

</Hint>

<Solution>

```sql
SELECT
  name,
  salary,
  CASE
    WHEN salary >= 100000 THEN 'top'
    WHEN salary >= 70000 THEN 'middle'
    ELSE 'entry'
  END AS band
FROM employees
ORDER BY
  CASE
    WHEN salary >= 100000 THEN 1
    WHEN salary >= 70000 THEN 2
    ELSE 3
  END,
  name;
```

</Solution>

`ORDER BY salary DESC, name` расставил бы уровни в правильном порядке, но не имена внутри каждого уровня: поэтому для сортировки нужен свой `CASE`.

</Exercise>
