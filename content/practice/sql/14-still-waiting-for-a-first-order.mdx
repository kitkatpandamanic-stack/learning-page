The panda shop wants to send a **welcome discount** 🎁 to customers who signed up but have never actually bought anything. A customer counts as "never bought" when they have **no orders at all**, or **only cancelled ones**.

Show those customers with the columns `name`, `email` and `joined_on`. Sort by `joined_on`, **oldest first**, then by `name`.

```sql
-- name       | email               | joined_on
-- Grace Kim  | grace@pandadev.test | 2024-11-23
-- …
```

Today every customer with a cancelled order also has a real one, but that can change: your query must still work when someone's only order is cancelled.

>

Keep only the customers without a non-cancelled order, oldest sign-up first.

<Hint>

A `LEFT JOIN` keeps every customer and fills the order columns with NULL when nothing matches. Put the status rule inside the join, `ON o.customer_id = c.id AND o.status <> 'cancelled'`, so cancelled orders never match. Then `WHERE o.id IS NULL` keeps the customers left without a match.

</Hint>

<Solution>

```sql
SELECT c.name, c.email, c.joined_on
FROM customers AS c
LEFT JOIN orders AS o
  ON o.customer_id = c.id AND o.status <> 'cancelled'
WHERE o.id IS NULL
ORDER BY c.joined_on, c.name;
```

`WHERE NOT EXISTS (SELECT 1 FROM orders AS o WHERE o.customer_id = c.id AND o.status <> 'cancelled')` works just as well.

</Solution>
