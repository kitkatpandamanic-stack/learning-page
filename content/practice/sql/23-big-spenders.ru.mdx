Магазин панды хочет поблагодарить **крупных покупателей** открыткой, подписанной от руки 💌. Крупный покупатель — это тот, кто потратил **больше среднего покупателя**.

Учитывайте только **неотменённые** заказы, а среднее считайте по покупателям, которые **хоть что-то потратили** (покупатели без заказов или только с отменёнными заказами в среднее не входят).

Выведите:

- `name`: имя покупателя,
- `orders`: сколько неотменённых заказов он сделал,
- `spent`: общую сумму этих заказов (количество × цена за единицу, сложенные вместе).

Поставьте **самого крупного покупателя первым**; если двое потратили одинаково, отсортируйте их по имени.

```sql
-- name       | orders | spent
-- Ravi Patel |      3 | 282.23
-- Sam Ortiz  |      2 | 273.83
-- …
```

Допишите запрос в три шага: суммы заказов, суммы по покупателям и покупатели выше среднего.

<Hint>

Идите по шагам с помощью CTE: сумма каждого заказа, затем сумма каждого покупателя. Сравнивать нужно со средним по **покупателям**, а не по заказам. Где лучше всего отбросить отменённые заказы?

</Hint>

<Hint>

1. В `order_totals` добавьте `WHERE o.status <> 'cancelled'`.
2. Добавьте второе CTE, `customer_totals`, которое группирует `order_totals` по `customer_id` с `count(*) AS orders` и `sum(total) AS spent`. Покупателей, которые ничего не потратили, в нём нет, поэтому в среднее они не попадают.
3. В итоговом `SELECT` присоедините `customers`, чтобы получить имя, и оставьте строки, где `spent` больше, чем `(SELECT avg(spent) FROM customer_totals)`. Отсортируйте по `spent DESC`, затем по имени.

</Hint>

<Solution>

```sql
WITH order_totals AS (
  SELECT o.id, o.customer_id,
    sum(oi.quantity * oi.unit_price) AS total
  FROM orders AS o
  JOIN order_items AS oi ON oi.order_id = o.id
  WHERE o.status <> 'cancelled'
  GROUP BY o.id
),
customer_totals AS (
  SELECT customer_id, count(*) AS orders, sum(total) AS spent
  FROM order_totals
  GROUP BY customer_id
)
SELECT c.name, ct.orders, ct.spent
FROM customer_totals AS ct
JOIN customers AS c ON c.id = ct.customer_id
WHERE ct.spent > (SELECT avg(spent) FROM customer_totals)
ORDER BY ct.spent DESC, c.name;
```

</Solution>
