Магазин панды запускает карту лояльности 🐼, и первые карты получат **постоянные покупатели**: те, у кого **не меньше 3 неотменённых заказов**. Выведите:

- `name`: имя покупателя,
- `orders`: сколько у него неотменённых заказов,
- `first_order`: **дата** (без времени) первого такого заказа,
- `last_order`: дата последнего такого заказа.

Отсортируйте по `orders`, **от большего к меньшему**, затем по `name`.

```sql
-- name         | orders | first_order | last_order
-- Lucas Silva  |      3 | 2025-01-28  | 2025-06-17
-- …
```

Посчитайте неотменённые заказы каждого покупателя и оставьте только тех, у кого их 3 или больше.

<Hint>

Отфильтруйте отдельные строки до группировки с помощью `WHERE o.status <> 'cancelled'`, затем `GROUP BY c.id, c.name`. Группы отфильтруйте через `HAVING count(*) >= 3`. `min(o.ordered_at)::date` даёт дату первого заказа.

</Hint>

<Solution>

```sql
SELECT c.name,
  count(*) AS orders,
  min(o.ordered_at)::date AS first_order,
  max(o.ordered_at)::date AS last_order
FROM customers AS c
JOIN orders AS o ON o.customer_id = c.id
WHERE o.status <> 'cancelled'
GROUP BY c.id, c.name
HAVING count(*) >= 3
ORDER BY orders DESC, c.name;
```

</Solution>
