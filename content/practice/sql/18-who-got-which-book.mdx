The panda shop's book corner wants to send a "how did you like it?" note 📚 to everyone who has **received** a book. List every book sold in an order whose status is **`'delivered'`**, with:

- `order_id`,
- `customer`: the customer's name,
- `book`: the product's name,
- `quantity`: how many copies were in that order.

A book is a product whose `category` is **`'books'`**. Sort by `order_id`, then by `book`.

```sql
-- order_id | customer     | book                   | quantity
--        1 | Sofia Rossi  | Algorithms in Pictures |        3
--        5 | Sam Ortiz    | Clean Python           |        2
-- …
```

Walk from `customers` to `orders` to `order_items` to `products`, keeping only books in delivered orders.

<Hint>

The four columns come from four different tables. Sketch the path between them: which column links each table to the next one?

</Hint>

<Hint>

Start from `customers` and chain three joins: `orders` on `o.customer_id = c.id`, `order_items` on `oi.order_id = o.id`, and `products` on `p.id = oi.product_id`. Filter on two tables at once: `p.category = 'books' AND o.status = 'delivered'`. Rename the columns (`o.id AS order_id`, `c.name AS customer`, `p.name AS book`) and sort by `o.id, book`.

</Hint>

<Hint>

SELECT o.id AS order_id,
  c.name AS customer,

JOIN orders AS o ON o.customer_id = c.id

<Solution>

```sql
SELECT o.id AS order_id,
  c.name AS customer,
  p.name AS book,
  oi.quantity
FROM customers AS c
JOIN orders AS o ON o.customer_id = c.id
JOIN order_items AS oi ON oi.order_id = o.id
JOIN products AS p ON p.id = oi.product_id
WHERE p.category = 'books'
  AND o.status = 'delivered'
ORDER BY o.id, book;
```

</Solution>
