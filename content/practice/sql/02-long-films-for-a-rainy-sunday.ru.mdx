На улице льёт как из ведра, и киноклуб хочет посмотреть что-нибудь по-настоящему длинное 🍿. По таблице `movies` выведите **`title`**, **`director`** и **`minutes`** всех фильмов, которые идут **дольше 110 минут**.

Выведите **только эти три столбца**, в этом порядке. **Самый длинный фильм** поставьте **первым**; если у двух фильмов одинаковая длительность, отсортируйте их по названию.

```sql
-- title                 | director   | minutes
-- The Quiet Algorithm   | Ravi Patel | 131
-- Panda Express to Mars | Sam Ortiz  | 121
-- …
```

<Exercise

SELECT *

    { name: "Работает, когда меняются фильмы", check: "(r => r.map(x => x.title).join() === 'The Quiet Algorithm,Bug in the Machine,Panda Express to Mars,Mountain of Echoes,Midnight in the Forest')(await rerun(\"UPDATE movies SET minutes = 125 WHERE title = 'Bug in the Machine'\"))" },
  ]}
>

Перечислите три столбца, оставьте только длинные фильмы и поставьте самые длинные первыми.

<Hint>

Назовите столбцы после `SELECT` вместо `*`. «Дольше 110 минут» — это `minutes > 110`, а `ORDER BY minutes DESC, title` ставит самые длинные первыми и решает ничьи по названию.

</Hint>

<Solution>

```sql
SELECT title, director, minutes
FROM movies
WHERE minutes > 110
ORDER BY minutes DESC, title;
```

</Solution>
