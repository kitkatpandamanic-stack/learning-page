Отдел кадров хочет увидеть **лестницу зарплат** 🪜 каждого отдела. Для каждого сотрудника, который **состоит в отделе**, выведите:

- `department`: название отдела,
- `name`: имя сотрудника,
- `salary`: его зарплату,
- `pay_rank`: его место в отделе по зарплате, от самой высокой. Одинаковые зарплаты **делят одно место**, а следующее место **не пропускается** (1, 2, 2, 3),
- `behind_top`: на сколько меньше он зарабатывает, чем самый высокооплачиваемый сотрудник его отдела (0 для него самого).

Отсортируйте по отделу, затем по `pay_rank`, затем по имени.

```sql
-- department | name        | salary | pay_rank | behind_top
-- Design     | Don Norman  |  95000 |        1 |          0
-- Design     | Susan Kare  |  64000 |        2 |      31000
-- …
```

Добавьте два оконных столбца, `pay_rank` и `behind_top`.

<Hint>

Оба новых столбца смотрят на коллег **из того же отдела**, при этом у каждого сотрудника остаётся своя строка. Это задача для оконных функций с `PARTITION BY`. Какая функция ранжирования даёт равным значениям одно место и не пропускает следующее?

</Hint>

<Hint>

Оба столбца используют `OVER (PARTITION BY e.department_id …)`. Для `pay_rank` возьмите `dense_rank()` с сортировкой по `e.salary DESC`: равные зарплаты получают один номер, а следующий номер не пропускается. Для `behind_top` возьмите `max(e.salary)` по окну отдела (`ORDER BY` здесь не нужен) и вычтите зарплату сотрудника. Обычный `JOIN` уже отбрасывает CEO, у которого нет отдела. Отсортируйте по отделу, `pay_rank`, затем по имени.

</Hint>

<Hint>

```sql
SELECT d.name AS department, e.name, e.salary,
  dense_rank() OVER (...) AS pay_rank,
  ... AS behind_top  -- самая высокая зарплата отдела минус e.salary
FROM employees AS e
JOIN departments AS d ON d.id = e.department_id
ORDER BY department, pay_rank, e.name;
```

</Hint>

<Solution>

```sql
SELECT d.name AS department, e.name, e.salary,
  dense_rank() OVER (PARTITION BY e.department_id ORDER BY e.salary DESC) AS pay_rank,
  max(e.salary) OVER (PARTITION BY e.department_id) - e.salary AS behind_top
FROM employees AS e
JOIN departments AS d ON d.id = e.department_id
ORDER BY department, pay_rank, e.name;
```

</Solution>
