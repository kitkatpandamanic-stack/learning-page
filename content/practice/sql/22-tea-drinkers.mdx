The panda shop is sending a free sample of its new oolong 🍵 to everyone who has **bought tea**. A customer counts if they have **at least one order that wasn't cancelled** containing a product from the **`tea`** category.

Show each customer's **`name`** and **`country`**, **once each**, sorted by name.

Careful: some customers ordered tea only in orders that were later **cancelled**. They don't get a sample. And a customer who bought tea twice still gets **one** row.

```sql
-- name         | country
-- Anna Ivanova | Russia
-- Chloe Martin | France
-- …
```

<Exercise
  language="sql"
  title="Tea drinkers"
  starter={`-- name and country of customers with a non-cancelled order
-- that contains tea, once each, sorted by name
SELECT c.name, c.country
FROM customers AS c
ORDER BY c.name;
`}
  tests={[
    { name: "Columns are name, country", check: "columns.join() === 'name,country'" },
    { name: "The 6 tea drinkers, sorted by name", check: "rows.map(r => r.name).join() === 'Anna Ivanova,Chloe Martin,Lena Fischer,Lucas Silva,Noah Smith,Omar Haddad'" },
    { name: "Each customer appears once", check: "new Set(rows.map(r => r.name)).size === rows.length" },
    { name: "Cancelled tea orders don't count", check: "!rows.some(r => ['Mei Lin', 'Sam Ortiz', 'Zara Khan', 'Diego López'].includes(r.name))" },
    { name: "Works when the data changes", check: "(await rerun(\"UPDATE orders SET status = 'cancelled' WHERE id = 8; UPDATE orders SET status = 'paid' WHERE id = 39\")).map(r => r.name).join() === 'Anna Ivanova,Chloe Martin,Lucas Silva,Noah Smith,Omar Haddad,Sam Ortiz'" },
  ]}
>

Keep only the customers for whom a matching tea order **exists**.

<Hint>

Use `WHERE EXISTS (SELECT 1 FROM orders … JOIN order_items … JOIN products … WHERE …)`. Inside, link the order to the outer customer with `o.customer_id = c.id`, and check `o.status <> 'cancelled'` and `p.category = 'tea'`. `EXISTS` only asks "is there at least one?", so nobody is repeated.

</Hint>

<Solution>

```sql
SELECT c.name, c.country
FROM customers AS c
WHERE EXISTS (
  SELECT 1
  FROM orders AS o
  JOIN order_items AS oi ON oi.order_id = o.id
  JOIN products AS p ON p.id = oi.product_id
  WHERE o.customer_id = c.id
    AND o.status <> 'cancelled'
    AND p.category = 'tea'
)
ORDER BY c.name;
```

You could also join everything and add `DISTINCT`, but `EXISTS` says exactly what you mean and can stop at the first match.

</Solution>

</Exercise>
