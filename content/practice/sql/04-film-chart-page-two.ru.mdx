Сайт киноклуба показывает рейтинг фильмов **по четыре за раз**, начиная с самых высоко оценённых ⭐. Первая страница готова; вы делаете **вторую**.

По таблице `movies` выведите **`title`** и **`rating`** фильмов, которые занимают в рейтинге **места с 5 по 8**. Рейтинг отсортирован **по оценке, от самой высокой**; фильмы с одинаковой оценкой сортируются **по названию**, чтобы страницы не перемешивались между посещениями.

```sql
-- title               | rating
-- Snow Leopard Summer | 7.6
-- …
```

Пропустите первую страницу и выведите следующие четыре фильма в неизменном порядке.

<Hint>

Стартовый запрос уже показывает первую страницу. Какое предложение пропускает строки, прежде чем `LIMIT` начнёт отсчёт? Подумайте и о фильмах с одинаковой оценкой.

</Hint>

<Hint>

Оставьте `LIMIT 4` и добавьте `OFFSET 4`, чтобы пропустить первую страницу из четырёх фильмов. Добавьте `title` после `rating DESC` в `ORDER BY`: без второго ключа фильмы с одинаковой оценкой могут идти в любом порядке, и страница будет меняться от запуска к запуску.

</Hint>

<Hint>

```sql
SELECT title, rating
FROM movies
ORDER BY rating DESC, ...  -- второй ключ сортировки
LIMIT 4 ...;               -- пропустите первую страницу
```

</Hint>

<Solution>

```sql
SELECT title, rating
FROM movies
ORDER BY rating DESC, title
LIMIT 4 OFFSET 4;
```

</Solution>

Для страницы `n` смещение равно `(n - 1) * 4`.

</Exercise>
