Команда разработки едет на конференцию, и компании нужны бейджи и логины для Wi-Fi для всех участников 🎫. Каждое имя в `employees` — это имя и фамилия, разделённые одним пробелом.

Для сотрудников **отдела 1** (Engineering) выведите:

- **`name`**: полное имя как есть;
- **`badge`**: **фамилию заглавными буквами**, запятую и пробел, а затем имя, например `LOVELACE, Ada`;
- **`login`**: **первую букву** имени и следом **фамилию**, всё **строчными буквами**, например `alovelace`.

Отсортируйте строки **по `login`**.

```sql
-- name         | badge         | login
-- Ada Lovelace | LOVELACE, Ada | alovelace
-- Alan Turing  | TURING, Alan  | aturing
-- …
```

Разрежьте каждое полное имя на имя и фамилию и снова склейте кусочки.

<Hint>

Каждое полное имя — это имя и фамилия, разделённые одним пробелом. Есть ли функция, которая режет строку по разделителю и возвращает один из кусочков?

</Hint>

<Hint>

`split_part(name, ' ', 1)` — это имя, а `split_part(name, ' ', 2)` — фамилия. Для `badge` пропустите фамилию через `upper(…)` и склейте её с `', '` и именем через `||`. Для `login` возьмите `left(name, 1)`, приклейте фамилию через `||` и оберните всё в `lower(…)`. Отсортируйте через `ORDER BY login`.

</Hint>

<Hint>

```sql
SELECT
  name,
  upper(split_part(name, ' ', 2)) || ', ' || ... AS badge,
  lower(...) AS login  -- первая буква + фамилия
FROM employees
WHERE department_id = 1
ORDER BY login;
```

</Hint>

<Solution>

```sql
SELECT
  name,
  upper(split_part(name, ' ', 2)) || ', ' || split_part(name, ' ', 1) AS badge,
  lower(left(name, 1) || split_part(name, ' ', 2)) AS login
FROM employees
WHERE department_id = 1
ORDER BY login;
```

</Solution>

Вместо `||` можно использовать и `concat(…)`.
