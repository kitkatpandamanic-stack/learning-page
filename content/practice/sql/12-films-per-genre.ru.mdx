Киноклуб панды планирует сезон тематических вечеров 🎬 и хочет знать, в каких жанрах достаточно фильмов. По таблице `movies` выведите по одной строке на каждый **жанр** со столбцами:

- `genre`,
- `films`: сколько фильмов этого жанра есть в каталоге.

Отсортируйте по `films`, **от большего к меньшему**. Если у двух жанров одинаковое число фильмов, отсортируйте их по `genre`, от A до Z.

```sql
-- genre    | films
-- comedy   |     2
-- drama    |     2
-- …
```

Сгруппируйте фильмы по жанрам и посчитайте их, начиная с самого большого жанра.

<Hint>

Используйте `GROUP BY genre` и `count(*) AS films`. Сортировать можно по псевдониму: `ORDER BY films DESC, genre`.

</Hint>

<Solution>

```sql
SELECT genre, count(*) AS films
FROM movies
GROUP BY genre
ORDER BY films DESC, genre;
```

</Solution>
