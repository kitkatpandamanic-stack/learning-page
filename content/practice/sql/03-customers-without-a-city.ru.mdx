Курьер магазина панды всё время спрашивает, куда везти некоторые посылки 📦. Несколько покупателей так и не указали свой город, поэтому столбец `city` у них пустой (`NULL`).

Выведите **`name`**, **`email`** и **`country`** всех покупателей, у которых **не указан город**, отсортировав их **по имени**.

```sql
-- name        | email              | country
-- Omar Haddad | omar@pandadev.test | Egypt
-- …
```

Осторожно: `city = NULL` выглядит правильно, но никогда ничему не соответствует.

<Exercise
  language="sql"
  title="Покупатели без города"
  starter={`-- name, email и country покупателей без города,
-- по имени
SELECT name, email, country, city
FROM customers
ORDER BY name;
`}
  tests={[
    { name: "Столбцы: name, email, country", check: "columns.join() === 'name,email,country'" },
    { name: "Только покупатели без города", check: "rows.map(r => r.name).join() === 'Omar Haddad,Zara Khan'" },
    { name: "Есть адреса почты для напоминания", check: "rows.map(r => r.email).join() === 'omar@pandadev.test,zara@pandadev.test'" },
    { name: "Работает, когда меняются данные", check: "(r => r.map(x => x.name).join() === 'Tom Baker,Zara Khan')(await rerun(\"UPDATE customers SET city = 'Cairo' WHERE name = 'Omar Haddad'; UPDATE customers SET city = NULL WHERE name = 'Tom Baker'\"))" },
    { name: "Нет строк, когда город указан у всех", check: "(r => r.length === 0)(await rerun(\"UPDATE customers SET city = 'Somewhere' WHERE city IS NULL\"))" },
  ]}
>

Оставьте только покупателей, у которых не указан город.

<Hint>

`NULL` означает «неизвестно», поэтому сравнение через `=` тоже даёт «неизвестно». Используйте вместо него `IS NULL`.

</Hint>

<Solution>

```sql
SELECT name, email, country
FROM customers
WHERE city IS NULL
ORDER BY name;
```

</Solution>

</Exercise>
