Жизнь в Лондоне подорожала, поэтому компания панды повышает зарплату лондонским сотрудникам 💷. Каждый сотрудник, который работает в отделе, **расположенном в Лондоне** (смотрите столбец `location` таблицы `departments`), и зарабатывает **меньше 80000**, получит **на 4% больше** **с округлением до ближайшей сотни**.

Напишите один `UPDATE` для `employees`, который заканчивается на `RETURNING name, salary`, чтобы увидеть каждого, чья зарплата изменилась, вместе с его **новой** зарплатой. Порядок возвращённых строк не важен.

```sql
-- name              | salary
-- Linus Park        |  74900   -- было 72000: 72000 × 1.04 = 74880 → 74900
-- Margaret Hamilton |  79000
-- …
```

Находите отделы по их расположению, а не вписывайте их id вручную: если в следующем году отдел Sales переедет в Лондон, та же инструкция должна охватить и его.

Напишите `UPDATE`, который повышает зарплату лондонским сотрудникам, получающим меньше 80000, и возвращает `name` и `salary`.

<Hint>

`UPDATE employees AS e SET … FROM departments AS d WHERE d.id = e.department_id AND …` позволяет использовать `location` отдела. `round(x, -2)` округляет до ближайшей сотни.

</Hint>

<Solution>

```sql
UPDATE employees AS e
SET salary = round(e.salary * 1.04, -2)
FROM departments AS d
WHERE d.id = e.department_id
  AND d.location = 'London'
  AND e.salary < 80000
RETURNING e.name, e.salary;
```

Подойдёт и подзапрос: `WHERE salary < 80000 AND department_id IN (SELECT id FROM departments WHERE location = 'London')`. У Grace Hopper отдела нет вовсе, поэтому ни один из вариантов её не затрагивает.

</Solution>
