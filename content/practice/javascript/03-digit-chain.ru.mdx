Возьмите целое число, сложите его цифры — получится новое число. Повторяйте снова и снова, и в итоге всегда останется одна цифра: 9875 → 9 + 8 + 7 + 5 = 29 → 2 + 9 = 11 → 1 + 1 = 2.

Напишите функцию (function) `digitChain(n)`, которая возвращает всю эту цепочку в виде массива (array) чисел: от самого числа до последней одной цифры.

- Отрицательное число считается положительным: цепочка для `-38` начинается с `38`.
- Если в числе уже одна цифра, цепочка состоит только из него.

```js
digitChain(9875); // [ 9875, 29, 11, 2 ]
digitChain(38);   // [ 38, 11, 2 ]
digitChain(-38);  // [ 38, 11, 2 ]
digitChain(7);    // [ 7 ]
digitChain(0);    // [ 0 ]
```

Допишите `digitChain(n)`, чтобы функция возвращала каждое число цепочки — от `n` до одной цифры.

<Hint>

Цепочка продолжается, пока у числа две цифры или больше. Как это проверить и как отделить от числа последнюю цифру? Не забудьте про отрицательные числа.

</Hint>

<Hint>

Начните с `let current = Math.abs(n)` и массива, в котором лежит это число. Продолжайте, пока `while (current >= 10)`: найдите сумму цифр, добавьте её в массив через `push` и сделайте новым значением `current`. Чтобы сложить цифры, берите последнюю через `current % 10` и отбрасывайте её через `Math.floor(current / 10)`, пока ничего не останется. Однозначное число в цикл не попадёт, и цепочка будет состоять только из него.

</Hint>

```js
function digitChain(n) {
  let current = Math.abs(n);
  const chain = [current];
  while (current >= 10) {
    let sum = 0;
    // сложите цифры current в sum
    current = sum;
    chain.push(current);
  }
  return chain;
}
```

<Solution>

```js
function digitChain(n) {
  let current = Math.abs(n);
  const chain = [current];
  while (current >= 10) {
    let sum = 0;
    while (current > 0) {
      sum += current % 10;
      current = Math.floor(current / 10);
    }
    current = sum;
    chain.push(current);
  }
  return chain;
}

console.log(digitChain(9875)); // [ 9875, 29, 11, 2 ]
```

Внешний цикл (loop) выполняется один раз на каждый шаг цепочки, а внутренний отщипывает по одной цифре. Цифры можно сложить и так: `String(current).split("").reduce((sum, d) => sum + Number(d), 0)`.

</Solution>
