A curious panda has wandered into the hedge maze at the botanical garden. Write `route(grid)` that tells it exactly how to get out by the shortest way.

- `grid` is an array of strings, all the same length. `S` is the panda's start, `E` is the exit (there's exactly one of each), `#` is a hedge and `.` is open ground.
- In one move the panda steps one cell down, left, right or up: `"D"`, `"L"`, `"R"` or `"U"`. It can't leave the grid or step into a hedge.
- Return the **shortest** route as a string of moves. If there are several shortest routes, return the one that comes first **alphabetically** (so at every step, `D` is preferred over `L`, `L` over `R`, and `R` over `U`, as long as the route stays shortest).
- If the panda can't reach the exit, return `null`.
- Mazes can be 300 × 300 cells, so trying every possible path is far too slow.

```js
route([
  "S.#",
  "..#",
  "#.E",
]);
// "DRDR" (RDDR is just as short, but DRDR comes first alphabetically)

route([
  "S.....",
  ".####.",
  ".#..#.",
  ".#E.#.",
  ".##.#.",
  "......",
]);
// "DDDDDRRRUUL"

route(["S#.", "##.", "..E"]);  // null
route(["ES"]);                  // "L"
```

<Hint>

**Breadth-first search** (BFS) finds shortest distances in a grid. Think about where to start it: knowing how far every cell is from the **exit** makes choosing each move easy.

</Hint>

<Hint>

Run BFS from `E`, filling a 2D array `dist` (start it with `-1` everywhere) with each cell's number of moves to the exit; use an index into the queue array instead of `queue.shift()`, which is slow on long arrays. If `dist` at `S` is still `-1`, return `null`. Otherwise walk from `S`: at each step, try the moves in the order `D`, `L`, `R`, `U` and take the first one that leads to an open cell whose distance is exactly one less. Every step gets one closer to `E`, so the route is shortest, and taking the first possible letter each time makes it the alphabetically first one.

</Hint>

<Solution>

```js
const MOVES = [["D", 1, 0], ["L", 0, -1], ["R", 0, 1], ["U", -1, 0]];

function find(grid, char) {
  for (let r = 0; r < grid.length; r++) {
    const c = grid[r].indexOf(char);
    if (c !== -1) return [r, c];
  }
}

function route(grid) {
  const rows = grid.length;
  const cols = grid[0].length;
  const open = (r, c) =>
    r >= 0 && r < rows && c >= 0 && c < cols && grid[r][c] !== "#";

  // 1. BFS from the exit: dist[r][c] = moves from (r, c) to E.
  const dist = Array.from({ length: rows }, () => new Array(cols).fill(-1));
  const [er, ec] = find(grid, "E");
  dist[er][ec] = 0;
  const queue = [[er, ec]];
  for (let head = 0; head < queue.length; head++) {
    const [r, c] = queue[head];
    for (const [, dr, dc] of MOVES) {
      const nr = r + dr;
      const nc = c + dc;
      if (open(nr, nc) && dist[nr][nc] === -1) {
        dist[nr][nc] = dist[r][c] + 1;
        queue.push([nr, nc]);
      }
    }
  }

  // 2. Walk from S, always taking the first letter that gets closer.
  let [r, c] = find(grid, "S");
  if (dist[r][c] === -1) return null;
  let path = "";
  while (dist[r][c] > 0) {
    for (const [letter, dr, dc] of MOVES) {
      const nr = r + dr;
      const nc = c + dc;
      if (open(nr, nc) && dist[nr][nc] === dist[r][c] - 1) {
        path += letter;
        r = nr;
        c = nc;
        break;
      }
    }
  }
  return path;
}

console.log(route(["S.#", "..#", "#.E"])); // DRDR
```

The BFS from the exit tells every cell how far it is from `E`, and then the route builds itself greedily: a neighbour one step closer always exists on a shortest route, and taking the alphabetically first such neighbour at each step gives the alphabetically first shortest route. Both phases visit each cell a constant number of times, so it's O(rows × cols).

</Solution>
