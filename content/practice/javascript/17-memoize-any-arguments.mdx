A simple `memoize` that only looks at the first argument isn't enough for functions like `shippingCost(weight, country)`. Write a better one. `memoize(fn)` returns a new function that behaves exactly like `fn`, except it remembers results:

- Results are cached by **all** the arguments together, using `JSON.stringify(args)` as the key. So `(1, 2)` and `(12)` are different, and so are `1` and `"1"`.
- When the same arguments come again, return the remembered result without calling `fn`. This includes results like `undefined`, `0` or `false`: they are remembered too.
- If `fn` throws, the error goes to the caller as usual, and **nothing** is remembered: the next call with those arguments tries `fn` again.
- The returned function also has two methods: `.cacheSize()` returns how many results are remembered, and `.clear()` forgets them all.

Each memoized function has its own cache.

```js
let runs = 0;
const cost = memoize((kg, country) => {
  runs++;
  return country === "UK" ? kg * 2 : kg * 5;
});

cost(3, "UK");    // 6   (runs is 1)
cost(3, "UK");    // 6   (remembered: runs is still 1)
cost(3, "FR");    // 15  (runs is 2)
cost.cacheSize(); // 2
cost.clear();
cost(3, "UK");    // 6   (runs is 3)
```

Finish `memoize(fn)` so the returned function remembers results by all its arguments.

<Hint>

Create a `new Map()` inside `memoize`, then build the returned function as `const memo = (...args) => { … }`. Its key is `JSON.stringify(args)`. Ask `cache.has(key)` rather than checking whether `cache.get(key)` is truthy, otherwise `undefined`, `0` and `false` results are worked out again every time.

</Hint>

<Hint>

If `fn(...args)` throws, the line after it never runs, so store the result with `cache.set` only **after** the call returns. Functions are objects, so you can add methods to `memo` before returning it: `memo.cacheSize = () => cache.size;`.

</Hint>

<Solution>

```js
function memoize(fn) {
  const cache = new Map();
  const memo = (...args) => {
    const key = JSON.stringify(args);
    if (cache.has(key)) return cache.get(key);
    const result = fn(...args);
    cache.set(key, result);
    return result;
  };
  memo.cacheSize = () => cache.size;
  memo.clear = () => cache.clear();
  return memo;
}

let runs = 0;
const cost = memoize((kg, country) => {
  runs++;
  return country === "UK" ? kg * 2 : kg * 5;
});
console.log(cost(3, "UK"), cost(3, "UK"), runs); // 6 6 1
```

The `Map` lives in the closure, so each memoized function gets its own private cache, and looking a key up is O(1). Because `cache.set` comes after the call, an error skips it automatically, and `has` (not a truthy check) is what lets falsy results be remembered.

</Solution>
