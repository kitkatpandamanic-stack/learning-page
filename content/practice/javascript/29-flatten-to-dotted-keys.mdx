The panda app's settings are a deeply nested object, but the settings screen wants one flat list of rows. Write `flatten(value, separator = ".")` that returns a flat object whose keys are the paths to every leaf.

- A path joins the keys on the way down with `separator`. Array items use their index as the key, so the second item of `pets` is `pets.1`.
- Plain objects and arrays are opened up. Everything else is a leaf and is copied as it is: strings, numbers, booleans, `null`, `undefined`, functions and other objects such as dates.
- An empty object or empty array is kept as a leaf too, so it doesn't vanish: `{ tags: [] }` gives `{ tags: [] }`.
- Keys appear in the order you meet them going depth first: all of `a`'s paths before `b`'s.
- `flatten` is called with a plain object or an array. If it has nothing inside, the result is `{}`.

```js
flatten({
  user: { name: "Mei", pets: [{ name: "Bao" }, "fish"] },
  theme: "dark",
});
// {
//   "user.name": "Mei",
//   "user.pets.0.name": "Bao",
//   "user.pets.1": "fish",
//   "theme": "dark",
// }

flatten({ a: { b: 1 }, tags: [], extra: {} });  // { "a.b": 1, tags: [], extra: {} }
flatten({ a: { b: 1 } }, "/");                   // { "a/b": 1 }
flatten([10, [20]]);                             // { "0": 10, "1.0": 20 }
```

Finish `flatten(value, separator)`.

<Hint>

Recursion fits well: carry the path you've built so far as you go down, and write a value into the result when you reach a leaf. The tricky part is deciding what counts as a leaf: dates and empty containers are leaves too.

</Hint>

<Hint>

Write an inner function `walk(current, path)` that adds to one shared `result` object. A value should be opened up when it's `Array.isArray(current)` or a plain object (`current !== null && Object.getPrototypeOf(current) === Object.prototype`). If it should be opened up and `Object.entries(current)` isn't empty, call `walk` on each `[key, child]` with the longer path; otherwise store `result[path] = current`. Start with `walk(value, "")`; when the path is empty, the child path is the key alone, and an empty top-level value adds nothing.

</Hint>

<Solution>

```js
function isContainer(value) {
  if (Array.isArray(value)) return true;
  return value !== null && typeof value === "object" &&
    Object.getPrototypeOf(value) === Object.prototype;
}

function flatten(value, separator = ".") {
  const result = {};
  function walk(current, path) {
    const entries = isContainer(current) ? Object.entries(current) : [];
    if (entries.length === 0) {
      if (path !== "") result[path] = current;
      return;
    }
    for (const [key, child] of entries) {
      walk(child, path === "" ? key : path + separator + key);
    }
  }
  walk(value, "");
  return result;
}

console.log(flatten({ a: { b: 1, c: [2, 3] } })); // { 'a.b': 1, 'a.c.0': 2, 'a.c.1': 3 }
```

The recursion carries the path built so far, and whatever can't be opened up (or is empty) is stored under that path. Going through `Object.entries` handles arrays and objects the same way, since an array's keys are its indexes. Every value is visited once, so it's O(n) for n values.

</Solution>
