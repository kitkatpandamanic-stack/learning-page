The panda café's receipt printer only fits a few characters per line. Write a function `wrapText(text, width)` that breaks `text` into lines and returns them as an array of strings.

- The words of the text are separated by whitespace: spaces, tabs or new lines, any number of them.
- Fill each line **greedily**: put as many words on it as fit, separated by single spaces, so the line's length is at most `width`. Then start the next line with the word that didn't fit.
- A word that is longer than `width` on its own goes on a line by itself, unbroken (it's the only way it can be printed).
- Lines have no spaces at the start or end. A text with no words gives `[]`.

```js
wrapText("Bamboo tea and dumplings for two pandas", 12);
// [ 'Bamboo tea', 'and', 'dumplings', 'for two', 'pandas' ]
// ('and dumplings' would be 13 characters, too wide for 12)

wrapText("one two three", 7);   // [ 'one two', 'three' ]   ('one two' is exactly 7)
wrapText("hi supercalifragilistic yo", 5);
// [ 'hi', 'supercalifragilistic', 'yo' ]
wrapText("   \n  ", 10);        // []
```

Finish `wrapText(text, width)` so it returns the wrapped lines.

<Hint>

Get the words with `text.split(/\s+/).filter((word) => word !== "")`. `\s+` matches any run of whitespace, and the filter removes the empty strings you get from whitespace at the start or end.

</Hint>

<Hint>

Build the current line in a variable. For each word: if the line is empty, the word starts it; else if `line.length + 1 + word.length <= width`, add `" " + word`; otherwise push the line onto the result and start a new one with the word. Don't forget to push the last line after the loop.

</Hint>

<Solution>

```js
function wrapText(text, width) {
  const words = text.split(/\s+/).filter((word) => word !== "");
  const lines = [];
  let line = "";
  for (const word of words) {
    if (line === "") {
      line = word;
    } else if (line.length + 1 + word.length <= width) {
      line += " " + word;
    } else {
      lines.push(line);
      line = word;
    }
  }
  if (line !== "") lines.push(line);
  return lines;
}

console.log(wrapText("one two three", 7)); // [ 'one two', 'three' ]
```

The greedy idea: keep adding words to the current line until the next one wouldn't fit (counting the space before it), then start a new line. A word that starts a line is always accepted, which is how over-long words end up alone. Each word is looked at once, so it's O(n) in the length of the text.

</Solution>
