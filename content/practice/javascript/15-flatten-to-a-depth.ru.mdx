`[1, [2, [3]]].flat()` распаковывает вложенные массивы (array). Ваша задача — написать это самостоятельно, **без** `.flat()` и `.flatMap()`.

Напишите функцию (function) `flatten(items, depth)`, которая возвращает новый массив, где вложенные массивы распакованы на `depth` уровней вглубь:

- `depth` необязателен, по умолчанию он равен `1`: распаковываются только массивы, лежащие прямо внутри `items`.
- `depth` равный `0` ничего не распаковывает и возвращает копию `items`.
- `depth` равный `Infinity` распаковывает всё, какой бы ни была вложенность.
- Элементы, которые не являются массивами (числа, строки, объекты, `null`…), остаются как есть и в том же порядке. Пустые массивы при распаковке исчезают.
- Не изменяйте `items` и массивы внутри него.

```js
flatten([1, [2, [3, [4]]]]);           // [ 1, 2, [ 3, [ 4 ] ] ]
flatten([1, [2, [3, [4]]]], 2);        // [ 1, 2, 3, [ 4 ] ]
flatten([1, [2, [3, [4]]]], Infinity); // [ 1, 2, 3, 4 ]
flatten([[], ["a"], [[]]], 1);         // [ 'a', [] ]
flatten([1, [2]], 0);                  // [ 1, [ 2 ] ]
```

Допишите `flatten(items, depth)`, чтобы функция распаковывала вложенные массивы на `depth` уровней.

<Hint>

Начните с распаковки только одного уровня: что делать с элементом-массивом и что — с обычным элементом? Отличить их поможет `Array.isArray`. Потом подумайте, как повторить то же самое для следующего уровня.

</Hint>

<Hint>

Пройдите по элементам, складывая их в новый массив `result`. Если элемент — массив и `depth > 0`, добавьте элементы `flatten(item, depth - 1)` через `result.push(...)`; иначе добавьте сам элемент. Рекурсия остановится сама, когда дойдёт до элементов, которые не являются массивами, а `Infinity - 1` — это по-прежнему `Infinity`. При глубине 0 каждый элемент добавляется как есть, и получается копия.

</Hint>

<Solution>

```js
function flatten(items, depth = 1) {
  const result = [];
  for (const item of items) {
    if (Array.isArray(item) && depth > 0) {
      result.push(...flatten(item, depth - 1));
    } else {
      result.push(item);
    }
  }
  return result;
}

console.log(flatten([1, [2, [3, [4]]]], 2)); // [ 1, 2, 3, [ 4 ] ]
```

Каждый вызов распаковывает один уровень и поручает рекурсивному вызову (recursion) следующий — с глубиной на единицу меньше. `Infinity - 1` всё ещё `Infinity`, поэтому бесконечная глубина просто никогда не кончается, а рекурсия сама останавливается, дойдя до элементов, которые не являются массивами. Каждый элемент копируется по разу на каждый уровень вложенности над ним, так что сложность — O(всего элементов × вложенность).

</Solution>
