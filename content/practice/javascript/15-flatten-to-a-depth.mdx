`[1, [2, [3]]].flat()` unpacks nested arrays. Your job is to write that yourself, **without** using `.flat()` or `.flatMap()`.

Write a function `flatten(items, depth)` that returns a new array where nested arrays are unpacked `depth` levels deep:

- `depth` is optional and defaults to `1`: only the arrays directly inside `items` are unpacked.
- `depth` `0` unpacks nothing and returns a copy of `items`.
- `depth` `Infinity` unpacks everything, however deep it goes.
- Items that aren't arrays (numbers, strings, objects, `null`...) are kept as they are and in the same order. Empty arrays disappear when they are unpacked.
- Don't change `items` or any array inside it.

```js
flatten([1, [2, [3, [4]]]]);           // [ 1, 2, [ 3, [ 4 ] ] ]
flatten([1, [2, [3, [4]]]], 2);        // [ 1, 2, 3, [ 4 ] ]
flatten([1, [2, [3, [4]]]], Infinity); // [ 1, 2, 3, 4 ]
flatten([[], ["a"], [[]]], 1);         // [ 'a', [] ]
flatten([1, [2]], 0);                  // [ 1, [ 2 ] ]
```

Finish `flatten(items, depth)` so it unpacks nested arrays `depth` levels deep.

<Hint>

Start with unpacking only one level: what do you do with an item that's an array, and with one that isn't? `Array.isArray` tells them apart. Then think about how to repeat that for the next level down.

</Hint>

<Hint>

Loop over the items into a new `result` array. If an item is an array and `depth > 0`, push the items of `flatten(item, depth - 1)` with `result.push(...)`; otherwise push the item itself. The recursion stops on its own when it reaches items that aren't arrays, and `Infinity - 1` is still `Infinity`. With depth 0 every item is pushed as it is, which gives a copy.

</Hint>

<Solution>

```js
function flatten(items, depth = 1) {
  const result = [];
  for (const item of items) {
    if (Array.isArray(item) && depth > 0) {
      result.push(...flatten(item, depth - 1));
    } else {
      result.push(item);
    }
  }
  return result;
}

console.log(flatten([1, [2, [3, [4]]]], 2)); // [ 1, 2, 3, [ 4 ] ]
```

Each call unpacks one level and asks a recursive call to handle the next one, with one less depth to go. `Infinity - 1` is still `Infinity`, so infinite depth simply never runs out, and the recursion stops on its own when it reaches items that aren't arrays. Every item is copied once per level it sits under, so it's O(total items × nesting).

</Solution>
