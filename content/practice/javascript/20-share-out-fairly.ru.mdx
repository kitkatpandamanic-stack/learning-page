Три панды делят поровну 10 побегов бамбука. Это по 3⅓ на каждую, но побег не разрежешь. Кто-то получит 4, а остальные — по 3. Напишите функцию (function) `shareOut(total, weights)`, которая делит `total` предметов (целое число, 0 или больше) между участниками в соответствии с их весами `weights` (целые числа, 0 или больше, хотя бы одно больше 0) и возвращает массив (array) с долей каждого:

1. **Точная** доля каждого — `total × weight ÷ (сумма всех весов)`. Сначала выдайте всем эту долю, округлённую **вниз**.
2. Останется несколько предметов. Раздайте их **по одному** тем, у кого дробная часть точной доли (то, что после запятой) самая большая.
3. Если дробные части у двоих одинаковые, предмет первым получает тот, кто стоит в массиве **раньше**.

Доли — целые числа и в сумме всегда дают ровно `total`. Участник с весом 0 получает 0.

```js
shareOut(10, [1, 1, 1]);       // [ 4, 3, 3 ]
shareOut(7, [2, 1]);           // [ 5, 2 ]   (точно: 4.67 и 2.33)
shareOut(100, [50, 30, 20]);   // [ 50, 30, 20 ]
shareOut(11, [3, 3, 3, 1]);    // [ 4, 3, 3, 1 ]
shareOut(5, [0, 2, 0]);        // [ 0, 5, 0 ]
```

Совет: из-за ошибок округления дробные части, которые должны быть равны, могут немного различаться (`0.1 + 0.2` — это `0.30000000000000004`). Раз веса целые, можно сравнивать **остатки**: `(total * weight) % sum` — целое число, и это в точности дробная часть, умноженная на `sum`.

<Hint>

Если округлить каждую точную долю вниз, останется несколько лишних предметов. Кому их отдать? Подумайте, как измерить, сколько «отрезали» у каждого участника, — лучше в целых числах, чтобы не мешали ошибки округления дробей.

</Hint>

<Hint>

Найдите сумму весов `sum`. Для каждого участника `Math.floor(total * weight / sum)` — его доля, округлённая вниз, а `(total * weight) % sum` — его остаток. Количество оставшихся предметов — это `total` минус сумма округлённых вниз долей. Отсортируйте список индексов `[0, 1, 2, …]` по остатку, от большего к меньшему; сортировка в JavaScript устойчивая (stable), поэтому при равенстве более ранние участники остаются впереди. Затем выдайте по одному дополнительному предмету первым `leftover` индексам из этого списка.

</Hint>

<Solution>

```js
function shareOut(total, weights) {
  const sum = weights.reduce((a, b) => a + b, 0);
  const shares = weights.map((w) => Math.floor((total * w) / sum));
  const remainders = weights.map((w) => (total * w) % sum);
  let leftover = total - shares.reduce((a, b) => a + b, 0);

  const order = weights.map((_, i) => i);
  order.sort((a, b) => remainders[b] - remainders[a]);
  for (const i of order) {
    if (leftover === 0) break;
    shares[i]++;
    leftover--;
  }
  return shares;
}

console.log(shareOut(10, [1, 1, 1])); // [ 4, 3, 3 ]
```

Это **метод наибольшего остатка** (largest remainder method) — им, например, распределяют места на некоторых выборах. Округление вниз теряет меньше одного предмета на участника, поэтому оставшихся предметов всегда меньше, чем участников, а сравнение целых остатков избавляет от сюрпризов с плавающей точкой. Из-за сортировки индексов сложность — O(n log n) для n участников.

</Solution>
