Простого `memoize`, который смотрит только на первый аргумент (argument), не хватает для функций вроде `shippingCost(weight, country)`. Напишите версию получше. `memoize(fn)` возвращает новую функцию (function), которая ведёт себя точно так же, как `fn`, но запоминает результаты:

- Результаты кэшируются по **всем** аргументам вместе, а ключом служит `JSON.stringify(args)`. Поэтому `(1, 2)` и `(12)` — разные ключи, как и `1` и `"1"`.
- Когда те же аргументы приходят снова, верните запомненный результат, не вызывая `fn`. Это касается и результатов вроде `undefined`, `0` или `false`: их тоже нужно запоминать.
- Если `fn` выбрасывает ошибку (error), она, как обычно, доходит до вызывающего кода, и **ничего** не запоминается: следующий вызов с теми же аргументами снова пробует `fn`.
- У возвращаемой функции есть ещё два метода (method): `.cacheSize()` возвращает, сколько результатов запомнено, а `.clear()` забывает их все.

У каждой мемоизированной функции свой кэш.

```js
let runs = 0;
const cost = memoize((kg, country) => {
  runs++;
  return country === "UK" ? kg * 2 : kg * 5;
});

cost(3, "UK");    // 6   (runs равно 1)
cost(3, "UK");    // 6   (запомнено: runs всё ещё 1)
cost(3, "FR");    // 15  (runs равно 2)
cost.cacheSize(); // 2
cost.clear();
cost(3, "UK");    // 6   (runs равно 3)
```

Допишите `memoize(fn)`, чтобы возвращаемая функция запоминала результаты по всем своим аргументам.

<Hint>

Нужно место для результатов, которое видит только возвращённая функция, и способ превратить все аргументы в один ключ. Здесь хорошо подойдут `Map` и `JSON.stringify`. Осторожно: `undefined`, `0` и `false` — тоже настоящие результаты.

</Hint>

<Hint>

Создайте `new Map()` внутри `memoize`, а возвращаемую функцию соберите как `const memo = (...args) => …` с ключом `JSON.stringify(args)`. Спрашивайте `cache.has(key)`, а не проверяйте, истинно ли `cache.get(key)`. Иначе вызовите `fn(...args)` и сохраните результат через `cache.set` только **после** того, как вызов вернул значение, — тогда выброшенная ошибка никогда не попадёт в кэш. Функции — это объекты, поэтому перед возвратом `memo` добавьте к ней `memo.cacheSize` и `memo.clear`.

</Hint>

function memoize(fn) {
  const cache = new Map();
  const memo = (...args) => {
    const key = JSON.stringify(args);
    if (cache.has(key)) return cache.get(key);

  memo.clear = ...; // забыть все результаты
  return memo;

<Solution>

```js
function memoize(fn) {
  const cache = new Map();
  const memo = (...args) => {
    const key = JSON.stringify(args);
    if (cache.has(key)) return cache.get(key);
    const result = fn(...args);
    cache.set(key, result);
    return result;
  };
  memo.cacheSize = () => cache.size;
  memo.clear = () => cache.clear();
  return memo;
}

let runs = 0;
const cost = memoize((kg, country) => {
  runs++;
  return country === "UK" ? kg * 2 : kg * 5;
});
console.log(cost(3, "UK"), cost(3, "UK"), runs); // 6 6 1
```

`Map` живёт в замыкании (closure), поэтому у каждой мемоизированной функции свой личный кэш, а поиск по ключу занимает O(1). Поскольку `cache.set` идёт после вызова, ошибка автоматически его пропускает, а `has` (вместо проверки на истинность) позволяет запоминать ложные результаты.

</Solution>
