Школьные группы бронируют время у вольера с пандами в виде интервалов `[start, end]` — в минутах после открытия. Смотрителям нужно знать только, когда вольер занят, поэтому напишите `mergeRanges(ranges)`, которая объединяет брони в как можно меньшее число интервалов.

- Два интервала объединяются, если они пересекаются **или соприкасаются**: `[10, 20]` и `[20, 30]` превращаются в `[10, 30]`. Интервал внутри другого просто растворяется в нём.
- Входные данные могут идти в любом порядке. Верните объединённые интервалы, отсортированные по началу.
- У каждого интервала должно быть `start <= end`. Если хоть один интервал нарушает это правило, выбросьте `RangeError`.
- Не меняйте ни входной массив (array), ни интервалы в нём, и возвращайте новые массивы `[start, end]`.
- Если интервалов нет, результат — `[]`.

```js
mergeRanges([[10, 20], [15, 25], [40, 50]]);   // [[10, 25], [40, 50]]
mergeRanges([[30, 40], [0, 5], [5, 10]]);      // [[0, 10], [30, 40]]
mergeRanges([[0, 100], [20, 30], [99, 120]]);  // [[0, 120]]
mergeRanges([]);                               // []
mergeRanges([[8, 3]]);                         // RangeError
```

<Solution>

```js
function mergeRanges(ranges) {
  for (const [start, end] of ranges) {
    if (start > end) throw new RangeError(`Плохой интервал [${start}, ${end}]`);
  }
  const sorted = [...ranges].sort((a, b) => a[0] - b[0]);
  const merged = [];
  for (const [start, end] of sorted) {
    const last = merged.at(-1);
    if (last && start <= last[1]) {
      last[1] = Math.max(last[1], end);
    } else {
      merged.push([start, end]);
    }
  }
  return merged;
}

console.log(mergeRanges([[10, 20], [15, 25], [40, 50]])); // [ [ 10, 25 ], [ 40, 50 ] ]
```

Когда интервалы отсортированы по началу, пересекающиеся оказываются рядом, поэтому достаточно одного прохода, который растягивает последний объединённый интервал. Больше всего времени занимает сортировка: O(n log n).

</Solution>
