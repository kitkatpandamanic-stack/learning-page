The panda library types book titles in a hurry, so they come out messy. Write a function `titleCase(text)` that tidies one up:

- Words are separated by spaces. Extra spaces (at the start, at the end, or several in a row) are removed, so words end up separated by exactly one space.
- Every word gets a capital first letter and the rest in lower case: `"pANDA"` becomes `"Panda"`.
- Except the little words `a`, `an`, `the`, `and`, `or`, `of`, `in`, `on`, `at` and `to`: these are written all in lower case, **unless** they are the first or the last word of the title.
- Anything that isn't a space is part of a word, so `"well-known"` becomes `"Well-known"`.

An empty or blank title gives `""`.

```js
titleCase("the lord OF the rings");     // 'The Lord of the Rings'
titleCase("  a   tale of two pandas "); // 'A Tale of Two Pandas'
titleCase("something to hold on to");   // 'Something to Hold on To'
titleCase("of");                        // 'Of'
titleCase("   ");                       // ''
```

<Solution>

```js
const LITTLE = ["a", "an", "the", "and", "or", "of", "in", "on", "at", "to"];

function titleCase(text) {
  const words = text.trim().split(" ").filter((word) => word !== "");
  return words
    .map((word, i) => {
      const lower = word.toLowerCase();
      const edge = i === 0 || i === words.length - 1;
      if (LITTLE.includes(lower) && !edge) return lower;
      return lower[0].toUpperCase() + lower.slice(1);
    })
    .join(" ");
}

console.log(titleCase("the lord OF the rings")); // The Lord of the Rings
```

Splitting and filtering gives a clean list of words, and `map` gets each word's index for free, which is all you need to spot the first and last word. Comparing whole lower-cased words with `includes` keeps "Theory" and "Atom" from being mistaken for "the" and "at".

</Solution>
