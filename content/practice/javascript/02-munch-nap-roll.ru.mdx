Панда считает часы своего дня от 1 до `n`, но некоторые часы особенные. Напишите функцию (function) `munchNap(n)`, которая возвращает массив (array) с одной строкой для каждого числа от 1 до `n`:

- Если число кратно 3, строка содержит `"Munch"` («жуём»).
- Если оно кратно 4, строка содержит `"Nap"` («спим»).
- Если среди его цифр есть 7, строка содержит `"Roll"` («катаемся»).
- Слова склеиваются строго в таком порядке: Munch, потом Nap, потом Roll (так что 72 — это `"MunchNapRoll"`).
- Число, которое не подходит ни под одно правило, превращается в само себя, но строкой (`"5"`, а не `5`).

Если `n` меньше 1, верните пустой массив.

```js
munchNap(5);      // [ '1', '2', 'Munch', 'Nap', '5' ]
munchNap(12)[11]; // 'MunchNap'  (12-й элемент — для числа 12)
munchNap(27)[26]; // 'MunchRoll'
munchNap(70)[69]; // 'Roll'
munchNap(0);      // []
```

Допишите `munchNap(n)`, чтобы функция собирала список строк для чисел от 1 до `n`.

<Hint>

Число может подходить сразу под несколько правил — например, 12 даёт `MunchNap`. Выбирать одно правило через `else if` или пусть каждое правило добавляет к слову свой кусочек?

</Hint>

<Hint>

Используйте цикл `for (let i = 1; i <= n; i++)`. В начале каждого шага заведите пустую строку `let word = ""` и добавляйте `"Munch"`, `"Nap"` и `"Roll"` тремя отдельными `if` — именно в этом порядке. Для кратности подойдёт `%`, а для цифры — `String(i).includes("7")`. Если после проверок `word` всё ещё пустая, возьмите вместо неё `String(i)` и добавьте результат в массив через `push`. Когда `n` меньше 1, цикл не выполнится ни разу, и получится пустой массив.

</Hint>

  }

}

<Solution>

```js
function munchNap(n) {
  const day = [];
  for (let i = 1; i <= n; i++) {
    let word = "";
    if (i % 3 === 0) word += "Munch";
    if (i % 4 === 0) word += "Nap";
    if (String(i).includes("7")) word += "Roll";
    day.push(word || String(i));
  }
  return day;
}

console.log(munchNap(5)); // [ '1', '2', 'Munch', 'Nap', '5' ]
```

Слово собирается по кусочкам отдельными `if` (а не `else if`), поэтому случаи «сразу два правила» вроде `MunchNap` получаются сами собой — без отдельного правила для чисел, кратных 12. `word || String(i)` берёт число, только если ни одно правило ничего не добавило.

</Solution>
