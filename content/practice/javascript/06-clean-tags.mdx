Writers on the panda blog type tags however they like: `" JavaScript "`, `"javascript"`, `"Machine   Learning"`. Write a function `cleanTags(tags)` that takes an array of tag strings and returns a new, tidy array:

1. Remove spaces at the start and end of each tag.
2. Make it lower case.
3. Replace each run of spaces inside the tag with a single dash: `"machine   learning"` becomes `"machine-learning"`.
4. Leave out tags that end up empty.
5. Keep each tag only once, at the place where it first appeared.

Don't change the array you were given.

```js
cleanTags([" JavaScript ", "css", "javascript", "Machine   Learning", "", "CSS"]);
// [ 'javascript', 'css', 'machine-learning' ]

cleanTags(["   ", ""]); // []
cleanTags([]);          // []
```

<Solution>

```js
function cleanTags(tags) {
  const seen = new Set();
  for (const tag of tags) {
    const clean = tag
      .trim()
      .toLowerCase()
      .split(" ")
      .filter((part) => part !== "")
      .join("-");
    if (clean !== "") seen.add(clean);
  }
  return [...seen];
}

console.log(cleanTags([" JavaScript ", "css", "javascript", "Machine   Learning", "", "CSS"]));
// [ 'javascript', 'css', 'machine-learning' ]
```

Adding something to a `Set` a second time does nothing, and a `Set` keeps insertion order, so spreading it back into an array gives each tag once, where it first appeared. A regular expression can do step 3 in one go too: `.replace(/ +/g, "-")`.

</Solution>
