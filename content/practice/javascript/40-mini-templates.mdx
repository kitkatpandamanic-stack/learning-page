The panda newsletter is built from templates like `Hi {{ name }}!`. Write `render(template, data)`, a small template engine in the style of Mustache, which fills a template with values from `data`.

**Tags.** Everything between `{{` and `}}` is a tag (spaces just inside the braces are ignored), and everything else is copied as it is. A `{{` with no `}}` after it is just text. There are four kinds:

- `{{ path }}` is replaced with a value. `path` is a name like `name`, a dotted path like `food.favourite`, or `.` for "the current item". `undefined` and `null` print as nothing; anything else is turned into text with `String(value)`.
- `{{#path}} … {{/path}}` is a **section**. If the value is an array, the inside is rendered once per item, with that item as the current item. If the value is any other truthy value, the inside is rendered once, with the value as the current item. If it's falsy or an empty array, nothing is rendered.
- `{{^path}} … {{/path}}` is an **inverted section**: its inside is rendered once (without changing the current item) only when the value is falsy or an empty array.
- Sections can be nested. A closing tag must match the most recent open section; otherwise throw a `SyntaxError` with the message `Unexpected closing tag "<path>"`. A section that is still open at the end throws a `SyntaxError` with the message `Unclosed section "<path>"`.

**Looking up a path.** The current items form a stack: `data` is at the bottom, and each section adds its item on top while it renders. For `a.b.c`, find the topmost item that is an object having a property `a` (checked with `in`), then follow `.b.c` from there (a missing step gives `undefined`). If no item has `a`, the value is `undefined`. This lets a loop item use outer values, like the `{{zoo}}` below.

```js
const template =
  "{{#pandas}}[{{name}} eats {{food.favourite}} in {{zoo}}]{{/pandas}}" +
  "{{^pandas}}No pandas yet.{{/pandas}}";

render(template, {
  zoo: "Chengdu",
  pandas: [
    { name: "Mei", food: { favourite: "bamboo" } },
    { name: "Bao", food: { favourite: "apples" }, zoo: "Edinburgh" },
  ],
});
// "[Mei eats bamboo in Chengdu][Bao eats apples in Edinburgh]"

render(template, { pandas: [] });                         // "No pandas yet."
render("{{#tags}}{{.}}; {{/tags}}", { tags: ["cute", "sleepy"] });  // "cute; sleepy; "
render("{{#vip}}VIP {{name}}{{/vip}}", { vip: { name: "Lin" } });   // "VIP Lin"
render("{{#a}}oops{{/b}}", {});                           // SyntaxError: Unexpected closing tag "b"
```

<Hint>

Do it in two steps. First **parse**: find the tags with a regular expression such as `/\{\{\s*([#^/]?)\s*([^{}]*?)\s*\}\}/g` and `template.matchAll`, and build a tree. Keep a stack of open sections: text and value tags go into the children of the section on top, `#`/`^` tags push a new section, and `/` tags pop it (after checking the name).

</Hint>

<Hint>

Then **render** the tree with a recursive function that takes a list of nodes and the stack of current items (an array, `[data]` at first). For an array section, call it once per item with `[...contexts, item]`. Write the lookup as its own function that walks the stack from the top down.

</Hint>

<Solution>

```js
const TAG = /\{\{\s*([#^/]?)\s*([^{}]*?)\s*\}\}/g;

// Step 1: turn the template into a tree of text, values and sections.
function parse(template) {
  const root = { children: [] };
  const open = [root];
  let last = 0;
  for (const match of template.matchAll(TAG)) {
    const [whole, kind, path] = match;
    const current = open.at(-1);
    if (match.index > last) current.children.push(template.slice(last, match.index));
    last = match.index + whole.length;
    if (kind === "#" || kind === "^") {
      const section = { path, inverted: kind === "^", children: [] };
      current.children.push(section);
      open.push(section);
    } else if (kind === "/") {
      if (open.length === 1 || current.path !== path) {
        throw new SyntaxError(`Unexpected closing tag "${path}"`);
      }
      open.pop();
    } else {
      current.children.push({ path });
    }
  }
  if (open.length > 1) throw new SyntaxError(`Unclosed section "${open.at(-1).path}"`);
  if (last < template.length) root.children.push(template.slice(last));
  return root;
}

function lookup(path, contexts) {
  if (path === ".") return contexts.at(-1);
  const [first, ...rest] = path.split(".");
  for (let i = contexts.length - 1; i >= 0; i--) {
    const context = contexts[i];
    if (context !== null && typeof context === "object" && first in context) {
      let value = context[first];
      for (const key of rest) value = value?.[key];
      return value;
    }
  }
  return undefined;
}

// Step 2: render the tree with a stack of current items.
function renderNodes(nodes, contexts) {
  let out = "";
  for (const node of nodes) {
    if (typeof node === "string") {
      out += node;
      continue;
    }
    const value = lookup(node.path, contexts);
    if (!node.children) {
      out += value === undefined || value === null ? "" : String(value);
      continue;
    }
    const empty = !value || (Array.isArray(value) && value.length === 0);
    if (node.inverted) {
      if (empty) out += renderNodes(node.children, contexts);
    } else if (Array.isArray(value)) {
      for (const item of value) out += renderNodes(node.children, [...contexts, item]);
    } else if (!empty) {
      out += renderNodes(node.children, [...contexts, value]);
    }
  }
  return out;
}

function render(template, data) {
  return renderNodes(parse(template).children, [data]);
}

console.log(render("Hi {{ name }}!", { name: "Mei" })); // Hi Mei!
```

Splitting the work into parsing and rendering keeps both halves simple: the parser only has to match opening and closing tags with a stack, and the renderer is a recursive walk over the tree that carries the stack of current items. Lookups search that stack from the top, which is what lets a loop item fall back to outer values. Parsing is O(n) in the template's length, and rendering is proportional to the size of the output.

</Solution>
