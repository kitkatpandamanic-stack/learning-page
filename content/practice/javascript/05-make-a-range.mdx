JavaScript has no built-in `range()`, so let's write one. Write a function `range(start, end, step)` that returns an array of numbers, starting at `start` and moving by `step` each time, stopping **before** it reaches `end` (`end` itself is never included).

- `step` is optional and defaults to `1`.
- If `range` is called with only one argument, that argument is the `end` and `start` is `0`: `range(4)` is `[0, 1, 2, 3]`.
- A negative `step` counts down: `range(5, 0, -2)` is `[5, 3, 1]`.
- If the step points the wrong way (for example counting up from 5 to 1), or `step` is `0`, return an empty array.

```js
range(4);         // [ 0, 1, 2, 3 ]
range(2, 6);      // [ 2, 3, 4, 5 ]
range(0, 10, 3);  // [ 0, 3, 6, 9 ]
range(5, 0, -2);  // [ 5, 3, 1 ]
range(5, 1);      // []
range(1, 5, 0);   // []
```

<Hint>

<Hint>

If `end === undefined`, the real end is `start` and the real start is `0`. For a positive step, loop `for (let i = start; i < end; i += step)`; for a negative step the condition flips to `i > end`. A step of `0` gets no loop at all, so you return `[]`. Wrong-way ranges need no special code: their loop never runs.

</Hint>

<Solution>

```js
function range(start, end, step = 1) {
  if (end === undefined) {
    end = start;
    start = 0;
  }
  const numbers = [];
  if (step > 0) {
    for (let i = start; i < end; i += step) numbers.push(i);
  } else if (step < 0) {
    for (let i = start; i > end; i += step) numbers.push(i);
  }
  return numbers;
}

console.log(range(2, 6)); // [ 2, 3, 4, 5 ]
```

Two loops, one for each direction, and no loop at all for a step of `0` (which would otherwise run forever). A range that points the wrong way fails its loop condition straight away, so it comes back empty.

</Solution>
