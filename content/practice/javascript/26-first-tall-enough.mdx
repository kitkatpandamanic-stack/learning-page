The bamboo plantation keeps a list of stalk heights sorted from shortest to tallest, and it can be **huge**. A panda wants the first stalk that is at least `min` centimetres tall. Write `firstAtLeast(heights, min)` that returns its index.

- `heights` is sorted in ascending order and may contain the same height several times. Return the index of the **first** item that is `>= min`.
- If every item is shorter than `min` (or the array is empty), return `heights.length`, which is where `min` would be inserted.
- Reading items one by one is too slow for a million stalks. Use **binary search**: your function may look at no more than 25 items of the array, even when it has a million.

```js
const heights = [3, 8, 8, 8, 15, 21];
firstAtLeast(heights, 8);    // 1 (the first of the 8s)
firstAtLeast(heights, 9);    // 4
firstAtLeast(heights, 1);    // 0
firstAtLeast(heights, 99);   // 6 (nothing is tall enough)
firstAtLeast([], 5);         // 0
```

Finish `firstAtLeast(heights, min)` with a binary search.

<Hint>

Keep two indexes, `low = 0` and `high = heights.length`, with the answer always somewhere in `low..high`. Look at the middle item: if it's shorter than `min`, the answer is to its right (`low = mid + 1`); otherwise the middle item itself could be the answer (`high = mid`).

</Hint>

<Hint>

Stop when `low === high`: that's the answer. Use `Math.floor((low + high) / 2)` for the middle, and don't stop early when you find an item equal to `min`, because there may be an equal one further left.

</Hint>

<Solution>

```js
function firstAtLeast(heights, min) {
  let low = 0;
  let high = heights.length;
  while (low < high) {
    const mid = Math.floor((low + high) / 2);
    if (heights[mid] < min) {
      low = mid + 1;
    } else {
      high = mid;
    }
  }
  return low;
}

console.log(firstAtLeast([3, 8, 8, 8, 15, 21], 9)); // 4
```

The answer always stays between `low` and `high`, and every step halves that window, so a million items need only about 20 looks: O(log n). Moving `high` to `mid` (not `mid - 1`) on a match is what finds the first of several equal heights.

</Solution>
