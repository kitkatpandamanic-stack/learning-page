Three pandas share 10 bamboo shoots equally. That's 3⅓ each, but you can't cut a shoot. Someone gets 4 and the others get 3. Write a function `shareOut(total, weights)` that splits `total` items (a whole number, 0 or more) between people according to their `weights` (whole numbers, 0 or more, at least one of them above 0), and returns an array with each person's share:

1. Each person's **exact** share is `total × weight ÷ (sum of all weights)`. First give everyone that share rounded **down**.
2. Some items are left over. Hand them out **one each** to the people whose exact share had the biggest leftover fraction (the part after the decimal point).
3. If two people have the same fraction, the one who comes **first** in the array gets the item first.

The shares are whole numbers and always add up to exactly `total`. Someone with weight 0 gets 0.

```js
shareOut(10, [1, 1, 1]);       // [ 4, 3, 3 ]
shareOut(7, [2, 1]);           // [ 5, 2 ]   (exact: 4.67 and 2.33)
shareOut(100, [50, 30, 20]);   // [ 50, 30, 20 ]
shareOut(11, [3, 3, 3, 1]);    // [ 4, 3, 3, 1 ]
shareOut(5, [0, 2, 0]);        // [ 0, 5, 0 ]
```

Tip: rounding errors can make fractions that should be equal look slightly different (`0.1 + 0.2` is `0.30000000000000004`). Because the weights are whole numbers, you can compare **remainders** instead: `(total * weight) % sum` is a whole number, and it's exactly the leftover fraction times `sum`.

Finish `shareOut(total, weights)` so it splits `total` fairly by the weights.

<Hint>

Work out `sum` of the weights. For each person, `Math.floor(total * weight / sum)` is their rounded-down share and `(total * weight) % sum` is their remainder. The number of leftover items is `total` minus the sum of the rounded-down shares.

</Hint>

<Hint>

Make a list of the indexes `[0, 1, 2, …]` and sort it by remainder, biggest first: `.sort((a, b) => rem[b] - rem[a])`. JavaScript's sort is stable, so equal remainders keep their original order. Then give one extra item to the first `leftover` indexes in that list.

</Hint>

<Solution>

```js
function shareOut(total, weights) {
  const sum = weights.reduce((a, b) => a + b, 0);
  const shares = weights.map((w) => Math.floor((total * w) / sum));
  const remainders = weights.map((w) => (total * w) % sum);
  let leftover = total - shares.reduce((a, b) => a + b, 0);

  const order = weights.map((_, i) => i);
  order.sort((a, b) => remainders[b] - remainders[a]);
  for (const i of order) {
    if (leftover === 0) break;
    shares[i]++;
    leftover--;
  }
  return shares;
}

console.log(shareOut(10, [1, 1, 1])); // [ 4, 3, 3 ]
```

This is the **largest remainder method** (used to share out seats in some elections). Rounding down can only lose less than one item per person, so there are always fewer leftovers than people, and comparing whole-number remainders avoids floating-point surprises. Sorting the indexes makes it O(n log n) for n people.

</Solution>

</Exercise>
