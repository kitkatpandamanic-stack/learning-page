Покупатели то и дело вводят в поиск магазина панд «bambo» и «pnada». Напишите две функции, на которых будет работать подсказка «Вы имели в виду…?». Словарь магазина — на английском, и мы оставим слова как есть: от регистра и алфавитного порядка здесь зависит результат.

**`editDistance(a, b)`** возвращает наименьшее число правок по одному символу, которые превращают строку `a` в строку `b`. Правка — это вставка одного символа, удаление одного символа или замена одного символа другим. Заглавные и строчные буквы здесь — разные символы. Строки могут быть длиной до **2000 символов**, поэтому перебирать все возможные серии правок слишком медленно: используйте динамическое программирование (dynamic programming), O(len(a) × len(b)).

**`suggest(word, dictionary, maxDistance = 2)`** возвращает слова из словаря, близкие к `word`:

- Сравнивайте версии `word` и каждого слова словаря **в нижнем регистре**, но возвращайте слова в том написании, в каком они записаны в словаре.
- Оставляйте слова, расстояние до которых не больше `maxDistance` (точное совпадение имеет расстояние `0` и остаётся).
- Сортируйте их по расстоянию, начиная с самых близких. Слова с одинаковым расстоянием сортируйте по алфавиту через `<` (поэтому заглавные буквы идут раньше строчных).
- Слово, которое встречается в словаре несколько раз (с точно таким же написанием), выводится только один раз.

```js
editDistance("kitten", "sitting");    // 3 (k→s, e→i, добавить g)
editDistance("panda", "pandas");      // 1
editDistance("Bao", "bao");           // 1
editDistance("", "abc");              // 3

const dictionary = ["bamboo", "banana", "bambi", "bamboos", "panda", "Panda", "band", "bam"];
suggest("bambo", dictionary);         // ["bambi", "bamboo", "bam", "bamboos"]
suggest("PANDA", dictionary);         // ["Panda", "panda", "band"]
suggest("xyz", dictionary);           // []
```

<Hint>

Пусть `d[i][j]` — расстояние между первыми `i` символами `a` и первыми `j` символами `b`, причём `d[i][0] = i` и `d[0][j] = j`. Каждая другая клетка — наименьшее из `d[i-1][j] + 1` (удаление), `d[i][j-1] + 1` (вставка) и `d[i-1][j-1]` плюс `0` или `1` в зависимости от того, верно ли `a[i-1] === b[j-1]` (замена). Каждой строке нужна только строка над ней, так что хватит двух массивов.   let previous = Array.from({ length: b.length + 1 }, (_, j) => j);
  for (let i = 1; i <= a.length; i++) {
    const row = [i];
    for (let j = 1; j <= b.length; j++) {
      row[j] = ...; // наименьшее из удаления, вставки и замены

В `suggest` превратите каждое слово через `map` в `{ entry, distance }`, затем сделайте `filter`, `sort` и снова `map` обратно к словам.

<Solution>

```js
function editDistance(a, b) {
  let previous = Array.from({ length: b.length + 1 }, (_, j) => j);
  for (let i = 1; i <= a.length; i++) {
    const row = [i];
    for (let j = 1; j <= b.length; j++) {
      const replace = previous[j - 1] + (a[i - 1] === b[j - 1] ? 0 : 1);
      row[j] = Math.min(previous[j] + 1, row[j - 1] + 1, replace);
    }
    previous = row;
  }
  return previous[b.length];
}

function suggest(word, dictionary, maxDistance = 2) {
  const target = word.toLowerCase();
  return [...new Set(dictionary)]
    .map((entry) => ({ entry, distance: editDistance(target, entry.toLowerCase()) }))
    .filter(({ distance }) => distance <= maxDistance)
    .sort((x, y) => {
      if (x.distance !== y.distance) return x.distance - y.distance;
      return x.entry < y.entry ? -1 : x.entry > y.entry ? 1 : 0;
    })
    .map(({ entry }) => entry);
}

console.log(editDistance("kitten", "sitting")); // 3
console.log(suggest("bambo", ["bamboo", "banana", "bambi"])); // [ 'bambi', 'bamboo' ]
```

Это **расстояние Левенштейна** (Levenshtein distance), классическая задача динамического программирования: каждая клетка таблицы строится из трёх уже посчитанных соседей, поэтому вся таблица занимает O(len(a) × len(b)) времени вместо экспоненциального времени перебора всех последовательностей правок. Хранение только предыдущей строки сокращает память до O(len(b)).

</Solution>
