The bamboo-delivery server is a bit flaky: sometimes a request fails, and trying again a moment later works. Write an async function `retry(task, options)` that keeps trying.

- `task(attempt)` is a function that returns a promise (or a plain value). `attempt` is the try number, starting at `1`. If `task` throws instead of returning, that counts as a failure too.
- As soon as a try succeeds, `retry` resolves with its value.
- After a failure, if tries are left, `retry` waits and tries again. The first wait is `delay` ms, and each wait after that is **twice** the one before: 100, 200, 400, …
- After `attempts` failed tries, `retry` rejects with the error from the **last** try, without waiting again first.
- `options` is an object with `attempts` (default `3`), `delay` (default `100`) and `wait`: the function to call for waiting. `wait(ms)` returns a promise that resolves after `ms` milliseconds; by default it's a promise around `setTimeout`. Always wait by calling `wait`, so that tests can pass in a fake one.
- If `attempts` is less than 1, reject with a `RangeError` without calling `task`.

```js
let calls = 0;
const flaky = async () => {
  calls++;
  if (calls < 3) throw new Error("Server busy");
  return "🎋 delivered";
};

await retry(flaky, { delay: 50 });   // "🎋 delivered", after waiting 50 then 100 ms

await retry(() => Promise.reject(new Error("Down")), { attempts: 2 });
// rejects with Error("Down") after one wait of 100 ms
```

<Hint>

A loop over the attempts with `try`/`catch` inside fits well here. Watch out: a rejected promise only lands in your `catch` if you `await` it inside the `try`.

</Hint>

<Hint>

Throw a `RangeError` first if `attempts` is less than 1. Then loop `attempt` from `1` to `attempts`: in the `try`, `return await task(attempt)`; in the `catch`, remember the error and, unless this was the last try, `await wait(delay * 2 ** (attempt - 1))`. After the loop, `throw` the error you remembered: inside an `async` function, throwing rejects the promise.

</Hint>

<Solution>

```js
const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

async function retry(task, { attempts = 3, delay = 100, wait = sleep } = {}) {
  if (attempts < 1) throw new RangeError("attempts must be at least 1");
  let lastError;
  for (let attempt = 1; attempt <= attempts; attempt++) {
    try {
      return await task(attempt);
    } catch (error) {
      lastError = error;
      if (attempt < attempts) await wait(delay * 2 ** (attempt - 1));
    }
  }
  throw lastError;
}

let calls = 0;
const flaky = async () => {
  calls++;
  if (calls < 3) throw new Error("Server busy");
  return "delivered";
};
console.log(await retry(flaky, { delay: 10 })); // delivered
```

`return await` inside the `try` is important: it makes a rejected promise throw right there, so the `catch` sees it (a plain `return task(attempt)` would skip the `catch`). The waits double after each failure, which is called **exponential backoff**, and gives a struggling server more and more breathing room.

</Solution>
