Every compiler and code editor starts by chopping source code into **tokens**, the "words" of a programming language. Write `tokenize(source)` for a small JavaScript-like language. It returns an array of tokens shaped like `{ type, value, pos }`, where `pos` is the index in `source` of the token's first character.

- Spaces, tabs and newlines separate tokens and are skipped. `//` starts a comment that runs to the end of the line; it is skipped too.
- **`"number"`**: one or more digits, optionally followed by a `.` and one or more digits (`12`, `3.25`). Its `value` is a JavaScript number. A `.` that isn't followed by a digit is not part of the number: `7.` is the number `7` and then a `.`.
- **`"name"`**: starts with a letter (`a`–`z`, `A`–`Z`), `_` or `$`, followed by any number of those or digits. `2items` is the number `2` and then the name `items`.
- **`"string"`**: text between double quotes. A backslash takes the next character literally (`\"` is a quote, `\\` is a backslash), except `\n`, which is a newline. The `value` is the text without the quotes, with the escapes applied. If the source ends before the closing quote, throw a `SyntaxError` with the message `Unterminated string at <pos>`, using the position of the opening quote.
- **`"operator"`**: the **longest** of `===` `!==` `==` `!=` `<=` `>=` `=>` `&&` `||` `+` `-` `*` `/` `%` `=` `<` `>` `!` that matches, so `a===b` gives `===`, not `==` and `=`. Its `value` is the operator text.
- **`"punct"`**: one of `(` `)` `{` `}` `[` `]` `,` `;` `.` `:`.
- Any other character throws a `SyntaxError` with the message `Unexpected character "<char>" at <pos>`.

```js
tokenize('bao.eat("bamboo", 1.5)');
// [
//   { type: "name",     value: "bao",    pos: 0 },
//   { type: "punct",    value: ".",      pos: 3 },
//   { type: "name",     value: "eat",    pos: 4 },
//   { type: "punct",    value: "(",      pos: 7 },
//   { type: "string",   value: "bamboo", pos: 8 },
//   { type: "punct",    value: ",",      pos: 16 },
//   { type: "number",   value: 1.5,      pos: 18 },
//   { type: "punct",    value: ")",      pos: 21 },
// ]

tokenize("x >= 10 // big enough");  // name x, operator >=, number 10
tokenize("let x = 5 @ 3");          // SyntaxError: Unexpected character "@" at 10
tokenize('say("oops)');             // SyntaxError: Unterminated string at 4
```

<Hint>

Walk through the source with an index `i` in a `while (i < source.length)` loop. Look at the character at `i` to decide what kind of token starts there, then move `i` forward over the whole token. Remember `const start = i` first, because that's the token's `pos`.

</Hint>

<Hint>

Check for `//` before the operators, so a comment isn't read as two `/` operators. For operators, put the list in order from longest to shortest and take the first one where `source.startsWith(op, i)` is true. For strings, build the value character by character, and when you see a backslash, handle the character after it and skip both.

</Hint>

<Solution>

```js
const OPERATORS = ["===", "!==", "==", "!=", "<=", ">=", "=>", "&&", "||",
  "+", "-", "*", "/", "%", "=", "<", ">", "!"];
const PUNCTUATION = "(){}[],;.:";

const isDigit = (c) => c !== undefined && c >= "0" && c <= "9";
const isNameStart = (c) => c !== undefined && /[A-Za-z_$]/.test(c);
const isNamePart = (c) => isNameStart(c) || isDigit(c);

function tokenize(source) {
  const tokens = [];
  let i = 0;
  while (i < source.length) {
    const c = source[i];
    const start = i;
    if (c === " " || c === "\t" || c === "\n" || c === "\r") {
      i++;
    } else if (source.startsWith("//", i)) {
      while (i < source.length && source[i] !== "\n") i++;
    } else if (isDigit(c)) {
      while (isDigit(source[i])) i++;
      if (source[i] === "." && isDigit(source[i + 1])) {
        i++;
        while (isDigit(source[i])) i++;
      }
      tokens.push({ type: "number", value: Number(source.slice(start, i)), pos: start });
    } else if (isNameStart(c)) {
      while (isNamePart(source[i])) i++;
      tokens.push({ type: "name", value: source.slice(start, i), pos: start });
    } else if (c === '"') {
      let value = "";
      i++;
      while (source[i] !== '"') {
        if (i >= source.length) throw new SyntaxError(`Unterminated string at ${start}`);
        if (source[i] === "\\" && i + 1 < source.length) {
          value += source[i + 1] === "n" ? "\n" : source[i + 1];
          i += 2;
        } else {
          value += source[i];
          i++;
        }
      }
      i++; // the closing quote
      tokens.push({ type: "string", value, pos: start });
    } else {
      const op = OPERATORS.find((o) => source.startsWith(o, i));
      if (op) {
        tokens.push({ type: "operator", value: op, pos: start });
        i += op.length;
      } else if (PUNCTUATION.includes(c)) {
        tokens.push({ type: "punct", value: c, pos: start });
        i++;
      } else {
        throw new SyntaxError(`Unexpected character "${c}" at ${start}`);
      }
    }
  }
  return tokens;
}

console.log(tokenize("x >= 10"));
```

The tokenizer is a loop where the first character of each token decides which small "sub-loop" reads the rest of it. Taking the longest operator first (often called **maximal munch**) is what makes `===` one token. Each character is looked at a constant number of times, so it runs in O(n).

</Solution>
