A panda keeper writes down how many kilos of bamboo Mei eats each day. Now she wants to know which stretch of `size` days in a row had the most bamboo in total.

Write a function `bestStretch(kilos, size)` that returns the **index of the first day** of that stretch.

- A stretch is `size` days next to each other: with `size` 3, days 0–2, days 1–3, days 2–4 and so on.
- If two stretches have the same total, return the earlier one.
- If `size` is less than 1, or bigger than the number of days, there is no stretch: return `-1`.

```js
bestStretch([3, 8, 2, 9, 7, 1], 2); // 3  (9 + 7 = 16 is the best pair)
bestStretch([3, 8, 2, 9, 7, 1], 3); // 1  (8 + 2 + 9 = 19)
bestStretch([5, 1, 5, 1], 2);       // 0  (all pairs total 6: the first wins)
bestStretch([4, 2], 5);             // -1
```

Finish `bestStretch(kilos, size)` so it returns where the best stretch starts.

<Hint>

The stretches start at index `0` up to index `kilos.length - size`. For each start, add up the `size` numbers from there (`kilos.slice(start, start + size)` gives you exactly those days).

</Hint>

<Hint>

Keep the best total and its start in two variables. Only replace them when a total is **strictly** bigger, so ties keep the earlier stretch. Start the best total at `-Infinity`, not `0`, or a list of negative numbers won't work.

</Hint>

<Solution>

```js
function bestStretch(kilos, size) {
  if (size < 1 || size > kilos.length) return -1;
  let bestStart = -1;
  let bestTotal = -Infinity;
  for (let start = 0; start + size <= kilos.length; start++) {
    let total = 0;
    for (let i = start; i < start + size; i++) total += kilos[i];
    if (total > bestTotal) {
      bestTotal = total;
      bestStart = start;
    }
  }
  return bestStart;
}

console.log(bestStretch([3, 8, 2, 9, 7, 1], 2)); // 3
```

Each start position gets its own total, and `>` (not `>=`) keeps the earliest stretch on a tie. A faster trick is the **sliding window**: when you move one day along, add the new day and subtract the one that dropped off, instead of adding the whole stretch up again.

</Solution>

</Exercise>
