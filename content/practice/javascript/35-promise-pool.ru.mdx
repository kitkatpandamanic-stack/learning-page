Бамбуковой ферме нужно отправить сотни доставок, а грузовиков всего несколько. `Promise.all` отправил бы их все сразу, поэтому напишите `runWithLimit(tasks, limit)`, которая запускает асинхронные задачи так, чтобы **одновременно работало не больше `limit`**.

- `tasks` — массив функций. Вызов задачи запускает её, и она возвращает промис (promise) или обычное значение. Запускайте задачи в порядке массива.
- Первые `limit` задач стартуют **сразу**, ещё до того, как `runWithLimit` вернёт результат. После этого, как только **любая** запущенная задача завершается, стартует следующая ожидающая. Не ждите, пока закончится вся группа.
- `runWithLimit` возвращает промис массива с результатами всех задач **в том же порядке, что и `tasks`**, а не в порядке завершения.
- Если задача падает (её промис отклоняется или её вызов выбрасывает ошибку), возвращённый промис отклоняется с этой ошибкой и **новые задачи больше не запускаются**. Уже запущенные задачи не трогаем.
- Пустой массив `tasks` даёт `[]`. Если `limit` — не целое число не меньше 1, промис отклоняется с `RangeError`, ничего не запуская.

```js
const wait = (ms, value) => new Promise((resolve) => setTimeout(() => resolve(value), ms));

const deliveries = [
  () => wait(300, "🎋 к северным воротам"),
  () => wait(100, "🎋 в детскую"),
  () => wait(100, "🎋 на кухню"),
  () => wait(100, "🎋 к ветеринару"),
];

await runWithLimit(deliveries, 2);
// ["🎋 к северным воротам", "🎋 в детскую", "🎋 на кухню", "🎋 к ветеринару"]
// Грузовик из детской возвращается через 100 мс, и тогда стартует доставка на кухню,
// а доставка к ветеринару — через 200 мс: всё готово через 300 мс.
```

<Hint>

Представьте `limit` рабочих: каждый запускает задачу и, как только она завершится, берёт следующую из ожидающих. Результаты нужно вернуть в порядке задач, а не в порядке завершения — куда тогда сохранять каждый результат?

</Hint>

<Hint>

Верните `new Promise((resolve, reject) => { ... })` и при неправильном `limit` сразу отклоните его с `RangeError`. Держите счётчик `next` — индекс следующей задачи — и напишите `startNext()`: она запускает `tasks[next]`, увеличивает `next`, а когда задача завершится, сохраняет результат по её собственному индексу и снова вызывает `startNext()`. Оборачивайте каждый вызов в `new Promise((res) => res(tasks[index]()))` — тогда и возвращённое значение, и выброшенная ошибка становятся промисом. Считайте завершённые задачи, чтобы знать, когда вызвать `resolve(results)`, при первой ошибке ставьте флаг `failed`, чтобы новые задачи не запускались, а для пустого списка сразу верните `[]`. Для начала вызовите `startNext()` `Math.min(limit, tasks.length)` раз.

</Hint>

<Solution>

```js
function runWithLimit(tasks, limit) {
  return new Promise((resolve, reject) => {
    if (!Number.isInteger(limit) || limit < 1) {
      reject(new RangeError("limit должно быть целым числом не меньше 1"));
      return;
    }
    const results = new Array(tasks.length);
    let next = 0;
    let finished = 0;
    let failed = false;

    const startNext = () => {
      if (failed || next >= tasks.length) return;
      const index = next++;
      new Promise((res) => res(tasks[index]())).then(
        (value) => {
          results[index] = value;
          finished++;
          if (finished === tasks.length) resolve(results);
          else startNext();
        },
        (error) => {
          failed = true;
          reject(error);
        },
      );
    };

    if (tasks.length === 0) resolve(results);
    for (let i = 0; i < Math.min(limit, tasks.length); i++) startNext();
  });
}

const wait = (ms, value) => new Promise((resolve) => setTimeout(() => resolve(value), ms));
const tasks = [() => wait(30, "a"), () => wait(10, "b"), () => wait(10, "c")];
console.log(await runWithLimit(tasks, 2)); // [ 'a', 'b', 'c' ]
```

Представьте `limit` работников: каждый запускает задачу и, когда она готова, берёт следующую по общему счётчику `next`, так что освободившееся место сразу занимается. Результаты сохраняются по индексу — поэтому они идут в порядке задач, в каком бы порядке те ни завершались, — а флаг `failed` останавливает новые запуски после первой ошибки.

</Solution>

</Exercise>
