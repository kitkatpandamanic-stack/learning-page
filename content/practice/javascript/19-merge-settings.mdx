An app has default settings, and each user overrides some of them. Spread (`{ ...defaults, ...user }`) only merges the top level: a user who changes one colour would lose all the other colours. Write a function `mergeSettings(defaults, overrides)` that merges **deeply** and returns a new object:

- The result has every key from both objects.
- If a key holds a **plain object** in both (something like `{ … }`: not an array, not `null`), the two are merged in the same way, all the way down.
- Otherwise, the value from `overrides` wins. That includes arrays (they replace, they are not merged), `null`, and an object replacing a plain value or the other way round.
- A key whose value in `overrides` is `undefined` is ignored: the default stays.
- Neither input may change, and every plain object in the result must be **new**: changing `result.theme.colors.bg` must not change `defaults`.

```js
const defaults = {
  theme: { mode: "light", colors: { bg: "white", text: "black" } },
  sounds: true,
  shortcuts: ["ctrl+s"],
};
const user = {
  theme: { colors: { bg: "bamboo-green" } },
  shortcuts: ["cmd+s"],
  sounds: undefined,
};

mergeSettings(defaults, user);
// {
//   theme: { mode: 'light', colors: { bg: 'bamboo-green', text: 'black' } },
//   sounds: true,
//   shortcuts: [ 'cmd+s' ]
// }
```

<Hint>

Merge the two objects key by key, and when both sides of a key are plain objects, merge those the same way. That's a job for recursion. How will you tell a plain object apart from an array or `null`?

</Hint>

<Solution>

```js
function isPlainObject(value) {
  return typeof value === "object" && value !== null && !Array.isArray(value);
}

function mergeSettings(defaults, overrides) {
  const result = {};
  for (const [key, value] of Object.entries(defaults)) {
    result[key] = isPlainObject(value) ? mergeSettings(value, {}) : value;
  }
  for (const [key, value] of Object.entries(overrides)) {
    if (value === undefined) continue;
    if (isPlainObject(value)) {
      const base = isPlainObject(result[key]) ? result[key] : {};
      result[key] = mergeSettings(base, value);
    } else {
      result[key] = value;
    }
  }
  return result;
}

const defaults = {
  theme: { mode: "light", colors: { bg: "white", text: "black" } },
  sounds: true,
  shortcuts: ["ctrl+s"],
};
const user = { theme: { colors: { bg: "bamboo-green" } }, shortcuts: ["cmd+s"], sounds: undefined };
console.log(mergeSettings(defaults, user));
```

The function calls itself for every pair of plain objects, so it works at any depth, and it always builds into a brand-new `result`, which is why nothing is shared with the inputs. Merging an override object into `{}` copies it, so objects from `overrides` are new too. Every key is visited once per level, so it's O(total number of keys).

</Solution>
