The bamboo shop's search page puts the shopper's choices in the URL, like `?q=red+panda&size=s&size=m`. Write `parseQuery(query)` that turns such a query string into an object, without using `URLSearchParams`.

- A leading `?` is ignored. Pairs are separated by `&`, and empty pieces (from `&&` or a trailing `&`) are skipped.
- Each pair is split at its **first** `=`: the part before is the key, everything after is the value (it may contain more `=` signs). A piece without `=` is a key with the value `""`.
- In keys and values, first turn every `+` into a space, then decode `%XX` escapes with `decodeURIComponent`. If a part can't be decoded (like `100%`), keep it as it is after the `+` step.
- A key that appears once gets a string. A key that appears more than once gets an array of all its values, in order.
- Keys appear in the object in the order they first show up in the query.

```js
parseQuery("?q=red+panda&page=2");
// { q: "red panda", page: "2" }

parseQuery("size=s&size=m&size=l");
// { size: ["s", "m", "l"] }

parseQuery("name=Mei%20Ling&pet=%F0%9F%90%BC&sum=1%2B1");
// { name: "Mei Ling", pet: "🐼", sum: "1+1" }

parseQuery("debug&filter=a=b&&");
// { debug: "", filter: "a=b" }

parseQuery("");  // {}
```

Finish `parseQuery(query)`.

<Hint>

`query.split("&")` gives the pieces. For each one, `piece.indexOf("=")` finds the first `=`, and `slice` gives the parts before and after it. Write a small `decode(text)` helper that does the `+` replacement and wraps `decodeURIComponent` in `try`/`catch`.

</Hint>

<Hint>

When a key is already in the result, turn its value into an array the first time (`[result[key], value]`) and `push` onto it after that. `Array.isArray` tells you which case you're in.

</Hint>

<Solution>

```js
function decode(text) {
  const spaced = text.replaceAll("+", " ");
  try {
    return decodeURIComponent(spaced);
  } catch {
    return spaced;
  }
}

function parseQuery(query) {
  const result = {};
  const text = query.startsWith("?") ? query.slice(1) : query;
  for (const piece of text.split("&")) {
    if (piece === "") continue;
    const at = piece.indexOf("=");
    const key = decode(at === -1 ? piece : piece.slice(0, at));
    const value = at === -1 ? "" : decode(piece.slice(at + 1));
    if (!Object.hasOwn(result, key)) result[key] = value;
    else if (Array.isArray(result[key])) result[key].push(value);
    else result[key] = [result[key], value];
  }
  return result;
}

console.log(parseQuery("?q=red+panda&page=2")); // { q: 'red panda', page: '2' }
```

Each piece is split once at its first `=`, and both halves go through the same `decode` helper. Replacing `+` before decoding matters: an encoded plus (`%2B`) must stay a real `+`. The whole thing is one pass over the query, O(n).

</Solution>
