Любой компилятор и любой редактор кода начинают с того, что нарезают исходный код на **токены** (tokens) — «слова» языка программирования. Напишите `tokenize(source)` для небольшого языка, похожего на JavaScript. Функция возвращает массив токенов вида `{ type, value, pos }`, где `pos` — индекс первого символа токена в `source`.

- Пробелы, табуляции и переводы строк разделяют токены и пропускаются. `//` начинает комментарий до конца строки; он тоже пропускается.
- **`"number"`** (число): одна или несколько цифр, за которыми может идти `.` и ещё одна или несколько цифр (`12`, `3.25`). Его `value` — число JavaScript. `.`, за которой не идёт цифра, не входит в число: `7.` — это число `7`, а затем `.`.
- **`"name"`** (имя): начинается с буквы (`a`–`z`, `A`–`Z`), `_` или `$`, за которыми идёт сколько угодно таких же символов или цифр. `2items` — это число `2`, а затем имя `items`.
- **`"string"`** (строка): текст между двойными кавычками. Обратная косая черта берёт следующий символ буквально (`\"` — кавычка, `\\` — обратная косая черта), кроме `\n` — это перевод строки. `value` — текст без кавычек, с применёнными экранированиями. Если исходный код заканчивается раньше закрывающей кавычки, выбросьте `SyntaxError` с сообщением `Unterminated string at <pos>` («незакрытая строка на позиции `<pos>`»), где указана позиция открывающей кавычки.
- **`"operator"`** (оператор): **самый длинный** из подходящих `===` `!==` `==` `!=` `<=` `>=` `=>` `&&` `||` `+` `-` `*` `/` `%` `=` `<` `>` `!`, так что `a===b` даёт `===`, а не `==` и `=`. Его `value` — текст оператора.
- **`"punct"`** (знак препинания): один из `(` `)` `{` `}` `[` `]` `,` `;` `.` `:`.
- Любой другой символ выбрасывает `SyntaxError` с сообщением `Unexpected character "<char>" at <pos>` («неожиданный символ `"<char>"` на позиции `<pos>`»).

Сообщения об ошибках остаются на английском, как в настоящих инструментах.

```js
tokenize('bao.eat("bamboo", 1.5)');
// [
//   { type: "name",     value: "bao",    pos: 0 },
//   { type: "punct",    value: ".",      pos: 3 },
//   { type: "name",     value: "eat",    pos: 4 },
//   { type: "punct",    value: "(",      pos: 7 },
//   { type: "string",   value: "bamboo", pos: 8 },
//   { type: "punct",    value: ",",      pos: 16 },
//   { type: "number",   value: 1.5,      pos: 18 },
//   { type: "punct",    value: ")",      pos: 21 },
// ]

tokenize("x >= 10 // big enough");  // имя x, оператор >=, число 10
tokenize("let x = 5 @ 3");          // SyntaxError: Unexpected character "@" at 10
tokenize('say("oops)');             // SyntaxError: Unterminated string at 4
```

<Solution>

```js
const OPERATORS = ["===", "!==", "==", "!=", "<=", ">=", "=>", "&&", "||",
  "+", "-", "*", "/", "%", "=", "<", ">", "!"];
const PUNCTUATION = "(){}[],;.:";

const isDigit = (c) => c !== undefined && c >= "0" && c <= "9";
const isNameStart = (c) => c !== undefined && /[A-Za-z_$]/.test(c);
const isNamePart = (c) => isNameStart(c) || isDigit(c);

function tokenize(source) {
  const tokens = [];
  let i = 0;
  while (i < source.length) {
    const c = source[i];
    const start = i;
    if (c === " " || c === "\t" || c === "\n" || c === "\r") {
      i++;
    } else if (source.startsWith("//", i)) {
      while (i < source.length && source[i] !== "\n") i++;
    } else if (isDigit(c)) {
      while (isDigit(source[i])) i++;
      if (source[i] === "." && isDigit(source[i + 1])) {
        i++;
        while (isDigit(source[i])) i++;
      }
      tokens.push({ type: "number", value: Number(source.slice(start, i)), pos: start });
    } else if (isNameStart(c)) {
      while (isNamePart(source[i])) i++;
      tokens.push({ type: "name", value: source.slice(start, i), pos: start });
    } else if (c === '"') {
      let value = "";
      i++;
      while (source[i] !== '"') {
        if (i >= source.length) throw new SyntaxError(`Unterminated string at ${start}`);
        if (source[i] === "\\" && i + 1 < source.length) {
          value += source[i + 1] === "n" ? "\n" : source[i + 1];
          i += 2;
        } else {
          value += source[i];
          i++;
        }
      }
      i++; // закрывающая кавычка
      tokens.push({ type: "string", value, pos: start });
    } else {
      const op = OPERATORS.find((o) => source.startsWith(o, i));
      if (op) {
        tokens.push({ type: "operator", value: op, pos: start });
        i += op.length;
      } else if (PUNCTUATION.includes(c)) {
        tokens.push({ type: "punct", value: c, pos: start });
        i++;
      } else {
        throw new SyntaxError(`Unexpected character "${c}" at ${start}`);
      }
    }
  }
  return tokens;
}

console.log(tokenize("x >= 10"));
```

Токенизатор (tokenizer) — это цикл, в котором первый символ каждого токена решает, какой небольшой «вложенный цикл» прочитает остальное. Выбор самого длинного оператора (это часто называют **maximal munch** — «жадное поглощение») и делает `===` одним токеном. На каждый символ смотрят постоянное число раз, поэтому всё работает за O(n).

</Solution>
