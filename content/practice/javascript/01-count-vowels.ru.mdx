Напишите функцию (function) `countVowels(text)`, которая возвращает, сколько гласных (`a`, `e`, `i`, `o`, `u`) в строке `text`. Заглавные буквы тоже считаются, а всё остальное (пробелы, цифры, другие буквы) — нет.

```js
countVowels("Hello");         // 2
countVowels("JAVASCRIPT is"); // 4
countVowels("rhythm");        // 0
countVowels("");              // 0
```

<Hint>

Считаются и строчные, и заглавные гласные. Можно ли сначала привести весь текст к одному регистру, чтобы искать только `a`, `e`, `i`, `o` и `u`?

</Hint>

<Hint>

</Hint>

<Solution>

```js
function countVowels(text) {
  let count = 0;
  for (const char of text.toLowerCase()) {
    if ("aeiou".includes(char)) count++;
  }
  return count;
}

console.log(countVowels("Hello")); // 2
```

Короче можно отфильтровать массив символов: `[...text.toLowerCase()].filter((c) => "aeiou".includes(c)).length`.

</Solution>
