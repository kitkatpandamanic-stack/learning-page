Авторы блога панд пишут теги как попало: `" JavaScript "`, `"javascript"`, `"Machine   Learning"`. Напишите функцию (function) `cleanTags(tags)`, которая принимает массив (array) строк-тегов и возвращает новый, аккуратный массив:

1. Уберите пробелы в начале и в конце каждого тега.
2. Переведите тег в нижний регистр.
3. Замените каждую группу пробелов внутри тега одним дефисом: `"machine   learning"` превращается в `"machine-learning"`.
4. Пропустите теги, которые в итоге оказались пустыми.
5. Оставьте каждый тег только один раз — на том месте, где он встретился впервые.

Не изменяйте массив, который вам передали.

```js
cleanTags([" JavaScript ", "css", "javascript", "Machine   Learning", "", "CSS"]);
// [ 'javascript', 'css', 'machine-learning' ]

cleanTags(["   ", ""]); // []
cleanTags([]);          // []
```

<Solution>

```js
function cleanTags(tags) {
  const seen = new Set();
  for (const tag of tags) {
    const clean = tag
      .trim()
      .toLowerCase()
      .split(" ")
      .filter((part) => part !== "")
      .join("-");
    if (clean !== "") seen.add(clean);
  }
  return [...seen];
}

console.log(cleanTags([" JavaScript ", "css", "javascript", "Machine   Learning", "", "CSS"]));
// [ 'javascript', 'css', 'machine-learning' ]
```

Повторное добавление в `Set` ничего не делает, а порядок вставки `Set` сохраняет, поэтому, развернув его обратно в массив, вы получите каждый тег один раз — там, где он появился впервые. Шаг 3 можно сделать и одним регулярным выражением: `.replace(/ +/g, "-")`.

</Solution>
