Optional chaining (`a?.b?.c`) is great when you know the path while you write the code. Sometimes the path only arrives as text, for example from a settings file. Write a function `getPath(obj, path, fallback)` that follows a dotted path through nested objects and returns what it finds there.

- `path` is a string of keys separated by dots, like `"owner.address.city"`. Array positions are keys too: `"pandas.0.name"` is `obj.pandas[0].name`.
- If a step lands on `null` or `undefined` before the path ends, or the value at the end is `undefined`, return `fallback`. If no `fallback` is passed, that's `undefined`.
- Any other value at the end is returned as it is, **including** `0`, `""`, `false` and `null`.
- An empty path `""` returns `obj` itself.

```js
const zoo = {
  name: "Bamboo Park",
  owner: { name: "Sam", address: { city: "Leeds" } },
  pandas: [{ name: "Mei", age: 4 }, { name: "Bao", age: 0 }],
  manager: null,
};

getPath(zoo, "owner.address.city");          // 'Leeds'
getPath(zoo, "pandas.1.name");               // 'Bao'
getPath(zoo, "pandas.1.age", 99);            // 0
getPath(zoo, "owner.phone", "none");         // 'none'
getPath(zoo, "manager.name", "nobody");      // 'nobody'
getPath(zoo, "manager", "nobody");           // null
```

Finish `getPath(obj, path, fallback)` so it returns the value at the end of the path.

<Hint>

`path.split(".")` gives the list of keys. Walk through them with a `let current = obj`, doing `current = current[key]` for each. Bracket notation works for both object keys and array positions like `"1"`.

</Hint>

<Hint>

Before each step, check `if (current === null || current === undefined) return fallback;`. At the end, only an `undefined` value should become the fallback, so use `current === undefined ? fallback : current`, not `current || fallback` or `current ?? fallback`. Remember that `"".split(".")` is `[""]`, not `[]`.

</Hint>

<Solution>

```js
function getPath(obj, path, fallback) {
  if (path === "") return obj;
  let current = obj;
  for (const key of path.split(".")) {
    if (current === null || current === undefined) return fallback;
    current = current[key];
  }
  return current === undefined ? fallback : current;
}

const zoo = {
  name: "Bamboo Park",
  owner: { name: "Sam", address: { city: "Leeds" } },
  pandas: [{ name: "Mei", age: 4 }, { name: "Bao", age: 0 }],
  manager: null,
};

console.log(getPath(zoo, "owner.address.city")); // Leeds
```

This is optional chaining done by hand: stop early as soon as a step lands on `null` or `undefined`. Comparing with `=== undefined` at the end (rather than `||` or `??`) is what lets real values like `0`, `false` and `null` through.

</Solution>
