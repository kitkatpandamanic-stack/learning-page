Pandas stand in a line for the parade, all looking to the right. `heights[i]` is the height of panda `i`. Write `visibleCounts(heights)` that returns an array with, for each panda, **how many pandas to its right it can see**.

- Panda `i` can see panda `j` (with `j > i`) when every panda **between** them is strictly shorter than both of them, that is, shorter than `Math.min(heights[i], heights[j])`.
- Neighbours always see each other, since there's nobody in between.
- A panda of the same height or taller blocks the view of everyone behind it. So in `[5, 5, 5]` the first panda sees only the second.
- The last panda sees nobody (`0`), and an empty line gives `[]`.
- The line can hold **200,000** pandas, so checking every pair is too slow. Aim for O(n).

```js
visibleCounts([10, 6, 8, 5, 11, 9]);  // [3, 1, 2, 1, 1, 0]
visibleCounts([5, 5, 5]);             // [1, 1, 0]
visibleCounts([3, 1, 3, 1, 3]);       // [2, 1, 2, 1, 0]
visibleCounts([7]);                   // [0]
```

In the first example, the panda of height 10 sees 6 and 8 (6 is shorter than both), then 11 (6, 8 and 5 are all shorter than 10 and 11), and nothing after 11.

Finish `visibleCounts(heights)` so that it runs in O(n).

<Hint>

Go through the line from **right to left** and keep a stack of the pandas that could still be seen by someone further left. When panda `i` arrives, every shorter panda on top of the stack is visible to `i`, but hidden from everyone further left by `i` itself, so pop them and count them.

</Hint>

<Hint>

After popping the shorter ones, if the stack isn't empty, `i` also sees the panda now on top (it's at least as tall as `i`), so count one more. If that panda is exactly as tall as `i`, pop it too: `i` hides it from everyone further left. Then push `i`.

</Hint>

<Solution>

```js
function visibleCounts(heights) {
  const result = new Array(heights.length).fill(0);
  const stack = []; // heights still visible from the left, tallest at the bottom
  for (let i = heights.length - 1; i >= 0; i--) {
    const h = heights[i];
    let count = 0;
    while (stack.length > 0 && stack.at(-1) < h) {
      stack.pop();
      count++;
    }
    if (stack.length > 0) {
      count++;
      if (stack.at(-1) === h) stack.pop();
    }
    stack.push(h);
    result[i] = count;
  }
  return result;
}

console.log(visibleCounts([10, 6, 8, 5, 11, 9])); // [ 3, 1, 2, 1, 1, 0 ]
```

This is a **monotonic stack**: it always holds heights that strictly decrease from bottom to top, which are exactly the pandas someone further left might still see. Each panda is pushed once and popped at most once, so the whole line takes O(n), compared with O(n²) for checking every pair.

</Solution>
