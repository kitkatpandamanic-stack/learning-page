Red pandas like it cool, so the panda house has a smart thermostat. Write a class `Thermostat` that keeps its target temperature in a **private field**, so nobody can set it to something silly from the outside.

- `new Thermostat(target)` starts at `target`. A target must be a number between `10` and `30` (both included).
- The `target` getter returns the current target, and the `target` setter changes it. Anything that isn't a number (or is `NaN`) throws a `TypeError`, and a number outside 10–30 throws a `RangeError`. The constructor checks its argument the same way. A value that throws leaves the thermostat unchanged.
- `warmer(step = 0.5)` and `cooler(step = 0.5)` move the target up or down by `step`, but never past the limits: they stop at `30` or `10` instead of throwing. Both return the thermostat itself, so calls can be chained.
- The `history` getter returns an array of every target the thermostat has had, oldest first, starting with the one from the constructor. A value is only added when the target actually changes. Changing the returned array must not change the thermostat.
- The object has no public fields: `Object.keys(thermostat)` is `[]`.

```js
const t = new Thermostat(20);
t.warmer().warmer(2).cooler();
t.target;               // 22
t.warmer(20).target;    // 30 (stops at the limit)
t.target = 25;
t.history;              // [20, 20.5, 22.5, 22, 30, 25]
t.target = 40;          // RangeError
new Thermostat("21");   // TypeError
```

<Solution>

```js
class Thermostat {
  static MIN = 10;
  static MAX = 30;

  #target;
  #history = [];

  constructor(target) {
    this.target = target;
  }

  get target() {
    return this.#target;
  }

  set target(value) {
    if (typeof value !== "number" || Number.isNaN(value)) {
      throw new TypeError("The target must be a number");
    }
    if (value < Thermostat.MIN || value > Thermostat.MAX) {
      throw new RangeError("The target must be between 10 and 30");
    }
    this.#change(value);
  }

  warmer(step = 0.5) {
    this.#change(Math.min(Thermostat.MAX, this.#target + step));
    return this;
  }

  cooler(step = 0.5) {
    this.#change(Math.max(Thermostat.MIN, this.#target - step));
    return this;
  }

  get history() {
    return [...this.#history];
  }

  #change(value) {
    if (value === this.#target) return;
    this.#target = value;
    this.#history.push(value);
  }
}

const t = new Thermostat(20);
t.warmer();
console.log(t.target); // 20.5
```

All the validation lives in the setter, which the constructor reuses, and every change goes through the private `#change` method, so the history can't get out of step with the target. The `history` getter hands out a copy, which keeps the real array private.

</Solution>
