Панды выстроились в шеренгу для парада, и все смотрят направо. `heights[i]` — рост панды `i`. Напишите `visibleCounts(heights)`, которая возвращает массив (array), где для каждой панды записано, **скольких панд справа от себя она видит**.

- Панда `i` видит панду `j` (где `j > i`), когда каждая панда **между** ними строго ниже их обеих, то есть ниже `Math.min(heights[i], heights[j])`.
- Соседи всегда видят друг друга, ведь между ними никого нет.
- Панда того же роста или выше закрывает обзор на всех, кто за ней. Поэтому в `[5, 5, 5]` первая панда видит только вторую.
- Последняя панда не видит никого (`0`), а пустая шеренга даёт `[]`.
- В шеренге может стоять **200 000** панд, поэтому проверять каждую пару слишком медленно. Стремитесь к O(n).

```js
visibleCounts([10, 6, 8, 5, 11, 9]);  // [3, 1, 2, 1, 1, 0]
visibleCounts([5, 5, 5]);             // [1, 1, 0]
visibleCounts([3, 1, 3, 1, 3]);       // [2, 1, 2, 1, 0]
visibleCounts([7]);                   // [0]
```

В первом примере панда ростом 10 видит 6 и 8 (6 ниже их обеих), затем 11 (6, 8 и 5 все ниже 10 и 11) и ничего после 11.

<Solution>

```js
function visibleCounts(heights) {
  const result = new Array(heights.length).fill(0);
  const stack = []; // высоты, ещё видимые слева; самая высокая — внизу
  for (let i = heights.length - 1; i >= 0; i--) {
    const h = heights[i];
    let count = 0;
    while (stack.length > 0 && stack.at(-1) < h) {
      stack.pop();
      count++;
    }
    if (stack.length > 0) {
      count++;
      if (stack.at(-1) === h) stack.pop();
    }
    stack.push(h);
    result[i] = count;
  }
  return result;
}

console.log(visibleCounts([10, 6, 8, 5, 11, 9])); // [ 3, 1, 2, 1, 1, 0 ]
```

Это **монотонный стек** (monotonic stack): в нём всегда лежат высоты, строго убывающие снизу вверх, — ровно те панды, которых кто-то левее ещё может увидеть. Каждая панда кладётся в стек один раз и снимается не больше одного раза, поэтому вся шеренга обрабатывается за O(n), а не за O(n²), как при проверке всех пар.

</Solution>
