Три панды вели список перекусов на неделю, но некоторые быстро бросили. Напишите функцию (function) `zipLongest(arrays, fill)`, которая объединяет несколько массивов (array) в **строки**: строка `i` содержит элемент на позиции `i` из каждого массива, в том же порядке, что и сами массивы.

- Строк столько, сколько элементов в **самом длинном** массиве.
- Если у массива нет элемента на этой позиции, в строку попадает `fill`. `fill` необязателен (тогда это `undefined`).
- Элемент, который действительно равен `undefined` внутри массива, остаётся `undefined` — он не заменяется на `fill`. Заполняются только отсутствующие позиции.
- Если массивов нет вовсе (`[]`), верните `[]`. Не изменяйте переданные массивы.

```js
zipLongest([["apple", "kiwi", "fig"], [1, 2]], "-");
// [ [ 'apple', 1 ], [ 'kiwi', 2 ], [ 'fig', '-' ] ]

zipLongest([[1, 2], ["a"], [true, false, true]], 0);
// [ [ 1, 'a', true ], [ 2, 0, false ], [ 0, 0, true ] ]

zipLongest([[undefined, 5], [7]], 0);
// [ [ undefined, 7 ], [ 5, 0 ] ]

zipLongest([]); // []
```

Допишите `zipLongest(arrays, fill)`, чтобы функция возвращала строки.

<Hint>

Сколько будет строк? Это зависит от самого длинного массива. Затем для каждой позиции подумайте, как отличить отсутствующий элемент от элемента, который действительно равен `undefined`.

</Hint>

<Hint>

Найдите наибольшую длину через `Math.max(0, ...arrays.map((a) => a.length))`: `0` нужен, чтобы всё работало и без массивов. Для каждой позиции `i` от `0` до этой длины соберите строку, пройдя `map` по массивам. Выбирайте между элементом и `fill`, проверяя, существует ли позиция (`i < array.length`), а не равен ли элемент `undefined` или ложному значению. </Hint>

<Solution>

```js
function zipLongest(arrays, fill) {
  const longest = Math.max(0, ...arrays.map((array) => array.length));
  const rows = [];
  for (let i = 0; i < longest; i++) {
    rows.push(arrays.map((array) => (i < array.length ? array[i] : fill)));
  }
  return rows;
}

console.log(zipLongest([["apple", "kiwi", "fig"], [1, 2]], "-"));
// [ [ 'apple', 1 ], [ 'kiwi', 2 ], [ 'fig', '-' ] ]
```

Внешний цикл (loop) создаёт по строке на каждую позицию, а `map` берёт элемент из каждого массива, так что сложность — O(строки × массивы), и каждый элемент затрагивается один раз. Ключевая деталь — спрашивать «существует ли эта позиция?», а не «есть ли элемент?» (`array[i] ?? fill`): так сохраняются настоящие значения `undefined`.

</Solution>
