Three pandas kept a list of their snacks for the week, but some of them gave up early. Write a function `zipLongest(arrays, fill)` that combines several arrays into **rows**: row `i` holds the item at position `i` from each array, in the same order as the arrays.

- There are as many rows as the **longest** array has items.
- Where an array has no item at that position, the row gets `fill` instead. `fill` is optional (then it's `undefined`).
- An item that really is `undefined` inside an array stays `undefined`; it is not replaced by `fill`. Only missing positions are filled.
- With no arrays at all (`[]`), return `[]`. Don't change the arrays you were given.

```js
zipLongest([["apple", "kiwi", "fig"], [1, 2]], "-");
// [ [ 'apple', 1 ], [ 'kiwi', 2 ], [ 'fig', '-' ] ]

zipLongest([[1, 2], ["a"], [true, false, true]], 0);
// [ [ 1, 'a', true ], [ 2, 0, false ], [ 0, 0, true ] ]

zipLongest([[undefined, 5], [7]], 0);
// [ [ undefined, 7 ], [ 5, 0 ] ]

zipLongest([]); // []
```

<Solution>

```js
function zipLongest(arrays, fill) {
  const longest = Math.max(0, ...arrays.map((array) => array.length));
  const rows = [];
  for (let i = 0; i < longest; i++) {
    rows.push(arrays.map((array) => (i < array.length ? array[i] : fill)));
  }
  return rows;
}

console.log(zipLongest([["apple", "kiwi", "fig"], [1, 2]], "-"));
// [ [ 'apple', 1 ], [ 'kiwi', 2 ], [ 'fig', '-' ] ]
```

The outer loop makes one row per position and `map` picks the item from each array, so it's O(rows × arrays), touching every item once. Asking "does this position exist?" rather than "is the item there?" (`array[i] ?? fill`) is the detail that keeps real `undefined` values.

</Solution>
