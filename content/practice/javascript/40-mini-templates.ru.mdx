Рассылка о пандах собирается из шаблонов вроде `Привет, {{ name }}!`. Напишите `render(template, data)` — небольшой шаблонизатор (template engine) в стиле Mustache, который заполняет шаблон значениями из `data`.

**Теги.** Всё между `{{` и `}}` — тег (tag) (пробелы сразу внутри скобок игнорируются), а всё остальное копируется как есть. `{{`, после которого нет `}}`, — просто текст. Теги бывают четырёх видов:

- `{{ path }}` заменяется значением. `path` — это имя вроде `name`, путь через точку вроде `food.favourite` или `.` — «текущий элемент». `undefined` и `null` выводятся как пустота; всё остальное превращается в текст через `String(value)`.
- `{{#path}} … {{/path}}` — это **секция** (section). Если значение — массив, содержимое отрисовывается по разу для каждого элемента, и этот элемент становится текущим. Если значение — любое другое истинное значение, содержимое отрисовывается один раз, а текущим элементом становится само значение. Если значение ложное или это пустой массив, ничего не отрисовывается.
- `{{^path}} … {{/path}}` — **инвертированная секция** (inverted section): её содержимое отрисовывается один раз (без смены текущего элемента), только когда значение ложное или это пустой массив.
- Секции могут быть вложенными. Закрывающий тег должен соответствовать последней открытой секции; иначе выбросьте `SyntaxError` с сообщением `Unexpected closing tag "<path>"` («Неожиданный закрывающий тег»). Если в конце какая-то секция осталась открытой, выбросьте `SyntaxError` с сообщением `Unclosed section "<path>"` («Незакрытая секция»).

**Поиск по пути.** Текущие элементы образуют стек: `data` лежит на дне, а каждая секция на время отрисовки кладёт сверху свой элемент. Для `a.b.c` найдите самый верхний элемент, который является объектом со свойством `a` (проверка через `in`), а затем пройдите от него по `.b.c` (отсутствующий шаг даёт `undefined`). Если ни у одного элемента нет `a`, значение — `undefined`. Так элемент цикла может пользоваться внешними значениями, как `{{zoo}}` ниже.

```js
const template =
  "{{#pandas}}[{{name}} ест {{food.favourite}}, зоопарк: {{zoo}}]{{/pandas}}" +
  "{{^pandas}}Панд пока нет.{{/pandas}}";

render(template, {
  zoo: "Чэнду",
  pandas: [
    { name: "Mei", food: { favourite: "бамбук" } },
    { name: "Bao", food: { favourite: "яблоки" }, zoo: "Эдинбург" },
  ],
});
// "[Mei ест бамбук, зоопарк: Чэнду][Bao ест яблоки, зоопарк: Эдинбург]"

render(template, { pandas: [] });                         // "Панд пока нет."
render("{{#tags}}{{.}}; {{/tags}}", { tags: ["милая", "сонная"] });  // "милая; сонная; "
render("{{#vip}}VIP {{name}}{{/vip}}", { vip: { name: "Lin" } });   // "VIP Lin"
render("{{#a}}oops{{/b}}", {});                           // SyntaxError: Unexpected closing tag "b"
```

<Hint>

Разделите работу на две части: сначала **разберите** (parse) шаблон в дерево (текст, теги значений и секции со своими дочерними узлами), а потом **отрисуйте** (render) это дерево. В обеих частях помогает стек: при разборе — открытых секций, при отрисовке — текущих элементов.

</Hint>

<Hint>

Для разбора найдите теги регулярным выражением вроде `/\{\{\s*([#^/]?)\s*([^{}]*?)\s*\}\}/g` и `template.matchAll`. Текст и теги значений попадают в дочерние узлы секции на вершине стека, `#` и `^` кладут в стек новую секцию, а `/` снимает её, предварительно проверив имя (выбросьте `SyntaxError`, если оно не совпадает или если в конце какая-то секция осталась открытой). Для отрисовки напишите рекурсивную функцию, которая принимает список узлов и стек текущих элементов, сначала `[data]`. Секция с массивом вызывает её по разу на каждый элемент с `[...contexts, item]`, а с другим истинным значением — один раз с `[...contexts, value]`. Напишите отдельно `lookup(path, contexts)`: `.` — это верхний элемент; иначе найдите самый верхний объект с первым ключом (`in`) и пройдите от него остаток пути.

</Hint>

<Solution>

```js
const TAG = /\{\{\s*([#^/]?)\s*([^{}]*?)\s*\}\}/g;

// Шаг 1: превращаем шаблон в дерево из текста, значений и секций.
function parse(template) {
  const root = { children: [] };
  const open = [root];
  let last = 0;
  for (const match of template.matchAll(TAG)) {
    const [whole, kind, path] = match;
    const current = open.at(-1);
    if (match.index > last) current.children.push(template.slice(last, match.index));
    last = match.index + whole.length;
    if (kind === "#" || kind === "^") {
      const section = { path, inverted: kind === "^", children: [] };
      current.children.push(section);
      open.push(section);
    } else if (kind === "/") {
      if (open.length === 1 || current.path !== path) {
        throw new SyntaxError(`Unexpected closing tag "${path}"`);
      }
      open.pop();
    } else {
      current.children.push({ path });
    }
  }
  if (open.length > 1) throw new SyntaxError(`Unclosed section "${open.at(-1).path}"`);
  if (last < template.length) root.children.push(template.slice(last));
  return root;
}

function lookup(path, contexts) {
  if (path === ".") return contexts.at(-1);
  const [first, ...rest] = path.split(".");
  for (let i = contexts.length - 1; i >= 0; i--) {
    const context = contexts[i];
    if (context !== null && typeof context === "object" && first in context) {
      let value = context[first];
      for (const key of rest) value = value?.[key];
      return value;
    }
  }
  return undefined;
}

// Шаг 2: отрисовываем дерево со стеком текущих элементов.
function renderNodes(nodes, contexts) {
  let out = "";
  for (const node of nodes) {
    if (typeof node === "string") {
      out += node;
      continue;
    }
    const value = lookup(node.path, contexts);
    if (!node.children) {
      out += value === undefined || value === null ? "" : String(value);
      continue;
    }
    const empty = !value || (Array.isArray(value) && value.length === 0);
    if (node.inverted) {
      if (empty) out += renderNodes(node.children, contexts);
    } else if (Array.isArray(value)) {
      for (const item of value) out += renderNodes(node.children, [...contexts, item]);
    } else if (!empty) {
      out += renderNodes(node.children, [...contexts, value]);
    }
  }
  return out;
}

function render(template, data) {
  return renderNodes(parse(template).children, [data]);
}

console.log(render("Привет, {{ name }}!", { name: "Mei" })); // Привет, Mei!
```

Разделение работы на разбор и отрисовку делает обе половины простыми: парсеру нужно только сопоставлять открывающие и закрывающие теги с помощью стека, а отрисовка — это рекурсивный обход дерева, который несёт с собой стек текущих элементов. Поиск идёт по этому стеку сверху, и именно это позволяет элементу цикла обращаться к внешним значениям. Разбор занимает O(n) от длины шаблона, а отрисовка — время, пропорциональное размеру результата.

</Solution>
