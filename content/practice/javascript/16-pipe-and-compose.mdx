Small functions are easy to test, and gluing them together gives you bigger ones. Write two functions that do the gluing. Both take any number of functions and return a **new function**:

- `pipe(f, g, h)` runs left to right: calling the result with some arguments gives `h(g(f(...args)))`.
- `compose(f, g, h)` runs right to left: calling the result gives `f(g(h(...args)))`.

The **first function to run** (the leftmost for `pipe`, the rightmost for `compose`) receives **all** the arguments the new function was called with. Every later function receives just the previous result.

With no functions at all, the new function returns its first argument unchanged. Neither `pipe` nor `compose` should call any function until the new function is called, and the new function can be called many times.

```js
const add = (a, b) => a + b;
const double = (x) => x * 2;
const shout = (x) => x + "!";

pipe(add, double, shout)(2, 3);    // '10!'   (2 + 3 = 5, 5 * 2 = 10, '10!')
compose(shout, double, add)(2, 3); // '10!'   (same steps, written the other way)
pipe(double, (x) => x + 1)(5);     // 11
compose(double, (x) => x + 1)(5);  // 12
pipe()("same");                    // 'same'
```

Finish `pipe` and `compose`.

<Hint>

`pipe` returns `(...args) => { … }`. Inside, if there are no functions return `args[0]`. Otherwise call the first function with `...args`, then loop over the rest, feeding each one the previous result.

</Hint>

<Hint>

`compose` is just `pipe` with the functions in the opposite order. `[...fns].reverse()` gives a reversed copy without changing `fns`.

</Hint>

<Solution>

```js
function pipe(...fns) {
  return (...args) => {
    if (fns.length === 0) return args[0];
    let result = fns[0](...args);
    for (const fn of fns.slice(1)) {
      result = fn(result);
    }
    return result;
  };
}

function compose(...fns) {
  return pipe(...[...fns].reverse());
}

const add = (a, b) => a + b;
const double = (x) => x * 2;
console.log(pipe(add, double)(2, 3));    // 10
console.log(compose(double, add)(2, 3)); // 10
```

The returned arrow function closes over `fns`, and the work only happens when it's called, with a fresh `result` each time. `compose` reuses `pipe` on a reversed copy, so there's only one loop to get right. You can also write the loop as `fns.slice(1).reduce((value, fn) => fn(value), fns[0](...args))`.

</Solution>
