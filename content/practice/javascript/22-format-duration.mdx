The panda sleep tracker stores naps in seconds, which nobody wants to read. Write `formatDuration(seconds, options)` that turns them into words.

- Split `seconds` into days (86,400 s), hours (3,600 s), minutes (60 s) and seconds, largest first, and leave out the units that are `0`.
- Each part is the number and the unit, singular for 1 (`"1 minute"`) and plural otherwise (`"2 minutes"`).
- Join the parts like a sentence: one part on its own, two parts with `" and "`, and more parts with `", "` except for the last two, which are joined with `" and "`.
- `0` seconds gives `"now"`.
- With `{ short: true }` as the second argument, use `d`, `h`, `m` and `s` straight after the number and join the parts with single spaces, so `0` gives `"0s"`.
- `seconds` must be a whole number, 0 or more. Anything else (`-1`, `1.5`, `NaN`, `"60"`) throws a `RangeError`.

```js
formatDuration(62);                     // "1 minute and 2 seconds"
formatDuration(3600);                   // "1 hour"
formatDuration(3725);                   // "1 hour, 2 minutes and 5 seconds"
formatDuration(90061);                  // "1 day, 1 hour, 1 minute and 1 second"
formatDuration(0);                      // "now"
formatDuration(3725, { short: true });  // "1h 2m 5s"
formatDuration(-5);                     // RangeError
```

<Solution>

```js
const UNITS = [
  ["day", "d", 86400],
  ["hour", "h", 3600],
  ["minute", "m", 60],
  ["second", "s", 1],
];

function formatDuration(seconds, options = {}) {
  if (!Number.isInteger(seconds) || seconds < 0) {
    throw new RangeError("seconds must be a whole number, 0 or more");
  }
  const parts = [];
  let left = seconds;
  for (const [name, letter, size] of UNITS) {
    const count = Math.floor(left / size);
    left %= size;
    if (count === 0) continue;
    if (options.short) parts.push(count + letter);
    else parts.push(count + " " + name + (count === 1 ? "" : "s"));
  }
  if (options.short) return parts.length ? parts.join(" ") : "0s";
  if (parts.length === 0) return "now";
  if (parts.length === 1) return parts[0];
  const last = parts.pop();
  return parts.join(", ") + " and " + last;
}

console.log(formatDuration(3725)); // 1 hour, 2 minutes and 5 seconds
```

Going from the biggest unit to the smallest, each step takes as many whole units as fit and passes the remainder on. Only the joining rule needs care: everything except the last part is comma-separated, and the last part is attached with "and".

</Solution>
