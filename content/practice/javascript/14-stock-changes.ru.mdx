Каждый вечер магазин панд пересчитывает товары и записывает их в объект (object) «название → количество», например `{ bamboo: 12, apples: 3 }`. Напишите функцию (function) `stockChanges(before, after)`, которая сравнивает вчерашний подсчёт с сегодняшним и возвращает объект из трёх частей:

- `added`: массив названий, которые есть в `after`, но нет в `before`, отсортированный от A до Z.
- `removed`: массив названий, которые есть в `before`, но нет в `after`, отсортированный от A до Z.
- `changed`: объект с ключом для каждого названия, которое есть в **обоих** объектах с **разными** количествами. Значение — разница `after − before` (отрицательная, если товара стало меньше). Ключи отсортированы от A до Z.

Названия, количество которых не изменилось, нигде не появляются.

Особые случаи: название с количеством `0` всё ещё есть в объекте (оно не «пропало»), а названия товаров могут быть любым текстом — даже таким, как `"toString"`, похожим на встроенные методы объектов. Не изменяйте ни один из объектов.

```js
stockChanges(
  { bamboo: 12, apples: 3, tea: 5, cups: 0 },
  { bamboo: 9, tea: 5, cups: 4, honey: 2 },
);
// {
//   added: [ 'honey' ],
//   removed: [ 'apples' ],
//   changed: { bamboo: -3, cups: 4 }
// }

stockChanges({ a: 1 }, { a: 1 }); // { added: [], removed: [], changed: {} }
```

Допишите `stockChanges(before, after)`, чтобы функция возвращала все три части.

<Hint>

Пройдите циклом по `Object.keys(after)`, чтобы найти добавленные и изменившиеся названия, и по `Object.keys(before)` — чтобы найти пропавшие. Если сначала отсортировать списки ключей через `.sort()`, всё, что вы соберёте, окажется в порядке от A до Z.

</Hint>

<Hint>

Чтобы спросить «есть ли такое название в объекте?», не используйте `if (before[name])` (это ложь для `0`) или `name in before` (это истина для `"toString"` в любом объекте). `Object.hasOwn(before, name)` проверяет только собственные ключи объекта.

</Hint>

<Solution>

```js
function stockChanges(before, after) {
  const added = [];
  const removed = [];
  const changed = {};
  for (const name of Object.keys(after).sort()) {
    if (!Object.hasOwn(before, name)) added.push(name);
    else if (after[name] !== before[name]) {
      changed[name] = after[name] - before[name];
    }
  }
  for (const name of Object.keys(before).sort()) {
    if (!Object.hasOwn(after, name)) removed.push(name);
  }
  return { added, removed, changed };
}

console.log(stockChanges(
  { bamboo: 12, apples: 3, tea: 5, cups: 0 },
  { bamboo: 9, tea: 5, cups: 4, honey: 2 },
));
```

Двух проходов по отсортированным ключам хватает, чтобы найти всё; из-за сортировки сложность — O(n log n) для n названий. `Object.hasOwn` — надёжная проверка наличия: она не учитывает методы, которые наследует любой объект, и ей неважно, равно ли значение `0`.

</Solution>
