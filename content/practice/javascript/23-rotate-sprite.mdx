A pixel-art game stores its sprites as grids: arrays of rows, where every row has the same length. Write `rotate(grid, turns = 1)` that returns the grid turned by `turns` quarter turns **clockwise**.

- A grid with `r` rows and `c` columns becomes one with `c` rows and `r` columns after one turn. The first column, read from the bottom up, becomes the first row.
- A negative `turns` rotates anticlockwise, so `-1` is the same as `3`. Any whole number works: `5` is the same as `1`, and `0` gives the same picture back.
- Always return a **new** grid made of new row arrays, even for `0` turns, and never change `grid` itself.
- An empty grid (`[]`) stays `[]`.

```js
rotate([
  [1, 2, 3],
  [4, 5, 6],
]);
// [[4, 1],
//  [5, 2],
//  [6, 3]]

rotate([[1, 2], [3, 4]], 2);   // [[4, 3], [2, 1]]
rotate([[1, 2], [3, 4]], -1);  // [[2, 4], [1, 3]]
rotate([["🐼"]], 7);            // [["🐼"]]
```

<Hint>

Write one clockwise quarter turn first; every other rotation is that turn repeated. How can you turn any `turns`, even a negative one, into a number from 0 to 3?

</Hint>

<Hint>

For one turn, row `i` of the result is column `i` of the grid read from the bottom row up: `grid.map((row) => row[i]).reverse()`. Do that for every column index of the first row, and return `[]` for an empty grid. Then turn `turns` into 0–3 with `((turns % 4) + 4) % 4` (the extra `+ 4` fixes negative numbers). Start from a copy of every row with `[...row]`, so even 0 turns gives new arrays, and apply the single turn that many times.

</Hint>

<Solution>

```js
function turnOnce(grid) {
  if (grid.length === 0) return [];
  return grid[0].map((_, col) => grid.map((row) => row[col]).reverse());
}

function rotate(grid, turns = 1) {
  const times = ((turns % 4) + 4) % 4;
  let result = grid.map((row) => [...row]);
  for (let i = 0; i < times; i++) {
    result = turnOnce(result);
  }
  return result;
}

console.log(rotate([[1, 2, 3], [4, 5, 6]])); // [ [ 4, 1 ], [ 5, 2 ], [ 6, 3 ] ]
```

A clockwise quarter turn makes each column, read bottom-up, into a row. Every other rotation is that turn repeated 0 to 3 times, and starting from a copy means even 0 turns hands back fresh arrays. Each turn touches every cell once, so it's O(r × c).

</Solution>
