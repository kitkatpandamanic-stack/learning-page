Настройки приложения о пандах — это глубоко вложенный объект (object), а экрану настроек нужен один плоский список строк. Напишите `flatten(value, separator = ".")`, которая возвращает плоский объект, ключи которого — пути к каждому листу.

- Путь соединяет ключи по пути вниз через `separator`. Элементы массива (array) используют свой индекс в качестве ключа, так что второй элемент `pets` — это `pets.1`.
- Простые объекты и массивы раскрываются. Всё остальное — лист, и он копируется как есть: строки, числа, логические значения, `null`, `undefined`, функции и другие объекты, например даты.
- Пустой объект или пустой массив тоже сохраняется как лист, чтобы он не пропал: `{ tags: [] }` даёт `{ tags: [] }`.
- Ключи идут в том порядке, в котором вы их встречаете при обходе в глубину: все пути `a` раньше путей `b`.
- `flatten` вызывается с простым объектом или массивом. Если внутри ничего нет, результат — `{}`.

```js
flatten({
  user: { name: "Mei", pets: [{ name: "Bao" }, "fish"] },
  theme: "dark",
});
// {
//   "user.name": "Mei",
//   "user.pets.0.name": "Bao",
//   "user.pets.1": "fish",
//   "theme": "dark",
// }

flatten({ a: { b: 1 }, tags: [], extra: {} });  // { "a.b": 1, tags: [], extra: {} }
flatten({ a: { b: 1 } }, "/");                   // { "a/b": 1 }
flatten([10, [20]]);                             // { "0": 10, "1.0": 20 }
```

<Solution>

```js
function isContainer(value) {
  if (Array.isArray(value)) return true;
  return value !== null && typeof value === "object" &&
    Object.getPrototypeOf(value) === Object.prototype;
}

function flatten(value, separator = ".") {
  const result = {};
  function walk(current, path) {
    const entries = isContainer(current) ? Object.entries(current) : [];
    if (entries.length === 0) {
      if (path !== "") result[path] = current;
      return;
    }
    for (const [key, child] of entries) {
      walk(child, path === "" ? key : path + separator + key);
    }
  }
  walk(value, "");
  return result;
}

console.log(flatten({ a: { b: 1, c: [2, 3] } })); // { 'a.b': 1, 'a.c.0': 2, 'a.c.1': 3 }
```

Рекурсия несёт с собой уже построенный путь, а всё, что нельзя раскрыть (или что пусто), сохраняется под этим путём. `Object.entries` обрабатывает массивы и объекты одинаково, ведь ключи массива — его индексы. Каждое значение посещается один раз, так что это O(n) для n значений.

</Solution>
