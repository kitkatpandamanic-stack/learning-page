Страница поиска в бамбуковом магазине кладёт выбор покупателя в URL, например `?q=red+panda&size=s&size=m`. Напишите `parseQuery(query)`, которая превращает такую строку запроса (query string) в объект (object), не используя `URLSearchParams`.

- Начальный `?` игнорируется. Пары разделяются `&`, а пустые кусочки (из `&&` или `&` в конце) пропускаются.
- Каждая пара делится по **первому** `=`: часть до него — ключ, всё после — значение (в нём могут быть ещё знаки `=`). Кусочек без `=` — это ключ со значением `""`.
- В ключах и значениях сначала замените каждый `+` на пробел, а затем раскодируйте последовательности `%XX` через `decodeURIComponent`. Если часть не раскодируется (например, `100%`), оставьте её такой, какой она стала после замены `+`.
- Ключ, который встречается один раз, получает строку. Ключ, который встречается несколько раз, получает массив всех своих значений по порядку.
- Ключи идут в объекте в том порядке, в котором они впервые появляются в строке запроса.

```js
parseQuery("?q=red+panda&page=2");
// { q: "red panda", page: "2" }

parseQuery("size=s&size=m&size=l");
// { size: ["s", "m", "l"] }

parseQuery("name=Mei%20Ling&pet=%F0%9F%90%BC&sum=1%2B1");
// { name: "Mei Ling", pet: "🐼", sum: "1+1" }

parseQuery("debug&filter=a=b&&");
// { debug: "", filter: "a=b" }

parseQuery("");  // {}
```

<Solution>

```js
function decode(text) {
  const spaced = text.replaceAll("+", " ");
  try {
    return decodeURIComponent(spaced);
  } catch {
    return spaced;
  }
}

function parseQuery(query) {
  const result = {};
  const text = query.startsWith("?") ? query.slice(1) : query;
  for (const piece of text.split("&")) {
    if (piece === "") continue;
    const at = piece.indexOf("=");
    const key = decode(at === -1 ? piece : piece.slice(0, at));
    const value = at === -1 ? "" : decode(piece.slice(at + 1));
    if (!Object.hasOwn(result, key)) result[key] = value;
    else if (Array.isArray(result[key])) result[key].push(value);
    else result[key] = [result[key], value];
  }
  return result;
}

console.log(parseQuery("?q=red+panda&page=2")); // { q: 'red panda', page: '2' }
```

Каждый кусочек делится один раз по первому `=`, и обе половины проходят через одну и ту же функцию `decode`. Важно заменять `+` до раскодирования: закодированный плюс (`%2B`) должен остаться настоящим `+`. Всё решение — один проход по строке запроса, O(n).

</Solution>
