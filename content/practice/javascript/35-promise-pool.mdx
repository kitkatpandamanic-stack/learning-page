The bamboo farm has hundreds of deliveries to send, but only a few trucks. `Promise.all` would send them all at once, so write `runWithLimit(tasks, limit)` that runs async tasks with **at most `limit` running at the same time**.

- `tasks` is an array of functions. Calling a task starts it, and it returns a promise (or a plain value). Start tasks in array order.
- The first `limit` tasks start **straight away**, before `runWithLimit` returns. After that, as soon as **any** running task finishes, the next waiting task starts. Don't wait for a whole group to finish.
- `runWithLimit` returns a promise of an array with every task's result, **in the same order as `tasks`**, not in the order they finished.
- If a task fails (its promise rejects, or calling it throws), the returned promise rejects with that error and **no more tasks are started**. Tasks that are already running are left alone.
- An empty `tasks` array gives `[]`. A `limit` that isn't a whole number of at least 1 rejects with a `RangeError` without starting anything.

```js
const wait = (ms, value) => new Promise((resolve) => setTimeout(() => resolve(value), ms));

const deliveries = [
  () => wait(300, "🎋 to the north gate"),
  () => wait(100, "🎋 to the nursery"),
  () => wait(100, "🎋 to the kitchen"),
  () => wait(100, "🎋 to the vet"),
];

await runWithLimit(deliveries, 2);
// ["🎋 to the north gate", "🎋 to the nursery", "🎋 to the kitchen", "🎋 to the vet"]
// The nursery truck is back at 100 ms, so the kitchen delivery starts then,
// and the vet delivery at 200 ms: all done after 300 ms.
```

<Solution>

```js
function runWithLimit(tasks, limit) {
  return new Promise((resolve, reject) => {
    if (!Number.isInteger(limit) || limit < 1) {
      reject(new RangeError("limit must be a whole number of at least 1"));
      return;
    }
    const results = new Array(tasks.length);
    let next = 0;
    let finished = 0;
    let failed = false;

    const startNext = () => {
      if (failed || next >= tasks.length) return;
      const index = next++;
      new Promise((res) => res(tasks[index]())).then(
        (value) => {
          results[index] = value;
          finished++;
          if (finished === tasks.length) resolve(results);
          else startNext();
        },
        (error) => {
          failed = true;
          reject(error);
        },
      );
    };

    if (tasks.length === 0) resolve(results);
    for (let i = 0; i < Math.min(limit, tasks.length); i++) startNext();
  });
}

const wait = (ms, value) => new Promise((resolve) => setTimeout(() => resolve(value), ms));
const tasks = [() => wait(30, "a"), () => wait(10, "b"), () => wait(10, "c")];
console.log(await runWithLimit(tasks, 2)); // [ 'a', 'b', 'c' ]
```

Think of `limit` workers: each one starts a task and, when it's done, picks up the next task from the shared `next` counter, so a free slot is refilled immediately. Results are stored by index, which keeps them in task order whatever order they finish in, and the `failed` flag stops any new starts after the first error.

</Solution>
