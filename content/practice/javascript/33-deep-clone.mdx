The `{ ...spread }` copy is **shallow**: nested objects are still shared with the original. Write `deepClone(value)` that copies everything, all the way down, so changing the copy can never change the original.

- Primitives (`5`, `"bao"`, `null`, `undefined`, …) and **functions** are returned as they are.
- Arrays become new arrays of cloned items.
- A `Date` becomes a new `Date` with the same time. A `Map` becomes a new `Map` whose keys **and** values are cloned, in the same order, and a `Set` becomes a new `Set` of cloned values.
- Any other object (a plain object or a class instance) becomes a new object with the **same prototype** (`Object.getPrototypeOf`) and clones of its own enumerable properties (`Object.keys`). So a cloned `Panda` is still `instanceof Panda`, and its methods still work.
- If the same object appears several times in `value`, the clone contains **one** copy of it, in all the same places. This also means circular references work: an object that contains itself is cloned into a copy that contains the copy.
- Don't use `structuredClone`: it can't copy functions and turns class instances into plain objects.

```js
class Panda {
  constructor(name) { this.name = name; }
  hello() { return `Hi, I'm ${this.name}`; }
}

const mum = new Panda("Mei");
const family = { mum, kids: [new Panda("Bao")], born: new Date(2020, 4, 1), favourite: mum };
family.self = family;

const copy = deepClone(family);
copy.kids[0].name = "Ling";
family.kids[0].name;          // "Bao" (the original is untouched)
copy.mum.hello();             // "Hi, I'm Mei"
copy.favourite === copy.mum;  // true (shared, like in the original)
copy.self === copy;           // true
copy.born === family.born;    // false (a new Date with the same time)
```

Recursion does the copying, one kind of value at a time: primitives and functions come back as they are, and each kind of object gets its own empty copy. The hard part is shared and circular references: how will you know you've already copied an object?

<Solution>

```js
function deepClone(value, copies = new Map()) {
  if (typeof value !== "object" || value === null) return value;
  if (copies.has(value)) return copies.get(value);

  if (value instanceof Date) {
    const copy = new Date(value.getTime());
    copies.set(value, copy);
    return copy;
  }
  if (value instanceof Map) {
    const copy = new Map();
    copies.set(value, copy);
    for (const [key, item] of value) {
      copy.set(deepClone(key, copies), deepClone(item, copies));
    }
    return copy;
  }
  if (value instanceof Set) {
    const copy = new Set();
    copies.set(value, copy);
    for (const item of value) copy.add(deepClone(item, copies));
    return copy;
  }

  const copy = Array.isArray(value)
    ? []
    : Object.create(Object.getPrototypeOf(value));
  copies.set(value, copy);
  for (const key of Object.keys(value)) {
    copy[key] = deepClone(value[key], copies);
  }
  return copy;
}

const original = { name: "Mei", toys: ["ball"] };
const copy = deepClone(original);
console.log(copy === original, copy); // false { name: 'Mei', toys: [ 'ball' ] }
```

Each kind of object gets its own empty copy, which goes into the `copies` map before its contents are cloned. That map is what keeps shared objects shared and stops circular references from recursing forever: the second time an object is reached, its existing copy is returned. Every object is copied once, so it's O(n) for n values.

</Solution>
