School groups book time at the panda enclosure as ranges `[start, end]` in minutes after opening. The keepers only need to know when the enclosure is busy, so write `mergeRanges(ranges)` that merges the bookings into the fewest ranges.

- Two ranges merge when they overlap **or touch**: `[10, 20]` and `[20, 30]` become `[10, 30]`. A range inside another disappears into it.
- The input can be in any order. Return the merged ranges sorted by start.
- Every range must have `start <= end`. If any range breaks this, throw a `RangeError`.
- Don't change the input array or the ranges in it, and return new `[start, end]` arrays.
- No ranges give `[]`.

```js
mergeRanges([[10, 20], [15, 25], [40, 50]]);   // [[10, 25], [40, 50]]
mergeRanges([[30, 40], [0, 5], [5, 10]]);      // [[0, 10], [30, 40]]
mergeRanges([[0, 100], [20, 30], [99, 120]]);  // [[0, 120]]
mergeRanges([]);                               // []
mergeRanges([[8, 3]]);                         // RangeError
```

<Hint>

First check every range and throw a `RangeError` if `start > end`. Then sort a copy by start: `[...ranges].sort((a, b) => a[0] - b[0])`. Walk through the sorted ranges, keeping a `merged` list: if the next start is `<=` the end of the last kept range, stretch that end to `Math.max(lastEnd, nextEnd)`; otherwise push a **copy** of the next range, so you never change the input.

</Hint>

<Solution>

```js
function mergeRanges(ranges) {
  for (const [start, end] of ranges) {
    if (start > end) throw new RangeError(`Bad range [${start}, ${end}]`);
  }
  const sorted = [...ranges].sort((a, b) => a[0] - b[0]);
  const merged = [];
  for (const [start, end] of sorted) {
    const last = merged.at(-1);
    if (last && start <= last[1]) {
      last[1] = Math.max(last[1], end);
    } else {
      merged.push([start, end]);
    }
  }
  return merged;
}

console.log(mergeRanges([[10, 20], [15, 25], [40, 50]])); // [ [ 10, 25 ], [ 40, 50 ] ]
```

Once the ranges are sorted by start, overlapping ones sit next to each other, so a single pass that keeps stretching the last merged range is enough. Sorting dominates the time: O(n log n).

</Solution>
