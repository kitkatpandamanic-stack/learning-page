Копия через `{ ...spread }` — **поверхностная** (shallow): вложенные объекты по-прежнему общие с оригиналом. Напишите `deepClone(value)`, которая копирует всё до самого дна, чтобы изменение копии никогда не меняло оригинал.

- Примитивы (`5`, `"bao"`, `null`, `undefined`, …) и **функции** возвращаются как есть.
- Массивы (array) становятся новыми массивами из клонированных элементов.
- `Date` становится новым `Date` с тем же временем. `Map` становится новым `Map`, у которого клонированы и ключи, **и** значения, в том же порядке, а `Set` — новым `Set` из клонированных значений.
- Любой другой объект (простой объект или экземпляр (instance) класса) становится новым объектом с **тем же прототипом** (`Object.getPrototypeOf`) и клонами его собственных перечисляемых свойств (`Object.keys`). Поэтому клонированная `Panda` по-прежнему `instanceof Panda`, и её методы работают.
- Если один и тот же объект встречается в `value` несколько раз, в клоне будет **одна** его копия — во всех тех же местах. Это значит, что работают и циклические ссылки (circular references): объект, который содержит сам себя, клонируется в копию, которая содержит саму копию.
- Не используйте `structuredClone`: он не умеет копировать функции и превращает экземпляры классов в простые объекты.

```js
class Panda {
  constructor(name) { this.name = name; }
  hello() { return `Привет, я ${this.name}`; }
}

const mum = new Panda("Mei");
const family = { mum, kids: [new Panda("Bao")], born: new Date(2020, 4, 1), favourite: mum };
family.self = family;

const copy = deepClone(family);
copy.kids[0].name = "Ling";
family.kids[0].name;          // "Bao" (оригинал не тронут)
copy.mum.hello();             // "Привет, я Mei"
copy.favourite === copy.mum;  // true (общий объект, как в оригинале)
copy.self === copy;           // true
copy.born === family.born;    // false (новый Date с тем же временем)
```

<Solution>

```js
function deepClone(value, copies = new Map()) {
  if (typeof value !== "object" || value === null) return value;
  if (copies.has(value)) return copies.get(value);

  if (value instanceof Date) {
    const copy = new Date(value.getTime());
    copies.set(value, copy);
    return copy;
  }
  if (value instanceof Map) {
    const copy = new Map();
    copies.set(value, copy);
    for (const [key, item] of value) {
      copy.set(deepClone(key, copies), deepClone(item, copies));
    }
    return copy;
  }
  if (value instanceof Set) {
    const copy = new Set();
    copies.set(value, copy);
    for (const item of value) copy.add(deepClone(item, copies));
    return copy;
  }

  const copy = Array.isArray(value)
    ? []
    : Object.create(Object.getPrototypeOf(value));
  copies.set(value, copy);
  for (const key of Object.keys(value)) {
    copy[key] = deepClone(value[key], copies);
  }
  return copy;
}

const original = { name: "Mei", toys: ["ball"] };
const copy = deepClone(original);
console.log(copy === original, copy); // false { name: 'Mei', toys: [ 'ball' ] }
```

Каждый вид объекта получает свою пустую копию, и она попадает в `Map` `copies` до того, как клонируется её содержимое. Именно этот `Map` сохраняет общие объекты общими и не даёт циклическим ссылкам уйти в бесконечную рекурсию: когда до объекта доходят во второй раз, возвращается уже готовая копия. Каждый объект копируется один раз, так что это O(n) для n значений.

</Solution>
