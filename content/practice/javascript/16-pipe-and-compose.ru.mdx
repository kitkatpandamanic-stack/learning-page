Маленькие функции (function) легко тестировать, а склеив их, можно получить большие. Напишите две функции, которые занимаются склейкой. Обе принимают любое количество функций и возвращают **новую функцию**:

- `pipe(f, g, h)` работает слева направо: вызов результата с какими-то аргументами даёт `h(g(f(...args)))`.
- `compose(f, g, h)` работает справа налево: вызов результата даёт `f(g(h(...args)))`.

**Первая выполняемая функция** (крайняя левая для `pipe`, крайняя правая для `compose`) получает **все** аргументы (argument), с которыми вызвали новую функцию. Каждая следующая получает только предыдущий результат.

Если функций нет вовсе, новая функция возвращает свой первый аргумент без изменений. Ни `pipe`, ни `compose` не должны вызывать функции, пока не вызвана новая функция, а саму новую функцию можно вызывать сколько угодно раз.

```js
const add = (a, b) => a + b;
const double = (x) => x * 2;
const shout = (x) => x + "!";

pipe(add, double, shout)(2, 3);    // '10!'   (2 + 3 = 5, 5 * 2 = 10, '10!')
compose(shout, double, add)(2, 3); // '10!'   (те же шаги, записанные в обратном порядке)
pipe(double, (x) => x + 1)(5);     // 11
compose(double, (x) => x + 1)(5);  // 12
pipe()("same");                    // 'same'
```

Допишите `pipe` и `compose`.

<Hint>

Обе функции возвращают новую функцию, которая по очереди запускает список функций и передаёт каждой результат предыдущей. Заметьте: `compose` — это тот же `pipe`, только в обратном порядке.

</Hint>

<Hint>

`pipe` возвращает `(...args) => …`. Внутри, если функций нет, верните `args[0]`. Иначе вызовите первую функцию с `...args`, а затем пройдите циклом по остальным, передавая каждой предыдущий результат. Пока возвращённую функцию не вызвали, ничего не запускается. `compose` может использовать `pipe` с перевёрнутой копией: `[...fns].reverse()` не изменяет `fns`.

</Hint>

<Hint>

```js
function pipe(...fns) {
  return (...args) => {
    if (fns.length === 0) return args[0];
    let result = fns[0](...args);
    // пропустите result через остальные функции по очереди
    return result;
  };
}

function compose(...fns) {
  return ...; // pipe с функциями в обратном порядке
}
```

</Hint>

<Solution>

```js
function pipe(...fns) {
  return (...args) => {
    if (fns.length === 0) return args[0];
    let result = fns[0](...args);
    for (const fn of fns.slice(1)) {
      result = fn(result);
    }
    return result;
  };
}

function compose(...fns) {
  return pipe(...[...fns].reverse());
}

const add = (a, b) => a + b;
const double = (x) => x * 2;
console.log(pipe(add, double)(2, 3));    // 10
console.log(compose(double, add)(2, 3)); // 10
```

Возвращаемая стрелочная функция замыкает (closure) `fns`, а работа происходит только при её вызове — каждый раз с новым `result`. `compose` переиспользует `pipe` на перевёрнутой копии, так что правильно написать нужно только один цикл. Цикл можно записать и так: `fns.slice(1).reduce((value, fn) => fn(value), fns[0](...args))`.

</Solution>
