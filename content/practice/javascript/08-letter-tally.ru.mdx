Напишите функцию (function) `letterTally(text)`, которая считает, сколько раз каждая буква встречается в `text`, и возвращает результат в виде объекта (object), например `{ a: 3, b: 1, n: 2 }`.

- Заглавные и строчные буквы считаются одной и той же буквой, а ключи — строчные.
- Считаются только 26 латинских букв `a`–`z`. Пробелы, цифры, знаки препинания и буквы вроде `é` (а также кириллица) пропускаются.
- Буквы, которых в тексте нет, вообще не получают ключа (никаких нулей).
- Ключи должны идти в **алфавитном порядке**, чтобы при выводе объект читался от A до Z.

```js
letterTally("banana");   // { a: 3, b: 1, n: 2 }
letterTally("Hello!!");  // { e: 1, h: 1, l: 2, o: 1 }
letterTally("123 ...");  // {}
```

<Solution>

```js
function letterTally(text) {
  const counts = {};
  for (const char of text.toLowerCase()) {
    if (char >= "a" && char <= "z") {
      counts[char] = (counts[char] ?? 0) + 1;
    }
  }
  const sorted = {};
  for (const letter of Object.keys(counts).sort()) {
    sorted[letter] = counts[letter];
  }
  return sorted;
}

console.log(letterTally("banana")); // { a: 3, b: 1, n: 2 }
```

Сравнение через `>=` и `<=` работает, потому что строки сравниваются посимвольно, а `é` при сортировке идёт после `z`. А перенос в новый объект в отсортированном порядке ключей и выстраивает ключи от A до Z.

</Solution>
