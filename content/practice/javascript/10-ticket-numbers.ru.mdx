Кафе для панд нужны номерки для заказов, а зоопарку — свои, для посетителей. Напишите функцию (function) `makeIdMaker(prefix, width)`, которая возвращает **новую функцию**. Каждый вызов этой новой функции возвращает следующий ID:

- ID состоит из префикса, дефиса и номера: первый вызов даёт номер 1, затем 2, 3 и так далее.
- Номер дополняется нулями слева до `width` цифр. `width` необязателен, по умолчанию он равен `3`: `"ord-001"`.
- Номера, которые уже длиннее `width`, не обрезаются: после `"ord-999"` идёт `"ord-1000"`.
- У каждого генератора ID **свой** счётчик. Создание второго генератора никак не влияет на первый.

```js
const nextOrder = makeIdMaker("ord");
nextOrder(); // 'ord-001'
nextOrder(); // 'ord-002'

const nextVisitor = makeIdMaker("visitor", 5);
nextVisitor(); // 'visitor-00001'
nextOrder();   // 'ord-003'
```

Допишите `makeIdMaker(prefix, width)`, чтобы функция возвращала функцию, выдающую ID.

<Hint>

Храните счётчик в переменной `let` **внутри** `makeIdMaker`, а затем верните стрелочную функцию, которая прибавляет к нему 1 и собирает ID. Каждый вызов `makeIdMaker` создаёт новый счётчик, и видит его только возвращённая функция.

</Hint>

<Hint>

`String(7).padStart(3, "0")` даёт `"007"`. `padStart` никогда не обрезает строку, которая уже достаточно длинная.

</Hint>

<Solution>

```js
function makeIdMaker(prefix, width = 3) {
  let count = 0;
  return () => {
    count++;
    return prefix + "-" + String(count).padStart(width, "0");
  };
}

const nextOrder = makeIdMaker("ord");
console.log(nextOrder()); // ord-001
console.log(nextOrder()); // ord-002
```

Возвращённая функция **замыкает** (closes over) `count`, `prefix` и `width`, поэтому помнит их между вызовами. Это и есть замыкание (closure). Каждый вызов `makeIdMaker` заново выполняет тело функции и создаёт совершенно новый `count` — поэтому два генератора никогда не делят один счётчик.

</Solution>
