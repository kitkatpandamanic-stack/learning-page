Пиксельная игра хранит спрайты как сетки: массивы (array) строк, где все строки одной длины. Напишите `rotate(grid, turns = 1)`, которая возвращает сетку, повёрнутую на `turns` четвертей оборота **по часовой стрелке**.

- Сетка из `r` строк и `c` столбцов после одного поворота становится сеткой из `c` строк и `r` столбцов. Первый столбец, прочитанный снизу вверх, становится первой строкой.
- Отрицательный `turns` поворачивает против часовой стрелки, так что `-1` — то же, что `3`. Подходит любое целое число: `5` — то же, что `1`, а `0` возвращает ту же картинку.
- Всегда возвращайте **новую** сетку из новых массивов-строк, даже при `0` поворотов, и никогда не меняйте сам `grid`.
- Пустая сетка (`[]`) остаётся `[]`.

```js
rotate([
  [1, 2, 3],
  [4, 5, 6],
]);
// [[4, 1],
//  [5, 2],
//  [6, 3]]

rotate([[1, 2], [3, 4]], 2);   // [[4, 3], [2, 1]]
rotate([[1, 2], [3, 4]], -1);  // [[2, 4], [1, 3]]
rotate([["🐼"]], 7);            // [["🐼"]]
```

Допишите `rotate(grid, turns)`.

<Hint>

Сначала напишите один поворот на четверть оборота по часовой стрелке — любой другой поворот получается его повторением. Как превратить любое `turns`, даже отрицательное, в число от 0 до 3?

</Hint>

<Hint>

При одном повороте строка `i` результата — это столбец `i` сетки, прочитанный от нижней строки к верхней: `grid.map((row) => row[i]).reverse()`. Сделайте так для каждого индекса столбца первой строки, а для пустой сетки верните `[]`. Затем превратите `turns` в число от 0 до 3 с помощью `((turns % 4) + 4) % 4` (лишнее `+ 4` исправляет отрицательные числа). Начните с копии каждой строки через `[...row]`, чтобы даже при 0 поворотов получились новые массивы, и примените один поворот столько раз.

</Hint>

  if (grid.length === 0) return [];

<Solution>

```js
function turnOnce(grid) {
  if (grid.length === 0) return [];
  return grid[0].map((_, col) => grid.map((row) => row[col]).reverse());
}

function rotate(grid, turns = 1) {
  const times = ((turns % 4) + 4) % 4;
  let result = grid.map((row) => [...row]);
  for (let i = 0; i < times; i++) {
    result = turnOnce(result);
  }
  return result;
}

console.log(rotate([[1, 2, 3], [4, 5, 6]])); // [ [ 4, 1 ], [ 5, 2 ], [ 6, 3 ] ]
```

Поворот на четверть по часовой стрелке превращает каждый столбец, прочитанный снизу вверх, в строку. Любой другой поворот — это тот же шаг, повторённый от 0 до 3 раз, а раз мы начинаем с копии, даже 0 поворотов возвращает свежие массивы. Каждый поворот проходит по каждой клетке один раз, так что это O(r × c).

</Solution>
