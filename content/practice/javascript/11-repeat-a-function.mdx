Write a function `repeatFn(fn, times)` that takes a one-argument function and a whole number, and returns a **new function**. Calling the new function with `x` applies `fn` to `x`, then `fn` to that result, and so on, `times` times in total:

- `repeatFn(fn, 3)(x)` is the same as `fn(fn(fn(x)))`.
- `repeatFn(fn, 0)(x)` just returns `x`.
- `repeatFn` itself must not call `fn`. Only calling the new function does, and every call starts again from its own `x`.

```js
const addTwo = (x) => x + 2;
repeatFn(addTwo, 3)(1);              // 7
repeatFn((x) => x * 2, 10)(1);       // 1024
repeatFn((s) => s + "!", 3)("Hi");   // 'Hi!!!'
repeatFn(addTwo, 0)(5);              // 5
```

Finish `repeatFn(fn, times)` so it returns the repeating function.

<Hint>

`repeatFn` doesn't do the repeating itself; it hands back a new function. Which function should hold the loop, and when should `fn` be called for the first time?

</Hint>

<Hint>

`repeatFn` should `return (x) => …`, with all the work inside that arrow function, so nothing happens until someone calls it. Inside, copy `x` into a `let result`, loop `times` times doing `result = fn(result)`, and return `result`. Make a new `result` on every call, not one shared variable outside the arrow function, so the function can be reused. When `times` is 0 the loop never runs and `x` comes back unchanged.

</Hint>

<Hint>

```js
function repeatFn(fn, times) {
  return (x) => {
    let result = x;
    // apply fn to result, times times in a row
    return result;
  };
}
```

</Hint>

<Solution>

```js
function repeatFn(fn, times) {
  return (x) => {
    let result = x;
    for (let i = 0; i < times; i++) {
      result = fn(result);
    }
    return result;
  };
}

const addTwo = (x) => x + 2;
console.log(repeatFn(addTwo, 3)(1)); // 7
```

`repeatFn` is a **higher-order function**: it takes a function and returns a new one. The loop lives inside the returned function, so `fn` only runs when that function is called, and `result` starts fresh each time.

</Solution>
