Write a function `countVowels(text)` that returns how many vowels (`a`, `e`, `i`, `o`, `u`) are in `text`. Capital letters count too, and everything else (spaces, digits, other letters) doesn't.

```js
countVowels("Hello");         // 2
countVowels("JAVASCRIPT is"); // 4
countVowels("rhythm");        // 0
countVowels("");              // 0
```

Finish `countVowels(text)` so it returns the number of vowels in `text`.

<Hint>

Lower-case the text once with `text.toLowerCase()`, then loop over its characters with `for (const char of …)` and count the ones that `"aeiou".includes(char)`.

</Hint>

<Solution>

```js
function countVowels(text) {
  let count = 0;
  for (const char of text.toLowerCase()) {
    if ("aeiou".includes(char)) count++;
  }
  return count;
}

console.log(countVowels("Hello")); // 2
```

A shorter version filters an array of characters: `[...text.toLowerCase()].filter((c) => "aeiou".includes(c)).length`.

</Solution>
