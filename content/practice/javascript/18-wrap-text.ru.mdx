Принтер чеков в кафе для панд умещает в строку всего несколько символов. Напишите функцию (function) `wrapText(text, width)`, которая разбивает `text` на строки и возвращает их в виде массива (array) строк.

- Слова в тексте разделены пробельными символами: пробелами, табуляциями или переводами строки — в любом количестве.
- Заполняйте каждую строку **жадно** (greedy): помещайте в неё столько слов, сколько влезает, разделяя их одним пробелом, так чтобы длина строки была не больше `width`. Затем начните следующую строку со слова, которое не влезло.
- Слово, которое само по себе длиннее `width`, занимает отдельную строку целиком, без разрыва (иначе его не напечатать).
- В начале и в конце строк нет пробелов. Текст без слов даёт `[]`.

```js
wrapText("Bamboo tea and dumplings for two pandas", 12);
// [ 'Bamboo tea', 'and', 'dumplings', 'for two', 'pandas' ]
// ('and dumplings' — это 13 символов, слишком широко для 12)

wrapText("one two three", 7);   // [ 'one two', 'three' ]   ('one two' — ровно 7)
wrapText("hi supercalifragilistic yo", 5);
// [ 'hi', 'supercalifragilistic', 'yo' ]
wrapText("   \n  ", 10);        // []
```

<Solution>

```js
function wrapText(text, width) {
  const words = text.split(/\s+/).filter((word) => word !== "");
  const lines = [];
  let line = "";
  for (const word of words) {
    if (line === "") {
      line = word;
    } else if (line.length + 1 + word.length <= width) {
      line += " " + word;
    } else {
      lines.push(line);
      line = word;
    }
  }
  if (line !== "") lines.push(line);
  return lines;
}

console.log(wrapText("one two three", 7)); // [ 'one two', 'three' ]
```

Жадная идея: добавлять слова в текущую строку, пока следующее не перестанет влезать (с учётом пробела перед ним), а затем начинать новую строку. Слово, которое начинает строку, принимается всегда — так слишком длинные слова и оказываются в одиночестве. Каждое слово просматривается один раз, так что сложность — O(n) от длины текста.

</Solution>
