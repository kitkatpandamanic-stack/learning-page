Смотрительница записывает, сколько килограммов бамбука Мэй съедает каждый день. Теперь она хочет узнать, в какие `size` дней подряд бамбука было съедено больше всего.

Напишите функцию (function) `bestStretch(kilos, size)`, которая возвращает **индекс первого дня** этой серии.

- Серия — это `size` соседних дней: при `size` равном 3 это дни 0–2, дни 1–3, дни 2–4 и так далее.
- Если у двух серий одинаковая сумма, верните более раннюю.
- Если `size` меньше 1 или больше количества дней, серии нет: верните `-1`.

```js
bestStretch([3, 8, 2, 9, 7, 1], 2); // 3  (9 + 7 = 16 — лучшая пара)
bestStretch([3, 8, 2, 9, 7, 1], 3); // 1  (8 + 2 + 9 = 19)
bestStretch([5, 1, 5, 1], 2);       // 0  (у всех пар сумма 6: побеждает первая)
bestStretch([4, 2], 5);             // -1
```

<Solution>

```js
function bestStretch(kilos, size) {
  if (size < 1 || size > kilos.length) return -1;
  let bestStart = -1;
  let bestTotal = -Infinity;
  for (let start = 0; start + size <= kilos.length; start++) {
    let total = 0;
    for (let i = start; i < start + size; i++) total += kilos[i];
    if (total > bestTotal) {
      bestTotal = total;
      bestStart = start;
    }
  }
  return bestStart;
}

console.log(bestStretch([3, 8, 2, 9, 7, 1], 2)); // 3
```

Для каждой стартовой позиции считается своя сумма, а `>` (а не `>=`) при равенстве оставляет самую раннюю серию. Есть приём быстрее — **скользящее окно** (sliding window): сдвигаясь на один день, прибавьте новый день и вычтите тот, что выпал, вместо того чтобы снова складывать всю серию.

</Solution>
