Опциональная цепочка (optional chaining, `a?.b?.c`) отлично работает, когда путь известен уже при написании кода. Но иногда путь приходит только в виде текста — например, из файла настроек. Напишите функцию (function) `getPath(obj, path, fallback)`, которая проходит по пути с точками через вложенные объекты (object) и возвращает то, что там найдёт.

- `path` — строка из ключей, разделённых точками, например `"owner.address.city"`. Позиции в массиве — тоже ключи: `"pandas.0.name"` — это `obj.pandas[0].name`.
- Если какой-то шаг попадает на `null` или `undefined` раньше конца пути, или значение в конце равно `undefined`, верните `fallback`. Если `fallback` не передан, это `undefined`.
- Любое другое значение в конце возвращается как есть, **включая** `0`, `""`, `false` и `null`.
- Пустой путь `""` возвращает сам `obj`.

```js
const zoo = {
  name: "Bamboo Park",
  owner: { name: "Sam", address: { city: "Leeds" } },
  pandas: [{ name: "Mei", age: 4 }, { name: "Bao", age: 0 }],
  manager: null,
};

getPath(zoo, "owner.address.city");          // 'Leeds'
getPath(zoo, "pandas.1.name");               // 'Bao'
getPath(zoo, "pandas.1.age", 99);            // 0
getPath(zoo, "owner.phone", "none");         // 'none'
getPath(zoo, "manager.name", "nobody");      // 'nobody'
getPath(zoo, "manager", "nobody");           // null
```

Допишите `getPath(obj, path, fallback)`, чтобы функция возвращала значение в конце пути.

<Hint>

`path.split(".")` даёт список ключей. Пройдите по ним с `let current = obj`, выполняя для каждого `current = current[key]`. Квадратные скобки работают и для ключей объекта, и для позиций в массиве вроде `"1"`.

</Hint>

<Hint>

Перед каждым шагом проверяйте `if (current === null || current === undefined) return fallback;`. В конце запасным значением должно заменяться только `undefined`, поэтому используйте `current === undefined ? fallback : current`, а не `current || fallback` или `current ?? fallback`. Помните, что `"".split(".")` — это `[""]`, а не `[]`.

</Hint>

<Solution>

```js
function getPath(obj, path, fallback) {
  if (path === "") return obj;
  let current = obj;
  for (const key of path.split(".")) {
    if (current === null || current === undefined) return fallback;
    current = current[key];
  }
  return current === undefined ? fallback : current;
}

const zoo = {
  name: "Bamboo Park",
  owner: { name: "Sam", address: { city: "Leeds" } },
  pandas: [{ name: "Mei", age: 4 }, { name: "Bao", age: 0 }],
  manager: null,
};

console.log(getPath(zoo, "owner.address.city")); // Leeds
```

Это опциональная цепочка, сделанная вручную: остановиться, как только шаг попал на `null` или `undefined`. А сравнение `=== undefined` в конце (вместо `||` или `??`) пропускает настоящие значения вроде `0`, `false` и `null`.

</Solution>
