`===` сравнивает объекты по ссылке, поэтому `{ name: "Mei" } === { name: "Mei" }` даёт `false`. Напишите рекурсивную функцию (function) `deepEqual(a, b)`, которая вместо этого сравнивает **содержимое**. Значения состоят из примитивов, массивов (array) и простых объектов (object), вложенных сколь угодно глубоко.

- Примитивы равны, когда так говорит `===`, но `NaN` равно `NaN`.
- Два массива равны, когда у них одинаковая длина и их элементы глубоко равны, позиция за позицией.
- Два простых объекта равны, когда у них одинаковый набор собственных ключей (в любом порядке) и значения под каждым ключом глубоко равны. `{ a: undefined }` и `{}` **не** равны, потому что у них разные ключи.
- Массив никогда не равен простому объекту, даже пустому, а `null` равен только `null`.
- Всё остальное (например, функции) равно только самому себе, по `===`.

```js
deepEqual({ name: "Mei", tags: ["red", "fluffy"] }, { tags: ["red", "fluffy"], name: "Mei" }); // true
deepEqual([1, [2, [3]]], [1, [2, [3]]]);  // true
deepEqual([1, 2], [2, 1]);                // false
deepEqual({ a: undefined }, {});          // false
deepEqual([], {});                        // false
deepEqual(NaN, NaN);                      // true
deepEqual(null, {});                      // false
```

<Hint>

Это задача на рекурсию: два контейнера равны, когда равны их части. Сначала разберите быстрые случаи (примитивы, `NaN`, `null`) и помните, что `typeof []` — тоже `"object"`.

</Hint>

<Hint>

Возвращайте `true`, если `a === b` или оба значения — `NaN` (`Number.isNaN`). Дальше, если хотя бы одно значение не объект (`typeof value !== "object"`) или `null`, возвращайте `false`. Если `Array.isArray(a)` не совпадает с `Array.isArray(b)`, тоже `false`. Затем сравните списки ключей из `Object.keys`: одинаковая длина, и каждый ключ `a` — собственный ключ `b` (`Object.hasOwn`), значения под которым равны по `deepEqual`. Массивы обрабатываются тем же кодом, потому что их ключи — это индексы.

</Hint>

<Solution>

```js
function deepEqual(a, b) {
  if (a === b || (Number.isNaN(a) && Number.isNaN(b))) return true;
  if (typeof a !== "object" || typeof b !== "object") return false;
  if (a === null || b === null) return false;
  if (Array.isArray(a) !== Array.isArray(b)) return false;

  const keysA = Object.keys(a);
  const keysB = Object.keys(b);
  if (keysA.length !== keysB.length) return false;
  return keysA.every((key) => Object.hasOwn(b, key) && deepEqual(a[key], b[key]));
}

console.log(deepEqual({ name: "Mei" }, { name: "Mei" })); // true
```

После быстрых проверок на примитивы, `null` и «массив против объекта» оба значения сравниваются ключ за ключом, и один и тот же код подходит и для массивов (их ключи — индексы), и для объектов. Рекурсия останавливается на примитивах, и каждое значение посещается один раз: O(n) для n значений в сумме.

</Solution>
