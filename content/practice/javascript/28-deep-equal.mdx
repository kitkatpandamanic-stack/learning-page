`===` compares objects by reference, so `{ name: "Mei" } === { name: "Mei" }` is `false`. Write a recursive function `deepEqual(a, b)` that compares the **contents** instead. Values are made of primitives, arrays and plain objects, nested as deep as you like.

- Primitives are equal when `===` says so, except that `NaN` equals `NaN`.
- Two arrays are equal when they have the same length and their items are deeply equal, position by position.
- Two plain objects are equal when they have the same set of own keys (in any order) and the values under each key are deeply equal. `{ a: undefined }` and `{}` are **not** equal, because their keys differ.
- An array never equals a plain object, even an empty one, and `null` only equals `null`.
- Anything else (like functions) is equal only to itself, by `===`.

```js
deepEqual({ name: "Mei", tags: ["red", "fluffy"] }, { tags: ["red", "fluffy"], name: "Mei" }); // true
deepEqual([1, [2, [3]]], [1, [2, [3]]]);  // true
deepEqual([1, 2], [2, 1]);                // false
deepEqual({ a: undefined }, {});          // false
deepEqual([], {});                        // false
deepEqual(NaN, NaN);                      // true
deepEqual(null, {});                      // false
```

<Hint>

Handle the simple cases first: `a === b` covers the same primitive and the same object, and `Number.isNaN` covers `NaN` with `NaN`. If either value is `null` or not an object (`typeof value !== "object"`), and that test failed, they're not equal.

</Hint>

<Hint>

For two objects, compare `Array.isArray(a)` with `Array.isArray(b)` first. Then compare the lists of keys from `Object.keys` (same length, and every key of `a` is an own key of `b`, checked with `Object.hasOwn`), and call `deepEqual` on the values under each key. Arrays work with the same code, because their keys are the indexes.

</Hint>

<Solution>

```js
function deepEqual(a, b) {
  if (a === b || (Number.isNaN(a) && Number.isNaN(b))) return true;
  if (typeof a !== "object" || typeof b !== "object") return false;
  if (a === null || b === null) return false;
  if (Array.isArray(a) !== Array.isArray(b)) return false;

  const keysA = Object.keys(a);
  const keysB = Object.keys(b);
  if (keysA.length !== keysB.length) return false;
  return keysA.every((key) => Object.hasOwn(b, key) && deepEqual(a[key], b[key]));
}

console.log(deepEqual({ name: "Mei" }, { name: "Mei" })); // true
```

After the quick checks for primitives, `null` and array-versus-object, both values are compared key by key, and the same code serves arrays (whose keys are the indexes) and objects. The recursion stops at primitives, and every value is visited once: O(n) for n values in total.

</Solution>
