У приложения есть настройки по умолчанию, а каждый пользователь меняет некоторые из них. Spread (`{ ...defaults, ...user }`) объединяет только верхний уровень: пользователь, поменявший один цвет, потерял бы все остальные цвета. Напишите функцию (function) `mergeSettings(defaults, overrides)`, которая объединяет **глубоко** и возвращает новый объект (object):

- В результате есть все ключи из обоих объектов.
- Если по ключу в обоих объектах лежит **простой объект** (что-то вроде `{ … }`: не массив и не `null`), они объединяются тем же способом — на всю глубину.
- В остальных случаях побеждает значение из `overrides`. Это касается и массивов (они заменяются, а не объединяются), и `null`, и случаев, когда объект заменяет простое значение или наоборот.
- Ключ, значение которого в `overrides` равно `undefined`, игнорируется: остаётся значение по умолчанию.
- Ни один из входных объектов не должен меняться, и каждый простой объект в результате должен быть **новым**: изменение `result.theme.colors.bg` не должно менять `defaults`.

```js
const defaults = {
  theme: { mode: "light", colors: { bg: "white", text: "black" } },
  sounds: true,
  shortcuts: ["ctrl+s"],
};
const user = {
  theme: { colors: { bg: "bamboo-green" } },
  shortcuts: ["cmd+s"],
  sounds: undefined,
};

mergeSettings(defaults, user);
// {
//   theme: { mode: 'light', colors: { bg: 'bamboo-green', text: 'black' } },
//   sounds: true,
//   shortcuts: [ 'cmd+s' ]
// }
```

Допишите `mergeSettings(defaults, overrides)`, чтобы функция возвращала глубоко объединённые настройки.

<Hint>

Напишите маленькую вспомогательную функцию `isPlainObject(value)`, которая возвращает истину, когда `typeof value === "object"`, `value !== null` и `!Array.isArray(value)`. Затем пройдите по ключам `defaults` и `overrides`, собирая новый объект `result`.

</Hint>

<Hint>

Сначала скопируйте в `result` все ключи `defaults`. Затем для каждого ключа `overrides`: пропустите `undefined`; если с обеих сторон простые объекты, присвойте `result[key] = mergeSettings(result[key], value)`; иначе просто запишите переопределение. Чтобы даже непереопределённые объекты были новыми, копируйте простой объект из `defaults` через `mergeSettings(value, {})`.

</Hint>

<Solution>

```js
function isPlainObject(value) {
  return typeof value === "object" && value !== null && !Array.isArray(value);
}

function mergeSettings(defaults, overrides) {
  const result = {};
  for (const [key, value] of Object.entries(defaults)) {
    result[key] = isPlainObject(value) ? mergeSettings(value, {}) : value;
  }
  for (const [key, value] of Object.entries(overrides)) {
    if (value === undefined) continue;
    if (isPlainObject(value)) {
      const base = isPlainObject(result[key]) ? result[key] : {};
      result[key] = mergeSettings(base, value);
    } else {
      result[key] = value;
    }
  }
  return result;
}

const defaults = {
  theme: { mode: "light", colors: { bg: "white", text: "black" } },
  sounds: true,
  shortcuts: ["ctrl+s"],
};
const user = { theme: { colors: { bg: "bamboo-green" } }, shortcuts: ["cmd+s"], sounds: undefined };
console.log(mergeSettings(defaults, user));
```

Функция вызывает сама себя для каждой пары простых объектов, поэтому работает на любой глубине, и всегда собирает совершенно новый `result` — вот почему у результата нет общих объектов с входными данными. Объединение объекта-переопределения с `{}` копирует его, так что объекты из `overrides` тоже оказываются новыми. Каждый ключ посещается один раз на каждом уровне, так что сложность — O(общее число ключей).

</Solution>
