Напишите функцию (function) `repeatFn(fn, times)`, которая принимает функцию с одним аргументом и целое число и возвращает **новую функцию**. Вызов новой функции с `x` применяет `fn` к `x`, затем `fn` к полученному результату и так далее — всего `times` раз:

- `repeatFn(fn, 3)(x)` — то же самое, что `fn(fn(fn(x)))`.
- `repeatFn(fn, 0)(x)` просто возвращает `x`.
- Сама `repeatFn` не должна вызывать `fn`. Это делает только вызов новой функции, и каждый вызов начинает заново со своего `x`.

```js
const addTwo = (x) => x + 2;
repeatFn(addTwo, 3)(1);              // 7
repeatFn((x) => x * 2, 10)(1);       // 1024
repeatFn((s) => s + "!", 3)("Hi");   // 'Hi!!!'
repeatFn(addTwo, 0)(5);              // 5
```

Допишите `repeatFn(fn, times)`, чтобы функция возвращала повторяющую функцию.

<Hint>

`repeatFn` должна делать `return (x) => { … }`. Вся работа происходит внутри этой стрелочной функции, поэтому ничего не случится, пока её кто-нибудь не вызовет.

</Hint>

<Hint>

Внутри скопируйте `x` в `let result`, а затем в цикле `times` раз выполните `result = fn(result)`. Заводите новый `result` при каждом вызове, а не одну общую переменную снаружи стрелочной функции.

</Hint>

<Solution>

```js
function repeatFn(fn, times) {
  return (x) => {
    let result = x;
    for (let i = 0; i < times; i++) {
      result = fn(result);
    }
    return result;
  };
}

const addTwo = (x) => x + 2;
console.log(repeatFn(addTwo, 3)(1)); // 7
```

`repeatFn` — это **функция высшего порядка** (higher-order function): она принимает функцию и возвращает новую. Цикл находится внутри возвращаемой функции, поэтому `fn` выполняется только при её вызове, а `result` каждый раз начинается заново.

</Solution>
