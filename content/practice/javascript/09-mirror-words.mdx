Some words are their own mirror image: "noon", "level", "racecar". Write a function `mirrorWords(text)` that finds all of them in a piece of text.

- A **word** is a run of the letters `a`–`z` or `A`–`Z`. Everything else (spaces, punctuation, digits) separates words, so `"noon,"` is the word `noon`, and `"don't"` is the two words `don` and `t`.
- A mirror word reads the same backwards, ignoring case, and is **at least 3 letters** long (so `"a"` and `"oo"` don't count).
- Return the mirror words in lower case, in the order they first appear, each one only once.

```js
mirrorWords("Anna saw a racecar at noon, ANNA!"); // [ 'anna', 'racecar', 'noon' ]
mirrorWords("Wow, level 42 up!");                 // [ 'wow', 'level' ]
mirrorWords("oo a bb");                           // []
mirrorWords("");                                  // []
```

<Solution>

```js
function mirrorWords(text) {
  const words = text.toLowerCase().match(/[a-z]+/g) ?? [];
  const found = [];
  for (const word of words) {
    const backwards = [...word].reverse().join("");
    if (word.length >= 3 && word === backwards && !found.includes(word)) {
      found.push(word);
    }
  }
  return found;
}

console.log(mirrorWords("Anna saw a racecar at noon, ANNA!"));
// [ 'anna', 'racecar', 'noon' ]
```

Lower-casing first means "Anna" and "ANNA" become the same word, which handles both the comparison and the duplicates. `match` with the `g` flag returns every run of letters, and `?? []` covers text with no letters at all.

</Solution>
