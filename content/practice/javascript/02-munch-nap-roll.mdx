A panda counts the hours of its day from 1 to `n`, but some hours are special. Write a function `munchNap(n)` that returns an array with one string for each number from 1 to `n`:

- If the number is a multiple of 3, the string contains `"Munch"`.
- If it's a multiple of 4, the string contains `"Nap"`.
- If one of its digits is a 7, the string contains `"Roll"`.
- The words are joined in exactly that order: Munch, then Nap, then Roll (so 72 is `"MunchNapRoll"`).
- A number that matches none of the rules becomes the number itself, as a string (`"5"`, not `5`).

If `n` is less than 1, return an empty array.

```js
munchNap(5);      // [ '1', '2', 'Munch', 'Nap', '5' ]
munchNap(12)[11]; // 'MunchNap'  (the 12th item is for 12)
munchNap(27)[26]; // 'MunchRoll'
munchNap(70)[69]; // 'Roll'
munchNap(0);      // []
```

Finish `munchNap(n)` so it builds the list of strings for the numbers 1 to `n`.

<Hint>

Loop with `for (let i = 1; i <= n; i++)`. Start each round with an empty string `let word = ""` and add `"Munch"`, `"Nap"` and `"Roll"` with three separate `if`s, in that order. Use `%` for the multiples, and `String(i).includes("7")` for the digit.

</Hint>

<Hint>

After the three checks, if `word` is still empty, use `String(i)` instead. Then `push` it onto your result array.

</Hint>

<Solution>

```js
function munchNap(n) {
  const day = [];
  for (let i = 1; i <= n; i++) {
    let word = "";
    if (i % 3 === 0) word += "Munch";
    if (i % 4 === 0) word += "Nap";
    if (String(i).includes("7")) word += "Roll";
    day.push(word || String(i));
  }
  return day;
}

console.log(munchNap(5)); // [ '1', '2', 'Munch', 'Nap', '5' ]
```

Building the word piece by piece with separate `if`s (not `else if`) means the "both" cases like `MunchNap` come for free, with no extra rule for multiples of 12. `word || String(i)` uses the number only when no rule added anything.

</Solution>
