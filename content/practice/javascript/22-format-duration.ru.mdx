Трекер сна панд хранит дневной сон в секундах, а такое никто не хочет читать. Напишите `formatDuration(seconds, options)`, которая превращает секунды в слова. Текст получается на английском — так его ждёт интерфейс трекера, а для нас это хороший повод потренировать правила склейки строк (string).

- Разложите `seconds` на дни (86 400 с), часы (3600 с), минуты (60 с) и секунды, начиная с самой крупной единицы, и пропустите единицы, равные `0`.
- Каждая часть — это число и единица: в единственном числе для 1 (`"1 minute"` — «1 минута») и во множественном для остальных (`"2 minutes"`).
- Соединяйте части как в предложении: одна часть — как есть, две части — через `" and "` («и»), а больше частей — через `", "`, кроме последних двух, которые соединяются через `" and "`.
- `0` секунд даёт `"now"` («сейчас»).
- С `{ short: true }` во втором аргументе пишите `d`, `h`, `m` и `s` сразу после числа и соединяйте части одиночными пробелами, так что `0` даёт `"0s"`.
- `seconds` должно быть целым числом, 0 или больше. Всё остальное (`-1`, `1.5`, `NaN`, `"60"`) выбрасывает `RangeError`.

```js
formatDuration(62);                     // "1 minute and 2 seconds"
formatDuration(3600);                   // "1 hour"
formatDuration(3725);                   // "1 hour, 2 minutes and 5 seconds"
formatDuration(90061);                  // "1 day, 1 hour, 1 minute and 1 second"
formatDuration(0);                      // "now"
formatDuration(3725, { short: true });  // "1h 2m 5s"
formatDuration(-5);                     // RangeError
```

Допишите `formatDuration(seconds, options)`.

<Hint>

Храните единицы в массиве вроде `[["day", "d", 86400], ["hour", "h", 3600], ...]`. Для каждой из них `Math.floor(seconds / size)` — сколько таких единиц помещается, а `seconds % size` — что остаётся для единиц поменьше.

</Hint>

<Hint>

Собирайте слова в массив `parts`. Для длинного формата, если частей больше одной, снимите последнюю через `parts.pop()`, соедините остальные через `", "` и добавьте `" and "` плюс последнюю часть.

</Hint>

<Solution>

```js
const UNITS = [
  ["day", "d", 86400],
  ["hour", "h", 3600],
  ["minute", "m", 60],
  ["second", "s", 1],
];

function formatDuration(seconds, options = {}) {
  if (!Number.isInteger(seconds) || seconds < 0) {
    throw new RangeError("seconds должно быть целым числом, 0 или больше");
  }
  const parts = [];
  let left = seconds;
  for (const [name, letter, size] of UNITS) {
    const count = Math.floor(left / size);
    left %= size;
    if (count === 0) continue;
    if (options.short) parts.push(count + letter);
    else parts.push(count + " " + name + (count === 1 ? "" : "s"));
  }
  if (options.short) return parts.length ? parts.join(" ") : "0s";
  if (parts.length === 0) return "now";
  if (parts.length === 1) return parts[0];
  const last = parts.pop();
  return parts.join(", ") + " and " + last;
}

console.log(formatDuration(3725)); // 1 hour, 2 minutes and 5 seconds
```

Идём от самой крупной единицы к самой мелкой: каждый шаг забирает столько целых единиц, сколько помещается, и передаёт остаток дальше. Внимания требует только правило склейки: все части, кроме последней, разделяются запятыми, а последняя присоединяется через «and».

</Solution>
