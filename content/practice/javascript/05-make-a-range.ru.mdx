Встроенного `range()` в JavaScript нет, так что напишем свой. Напишите функцию (function) `range(start, end, step)`, которая возвращает массив (array) чисел: начинает с `start`, каждый раз сдвигается на `step` и останавливается **до того**, как дойдёт до `end` (сам `end` никогда не входит в результат).

- `step` необязателен, по умолчанию он равен `1`.
- Если `range` вызвана с одним аргументом (argument), этот аргумент — `end`, а `start` равен `0`: `range(4)` — это `[0, 1, 2, 3]`.
- Отрицательный `step` считает вниз: `range(5, 0, -2)` — это `[5, 3, 1]`.
- Если шаг направлен не туда (например, считать вверх от 5 до 1) или `step` равен `0`, верните пустой массив.

```js
range(4);         // [ 0, 1, 2, 3 ]
range(2, 6);      // [ 2, 3, 4, 5 ]
range(0, 10, 3);  // [ 0, 3, 6, 9 ]
range(5, 0, -2);  // [ 5, 3, 1 ]
range(5, 1);      // []
range(1, 5, 0);   // []
```

Допишите `range(start, end, step)`, чтобы функция возвращала числа из диапазона.

<Hint>

До подсчёта разберитесь с двумя вещами: что значит `range(n)` с одним аргументом и в какую сторону идут числа при отрицательном `step`. Осторожно с шагом `0`: с ним цикл никуда не сдвинется.

</Hint>

<Hint>

Если `end === undefined`, настоящий конец — это `start`, а настоящее начало — `0`. Для положительного шага используйте цикл `for (let i = start; i < end; i += step)`, для отрицательного условие переворачивается: `i > end`. При шаге `0` цикла нет совсем, и вы возвращаете `[]`. Диапазоны «не в ту сторону» не требуют особого кода — их цикл ни разу не выполнится.

</Hint>

<Hint>

```js
function range(start, end, step = 1) {
  if (end === undefined) {
    // один аргумент: считаем от 0 до start
  }
  const numbers = [];
  if (step > 0) {
    for (let i = start; i < end; i += step) numbers.push(i);
  } else if (step < 0) {
    ... // такой же цикл, но в обратную сторону
  }
  return numbers;
}
```

</Hint>

<Solution>

```js
function range(start, end, step = 1) {
  if (end === undefined) {
    end = start;
    start = 0;
  }
  const numbers = [];
  if (step > 0) {
    for (let i = start; i < end; i += step) numbers.push(i);
  } else if (step < 0) {
    for (let i = start; i > end; i += step) numbers.push(i);
  }
  return numbers;
}

console.log(range(2, 6)); // [ 2, 3, 4, 5 ]
```

Два цикла (loop) — по одному на каждое направление — и ни одного для шага `0` (иначе цикл крутился бы вечно). Диапазон, направленный не в ту сторону, сразу не проходит условие цикла и возвращается пустым.

</Solution>
