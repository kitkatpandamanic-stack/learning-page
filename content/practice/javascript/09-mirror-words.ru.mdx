Некоторые слова — сами себе зеркальное отражение: «noon» (полдень), «level» (уровень), «racecar» (гоночная машина). Такие слова называют палиндромами. Напишите функцию (function) `mirrorWords(text)`, которая находит их все в тексте.

- **Слово** — это непрерывная последовательность латинских букв `a`–`z` или `A`–`Z`. Всё остальное (пробелы, знаки препинания, цифры, а также кириллица) разделяет слова, так что `"noon,"` — это слово `noon`, а `"don't"` — два слова: `don` и `t`.
- Слово-перевёртыш читается одинаково справа налево без учёта регистра, и в нём **не меньше 3 букв** (поэтому `"a"` и `"oo"` не считаются).
- Верните слова-перевёртыши в нижнем регистре, в порядке первого появления, каждое только один раз.

```js
mirrorWords("Anna saw a racecar at noon, ANNA!"); // [ 'anna', 'racecar', 'noon' ]
mirrorWords("Wow, level 42 up!");                 // [ 'wow', 'level' ]
mirrorWords("oo a bb");                           // []
mirrorWords("");                                  // []
```

Допишите `mirrorWords(text)`, чтобы функция возвращала слова-перевёртыши.

<Hint>

Достаньте слова регулярным выражением: `text.toLowerCase().match(/[a-z]+/g)` возвращает массив последовательностей букв или `null`, если их нет (поэтому добавьте `?? []`).

</Hint>

<Hint>

Слово читается одинаково в обе стороны, когда `word === [...word].reverse().join("")`. Чтобы пропускать уже добавленные слова, используйте `Set` или `includes`.

</Hint>

<Solution>

```js
function mirrorWords(text) {
  const words = text.toLowerCase().match(/[a-z]+/g) ?? [];
  const found = [];
  for (const word of words) {
    const backwards = [...word].reverse().join("");
    if (word.length >= 3 && word === backwards && !found.includes(word)) {
      found.push(word);
    }
  }
  return found;
}

console.log(mirrorWords("Anna saw a racecar at noon, ANNA!"));
// [ 'anna', 'racecar', 'noon' ]
```

Если сначала перевести всё в нижний регистр, «Anna» и «ANNA» станут одним словом — это решает и сравнение, и повторы. `match` с флагом `g` возвращает все последовательности букв, а `?? []` выручает, когда букв в тексте нет вовсе.

</Solution>
