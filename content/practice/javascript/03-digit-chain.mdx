Take a whole number, add up its digits, and you get a new number. Do it again and again, and you always end up with a single digit: 9875 → 9 + 8 + 7 + 5 = 29 → 2 + 9 = 11 → 1 + 1 = 2.

Write a function `digitChain(n)` that returns that whole chain as an array of numbers, starting with the number itself and ending with the single digit.

- A negative number is treated as positive: the chain of `-38` starts at `38`.
- A number that already has one digit gives a chain of just that number.

```js
digitChain(9875); // [ 9875, 29, 11, 2 ]
digitChain(38);   // [ 38, 11, 2 ]
digitChain(-38);  // [ 38, 11, 2 ]
digitChain(7);    // [ 7 ]
digitChain(0);    // [ 0 ]
```

Finish `digitChain(n)` so it returns every number in the chain, from `n` down to a single digit.

<Hint>

The chain goes on while the number still has two or more digits. How can you tell that, and how could you peel the last digit off a number? Watch out for negative numbers.

</Hint>

<Hint>

Start with `let current = Math.abs(n)` and an array holding it. Keep going `while (current >= 10)`: work out the digit sum, push it, and make it the new `current`. To add up the digits, take the last one with `current % 10` and drop it with `Math.floor(current / 10)`, until nothing is left. A one-digit number skips the loop, so its chain is only itself.

</Hint>

<Hint>

```js
function digitChain(n) {
  let current = Math.abs(n);
  const chain = [current];
  while (current >= 10) {
    let sum = 0;
    // add up the digits of current into sum
    current = sum;
    chain.push(current);
  }
  return chain;
}
```

</Hint>

<Solution>

```js
function digitChain(n) {
  let current = Math.abs(n);
  const chain = [current];
  while (current >= 10) {
    let sum = 0;
    while (current > 0) {
      sum += current % 10;
      current = Math.floor(current / 10);
    }
    current = sum;
    chain.push(current);
  }
  return chain;
}

console.log(digitChain(9875)); // [ 9875, 29, 11, 2 ]
```

The outer loop runs once per step of the chain and the inner loop peels off one digit at a time. You could also add the digits with `String(current).split("").reduce((sum, d) => sum + Number(d), 0)`.

</Solution>
