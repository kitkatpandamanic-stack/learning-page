Поле поиска в магазине панд запрашивает у сервера подсказки при каждом нажатии клавиши. Ввод слова «бамбук» отправил бы шесть запросов! Напишите `debounceAsync(fn, ms)`, которая возвращает новую функцию `debounced`, а та по-настоящему вызывает `fn` только тогда, когда вызовы ненадолго прекращаются.

- Каждый вызов `debounced(...args)` возвращает промис (promise) и **перезапускает** таймер на `ms` миллисекунд.
- Когда таймер истекает без нового вызова, `fn` вызывается **один раз** с аргументами **последнего** вызова. Каждый промис, возвращённый с предыдущего запуска `fn` («группа» вызовов), завершается этим единственным результатом: разрешается значением `fn` или отклоняется с его ошибкой. `fn` может вернуть значение, вернуть промис или выбросить ошибку.
- Вызов, сделанный после того, как таймер истёк, начинает **новую** группу, даже если `fn` ещё занята предыдущей.
- `debounced.cancel()` останавливает ожидающий таймер, так что `fn` для текущей группы не вызывается, и отклоняет все промисы этой группы с `Error`, у которой сообщение `"Cancelled"` («Отменено»). Если ничего не ожидает, метод ничего не делает.

```js
const search = debounceAsync(async (text) => {
  console.log("Спрашиваем сервер про", text);
  return [`${text}: побеги`, `${text}: листья`];
}, 200);

const p1 = search("б");
const p2 = search("бам");
const p3 = search("бамбук");
// через 200 мс после последнего вызова: Спрашиваем сервер про бамбук
await p1;  // ["бамбук: побеги", "бамбук: листья"], и p2 с p3 — то же самое
```

<Hint>

Храните в замыкании (closure) три вещи: id таймера, аргументы последнего вызова и текущую группу — массив пар `{ resolve, reject }`, по одной на каждый ожидающий промис. Каждый вызов делает `clearTimeout`, сохраняет свои аргументы, добавляет свою пару и запускает новый `setTimeout`.

</Hint>

<Hint>

Когда таймер срабатывает, **сначала** заберите группу из замыкания (`const group = waiting; waiting = [];`), чтобы вызовы, пришедшие во время работы `fn`, начинали новую группу. Затем запустите `fn` внутри `new Promise((res) => res(fn(...args)))` и завершите каждую пару в `group` результатом. `cancel` забирает группу так же, но отклоняет промисы вместо вызова `fn`.

</Hint>

<Solution>

```js
function debounceAsync(fn, ms) {
  let timer = null;
  let lastArgs = [];
  let waiting = []; // { resolve, reject } для каждого вызова в группе

  function debounced(...args) {
    lastArgs = args;
    clearTimeout(timer);
    const promise = new Promise((resolve, reject) => {
      waiting.push({ resolve, reject });
    });
    timer = setTimeout(() => {
      timer = null;
      const group = waiting;
      waiting = [];
      new Promise((res) => res(fn(...lastArgs))).then(
        (value) => group.forEach((caller) => caller.resolve(value)),
        (error) => group.forEach((caller) => caller.reject(error)),
      );
    }, ms);
    return promise;
  }

  debounced.cancel = () => {
    if (timer === null) return;
    clearTimeout(timer);
    timer = null;
    const group = waiting;
    waiting = [];
    group.forEach((caller) => caller.reject(new Error("Cancelled")));
  };

  return debounced;
}

const shout = debounceAsync((text) => text.toUpperCase(), 50);
shout("б");
console.log(await shout("бамбук")); // БАМБУК
```

Замыкание хранит ожидающий таймер и функции `resolve`/`reject` каждого промиса текущей группы. Подмена массива `waiting` на свежий перед вызовом `fn` — вот что позволяет новой группе собраться, пока старая ещё работает. Каждый вызов и каждая завершённая группа выполняют постоянный объём работы на одного вызвавшего.

</Solution>
