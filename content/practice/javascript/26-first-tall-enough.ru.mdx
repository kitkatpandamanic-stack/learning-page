Бамбуковая плантация ведёт список высот стеблей, отсортированный от самого низкого к самому высокому, и он может быть **огромным**. Панда хочет найти первый стебель высотой не меньше `min` сантиметров. Напишите `firstAtLeast(heights, min)`, которая возвращает его индекс.

- `heights` отсортирован по возрастанию, и одна и та же высота может встречаться несколько раз. Верните индекс **первого** элемента, который `>= min`.
- Если все элементы ниже `min` (или массив пустой), верните `heights.length` — это место, куда вставили бы `min`.
- Перебирать элементы по одному для миллиона стеблей слишком медленно. Используйте **бинарный поиск** (binary search): ваша функция может заглянуть не больше чем в 25 элементов массива, даже если их миллион.

```js
const heights = [3, 8, 8, 8, 15, 21];
firstAtLeast(heights, 8);    // 1 (первая из восьмёрок)
firstAtLeast(heights, 9);    // 4
firstAtLeast(heights, 1);    // 0
firstAtLeast(heights, 99);   // 6 (ни один не достаточно высокий)
firstAtLeast([], 5);         // 0
```

Допишите `firstAtLeast(heights, min)` с бинарным поиском.

<Hint>

Храните два индекса, `low = 0` и `high = heights.length`, так, чтобы ответ всегда был где-то в `low..high`. Посмотрите на средний элемент: если он ниже `min`, ответ правее него (`low = mid + 1`); иначе ответом может быть сам средний элемент (`high = mid`).

</Hint>

<Hint>

Остановитесь, когда `low === high`: это и есть ответ. Для середины используйте `Math.floor((low + high) / 2)` и не останавливайтесь раньше, когда нашли элемент, равный `min`, — левее может быть ещё один такой же.

</Hint>

<Solution>

```js
function firstAtLeast(heights, min) {
  let low = 0;
  let high = heights.length;
  while (low < high) {
    const mid = Math.floor((low + high) / 2);
    if (heights[mid] < min) {
      low = mid + 1;
    } else {
      high = mid;
    }
  }
  return low;
}

console.log(firstAtLeast([3, 8, 8, 8, 15, 21], 9)); // 4
```

Ответ всегда остаётся между `low` и `high`, а каждый шаг вдвое сужает это окно, поэтому миллиону элементов хватает примерно 20 взглядов: O(log n). Именно сдвиг `high` на `mid` (а не на `mid - 1`) при совпадении находит первую из нескольких одинаковых высот.

</Solution>
