Write a function `letterTally(text)` that counts how often each letter appears in `text` and returns the counts as an object, like `{ a: 3, b: 1, n: 2 }`.

- Upper- and lower-case letters count as the same letter, and the keys are lower case.
- Only the 26 letters `a`–`z` are counted. Spaces, digits, punctuation and letters like `é` are ignored.
- Letters that don't appear don't get a key at all (no zeros).
- The keys must be in **alphabetical order**, so printing the object reads from A to Z.

```js
letterTally("banana");   // { a: 3, b: 1, n: 2 }
letterTally("Hello!!");  // { e: 1, h: 1, l: 2, o: 1 }
letterTally("123 ...");  // {}
```

Finish `letterTally(text)` so it returns the letter counts in alphabetical order.

<Hint>

Loop over `text.toLowerCase()` and keep only characters where `char >= "a" && char <= "z"`. Count them in an object with `counts[char] = (counts[char] ?? 0) + 1`.

</Hint>

<Hint>

An object keeps its keys in the order they were added. So once you've counted, build a second object by going through `Object.keys(counts).sort()` and copying each count across.

</Hint>

<Solution>

```js
function letterTally(text) {
  const counts = {};
  for (const char of text.toLowerCase()) {
    if (char >= "a" && char <= "z") {
      counts[char] = (counts[char] ?? 0) + 1;
    }
  }
  const sorted = {};
  for (const letter of Object.keys(counts).sort()) {
    sorted[letter] = counts[letter];
  }
  return sorted;
}

console.log(letterTally("banana")); // { a: 3, b: 1, n: 2 }
```

Comparing with `>=` and `<=` works because strings compare letter by letter, and `é` sorts after `z`. Copying into a new object in sorted key order is what puts the keys in A to Z order.

</Solution>
