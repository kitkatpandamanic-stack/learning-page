Любопытная панда забрела в лабиринт из живой изгороди в ботаническом саду. Напишите `route(grid)`, которая точно подскажет ей, как выйти кратчайшим путём.

- `grid` — массив (array) строк одинаковой длины. `S` — старт панды, `E` — выход (ровно по одному каждого), `#` — изгородь, а `.` — свободная клетка.
- За один ход панда переходит на одну клетку вниз, влево, вправо или вверх: `"D"` (down — вниз), `"L"` (left — влево), `"R"` (right — вправо) или `"U"` (up — вверх). Выходить за пределы сетки и заходить в изгородь нельзя.
- Верните **кратчайший** путь в виде строки ходов. Если кратчайших путей несколько, верните тот, что идёт первым **по алфавиту** (то есть на каждом шаге `D` лучше `L`, `L` лучше `R`, а `R` лучше `U` — пока путь остаётся кратчайшим).
- Если панда не может добраться до выхода, верните `null`.
- Лабиринты бывают размером 300 × 300 клеток, поэтому перебирать все возможные пути слишком медленно.

```js
route([
  "S.#",
  "..#",
  "#.E",
]);
// "DRDR" (RDDR такой же длины, но DRDR идёт первым по алфавиту)

route([
  "S.....",
  ".####.",
  ".#..#.",
  ".#E.#.",
  ".##.#.",
  "......",
]);
// "DDDDDRRRUUL"

route(["S#.", "##.", "..E"]);  // null
route(["ES"]);                  // "L"
```

<Hint>

**Поиск в ширину** (breadth-first search, BFS) находит кратчайшие расстояния на сетке. Подумайте, откуда его запускать: если знать, как далеко каждая клетка от **выхода**, выбирать каждый ход становится легко.

</Hint>

<Hint>

Запустите BFS от `E` и заполните двумерный массив `dist` (сначала везде `-1`) числом ходов от каждой клетки до выхода; используйте индекс в массиве-очереди вместо `queue.shift()`, который медленно работает на длинных массивах. Если `dist` у `S` так и осталось `-1`, верните `null`. Иначе идите от `S`: на каждом шаге пробуйте ходы в порядке `D`, `L`, `R`, `U` и берите первый, который ведёт в свободную клетку с расстоянием ровно на один меньше. Каждый шаг приближает к `E` на единицу, так что путь кратчайший, а выбор первой возможной буквы каждый раз делает его первым по алфавиту.

</Hint>

<Solution>

```js
const MOVES = [["D", 1, 0], ["L", 0, -1], ["R", 0, 1], ["U", -1, 0]];

function find(grid, char) {
  for (let r = 0; r < grid.length; r++) {
    const c = grid[r].indexOf(char);
    if (c !== -1) return [r, c];
  }
}

function route(grid) {
  const rows = grid.length;
  const cols = grid[0].length;
  const open = (r, c) =>
    r >= 0 && r < rows && c >= 0 && c < cols && grid[r][c] !== "#";

  // 1. BFS от выхода: dist[r][c] = число ходов от (r, c) до E.
  const dist = Array.from({ length: rows }, () => new Array(cols).fill(-1));
  const [er, ec] = find(grid, "E");
  dist[er][ec] = 0;
  const queue = [[er, ec]];
  for (let head = 0; head < queue.length; head++) {
    const [r, c] = queue[head];
    for (const [, dr, dc] of MOVES) {
      const nr = r + dr;
      const nc = c + dc;
      if (open(nr, nc) && dist[nr][nc] === -1) {
        dist[nr][nc] = dist[r][c] + 1;
        queue.push([nr, nc]);
      }
    }
  }

  // 2. Идём от S, каждый раз выбирая первую букву, которая приближает к выходу.
  let [r, c] = find(grid, "S");
  if (dist[r][c] === -1) return null;
  let path = "";
  while (dist[r][c] > 0) {
    for (const [letter, dr, dc] of MOVES) {
      const nr = r + dr;
      const nc = c + dc;
      if (open(nr, nc) && dist[nr][nc] === dist[r][c] - 1) {
        path += letter;
        r = nr;
        c = nc;
        break;
      }
    }
  }
  return path;
}

console.log(route(["S.#", "..#", "#.E"])); // DRDR
```

BFS от выхода сообщает каждой клетке, насколько она далеко от `E`, а дальше путь строится жадно: на кратчайшем пути всегда есть сосед на шаг ближе, и выбор первого по алфавиту такого соседа на каждом шаге даёт первый по алфавиту кратчайший путь. Обе фазы посещают каждую клетку постоянное число раз, так что это O(rows × cols).

</Solution>
