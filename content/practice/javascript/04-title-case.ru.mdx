В библиотеке панд названия книг набирают в спешке, и получается неаккуратно. Напишите функцию (function) `titleCase(text)`, которая наводит порядок в английском названии:

- Слова разделены пробелами. Лишние пробелы (в начале, в конце или несколько подряд) убираются, так что между словами остаётся ровно один пробел.
- Каждое слово начинается с заглавной буквы, а остальные буквы строчные: `"pANDA"` превращается в `"Panda"`.
- Исключение — короткие слова `a`, `an`, `the`, `and`, `or`, `of`, `in`, `on`, `at` и `to` (артикли, союзы и предлоги): они пишутся целиком строчными, **если только** это не первое и не последнее слово названия.
- Всё, что не пробел, — часть слова, поэтому `"well-known"` превращается в `"Well-known"`.

Пустое название или название из одних пробелов даёт `""`.

```js
titleCase("the lord OF the rings");     // 'The Lord of the Rings'
titleCase("  a   tale of two pandas "); // 'A Tale of Two Pandas'
titleCase("something to hold on to");   // 'Something to Hold on To'
titleCase("of");                        // 'Of'
titleCase("   ");                       // ''
```

Допишите `titleCase(text)`, чтобы функция возвращала приведённое в порядок название.

<Hint>

`text.trim().split(" ")` оставляет пустые строки там, где было несколько пробелов подряд, поэтому уберите их с помощью `.filter((word) => word !== "")`. Так получится чистый массив слов.

</Hint>

<Hint>

Пройдите по словам вместе с их индексами. Сначала переведите каждое слово в нижний регистр; если оно есть в вашем списке коротких слов и стоит не на индексе `0` и не на последнем индексе, оставьте его так. Иначе используйте `word[0].toUpperCase() + word.slice(1)`. В конце — `.join(" ")`.

</Hint>

<Solution>

```js
const LITTLE = ["a", "an", "the", "and", "or", "of", "in", "on", "at", "to"];

function titleCase(text) {
  const words = text.trim().split(" ").filter((word) => word !== "");
  return words
    .map((word, i) => {
      const lower = word.toLowerCase();
      const edge = i === 0 || i === words.length - 1;
      if (LITTLE.includes(lower) && !edge) return lower;
      return lower[0].toUpperCase() + lower.slice(1);
    })
    .join(" ");
}

console.log(titleCase("the lord OF the rings")); // The Lord of the Rings
```

Разбиение и фильтрация дают чистый список слов, а `map` бесплатно передаёт индекс каждого слова — этого достаточно, чтобы узнать первое и последнее. Сравнение целых слов в нижнем регистре через `includes` не даёт спутать «Theory» и «Atom» с «the» и «at».

</Solution>
