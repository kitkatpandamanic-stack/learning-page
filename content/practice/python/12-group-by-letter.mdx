Write a function `group_by_letter(words)` that returns a dictionary where each key is a lower-case first letter and each value is the list of words starting with that letter.

- Upper and lower case go in the same group: `"Plum"` goes under `"p"`.
- Keep each word exactly as written, in the order it appears.
- Keys appear in the order their first word appears.
- Skip empty strings. Repeated words are all kept.

```python
group_by_letter(["panda", "Plum", "apple", "pear"])
# {'p': ['panda', 'Plum', 'pear'], 'a': ['apple']}
group_by_letter([])   # {}
```

Finish `group_by_letter(words)` so it groups the words by their lower-case first letter.

<Hint>

For each non-empty word, take `word[0].lower()`. If that key isn't in the dictionary yet, give it an empty list; then append the word.

</Hint>

<Solution>

```python
def group_by_letter(words):
    groups = {}
    for word in words:
        if not word:
            continue
        letter = word[0].lower()
        if letter not in groups:
            groups[letter] = []
        groups[letter].append(word)
    return groups

print(group_by_letter(["panda", "Plum", "apple", "pear"]))
```

`groups.setdefault(letter, []).append(word)` does the "create if missing, then append" in one line.
