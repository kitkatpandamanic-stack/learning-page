The panda museum labels its exhibits with Roman numerals. Write two functions:

- `to_roman(number)` takes a whole number from 1 to 3999 and returns its Roman numeral as an upper-case string.
- `from_roman(text)` takes a valid Roman numeral (upper or lower case) and returns the number.

The symbols are `I` = 1, `V` = 5, `X` = 10, `L` = 50, `C` = 100, `D` = 500 and `M` = 1000. Symbols are written largest first and added up, except for six subtractive pairs where a smaller symbol comes before a larger one: `IV` = 4, `IX` = 9, `XL` = 40, `XC` = 90, `CD` = 400 and `CM` = 900. No symbol repeats more than three times in a row, so 4 is `IV`, never `IIII`.

```python
to_roman(3)        # 'III'
to_roman(1994)     # 'MCMXCIV'
to_roman(3999)     # 'MMMCMXCIX'
from_roman("XLII") # 42
from_roman("mmxxvi")  # 2026
```

<Solution>

```python
PAIRS = [
    (1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
    (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
    (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I"),
]
VALUES = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}

def to_roman(number):
    parts = []
    for value, symbol in PAIRS:
        while number >= value:
            parts.append(symbol)
            number -= value
    return "".join(parts)

def from_roman(text):
    digits = [VALUES[char] for char in text.upper()]
    total = 0
    for i, value in enumerate(digits):
        if i + 1 < len(digits) and digits[i + 1] > value:
            total -= value
        else:
            total += value
    return total

print(to_roman(1994))  # MCMXCIV
```

`to_roman` is greedy: putting the subtractive pairs in the table means the biggest piece that fits is always right. `from_roman` makes one pass with a dict lookup per symbol, so both directions are O(length of the numeral).
