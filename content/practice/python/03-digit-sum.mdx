Write a function `digit_sum(n)` that returns the sum of the digits of the whole number `n`. For a negative number, ignore the minus sign. The digit sum of `0` is `0`.

```python
digit_sum(123)    # 6   (1 + 2 + 3)
digit_sum(-482)   # 14  (4 + 8 + 2)
digit_sum(0)      # 0
```

Finish `digit_sum(n)` so it returns the sum of the digits of `n`.

<Hint>

Two operators split off digits: `n % 10` gives the last digit and `n // 10` drops it. What should happen to the minus sign of a negative number?

</Hint>

<Hint>

Start with `n = abs(n)` and a `total` of 0. While `n` is greater than 0, add `n % 10` to the total and then do `n //= 10`. For 0 the loop never runs, so the total stays 0.

</Hint>

<Hint>

<Solution>

```python
def digit_sum(n):
    n = abs(n)
    total = 0
    while n > 0:
        total += n % 10
        n //= 10
    return total

print(digit_sum(123))  # 6
```

Each round peels off the last digit with `% 10` and removes it with `// 10`. You could also turn the number into text: `sum(int(d) for d in str(abs(n)))`.
