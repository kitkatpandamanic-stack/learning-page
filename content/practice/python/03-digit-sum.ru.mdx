Напишите функцию (function) `digit_sum(n)`, которая возвращает сумму цифр целого числа `n`. У отрицательного числа знак минус не учитывается. Сумма цифр числа `0` равна `0`.

```python
digit_sum(123)    # 6   (1 + 2 + 3)
digit_sum(-482)   # 14  (4 + 8 + 2)
digit_sum(0)      # 0
```

Допишите `digit_sum(n)`, чтобы функция возвращала сумму цифр `n`.

<Hint>

`n % 10` — это последняя цифра, а `n // 10` её отбрасывает. Повторяйте, пока от числа ничего не останется. Начните с `abs(n)`, чтобы избавиться от знака.

</Hint>

<Solution>

```python
def digit_sum(n):
    n = abs(n)
    total = 0
    while n > 0:
        total += n % 10
        n //= 10
    return total

print(digit_sum(123))  # 6
```

На каждом шаге `% 10` берёт последнюю цифру, а `// 10` её убирает. Можно также превратить число в строку: `sum(int(d) for d in str(abs(n)))`.

</Solution>
