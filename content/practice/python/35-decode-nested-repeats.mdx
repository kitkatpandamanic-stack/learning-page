Pandas send each other compressed messages. In the code, `k[...]` means "the part inside the brackets, repeated `k` times", and these can be nested. Everything outside brackets is copied as it is.

Write two functions:

- `expand(code)` returns the full message as a string.
- `expanded_length(code)` returns the length of the full message **without** building it, because some messages are far too big to fit in memory.

The codes are always valid: a count is one or more digits (it can be `0` or bigger than 9) and is always followed by `[`, every `[` has a matching `]`, and digits never appear anywhere else. Other characters are letters, spaces or punctuation.

```python
expand("3[ab]")          # 'ababab'
expand("2[a3[b]]c")      # 'abbbabbbc'
expand("x10[y]")         # 'xyyyyyyyyyy'
expand("0[abc]ok")       # 'ok'
expand("")               # ''

expanded_length("2[a3[b]]c")              # 9
expanded_length("1000000[1000000[hi]]")   # 2000000000000
```

The part inside `k[...]` is itself a complete code, maybe with its own brackets. That's a sign for recursion. The tricky part is that after the inner call returns, the caller needs to know where to carry on reading.

<Solution>

```python
def _read(code, i, as_length):
    # Read from position i up to a "]" or the end.
    # Returns (text or length, position after what was read).
    parts = []
    total = 0
    while i < len(code) and code[i] != "]":
        if code[i].isdigit():
            j = i
            while code[j].isdigit():
                j += 1
            count = int(code[i:j])
            inner, i = _read(code, j + 1, as_length)  # j is the "["
            i += 1                                     # skip the "]"
            if as_length:
                total += count * inner
            else:
                parts.append(inner * count)
        else:
            if as_length:
                total += 1
            else:
                parts.append(code[i])
            i += 1
    return (total if as_length else "".join(parts)), i

def expand(code):
    return _read(code, 0, False)[0]

def expanded_length(code):
    return _read(code, 0, True)[0]

print(expand("2[a3[b]]c"))  # abbbabbbc
```

Each pair of brackets is one recursive call, which returns where it stopped so the caller can carry on after the `]`. Both functions read every character of the code once, so `expanded_length` is O(length of the code) however huge the message is, while `expand` also has to spend time and memory on every character of the result.

</Solution>
