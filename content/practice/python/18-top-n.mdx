Write a function `top_n(items, key, n=3)` that returns a list of the `n` items with the highest `key(item)`, best first. `key` is a function, like `len`, `abs` or a `lambda`.

- When two items have the same score, keep them in the order they had in `items`.
- If there are fewer than `n` items, return all of them, best first.
- If `n` is 0 or negative, return `[]`.
- Don't change the list you were given.

```python
pandas = [("Mei", 12), ("Bao", 30), ("Lin", 30), ("Tao", 7)]
top_n(pandas, lambda p: p[1], 2)
# [('Bao', 30), ('Lin', 30)]

top_n(["kiwi", "fig", "banana", "plum"], len)
# ['banana', 'kiwi', 'plum']   (kiwi and plum tie: kiwi came first)
```

Finish `top_n(items, key, n=3)` so it returns the best `n` items by `key`.

<Hint>

`sorted()` takes the same kind of function: `sorted(items, key=key, reverse=True)`. Python's sort is *stable*, so items with equal scores keep their order, even with `reverse=True`.

</Hint>

<Hint>

Be careful with the slice: `[:-1]` means "all but the last", so a negative `n` needs its own check.

</Hint>

<Solution>

```python
def top_n(items, key, n=3):
    if n <= 0:
        return []
    return sorted(items, key=key, reverse=True)[:n]

print(top_n(["kiwi", "fig", "banana", "plum"], len))  # ['banana', 'kiwi', 'plum']
```

Passing `key` straight on to `sorted()` is the whole trick: your function decides what "best" means. Sorting with `reverse=True` keeps ties in order, while sorting ascending and then reversing the list would flip them. Sorting costs O(n log n).

</Solution>
