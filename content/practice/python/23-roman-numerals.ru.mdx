Музей панд подписывает экспонаты римскими цифрами. Напишите две функции (function):

- `to_roman(number)` принимает целое число от 1 до 3999 и возвращает его римскую запись строкой в верхнем регистре.
- `from_roman(text)` принимает корректную римскую запись (в верхнем или нижнем регистре) и возвращает число.

Символы такие: `I` = 1, `V` = 5, `X` = 10, `L` = 50, `C` = 100, `D` = 500 и `M` = 1000. Символы записываются от большего к меньшему и складываются. Исключение — шесть вычитающих пар, где меньший символ стоит перед большим: `IV` = 4, `IX` = 9, `XL` = 40, `XC` = 90, `CD` = 400 и `CM` = 900. Ни один символ не повторяется больше трёх раз подряд, поэтому 4 — это `IV`, а не `IIII`.

```python
to_roman(3)        # 'III'
to_roman(1994)     # 'MCMXCIV'
to_roman(3999)     # 'MMMCMXCIX'
from_roman("XLII") # 42
from_roman("mmxxvi")  # 2026
```

<Solution>

```python
PAIRS = [
    (1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
    (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
    (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I"),
]
VALUES = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}

def to_roman(number):
    parts = []
    for value, symbol in PAIRS:
        while number >= value:
            parts.append(symbol)
            number -= value
    return "".join(parts)

def from_roman(text):
    digits = [VALUES[char] for char in text.upper()]
    total = 0
    for i, value in enumerate(digits):
        if i + 1 < len(digits) and digits[i + 1] > value:
            total -= value
        else:
            total += value
    return total

print(to_roman(1994))  # MCMXCIV
```

`to_roman` — жадный алгоритм (greedy algorithm): раз вычитающие пары есть в таблице, самый большой подходящий кусок всегда оказывается верным. `from_roman` делает один проход и один поиск в словаре (dictionary) на символ, так что оба направления работают за O(длина записи).

</Solution>
