Each bamboo shop sends a dictionary of stock changes, like `{"bamboo": 3, "apple": -1}` (negative means items went out). Write a function `merge_counts(counts_list)` that takes a list of these dictionaries and returns **one new** dictionary with the totals.

- A key's total is the sum of its values in every dictionary that has it.
- Leave out keys whose total is exactly `0`.
- An empty list (or a list of empty dictionaries) gives `{}`.
- Don't change any of the dictionaries you were given.

```python
merge_counts([{"bamboo": 3, "apple": 1}, {"bamboo": 2, "pear": 4}])
# {'bamboo': 5, 'apple': 1, 'pear': 4}
merge_counts([{"leaf": 2}, {"leaf": -2, "nut": 1}])
# {'nut': 1}
merge_counts([])   # {}
```

<Solution>

```python
def merge_counts(counts_list):
    totals = {}
    for counts in counts_list:
        for key, value in counts.items():
            totals[key] = totals.get(key, 0) + value
    return {key: total for key, total in totals.items() if total != 0}

print(merge_counts([{"bamboo": 3, "apple": 1}, {"bamboo": 2, "pear": 4}]))
```

Summing first and filtering last means a key can pass through zero and come back without special cases. Each key-value pair is visited once, so the work is O(total number of entries). `collections.Counter` can add dictionaries too, but `Counter + Counter` also drops negative totals, which isn't what we want here.

</Solution>
