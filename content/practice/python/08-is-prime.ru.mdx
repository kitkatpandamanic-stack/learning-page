Простое число (prime number) — это целое число больше 1, которое делится без остатка только на 1 и на само себя: 2, 3, 5, 7, 11, 13, …

Напишите функцию (function) `is_prime(n)`, которая возвращает `True`, если `n` простое, и `False` в противном случае. Числа меньше 2 (включая 0 и отрицательные) простыми не считаются.

```python
is_prime(7)    # True
is_prime(9)    # False  (3 × 3)
is_prime(2)    # True   (единственное чётное простое число)
is_prime(1)    # False
```

Допишите `is_prime(n)`, чтобы функция возвращала, простое ли `n`.

<Hint>

Пробуйте делить на 2, 3, 4, … и остановитесь, как только какое-то число разделит без остатка (`n % d == 0`). Делители достаточно перебирать, пока `d * d <= n`: если у `n` есть делитель побольше, у него есть и меньший «напарник», которого вы уже проверили.

</Hint>

<Solution>

```python
def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

print(is_prime(7))  # True
```

Делители идут парами (для 91: 7 × 13), и меньший в каждой паре не больше квадратного корня из `n`. Если останавливаться на нём, для 7919 понадобится около 89 попыток вместо 7917.

</Solution>
