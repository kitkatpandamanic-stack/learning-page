Two words are anagrams when they use exactly the same letters the same number of times, like `listen` and `silent`. Write a function `anagram_groups(words)` that returns a list of groups (lists of words), where each group holds words that are anagrams of each other.

- Ignore case when comparing: `"Tea"` and `"EAT"` are anagrams. Keep each word exactly as written.
- Inside a group, words keep their order from `words`. Groups are ordered by where their first word appears.
- A word with no anagram partner forms a group on its own. Repeated words stay in their group.
- An empty list gives `[]`.

```python
anagram_groups(["listen", "Silent", "panda", "enlist", "adnap"])
# [['listen', 'Silent', 'enlist'], ['panda', 'adnap']]
anagram_groups(["aab", "abb", "bab"])
# [['aab'], ['abb', 'bab']]
```

<Solution>

```python
def anagram_groups(words):
    groups = {}
    for word in words:
        signature = "".join(sorted(word.lower()))
        if signature not in groups:
            groups[signature] = []
        groups[signature].append(word)
    return list(groups.values())

print(anagram_groups(["listen", "Silent", "panda", "enlist", "adnap"]))
```

Sorting the letters gives anagrams the same dictionary key, so one pass puts every word straight into its group. With n words of up to k letters that is O(n · k log k), much faster than comparing every pair of words.
