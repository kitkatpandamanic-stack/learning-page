Write a function `second_largest(numbers)` that returns the second-largest **different** value in the list.

- Repeats of the largest value don't count: in `[4, 9, 2, 9, 7]` the answer is `7`, not `9`.
- If there are fewer than two different values (an empty list, one item, or all the same), return `None`.
- Don't change the list you were given.

```python
second_largest([3, 8, 5])         # 5
second_largest([4, 9, 2, 9, 7])   # 7
second_largest([5, 5, 5])         # None
second_largest([-3, -1, -7])      # -3
```

<Hint>

Turn the list into a set to drop the repeats, then sort it with `sorted(...)`, which returns a new list and leaves the original alone. If fewer than two values are left, return `None`. Otherwise the runner-up is second from the end, `unique[-2]`.

</Hint>

<Solution>

```python
def second_largest(numbers):
    unique = sorted(set(numbers))
    if len(unique) < 2:
        return None
    return unique[-2]

print(second_largest([4, 9, 2, 9, 7]))  # 7
```

`sorted()` returns a new list, so the original is untouched. A single loop that tracks the best and second-best values so far would also work without sorting.
