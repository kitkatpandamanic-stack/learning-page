The Panda Times wants a "most used words" box. Write `top_words(text, k)` that returns a list of `(word, count)` tuples for the `k` most frequent words in `text`.

- Words are compared in lower case. A word is a run of letters `a` to `z`, which may contain apostrophes between letters (like `don't`). Everything else (spaces, digits, punctuation) separates words.
- Sort by count, highest first. Words with the same count go in alphabetical order.
- Return at most `k` tuples: fewer if the text has fewer different words, and an empty list if `k` is 0 or less.

```python
top_words("the panda and the bamboo and the tea", 2)
# [('the', 3), ('and', 2)]
top_words("b a c b a", 2)
# [('a', 2), ('b', 2)]   'a' and 'b' tie, so alphabetical
top_words("Don't stop. DON'T!", 5)
# [("don't", 2), ('stop', 1)]
top_words("", 3)
# []
```

<Solution>

```python
import re
from collections import Counter

def top_words(text, k):
    if k <= 0:
        return []
    words = re.findall(r"[a-z]+(?:'[a-z]+)*", text.lower())
    counts = Counter(words)
    ranked = sorted(counts.items(), key=lambda pair: (-pair[1], pair[0]))
    return ranked[:k]

print(top_words("the panda and the bamboo and the tea", 2))  # [('the', 3), ('and', 2)]
```

Counting is O(n) for n words, and sorting the m different words by `(-count, word)` is O(m log m). `Counter.most_common` alone isn't enough here, because it keeps tied words in the order they first appeared rather than alphabetically.

</Solution>
