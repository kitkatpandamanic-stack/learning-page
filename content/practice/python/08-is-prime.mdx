A prime number is a whole number greater than 1 that can only be divided evenly by 1 and itself: 2, 3, 5, 7, 11, 13, …

Write a function `is_prime(n)` that returns `True` if `n` is prime and `False` otherwise. Numbers below 2 (including 0 and negatives) are not prime.

```python
is_prime(7)    # True
is_prime(9)    # False  (3 × 3)
is_prime(2)    # True   (the only even prime)
is_prime(1)    # False
```

Finish `is_prime(n)` so it returns whether `n` is prime.

<Hint>

A number isn't prime if some smaller number above 1 divides it evenly (`n % d == 0`). Watch out for 0, 1 and negative numbers. And do you really need to try every divisor up to `n`?

</Hint>

<Hint>

Return `False` straight away when `n` is less than 2. Then try divisors `d` = 2, 3, 4, … while `d * d <= n`, and return `False` as soon as one divides evenly. If the loop ends without finding one, return `True`. Divisors come in pairs, and the smaller one of each pair is never bigger than the square root of `n`.

</Hint>

<Solution>

```python
def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

print(is_prime(7))  # True
```

Divisors come in pairs (for 91: 7 × 13), and the smaller one of each pair is at most the square root of `n`. Stopping there means about 89 tries for 7919 instead of 7917.

</Solution>
