Напишите функцию (function) `flatten(items)`. Она принимает список (list), в котором могут быть другие списки любой глубины вложенности, и возвращает новый плоский список из всех значений, которые не являются списками, в исходном порядке слева направо.

- Распаковываются только списки. Строки, кортежи, словари и всё остальное остаются отдельными значениями.
- Пустые списки просто исчезают.
- Не меняйте список, который вам передали.

```python
flatten([1, [2, 3], [4, [5, [6]]]])     # [1, 2, 3, 4, 5, 6]
flatten(["bamboo", ["panda", ["red"]]])  # ['bamboo', 'panda', 'red']
flatten([[], [[]], 7])                  # [7]
flatten([(1, 2), [3]])                  # [(1, 2), 3]
flatten([])                             # []
```

Допишите `flatten(items)`, чтобы функция возвращала один плоский список.

<Hint>

Пройдите циклом по элементам. Если элемент — список (`isinstance(item, list)`), разверните *его* рекурсивным вызовом и добавьте все результаты; иначе добавьте сам элемент.

</Hint>

<Solution>

```python
def flatten(items):
    result = []
    for item in items:
        if isinstance(item, list):
            result.extend(flatten(item))
        else:
            result.append(item)
    return result

print(flatten([1, [2, 3], [4, [5, [6]]]]))  # [1, 2, 3, 4, 5, 6]
```

Базовый случай (base case) — значение, которое не является списком: оно добавляется как есть. Каждый вложенный список превращается в уменьшенную версию той же задачи. Каждое значение посещается один раз, поэтому работа занимает O(n), где n — общее число значений и списков.

</Solution>
