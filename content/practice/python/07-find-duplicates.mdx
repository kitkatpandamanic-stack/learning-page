Write a function `find_duplicates(items)` that returns a list of the values that appear **more than once** in `items`.

- Each duplicate appears only once in the result.
- Order the result by where each value **first** appears in `items`.
- Strings are compared exactly, so `"Bamboo"` and `"bamboo"` are different.
- No duplicates (or an empty list) gives `[]`.

```python
find_duplicates([3, 1, 3, 2, 1, 3])   # [3, 1]
find_duplicates([1, 2, 2, 1])         # [1, 2]   (1 appears first)
find_duplicates(["leaf", "nut"])      # []
```

Finish `find_duplicates(items)` so it returns each repeated value once, in order of first appearance.

<Hint>

To know whether a value repeats, you need to count it. Which data structure can count values and also remember the order you first saw them in?

</Hint>

<Hint>

Count every value in a dictionary first, with `counts[item] = counts.get(item, 0) + 1`. Dictionaries keep the order keys were added, so the keys are already in first-appearance order. Then keep only the keys whose count is more than 1. Don't add a value the moment you see it a second time: for `[1, 2, 2, 1]` that gives the wrong order.

</Hint>

<Solution>

```python
def find_duplicates(items):
    counts = {}
    for item in items:
        counts[item] = counts.get(item, 0) + 1
    return [item for item, count in counts.items() if count > 1]

print(find_duplicates([3, 1, 3, 2, 1, 3]))  # [3, 1]
```

The dictionary does two jobs: it counts, and its keys keep the order each value was first seen. Adding a value to the result the moment you see it a second time would give `[2, 1]` for `[1, 2, 2, 1]`, which is the wrong order.
