Смотрителям панд платят за каждый рабочий день. Напишите `count_workdays(start, end, holidays=())`, которая считает рабочие дни от `start` до `end`, **включая обе даты**.

- `start`, `end` и все элементы `holidays` — даты, записанные строками в формате ISO, например `"2026-10-05"`.
- Рабочий день — это понедельник, вторник, среда, четверг или пятница, которых нет в `holidays`. Праздник, выпавший на выходной, ничего не меняет.
- Если `end` раньше `start`, верните `0`.

```python
count_workdays("2026-10-05", "2026-10-09")   # 5 (с понедельника по пятницу)
count_workdays("2026-10-05", "2026-10-18")   # 10 (две полные недели)
count_workdays("2026-10-03", "2026-10-04")   # 0 (выходные)
count_workdays("2026-12-21", "2027-01-03",
               ["2026-12-25", "2027-01-01"])  # 8
count_workdays("2026-10-09", "2026-10-05")   # 0 (end раньше start)
```

Допишите `count_workdays`, чтобы функция считала рабочие дни между двумя датами.

<Hint>

Превратите строки в объекты `date` с помощью `date.fromisoformat`, а праздники — в множество (set) дат, чтобы проверка была быстрой. Затем шагайте от `start` до `end` с помощью `timedelta(days=1)`.

</Hint>

<Hint>

`day.weekday()` равно 0 для понедельника и так далее до 6 для воскресенья, поэтому будние дни — это те, где значение меньше 5.

</Hint>

<Solution>

```python
from datetime import date, timedelta

def count_workdays(start, end, holidays=()):
    day = date.fromisoformat(start)
    last = date.fromisoformat(end)
    days_off = {date.fromisoformat(h) for h in holidays}
    count = 0
    while day <= last:
        if day.weekday() < 5 and day not in days_off:
            count += 1
        day += timedelta(days=1)
    return count

print(count_workdays("2026-10-05", "2026-10-09"))  # 5
```

Объекты `date` уже знают длину месяцев и про високосные годы, поэтому прибавление по одному дню всегда даёт верный результат. Это O(d) для d дней в диапазоне плюс поиск в множестве за O(1) для праздников.

</Solution>
