Write a function `word_counts(text)` that returns a dictionary mapping each word in `text` to how many times it appears.

- Split the text into words on whitespace (`text.split()` does this).
- Lower-case every word, so `"The"` and `"the"` are the same word.
- Strip the punctuation characters `.,!?;:` from both ends of each word.
- If a word is nothing but punctuation, skip it.

```python
word_counts("The panda ate. The PANDA slept!")
# {'the': 2, 'panda': 2, 'ate': 1, 'slept': 1}
word_counts("Hi! hi? hi.")   # {'hi': 3}
word_counts("")              # {}
```

Finish `word_counts(text)` so it counts each cleaned-up word.

<Hint>

`word.strip(".,!?;:")` removes any of those characters from both ends. Then count with `counts[word] = counts.get(word, 0) + 1`, skipping words that ended up empty.

</Hint>

<Solution>

```python
def word_counts(text):
    counts = {}
    for word in text.lower().split():
        word = word.strip(".,!?;:")
        if word:
            counts[word] = counts.get(word, 0) + 1
    return counts

print(word_counts("The panda ate. The PANDA slept!"))
```

`.get(word, 0)` returns 0 for a word you haven't seen yet, so the same line handles new and repeated words. `collections.Counter` does the counting part for you once you've cleaned the words.
