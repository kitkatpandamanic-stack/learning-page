Палиндром читается одинаково слева направо и справа налево, как «racecar». Напишите функцию (function) `is_palindrome(text)`, которая возвращает `True`, если `text` — палиндром, и `False` в противном случае.

- Учитываются только буквы и цифры: пропускайте пробелы, запятые, двоеточия и любые другие символы.
- Регистр не важен, так что `"A"` и `"a"` совпадают.
- Текст совсем без букв и цифр (включая `""`) считается палиндромом: верните `True`.

```python
is_palindrome("racecar")                          # True
is_palindrome("A man, a plan, a canal: Panama!")  # True
is_palindrome("Panda")                            # False
is_palindrome("")                                 # True
```

<Hint>

</Hint>

<Solution>

```python
def is_palindrome(text):
    cleaned = ""
    for char in text:
        if char.isalnum():
            cleaned += char.lower()
    return cleaned == cleaned[::-1]

print(is_palindrome("racecar"))  # True
```

После очистки задача сводится к простой проверке «равна ли строка самой себе задом наперёд?». Пустая очищенная строка равна своей перевёрнутой версии, так что для этого крайнего случая лишний код не нужен.

</Solution>
