Напишите функцию (function) `compress(text)`, которая заменяет каждую серию одинаковых символов на сам символ и число его повторений.

- Серия длины 1 записывается просто символом: `"abc"` остаётся `"abc"`.
- Серию образуют только символы, стоящие **рядом**: `"abab"` остаётся `"abab"`.
- Регистр важен: `"a"` и `"A"` — разные символы.
- В числе может быть несколько цифр: двенадцать букв `z` превращаются в `"z12"`.
- Пустая строка даёт `""`.

```python
compress("aaabb")     # 'a3b2'
compress("aabcccd")   # 'a2bc3d'
compress("aabaa")     # 'a2ba2'
compress("abc")       # 'abc'
```

Допишите `compress(text)`, чтобы каждая серия превращалась в символ и число.

<Hint>

</Hint>

<Solution>

```python
def compress(text):
    result = ""
    i = 0
    while i < len(text):
        j = i
        while j < len(text) and text[j] == text[i]:
            j += 1
        length = j - i
        result += text[i] if length == 1 else f"{text[i]}{length}"
        i = j
    return result

print(compress("aaabb"))  # a3b2
```

Внутренний цикл находит конец текущей серии, а внешний начинает следующую серию прямо там, так что каждый символ просматривается один раз: O(n). Найти серии за вас может и `itertools.groupby(text)`.

</Solution>
