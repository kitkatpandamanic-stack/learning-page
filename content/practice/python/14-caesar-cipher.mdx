In a Caesar cipher every letter moves a fixed number of places along the alphabet: with a shift of 3, `a` becomes `d` and `z` wraps around to `c`. Write a function `caesar(text, shift)` that returns the shifted text.

- Upper-case letters stay upper-case, lower-case stay lower-case.
- Only the 26 letters `a`–`z` and `A`–`Z` move. Spaces, digits, punctuation and other letters such as `é` stay as they are.
- `shift` can be negative (shift backwards, which decodes) or bigger than 26 (it wraps around).

```python
caesar("panda", 3)    # 'sdqgd'
caesar("Zoo!", 1)     # 'App!'
caesar("sdqgd", -3)   # 'panda'
caesar("abc", 29)     # 'def'
caesar("café", 1)     # 'dbgé'
```

<Hint>

Keep `lower = "abcdefghijklmnopqrstuvwxyz"`. For a letter in it, `lower.index(char)` gives its position; add the shift and use `% 26` to wrap around (it also turns negative positions into the right ones).

</Hint>

<Hint>

Handle capitals with a second alphabet, `lower.upper()`, so `É` and friends simply fall through to "leave it as it is".

</Hint>

<Solution>

```python
def caesar(text, shift):
    lower = "abcdefghijklmnopqrstuvwxyz"
    upper = lower.upper()
    result = ""
    for char in text:
        if char in lower:
            result += lower[(lower.index(char) + shift) % 26]
        elif char in upper:
            result += upper[(upper.index(char) + shift) % 26]
        else:
            result += char
    return result

print(caesar("panda", 3))  # sdqgd
```

`% 26` keeps every new position between 0 and 25, whatever the shift: Python's `%` returns a non-negative result even for negative numbers, so `-1 % 26` is 25. Checking membership in the two alphabets (instead of `char.isalpha()`) is what leaves letters like `é` alone. The work is O(n) for n characters.
