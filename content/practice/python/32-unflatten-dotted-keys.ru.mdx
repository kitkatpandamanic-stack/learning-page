В файлах настроек часто используют ключи с точками, например `"db.host"`, а программам удобнее вложенные словари (dictionary). Напишите две функции, которые переводят одну форму в другую.

`unflatten(flat)` принимает словарь, ключи которого — пути через точку, и возвращает вложенные словари:

- `"db.host": "x"` означает `result["db"]["host"] == "x"`. Ключ без точек — значение верхнего уровня.
- Ключи никогда не бывают пустыми и не содержат пустых частей (не бывает `".a"`, `"a."` или `"a..b"`), а значения никогда не бывают словарями.
- Если один ключ оказывается одновременно значением **и** папкой, как `"db"` вместе с `"db.host"`, вызовите `ValueError` — независимо от того, какой из них идёт первым.

`flatten_keys(nested)` делает обратное: принимает вложенные словари (ключи без точек) и возвращает плоский словарь с путями через точку. Пустой вложенный словарь не добавляет ключей.

Ни одна из функций не должна менять свой аргумент.

```python
unflatten({"db.host": "localhost", "db.port": 5432, "debug": True})
# {'db': {'host': 'localhost', 'port': 5432}, 'debug': True}

unflatten({"a.b.c": 1, "a.b.d": 2, "a.e": 3})
# {'a': {'b': {'c': 1, 'd': 2}, 'e': 3}}

unflatten({"db": "sqlite", "db.host": "x"})   # ValueError

flatten_keys({"db": {"host": "localhost", "port": 5432}, "debug": True})
# {'db.host': 'localhost', 'db.port': 5432, 'debug': True}
```

<Solution>

```python
def unflatten(flat):
    result = {}
    for key, value in flat.items():
        *folders, last = key.split(".")
        node = result
        for part in folders:
            node = node.setdefault(part, {})
            if not isinstance(node, dict):
                raise ValueError(f"{key!r} clashes with an existing value")
        if last in node:
            raise ValueError(f"{key!r} clashes with an existing folder")
        node[last] = value
    return result

def flatten_keys(nested, prefix=""):
    flat = {}
    for key, value in nested.items():
        path = f"{prefix}.{key}" if prefix else key
        if isinstance(value, dict):
            flat.update(flatten_keys(value, path))
        else:
            flat[path] = value
    return flat

print(unflatten({"db.host": "localhost", "db.port": 5432, "debug": True}))
```

Поскольку значения никогда не бывают словарями, словарь в результате — это всегда папка, и оба вида конфликта легко заметить: путь к папке упирается в обычное значение или значение попадает туда, где уже есть папка. Обе функции обрабатывают каждую часть ключа один раз, так что сложность — O(суммарная длина всех ключей).

</Solution>
