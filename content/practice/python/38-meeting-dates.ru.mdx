Клуб панд собирается по датам вроде «последняя пятница месяца» или «второй вторник». Правила записываются по-английски: `"last friday"`, `"2nd Tuesday"`. Напишите `meeting_dates(rule, start, end)`, которая возвращает все даты встреч от `start` до `end` (включая обе).

- `rule` — это позиция, за которой идёт название дня недели, например `"last friday"` или `"2nd Tuesday"`. Позиция — одно из `first`, `second`, `third`, `fourth`, `fifth`, `1st`, `2nd`, `3rd`, `4th`, `5th` или `last`; день недели — от `monday` до `sunday`. Подходят и верхний, и нижний регистр, а также лишние пробелы между словами и вокруг них.
- Любое другое правило (неизвестные слова, недостающие части, лишние слова) вызывает `ValueError`.
- `start` и `end` — даты в формате ISO, например `"2026-10-05"`, а результат — список строк с датами ISO по порядку. Если `end` раньше `start`, список пуст.
- Месяцы, в которых нет нужного дня (в большинстве месяцев нет пятой субботы), пропускаются.

```python
meeting_dates("last friday", "2026-01-01", "2026-06-30")
# ['2026-01-30', '2026-02-27', '2026-03-27', '2026-04-24', '2026-05-29', '2026-06-26']

meeting_dates("2nd Tuesday", "2026-10-01", "2027-02-28")
# ['2026-10-13', '2026-11-10', '2026-12-08', '2027-01-12', '2027-02-09']

meeting_dates("fifth saturday", "2026-01-01", "2026-12-31")
# ['2026-01-31', '2026-05-30', '2026-08-29', '2026-10-31']

meeting_dates("  FIRST   monday ", "2026-10-06", "2026-12-07")
# ['2026-11-02', '2026-12-07']   (5 октября раньше start)

meeting_dates("every friday", "2026-01-01", "2026-12-31")   # ValueError
```

В `meeting_dates` идите от `(first.year, first.month)` до `(last.year, last.month)`, после 12-го месяца переходя к январю следующего года.

<Solution>

```python
import re
import calendar
from datetime import date

WEEKDAYS = ["monday", "tuesday", "wednesday", "thursday",
            "friday", "saturday", "sunday"]
POSITIONS = {"first": 1, "1st": 1, "second": 2, "2nd": 2, "third": 3, "3rd": 3,
             "fourth": 4, "4th": 4, "fifth": 5, "5th": 5, "last": -1}
RULE = re.compile(
    r"\s*(" + "|".join(POSITIONS) + r")\s+(" + "|".join(WEEKDAYS) + r")\s*",
    re.IGNORECASE,
)

def day_in_month(year, month, weekday, position):
    days = calendar.monthrange(year, month)[1]
    if position == -1:
        last = date(year, month, days)
        return date(year, month, days - (last.weekday() - weekday) % 7)
    first = date(year, month, 1)
    day = 1 + (weekday - first.weekday()) % 7 + 7 * (position - 1)
    return date(year, month, day) if day <= days else None

def meeting_dates(rule, start, end):
    match = RULE.fullmatch(rule)
    if match is None:
        raise ValueError(f"can't understand the rule {rule!r}")
    position = POSITIONS[match[1].lower()]
    weekday = WEEKDAYS.index(match[2].lower())
    first, last = date.fromisoformat(start), date.fromisoformat(end)
    year, month = first.year, first.month
    found = []
    while (year, month) <= (last.year, last.month):
        day = day_in_month(year, month, weekday, position)
        if day is not None and first <= day <= last:
            found.append(day.isoformat())
        year, month = (year + 1, 1) if month == 12 else (year, month + 1)
    return found

print(meeting_dates("2nd Tuesday", "2026-10-01", "2026-12-31"))
# ['2026-10-13', '2026-11-10', '2026-12-08']
```

`fullmatch` заставляет регулярное выражение проверить правило целиком, поэтому лишние слова или слова с опечатками не проходят, а не совпадают наполовину. Дальше для каждого месяца нужна лишь простая арифметика по модулю 7, так что работа занимает O(число месяцев) между двумя датами.
