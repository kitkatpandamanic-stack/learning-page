Write a function `rotate(items, k)` that returns a **new** list with the items rotated `k` steps to the right: the last `k` items move to the front, in order.

- A negative `k` rotates to the left instead.
- `k` can be bigger than the list: rotating a 3-item list by 7 is the same as rotating it by 1.
- An empty list gives `[]` for any `k`.
- Don't change the list you were given.

```python
rotate([1, 2, 3, 4, 5], 2)   # [4, 5, 1, 2, 3]
rotate([1, 2, 3], -1)        # [2, 3, 1]
rotate([1, 2, 3], 7)         # [3, 1, 2]
rotate([], 3)                # []
```

Finish `rotate(items, k)` so it returns the rotated copy.

<Hint>

`k % len(items)` turns any `k` (even a negative one) into a step count between 0 and `len(items) - 1`. Watch out: `% 0` is an error, so handle the empty list first.

</Hint>

<Hint>

With slicing, the last `k` items are `items[-k:]` and the ones before them are `items[:-k]`.

</Hint>

<Solution>

```python
def rotate(items, k):
    if not items:
        return []
    k %= len(items)
    return items[-k:] + items[:-k]

print(rotate([1, 2, 3, 4, 5], 2))  # [4, 5, 1, 2, 3]
```

After `k %= len(items)`, a left rotation by 1 has become a right rotation by `len - 1`, so one formula covers every case (for `k = 0`, `items[-0:]` is the whole list and `items[:-0]` is empty). Slices build new lists, so the original is untouched; the work is O(n).

</Solution>
