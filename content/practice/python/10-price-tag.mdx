The bamboo shop needs price tags. Write a function `price_tag(amount, currency="$", decimals=2)` that returns the price as text:

- the `currency` symbol, then the amount with commas between thousands and exactly `decimals` digits after the point (`decimals=0` means no point at all);
- for a negative amount, put a minus sign before the symbol: `-$5.00`.

Format specs do the hard part: `f"{1234.5:,.2f}"` gives `'1,234.50'`. The `,` adds thousands separators and `.2f` means "2 decimals".

```python
price_tag(4.5)                  # '$4.50'
price_tag(1234567.891)          # '$1,234,567.89'
price_tag(12, currency="€")     # '€12.00'
price_tag(9.99, decimals=0)     # '$10'
price_tag(-5)                   # '-$5.00'
price_tag(1000, "£", 1)         # '£1,000.0'
```

<Hint>

A format spec can contain a value too: `f"{amount:,.{decimals}f}"`. For negative amounts, format `abs(amount)` and put `"-"` in front yourself.

</Hint>

<Solution>

```python
def price_tag(amount, currency="$", decimals=2):
    number = f"{abs(amount):,.{decimals}f}"
    sign = "-" if amount < 0 else ""
    return f"{sign}{currency}{number}"

print(price_tag(4.5))  # $4.50
```

Formatting `abs(amount)` keeps the minus sign out of the number, so it can go before the currency symbol. The defaults mean callers only pass `currency` or `decimals` when they want something different.
