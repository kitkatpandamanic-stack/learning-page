A panda has some letter tiles and wants to see every different "word" it can lay out using **all** of them. Write `arrangements(tiles)` that returns a list of all the distinct strings that use each tile exactly once.

- `tiles` is a string; tiles with the same letter are identical, so `"aab"` has only 3 different arrangements, not 6.
- Return the strings in alphabetical order (the order `sorted()` gives), with no duplicates.
- `arrangements("")` returns `[""]`: there is exactly one way to lay out no tiles.

```python
arrangements("abc")    # ['abc', 'acb', 'bac', 'bca', 'cab', 'cba']
arrangements("aab")    # ['aab', 'aba', 'baa']
arrangements("zz")     # ['zz']
arrangements("")       # ['']
```

Watch out for lots of repeated tiles: `"aaaaaaaaaaab"` has only 12 different arrangements, but 479,001,600 orderings if you treat every tile as different. Generating all of those and removing duplicates afterwards takes far too long.

Finish `arrangements(tiles)` so it returns every distinct arrangement in sorted order.

<Hint>

Count how many of each letter you have (`collections.Counter`). To build an arrangement, choose the next letter from the *different* letters still available, use one, recurse, then put it back.

</Hint>

<Hint>

If you try the available letters in alphabetical order at every step, the results come out already sorted, and because you never choose the same letter twice at one position, no duplicates appear.

</Hint>

<Solution>

```python
from collections import Counter

def arrangements(tiles):
    counts = Counter(tiles)
    letters = sorted(counts)
    result = []

    def build(prefix):
        if len(prefix) == len(tiles):
            result.append(prefix)
            return
        for letter in letters:
            if counts[letter] > 0:
                counts[letter] -= 1
                build(prefix + letter)
                counts[letter] += 1

    build("")
    return result

print(arrangements("aab"))  # ['aab', 'aba', 'baa']
```

This is backtracking over letter counts instead of over tile positions: at each step only distinct letters are tried, so every path through the recursion makes a new arrangement and nothing is thrown away. The work is about O(r × n) for r results of length n, instead of O(n!) for all orderings.

</Solution>
