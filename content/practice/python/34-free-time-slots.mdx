The panda keeper's calendar is a mess: bookings overlap, touch each other, come in any order and sometimes spill outside working hours. Write `free_slots(bookings, min_minutes=1, day=("09:00", "17:00"))` that returns the free gaps in the working day.

- Every time is a 24-hour `"HH:MM"` string. Each booking is a `(start, end)` tuple with `start` before `end`; the panda is busy from `start` up to `end`.
- `day` is the `(start, end)` of the working day. Only time inside it counts; bookings partly or fully outside it are cut to fit or ignored.
- Return a list of `(start, end)` tuples of `"HH:MM"` strings, in time order, for every free gap that lasts at least `min_minutes` minutes. Gaps of zero minutes never appear (two bookings that touch leave no gap).

```python
bookings = [("10:00", "11:00"), ("09:30", "10:15"),
            ("13:00", "14:00"), ("13:30", "13:45"), ("16:50", "18:00")]

free_slots(bookings)
# [('09:00', '09:30'), ('11:00', '13:00'), ('14:00', '16:50')]

free_slots(bookings, min_minutes=60)
# [('11:00', '13:00'), ('14:00', '16:50')]

free_slots([])                                      # [('09:00', '17:00')]
free_slots([("09:00", "12:00"), ("12:00", "17:00")])  # []
```

Finish `free_slots` so it lists the free gaps in time order.

<Hint>

Turn each `"HH:MM"` into minutes since midnight so times are easy to compare and subtract, and only turn them back into strings at the end with `f"{m // 60:02d}:{m % 60:02d}"`.

</Hint>

<Hint>

Sort the bookings by start time and walk through them with a `free_from` time that starts at the beginning of the day. A booking that starts after `free_from` leaves a gap; either way, `free_from` moves to `max(free_from, booking_end)`. Don't forget the gap after the last booking.

</Hint>

<Solution>

```python
def to_minutes(hhmm):
    hours, minutes = hhmm.split(":")
    return int(hours) * 60 + int(minutes)

def to_hhmm(minutes):
    return f"{minutes // 60:02d}:{minutes % 60:02d}"

def free_slots(bookings, min_minutes=1, day=("09:00", "17:00")):
    day_start, day_end = to_minutes(day[0]), to_minutes(day[1])
    busy = sorted((to_minutes(s), to_minutes(e)) for s, e in bookings)
    gaps = []
    free_from = day_start
    for start, end in busy:
        start, end = max(start, day_start), min(end, day_end)
        if start >= end:
            continue  # outside the working day
        if start > free_from:
            gaps.append((free_from, start))
        free_from = max(free_from, end)
    if day_end > free_from:
        gaps.append((free_from, day_end))
    return [(to_hhmm(s), to_hhmm(e)) for s, e in gaps
            if e - s >= max(min_minutes, 1)]

print(free_slots([("10:00", "11:00"), ("09:30", "10:15")]))
# [('09:00', '09:30'), ('11:00', '17:00')]
```

After sorting by start, one sweep is enough: `free_from` is the end of everything booked so far, so overlapping, nested and touching bookings all merge naturally. Sorting dominates, giving O(n log n) for n bookings.

</Solution>
