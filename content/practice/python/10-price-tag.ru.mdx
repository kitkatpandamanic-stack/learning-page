Бамбуковому магазину нужны ценники. Напишите функцию (function) `price_tag(amount, currency="$", decimals=2)`, которая возвращает цену в виде текста:

- сначала символ валюты `currency`, затем сумма с запятыми между разрядами тысяч и ровно `decimals` цифрами после точки (`decimals=0` — точки нет вовсе);
- для отрицательной суммы знак минус ставится перед символом валюты: `-$5.00`.

Самую трудную часть берут на себя спецификаторы формата (format specs): `f"{1234.5:,.2f}"` даёт `'1,234.50'`. Запятая `,` добавляет разделители тысяч, а `.2f` означает «2 знака после точки».

```python
price_tag(4.5)                  # '$4.50'
price_tag(1234567.891)          # '$1,234,567.89'
price_tag(12, currency="€")     # '€12.00'
price_tag(9.99, decimals=0)     # '$10'
price_tag(-5)                   # '-$5.00'
price_tag(1000, "£", 1)         # '£1,000.0'
```

Допишите `price_tag(amount, currency="$", decimals=2)`, чтобы функция собирала текст цены.

<Hint>

Внутрь спецификатора формата тоже можно подставить значение: `f"{amount:,.{decimals}f}"`. Для отрицательных сумм форматируйте `abs(amount)` и сами ставьте `"-"` в начало.

</Hint>

<Solution>

```python
def price_tag(amount, currency="$", decimals=2):
    number = f"{abs(amount):,.{decimals}f}"
    sign = "-" if amount < 0 else ""
    return f"{sign}{currency}{number}"

print(price_tag(4.5))  # $4.50
```

Форматирование `abs(amount)` не пускает минус внутрь числа, поэтому его можно поставить перед символом валюты. Благодаря значениям по умолчанию вызывающий код передаёт `currency` или `decimals`, только когда ему нужно что-то другое.

</Solution>
