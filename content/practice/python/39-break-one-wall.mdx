A very strong panda is in a maze and wants to reach the exit in as few steps as possible. It can smash through **one** wall on the whole trip, but only one. Write `shortest_escape(grid)` that returns the smallest number of steps, or `-1` if the exit can't be reached.

- `grid` is a list of equal-length strings. `"S"` is the start, `"E"` the exit, `"."` an open square and `"#"` a wall. There is exactly one `S` and one `E`.
- Each step moves one square up, down, left or right, never diagonally and never off the grid.
- Stepping onto a wall square smashes it, and that step counts like any other. After one smash, every other wall blocks the way.

```python
shortest_escape(["S.#.E"])          # 4: walk through the smashed wall

shortest_escape(["S#...",
                 ".#.#.",
                 "...#E"])          # 6 (without smashing it would be 10)

shortest_escape(["S##E"])           # -1: two walls in the way
shortest_escape(["SE"])             # 1
```

Finish `shortest_escape(grid)`.

<Hint>

Breadth-first search with a `deque` finds the fewest steps, because it explores all squares 1 step away, then 2 steps away, and so on. The twist is that "standing on this square" isn't the whole story: it matters whether you've already used your smash.

</Hint>

<Hint>

Make the search state `(row, col, smashed)` where `smashed` is 0 or 1, and keep the visited set over those states. Reaching a square with your smash still unused is a *different* state from reaching it after smashing, and both are worth exploring.

</Hint>

<Solution>

```python
from collections import deque

def shortest_escape(grid):
    rows, cols = len(grid), len(grid[0])
    start = next((r, c) for r in range(rows) for c in range(cols)
                 if grid[r][c] == "S")
    queue = deque([(start[0], start[1], 0, 0)])  # row, col, smashed, steps
    seen = {(start[0], start[1], 0)}
    while queue:
        r, c, smashed, steps = queue.popleft()
        if grid[r][c] == "E":
            return steps
        for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
            if 0 <= nr < rows and 0 <= nc < cols:
                now_smashed = smashed + (grid[nr][nc] == "#")
                state = (nr, nc, now_smashed)
                if now_smashed <= 1 and state not in seen:
                    seen.add(state)
                    queue.append((nr, nc, now_smashed, steps + 1))
    return -1

print(shortest_escape(["S#...", ".#.#.", "...#E"]))  # 6
```

The search runs over every square twice, once with the smash unused and once with it used, so it's O(rows × columns). Trying each wall one at a time and running a fresh search would be O(walls × rows × columns), which is why the last check would take minutes that way.

</Solution>
