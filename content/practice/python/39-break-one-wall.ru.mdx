Очень сильная панда оказалась в лабиринте и хочет добраться до выхода за как можно меньшее число шагов. За весь путь она может проломить **одну** стену — но только одну. Напишите `shortest_escape(grid)`, которая возвращает наименьшее число шагов или `-1`, если до выхода не добраться.

- `grid` — список строк одинаковой длины. `"S"` — старт, `"E"` — выход, `"."` — свободная клетка, `"#"` — стена. Ровно одна `S` и одна `E`.
- Каждый шаг перемещает на одну клетку вверх, вниз, влево или вправо — никогда по диагонали и никогда за пределы поля.
- Шаг на клетку со стеной проламывает её, и этот шаг считается как обычный. После одного пролома все остальные стены преграждают путь.

```python
shortest_escape(["S.#.E"])          # 4: проходим через проломленную стену

shortest_escape(["S#...",
                 ".#.#.",
                 "...#E"])          # 6 (без пролома было бы 10)

shortest_escape(["S##E"])           # -1: на пути две стены
shortest_escape(["SE"])             # 1
```

<Solution>

```python
from collections import deque

def shortest_escape(grid):
    rows, cols = len(grid), len(grid[0])
    start = next((r, c) for r in range(rows) for c in range(cols)
                 if grid[r][c] == "S")
    queue = deque([(start[0], start[1], 0, 0)])  # строка, столбец, пролом, шаги
    seen = {(start[0], start[1], 0)}
    while queue:
        r, c, smashed, steps = queue.popleft()
        if grid[r][c] == "E":
            return steps
        for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
            if 0 <= nr < rows and 0 <= nc < cols:
                now_smashed = smashed + (grid[nr][nc] == "#")
                state = (nr, nc, now_smashed)
                if now_smashed <= 1 and state not in seen:
                    seen.add(state)
                    queue.append((nr, nc, now_smashed, steps + 1))
    return -1

print(shortest_escape(["S#...", ".#.#.", "...#E"]))  # 6
```

Поиск проходит каждую клетку дважды — один раз с неиспользованным проломом и один раз с использованным, — так что сложность O(строки × столбцы). Если пробовать проломить каждую стену по очереди и каждый раз запускать новый поиск, получится O(стены × строки × столбцы) — поэтому последняя проверка заняла бы так минуты.
