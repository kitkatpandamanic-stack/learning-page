Напишите `sudoku_conflicts(board)`, которая проверяет поле судоку на нарушения правил. `board` — список из 9 строк, каждая из которых — список из 9 целых чисел: от `1` до `9` для заполненной клетки и `0` для пустой.

В строке, столбце или квадрате 3×3 есть **конфликт**, если одна и та же цифра (от 1 до 9) встречается в нём больше одного раза. Пустые клетки никогда не конфликтуют.

- Строки и столбцы пронумерованы от 0 до 8. Квадраты тоже пронумерованы от 0 до 8 — слева направо и сверху вниз: квадрат 0 — левый верхний, квадрат 2 — правый верхний, квадрат 4 — центральный, квадрат 8 — правый нижний.
- Верните список кортежей (tuple) вида `("row", 0)`, `("col", 1)` или `("box", 4)`, по одному на каждую группу с конфликтом, отсортированный с помощью `sorted()`. Тогда сначала идут квадраты, затем столбцы, затем строки, каждые — по номеру.
- Поле без конфликтов (даже пустое или заполненное наполовину) даёт `[]`.

```python
solved = [[5, 3, 4, 6, 7, 8, 9, 1, 2],
          [6, 7, 2, 1, 9, 5, 3, 4, 8],
          [1, 9, 8, 3, 4, 2, 5, 6, 7],
          [8, 5, 9, 7, 6, 1, 4, 2, 3],
          [4, 2, 6, 8, 5, 3, 7, 9, 1],
          [7, 1, 3, 9, 2, 4, 8, 5, 6],
          [9, 6, 1, 5, 3, 7, 2, 8, 4],
          [2, 8, 7, 4, 1, 9, 6, 3, 5],
          [3, 4, 5, 2, 8, 6, 1, 7, 9]]
sudoku_conflicts(solved)   # []

solved[0][1] = 5           # теперь в строке 0, столбце 1 и квадрате 0 по две пятёрки
sudoku_conflicts(solved)   # [('box', 0), ('col', 1), ('row', 0)]
```

Допишите `sudoku_conflicts(board)`, чтобы функция перечисляла все группы, где повторяется цифра.

<Hint>

Клетка в строке `r` и столбце `c` относится к квадрату `(r // 3) * 3 + c // 3`.

</Hint>

<Hint>

Пройдите по клеткам один раз. Для каждой цифры запоминайте в множестве (set) пары `(группа, цифра)`, которые уже встречались; если та же пара попалась снова, добавьте эту группу в множество конфликтов.

</Hint>

<Solution>

```python
def sudoku_conflicts(board):
    seen = set()
    conflicts = set()
    for r in range(9):
        for c in range(9):
            digit = board[r][c]
            if digit == 0:
                continue
            box = (r // 3) * 3 + c // 3
            for unit in (("row", r), ("col", c), ("box", box)):
                if (unit, digit) in seen:
                    conflicts.add(unit)
                seen.add((unit, digit))
    return sorted(conflicts)

empty = [[0] * 9 for _ in range(9)]
print(sudoku_conflicts(empty))  # []
```

Каждая клетка принадлежит ровно одной строке, одному столбцу и одному квадрату, поэтому один проход с множеством пар `(unit, digit)` находит все повторы. Конфликты собираются в множество, так что группа с многими повторами указывается один раз; работа — O(1) на клетку.

</Solution>
