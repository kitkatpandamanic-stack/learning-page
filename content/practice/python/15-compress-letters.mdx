Write a function `compress(text)` that replaces every run of the same character with the character followed by how many times it repeats.

- A run of length 1 is written as just the character: `"abc"` stays `"abc"`.
- Only characters **next to each other** form a run: `"abab"` stays `"abab"`.
- Case matters: `"a"` and `"A"` are different characters.
- Counts can have several digits: twelve `z`s become `"z12"`.
- An empty string gives `""`.

```python
compress("aaabb")     # 'a3b2'
compress("aabcccd")   # 'a2bc3d'
compress("aabaa")     # 'a2ba2'
compress("abc")       # 'abc'
```

<Solution>

```python
def compress(text):
    result = ""
    i = 0
    while i < len(text):
        j = i
        while j < len(text) and text[j] == text[i]:
            j += 1
        length = j - i
        result += text[i] if length == 1 else f"{text[i]}{length}"
        i = j
    return result

print(compress("aaabb"))  # a3b2
```

The inner loop finds where the current run ends, and the outer loop starts the next run right there, so every character is looked at once: O(n). `itertools.groupby(text)` can find the runs for you too.

</Solution>
