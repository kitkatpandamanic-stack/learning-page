Write a function `count_vowels(text)` that returns how many vowels (`a`, `e`, `i`, `o`, `u`) are in `text`. Capital letters count too, and everything else (spaces, digits, other letters) doesn't.

```python
count_vowels("Hello")          # 2
count_vowels("PYTHON rocks")   # 2
count_vowels("rhythm")         # 0
count_vowels("")               # 0
```

<Hint>

Lower-case the text once with `text.lower()`, then loop over its characters and count the ones that are `in "aeiou"`.

</Hint>

<Solution>

```python
def count_vowels(text):
    count = 0
    for char in text.lower():
        if char in "aeiou":
            count += 1
    return count

print(count_vowels("Hello"))  # 2
```

A shorter version uses a generator expression: `sum(1 for char in text.lower() if char in "aeiou")`.
