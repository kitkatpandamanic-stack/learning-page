Write a function `flatten(items)` that takes a list which may contain other lists, nested to any depth, and returns a new flat list of all the non-list values in their original left-to-right order.

- Only lists are unpacked. Strings, tuples, dicts and everything else stay as single values.
- Empty lists simply disappear.
- Don't change the list you were given.

```python
flatten([1, [2, 3], [4, [5, [6]]]])     # [1, 2, 3, 4, 5, 6]
flatten(["bamboo", ["panda", ["red"]]])  # ['bamboo', 'panda', 'red']
flatten([[], [[]], 7])                  # [7]
flatten([(1, 2), [3]])                  # [(1, 2), 3]
flatten([])                             # []
```

<Hint>

Start with an empty `result` list and loop over the items. If an item is a list (`isinstance(item, list)`), flatten *it* with a recursive call and add all of the results with `result.extend(...)`; otherwise `append` the item itself. Only check for `list`, so strings, tuples and dicts stay whole. You build a new list, so the original is never changed, and empty lists add nothing.

</Hint>

<Solution>

```python
def flatten(items):
    result = []
    for item in items:
        if isinstance(item, list):
            result.extend(flatten(item))
        else:
            result.append(item)
    return result

print(flatten([1, [2, 3], [4, [5, [6]]]]))  # [1, 2, 3, 4, 5, 6]
```

The base case is a non-list value, which is added as it is; every inner list becomes a smaller version of the same problem. Each value is visited once, so the work is O(n) for n values and lists in total.
