В календаре смотрителя панд беспорядок: записи пересекаются, стыкуются друг с другом, идут в любом порядке и иногда выходят за рабочие часы. Напишите `free_slots(bookings, min_minutes=1, day=("09:00", "17:00"))`, которая возвращает свободные промежутки рабочего дня.

- Любое время — строка `"HH:MM"` в 24-часовом формате. Каждая запись — кортеж (tuple) `(start, end)`, где `start` раньше `end`; панда занята с `start` до `end`.
- `day` — это `(start, end)` рабочего дня. Учитывается только время внутри него; записи, которые частично или полностью выходят за его пределы, обрезаются или игнорируются.
- Верните список кортежей `(start, end)` из строк `"HH:MM"` в порядке времени — для каждого свободного промежутка длиной не меньше `min_minutes` минут. Промежутки нулевой длины никогда не попадают в результат (две стыкующиеся записи не оставляют промежутка).

```python
bookings = [("10:00", "11:00"), ("09:30", "10:15"),
            ("13:00", "14:00"), ("13:30", "13:45"), ("16:50", "18:00")]

free_slots(bookings)
# [('09:00', '09:30'), ('11:00', '13:00'), ('14:00', '16:50')]

free_slots(bookings, min_minutes=60)
# [('11:00', '13:00'), ('14:00', '16:50')]

free_slots([])                                      # [('09:00', '17:00')]
free_slots([("09:00", "12:00"), ("12:00", "17:00")])  # []
```

<Solution>

```python
def to_minutes(hhmm):
    hours, minutes = hhmm.split(":")
    return int(hours) * 60 + int(minutes)

def to_hhmm(minutes):
    return f"{minutes // 60:02d}:{minutes % 60:02d}"

def free_slots(bookings, min_minutes=1, day=("09:00", "17:00")):
    day_start, day_end = to_minutes(day[0]), to_minutes(day[1])
    busy = sorted((to_minutes(s), to_minutes(e)) for s, e in bookings)
    gaps = []
    free_from = day_start
    for start, end in busy:
        start, end = max(start, day_start), min(end, day_end)
        if start >= end:
            continue  # вне рабочего дня
        if start > free_from:
            gaps.append((free_from, start))
        free_from = max(free_from, end)
    if day_end > free_from:
        gaps.append((free_from, day_end))
    return [(to_hhmm(s), to_hhmm(e)) for s, e in gaps
            if e - s >= max(min_minutes, 1)]

print(free_slots([("10:00", "11:00"), ("09:30", "10:15")]))
# [('09:00', '09:30'), ('11:00', '17:00')]
```

После сортировки по началу достаточно одного прохода: `free_from` — это конец всего, что уже занято, поэтому пересекающиеся, вложенные и стыкующиеся записи сливаются сами собой. Больше всего времени занимает сортировка: O(n log n) для n записей.

</Solution>
