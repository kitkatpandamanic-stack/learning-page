Напишите функцию (function) `count_vowels(text)`, которая возвращает, сколько гласных (`a`, `e`, `i`, `o`, `u`) в строке `text`. Заглавные буквы тоже считаются, а всё остальное (пробелы, цифры, другие буквы) — нет.

```python
count_vowels("Hello")          # 2
count_vowels("PYTHON rocks")   # 2
count_vowels("rhythm")         # 0
count_vowels("")               # 0
```

<Hint>

Считаются и строчные, и заглавные гласные. Можно ли сначала привести весь текст к одному регистру, чтобы искать только `a`, `e`, `i`, `o` и `u`?

</Hint>

<Hint>

Один раз переведите текст в нижний регистр с помощью `text.lower()`. Затем пройдите по нему символ за символом и прибавляйте 1 к счётчику, когда символ `in "aeiou"`. В конце верните счётчик: для пустого текста цикл не выполнится ни разу, и получится 0.

</Hint>

<Solution>

```python
def count_vowels(text):
    count = 0
    for char in text.lower():
        if char in "aeiou":
            count += 1
    return count

print(count_vowels("Hello"))  # 2
```

Короче можно записать через выражение-генератор (generator expression): `sum(1 for char in text.lower() if char in "aeiou")`.

</Solution>
