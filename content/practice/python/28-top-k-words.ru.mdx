Газета «Панда Таймс» хочет сделать блок «самые частые слова». Напишите `top_words(text, k)`, которая возвращает список кортежей (tuple) `(word, count)` для `k` самых частых слов в `text`.

- Слова сравниваются в нижнем регистре. Слово — это последовательность латинских букв от `a` до `z`, внутри которой между буквами могут стоять апострофы (например, `don't`). Всё остальное (пробелы, цифры, знаки препинания) разделяет слова.
- Сортируйте по количеству, от большего к меньшему. Слова с одинаковым количеством идут в алфавитном порядке.
- Верните не больше `k` кортежей: меньше, если в тексте меньше разных слов, и пустой список, если `k` равно 0 или меньше.

```python
top_words("the panda and the bamboo and the tea", 2)
# [('the', 3), ('and', 2)]
top_words("b a c b a", 2)
# [('a', 2), ('b', 2)]   у 'a' и 'b' поровну, поэтому по алфавиту
top_words("Don't stop. DON'T!", 5)
# [("don't", 2), ('stop', 1)]
top_words("", 3)
# []
```

<Solution>

```python
import re
from collections import Counter

def top_words(text, k):
    if k <= 0:
        return []
    words = re.findall(r"[a-z]+(?:'[a-z]+)*", text.lower())
    counts = Counter(words)
    ranked = sorted(counts.items(), key=lambda pair: (-pair[1], pair[0]))
    return ranked[:k]

print(top_words("the panda and the bamboo and the tea", 2))  # [('the', 3), ('and', 2)]
```

Подсчёт занимает O(n) для n слов, а сортировка m разных слов по `(-count, word)` — O(m log m). Одного `Counter.most_common` здесь недостаточно: слова с равным количеством он оставляет в порядке первого появления, а не по алфавиту.

</Solution>
