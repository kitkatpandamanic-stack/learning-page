Write `sudoku_conflicts(board)` that checks a sudoku board for broken rules. `board` is a list of 9 rows, each a list of 9 whole numbers: `1` to `9` for a filled square and `0` for an empty one.

A row, column or 3×3 box has a **conflict** if the same digit (1 to 9) appears in it more than once. Empty squares never conflict.

- Rows and columns are numbered 0 to 8. Boxes are numbered 0 to 8 too, left to right and top to bottom: box 0 is the top-left, box 2 the top-right, box 4 the centre and box 8 the bottom-right.
- Return a list of tuples like `("row", 0)`, `("col", 1)` or `("box", 4)`, one for each unit with a conflict, sorted with `sorted()`. That puts boxes first, then columns, then rows, each by number.
- A board with no conflicts (even an empty or half-filled one) gives `[]`.

```python
solved = [[5, 3, 4, 6, 7, 8, 9, 1, 2],
          [6, 7, 2, 1, 9, 5, 3, 4, 8],
          [1, 9, 8, 3, 4, 2, 5, 6, 7],
          [8, 5, 9, 7, 6, 1, 4, 2, 3],
          [4, 2, 6, 8, 5, 3, 7, 9, 1],
          [7, 1, 3, 9, 2, 4, 8, 5, 6],
          [9, 6, 1, 5, 3, 7, 2, 8, 4],
          [2, 8, 7, 4, 1, 9, 6, 3, 5],
          [3, 4, 5, 2, 8, 6, 1, 7, 9]]
sudoku_conflicts(solved)   # []

solved[0][1] = 5           # now row 0, column 1 and box 0 each have two 5s
sudoku_conflicts(solved)   # [('box', 0), ('col', 1), ('row', 0)]
```

<Solution>

```python
def sudoku_conflicts(board):
    seen = set()
    conflicts = set()
    for r in range(9):
        for c in range(9):
            digit = board[r][c]
            if digit == 0:
                continue
            box = (r // 3) * 3 + c // 3
            for unit in (("row", r), ("col", c), ("box", box)):
                if (unit, digit) in seen:
                    conflicts.add(unit)
                seen.add((unit, digit))
    return sorted(conflicts)

empty = [[0] * 9 for _ in range(9)]
print(sudoku_conflicts(empty))  # []
```

Each square belongs to exactly one row, one column and one box, so a single pass with a set of `(unit, digit)` pairs finds every repeat. Collecting the conflicts in a set means a unit with many repeats is reported once; the work is O(1) per square.

</Solution>
