A panda logs how many bamboo shoots it eats each day. Write a function `running_totals(numbers)` that returns a **new** list where each item is the total of all numbers up to and including that position.

- An empty list gives an empty list.
- Don't change the list you were given.

```python
running_totals([1, 2, 3, 4])    # [1, 3, 6, 10]
running_totals([3, -1, -2, 4])  # [3, 2, 0, 4]
running_totals([])              # []
```

<Hint>

Keep a `total` that starts at 0 and a new, empty list. For each number, add it to `total`, then append `total` to the new list. You never write to `numbers`, so the original stays as it was, and an empty list gives an empty result.

</Hint>

<Solution>

```python
def running_totals(numbers):
    totals = []
    total = 0
    for number in numbers:
        total += number
        totals.append(total)
    return totals

print(running_totals([1, 2, 3, 4]))  # [1, 3, 6, 10]
```

One pass is enough: the running total carries over from one item to the next, so you never add up the same numbers twice.
