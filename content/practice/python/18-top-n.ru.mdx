Напишите функцию (function) `top_n(items, key, n=3)`, которая возвращает список из `n` элементов с наибольшим `key(item)`, начиная с лучшего. `key` — это функция, например `len`, `abs` или `lambda`.

- Если у двух элементов одинаковая оценка, сохраните их порядок из `items`.
- Если элементов меньше `n`, верните их все, начиная с лучшего.
- Если `n` равно 0 или отрицательное, верните `[]`.
- Не меняйте список, который вам передали.

```python
pandas = [("Mei", 12), ("Bao", 30), ("Lin", 30), ("Tao", 7)]
top_n(pandas, lambda p: p[1], 2)
# [('Bao', 30), ('Lin', 30)]

top_n(["kiwi", "fig", "banana", "plum"], len)
# ['banana', 'kiwi', 'plum']   (у kiwi и plum ничья: kiwi был раньше)
```

Допишите `top_n(items, key, n=3)`, чтобы функция возвращала `n` лучших элементов по `key`.

<Hint>

`sorted()` принимает такую же функцию: `sorted(items, key=key, reverse=True)`. Сортировка в Python *устойчивая* (stable): элементы с равными оценками сохраняют свой порядок даже при `reverse=True`.

</Hint>

<Hint>

Осторожнее со срезом: `[:-1]` означает «все, кроме последнего», поэтому отрицательное `n` нужно проверить отдельно.

</Hint>

<Solution>

```python
def top_n(items, key, n=3):
    if n <= 0:
        return []
    return sorted(items, key=key, reverse=True)[:n]

print(top_n(["kiwi", "fig", "banana", "plum"], len))  # ['banana', 'kiwi', 'plum']
```

Весь фокус в том, чтобы передать `key` прямо в `sorted()`: ваша функция решает, что значит «лучший». Сортировка с `reverse=True` сохраняет порядок равных элементов, а сортировка по возрастанию с последующим разворотом списка поменяла бы их местами. Сортировка стоит O(n log n).

</Solution>
