Каждый бамбуковый магазин присылает словарь (dictionary) изменений на складе, например `{"bamboo": 3, "apple": -1}` (отрицательное число значит, что товар ушёл). Напишите функцию (function) `merge_counts(counts_list)`, которая принимает список таких словарей и возвращает **один новый** словарь с итоговыми суммами.

- Итог для ключа — сумма его значений во всех словарях, где он есть.
- Ключи, у которых итог ровно `0`, не включайте.
- Пустой список (или список пустых словарей) даёт `{}`.
- Не меняйте ни один из словарей, которые вам передали.

```python
merge_counts([{"bamboo": 3, "apple": 1}, {"bamboo": 2, "pear": 4}])
# {'bamboo': 5, 'apple': 1, 'pear': 4}
merge_counts([{"leaf": 2}, {"leaf": -2, "nut": 1}])
# {'nut': 1}
merge_counts([])   # {}
```

Допишите `merge_counts(counts_list)`, чтобы функция возвращала объединённые суммы.

<Hint>

Начните с пустого словаря и прибавляйте в него каждое значение: `totals.get(key, 0) + value`. Не используйте первый входной словарь как результат, иначе вы его измените.

</Hint>

<Hint>

Нули уберите в самом конце, когда все суммы уже известны, — например, с помощью словарного включения (dictionary comprehension).

</Hint>

<Solution>

```python
def merge_counts(counts_list):
    totals = {}
    for counts in counts_list:
        for key, value in counts.items():
            totals[key] = totals.get(key, 0) + value
    return {key: total for key, total in totals.items() if total != 0}

print(merge_counts([{"bamboo": 3, "apple": 1}, {"bamboo": 2, "pear": 4}]))
```

Сначала суммируем, в конце фильтруем — так ключ может пройти через ноль и вернуться без особых случаев. Каждая пара «ключ — значение» просматривается один раз, поэтому работа занимает O(общее число записей). `collections.Counter` тоже умеет складывать словари, но `Counter + Counter` выбрасывает и отрицательные итоги, а здесь это не нужно.

</Solution>
