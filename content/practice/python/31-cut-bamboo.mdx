The zoo has some bamboo stalks of different lengths and `k` hungry pandas. Every panda must get one piece, and all pieces must be the **same** whole-number length so nobody feels cheated. Write `longest_piece(stalks, k)` that returns the longest piece length that makes this possible.

- `stalks` is a list of stalk lengths (whole numbers, 1 or more) and `k` is at least 1.
- A stalk of length `s` gives `s // length` pieces; the leftover bit is wasted, and pieces from different stalks can't be glued together.
- You may cut more than `k` pieces; you need *at least* `k`.
- If even pieces of length 1 aren't enough (or there are no stalks), return `0`.

```python
longest_piece([8, 5, 10], 4)    # 5: pieces of 5 give 1 + 1 + 2 = 4
longest_piece([8, 5, 10], 5)    # 4: 2 + 1 + 2 = 5
longest_piece([8, 5, 10], 1)    # 10
longest_piece([8, 5, 10], 23)   # 1
longest_piece([8, 5, 10], 24)   # 0: only 23 cm of bamboo
```

Stalks can be up to a billion units long, so trying every length one by one is far too slow.

<Solution>

```python
def longest_piece(stalks, k):
    lo, hi = 0, max(stalks, default=0)
    # Invariant: length lo works (0 always "works"), lengths above hi don't.
    while lo < hi:
        mid = (lo + hi + 1) // 2
        pieces = sum(s // mid for s in stalks)
        if pieces >= k:
            lo = mid
        else:
            hi = mid - 1
    return lo

print(longest_piece([8, 5, 10], 4))  # 5
```

This is binary search on the *answer* rather than on a list: each guess is checked in O(n), and halving the range of possible lengths takes O(log M) guesses for a longest stalk of M, so O(n log M) in total, about 30 rounds even for a billion.

</Solution>
