Напишите функцию (function) `second_largest(numbers)`, которая возвращает второе по величине **различное** значение в списке (list).

- Повторы самого большого значения не считаются: в `[4, 9, 2, 9, 7]` ответ — `7`, а не `9`.
- Если различных значений меньше двух (пустой список, один элемент или все одинаковые), верните `None`.
- Не меняйте список, который вам передали.

```python
second_largest([3, 8, 5])         # 5
second_largest([4, 9, 2, 9, 7])   # 7
second_largest([5, 5, 5])         # None
second_largest([-3, -1, -7])      # -3
```

Допишите `second_largest(numbers)`, чтобы функция возвращала второе место или `None`.

<Hint>

`set(numbers)` отбрасывает повторы. Если осталось хотя бы два значения, `sorted(...)` поставит второе по величине на предпоследнее место.

</Hint>

<Solution>

```python
def second_largest(numbers):
    unique = sorted(set(numbers))
    if len(unique) < 2:
        return None
    return unique[-2]

print(second_largest([4, 9, 2, 9, 7]))  # 7
```

`sorted()` возвращает новый список, так что исходный остаётся нетронутым. Подойдёт и один цикл без сортировки, который запоминает лучшее и второе по величине значения, встреченные до сих пор.

</Solution>
