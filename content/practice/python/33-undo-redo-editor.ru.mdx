Напишите класс (class) `Editor` для однострочного текстового поля с отменой (undo) и повтором (redo) — так, как это работает в настоящих редакторах:

- `Editor(limit=None)` начинает с `text`, равного `""`. `limit` — сколько изменений можно отменить (самые старые забываются первыми); `None` означает «без ограничения».
- `type(chars)` дописывает `chars` в конец `text`.
- `delete(count)` удаляет последние `count` символов (все, если их меньше).
- `undo()` откатывает самое свежее ещё не отменённое изменение и возвращает `True` или возвращает `False`, если отменять нечего.
- `redo()` заново применяет последнее отменённое изменение и возвращает `True` или возвращает `False`, если повторять нечего.
- Новый `type` или `delete`, который меняет текст, стирает всё, что можно было повторить. Вызов, который не меняет текст (ввод `""`, `delete(0)`, удаление из пустого текста), вообще не считается изменением: он не учитывается для отмены и не стирает историю повтора.

```python
e = Editor()
e.type("bamboo")
e.delete(3)      # теперь text равен 'bam'
e.undo()         # True, text равен 'bamboo'
e.undo()         # True, text равен ''
e.undo()         # False, больше ничего нет
e.redo()         # True, text равен 'bamboo'
e.type("!")      # text равен 'bamboo!', а история повтора стёрта
e.redo()         # False

small = Editor(limit=2)
for word in ["a", "b", "c"]:
    small.type(word)
small.undo(); small.undo()   # text равен 'a'
small.undo()                 # False: запоминаются только 2 изменения
```

<Hint>

И отмена, и повтор работают по принципу «последним пришёл — первым ушёл»: первым возвращается самое свежее изменение. А что, если перед каждым изменением сохранять снимок всего `text`?

Держите два стека (stack). Пропускайте каждое изменение через один помощник, например `_change(new_text)`: если новый текст равен старому, ничего не делайте; иначе положите старый `text` в стек отмены, очистите стек повтора и запишите новый текст. `undo` достаёт значение из стека отмены и кладёт текущий текст в стек повтора; `redo` делает наоборот. Тогда `type` и `delete` превращаются в однострочные вызовы `_change` (осторожно с `delete(0)`: `text[:-0]` — это пустая строка).

<Solution>

```python
from collections import deque

class Editor:
    def __init__(self, limit=None):
        self.text = ""
        self._undo = deque(maxlen=limit)
        self._redo = []

    def _change(self, new_text):
        if new_text == self.text:
            return
        self._undo.append(self.text)
        self._redo.clear()
        self.text = new_text

    def type(self, chars):
        self._change(self.text + chars)

    def delete(self, count):
        if count > 0:
            self._change(self.text[:-count])

    def undo(self):
        if not self._undo:
            return False
        self._redo.append(self.text)
        self.text = self._undo.pop()
        return True

    def redo(self):
        if not self._redo:
            return False
        self._undo.append(self.text)
        self.text = self._redo.pop()
        return True


e = Editor()
e.type("bamboo")
e.delete(3)
print(e.text)  # bam
```

Каждый стек хранит снимки текста, поэтому отмена и повтор — это просто перекладывание текущего текста между двумя стеками, O(1), не считая копирования строк. Все правки проходят через `_change`, и правила собраны в одном месте: правки, которые ничего не меняют, пропускаются, а настоящие стирают стек повтора.

</Solution>
