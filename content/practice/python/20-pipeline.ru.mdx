В Python функции (functions) — это значения: их можно класть в список, передавать куда угодно и даже **возвращать**. Напишите функцию `pipeline(steps)`, которая принимает список функций с одним аргументом и возвращает **новую функцию**. Вызов этой новой функции со значением пропускает его через все шаги по порядку и возвращает итоговый результат.

- `pipeline([f, g, h])(x)` должно давать тот же ответ, что и `h(g(f(x)))`.
- Если шагов нет, новая функция возвращает значение без изменений.
- Новую функцию можно вызывать снова и снова с разными значениями.

```python
clean = pipeline([str.strip, str.lower, lambda s: s.replace(" ", "-")])
clean("  Red Panda ")    # 'red-panda'
clean("BAMBOO Forest")   # 'bamboo-forest'

pipeline([])(42)         # 42
```

Чтобы вернуть функцию, определите её через `def` внутри `pipeline` и сделайте `return` её имени — без вызова.

Допишите `pipeline(steps)`, чтобы функция возвращала функцию, которая выполняет все шаги.

<Hint>

Внутри `pipeline` напишите `def run(value):` — функцию, которая проходит циклом по `steps` и каждый раз заменяет `value` на `step(value)`. Внутренняя функция видит `steps`, потому что определена внутри `pipeline`.

</Hint>

<Solution>

```python
def pipeline(steps):
    def run(value):
        for step in steps:
            value = step(value)
        return value
    return run

clean = pipeline([str.strip, str.lower, lambda s: s.replace(" ", "-")])
print(clean("  Red Panda "))  # red-panda
```

`run` запоминает `steps`, с которыми была создана (это называется *замыканием*, closure), поэтому каждый конвейер — это отдельная маленькая машина. Её вызов стоит по одному вызову на каждый шаг.

</Solution>

</Exercise>
