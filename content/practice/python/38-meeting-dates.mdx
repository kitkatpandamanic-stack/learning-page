The Panda Club meets on dates like "the last Friday of the month" or "the 2nd Tuesday". Write `meeting_dates(rule, start, end)` that returns every meeting date from `start` to `end` (both included).

- `rule` is a position followed by a weekday name, like `"last friday"` or `"2nd Tuesday"`. The position is one of `first`, `second`, `third`, `fourth`, `fifth`, `1st`, `2nd`, `3rd`, `4th`, `5th` or `last`; the weekday is `monday` to `sunday`. Upper and lower case are both fine, and so are extra spaces between and around the words.
- Any other rule (unknown words, missing parts, extra words) raises `ValueError`.
- `start` and `end` are ISO dates like `"2026-10-05"`, and the result is a list of ISO date strings in order. If `end` is before `start`, the list is empty.
- Months that don't have the asked-for day (most months have no fifth Saturday) are skipped.

```python
meeting_dates("last friday", "2026-01-01", "2026-06-30")
# ['2026-01-30', '2026-02-27', '2026-03-27', '2026-04-24', '2026-05-29', '2026-06-26']

meeting_dates("2nd Tuesday", "2026-10-01", "2027-02-28")
# ['2026-10-13', '2026-11-10', '2026-12-08', '2027-01-12', '2027-02-09']

meeting_dates("fifth saturday", "2026-01-01", "2026-12-31")
# ['2026-01-31', '2026-05-30', '2026-08-29', '2026-10-31']

meeting_dates("  FIRST   monday ", "2026-10-06", "2026-12-07")
# ['2026-11-02', '2026-12-07']   (5 October is before start)

meeting_dates("every friday", "2026-01-01", "2026-12-31")   # ValueError
```

Finish `meeting_dates` so it reads the rule and lists the matching dates.

<Hint>

Check the whole rule with one `re.fullmatch` and `re.IGNORECASE`: `\s*` at both ends, `\s+` between the words, and two groups made from the allowed words joined with `|`. Then look the words up in dicts to get a number for the position (`last` can be `-1`) and a weekday number (Monday is 0, like `date.weekday()`).

</Hint>

<Hint>

For the n-th weekday of a month, start at the 1st: `(weekday - first.weekday()) % 7` days later is the first one, then add `7 * (n - 1)`. `calendar.monthrange(year, month)[1]` gives the number of days in the month, so you can tell when the day doesn't exist, and work backwards from it for `last`.

</Hint>

<Solution>

```python
import re
import calendar
from datetime import date

WEEKDAYS = ["monday", "tuesday", "wednesday", "thursday",
            "friday", "saturday", "sunday"]
POSITIONS = {"first": 1, "1st": 1, "second": 2, "2nd": 2, "third": 3, "3rd": 3,
             "fourth": 4, "4th": 4, "fifth": 5, "5th": 5, "last": -1}
RULE = re.compile(
    r"\s*(" + "|".join(POSITIONS) + r")\s+(" + "|".join(WEEKDAYS) + r")\s*",
    re.IGNORECASE,
)

def day_in_month(year, month, weekday, position):
    days = calendar.monthrange(year, month)[1]
    if position == -1:
        last = date(year, month, days)
        return date(year, month, days - (last.weekday() - weekday) % 7)
    first = date(year, month, 1)
    day = 1 + (weekday - first.weekday()) % 7 + 7 * (position - 1)
    return date(year, month, day) if day <= days else None

def meeting_dates(rule, start, end):
    match = RULE.fullmatch(rule)
    if match is None:
        raise ValueError(f"can't understand the rule {rule!r}")
    position = POSITIONS[match[1].lower()]
    weekday = WEEKDAYS.index(match[2].lower())
    first, last = date.fromisoformat(start), date.fromisoformat(end)
    year, month = first.year, first.month
    found = []
    while (year, month) <= (last.year, last.month):
        day = day_in_month(year, month, weekday, position)
        if day is not None and first <= day <= last:
            found.append(day.isoformat())
        year, month = (year + 1, 1) if month == 12 else (year, month + 1)
    return found

print(meeting_dates("2nd Tuesday", "2026-10-01", "2026-12-31"))
# ['2026-10-13', '2026-11-10', '2026-12-08']
```

`fullmatch` makes the regex check the entire rule, so extra or misspelled words fail instead of being half-matched. After that, each month needs only a little modulo-7 arithmetic, so the work is O(number of months) between the two dates.
