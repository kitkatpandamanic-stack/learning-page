A panda has a gift card worth exactly `budget` coins and wants to spend all of it on two different snacks from the shelf. Write `snack_pair(prices, budget)` that returns a tuple `(i, j)` of two positions in the list, with `i < j` and `prices[i] + prices[j] == budget`.

- Prices are whole numbers (0 or more), and the same price can appear several times.
- If several pairs work, return the one whose **second** position `j` is smallest. If that `j` works with several earlier positions, use the smallest `i`.
- If no pair adds up to the budget, return `None`.

```python
snack_pair([3, 8, 4, 6, 2], 10)   # (2, 3): 4 + 6 (8 + 2 also works, but ends later)
snack_pair([2, 7, 2, 8], 10)      # (0, 3): 2 + 8, using the first 2
snack_pair([5, 5], 10)            # (0, 1)
snack_pair([5], 10)               # None
```

Aim for one pass over the list, not a loop inside a loop.

<Hint>

Walk through the list once. For the price at position `j`, the partner you need is `budget - price`. Keep a dict from each price you've already seen to the first position where you saw it.

</Hint>

<Solution>

```python
def snack_pair(prices, budget):
    first_seen = {}
    for j, price in enumerate(prices):
        partner = budget - price
        if partner in first_seen:
            return (first_seen[partner], j)
        if price not in first_seen:
            first_seen[price] = j
    return None

print(snack_pair([3, 8, 4, 6, 2], 10))  # (2, 3)
```

Scanning left to right means the first match found has the smallest `j`, and storing only the first position of each price gives the smallest `i`. Dict lookups are O(1) on average, so the whole search is O(n) instead of the O(n²) of checking every pair.

</Solution>
