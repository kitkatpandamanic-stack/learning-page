В шифре Цезаря каждая буква сдвигается по алфавиту на одно и то же число позиций: при сдвиге 3 буква `a` становится `d`, а `z` переходит через конец алфавита и становится `c`. Напишите функцию (function) `caesar(text, shift)`, которая возвращает сдвинутый текст.

- Заглавные буквы остаются заглавными, строчные — строчными.
- Сдвигаются только 26 букв `a`–`z` и `A`–`Z`. Пробелы, цифры, знаки препинания и другие буквы, например `é`, остаются как есть.
- `shift` может быть отрицательным (сдвиг назад — это расшифровка) или больше 26 (тогда счёт идёт по кругу).

```python
caesar("panda", 3)    # 'sdqgd'
caesar("Zoo!", 1)     # 'App!'
caesar("sdqgd", -3)   # 'panda'
caesar("abc", 29)     # 'def'
caesar("café", 1)     # 'dbgé'
```

<Solution>

```python
def caesar(text, shift):
    lower = "abcdefghijklmnopqrstuvwxyz"
    upper = lower.upper()
    result = ""
    for char in text:
        if char in lower:
            result += lower[(lower.index(char) + shift) % 26]
        elif char in upper:
            result += upper[(upper.index(char) + shift) % 26]
        else:
            result += char
    return result

print(caesar("panda", 3))  # sdqgd
```

`% 26` держит каждую новую позицию в пределах от 0 до 25 при любом сдвиге: оператор `%` в Python возвращает неотрицательный результат даже для отрицательных чисел, так что `-1 % 26` равно 25. Именно проверка вхождения в два алфавита (а не `char.isalpha()`) оставляет буквы вроде `é` на месте. Для n символов решение работает за O(n).

</Solution>
