Write a function `bamboo_buzz(n)` that returns a list with one string for every number from 1 to `n`:

- a multiple of both 3 and 5 becomes `"BambooPanda"`
- any other multiple of 3 becomes `"Bamboo"`
- any other multiple of 5 becomes `"Panda"`
- every other number becomes the number as a string, like `"7"`

If `n` is 0 or negative, return an empty list.

```python
bamboo_buzz(5)       # ['1', '2', 'Bamboo', '4', 'Panda']
bamboo_buzz(15)[-1]  # 'BambooPanda'
bamboo_buzz(0)       # []
```

Finish `bamboo_buzz(n)` so it returns the list of words for 1 to `n`.

<Hint>

Loop with `range(1, n + 1)`. A number is a multiple of 3 when `number % 3 == 0`. Check the "both" case first, or it will never be reached.

</Hint>

<Solution>

```python
def bamboo_buzz(n):
    words = []
    for number in range(1, n + 1):
        if number % 15 == 0:
            words.append("BambooPanda")
        elif number % 3 == 0:
            words.append("Bamboo")
        elif number % 5 == 0:
            words.append("Panda")
        else:
            words.append(str(number))
    return words

print(bamboo_buzz(5))  # ['1', '2', 'Bamboo', '4', 'Panda']
```

A multiple of both 3 and 5 is a multiple of 15, so that case goes first. `range(1, 1)` is empty, which handles 0 and negative numbers for free.
