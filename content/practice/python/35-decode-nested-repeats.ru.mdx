Панды отправляют друг другу сжатые сообщения. В коде `k[...]` означает «то, что в скобках, повторённое `k` раз», и такие конструкции могут быть вложенными. Всё, что вне скобок, копируется как есть.

Напишите две функции (function):

- `expand(code)` возвращает полное сообщение строкой.
- `expanded_length(code)` возвращает длину полного сообщения, **не** собирая его, потому что некоторые сообщения слишком велики, чтобы поместиться в памяти.

Коды всегда корректны: количество — это одна или несколько цифр (оно может быть `0` или больше 9), и за ним всегда идёт `[`, у каждой `[` есть парная `]`, а больше нигде цифры не встречаются. Остальные символы — буквы, пробелы или знаки препинания.

```python
expand("3[ab]")          # 'ababab'
expand("2[a3[b]]c")      # 'abbbabbbc'
expand("x10[y]")         # 'xyyyyyyyyyy'
expand("0[abc]ok")       # 'ok'
expand("")               # ''

expanded_length("2[a3[b]]c")              # 9
expanded_length("1000000[1000000[hi]]")   # 2000000000000
```

<Hint>

Напишите вспомогательную функцию, которая читает код с позиции `i`, пока не встретит `]` или конец, и возвращает прочитанное вместе с позицией, где она остановилась. Встретив количество, она читает цифры, пропускает `[`, вызывает *саму себя* для содержимого, пропускает `]` и повторяет результат.

</Hint>

<Hint>

У `expanded_length` точно такая же форма, только вместо склеивания строк она складывает числа: буква добавляет 1, а `k[...]` добавляет `k`, умноженное на длину содержимого.

</Hint>

<Solution>

```python
def _read(code, i, as_length):
    # Читает с позиции i до "]" или до конца.
    # Возвращает (текст или длину, позицию после прочитанного).
    parts = []
    total = 0
    while i < len(code) and code[i] != "]":
        if code[i].isdigit():
            j = i
            while code[j].isdigit():
                j += 1
            count = int(code[i:j])
            inner, i = _read(code, j + 1, as_length)  # на позиции j стоит "["
            i += 1                                     # пропускаем "]"
            if as_length:
                total += count * inner
            else:
                parts.append(inner * count)
        else:
            if as_length:
                total += 1
            else:
                parts.append(code[i])
            i += 1
    return (total if as_length else "".join(parts)), i

def expand(code):
    return _read(code, 0, False)[0]

def expanded_length(code):
    return _read(code, 0, True)[0]

print(expand("2[a3[b]]c"))  # abbbabbbc
```

Каждая пара скобок — это один рекурсивный вызов, который возвращает место, где он остановился, чтобы вызывающий код мог продолжить после `]`. Обе функции читают каждый символ кода один раз, поэтому `expanded_length` работает за O(длина кода), каким бы огромным ни было сообщение, а `expand` вдобавок тратит время и память на каждый символ результата.

</Solution>
