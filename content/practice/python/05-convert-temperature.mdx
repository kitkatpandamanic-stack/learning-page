Write a function `convert(degrees, to="F")`:

- `to="F"` (the default) means `degrees` is in Celsius: return Fahrenheit, `degrees * 9 / 5 + 32`.
- `to="C"` means `degrees` is in Fahrenheit: return Celsius, `(degrees - 32) * 5 / 9`.
- Round the answer to 1 decimal place with `round(value, 1)`.
- For any other value of `to`, return `None`.

```python
convert(100)            # 212.0
convert(37)             # 98.6
convert(212, to="C")    # 100.0
convert(70, "C")        # 21.1
convert(10, to="K")     # None
```

<Solution>

```python
def convert(degrees, to="F"):
    if to == "F":
        return round(degrees * 9 / 5 + 32, 1)
    elif to == "C":
        return round((degrees - 32) * 5 / 9, 1)
    return None

print(convert(100))  # 212.0
```

The default value `"F"` is used whenever the caller leaves `to` out, so `convert(100)` and `convert(100, to="F")` do the same thing.
