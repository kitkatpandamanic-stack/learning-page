The panda keepers get paid per working day. Write `count_workdays(start, end, holidays=())` that counts the working days from `start` to `end`, **both included**.

- `start`, `end` and every item in `holidays` are dates written as ISO strings, like `"2026-10-05"`.
- A working day is a Monday, Tuesday, Wednesday, Thursday or Friday that isn't in `holidays`. A holiday that falls on a weekend changes nothing.
- If `end` is before `start`, return `0`.

```python
count_workdays("2026-10-05", "2026-10-09")   # 5 (Monday to Friday)
count_workdays("2026-10-05", "2026-10-18")   # 10 (two full weeks)
count_workdays("2026-10-03", "2026-10-04")   # 0 (a weekend)
count_workdays("2026-12-21", "2027-01-03",
               ["2026-12-25", "2027-01-01"])  # 8
count_workdays("2026-10-09", "2026-10-05")   # 0 (end is before start)
```

<Solution>

```python
from datetime import date, timedelta

def count_workdays(start, end, holidays=()):
    day = date.fromisoformat(start)
    last = date.fromisoformat(end)
    days_off = {date.fromisoformat(h) for h in holidays}
    count = 0
    while day <= last:
        if day.weekday() < 5 and day not in days_off:
            count += 1
        day += timedelta(days=1)
    return count

print(count_workdays("2026-10-05", "2026-10-09"))  # 5
```

`date` objects already know about month lengths and leap years, so adding one day at a time is always right. That's O(d) for d days in the range, plus O(1) set lookups for the holidays.

</Solution>
