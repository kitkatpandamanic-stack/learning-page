The bamboo warehouse has room for only `capacity` crates near the door. When a new crate arrives and the space is full, the crate that hasn't been touched for the longest time goes to the back store. Write a class `LRUCache` that works the same way:

- `LRUCache(capacity)` makes an empty cache. A `capacity` below 1 raises `ValueError`.
- `get(key, default=None)` returns the value stored for `key` and marks it as the most recently used. A missing key returns `default` and changes nothing.
- `put(key, value)` stores the value (replacing an old value for the same key) and marks the key as the most recently used. If the cache now holds more than `capacity` keys, it removes the least recently used one and **returns that key**; otherwise it returns `None`.
- `len(cache)` is the number of keys stored, and `key in cache` checks for a key **without** counting as a use.
- `keys()` returns a list of the keys from least to most recently used.

`get` and `put` must take O(1) time, however big the cache is.

```python
cache = LRUCache(2)
cache.put("a", 1)     # None
cache.put("b", 2)     # None
cache.get("a")        # 1, so "b" is now the least recently used
cache.put("c", 3)     # 'b' is removed
cache.keys()          # ['a', 'c']
cache.get("b", 0)     # 0
"a" in cache          # True (and "a" is still the oldest)
cache.put("d", 4)     # 'a' is removed
```

<Hint>

A plain dict remembers insertion order, but moving a key to the end means deleting and re-inserting it. `collections.OrderedDict` has `move_to_end(key)` and `popitem(last=False)` (remove the oldest), both O(1).

</Hint>

<Hint>

Keep a list of keys for the order and you'll find `list.remove` has to search the whole list: O(n) per `get`. That's what the last check catches.

</Hint>

<Solution>

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        if capacity < 1:
            raise ValueError("capacity must be at least 1")
        self.capacity = capacity
        self._data = OrderedDict()  # oldest first, newest last

    def get(self, key, default=None):
        if key not in self._data:
            return default
        self._data.move_to_end(key)
        return self._data[key]

    def put(self, key, value):
        self._data[key] = value
        self._data.move_to_end(key)
        if len(self._data) > self.capacity:
            oldest, _ = self._data.popitem(last=False)
            return oldest
        return None

    def keys(self):
        return list(self._data)

    def __len__(self):
        return len(self._data)

    def __contains__(self, key):
        return key in self._data


cache = LRUCache(2)
cache.put("a", 1)
cache.put("b", 2)
print(cache.get("a"))       # 1
print(cache.put("c", 3))    # b
```

An `OrderedDict` is a hash map plus a doubly linked list, so it can find a key, move it to the newest end and drop the oldest key all in O(1). `__contains__` uses only the hash map, so checking for a key doesn't change the order.

</Solution>
