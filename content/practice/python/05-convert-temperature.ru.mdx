Напишите функцию (function) `convert(degrees, to="F")`:

- `to="F"` (значение по умолчанию) означает, что `degrees` — это градусы Цельсия: верните градусы Фаренгейта, `degrees * 9 / 5 + 32`.
- `to="C"` означает, что `degrees` — это градусы Фаренгейта: верните градусы Цельсия, `(degrees - 32) * 5 / 9`.
- Округлите ответ до 1 знака после запятой с помощью `round(value, 1)`.
- Для любого другого значения `to` верните `None`.

```python
convert(100)            # 212.0
convert(37)             # 98.6
convert(212, to="C")    # 100.0
convert(70, "C")        # 21.1
convert(10, to="K")     # None
```

Допишите `convert(degrees, to="F")`, чтобы функция переводила температуру в направлении, которое задаёт `to`.

<Hint>

От значения `to` зависит, какую формулу использовать. Какая конструкция Python позволяет выбрать одну из нескольких веток?

</Hint>

<Hint>

Проверьте `if to == "F":` и верните формулу для Фаренгейта, затем `elif to == "C":` и верните формулу для Цельсия. Оберните каждый результат в `round(value, 1)`. Для всего остального (в том числе для строчной `"f"`) пусть функция дойдёт до `return None` в конце.

</Hint>

```python
def convert(degrees, to="F"):
    if to == "F":
        return round(degrees * 9 / 5 + 32, 1)
    elif ...:  # обратное направление
        return ...  # Цельсий, округлённый до 1 знака
    return None
```

</Hint>

<Solution>

```python
def convert(degrees, to="F"):
    if to == "F":
        return round(degrees * 9 / 5 + 32, 1)
    elif to == "C":
        return round((degrees - 32) * 5 / 9, 1)
    return None

print(convert(100))  # 212.0
```

Значение по умолчанию `"F"` подставляется всякий раз, когда вызывающий код не передаёт `to`, поэтому `convert(100)` и `convert(100, to="F")` делают одно и то же.

</Solution>
