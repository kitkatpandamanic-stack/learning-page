На бамбуковом складе у двери помещается только `capacity` ящиков. Когда приходит новый ящик, а места нет, ящик, к которому дольше всех не прикасались, отправляется в дальнее хранилище. Напишите класс (class) `LRUCache`, который работает так же (LRU — least recently used, «давно не использовавшийся»):

- `LRUCache(capacity)` создаёт пустой кеш. `capacity` меньше 1 вызывает `ValueError`.
- `get(key, default=None)` возвращает значение, сохранённое для `key`, и отмечает ключ как использованный последним. Для отсутствующего ключа возвращается `default`, и ничего не меняется.
- `put(key, value)` сохраняет значение (заменяя старое значение для того же ключа) и отмечает ключ как использованный последним. Если теперь в кеше больше `capacity` ключей, он удаляет тот, что использовался давнее всех, и **возвращает этот ключ**; иначе возвращает `None`.
- `len(cache)` — количество сохранённых ключей, а `key in cache` проверяет наличие ключа, **не** считая это использованием.
- `keys()` возвращает список ключей от давно использованных к недавно использованным.

`get` и `put` должны работать за O(1), каким бы большим ни был кеш.

```python
cache = LRUCache(2)
cache.put("a", 1)     # None
cache.put("b", 2)     # None
cache.get("a")        # 1, теперь "b" использовался давнее всех
cache.put("c", 3)     # 'b' удалён
cache.keys()          # ['a', 'c']
cache.get("b", 0)     # 0
"a" in cache          # True (и "a" по-прежнему самый старый)
cache.put("d", 4)     # 'a' удалён
```

<Hint>

Нужны сразу две вещи: быстрый поиск по ключу и порядок от самого старого использования к самому новому, который можно менять за O(1). Отдельный список для порядка не подойдёт: `list.remove` приходится просматривать весь список. Посмотрите на `collections.OrderedDict`.

</Hint>

<Solution>

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        if capacity < 1:
            raise ValueError("capacity must be at least 1")
        self.capacity = capacity
        self._data = OrderedDict()  # самые старые первыми, самые новые последними

    def get(self, key, default=None):
        if key not in self._data:
            return default
        self._data.move_to_end(key)
        return self._data[key]

    def put(self, key, value):
        self._data[key] = value
        self._data.move_to_end(key)
        if len(self._data) > self.capacity:
            oldest, _ = self._data.popitem(last=False)
            return oldest
        return None

    def keys(self):
        return list(self._data)

    def __len__(self):
        return len(self._data)

    def __contains__(self, key):
        return key in self._data


cache = LRUCache(2)
cache.put("a", 1)
cache.put("b", 2)
print(cache.get("a"))       # 1
print(cache.put("c", 3))    # b
```

`OrderedDict` — это хеш-таблица плюс двусвязный список, поэтому он умеет найти ключ, переместить его в «новый» конец и выбросить самый старый ключ — всё за O(1). `__contains__` использует только хеш-таблицу, поэтому проверка наличия ключа не меняет порядок.

</Solution>
