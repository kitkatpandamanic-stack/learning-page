Write a function `password_problems(password)` that returns a list of messages, one for each rule the password breaks, **in this order**:

1. `"too short"`: fewer than 8 characters.
2. `"no lower-case letter"`: no character where `char.islower()` is true.
3. `"no upper-case letter"`: no character where `char.isupper()` is true.
4. `"no digit"`: no character where `char.isdigit()` is true.
5. `"no symbol"`: no character that is neither a letter nor a digit (spaces count as symbols).
6. `"contains the word password"`: the text `password` appears anywhere, in any case.

A password that breaks no rules gives `[]`.

```python
password_problems("Bamb00!Panda")   # []
password_problems("Ab1!")           # ['too short']
password_problems("bamboopanda")    # ['no upper-case letter', 'no digit', 'no symbol']
password_problems("MyPassword1!")   # ['contains the word password']
```

<Solution>

```python
def password_problems(password):
    problems = []
    if len(password) < 8:
        problems.append("too short")
    if not any(char.islower() for char in password):
        problems.append("no lower-case letter")
    if not any(char.isupper() for char in password):
        problems.append("no upper-case letter")
    if not any(char.isdigit() for char in password):
        problems.append("no digit")
    if not any(not char.isalnum() for char in password):
        problems.append("no symbol")
    if "password" in password.lower():
        problems.append("contains the word password")
    return problems

print(password_problems("bamboopanda"))
```

Each rule is its own `if`, not an `elif`, so every broken rule is reported and the order of the checks is the order of the messages. Each check scans the password once, so the whole thing is O(n) for a password of length n.

</Solution>
