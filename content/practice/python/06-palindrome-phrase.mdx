A palindrome reads the same forwards and backwards, like "racecar". Write a function `is_palindrome(text)` that returns `True` if `text` is a palindrome and `False` otherwise.

- Only letters and digits count: skip spaces, commas, colons and every other character.
- Ignore case, so `"A"` and `"a"` match.
- Text with no letters or digits at all (including `""`) counts as a palindrome: return `True`.

```python
is_palindrome("racecar")                          # True
is_palindrome("A man, a plan, a canal: Panama!")  # True
is_palindrome("Panda")                            # False
is_palindrome("")                                 # True
```

<Solution>

```python
def is_palindrome(text):
    cleaned = ""
    for char in text:
        if char.isalnum():
            cleaned += char.lower()
    return cleaned == cleaned[::-1]

print(is_palindrome("racecar"))  # True
```

Cleaning first turns the problem into a plain "is this string equal to its reverse?" check. An empty cleaned string equals its own reverse, so the edge case needs no extra code.
