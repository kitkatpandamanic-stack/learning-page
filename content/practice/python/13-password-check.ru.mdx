Напишите функцию (function) `password_problems(password)`, которая возвращает список сообщений — по одному на каждое правило, которое нарушает пароль, **в таком порядке**:

1. `"too short"` («слишком короткий»): меньше 8 символов.
2. `"no lower-case letter"` («нет строчной буквы»): нет ни одного символа, для которого `char.islower()` истинно.
3. `"no upper-case letter"` («нет заглавной буквы»): нет ни одного символа, для которого `char.isupper()` истинно.
4. `"no digit"` («нет цифры»): нет ни одного символа, для которого `char.isdigit()` истинно.
5. `"no symbol"` («нет спецсимвола»): нет ни одного символа, который не буква и не цифра (пробелы считаются спецсимволами).
6. `"contains the word password"` («содержит слово password»): текст `password` встречается где угодно и в любом регистре.

Пароль, который не нарушает ни одного правила, даёт `[]`.

```python
password_problems("Bamb00!Panda")   # []
password_problems("Ab1!")           # ['too short']
password_problems("bamboopanda")    # ['no upper-case letter', 'no digit', 'no symbol']
password_problems("MyPassword1!")   # ['contains the word password']
```

<Solution>

```python
def password_problems(password):
    problems = []
    if len(password) < 8:
        problems.append("too short")
    if not any(char.islower() for char in password):
        problems.append("no lower-case letter")
    if not any(char.isupper() for char in password):
        problems.append("no upper-case letter")
    if not any(char.isdigit() for char in password):
        problems.append("no digit")
    if not any(not char.isalnum() for char in password):
        problems.append("no symbol")
    if "password" in password.lower():
        problems.append("contains the word password")
    return problems

print(password_problems("bamboopanda"))
```

Каждое правило — отдельный `if`, а не `elif`, поэтому сообщается о каждом нарушенном правиле, а порядок проверок совпадает с порядком сообщений. Каждая проверка просматривает пароль один раз, так что для пароля длины n всё решение работает за O(n).

</Solution>
