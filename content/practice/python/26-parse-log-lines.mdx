The Bamboo Shop's servers write log lines like this:

```text
2026-03-14 09:26:53 ERROR [payments] Card declined (code 51)
```

That is a date `YYYY-MM-DD`, a time `HH:MM:SS`, a level, a service name in square brackets and a message, separated by single spaces. Write two functions:

- `parse_line(line)` returns a dict with the keys `"date"`, `"time"`, `"level"`, `"service"` and `"message"` (all strings), or `None` if the line doesn't follow the format. Spaces at the start and end of the line are ignored.
  - The level is exactly one of `DEBUG`, `INFO`, `WARNING` or `ERROR`.
  - The service is one or more lower-case letters, digits or hyphens.
  - The message is everything after the service and its space, and can't be empty.
- `errors_by_service(lines)` returns a dict mapping each service to how many valid `ERROR` lines it has. Services without errors don't appear.

```python
parse_line("2026-03-14 09:26:53 ERROR [payments] Card declined (code 51)")
# {'date': '2026-03-14', 'time': '09:26:53', 'level': 'ERROR',
#  'service': 'payments', 'message': 'Card declined (code 51)'}
parse_line("2026-03-14 09:26:53 OOPS [payments] Hmm")   # None (unknown level)
parse_line("just some text")                            # None

errors_by_service([
    "2026-03-14 09:00:00 ERROR [payments] Timeout",
    "2026-03-14 09:00:05 INFO [search] Query took 12 ms",
    "2026-03-14 09:01:00 ERROR [payments] Card declined",
    "2026-03-14 09:02:00 ERROR [stock-db] Disk almost full",
    "garbage ERROR [payments] not a real line",
])
# {'payments': 2, 'stock-db': 1}
```

<Solution>

```python
import re

LINE = re.compile(
    r"(\d{4}-\d{2}-\d{2}) (\d{2}:\d{2}:\d{2}) "
    r"(DEBUG|INFO|WARNING|ERROR) \[([a-z0-9-]+)\] (.+)"
)

def parse_line(line):
    match = LINE.fullmatch(line.strip())
    if match is None:
        return None
    date, time, level, service, message = match.groups()
    return {"date": date, "time": time, "level": level,
            "service": service, "message": message}

def errors_by_service(lines):
    counts = {}
    for line in lines:
        entry = parse_line(line)
        if entry and entry["level"] == "ERROR":
            counts[entry["service"]] = counts.get(entry["service"], 0) + 1
    return counts

print(parse_line("2026-03-14 09:26:53 ERROR [payments] Card declined"))
```

`fullmatch` anchors the pattern to the whole line, and the groups pull out each part in one step. Stripping first means the message can't end in spaces, and an empty message fails because `.+` needs at least one character.

</Solution>
