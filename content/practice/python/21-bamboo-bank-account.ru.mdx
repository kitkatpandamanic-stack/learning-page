Бамбуковому банку нужен класс (class) `Account` для клиентов. Точно следуйте этим правилам:

- `Account(owner, balance=0)` сохраняет `owner` и `balance`. Отрицательный начальный баланс вызывает `ValueError`.
- `deposit(amount)` добавляет деньги и возвращает новый баланс. Если `amount` равно 0 или меньше, возникает `ValueError`.
- `withdraw(amount)` снимает деньги и возвращает новый баланс. Если `amount` равно 0 или меньше либо больше баланса, возникает `ValueError`.
- `transfer(other, amount)` переводит деньги с этого счёта на счёт `other` по тем же правилам, что и `withdraw`. Если перевод не удался, ни один баланс не меняется.
- `history` — список кортежей (tuple) `(kind, amount)`, по одному на каждую успешную операцию, от старых к новым: `"deposit"`, `"withdraw"`, `"transfer out"` (у отправителя) и `"transfer in"` (у получателя). Неудачные операции ничего не добавляют.

```python
po = Account("Po", 100)
mei = Account("Mei")
po.deposit(50)          # 150
po.withdraw(30)         # 120
po.transfer(mei, 20)
po.balance              # 100
mei.balance             # 20
po.withdraw(500)        # ValueError, po.balance по-прежнему 100
po.history              # [('deposit', 50), ('withdraw', 30), ('transfer out', 20)]
mei.history             # [('transfer in', 20)]
```

У каждого счёта должен быть свой список `history`, поэтому создавайте его внутри `__init__`.

<Solution>

```python
class Account:
    def __init__(self, owner, balance=0):
        if balance < 0:
            raise ValueError("balance can't start below 0")
        self.owner = owner
        self.balance = balance
        self.history = []

    def _check(self, amount):
        if amount <= 0:
            raise ValueError("amount must be positive")
        if amount > self.balance:
            raise ValueError("insufficient funds")

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("amount must be positive")
        self.balance += amount
        self.history.append(("deposit", amount))
        return self.balance

    def withdraw(self, amount):
        self._check(amount)
        self.balance -= amount
        self.history.append(("withdraw", amount))
        return self.balance

    def transfer(self, other, amount):
        self._check(amount)
        self.balance -= amount
        other.balance += amount
        self.history.append(("transfer out", amount))
        other.history.append(("transfer in", amount))


po = Account("Po", 100)
print(po.deposit(50))  # 150
```

Каждый метод (method) сначала проверяет данные и только потом меняет состояние, поэтому `ValueError` никогда не оставляет счёт обновлённым наполовину. Общий помощник `_check` держит правила для снятия и перевода в одном месте.

</Solution>
