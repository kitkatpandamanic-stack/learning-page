Напишите функцию (function) `bamboo_buzz(n)`, которая возвращает список (list) с одной строкой для каждого числа от 1 до `n`:

- число, кратное и 3, и 5, превращается в `"BambooPanda"`;
- любое другое число, кратное 3, — в `"Bamboo"`;
- любое другое число, кратное 5, — в `"Panda"`;
- все остальные числа превращаются в строку с самим числом, например `"7"`.

Если `n` равно 0 или отрицательное, верните пустой список.

```python
bamboo_buzz(5)       # ['1', '2', 'Bamboo', '4', 'Panda']
bamboo_buzz(15)[-1]  # 'BambooPanda'
bamboo_buzz(0)       # []
```

<Solution>

```python
def bamboo_buzz(n):
    words = []
    for number in range(1, n + 1):
        if number % 15 == 0:
            words.append("BambooPanda")
        elif number % 3 == 0:
            words.append("Bamboo")
        elif number % 5 == 0:
            words.append("Panda")
        else:
            words.append(str(number))
    return words

print(bamboo_buzz(5))  # ['1', '2', 'Bamboo', '4', 'Panda']
```

Число, кратное и 3, и 5, кратно 15, поэтому этот случай идёт первым. `range(1, 1)` пуст, так что 0 и отрицательные числа обрабатываются сами собой.

</Solution>
