Два слова — анаграммы, если в них ровно одни и те же буквы в одинаковом количестве, как в `listen` и `silent`. Напишите функцию (function) `anagram_groups(words)`, которая возвращает список групп (списков слов), где в каждой группе собраны слова, являющиеся анаграммами друг друга.

- При сравнении регистр не важен: `"Tea"` и `"EAT"` — анаграммы. Каждое слово сохраняйте ровно в том виде, в каком оно записано.
- Внутри группы слова идут в том же порядке, что и в `words`. Группы упорядочены по тому, где встречается их первое слово.
- Слово без пары-анаграммы образует отдельную группу. Повторяющиеся слова остаются в своей группе.
- Пустой список даёт `[]`.

```python
anagram_groups(["listen", "Silent", "panda", "enlist", "adnap"])
# [['listen', 'Silent', 'enlist'], ['panda', 'adnap']]
anagram_groups(["aab", "abb", "bab"])
# [['aab'], ['abb', 'bab']]
```

Допишите `anagram_groups(words)`, чтобы функция возвращала группы анаграмм по порядку.

<Hint>

Дайте каждому слову «подпись», общую для всех его анаграмм: его буквы в нижнем регистре, отсортированные по порядку. `"".join(sorted("Silent".lower()))` — это `'eilnst'`, то же самое, что для `"listen"`.

</Hint>

<Hint>

Заведите словарь (dictionary) из подписи в список слов. Он помнит порядок добавления ключей — а это как раз тот порядок, который нужен группам.

</Hint>

<Solution>

```python
def anagram_groups(words):
    groups = {}
    for word in words:
        signature = "".join(sorted(word.lower()))
        if signature not in groups:
            groups[signature] = []
        groups[signature].append(word)
    return list(groups.values())

print(anagram_groups(["listen", "Silent", "panda", "enlist", "adnap"]))
```

Сортировка букв даёт анаграммам один и тот же ключ словаря, поэтому за один проход каждое слово сразу попадает в свою группу. Для n слов длиной до k букв это O(n · k log k) — гораздо быстрее, чем сравнивать все пары слов.

</Solution>
