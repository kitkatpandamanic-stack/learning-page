Панда записывает, сколько побегов бамбука съедает каждый день. Напишите функцию (function) `running_totals(numbers)`, которая возвращает **новый** список (list), где каждый элемент — сумма всех чисел до этой позиции включительно.

- Пустой список даёт пустой список.
- Не меняйте список, который вам передали.

```python
running_totals([1, 2, 3, 4])    # [1, 3, 6, 10]
running_totals([3, -1, -2, 4])  # [3, 2, 0, 4]
running_totals([])              # []
```

Допишите `running_totals(numbers)`, чтобы функция возвращала список накопительных сумм.

<Hint>

Заведите переменную `total`, равную 0. Для каждого числа прибавляйте его к `total`, а затем добавляйте `total` в новый список.

</Hint>

<Solution>

```python
def running_totals(numbers):
    totals = []
    total = 0
    for number in numbers:
        total += number
        totals.append(total)
    return totals

print(running_totals([1, 2, 3, 4]))  # [1, 3, 6, 10]
```

Хватает одного прохода: накопленная сумма переходит от элемента к элементу, поэтому одни и те же числа никогда не складываются дважды.
