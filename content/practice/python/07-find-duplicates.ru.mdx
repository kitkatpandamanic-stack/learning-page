Напишите функцию (function) `find_duplicates(items)`, которая возвращает список (list) значений, встречающихся в `items` **больше одного раза**.

- Каждый повтор попадает в результат только один раз.
- Упорядочьте результат по тому, где каждое значение появляется в `items` **впервые**.
- Строки сравниваются точно, поэтому `"Bamboo"` и `"bamboo"` — разные значения.
- Если повторов нет (или список пуст), верните `[]`.

```python
find_duplicates([3, 1, 3, 2, 1, 3])   # [3, 1]
find_duplicates([1, 2, 2, 1])         # [1, 2]   (1 появляется первой)
find_duplicates(["leaf", "nut"])      # []
```

Допишите `find_duplicates(items)`, чтобы функция возвращала каждое повторяющееся значение один раз, в порядке первого появления.

<Hint>

Чтобы понять, повторяется ли значение, его нужно посчитать. Какая структура данных умеет считать значения и при этом помнить, в каком порядке вы их впервые встретили?

</Hint>

<Hint>

</Hint>

<Solution>

```python
def find_duplicates(items):
    counts = {}
    for item in items:
        counts[item] = counts.get(item, 0) + 1
    return [item for item, count in counts.items() if count > 1]

print(find_duplicates([3, 1, 3, 2, 1, 3]))  # [3, 1]
```

Словарь делает две работы: считает и хранит ключи в том порядке, в каком значения встретились впервые. Если добавлять значение в результат в тот момент, когда оно встретилось второй раз, для `[1, 2, 2, 1]` получится `[2, 1]` — а это неправильный порядок.

</Solution>
