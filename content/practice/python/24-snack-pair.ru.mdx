У панды есть подарочная карта ровно на `budget` монет, и она хочет потратить её целиком на две разные вкусняшки с полки. Напишите `snack_pair(prices, budget)`, которая возвращает кортеж (tuple) `(i, j)` из двух позиций в списке, где `i < j` и `prices[i] + prices[j] == budget`.

- Цены — целые числа (0 или больше), и одна и та же цена может встречаться несколько раз.
- Если подходят несколько пар, верните ту, у которой **вторая** позиция `j` наименьшая. Если этот `j` подходит к нескольким более ранним позициям, возьмите наименьший `i`.
- Если ни одна пара не даёт в сумме бюджет, верните `None`.

```python
snack_pair([3, 8, 4, 6, 2], 10)   # (2, 3): 4 + 6 (8 + 2 тоже подходит, но заканчивается позже)
snack_pair([2, 7, 2, 8], 10)      # (0, 3): 2 + 8, берём первую двойку
snack_pair([5, 5], 10)            # (0, 1)
snack_pair([5], 10)               # None
```

Постарайтесь обойтись одним проходом по списку, без цикла внутри цикла.

<Solution>

```python
def snack_pair(prices, budget):
    first_seen = {}
    for j, price in enumerate(prices):
        partner = budget - price
        if partner in first_seen:
            return (first_seen[partner], j)
        if price not in first_seen:
            first_seen[price] = j
    return None

print(snack_pair([3, 8, 4, 6, 2], 10))  # (2, 3)
```

Просмотр слева направо гарантирует, что первое найденное совпадение имеет наименьший `j`, а хранение только первой позиции каждой цены даёт наименьший `i`. Поиск в словаре в среднем занимает O(1), поэтому весь поиск — O(n), а не O(n²), как при проверке всех пар.

</Solution>
