Редактор кода хочет подчёркивать скобку, из-за которой всё ломается. Напишите `first_bad_bracket(text)`, которая проверяет три вида скобок — `()`, `[]` и `{}` — и возвращает позицию в `text`:

- `-1`, если каждая скобка закрыта скобкой того же вида и в правильном порядке. Все остальные символы игнорируются.
- Если встретилась закрывающая скобка, которая не подходит к последней незакрытой открывающей (или открытых скобок нет вовсе), верните позицию этой закрывающей скобки.
- Если текст закончился, а скобки ещё открыты, верните позицию **самой ранней** из тех, что так и не закрылись.

```python
first_bad_bracket("print(a[0], {1: 2})")  # -1
first_bad_bracket("(]")                    # 1
first_bad_bracket("x)")                    # 1
first_bad_bracket("{[}]")                  # 2: } пришла, пока [ ещё открыта
first_bad_bracket("[()")                   # 0: [ так и не закрылась
first_bad_bracket("")                      # -1
```

<Solution>

```python
PAIRS = {")": "(", "]": "[", "}": "{"}

def first_bad_bracket(text):
    stack = []
    for i, char in enumerate(text):
        if char in "([{":
            stack.append((char, i))
        elif char in PAIRS:
            if not stack or stack[-1][0] != PAIRS[char]:
                return i
            stack.pop()
    if stack:
        return stack[0][1]
    return -1

print(first_bad_bracket("{[}]"))  # 2
```

В стеке всегда лежат ещё открытые скобки, самая свежая — сверху, поэтому каждой закрывающей скобке достаточно посмотреть на вершину. Один проход с O(1) работы на символ даёт O(n) по времени и до O(n) дополнительной памяти на стек.

</Solution>
