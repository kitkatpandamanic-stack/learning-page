У панды есть фишки с буквами, и она хочет увидеть все различные «слова», которые можно выложить, используя **все** фишки. Напишите `arrangements(tiles)`, которая возвращает список всех различных строк, где каждая фишка использована ровно один раз.

- `tiles` — строка; фишки с одинаковой буквой неразличимы, поэтому у `"aab"` всего 3 различные расстановки, а не 6.
- Верните строки в алфавитном порядке (в том, который даёт `sorted()`), без повторов.
- `arrangements("")` возвращает `[""]`: выложить ноль фишек можно ровно одним способом.

```python
arrangements("abc")    # ['abc', 'acb', 'bac', 'bca', 'cab', 'cba']
arrangements("aab")    # ['aab', 'aba', 'baa']
arrangements("zz")     # ['zz']
arrangements("")       # ['']
```

Осторожнее с большим числом повторяющихся фишек: у `"aaaaaaaaaaab"` всего 12 различных расстановок, но 479 001 600 перестановок, если считать каждую фишку отдельной. Сгенерировать их все, а потом убрать повторы — слишком долго.

Допишите `arrangements(tiles)`, чтобы функция возвращала все различные расстановки в отсортированном порядке.

<Hint>

Посчитайте, сколько у вас каждой буквы (`collections.Counter`). Чтобы построить расстановку, выберите следующую букву из *различных* букв, которые ещё остались, используйте одну, сделайте рекурсивный вызов, а затем верните её обратно.

</Hint>

<Hint>

Если на каждом шаге перебирать доступные буквы в алфавитном порядке, результаты сразу получаются отсортированными, а поскольку вы никогда не выбираете одну и ту же букву дважды на одну позицию, дубликатов не появляется.

</Hint>

<Solution>

```python
from collections import Counter

def arrangements(tiles):
    counts = Counter(tiles)
    letters = sorted(counts)
    result = []

    def build(prefix):
        if len(prefix) == len(tiles):
            result.append(prefix)
            return
        for letter in letters:
            if counts[letter] > 0:
                counts[letter] -= 1
                build(prefix + letter)
                counts[letter] += 1

    build("")
    return result

print(arrangements("aab"))  # ['aab', 'aba', 'baa']
```

Это перебор с возвратом (backtracking) по количествам букв, а не по позициям фишек: на каждом шаге пробуются только различные буквы, поэтому каждый путь в рекурсии даёт новую расстановку и ничего не выбрасывается. Работа занимает примерно O(r × n) для r результатов длины n вместо O(n!) для всех перестановок.

</Solution>
