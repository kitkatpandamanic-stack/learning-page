Серверы Бамбукового магазина пишут в лог такие строки:

```text
2026-03-14 09:26:53 ERROR [payments] Card declined (code 51)
```

Это дата `YYYY-MM-DD`, время `HH:MM:SS`, уровень, имя сервиса в квадратных скобках и сообщение, разделённые одиночными пробелами. Напишите две функции (function):

- `parse_line(line)` возвращает словарь (dictionary) с ключами `"date"`, `"time"`, `"level"`, `"service"` и `"message"` (все — строки) или `None`, если строка не соответствует формату. Пробелы в начале и в конце строки игнорируются.
  - Уровень — ровно одно из `DEBUG`, `INFO`, `WARNING` или `ERROR`.
  - Сервис состоит из одной или нескольких строчных латинских букв, цифр или дефисов.
  - Сообщение — всё, что идёт после сервиса и пробела за ним; оно не может быть пустым.
- `errors_by_service(lines)` возвращает словарь, где каждому сервису сопоставлено количество его корректных строк с уровнем `ERROR`. Сервисы без ошибок в словарь не попадают.

```python
parse_line("2026-03-14 09:26:53 ERROR [payments] Card declined (code 51)")
# {'date': '2026-03-14', 'time': '09:26:53', 'level': 'ERROR',
#  'service': 'payments', 'message': 'Card declined (code 51)'}
parse_line("2026-03-14 09:26:53 OOPS [payments] Hmm")   # None (неизвестный уровень)
parse_line("just some text")                            # None

errors_by_service([
    "2026-03-14 09:00:00 ERROR [payments] Timeout",
    "2026-03-14 09:00:05 INFO [search] Query took 12 ms",
    "2026-03-14 09:01:00 ERROR [payments] Card declined",
    "2026-03-14 09:02:00 ERROR [stock-db] Disk almost full",
    "garbage ERROR [payments] not a real line",
])
# {'payments': 2, 'stock-db': 1}
```

<Solution>

```python
import re

LINE = re.compile(
    r"(\d{4}-\d{2}-\d{2}) (\d{2}:\d{2}:\d{2}) "
    r"(DEBUG|INFO|WARNING|ERROR) \[([a-z0-9-]+)\] (.+)"
)

def parse_line(line):
    match = LINE.fullmatch(line.strip())
    if match is None:
        return None
    date, time, level, service, message = match.groups()
    return {"date": date, "time": time, "level": level,
            "service": service, "message": message}

def errors_by_service(lines):
    counts = {}
    for line in lines:
        entry = parse_line(line)
        if entry and entry["level"] == "ERROR":
            counts[entry["service"]] = counts.get(entry["service"], 0) + 1
    return counts

print(parse_line("2026-03-14 09:26:53 ERROR [payments] Card declined"))
```

`fullmatch` привязывает шаблон ко всей строке целиком, а группы за один шаг извлекают каждую часть. Благодаря предварительному `strip()` сообщение не может заканчиваться пробелами, а пустое сообщение не проходит, потому что `.+` требует хотя бы одного символа.

</Solution>
