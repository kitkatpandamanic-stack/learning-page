Functions are values in Python: you can put them in a list, pass them around and even **return** them. Write a function `pipeline(steps)` that takes a list of one-argument functions and returns a **new function**. Calling that new function with a value passes it through every step in order and returns the final result.

- `pipeline([f, g, h])(x)` must give the same answer as `h(g(f(x)))`.
- With no steps, the new function returns its value unchanged.
- The new function can be called again and again with different values.

```python
clean = pipeline([str.strip, str.lower, lambda s: s.replace(" ", "-")])
clean("  Red Panda ")    # 'red-panda'
clean("BAMBOO Forest")   # 'bamboo-forest'

pipeline([])(42)         # 42
```

To return a function, define it with `def` inside `pipeline` and `return` its name, without calling it.

Finish `pipeline(steps)` so it returns a function that runs all the steps.

<Hint>

Inside `pipeline`, write `def run(value):` that loops over `steps` and replaces `value` with `step(value)` each time. The inner function can see `steps` because it was defined inside `pipeline`.

</Hint>

<Solution>

```python
def pipeline(steps):
    def run(value):
        for step in steps:
            value = step(value)
        return value
    return run

clean = pipeline([str.strip, str.lower, lambda s: s.replace(" ", "-")])
print(clean("  Red Panda "))  # red-panda
```

`run` remembers the `steps` it was created with (this is called a *closure*), so each pipeline is its own little machine. Calling it costs one call per step.

</Solution>
