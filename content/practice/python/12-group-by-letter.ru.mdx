Напишите функцию (function) `group_by_letter(words)`, которая возвращает словарь (dictionary): каждый ключ — первая буква в нижнем регистре, а значение — список слов, начинающихся с этой буквы.

- Заглавные и строчные буквы попадают в одну группу: `"Plum"` идёт под ключ `"p"`.
- Сохраняйте каждое слово ровно в том виде, в каком оно записано, и в том порядке, в каком оно встречается.
- Ключи идут в том порядке, в каком встречается первое слово каждой группы.
- Пустые строки пропускайте. Повторяющиеся слова сохраняются все.

```python
group_by_letter(["panda", "Plum", "apple", "pear"])
# {'p': ['panda', 'Plum', 'pear'], 'a': ['apple']}
group_by_letter([])   # {}
```

Допишите `group_by_letter(words)`, чтобы функция группировала слова по их первой букве в нижнем регистре.

<Hint>

Для каждого непустого слова возьмите `word[0].lower()`. Если такого ключа в словаре ещё нет, создайте для него пустой список, а затем добавьте слово.

</Hint>

<Solution>

```python
def group_by_letter(words):
    groups = {}
    for word in words:
        if not word:
            continue
        letter = word[0].lower()
        if letter not in groups:
            groups[letter] = []
        groups[letter].append(word)
    return groups

print(group_by_letter(["panda", "Plum", "apple", "pear"]))
```

`groups.setdefault(letter, []).append(word)` делает «создать, если нет, затем добавить» в одну строку.

</Solution>
