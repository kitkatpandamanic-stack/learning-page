Settings files often use dotted keys like `"db.host"`, while programs prefer nested dicts. Write two functions that convert between the two shapes.

`unflatten(flat)` takes a dict whose keys are dotted paths and returns nested dicts:

- `"db.host": "x"` means `result["db"]["host"] == "x"`. A key without dots is a top-level value.
- Keys are never empty and never have empty parts (no `".a"`, `"a."` or `"a..b"`), and the values are never dicts.
- If one key is a value **and** a folder at the same time, like `"db"` together with `"db.host"`, raise `ValueError`, whichever comes first.

`flatten_keys(nested)` does the opposite: it takes nested dicts (keys without dots) and returns a flat dict of dotted paths. An empty dict inside contributes no keys.

Neither function may change its argument.

```python
unflatten({"db.host": "localhost", "db.port": 5432, "debug": True})
# {'db': {'host': 'localhost', 'port': 5432}, 'debug': True}

unflatten({"a.b.c": 1, "a.b.d": 2, "a.e": 3})
# {'a': {'b': {'c': 1, 'd': 2}, 'e': 3}}

unflatten({"db": "sqlite", "db.host": "x"})   # ValueError

flatten_keys({"db": {"host": "localhost", "port": 5432}, "debug": True})
# {'db.host': 'localhost', 'db.port': 5432, 'debug': True}
```

Finish `unflatten` and `flatten_keys`.

<Hint>

For `unflatten`, split each key on `"."` and walk down from the result dict, creating a new dict for each missing folder. If a folder name already holds a value that isn't a dict, or the last part already exists, that's a clash.

</Hint>

<Hint>

`flatten_keys` is naturally recursive: pass the path so far (`"a.b"`) down as a prefix. A dict value means "go deeper", anything else is stored under `prefix + "." + key`.

</Hint>

<Solution>

```python
def unflatten(flat):
    result = {}
    for key, value in flat.items():
        *folders, last = key.split(".")
        node = result
        for part in folders:
            node = node.setdefault(part, {})
            if not isinstance(node, dict):
                raise ValueError(f"{key!r} clashes with an existing value")
        if last in node:
            raise ValueError(f"{key!r} clashes with an existing folder")
        node[last] = value
    return result

def flatten_keys(nested, prefix=""):
    flat = {}
    for key, value in nested.items():
        path = f"{prefix}.{key}" if prefix else key
        if isinstance(value, dict):
            flat.update(flatten_keys(value, path))
        else:
            flat[path] = value
    return flat

print(unflatten({"db.host": "localhost", "db.port": 5432, "debug": True}))
```

Because values are never dicts, a dict in the result is always a folder, which makes both clash cases easy to spot: a folder path runs into a plain value, or a value lands where a folder already is. Both functions touch each key part once, so they're O(total length of all the keys).

</Solution>
