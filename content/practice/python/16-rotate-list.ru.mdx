Напишите функцию (function) `rotate(items, k)`, которая возвращает **новый** список (list), повёрнутый на `k` шагов вправо: последние `k` элементов по порядку переезжают в начало.

- Отрицательное `k` поворачивает список влево.
- `k` может быть больше длины списка: повернуть список из 3 элементов на 7 — то же самое, что повернуть его на 1.
- Пустой список при любом `k` даёт `[]`.
- Не меняйте список, который вам передали.

```python
rotate([1, 2, 3, 4, 5], 2)   # [4, 5, 1, 2, 3]
rotate([1, 2, 3], -1)        # [2, 3, 1]
rotate([1, 2, 3], 7)         # [3, 1, 2]
rotate([], 3)                # []
```

Допишите `rotate(items, k)`, чтобы функция возвращала повёрнутую копию.

<Hint>

Поворот списка на его собственную длину ничего не меняет. Как превратить любое `k`, даже огромное или отрицательное, в небольшое число шагов? Осторожно с пустым списком.

</Hint>

<Hint>

Если список пуст, сразу верните `[]`, потому что `% 0` — это ошибка. Затем сделайте `k %= len(items)`: это превращает любое `k` (и отрицательное тоже) в число шагов от 0 до `len(items) - 1`. Через срезы последние `k` элементов — это `items[-k:]`, а те, что перед ними, — `items[:-k]`; склейте их. Срезы создают новые списки, поэтому исходный не меняется.

</Hint>

<Solution>

```python
def rotate(items, k):
    if not items:
        return []
    k %= len(items)
    return items[-k:] + items[:-k]

print(rotate([1, 2, 3, 4, 5], 2))  # [4, 5, 1, 2, 3]
```

После `k %= len(items)` поворот влево на 1 превращается в поворот вправо на `len - 1`, так что одна формула покрывает все случаи (при `k = 0` срез `items[-0:]` — это весь список, а `items[:-0]` пуст). Срезы создают новые списки, поэтому исходный остаётся нетронутым; работа занимает O(n).

</Solution>
