Напишите функцию (function) `word_counts(text)`, которая возвращает словарь (dictionary): каждому слову из `text` в нём соответствует количество его появлений.

- Разбейте текст на слова по пробельным символам (это делает `text.split()`).
- Переведите каждое слово в нижний регистр, чтобы `"The"` и `"the"` считались одним словом.
- Уберите знаки препинания `.,!?;:` с обоих концов каждого слова.
- Если слово состоит только из знаков препинания, пропустите его.

```python
word_counts("The panda ate. The PANDA slept!")
# {'the': 2, 'panda': 2, 'ate': 1, 'slept': 1}
word_counts("Hi! hi? hi.")   # {'hi': 3}
word_counts("")              # {}
```

<Solution>

```python
def word_counts(text):
    counts = {}
    for word in text.lower().split():
        word = word.strip(".,!?;:")
        if word:
            counts[word] = counts.get(word, 0) + 1
    return counts

print(word_counts("The panda ate. The PANDA slept!"))
```

`.get(word, 0)` возвращает 0 для слова, которое ещё не встречалось, поэтому одна и та же строка обрабатывает и новые, и повторные слова. Когда слова очищены, подсчёт за вас может сделать `collections.Counter`.

</Solution>
