A code editor wants to underline the bracket that causes trouble. Write `first_bad_bracket(text)` that checks the three bracket kinds `()`, `[]` and `{}` and returns a position in `text`:

- `-1` if every bracket is closed by the matching kind, in the right order. All other characters are ignored.
- If a closing bracket appears that doesn't match the most recent unclosed opening bracket (or there is nothing open), return the position of that closing bracket.
- If the text ends while brackets are still open, return the position of the **earliest** one that was never closed.

```python
first_bad_bracket("print(a[0], {1: 2})")  # -1
first_bad_bracket("(]")                    # 1
first_bad_bracket("x)")                    # 1
first_bad_bracket("{[}]")                  # 2: } arrives while [ is still open
first_bad_bracket("[()")                   # 0: the [ is never closed
first_bad_bracket("")                      # -1
```

<Solution>

```python
PAIRS = {")": "(", "]": "[", "}": "{"}

def first_bad_bracket(text):
    stack = []
    for i, char in enumerate(text):
        if char in "([{":
            stack.append((char, i))
        elif char in PAIRS:
            if not stack or stack[-1][0] != PAIRS[char]:
                return i
            stack.pop()
    if stack:
        return stack[0][1]
    return -1

print(first_bad_bracket("{[}]"))  # 2
```

The stack always holds the brackets that are still open, most recent on top, so each closing bracket only needs to look at the top. One pass with O(1) work per character makes it O(n) time and up to O(n) extra space for the stack.
