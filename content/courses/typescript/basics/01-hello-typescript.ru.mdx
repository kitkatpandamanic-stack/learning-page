**Программа** (program) — это список инструкций, которые компьютер выполняет сверху вниз. **TypeScript** — язык программирования, на котором эти инструкции пишут. По сути это **JavaScript плюс типы**: вы указываете, каким должно быть каждое значение, а **компилятор** (compiler) TypeScript проверяет код на ошибки _ещё до_ его запуска. 🐼

## Ваша первая программа

`console.log(...)` выводит всё, что стоит в скобках. Текст пишут в кавычках, и он называется **строкой** (string). Числа пишут без кавычек:

<CodeExample output={`Привет, TypeScript! 🐼
5`}>

```ts
console.log("Привет, TypeScript! 🐼");
console.log(2 + 3);
```

</CodeExample>

Каждая строка кода — это одна **инструкция** (statement), и выполняются они по порядку. Символ `;` в конце показывает, где инструкция заканчивается.

## Переменные и первая аннотация типа

**Переменная** (variable) — это коробка с именем, в которой лежит значение. Её создают с помощью `const` (значение никогда не меняется) или `let` (значение можно поменять позже). В TypeScript можно добавить **аннотацию типа** (type annotation) — двоеточие и после него тип, — чтобы указать, что может лежать в коробке:

<CodeExample output={`Мурка
12
Мурка: 12 лет`}>

```ts
const petName: string = "Мурка";
let age: number = 12;

console.log(petName);
console.log(age);
console.log(`${petName}: ${age} лет`);
```

</CodeExample>

- `: string` означает «здесь лежит текст».
- `: number` означает «здесь лежит число».
- Текст в обратных кавычках — это **шаблонная строка** (template literal): `${...}` подставляет значение прямо в строку.

## Ловим ошибки до запуска

Вот главная идея. Если `age` — это `number`, TypeScript не даст положить туда текст:

```ts
let age: number = 12;
age = "тринадцать";
// ❌ Error: Type 'string' is not assignable to type 'number'.
```

Обычный JavaScript спокойно выполнил бы этот код, и ошибка всплыла бы гораздо позже. TypeScript останавливает вас **сразу** и показывает, в какой строке проблема.

Он также знает, что можно _делать_ с каждым типом. У чисел нет верхнего регистра, поэтому и такая ошибка будет поймана:

```ts
const score: number = 10;
score.toUpperCase();
// ❌ Error: Property 'toUpperCase' does not exist on type 'number'.
```

Исправьте ошибки — и программа заработает как обычно:

<CodeExample output={`14
УраУраУра`}>

```ts
let age: number = 12;
age = 13;
console.log(age + 1);

const greeting: string = "Ура";
console.log(greeting.repeat(3));
```

</CodeExample>

<Callout type="note" title="Во время работы программы типов нет">

На самом деле компьютеры (и браузеры) выполняют **JavaScript**. Компилятор проверяет типы, а потом удаляет их, и остаётся обычный JavaScript. Типы — это страховка для _вас_, пока вы пишете код; на то, что делает программа, они не влияют.

</Callout>

## Как PandaDev проверяет ваш код

В редакторах PandaDev кнопки **«Запустить»** и **«Проверить»** сначала **проверяют типы** в коде. Если есть ошибки типов, код не выполняется. Вместо этого вы увидите сообщения вроде такого:

```text
Line 2: Type 'string' is not assignable to type 'number'.
```

Посмотрите на номер строки (`Line 2` — «строка 2»), исправьте её и снова нажмите «Запустить». В настоящем проекте то же самое делает компилятор `tsc` на вашем компьютере:

```bash
npx tsc hello.ts   # проверить типы и создать hello.js
node hello.js      # запустить JavaScript
```

<Callout type="tip" title="Сообщения об ошибках — ваши друзья">

Поначалу ошибки типов могут пугать, но они устроены по одному шаблону: «Type **X** is not assignable to type **Y**» означает, что вы передали значение типа X туда, где ожидался тип Y. Читайте их не спеша — почти всегда они точно говорят, что не так.

</Callout>

`boolean` — это тип для `true` и `false` (пишутся без кавычек), то есть **логическое значение** (boolean). Подробно вы познакомитесь с ним в следующем уроке.

<Hint>

`"Панда"` — это текст, поэтому `playerName` должен быть `string`. Жизни считают, так что оставьте `number`, но уберите кавычки у `"3"`. Точно так же `"false"` в кавычках — это строка, а логическое значение пишется просто `false`.

```ts
const playerName: string = "Панда";
let lives: number = 3;
let isWinner: boolean = false;

lives = lives + 1;

console.log(playerName); // Панда
console.log(lives); // 4
console.log(isWinner); // false
```

## Итоги

- TypeScript — это **JavaScript плюс типы**; компилятор проверяет код до запуска.
- `console.log(...)` выводит значение; строки пишут в кавычках, числа — без.
- `const` создаёт переменную, которую нельзя изменить, а `let` — ту, которую можно.
- **Аннотация типа**, например `let age: number = 12`, говорит, что может хранить переменная.
- Ошибки типов не дают коду запуститься и сообщают строку и суть проблемы.
