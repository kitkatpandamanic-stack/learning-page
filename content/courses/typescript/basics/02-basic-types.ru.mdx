У каждого значения (value) в программе есть **тип** (type): это текст, число или ответ «да/нет»? В этом уроке вы познакомитесь с тремя типами, которые нужны постоянно, узнаете, когда TypeScript может определить тип **сам**, и впервые посмотрите на списки значений.

## Три повседневных типа

| Тип       | Что хранит                       | Примеры                |
| --------- | -------------------------------- | ---------------------- |
| `string`  | Текст в кавычках                 | `"Токио"`, `'hi'`      |
| `number`  | Любое число, целое или дробное   | `42`, `-3`, `13.96`    |
| `boolean` | Ответ «да/нет»                   | `true`, `false`        |

<CodeExample output={`Токио 13.96 true
string number boolean`}>

```ts
const city: string = "Токио";
const population: number = 13.96;
const isCapital: boolean = true;

console.log(city, population, isCapital);
console.log(typeof city, typeof population, typeof isCapital);
```

</CodeExample>

`console.log` может вывести сразу несколько значений, перечисленных через запятую. **Оператор** (operator) `typeof` спрашивает у JavaScript тип значения прямо во время работы программы.

## Вывод типов: TypeScript догадывается сам

Аннотировать всё подряд не обязательно. Если вы задаёте переменной начальное значение, TypeScript **выводит** (infers) её тип из этого значения. Это называется **вывод типов** (type inference):

<CodeExample output="ПРИВЕТ, МИР">

```ts
let message = "Привет"; // TypeScript выводит: string
message = message + ", мир";
console.log(message.toUpperCase());
```

</CodeExample>

Здесь нет `: string`, но `message` всё равно строка, и она всё равно проверяется:

```ts
let score = 10; // выведено: number
score = 15; // всё в порядке
score = "пятнадцать";
// ❌ Error: Type 'string' is not assignable to type 'number'.
```

## `let` и `const` (и литеральные типы)

Переменной `let` можно присвоить новое значение, а `const` — нельзя:

```ts
const lives = 3;
lives = 2;
// ❌ Error: Cannot assign to 'lives' because it is a constant.
```

Раз `const` никогда не меняется, TypeScript выводит для неё более точный тип — **литеральный тип** (literal type):

```ts
let pet = "кот"; // тип: string (значение может измениться)
const sound = "мяу"; // тип: "мяу" (значение всегда будет только "мяу")
```

Пока с литеральными типами ничего делать не нужно. По-настоящему полезными они станут в модуле «Управление потоком».

<Callout type="tip" title="Выбирайте const">

По умолчанию используйте `const` и переходите на `let`, только когда значение действительно должно меняться. Код проще читать, когда большинство значений остаются на месте.

</Callout>

## Массивы: первое знакомство

**Массив** (array) — это список значений в квадратных скобках. Его тип записывают как тип элемента и `[]` после него, так что `string[]` означает «список строк»:

<CodeExample output={`[ 'яблоко', 'банан', 'манго' ]
3
яблоко`}>

```ts
const fruits: string[] = ["яблоко", "банан"];
fruits.push("манго");

console.log(fruits);
console.log(fruits.length);
console.log(fruits[0]);
```

</CodeExample>

- `.push(...)` добавляет элемент в конец.
- `.length` — сколько в массиве элементов.
- `fruits[0]` — это **первый** элемент: счёт начинается с 0.

TypeScript следит, чтобы в массив попадали только элементы нужного типа:

```ts
fruits.push(42);
// ❌ Error: Argument of type 'number' is not assignable to parameter of type 'string'.
```

## Первое знакомство с функциями

**Функция** (function) — это именованный блок кода, который можно использовать снова и снова. Её **параметры** (parameters) — это входные данные, а `return` отправляет результат обратно. Тип параметров вывести нельзя (функцию могут вызвать с чем угодно), поэтому их всегда аннотируют. Можно также указать, что функция возвращает:

<CodeExample output={`14
2.5`}>

```ts
function double(n: number): number {
  return n * 2;
}

console.log(double(7));
console.log(double(1.25));
```

</CodeExample>

Гораздо больше о функциях вы узнаете в модуле «Типизированные функции». А пока запомните: **у параметров всегда есть тип**.

## Когда писать аннотацию?

<CodeExample output={`12
[ 'Аня' ]`}>

```ts
let total: number; // начального значения нет, поэтому аннотируем
total = 5 + 7;
console.log(total);

const names: string[] = []; // пустой массив, поэтому аннотируем
names.push("Аня");
console.log(names);
```

</CodeExample>

Простое правило:

- **Доверьте TypeScript вывод типа**, если сразу задаёте переменной значение: `let count = 0`.
- **Пишите аннотацию**, если начального значения нет, если начинаете с пустого массива, и для параметров функций.

<Callout type="note">

Аннотация там, где сработал бы вывод типов, — не ошибка, просто лишние символы. Пока вы учитесь, несколько дополнительных аннотаций помогают лучше думать о типах.

</Callout>

## Итоги

- `string` — это текст, `number` — любое число, `boolean` — `true` или `false`.
- TypeScript **выводит** тип переменной из её начального значения.
- `const` нельзя переприсвоить, поэтому она получает точный **литеральный тип**; `let` получает более широкий тип.
- `string[]` — это массив строк; `.push` добавляет элементы, а `.length` считает их.
- Пишите аннотацию, когда нет начального значения, для пустых массивов и для параметров функций.
