У вас есть типизированные вопросы (часть 1) и надёжная проверка ответов (часть 2). Пора играть! В этой заключительной части вы проведёте викторину от начала до конца: покажете каждый вопрос, отреагируете на ответ игрока знаком ✅ или ❌ и закончите **отчётом с результатами**, где игрок получит ранг. 🏆

По пути вы будете использовать **массивы и индексы** (урок «Массивы и кортежи»), **объединения литералов** для ранга (урок «Литеральные типы и switch»), **интерфейс** для отчёта и много небольших типизированных функций, работающих вместе.

## Имитируем игрока

Настоящая викторина ждала бы, пока игрок наберёт ответ. PandaDev запускает ваш код без клавиатуры, поэтому мы будем **имитировать** игрока: его ответы приходят в виде массива чисел, по одному на вопрос. `[2, 1, 3]` означает «вариант 2 в первом вопросе, вариант 1 во втором, вариант 3 в третьем».

Это на самом деле отличная привычка. Игра, которая получает ввод (input) через **параметр**, предсказуема: одни и те же ответы всегда дают один и тот же результат, а значит, её можно тестировать. Подставьте другой массив — и у вас другой игрок.

А если игрок даст меньше ответов, чем есть вопросов? Вспомните предупреждение из урока «Массивы и кортежи»: **индексы не проверяются**. TypeScript считает, что `choices[5]` — это `number`, но там ничего нет:

<CodeExample output={`1
undefined
1
null`}>

```ts
const playerChoices: number[] = [2, 1];

console.log(playerChoices[1]);
console.log(playerChoices[5]); // тип number, но элемента нет!

function choiceFor(choices: number[], round: number): number | null {
  if (round < choices.length) {
    return choices[round];
  }
  return null; // ответы закончились: считаем вопрос пропущенным
}

console.log(choiceFor(playerChoices, 1));
console.log(choiceFor(playerChoices, 5));
```

</CodeExample>

`choiceFor` сначала проверяет длину и честно возвращает `number | null`. А `null` — это ровно то, что `grade` из части 2 уже понимает как «пропущено». Детали складываются вместе. 🧩

## Обратная связь для игрока

После каждого вопроса игрок хочет знать, как он справился. `feedback` превращает проверенный ответ в дружелюбную строку. Она принимает `AnswerResult` от `grade`, поэтому ей самой ничего проверять не нужно:

<CodeExample output={`Ваш выбор: 2 ✅ +10 очков
Ваш выбор: 3 ❌ Правильный ответ: string
Пропущено ❌ Правильный ответ: string`}>

```ts
type Difficulty = "easy" | "medium" | "hard";

interface Question {
  readonly id: number;
  prompt: string;
  choices: string[];
  answer: number;
  difficulty: Difficulty;
  points?: number;
}

type AnswerResult = {
  questionId: number;
  correct: boolean;
  points: number;
};

function feedback(
  q: Question,
  choice: number | null,
  result: AnswerResult,
): string {
  const answer = q.choices[q.answer];
  if (choice === null) {
    return `Пропущено ❌ Правильный ответ: ${answer}`;
  }
  if (result.correct) {
    return `Ваш выбор: ${choice} ✅ +${result.points} очков`;
  }
  return `Ваш выбор: ${choice} ❌ Правильный ответ: ${answer}`;
}

const q1: Question = {
  id: 1,
  prompt: "Какой тип хранит текст?",
  choices: ["number", "string", "boolean"],
  answer: 1,
  difficulty: "easy",
};

const right: AnswerResult = { questionId: 1, correct: true, points: 10 };
const wrong: AnswerResult = { questionId: 1, correct: false, points: 0 };

console.log(feedback(q1, 2, right));
console.log(feedback(q1, 3, wrong));
console.log(feedback(q1, null, wrong));
```

</CodeExample>

Тогда один **раунд** игры — это три шага: проверить выбор, вывести вопрос, вывести обратную связь. В упражнении вы напишете это как `playRound(q, choice)`; функция ещё и возвращает `AnswerResult`, чтобы потом можно было подсчитать очки.

## Отчёт с результатами

В конце игрок получает **ранг**. Рангов ровно три, так что это снова объединение литералов. Опечатка в названии ранга не проскочит:

```ts
type Rank = "Panda Master" | "Bamboo Expert" | "Curious Cub";

function rankFor(percentage: number): Rank {
  if (percentage >= 80) {
    return "Panda master";
    // ❌ Error: Type '"Panda master"' is not assignable to type 'Rank'. Did you mean '"Panda Master"'?
  }
  // ...
}
```

Ранг зависит от **процента** набранных игроком очков. Одна небольшая новинка: `Math.round(n)` округляет число до **ближайшего целого**, так что `12.5` превращается в `13`, а `74.6` — в `75`.

Здесь есть и ловушка. Если вопросов нет, максимальный счёт равен `0`, а деление на `0` даёт `NaN` («не число», not a number), что в отчёте выглядело бы нелепо. Это исправляет защитное условие:

<CodeExample output={`75 Bamboo Expert
13 Curious Cub
100 Panda Master
NaN
0`}>

```ts
type Rank = "Panda Master" | "Bamboo Expert" | "Curious Cub";

function rankFor(percentage: number): Rank {
  if (percentage >= 80) {
    return "Panda Master";
  }
  if (percentage >= 50) {
    return "Bamboo Expert";
  }
  return "Curious Cub";
}

function percentOf(score: number, max: number): number {
  if (max === 0) {
    return 0; // вопросов нет: не делим на 0
  }
  return Math.round((score / max) * 100);
}

console.log(percentOf(60, 80), rankFor(percentOf(60, 80)));
console.log(percentOf(10, 80), rankFor(percentOf(10, 80)));
console.log(percentOf(80, 80), rankFor(percentOf(80, 80)));
console.log(0 / 0);
console.log(percentOf(0, 0));
```

</CodeExample>

Весь отчёт — это один объект, поэтому для него нужен интерфейс. Обратите внимание: `rank` имеет тип `Rank`, а не просто `string`:

```ts
interface QuizReport {
  score: number;
  maxScore: number;
  correctCount: number;
  questionCount: number;
  percentage: number;
  rank: Rank;
}
```

## Выбираем, какие вопросы играть

Поскольку `playQuiz` получает вопросы через параметр, вы ещё до начала игры решаете, **какие** вопросы играть и в **каком порядке**. Хотите лёгкий раунд? Отфильтруйте по сложности через `filter`. Хотите другой порядок? Передайте список позиций:

<CodeExample output={`[ 3 ]

[ 2 ]`}>

```ts
type Difficulty = "easy" | "medium" | "hard";

interface Question {
  readonly id: number;
  prompt: string;
  choices: string[];
  answer: number;
  difficulty: Difficulty;
  points?: number;
}

function byDifficulty(list: Question[], level: Difficulty): Question[] {
  return list.filter((q) => q.difficulty === level);
}

function pickQuestions(list: Question[], order: number[]): Question[] {
  const picked: Question[] = [];
  for (const index of order) {
    if (index >= 0 && index < list.length) {
      picked.push(list[index]); // пропускаем несуществующие позиции
    }
  }
  return picked;
}

function makeQuestion(id: number, level: Difficulty): Question {
  return {
    id: id,
    prompt: `Вопрос ${id}`,
    choices: ["да", "нет"],
    answer: 0,
    difficulty: level,
  };
}

const questions: Question[] = [
  makeQuestion(1, "easy"),
  makeQuestion(2, "medium"),
  makeQuestion(3, "hard"),
];

console.log(byDifficulty(questions, "hard").map((q) => q.id));
console.log(pickQuestions(questions, [2, 0, 1]).map((q) => q.id));
console.log(pickQuestions(questions, [1, 7]).map((q) => q.id));
```

</CodeExample>

Затем сыграйте выбранный раунд: `playQuiz(byDifficulty(questions, "easy"), [2])`. Порядок **внедряется** (inject) через параметр, так же как ответы игрока, поэтому даже «перемешанная» викторина остаётся предсказуемой и тестируемой.

<Callout type="tip" title="Внедряйте то, что меняется">

Ввод игрока, случайный порядок, текущее время: всё, что меняется от запуска к запуску, проще всего обрабатывать, когда оно передаётся **внутрь** через параметр. Логика игры остаётся прежней, а тестировать её можно на любых входных данных.

</Callout>

type AnswerResult = {
  questionId: number;

function pointsFor(difficulty: Difficulty): number {
  switch (difficulty) {
    case "easy":
      return 10;
    case "medium":
      return 20;
    case "hard":
      return 30;
    default: {
      const unreachable: never = difficulty;
      return unreachable;
    }
  }
}

function questionPoints(q: Question): number {
  return q.points ?? pointsFor(q.difficulty);
}

function grade(q: Question, choice: number | null): AnswerResult {
  if (choice === null) {
    return { questionId: q.id, correct: false, points: 0 };
  }
  if (choice < 1 || choice > q.choices.length) {
    return { questionId: q.id, correct: false, points: 0 };
  }
  if (choice - 1 !== q.answer) {
    return { questionId: q.id, correct: false, points: 0 };
  }
  return { questionId: q.id, correct: true, points: questionPoints(q) };
}

  let total = 0;
  for (const result of results) {
    total += result.points;

  return total;

  let total = 0;
  for (const q of list) {
    total += questionPoints(q);

type Rank = "Panda Master" | "Bamboo Expert" | "Curious Cub";

interface QuizReport {
  score: number;
  maxScore: number;
  correctCount: number;
  questionCount: number;
  percentage: number;
  rank: Rank;
}

function choiceFor(choices: number[], round: number): number | null {
  if (round < choices.length) {
    return choices[round];
  }
  return null;
}

function percentOf(score: number, max: number): number {
  if (max === 0) {
    return 0;
  }
  return Math.round((score / max) * 100);
}

function feedback(
  q: Question,
  choice: number | null,
  result: AnswerResult,
): string {
  const answer = q.choices[q.answer];
  if (choice === null) {
    return `Пропущено ❌ Правильный ответ: ${answer}`;
  }
  if (result.correct) {
    return `Ваш выбор: ${choice} ✅ +${result.points} очков`;
  }
  return `Ваш выбор: ${choice} ❌ Правильный ответ: ${answer}`;
}

function rankFor(percentage: number): Rank {
  if (percentage >= 80) {
    return "Panda Master";
  }
  if (percentage >= 50) {
    return "Bamboo Expert";
  }
  return "Curious Cub";
}

function playQuiz(list: Question[], choices: number[]): QuizReport {
  const results: AnswerResult[] = [];
  let correctCount = 0;

  for (let i = 0; i < list.length; i++) {
    const result = playRound(list[i], choiceFor(choices, i));
    results.push(result);
    if (result.correct) {
      correctCount++;
    }

  const score = totalScore(results);
  const max = maxScore(list);
  const percentage = percentOf(score, max);

  return {
    score: score,
    maxScore: max,
    correctCount: correctCount,
    questionCount: list.length,
    percentage: percentage,
    rank: rankFor(percentage),
  };
}
