Here's a bug that type-checks perfectly. On Friday the server team renames a note's `text` field to `body`. Their tests pass. The front end still reads `note.text`, gets `undefined` and shows empty notes, and no compiler complains, because the front end has its **own** copy of the `Note` type that nobody updated. Both sides were type-safe; they just weren't safe **together**.

The fix is to describe the API **once**, as a **contract**, and let both sides use it. In this lesson you'll write a contract type, derive a typed client from it, make the server's handlers follow it, and finish the module by building the typed notes API with its own client. 🤝

## One contract for both sides

A contract lists every endpoint of the API with what goes in and what comes out. A nice way to write it in TypeScript is one object type whose keys are `"METHOD /path"` strings:

```ts title="contract.ts"
export interface Note {
  id: number;
  title: string;
  text: string;
  pinned: boolean;
}
export interface NewNote {
  title: string;
  text?: string;
  pinned?: boolean;
}
export type NotePatch = Partial<NewNote>;

export type NotesApi = {
  "GET /notes": { response: Note[] };
  "POST /notes": { body: NewNote; response: Note };
  "GET /notes/:id": { params: { id: string }; response: Note };
  "PATCH /notes/:id": {
    params: { id: string };
    body: NotePatch;
    response: Note;
  };
  "DELETE /notes/:id": { params: { id: string }; response: null };
};
```

Each entry says which `params` the path has, what `body` the client sends (if any) and what `response` it gets back (`null` for the `DELETE`, which answers 204 with no body). It's only types, so it costs nothing at runtime.

The pieces come out with the tools from the Generics module: `keyof` for the list of routes and **indexed access types** for the parts of one route:

```ts
type Route = keyof NotesApi; // "GET /notes" | "POST /notes" | ...
type CreateBody = NotesApi["POST /notes"]["body"]; // NewNote
type ListResponse = NotesApi["GET /notes"]["response"]; // Note[]

const route: Route = "GET /note";
// ❌ Error: Type '"GET /note"' is not assignable to type 'keyof NotesApi'. Did you mean '"GET /notes"'?
const draft: CreateBody = { titel: "Nap" };
// ❌ Error: Object literal may only specify known properties, but 'titel' does not exist in type 'NewNote'. Did you mean to write 'title'?
type Nope = NotesApi["GET /notes"]["body"];
// ❌ Error: Property 'body' does not exist on type '{ response: Note[]; }'.
```

In a real project, `contract.ts` lives in a folder (or package) that both the server and the front end import, with `import type { NotesApi } from "../shared/contract"`. As you saw in [Modules & Declaration Files](/learn/typescript/modules-and-declaration-files), a type-only import disappears from the compiled JavaScript, so the browser bundle doesn't pull in any server code. Rename `text` to `body` in the contract, and every place on **both** sides that still says `text` stops compiling.

## A client derived from the contract

Writing one fetch function per endpoint by hand is how clients drift. Instead, write **one** generic `call` function whose types come from the contract: pick a route, and TypeScript knows which params and body it needs and what it returns. It doesn't even need to know about notes: `createClient<Api>` works for **any** contract.

To show that, here's a contract for the practice API's to-dos. PandaDev has a practice API built in, so this runs offline and always gives the same answers, but real APIs work the same way:

<CodeExample output={`{ id: 4, title: 'Nap', done: false }
true
[ 'Learn fetch', 'Build the movie app', 'Eat some bamboo', 'Nap' ]
{ kind: 'http', status: 404, message: 'Todo not found' }`}>

```ts
// ----- the contract (shared by client and server) -----
interface Todo {
  id: number;
  title: string;
  done: boolean;
}
type NewTodo = { title: string; done?: boolean };

type TodosApi = {
  "GET /todos": { response: Todo[] };
  "POST /todos": { body: NewTodo; response: Todo };
  "PATCH /todos/:id": {
    params: { id: string };
    body: Partial<NewTodo>;
    response: Todo;
  };
  "DELETE /todos/:id": { params: { id: string }; response: null };
};

// ----- a client for ANY contract -----
interface Endpoint {
  params?: Record<string, string>;
  body?: object;
  response: unknown;
}

type Result<T, E> = { ok: true; value: T } | { ok: false; error: E };
type ApiError =
  | { kind: "network"; message: string }
  | { kind: "http"; status: number; message: string };

// How requests travel: fetch in the browser, supertest in tests
type Transport = (request: {
  method: string;
  path: string;
  body?: object;
}) => Promise<{ status: number; body: unknown }>;

function errorMessage(status: number, body: unknown): string {
  if (typeof body === "object" && body !== null && "error" in body &&
      typeof body.error === "string") {
    return body.error;
  }
  return `HTTP ${status}`;
}

function createClient<Api extends Record<keyof Api, Endpoint>>(
  transport: Transport,
) {
  return async function call<R extends keyof Api & string>(
    route: R,
    input: Omit<Api[R], "response">,
  ): Promise<Result<Api[R]["response"], ApiError>> {
    const { params = {}, body }: Omit<Endpoint, "response"> = input;
    const [method, pattern] = route.split(" ");
    const path = pattern.replace(/:(\w+)/g, (_, name: string) =>
      encodeURIComponent(params[name] ?? ""),
    );
    let res;
    try {
      res = await transport({ method, path, body });
    } catch (err) {
      const message = err instanceof Error ? err.message : String(err);
      return { ok: false, error: { kind: "network", message } };
    }
    const { status } = res;
    if (status >= 400) {
      const message = errorMessage(status, res.body);
      return { ok: false, error: { kind: "http", status, message } };
    }
    // We trust our own server here (see the callout below)
    const value = status === 204 ? null : res.body;
    return { ok: true, value: value as Api[R]["response"] };
  };
}

function fetchTransport(baseUrl: string): Transport {
  return async ({ method, path, body }) => {
    const res = await fetch(baseUrl + path, {
      method,
      headers: body ? { "Content-Type": "application/json" } : {},
      body: body ? JSON.stringify(body) : undefined,
    });
    const text = await res.text();
    return { status: res.status, body: text ? JSON.parse(text) : null };
  };
}

// ----- using it -----
const todos = createClient<TodosApi>(
  fetchTransport("https://api.pandadev.test"),
);

const created = await todos("POST /todos", { body: { title: "Nap" } });
if (created.ok) console.log(created.value); // Todo

const updated = await todos("PATCH /todos/:id", {
  params: { id: "4" },
  body: { done: true },
});
if (updated.ok) console.log(updated.value.done); // boolean

const all = await todos("GET /todos", {});
if (all.ok) console.log(all.value.map((t) => t.title));

const missing = await todos("DELETE /todos/:id", {
  params: { id: "99" },
});
if (!missing.ok) console.log(missing.error);
```

</CodeExample>

The interesting types, piece by piece:

- **`Api extends Record<keyof Api, Endpoint>`** says "every entry of this contract must look like an endpoint". A contract with `body: string` is rejected, because `Endpoint` says bodies are objects.
- **`call<R extends keyof Api & string>(route: R, ...)`** makes `R` the exact route you pass, like `"PATCH /todos/:id"`. (`& string` because object keys could also be numbers or symbols, and we call `route.split`.)
- **`input: Omit<Api[R], "response">`** is "everything the endpoint describes, except the response": `params` and `body`, exactly as the contract requires them.
- **`Promise<Result<Api[R]["response"], ApiError>>`** is the contract's response, wrapped in the `Result` from [Typed Fetch](/learn/typescript/typed-fetch), so callers must handle errors before they can touch the data.
- **`Transport`** is the only part that knows how requests travel. Here it's `fetch`; in tests it can be anything with the same signature.

And every way of calling it wrong is now a compile error:

```ts
await todos("GET /todo", {});
// ❌ Error: Argument of type '"GET /todo"' is not assignable to parameter of type '"GET /todos" | "POST /todos" | "PATCH /todos/:id" | "DELETE /todos/:id"'.

await todos("POST /todos", { body: { titel: "Nap" } });
// ❌ Error: Object literal may only specify known properties, but 'titel' does not exist in type 'NewTodo'. Did you mean to write 'title'?

await todos("PATCH /todos/:id", { body: { done: true } });
// ❌ Error: Property 'params' is missing in type '{ body: { done: true; }; }' but required in type 'Omit<{ params: { id: string; }; body: Partial<NewTodo>; response: Todo; }, "response">'.

const all = await todos("GET /todos", {});
if (all.ok) console.log(all.value[0].name);
// ❌ Error: Property 'name' does not exist on type 'Todo'.
```

<Callout type="warning" title="The one place where the client trusts the server">

Look at the end of `call`: `value as Api[R]["response"]`. The response is `unknown` (it came over the network), and the client simply **believes** the contract. That's a reasonable trade when you own both sides and deploy them together: one cast, in one tested function, instead of one in every call. For an API you don't control, validate responses with schemas, as in [Runtime Validation](/learn/typescript/runtime-validation). Some teams share the **schemas** instead of plain types, so the client can check everything it receives.

</Callout>

## Keeping the server in sync

The client now follows the contract. The server has to as well, or the contract is just a hopeful comment. The trick is to describe the server's handlers **with the contract too**: an object with one handler per route, where each handler must return that route's response type:

```ts
type Handlers<Api extends Record<keyof Api, Endpoint>> = {
  [R in keyof Api]: (req: RawRequest) => Promise<Api[R]["response"]>;
};
```

This is a **mapped type**: "for every route `R` in the contract, a function returning a promise of `R`'s response". `Partial` and `Record` are built the same way, and you'll write your own in Level 3. A small `mountApi` helper registers each handler with Express, using the method and path from the key:

<CodeExample output={`1 Nap
[ { id: 1, title: 'Nap' } ]`}>

```ts
import express, {
  type Application,
  type RequestHandler,
  type Router,
} from "express";
import request from "supertest";

// ----- contract.ts -----
interface Note {
  id: number;
  title: string;
}
type NotesApi = {
  "GET /notes": { response: Note[] };
  "POST /notes": { body: { title: string }; response: Note };
};

interface Endpoint {
  params?: Record<string, string>;
  body?: object;
  response: unknown;
}

// ----- server.ts: one handler per route in the contract -----
type RawRequest = { params: Record<string, string>; body: unknown };
type Handlers<Api extends Record<keyof Api, Endpoint>> = {
  [R in keyof Api]: (req: RawRequest) => Promise<Api[R]["response"]>;
};

function register(
  router: Router,
  method: string,
  path: string,
  handler: RequestHandler,
): void {
  if (method === "GET") router.get(path, handler);
  else if (method === "POST") router.post(path, handler);
  else if (method === "PATCH") router.patch(path, handler);
  else if (method === "DELETE") router.delete(path, handler);
  else throw new Error(`Unsupported method: ${method}`);
}

function mountApi<Api extends Record<keyof Api, Endpoint>>(
  router: Router,
  handlers: Handlers<Api>,
): void {
  for (const route of Object.keys(handlers) as (keyof Api & string)[]) {
    const [method, path] = route.split(" ");
    const handler = handlers[route];
    register(router, method, path, async (req, res) => {
      const { params, body } = req;
      const result = await handler({ params, body });
      res.status(method === "POST" ? 201 : 200).json(result);
    });
  }
}

function createApp(): Application {
  const notes: Note[] = [];
  const router = express.Router();
  mountApi<NotesApi>(router, {
    "GET /notes": async () => notes,
    "POST /notes": async ({ body }) => {
      // body is unknown: the contract can't promise what clients send
      const title =
        typeof body === "object" && body !== null && "title" in body &&
        typeof body.title === "string" ? body.title.trim() : "";
      const note: Note = { id: notes.length + 1, title };
      notes.push(note);
      return note; // must be a Note, says the contract
    },
  });
  const app = express();
  app.use(express.json());
  app.use("/api", router);
  return app;
}

// ----- client.ts: requests typed by the same contract -----
type Transport = (request: {
  method: string;
  path: string;
  body?: object;
}) => Promise<{ status: number; body: unknown }>;

function createClient<Api extends Record<keyof Api, Endpoint>>(
  transport: Transport,
) {
  return async function call<R extends keyof Api & string>(
    route: R,
    input: Omit<Api[R], "response">,
  ): Promise<Api[R]["response"]> {
    const { params = {}, body }: Omit<Endpoint, "response"> = input;
    const [method, pattern] = route.split(" ");
    const path = pattern.replace(/:(\w+)/g, (_, name: string) =>
      encodeURIComponent(params[name] ?? ""),
    );
    const res = await transport({ method, path, body });
    if (res.status >= 400) throw new Error(`HTTP ${res.status}`);
    return res.body as Api[R]["response"];
  };
}

// In tests: requests go straight to the Express app
function supertestTransport(app: Application, prefix = ""): Transport {
  const agent = request(app);
  return async ({ method, path, body }) => {
    const url = prefix + path;
    const test =
      method === "POST" ? agent.post(url)
      : method === "PATCH" ? agent.patch(url)
      : method === "DELETE" ? agent.delete(url)
      : agent.get(url);
    const res = await (body === undefined ? test : test.send(body));
    return { status: res.status, body: res.body };
  };
}

// ----- both sides, one contract -----
const api = createClient<NotesApi>(
  supertestTransport(createApp(), "/api"),
);
const note = await api("POST /notes", { body: { title: " Nap " } });
console.log(note.id, note.title); // note: Note
const all = await api("GET /notes", {});
console.log(all); // all: Note[]
```

</CodeExample>

To keep the focus on the server, the client here is a trimmed version of the previous one: it throws on errors instead of returning a `Result`. The important part is what the compiler now checks on the server side:

```ts
mountApi<NotesApi>(router, {
  "GET /notes": async () => notes,
});
// ❌ Error: Property '"POST /notes"' is missing in type '{ "GET /notes": () => Promise<Note[]>; }' but required in type 'Handlers<NotesApi>'.

mountApi<NotesApi>(router, {
  "GET /notes": async () => notes,
  "POST /notes": async () => ({ id: 1, name: "Nap" }),
  // ❌ Error: Type 'Promise<{ id: number; name: string; }>' is not assignable to type 'Promise<Note>'.
});
```

Add a route to the contract and the server won't compile until it handles it; change a response type and every handler that returns the old shape lights up. A handler that might return `undefined` (like a `find` that didn't find anything) is caught too, which nudges you to throw a 404 instead.

Notice what the handlers **don't** get: a typed body. `body` is `unknown`, even though the contract says the client sends a `NewNote`. That's deliberate. The contract binds **your** client, but anyone can call your API with `curl`, an old version of your app or a script. The server still parses every body, exactly as in the [last lesson](/learn/typescript/validation-and-errors).

<Callout type="tip" title="Conventions instead of configuration">

`mountApi` decides the status codes by convention: `POST` answers 201, a handler that returns `null` answers 204, and everything else 200. Conventions like this keep the contract small. When an API needs more (headers, several success codes, streaming), contracts grow a `status` field or move to one of the tools below.

</Callout>

## How real projects share a contract

What you built is the core idea behind several popular tools. Which one fits depends mostly on **who** writes the server and the clients.

**A shared package in a monorepo.** When the front end and the back end live in one repository, the contract becomes a small package that both import. This is exactly this lesson's approach, with the folders split up:

```text
notes-app/
├── package.json          "workspaces": ["packages/*"]
└── packages/
    ├── contract/         NotesApi, Note, NewNote (types only)
    ├── server/           Express + mountApi, imports @notes/contract
    └── web/              React app + createClient, imports @notes/contract
```

**tRPC.** If both sides are TypeScript, tRPC removes the separate contract: the server's router **is** the contract, and the client imports its type.

```ts
// server: procedures with input schemas
const t = initTRPC.create();
export const appRouter = t.router({
  noteById: t.procedure
    .input(z.object({ id: z.number() }))
    .query(({ input }) => notes.get(input.id)),
});
export type AppRouter = typeof appRouter;

// client: fully typed calls, no code generation
const trpc = createTRPCClient<AppRouter>({
  links: [httpBatchLink({ url: "/trpc" })],
});
const note = await trpc.noteById.query({ id: 1 });
```

**OpenAPI.** When clients are written in other languages, or the API is public, the contract is an **OpenAPI** document (YAML or JSON) that tools turn into types for every language. For TypeScript, `openapi-typescript` generates the types and `openapi-fetch` gives you a client that looks remarkably like yours:

```bash
npx openapi-typescript ./openapi.yaml -o src/api-types.ts
```

```ts
import createClient from "openapi-fetch";
import type { paths } from "./api-types";

const api = createClient<paths>({ baseUrl: "https://api.example.com" });
const { data, error } = await api.GET("/notes/{id}", {
  params: { path: { id: 1 } },
});
```

| Approach | Good fit when | Watch out for |
| --- | --- | --- |
| Shared contract types | one repo, TypeScript on both sides, plain REST | the server must still validate input |
| tRPC | one team, TypeScript everywhere, internal API | not a public REST API; clients must be TypeScript |
| OpenAPI + generators | public APIs, many languages, separate teams | keeping the spec and the code in sync (generate one from the other) |

Whichever you choose, run `tsc --noEmit` over the **whole** repository in CI, so a contract change that breaks the other side fails the build instead of reaching users.

<Exercise
  title="Mini-project: Typed notes API"
  language="typescript"
  starter={`import express, {
  type Application,
  type NextFunction,
  type Request,
  type RequestHandler,
  type Response,
  type Router,
} from "express";
import request from "supertest";
import { describe, it, expect, beforeEach } from "vitest";

// ========== contract.ts: shared by server and client ==========

interface Note {
  id: number;
  title: string;
  text: string;
  pinned: boolean;
}
interface NewNote {
  title: string;
  text?: string;
  pinned?: boolean;
}
type NotePatch = Partial<NewNote>;

type ErrorCode = "bad_request" | "not_found" | "internal";
const STATUS: Record<ErrorCode, number> = {
  bad_request: 400,
  not_found: 404,
  internal: 500,
};
interface ErrorBody {
  error: string;
  code: ErrorCode;
  details?: string[];
}

type NotesApi = {
  "GET /notes": { response: Note[] };
  "POST /notes": { body: NewNote; response: Note };
  "GET /notes/:id": { params: { id: string }; response: Note };
  "PATCH /notes/:id": {
    params: { id: string };
    body: NotePatch;
    response: Note;
  };
  "DELETE /notes/:id": { params: { id: string }; response: null };
};

// ========== ready-made helpers: don't change this part ==========

interface Endpoint {
  params?: Record<string, string>;
  body?: object;
  response: unknown;
}
type Result<T, E> = { ok: true; value: T } | { ok: false; error: E };

function isRecord(value: unknown): value is Record<string, unknown> {
  return (
    typeof value === "object" && value !== null && !Array.isArray(value)
  );
}

// Express's own errors (e.g. broken JSON) carry a 4xx status
type ClientError = Error & { status: number };
function isClientError(err: unknown): err is ClientError {
  return err instanceof Error && "status" in err &&
    typeof err.status === "number" && err.status < 500;
}

class HttpError extends Error {
  readonly status: number;
  readonly code: ErrorCode;
  readonly details?: string[];
  constructor(code: ErrorCode, message: string, details?: string[]) {
    super(message);
    this.name = "HttpError";
    this.code = code;
    this.status = STATUS[code];
    this.details = details;
  }
}

function parseOrThrow<T>(
  parse: (input: unknown) => Result<T, string[]>,
  input: unknown,
): T {
  const result = parse(input);
  if (!result.ok) {
    throw new HttpError("bad_request", "Invalid body", result.error);
  }
  return result.value;
}

// Returns the trimmed title, or adds a message to errors
function checkTitle(
  value: unknown,
  errors: string[],
): string | undefined {
  if (typeof value !== "string" || value.trim() === "") {
    errors.push("title is required");
  } else if (value.length > 100) {
    errors.push("title must be at most 100 characters");
  } else {
    return value.trim();
  }
  return undefined;
}

function parseNewNote(input: unknown): Result<NewNote, string[]> {
  if (!isRecord(input)) {
    return { ok: false, error: ["body must be a JSON object"] };
  }
  const errors: string[] = [];
  const title = checkTitle(input.title, errors);
  if (input.text !== undefined && typeof input.text !== "string") {
    errors.push("text must be a string");
  }
  if (input.pinned !== undefined && typeof input.pinned !== "boolean") {
    errors.push("pinned must be true or false");
  }
  if (title === undefined || errors.length > 0) {
    return { ok: false, error: errors };
  }
  const note: NewNote = { title };
  if (typeof input.text === "string") note.text = input.text;
  if (typeof input.pinned === "boolean") note.pinned = input.pinned;
  return { ok: true, value: note };
}

function createNotesRepository() {
  const notes = new Map<number, Note>();
  let nextId = 1;
  return {
    list(): Note[] {
      return [...notes.values()];
    },
    get(id: number): Note | undefined {
      return notes.get(id);
    },
    create(input: NewNote): Note {
      const note: Note = {
        id: nextId++,
        title: input.title,
        text: input.text ?? "",
        pinned: input.pinned ?? false,
      };
      notes.set(note.id, note);
      return note;
    },
    update(id: number, changes: NotePatch): Note | undefined {
      const note = notes.get(id);
      if (!note) return undefined;
      const updated = { ...note, ...changes };
      notes.set(id, updated);
      return updated;
    },
    remove(id: number): boolean {
      return notes.delete(id);
    },
  };
}

// The server side of the contract: one handler per route
type RawRequest = { params: Record<string, string>; body: unknown };
type Handlers<Api extends Record<keyof Api, Endpoint>> = {
  [R in keyof Api]: (req: RawRequest) => Promise<Api[R]["response"]>;
};

function register(
  router: Router,
  method: string,
  path: string,
  handler: RequestHandler,
): void {
  if (method === "GET") router.get(path, handler);
  else if (method === "POST") router.post(path, handler);
  else if (method === "PATCH") router.patch(path, handler);
  else if (method === "DELETE") router.delete(path, handler);
  else throw new Error(\`Unsupported method: \${method}\`);
}

// POST answers 201, a null result 204, everything else 200
function mountApi<Api extends Record<keyof Api, Endpoint>>(
  router: Router,
  handlers: Handlers<Api>,
): void {
  for (const route of Object.keys(handlers) as (keyof Api & string)[]) {
    const [method, path] = route.split(" ");
    const handler = handlers[route];
    register(router, method, path, async (req, res) => {
      const { params, body } = req;
      const result = await handler({ params, body });
      if (result === null) {
        res.sendStatus(204);
        return;
      }
      res.status(method === "POST" ? 201 : 200).json(result);
    });
  }
}

function errorHandler(
  err: unknown,
  req: Request,

  path: string;
  body?: object;

function createClient<Api extends Record<keyof Api, Endpoint>>(
  transport: Transport,
) {
  return async function call<R extends keyof Api & string>(
    route: R,
    input: Omit<Api[R], "response">,
  ): Promise<Result<Api[R]["response"], ApiError>> {
    const { params = {}, body }: Omit<Endpoint, "response"> = input;
    const [method, pattern] = route.split(" ");
    const path = pattern.replace(/:(\\w+)/g, (_, name: string) =>
      encodeURIComponent(params[name] ?? ""),
    );
    let res;
    try {
      res = await transport({ method, path, body });
    } catch (err) {
      const message = err instanceof Error ? err.message : String(err);
      return { ok: false, error: { kind: "network", message } };
    }
    const { status } = res;
    if (status >= 400) {
      const message =
        isRecord(res.body) && typeof res.body.error === "string"
          ? res.body.error
          : \`HTTP \${status}\`;
      return { ok: false, error: { kind: "http", status, message } };
    }
    const value = status === 204 ? null : res.body;
    return { ok: true, value: value as Api[R]["response"] };
  };
}

function parseNewNote(input: unknown): Result<NewNote, string[]> {
  if (!isRecord(input)) {
    return { ok: false, error: ["body must be a JSON object"] };
  }
  const errors: string[] = [];
  const title = checkTitle(input.title, errors);
  if (input.text !== undefined && typeof input.text !== "string") {

    errors.push("pinned must be true or false");

function createNotesRepository() {

  let nextId = 1;
  return {
    list(): Note[] {
      return [...notes.values()];

      return notes.get(id);

      const note: Note = {

type RawRequest = { params: Record<string, string>; body: unknown };
type Handlers<Api extends Record<keyof Api, Endpoint>> = {
  [R in keyof Api]: (req: RawRequest) => Promise<Api[R]["response"]>;
};

function register(
  router: Router,
  method: string,
  path: string,
  handler: RequestHandler,
): void {
  if (method === "GET") router.get(path, handler);
  else if (method === "POST") router.post(path, handler);
  else if (method === "PATCH") router.patch(path, handler);
  else if (method === "DELETE") router.delete(path, handler);
  else throw new Error(`Unsupported method: ${method}`);
}

// POST answers 201, a null result 204, everything else 200
function mountApi<Api extends Record<keyof Api, Endpoint>>(
  router: Router,
  handlers: Handlers<Api>,
): void {
  for (const route of Object.keys(handlers) as (keyof Api & string)[]) {
    const [method, path] = route.split(" ");
    const handler = handlers[route];
    register(router, method, path, async (req, res) => {
      const { params, body } = req;
      const result = await handler({ params, body });
      if (result === null) {
        res.sendStatus(204);
        return;
      }
      res.status(method === "POST" ? 201 : 200).json(result);
    });
  }
}

## Recap

- Describe the API **once** as a contract type: keys like `"POST /notes"`, each with `params`, `body` and `response`. Share it between server and client with `import type`.
- `keyof` and indexed access types (`NotesApi["POST /notes"]["body"]`) pull out any piece of the contract.
- A **generic client** `createClient<Api>(transport)` derives each call's input (`Omit<Api[R], "response">`) and output (`Api[R]["response"]`) from the contract; wrong routes, params and bodies don't compile.
- Put how requests travel behind a **`Transport`**: `fetch` in the app, supertest in tests.
- Type the server's handlers with a **mapped type** over the contract, so a missing route or a wrong response shape is a compile error. Bodies stay `unknown` on the server and are still **parsed**.
- The client's response cast is a deliberate trust in your own server; validate responses from APIs you don't control.
- Real projects do the same with shared packages in a **monorepo**, **tRPC** (the router is the contract) or **OpenAPI** with code generators, plus `tsc --noEmit` over everything in CI.
