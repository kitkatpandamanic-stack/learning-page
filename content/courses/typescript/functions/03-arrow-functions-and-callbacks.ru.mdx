В JavaScript функции — это значения: их можно хранить в переменных и передавать в другие функции. TypeScript позволяет описать и **тип функции**, чтобы проверять, что передаётся функция нужного вида. Давайте посмотрим, как это работает, а потом соберём типизированный калькулятор. 🧮

## Типизированные стрелочные функции

**Стрелочные функции** (arrow functions) принимают типы ровно там же, где и обычные функции: после каждого параметра и после скобок — для возвращаемого типа:

<CodeExample output={`7
Привет, Маша!`}>

```ts
const add = (a: number, b: number): number => a + b;

const greet = (name: string) => `Привет, ${name}!`;

console.log(add(3, 4));
console.log(greet("Маша"));
```

</CodeExample>

У `greet` возвращаемый тип не указан, поэтому TypeScript выводит `string` из шаблонной строки.

## Функциональные типы

А какой тип у самой `add`? Он записывается как стрелочная функция, только после стрелки стоит **тип**, а не код:

```ts
(a: number, b: number) => number
```

Читайте это так: «функция, которая принимает два числа и возвращает число». Этим типом можно аннотировать переменную, и тогда в ней можно хранить только функции такого вида:

<CodeExample output={`8
2`}>

```ts
let operation: (a: number, b: number) => number;

operation = (a, b) => a + b;
console.log(operation(5, 3));

operation = (a, b) => a - b;
console.log(operation(5, 3));
```

</CodeExample>

<Callout type="note" title="Имена — просто подписи">

В функциональном типе имена параметров (`a` и `b`) нужны только для читаемости. Функция с параметрами `x` и `y` подходит под этот тип точно так же. Важны **типы** и их **порядок**.

</Callout>

## Даём функциональным типам имена через `type`

Писать полный функциональный тип снова и снова утомительно. Дайте ему имя с помощью **псевдонима типа** (type alias):

<CodeExample output={`12
4`}>

```ts
type MathFn = (a: number, b: number) => number;

const multiply: MathFn = (a, b) => a * b;
const divide: MathFn = (a, b) => a / b;

console.log(multiply(3, 4));
console.log(divide(12, 3));
```

</CodeExample>

Если функция не подходит под псевдоним, вы узнаете об этом сразу:

```ts
const shout: MathFn = (a: string) => a;
// ❌ Error: Type '(a: string) => string' is not assignable to type 'MathFn'.
```

## Контекстная типизация

Заметили, что у `multiply` и `divide` выше **нет** типов параметров — и при этом нет ошибки «implicit any»? Это **контекстная типизация** (contextual typing): TypeScript уже знает, что функция должна быть `MathFn`, поэтому сам присваивает `a` и `b` тип `number`.

То же самое происходит с методами массивов. `map` знает, что проходит по числам, поэтому `n` имеет тип `number` без всякой аннотации:

<CodeExample output={`[ 2, 4, 6 ]
[ 'МАША', 'САША' ]`}>

```ts
const nums = [1, 2, 3];
const doubled = nums.map((n) => n * 2); // n: number

const names = ["маша", "саша"];
const loud = names.map((name) => name.toUpperCase()); // name: string

console.log(doubled);
console.log(loud);
```

</CodeExample>

## Колбэки

**Колбэк** (callback, функция обратного вызова) — это функция, которую передают в другую функцию, чтобы та вызвала её позже. Чтобы принять колбэк, дайте параметру функциональный тип:

<CodeExample output={`Раунд 1
Раунд 2
Раунд 3`}>

```ts
function repeat(times: number, action: (round: number) => void) {
  for (let i = 1; i <= times; i++) {
    action(i);
  }
}

repeat(3, (round) => {
  console.log(`Раунд ${round}`);
});
```

</CodeExample>

Благодаря контекстной типизации `round` внутри стрелочной функции имеет тип `number`, а TypeScript проверяет, что переданный колбэк действительно принимает число.

<Callout type="tip">

Возвращаемый тип `void` у колбэка означает: «то, что ты вернёшь, я использовать не буду». Поэтому `(round: number) => void` спокойно принимает колбэк, который просто что-то выводит.

</Callout>

Соберите маленький калькулятор, в котором каждая операция — типизированная функция:

1. Напишите `multiply` и `divide` как стрелочные функции типа `MathFn`.
2. Допишите `calculate(a, b, op)`: с помощью `switch` по `op` вызовите подходящую функцию и верните результат.
3. Допишите `calculateAll(a, b, ops)`: верните массив с результатами всех операций из `ops` по порядку. Например, `calculateAll(10, 2, ["add", "divide"])` возвращает `[12, 5]`.

<Hint>

В `const multiply: MathFn = (a, b) => a * b;` типы параметров не нужны — спасибо контекстной типизации. В `calculate` напишите по одному `case` на операцию, в каждом — `return`. Для `calculateAll` всю работу делает `ops.map((op) => calculate(a, b, op))`.

</Hint>

<Solution>

```ts
type Operation = "add" | "subtract" | "multiply" | "divide";
type MathFn = (a: number, b: number) => number;

const add: MathFn = (a, b) => a + b;
const subtract: MathFn = (a, b) => a - b;
const multiply: MathFn = (a, b) => a * b;
const divide: MathFn = (a, b) => a / b;

function calculate(a: number, b: number, op: Operation): number {
  switch (op) {
    case "add":
      return add(a, b);
    case "subtract":
      return subtract(a, b);
    case "multiply":
      return multiply(a, b);
    case "divide":
      return divide(a, b);
  }
}

function calculateAll(
  a: number,
  b: number,
  ops: Operation[],
): number[] {
  return ops.map((op) => calculate(a, b, op));
}

console.log(calculate(6, 3, "add")); // 9
console.log(calculate(6, 3, "divide")); // 2
console.log(calculateAll(10, 2, ["add", "subtract", "multiply"]));
// [ 12, 8, 20 ]
```

</Solution>

</Exercise>

## Итоги

- Стрелочные функции принимают типы в тех же местах: `(a: number, b: number): number => a + b`.
- Функциональный тип выглядит так: `(a: number, b: number) => number`; дайте ему имя через `type MathFn = ...`.
- **Контекстная типизация** подставляет типы параметров, когда TypeScript уже знает тип функции, — например, в `map` или при присваивании в `MathFn`.
- **Колбэк** — это функция, переданная в другую функцию. Типизируйте параметр функциональным типом, например `(round: number) => void`.
