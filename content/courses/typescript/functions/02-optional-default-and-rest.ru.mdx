В TypeScript каждый вызов должен точно соответствовать параметрам функции: ни одного пропущенного **аргумента** (argument), ни одного лишнего. Это строго, но настоящим функциям часто нужна гибкость. В этом уроке вы узнаете четыре способа её получить — и все они полностью проверяются по типам.

## Необязательные параметры с `?`

Без дополнительных усилий пропущенный аргумент — это ошибка:

```ts
function greet(name: string, title: string) {}

greet("Маша");
// ❌ Error: Expected 2 arguments, but got 1.
```

Поставьте **`?`** после имени параметра, чтобы сделать его **необязательным** (optional). Внутри функции его тип становится `string | undefined`, поэтому перед использованием его нужно проверить:

<CodeExample output={`Здравствуйте, Маша!
Здравствуйте, доктор Петров!`}>

```ts
function greet(name: string, title?: string): string {
  if (title === undefined) {
    return `Здравствуйте, ${name}!`;
  }
  return `Здравствуйте, ${title} ${name}!`;
}

console.log(greet("Маша"));
console.log(greet("Петров", "доктор"));
```

</CodeExample>

Забудете проверку — TypeScript напомнит:

```ts
function shout(title?: string) {
  return title.toUpperCase();
  // ❌ Error: 'title' is possibly 'undefined'.
}
```

## Значения по умолчанию

Часто `undefined` вам вообще не нужен — нужно разумное запасное значение. Задайте параметру **значение по умолчанию** (default value) с помощью `=`. TypeScript выведет тип параметра из этого значения, а для вызывающего кода параметр станет необязательным:

<CodeExample output={`120
110`}>

```ts
function priceWithTax(amount: number, taxRate = 0.2): number {
  return amount + amount * taxRate;
}

console.log(priceWithTax(100)); // используется значение по умолчанию 0.2
console.log(priceWithTax(100, 0.1));
```

</CodeExample>

Здесь у `taxRate` тип `number` (выведен из `0.2`), а внутри функции он никогда не бывает `undefined`, так что проверка не нужна.

<Callout type="warning" title="Обязательные параметры идут первыми">

Необязательные параметры должны стоять **после** обязательных. Иначе TypeScript не поймёт, какой аргумент к чему относится:

```ts
function label(title?: string, name: string) {}
// ❌ Error: A required parameter cannot follow an optional parameter.
```

</Callout>

## Rest-параметры: любое число аргументов

Напишите **`...`** перед последним параметром, чтобы собрать все оставшиеся аргументы в **массив**. Такой параметр называется **rest-параметром** (rest parameter), и его тип — тип массива, например `number[]`:

<CodeExample output={`10
0
60`}>

```ts
function sum(...nums: number[]): number {
  let total = 0;
  for (const n of nums) {
    total += n;
  }
  return total;
}

console.log(sum(1, 2, 3, 4));
console.log(sum()); // без аргументов: nums равен []
const prices = [10, 20, 30];
console.log(sum(...prices)); // разворачиваем массив в аргументы
```

</CodeExample>

Обычные параметры и rest-параметр можно смешивать, если rest-параметр стоит последним: `function tag(label: string, ...words: string[])`.

## Параметры-объединения: больше одного типа

Иногда параметр может быть одного типа **или** другого. Используйте **объединение типов** (union type) с `|`, а затем сузьте его через `typeof` — так же, как вы делали с переменными:

<CodeExample output={`ID-0042
ID-ABC`}>

```ts
function formatId(id: number | string): string {
  if (typeof id === "number") {
    return "ID-" + String(id).padStart(4, "0");
  }
  return "ID-" + id.toUpperCase();
}

console.log(formatId(42));
console.log(formatId("abc"));
```

</CodeExample>

Внутри `if` TypeScript знает, что `id` — это `number`. После него `id` может быть только `string`, поэтому `toUpperCase()` разрешён.

<Callout type="tip">

Спросите себя, какой инструмент подходит: «может отсутствовать» → `?`. «Есть привычное значение» → значение по умолчанию. «Сколько угодно штук» → `...rest`. «Один из нескольких типов» → объединение.

</Callout>

Допишите две функции для кассы кафе:

1. `orderLine(item, quantity = 1, note?)` возвращает строку вроде `"2 x Чай"`. Если есть `note` (примечание), добавьте его в скобках: `"2 x Чай (без сахара)"`.
2. `orderTotal(...prices)` возвращает сумму всех переданных цен (и `0`, если цен нет).

<Hint>

В `orderLine` сначала соберите `quantity + " x " + item`, а затем добавляйте `" (" + note + ")"`, только если `note !== undefined`. В `orderTotal` заведите `total` со значением `0` и прибавляйте каждую цену в цикле `for...of`.

</Hint>

<Solution>

```ts
function orderLine(item: string, quantity = 1, note?: string): string {
  const line = quantity + " x " + item;
  if (note === undefined) {
    return line;
  }
  return line + " (" + note + ")";
}

function orderTotal(...prices: number[]): number {
  let total = 0;
  for (const price of prices) {
    total += price;
  }
  return total;
}

console.log(orderLine("Чай")); // 1 x Чай
console.log(orderLine("Торт", 2, "тёплый")); // 2 x Торт (тёплый)
console.log(orderTotal(2.5, 3, 4.5)); // 10
```

</Solution>

## Итоги

- `param?: Type` делает параметр необязательным; внутри функции он имеет тип `Type | undefined`, поэтому сначала проверьте его.
- `param = value` задаёт значение по умолчанию и выводит тип из этого значения.
- Необязательные параметры и параметры со значением по умолчанию идут после обязательных.
- `...rest: Type[]` собирает любое число аргументов в массив.
- `a: number | string` принимает любой из двух типов; перед использованием сузьте его через `typeof`.
