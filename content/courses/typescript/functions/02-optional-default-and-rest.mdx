In TypeScript, every call must match the function's parameters exactly: no missing arguments, no extra ones. That's strict, but real functions often need flexibility. In this lesson you'll learn four ways to get it, all fully type-checked.

## Optional parameters with `?`

Without help, leaving out an argument is an error:

```ts
function greet(name: string, title: string) {}

greet("Mei");
// ❌ Error: Expected 2 arguments, but got 1.
```

Put a **`?`** after a parameter name to make it **optional**. Inside the function, its type becomes `string | undefined`, so you have to check it before using it:

<CodeExample output={`Hello, Mei!
Hello, Dr Sam!`}>

```ts
function greet(name: string, title?: string): string {
  if (title === undefined) {
    return `Hello, ${name}!`;
  }
  return `Hello, ${title} ${name}!`;
}

console.log(greet("Mei"));
console.log(greet("Sam", "Dr"));
```

</CodeExample>

Forget the check and TypeScript reminds you:

```ts
function shout(title?: string) {
  return title.toUpperCase();
  // ❌ Error: 'title' is possibly 'undefined'.
}
```

## Default values

Often you don't want `undefined` at all, you want a sensible fallback. Give the parameter a **default value** with `=`. TypeScript infers its type from the default, and the parameter becomes optional for callers:

<CodeExample output={`120
110`}>

```ts
function priceWithTax(amount: number, taxRate = 0.2): number {
  return amount + amount * taxRate;
}

console.log(priceWithTax(100)); // uses the default 0.2
console.log(priceWithTax(100, 0.1));
```

</CodeExample>

Here `taxRate` has the type `number` (inferred from `0.2`), and inside the function it's never `undefined`, so no check is needed.

<Callout type="warning" title="Required parameters come first">

Optional parameters must come **after** the required ones. Otherwise TypeScript can't tell which argument is which:

```ts
function label(title?: string, name: string) {}
// ❌ Error: A required parameter cannot follow an optional parameter.
```

</Callout>

## Rest parameters: any number of arguments

Write **`...`** before the last parameter to collect all remaining arguments into an **array**. Its type is an array type such as `number[]`:

<CodeExample output={`10
0
60`}>

```ts
function sum(...nums: number[]): number {
  let total = 0;
  for (const n of nums) {
    total += n;
  }
  return total;
}

console.log(sum(1, 2, 3, 4));
console.log(sum()); // no arguments: nums is []
const prices = [10, 20, 30];
console.log(sum(...prices)); // spread an array in
```

</CodeExample>

You can mix normal and rest parameters, as long as the rest parameter is last: `function tag(label: string, ...words: string[])`.

## Union parameters: more than one type

Sometimes a parameter can be one type **or** another. Use a **union** with `|`, then narrow it with `typeof`, just like you did with variables:

<CodeExample output={`ID-0042
ID-ABC`}>

```ts
function formatId(id: number | string): string {
  if (typeof id === "number") {
    return "ID-" + String(id).padStart(4, "0");
  }
  return "ID-" + id.toUpperCase();
}

console.log(formatId(42));
console.log(formatId("abc"));
```

</CodeExample>

Inside the `if`, TypeScript knows `id` is a `number`. After it, `id` can only be a `string`, so `toUpperCase()` is allowed.

<Callout type="tip">

Ask yourself which tool fits: "might be missing" → `?`. "Has a usual value" → a default. "Any number of them" → `...rest`. "One of a few types" → a union.

</Callout>

<Hint>

In `orderLine`, build `quantity + " x " + item` first, then only add `" (" + note + ")"` when `note !== undefined`. In `orderTotal`, start a `total` at `0` and add each price with `for...of`.

<Solution>

```ts
function orderLine(item: string, quantity = 1, note?: string): string {
  const line = quantity + " x " + item;
  if (note === undefined) {
    return line;
  }
  return line + " (" + note + ")";
}

function orderTotal(...prices: number[]): number {
  let total = 0;
  for (const price of prices) {
    total += price;
  }
  return total;
}

console.log(orderLine("Tea")); // 1 x Tea
console.log(orderLine("Cake", 2, "warm")); // 2 x Cake (warm)
console.log(orderTotal(2.5, 3, 4.5)); // 10
```

</Solution>

## Recap

- `param?: Type` makes a parameter optional; inside, it's `Type | undefined`, so check it first.
- `param = value` gives a default and infers the type from the value.
- Optional and default parameters must come after required ones.
- `...rest: Type[]` collects any number of arguments into an array.
- `a: number | string` accepts either type; narrow it with `typeof` before using it.
