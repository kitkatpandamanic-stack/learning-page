In Part 1 you wrote the **pure** logic: schedules, `isDue` and streaks. Pure functions don't remember anything, though. An app needs a place to **keep** its habits and check-ins, **rules** for changing them, and a way to **save** them so they survive a reload. That's this part. 💾

You'll reuse a lot from Level 1: the generic `Store<T>` and `Result` from [Generics](/learn/typescript/utility-types), `private` and `readonly` from [Classes](/learn/typescript/classes-and-access-modifiers), `Omit` and `Pick`, and [type guards](/learn/typescript/type-guards-and-unknown) to check saved JSON. By the end you'll have a `HabitTracker` class that the page in Part 3 can simply call: `tracker.checkIn(id, today)`.

## The store, rebuilt

The Generics module ended with a mini-project: `Store<T>`, a generic in-memory store for anything with a string `id`, with typed errors and events for subscribers. It's exactly what we need, twice: a `Store<Habit>` and a `Store<CheckIn>`.

We'll rebuild it with three changes, because real code follows the app it's written for:

- **No `update`.** This app never edits a habit or a check-in: it adds and removes them. Code you don't need is code you have to read, test and keep working, so it goes. (You can add it back if you build renaming; see Part 3's ideas.)
- **New: `has(id)`**, a quick yes-or-no for "is this one stored?".
- **New: `removeWhere(predicate)`**, which removes every matching item. When you delete a habit, all its check-ins must go too.

There are also two tiny generic helpers, `ok` and `err`, that build each side of a `Result`. `return ok(item)` reads better than `return { ok: true, value: item }`, and TypeScript infers the types from the argument.

Here's the store, used for check-ins:

<CodeExample output={`added: h1@2026-03-16
added: h2@2026-03-16
added: h1@2026-03-17
{ ok: false, error: { type: 'duplicate-id', id: 'h1@2026-03-17' } }
removed: h1@2026-03-16
removed: h1@2026-03-17
Removed 2, left: 1`}>

```ts
type Result<T, E> =
  | { ok: true; value: T }
  | { ok: false; error: E };

function ok<T>(value: T): { ok: true; value: T } {
  return { ok: true, value };
}

function err<E>(error: E): { ok: false; error: E } {
  return { ok: false, error };
}

type StoreError =
  | { type: "duplicate-id"; id: string }
  | { type: "not-found"; id: string };

type StoreEvent<T> =
  | { type: "added"; item: T }
  | { type: "removed"; item: T };

type Listener<T> = (event: StoreEvent<T>) => void;

class Store<T extends { id: string }> {
  private items = new Map<string, T>();
  private listeners: Listener<T>[] = [];

  add(item: T): Result<T, StoreError> {
    if (this.items.has(item.id)) {
      return err({ type: "duplicate-id", id: item.id });
    }
    this.items.set(item.id, item);
    this.emit({ type: "added", item });
    return ok(item);
  }

  get(id: string): T | undefined {
    return this.items.get(id);
  }

  has(id: string): boolean {
    return this.items.has(id);
  }

  remove(id: string): Result<T, StoreError> {
    const item = this.items.get(id);
    if (item === undefined) {
      return err({ type: "not-found", id });
    }
    this.items.delete(id);
    this.emit({ type: "removed", item });
    return ok(item);
  }

  // Remove every matching item; returns what was removed
  removeWhere(predicate: (item: T) => boolean): T[] {
    const doomed = this.find(predicate);
    for (const item of doomed) {
      this.remove(item.id);
    }
    return doomed;
  }

  find(predicate: (item: T) => boolean): T[] {
    return this.list().filter(predicate);
  }

  list(): readonly T[] {
    return [...this.items.values()];
  }

  subscribe(listener: Listener<T>): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private emit(event: StoreEvent<T>): void {
    for (const listener of this.listeners) {
      listener(event);
    }
  }
}

// ===== Try it with check-ins =====
interface CheckIn {
  readonly id: string;
  readonly habitId: string;
  readonly date: string;
}

function makeCheckIn(habitId: string, date: string): CheckIn {
  return { id: `${habitId}@${date}`, habitId, date };
}

const checkIns = new Store<CheckIn>();
checkIns.subscribe((e) => console.log(`${e.type}: ${e.item.id}`));

checkIns.add(makeCheckIn("h1", "2026-03-16"));
checkIns.add(makeCheckIn("h2", "2026-03-16"));
checkIns.add(makeCheckIn("h1", "2026-03-17"));

// The same habit on the same day has the same id
const again = checkIns.add(makeCheckIn("h1", "2026-03-17"));
console.log(again);

const gone = checkIns.removeWhere((c) => c.habitId === "h1");
console.log(`Removed ${gone.length}, left: ${checkIns.list().length}`);
```

</CodeExample>

Look at the fourth line of output. In Part 1 we built each check-in's id from the habit and the day, so a second check-in for `h1` on the 17th has the **same id**, and the store refuses it. The rule "once per habit per day" needs no code of its own: it falls out of the data design.

`removeWhere` is built from methods the store already has (`find`, then `remove` for each item), so every removed item still sends its `"removed"` event.

## Errors that speak the tracker's language

The tracker's methods can fail in a few normal ways: an empty name, a habit that doesn't exist, a check-in on a day off, a second check-in on the same day, an undo of something that wasn't done. That's a job for a discriminated union of errors, returned in a `Result`, so no caller can forget them:

```ts
type TrackerError =
  | { type: "invalid-habit"; reason: string }
  | { type: "unknown-habit"; habitId: string }
  | { type: "not-due"; habitId: string; date: IsoDate }
  | { type: "already-done"; habitId: string; date: IsoDate }
  | { type: "not-done"; habitId: string; date: IsoDate };
```

Why not just pass on the store's errors? Because `"duplicate-id"` is a detail of **how** the tracker stores check-ins. The page shouldn't need to know that a check-in is an item in a `Store` with a made-up id; it wants to hear "already done on 2026-03-17". So the tracker **translates** store errors into its own. TypeScript makes sure you do: returning the store's `Result` directly doesn't compile, because a `StoreError` isn't a `TrackerError`:

```ts
checkIn(habitId: string, date: IsoDate): Result<CheckIn, TrackerError> {
  const id = checkInId(habitId, date);
  return this.checkInStore.add({ id, habitId, date });
  // ❌ Error: Type 'Result<CheckIn, StoreError>' is not assignable to type 'Result<CheckIn, TrackerError>'.
}
```

A new habit doesn't have an id yet: the tracker chooses it. That's `Omit` from [Utility Types](/learn/typescript/utility-types), and it stays in sync with `Habit` if you ever add a property:

```ts
type NewHabit = Omit<Habit, "id">;

tracker.addHabit({ id: "h9", name: "Read", schedule: { kind: "daily" } });
// ❌ Error: Object literal may only specify known properties, and 'id' does not exist in type 'NewHabit'.
```

The types guarantee the **shape** of a new habit, but not that it makes sense. An empty name or a weekly habit with no days are perfectly good shapes. Those rules need a runtime check, like `isValidQuestion` in the Level 0 quiz game. `habitProblem` returns what's wrong, or `null`, and `errorMessage` turns any error into a sentence for the page:

<CodeExample output={`✅ fine
Give the habit a name
Pick at least one day
Times a week must be from 1 to 7
That habit isn't due on 2026-03-17`}>

```ts
type IsoDate = string;
type Weekday = "mon" | "tue" | "wed" | "thu" | "fri" | "sat" | "sun";
type Schedule =
  | { kind: "daily" }
  | { kind: "weekly"; days: Weekday[] }
  | { kind: "timesPerWeek"; times: number };
interface Habit {
  readonly id: string;
  name: string;
  schedule: Schedule;
}
function assertNever(value: never): never {
  throw new Error(`Unexpected value: ${JSON.stringify(value)}`);
}

// ===== New in Part 2 =====
type NewHabit = Omit<Habit, "id">;

type TrackerError =
  | { type: "invalid-habit"; reason: string }
  | { type: "unknown-habit"; habitId: string }
  | { type: "not-due"; habitId: string; date: IsoDate }
  | { type: "already-done"; habitId: string; date: IsoDate }
  | { type: "not-done"; habitId: string; date: IsoDate };

function errorMessage(error: TrackerError): string {
  switch (error.type) {
    case "invalid-habit":
      return error.reason;
    case "unknown-habit":
      return `There's no habit with id ${error.habitId}`;
    case "not-due":
      return `That habit isn't due on ${error.date}`;
    case "already-done":
      return `Already done on ${error.date}`;
    case "not-done":
      return `Not done on ${error.date}, so there's nothing to undo`;
    default:
      return assertNever(error);
  }
}

// What's wrong with a new habit, or null if nothing is
function habitProblem(input: NewHabit): string | null {
  const name = input.name.trim();
  if (name === "") return "Give the habit a name";
  if (name.length > 40) return "Keep the name to 40 characters";
  const schedule = input.schedule;
  switch (schedule.kind) {
    case "daily":
      return null;
    case "weekly":
      return schedule.days.length > 0 ? null : "Pick at least one day";
    case "timesPerWeek": {
      const { times } = schedule;
      const valid = Number.isInteger(times) && times >= 1 && times <= 7;
      return valid ? null : "Times a week must be from 1 to 7";
    }
    default:
      return assertNever(schedule);
  }
}

const inputs: NewHabit[] = [
  { name: "Read 10 pages", schedule: { kind: "daily" } },
  { name: "   ", schedule: { kind: "daily" } },
  { name: "Swim", schedule: { kind: "weekly", days: [] } },
  { name: "Yoga", schedule: { kind: "timesPerWeek", times: 9 } },
];
for (const input of inputs) {
  console.log(habitProblem(input) ?? "✅ fine");
}

const notDue: TrackerError = {
  type: "not-due",
  habitId: "h2",
  date: "2026-03-17",
};
console.log(errorMessage(notDue));
```

</CodeExample>

Both `switch`es end in `assertNever`, so a new kind of schedule or a new kind of error can't be forgotten. In the `"timesPerWeek"` case, the braces `{ ... }` give the case its own block, so it can declare a `const`.

## The HabitTracker class

Now the class that ties it all together. Its two stores are **`private`**: the page can only change habits and check-ins through the tracker's methods, so it can't skip the rules (no check-ins on a day off, no check-ins for a deleted habit). Here's the heart of it:

```ts
class HabitTracker {
  private readonly habitStore = new Store<Habit>();
  private readonly checkInStore = new Store<CheckIn>();
  private nextNumber = 1;

  addHabit(input: NewHabit): Result<Habit, TrackerError> {
    const problem = habitProblem(input);
    if (problem !== null) {
      return err({ type: "invalid-habit", reason: problem });
    }
    const habit: Habit = {
      id: this.newId(),
      name: input.name.trim(),
      schedule: input.schedule,
    };
    this.habitStore.add(habit);
    return ok(habit);
  }

  checkIn(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const habit = this.habitStore.get(habitId);
    if (habit === undefined) {
      return err({ type: "unknown-habit", habitId });
    }
    if (!isDue(habit, date)) {
      return err({ type: "not-due", habitId, date });
    }
    const id = checkInId(habitId, date);
    const added = this.checkInStore.add({ id, habitId, date });
    if (!added.ok) {
      return err({ type: "already-done", habitId, date });
    }
    return ok(added.value);
  }

  isDone(habitId: string, date: IsoDate): boolean {
    return this.checkInStore.has(checkInId(habitId, date));
  }

  // h1, h2, h3... skipping ids that loaded habits already use
  private newId(): string {
    let id: string;
    do {
      id = `h${this.nextNumber}`;
      this.nextNumber++;
    } while (this.habitStore.has(id));
    return id;
  }

  // ...undo, removeHabit, statsFor, saving and loading
}
```

`checkIn` is a row of **guard clauses**: each check that fails returns an error straight away, and the code at the bottom only runs when everything is fine. `undo` and `removeHabit` follow the same pattern; you'll write them in the exercise.

The ids are simple: `h1`, `h2`, `h3`... A `do...while` loop runs its body at least once, then repeats while the id is taken, which matters after loading saved habits: the tracker never hands out an id that's already used.

## A day's numbers with Pick

The page in Part 3 shows the habits that are due on the chosen day, each with a ✓ button and a streak badge. The tracker gives it everything in one call, `statsFor(date)`, as a list of `HabitStats`:

```ts
interface HabitStats extends Pick<Habit, "id" | "name" | "schedule"> {
  done: boolean; // checked in on that day
  streak: number;
  thisWeek: number; // check-ins that week, up to that day
}
```

`extends Pick<...>` takes three properties straight from `Habit`, types included, and adds three numbers the page needs. `thisWeek` lets the page show progress like "1/2 this week" for times-per-week habits, using `timesInWeek` from Part 1. Like `streak`, it only counts check-ins up to the given day: looking back at Monday, you see Monday as it was, not the check-ins you added on Wednesday.

`statsFor` is where Part 1's pure functions meet the stored data: it keeps the habits that are due (`isDue`), and for each one asks `isDone`, `streak` and `timesInWeek`, always with the `date` it was given. The tracker never asks what day it **really** is.

## Saving through an interface

Next, saving. In the browser the data goes to `localStorage`, but the tracker shouldn't depend on it directly: tests run where there's no `localStorage` at all, and a test should never leave data behind for the next one. So the tracker asks for the **smallest thing it needs**, an object with `getItem` and `setItem`:

```ts
interface StorageLike {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
}
```

Thanks to [structural typing](/learn/typescript/structural-typing-and-class-design), the browser's real `localStorage` **already fits** this interface: it has both methods with these types (and more, which doesn't matter). So the page in Part 3 will simply write `new HabitTracker(localStorage)`, and tests pass in a `FakeStorage` that keeps everything in a `Map`. It's dependency injection again, just like the parking garage's clock. Here's the idea on a tiny class first:

<CodeExample output={`✓ VisitCounter > starts at 1
✓ VisitCounter > remembers visits in its storage

Tests  2 passed (2)`}>

```ts
import { describe, it, expect } from "vitest";

interface StorageLike {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
}

// For tests: keeps everything in a Map
class FakeStorage implements StorageLike {
  private data = new Map<string, string>();

  getItem(key: string): string | null {
    return this.data.get(key) ?? null;
  }

  setItem(key: string, value: string): void {
    this.data.set(key, value);
  }
}

class VisitCounter {
  constructor(private readonly storage: StorageLike) {}

  visit(): number {
    const count = Number(this.storage.getItem("visits") ?? "0") + 1;
    this.storage.setItem("visits", String(count));
    return count;
  }
}

describe("VisitCounter", () => {
  it("starts at 1", () => {
    const counter = new VisitCounter(new FakeStorage());
    expect(counter.visit()).toBe(1);
  });
  it("remembers visits in its storage", () => {
    const storage = new FakeStorage();
    new VisitCounter(storage).visit();
    new VisitCounter(storage).visit(); // like a page reload
    expect(storage.getItem("visits")).toBe("2");
  });
});
```

</CodeExample>

Each test makes its **own** fake storage, so the tests can't affect each other. The second one creates two counters on the same storage, which is exactly what reloading a page does: a new object, the same saved data.

## Loading without trusting

Saving is easy: `JSON.stringify` the habits and check-ins. Loading is where things go wrong. Whatever is in storage could come from an older version of your app, be half-written, or have been edited by hand in the browser's DevTools. As you learned in [Type Guards & unknown](/learn/typescript/type-guards-and-unknown): **`unknown` at the edges, guards to get in, real types inside.**

We need a guard for every type we save. One trap first: checking a weekday with `includes` doesn't compile when the value is a plain string:

```ts
function isWeekday(value: unknown): value is Weekday {
  return typeof value === "string" && WEEKDAYS.includes(value);
  // ❌ Error: Argument of type 'string' is not assignable to parameter of type 'Weekday'.
}
```

`WEEKDAYS` is a `Weekday[]`, so its `includes` only accepts a `Weekday`, and proving that the value is one is the whole point of the function! `WEEKDAYS.some((day) => day === value)` asks the same question and accepts any value.

Dates get a guard too. `isIsoDate` turns the text into a `Date` and back: if the result is the same text, it was a real date. That catches `"hello"` (an invalid date, whose `getTime()` is `NaN`) and also `"2026-02-30"`, which JavaScript quietly rolls over to 2 March.

Then `parseSaved` puts the guards together. It **never throws** and **never gives up on everything**: bad JSON or the wrong shape gives empty lists, and inside good data, each habit and check-in is checked on its own, so one damaged item doesn't lose all the others:

<CodeExample output={`true false
[ 'Read', 'Stretch' ] 1
{ habits: [], checkIns: [] }
{ habits: [], checkIns: [] }`}>

```ts
type IsoDate = string;
type Weekday = "mon" | "tue" | "wed" | "thu" | "fri" | "sat" | "sun";
const WEEKDAYS: Weekday[] = [
  "sun", "mon", "tue", "wed", "thu", "fri", "sat",
];
function toDate(date: IsoDate): Date {
  return new Date(`${date}T00:00:00Z`);
}
function toIsoDate(date: Date): IsoDate {
  return date.toISOString().slice(0, 10);
}
type Schedule =
  | { kind: "daily" }
  | { kind: "weekly"; days: Weekday[] }
  | { kind: "timesPerWeek"; times: number };
interface Habit {
  readonly id: string;
  name: string;
  schedule: Schedule;
}
interface CheckIn {
  readonly id: string;
  readonly habitId: string;
  readonly date: IsoDate;
}
function checkInId(habitId: string, date: IsoDate): string {
  return `${habitId}@${date}`;
}

// ===== Validating saved data =====
function isObject(value: unknown): value is Record<string, unknown> {
  return (
    typeof value === "object" && value !== null && !Array.isArray(value)
  );
}

function isWeekday(value: unknown): value is Weekday {
  return WEEKDAYS.some((day) => day === value);
}

function isIsoDate(value: unknown): value is IsoDate {
  if (typeof value !== "string") return false;
  const date = toDate(value);
  // Invalid text gives NaN; "2026-02-30" rolls over to March
  return !Number.isNaN(date.getTime()) && toIsoDate(date) === value;
}

function isSchedule(value: unknown): value is Schedule {
  if (!isObject(value)) return false;
  switch (value.kind) {
    case "daily":
      return true;
    case "weekly":
      return Array.isArray(value.days) && value.days.every(isWeekday);
    case "timesPerWeek":
      return typeof value.times === "number";
    default:
      return false; // a kind we don't know
  }
}

function isHabit(value: unknown): value is Habit {
  return (
    isObject(value) &&
    typeof value.id === "string" &&
    typeof value.name === "string" &&
    isSchedule(value.schedule)
  );
}

function isCheckIn(value: unknown): value is CheckIn {
  return (
    isObject(value) &&
    typeof value.habitId === "string" &&
    isIsoDate(value.date) &&
    value.id === checkInId(value.habitId, value.date)
  );
}

interface SavedData {
  habits: readonly Habit[];
  checkIns: readonly CheckIn[];
}

// Whatever is saved, give back valid data (maybe empty)
function parseSaved(text: string | null): SavedData {
  const empty: SavedData = { habits: [], checkIns: [] };
  if (text === null) return empty; // nothing saved yet
  let data: unknown;
  try {
    data = JSON.parse(text);
  } catch {
    return empty; // not even JSON
  }
  if (!isObject(data)) return empty;
  const { habits, checkIns } = data;
  return {
    habits: Array.isArray(habits) ? habits.filter(isHabit) : [],
    checkIns: Array.isArray(checkIns) ? checkIns.filter(isCheckIn) : [],
  };
}

// ===== Try it =====
console.log(isIsoDate("2026-03-16"), isIsoDate("2026-02-30"));

const saved = JSON.stringify({
  habits: [
    { id: "h1", name: "Read", schedule: { kind: "daily" } },
    { id: "h2", name: "Nap", schedule: { kind: "hourly" } },
    { id: "h3", name: "Run" },
    {
      id: "h4",
      name: "Swim",
      schedule: { kind: "weekly", days: ["tue", "funday"] },
    },
    { id: "h5", name: "Stretch", schedule: { kind: "daily" } },
  ],
  checkIns: [
    { id: "h1@2026-03-16", habitId: "h1", date: "2026-03-16" },
    { id: "h1@2026-03-17", habitId: "h1", date: "17/03/2026" },
  ],
});

const data = parseSaved(saved);
console.log(data.habits.map((h) => h.name), data.checkIns.length);
console.log(parseSaved("{ oops"));
console.log(parseSaved(null));
```

</CodeExample>

`isCheckIn` checks one more thing: that the id really is `checkInId(habitId, date)`. If a check-in were saved with some other id, the "once per day" rule from the store would no longer protect us.

<Callout type="tip" title="Validate once, at the edge">

All the checking happens in one place, `parseSaved`, which runs once, when the tracker starts. Every method after that works with real `Habit` and `CheckIn` values and needs no more checks. If validation were scattered around the code, you'd forget it somewhere.

</Callout>

## Saving on every change

The last piece: **when** to save. The stores already tell their subscribers about every change, so the tracker subscribes to both and saves whenever anything happens. It also passes the news on to its own listeners through `onChange`, so the page can redraw itself:

```ts
constructor(private readonly storage: StorageLike) {
  const saved = parseSaved(storage.getItem(STORAGE_KEY));
  for (const habit of saved.habits) {
    this.habitStore.add(habit);
  }
  for (const checkIn of saved.checkIns) {
    if (this.habitStore.has(checkIn.habitId)) {
      this.checkInStore.add(checkIn);
    }
  }
  // Only now: loading isn't a change that needs saving
  this.habitStore.subscribe(() => this.changed());
  this.checkInStore.subscribe(() => this.changed());
}

private changed(): void {
  this.save();
  for (const listener of this.listeners) {
    listener();
  }
}
```

Two details matter here. The tracker subscribes **after** loading, so filling the stores from storage doesn't trigger a pointless save for every item. And check-ins for habits that don't exist are skipped while loading, so leftovers from a deleted habit can't sneak back in.

<Callout type="note" title="Simple beats clever here">

Removing a habit with 30 check-ins sends 31 `"removed"` events, so the tracker saves 31 times in a row. For a habit tracker's few kilobytes of JSON that's nothing, and the code stays simple: no method can forget to save, because no method saves by hand. A bigger app might **batch** changes and save once at the end. Measure first, then optimise.

</Callout>

// getUTCDay() counts from Sunday (0) to Saturday (6)
const WEEKDAYS: Weekday[] = [
  "sun", "mon", "tue", "wed", "thu", "fri", "sat",
];

function toDate(date: IsoDate): Date {
  return new Date(\`\${date}T00:00:00Z\`); // midnight UTC
}

function toIsoDate(date: Date): IsoDate {
  return date.toISOString().slice(0, 10);
}

function addDays(date: IsoDate, days: number): IsoDate {
  const d = toDate(date);
  d.setUTCDate(d.getUTCDate() + days);
  return toIsoDate(d);
}

function weekdayOf(date: IsoDate): Weekday {
  return WEEKDAYS[toDate(date).getUTCDay()];
}

// The Monday of the week that date is in
function startOfWeek(date: IsoDate): IsoDate {
  const daysSinceMonday = (toDate(date).getUTCDay() + 6) % 7;
  return addDays(date, -daysSinceMonday);
}

// ===== Part 1: habits =====
type Schedule =
  | { kind: "daily" }
  | { kind: "weekly"; days: Weekday[] }
  | { kind: "timesPerWeek"; times: number };

interface Habit {
  readonly id: string;
  name: string;
  schedule: Schedule;
}

interface CheckIn {
  readonly id: string; // one per habit per day
  readonly habitId: string;
  readonly date: IsoDate;
}

function checkInId(habitId: string, date: IsoDate): string {
  return \`\${habitId}@\${date}\`;
}

function assertNever(value: never): never {
  throw new Error(\`Unexpected value: \${JSON.stringify(value)}\`);
}

const DAY_NAMES: Record<Weekday, string> = {
  mon: "Mon", tue: "Tue", wed: "Wed", thu: "Thu",
  fri: "Fri", sat: "Sat", sun: "Sun",
};

function describeSchedule(schedule: Schedule): string {
  switch (schedule.kind) {
    case "daily":
      return "Every day";
    case "weekly":
      return schedule.days.map((day) => DAY_NAMES[day]).join(", ");
    case "timesPerWeek":
      return \`\${schedule.times} times a week\`;
    default:
      return assertNever(schedule);
  }
}

function isDue(habit: Habit, date: IsoDate): boolean {
  const schedule = habit.schedule;
  switch (schedule.kind) {
    case "daily":
      return true;
    case "weekly":
      return schedule.days.includes(weekdayOf(date));
    case "timesPerWeek":
      return true; // any day can count towards the target
    default:
      return assertNever(schedule);
  }
}

// ===== Part 1: streaks =====
function doneDates(
  habitId: string,
  checkIns: readonly CheckIn[],
): IsoDate[] {
  return checkIns
    .filter((c) => c.habitId === habitId)
    .map((c) => c.date);
}

// How many dates fall in the week that starts on monday
function timesInWeek(dates: IsoDate[], monday: IsoDate): number {
  const sunday = addDays(monday, 6);
  return dates.filter((d) => d >= monday && d <= sunday).length;
}

// Due days in a row that were done, counting back from today
function dayStreak(
  habit: Habit,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0) return 0;
  const first = [...dates].sort()[0];
  let count = 0;
  for (let day = today; day >= first; day = addDays(day, -1)) {
    if (!isDue(habit, day)) continue; // a day off
    if (dates.includes(day)) {
      count++;
    } else if (day !== today) {
      break; // a missed day ends the streak
    }
  }
  return count;
}

// Weeks in a row that reached the target
function weekStreak(
  times: number,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0 || times < 1) return 0;
  const first = startOfWeek([...dates].sort()[0]);
  const thisMonday = startOfWeek(today);
  let count = 0;
  let monday = thisMonday;
  while (monday >= first) {
    if (timesInWeek(dates, monday) >= times) {
      count++;
    } else if (monday !== thisMonday) {
      break; // a missed week ends the streak
    }
    monday = addDays(monday, -7);
  }
  return count;
}

function streak(
  habit: Habit,
  checkIns: readonly CheckIn[],
  today: IsoDate,
): number {
  // Check-ins after today don't count (yet)
  const dates = doneDates(habit.id, checkIns)
    .filter((d) => d <= today);
  const schedule = habit.schedule;
  switch (schedule.kind) {
    case "daily":
    case "weekly":
      return dayStreak(habit, dates, today);
    case "timesPerWeek":
      return weekStreak(schedule.times, dates, today);
    default:
      return assertNever(schedule);
  }
}


// ===== Results =====
type Result<T, E> =
  | { ok: true; value: T }
  | { ok: false; error: E };

function ok<T>(value: T): { ok: true; value: T } {
  return { ok: true, value };
}

function err<E>(error: E): { ok: false; error: E } {
  return { ok: false, error };
}

// ===== A generic store (from Generics) =====
type StoreError =
  | { type: "duplicate-id"; id: string }
  | { type: "not-found"; id: string };

type StoreEvent<T> =
  | { type: "added"; item: T }
  | { type: "removed"; item: T };

type Listener<T> = (event: StoreEvent<T>) => void;

class Store<T extends { id: string }> {
  private items = new Map<string, T>();
  private listeners: Listener<T>[] = [];

  add(item: T): Result<T, StoreError> {
    if (this.items.has(item.id)) {
      return err({ type: "duplicate-id", id: item.id });
    }
    this.items.set(item.id, item);
    this.emit({ type: "added", item });
    return ok(item);
  }

  get(id: string): T | undefined {
    return this.items.get(id);
  }

  has(id: string): boolean {
    return this.items.has(id);
  }

  remove(id: string): Result<T, StoreError> {
    const item = this.items.get(id);
    if (item === undefined) {
      return err({ type: "not-found", id });
    }
    this.items.delete(id);
    this.emit({ type: "removed", item });
    return ok(item);
  }

  // Remove every matching item; returns what was removed
  removeWhere(predicate: (item: T) => boolean): T[] {
    const doomed = this.find(predicate);
    for (const item of doomed) {
      this.remove(item.id);
    }
    return doomed;
  }

  find(predicate: (item: T) => boolean): T[] {
    return this.list().filter(predicate);
  }

  list(): readonly T[] {
    return [...this.items.values()];
  }

  subscribe(listener: Listener<T>): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private emit(event: StoreEvent<T>): void {
    for (const listener of this.listeners) {
      listener(event);
    }
  }
}

// ===== Validating saved data =====
function isObject(value: unknown): value is Record<string, unknown> {
  return (
    typeof value === "object" && value !== null && !Array.isArray(value)
  );
}

function isWeekday(value: unknown): value is Weekday {
  return WEEKDAYS.some((day) => day === value);
}

function isIsoDate(value: unknown): value is IsoDate {
  if (typeof value !== "string") return false;
  const date = toDate(value);
  // Invalid text gives NaN; "2026-02-30" rolls over to March
  return !Number.isNaN(date.getTime()) && toIsoDate(date) === value;
}

// 1. An object with a known kind: "weekly" also needs an
//    array of weekdays, "timesPerWeek" a number of times
function isSchedule(value: unknown): value is Schedule {
  return false;
}

function isHabit(value: unknown): value is Habit {
  return (
    isObject(value) &&
    typeof value.id === "string" &&
    typeof value.name === "string" &&
    isSchedule(value.schedule)
  );
}

function isCheckIn(value: unknown): value is CheckIn {
  return (
    isObject(value) &&
    typeof value.habitId === "string" &&
    isIsoDate(value.date) &&
    value.id === checkInId(value.habitId, value.date)
  );
}

interface SavedData {
  habits: readonly Habit[];
  checkIns: readonly CheckIn[];
}

// 2. Whatever is saved, give back valid data: nothing saved,
//    broken JSON or not an object gives no habits and no
//    check-ins; otherwise keep the valid items of each list
function parseSaved(text: string | null): SavedData {
  return { habits: [], checkIns: [] };
}

// ===== Storage =====
interface StorageLike {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
}

// For tests: keeps everything in a Map
class FakeStorage implements StorageLike {
  private data = new Map<string, string>();

  getItem(key: string): string | null {
    return this.data.get(key) ?? null;
  }

  setItem(key: string, value: string): void {
    this.data.set(key, value);
  }
}

// ===== The tracker =====
// 3. A new habit has everything a Habit has, except the id
type NewHabit = Habit;

type TrackerError =
  | { type: "invalid-habit"; reason: string }
  | { type: "unknown-habit"; habitId: string }
  | { type: "not-due"; habitId: string; date: IsoDate }
  | { type: "already-done"; habitId: string; date: IsoDate }
  | { type: "not-done"; habitId: string; date: IsoDate };

function errorMessage(error: TrackerError): string {
  switch (error.type) {
    case "invalid-habit":
      return error.reason;
    case "unknown-habit":
      return \`There's no habit with id \${error.habitId}\`;
    case "not-due":
      return \`That habit isn't due on \${error.date}\`;
    case "already-done":
      return \`Already done on \${error.date}\`;
    case "not-done":
      return \`Not done on \${error.date}, so there's nothing to undo\`;
    default:
      return assertNever(error);
  }
}

// What's wrong with a new habit, or null if nothing is
function habitProblem(input: NewHabit): string | null {
  const name = input.name.trim();
  if (name === "") return "Give the habit a name";
  if (name.length > 40) return "Keep the name to 40 characters";
  const schedule = input.schedule;
  switch (schedule.kind) {
    case "daily":
      return null;
    case "weekly":
      return schedule.days.length > 0 ? null : "Pick at least one day";
    case "timesPerWeek": {
      const { times } = schedule;
      const valid = Number.isInteger(times) && times >= 1 && times <= 7;
      return valid ? null : "Times a week must be from 1 to 7";
    }
    default:
      return assertNever(schedule);
  }
}

// One row of the day's list
interface HabitStats extends Pick<Habit, "id" | "name" | "schedule"> {
  done: boolean; // checked in on that day
  streak: number;
  thisWeek: number; // check-ins that week, up to that day
}

const STORAGE_KEY = "pandadev-habits";

class HabitTracker {
  // 4. Only the tracker may touch its stores
  readonly habitStore = new Store<Habit>();
  readonly checkInStore = new Store<CheckIn>();
  private listeners: (() => void)[] = [];
  private nextNumber = 1;

  constructor(private readonly storage: StorageLike) {
    const saved = parseSaved(storage.getItem(STORAGE_KEY));
    for (const habit of saved.habits) {
      this.habitStore.add(habit);
    }
    for (const checkIn of saved.checkIns) {
      if (this.habitStore.has(checkIn.habitId)) {
        this.checkInStore.add(checkIn);
      }
    }
    // Only now: loading isn't a change that needs saving
    this.habitStore.subscribe(() => this.changed());
    this.checkInStore.subscribe(() => this.changed());
  }

  addHabit(input: NewHabit): Result<Habit, TrackerError> {
    const problem = habitProblem(input);
    if (problem !== null) {
      return err({ type: "invalid-habit", reason: problem });
    }
    const habit: Habit = {
      id: this.newId(),
      name: input.name.trim(),
      schedule: input.schedule,
    };
    this.habitStore.add(habit);
    return ok(habit);
  }

  // 5. Remove the habit AND its check-ins
  //    ("unknown-habit" if there's no such habit)
  removeHabit(habitId: string): Result<Habit, TrackerError> {
    return err({ type: "unknown-habit", habitId });
  }

  // 6. Check the habit in on date. Errors: "unknown-habit",
  //    "not-due" (use isDue) or "already-done" (the check-in
  //    store refuses the same id twice)
  checkIn(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    return err({ type: "unknown-habit", habitId });
  }

  // 7. Remove that day's check-in ("not-done" if there's none)
  undo(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    return err({ type: "not-done", habitId, date });
  }

  isDone(habitId: string, date: IsoDate): boolean {
    return this.checkInStore.has(checkInId(habitId, date));
  }

  listHabits(): readonly Habit[] {
    return this.habitStore.list();
  }

  // 8. One HabitStats for each habit that's due on date:
  //    done that day?, its streak, and its check-ins that
  //    week up to date (later ones haven't happened yet)
  statsFor(date: IsoDate): HabitStats[] {
    return [];
  }

  // Call listener after every change; returns "unsubscribe"
  onChange(listener: () => void): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private changed(): void {
    this.save();
    for (const listener of this.listeners) {
      listener();
    }
  }

  private save(): void {
    const data: SavedData = {
      habits: this.habitStore.list(),
      checkIns: this.checkInStore.list(),
    };
    this.storage.setItem(STORAGE_KEY, JSON.stringify(data));
  }

  // h1, h2, h3... skipping ids that loaded habits already use
  private newId(): string {
    let id: string;
    do {
      id = \`h\${this.nextNumber}\`;
      this.nextNumber++;
    } while (this.habitStore.has(id));
    return id;
  }
}

type IsoDate = string; // "2026-03-16": year-month-day

type Weekday = "mon" | "tue" | "wed" | "thu" | "fri" | "sat" | "sun";

// getUTCDay() counts from Sunday (0) to Saturday (6)
const WEEKDAYS: Weekday[] = [
  "sun", "mon", "tue", "wed", "thu", "fri", "sat",
];

function toDate(date: IsoDate): Date {
  return new Date(`${date}T00:00:00Z`); // midnight UTC
}

function toIsoDate(date: Date): IsoDate {
  return date.toISOString().slice(0, 10);
}

function addDays(date: IsoDate, days: number): IsoDate {
  const d = toDate(date);
  d.setUTCDate(d.getUTCDate() + days);
  return toIsoDate(d);
}

function weekdayOf(date: IsoDate): Weekday {
  return WEEKDAYS[toDate(date).getUTCDay()];
}

// The Monday of the week that date is in
function startOfWeek(date: IsoDate): IsoDate {
  const daysSinceMonday = (toDate(date).getUTCDay() + 6) % 7;
  return addDays(date, -daysSinceMonday);

type Schedule =
  | { kind: "daily" }
  | { kind: "weekly"; days: Weekday[] }
  | { kind: "timesPerWeek"; times: number };

interface Habit {
  readonly id: string;
  name: string;
  schedule: Schedule;
}

interface CheckIn {
  readonly id: string; // one per habit per day
  readonly habitId: string;
  readonly date: IsoDate;
}

function checkInId(habitId: string, date: IsoDate): string {
  return `${habitId}@${date}`;
}

function assertNever(value: never): never {
  throw new Error(`Unexpected value: ${JSON.stringify(value)}`);
}

const DAY_NAMES: Record<Weekday, string> = {
  mon: "Mon", tue: "Tue", wed: "Wed", thu: "Thu",
  fri: "Fri", sat: "Sat", sun: "Sun",
};

function describeSchedule(schedule: Schedule): string {
  switch (schedule.kind) {
    case "daily":
      return "Every day";
    case "weekly":
      return schedule.days.map((day) => DAY_NAMES[day]).join(", ");
    case "timesPerWeek":
      return `${schedule.times} times a week`;
    default:
      return assertNever(schedule);
  }
}

function isDue(habit: Habit, date: IsoDate): boolean {
  const schedule = habit.schedule;
  switch (schedule.kind) {
    case "daily":
      return true;
    case "weekly":
      return schedule.days.includes(weekdayOf(date));
    case "timesPerWeek":
      return true; // any day can count towards the target
    default:
      return assertNever(schedule);
  }
}

// ===== Part 1: streaks =====
function doneDates(
  habitId: string,
  checkIns: readonly CheckIn[],
): IsoDate[] {
  return checkIns
    .filter((c) => c.habitId === habitId)
    .map((c) => c.date);
}

// How many dates fall in the week that starts on monday
function timesInWeek(dates: IsoDate[], monday: IsoDate): number {
  const sunday = addDays(monday, 6);
  return dates.filter((d) => d >= monday && d <= sunday).length;
}

// Due days in a row that were done, counting back from today
function dayStreak(
  habit: Habit,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0) return 0;
  const first = [...dates].sort()[0];
  let count = 0;
  for (let day = today; day >= first; day = addDays(day, -1)) {
    if (!isDue(habit, day)) continue; // a day off
    if (dates.includes(day)) {
      count++;
    } else if (day !== today) {
      break; // a missed day ends the streak
    }
  }
  return count;
}

// Weeks in a row that reached the target
function weekStreak(
  times: number,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0 || times < 1) return 0;
  const first = startOfWeek([...dates].sort()[0]);
  const thisMonday = startOfWeek(today);
  let count = 0;
  let monday = thisMonday;
  while (monday >= first) {
    if (timesInWeek(dates, monday) >= times) {
      count++;
    } else if (monday !== thisMonday) {
      break; // a missed week ends the streak
    }
    monday = addDays(monday, -7);
  }
  return count;
}

function streak(
  habit: Habit,
  checkIns: readonly CheckIn[],
  today: IsoDate,
): number {
  // Check-ins after today don't count (yet)
  const dates = doneDates(habit.id, checkIns)
    .filter((d) => d <= today);
  const schedule = habit.schedule;
  switch (schedule.kind) {
    case "daily":
    case "weekly":
      return dayStreak(habit, dates, today);
    case "timesPerWeek":
      return weekStreak(schedule.times, dates, today);
    default:
      return assertNever(schedule);
  }
}


// ===== Results =====
type Result<T, E> =
  | { ok: true; value: T }
  | { ok: false; error: E };

function ok<T>(value: T): { ok: true; value: T } {
  return { ok: true, value };
}

function err<E>(error: E): { ok: false; error: E } {
  return { ok: false, error };
}

// ===== A generic store (from Generics) =====
type StoreError =
  | { type: "duplicate-id"; id: string }
  | { type: "not-found"; id: string };

type StoreEvent<T> =
  | { type: "added"; item: T }
  | { type: "removed"; item: T };

type Listener<T> = (event: StoreEvent<T>) => void;

class Store<T extends { id: string }> {
  private items = new Map<string, T>();
  private listeners: Listener<T>[] = [];

  add(item: T): Result<T, StoreError> {
    if (this.items.has(item.id)) {
      return err({ type: "duplicate-id", id: item.id });
    }
    this.items.set(item.id, item);
    this.emit({ type: "added", item });
    return ok(item);
  }

  get(id: string): T | undefined {
    return this.items.get(id);
  }

  has(id: string): boolean {
    return this.items.has(id);
  }

  remove(id: string): Result<T, StoreError> {
    const item = this.items.get(id);
    if (item === undefined) {
      return err({ type: "not-found", id });
    }
    this.items.delete(id);
    this.emit({ type: "removed", item });
    return ok(item);
  }

  // Remove every matching item; returns what was removed
  removeWhere(predicate: (item: T) => boolean): T[] {
    const doomed = this.find(predicate);
    for (const item of doomed) {
      this.remove(item.id);
    }
    return doomed;
  }

  find(predicate: (item: T) => boolean): T[] {
    return this.list().filter(predicate);
  }

  list(): readonly T[] {
    return [...this.items.values()];
  }

  subscribe(listener: Listener<T>): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private emit(event: StoreEvent<T>): void {
    for (const listener of this.listeners) {
      listener(event);
    }
  }
}

// ===== Validating saved data =====
function isObject(value: unknown): value is Record<string, unknown> {
  return (
    typeof value === "object" && value !== null && !Array.isArray(value)
  );
}

function isWeekday(value: unknown): value is Weekday {
  return WEEKDAYS.some((day) => day === value);
}

function isIsoDate(value: unknown): value is IsoDate {
  if (typeof value !== "string") return false;
  const date = toDate(value);
  // Invalid text gives NaN; "2026-02-30" rolls over to March
  return !Number.isNaN(date.getTime()) && toIsoDate(date) === value;
}

function isSchedule(value: unknown): value is Schedule {
  if (!isObject(value)) return false;
  switch (value.kind) {
    case "daily":
      return true;
    case "weekly":
      return Array.isArray(value.days) && value.days.every(isWeekday);
    case "timesPerWeek":
      return typeof value.times === "number";
    default:
      return false; // a kind we don't know
  }
}

function isHabit(value: unknown): value is Habit {
  return (
    isObject(value) &&
    typeof value.id === "string" &&
    typeof value.name === "string" &&
    isSchedule(value.schedule)
  );
}

function isCheckIn(value: unknown): value is CheckIn {
  return (
    isObject(value) &&
    typeof value.habitId === "string" &&
    isIsoDate(value.date) &&
    value.id === checkInId(value.habitId, value.date)
  );
}

interface SavedData {
  habits: readonly Habit[];
  checkIns: readonly CheckIn[];
}

// Whatever is saved, give back valid data (maybe empty)
function parseSaved(text: string | null): SavedData {
  const empty: SavedData = { habits: [], checkIns: [] };
  if (text === null) return empty; // nothing saved yet
  let data: unknown;
  try {
    data = JSON.parse(text);
  } catch {
    return empty; // not even JSON
  }
  if (!isObject(data)) return empty;
  const { habits, checkIns } = data;
  return {
    habits: Array.isArray(habits) ? habits.filter(isHabit) : [],
    checkIns: Array.isArray(checkIns) ? checkIns.filter(isCheckIn) : [],
  };
}

type NewHabit = Omit<Habit, "id">;

type TrackerError =
  | { type: "invalid-habit"; reason: string }
  | { type: "unknown-habit"; habitId: string }
  | { type: "not-due"; habitId: string; date: IsoDate }
  | { type: "already-done"; habitId: string; date: IsoDate }
  | { type: "not-done"; habitId: string; date: IsoDate };

function errorMessage(error: TrackerError): string {
  switch (error.type) {
    case "invalid-habit":
      return error.reason;
    case "unknown-habit":
      return `There's no habit with id ${error.habitId}`;
    case "not-due":
      return `That habit isn't due on ${error.date}`;
    case "already-done":
      return `Already done on ${error.date}`;
    case "not-done":
      return `Not done on ${error.date}, so there's nothing to undo`;
    default:
      return assertNever(error);
  }
}

// What's wrong with a new habit, or null if nothing is
function habitProblem(input: NewHabit): string | null {
  const name = input.name.trim();
  if (name === "") return "Give the habit a name";
  if (name.length > 40) return "Keep the name to 40 characters";
  const schedule = input.schedule;
  switch (schedule.kind) {
    case "daily":
      return null;
    case "weekly":
      return schedule.days.length > 0 ? null : "Pick at least one day";
    case "timesPerWeek": {
      const { times } = schedule;
      const valid = Number.isInteger(times) && times >= 1 && times <= 7;
      return valid ? null : "Times a week must be from 1 to 7";
    }
    default:
      return assertNever(schedule);
  }
}

// One row of the day's list
interface HabitStats extends Pick<Habit, "id" | "name" | "schedule"> {
  done: boolean; // checked in on that day
  streak: number;
  thisWeek: number; // check-ins that week, up to that day
}

const STORAGE_KEY = "pandadev-habits";

class HabitTracker {
  private readonly habitStore = new Store<Habit>();
  private readonly checkInStore = new Store<CheckIn>();
  private listeners: (() => void)[] = [];
  private nextNumber = 1;

  constructor(private readonly storage: StorageLike) {
    const saved = parseSaved(storage.getItem(STORAGE_KEY));
    for (const habit of saved.habits) {
      this.habitStore.add(habit);
    }
    for (const checkIn of saved.checkIns) {
      if (this.habitStore.has(checkIn.habitId)) {
        this.checkInStore.add(checkIn);
      }
    }
    // Only now: loading isn't a change that needs saving
    this.habitStore.subscribe(() => this.changed());
    this.checkInStore.subscribe(() => this.changed());
  }

  addHabit(input: NewHabit): Result<Habit, TrackerError> {
    const problem = habitProblem(input);
    if (problem !== null) {
      return err({ type: "invalid-habit", reason: problem });
    }
    const habit: Habit = {
      id: this.newId(),
      name: input.name.trim(),
      schedule: input.schedule,
    };
    this.habitStore.add(habit);
    return ok(habit);
  }

  removeHabit(habitId: string): Result<Habit, TrackerError> {
    const removed = this.habitStore.remove(habitId);
    if (!removed.ok) {
      return err({ type: "unknown-habit", habitId });
    }
    this.checkInStore.removeWhere((c) => c.habitId === habitId);
    return ok(removed.value);
  }

  checkIn(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const habit = this.habitStore.get(habitId);
    if (habit === undefined) {
      return err({ type: "unknown-habit", habitId });
    }
    if (!isDue(habit, date)) {
      return err({ type: "not-due", habitId, date });
    }
    const id = checkInId(habitId, date);
    const added = this.checkInStore.add({ id, habitId, date });
    if (!added.ok) {
      return err({ type: "already-done", habitId, date });
    }
    return ok(added.value);
  }

  undo(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const removed = this.checkInStore.remove(checkInId(habitId, date));
    if (!removed.ok) {
      return err({ type: "not-done", habitId, date });
    }
    return ok(removed.value);
  }

  isDone(habitId: string, date: IsoDate): boolean {
    return this.checkInStore.has(checkInId(habitId, date));
  }

  listHabits(): readonly Habit[] {
    return this.habitStore.list();
  }

  // The habits due on date, with their numbers
  statsFor(date: IsoDate): HabitStats[] {
    const checkIns = this.checkInStore.list();
    const monday = startOfWeek(date);
    return this.habitStore
      .find((habit) => isDue(habit, date))
      .map((habit) => {
        const dates = doneDates(habit.id, checkIns)
          .filter((d) => d <= date);
        return {
          id: habit.id,
          name: habit.name,
          schedule: habit.schedule,
          done: this.isDone(habit.id, date),
          streak: streak(habit, checkIns, date),
          thisWeek: timesInWeek(dates, monday),
        };
      });
  }

  // Call listener after every change; returns "unsubscribe"
  onChange(listener: () => void): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private changed(): void {
    this.save();
    for (const listener of this.listeners) {
      listener();
    }
  }

  private save(): void {
    const data: SavedData = {
      habits: this.habitStore.list(),
      checkIns: this.checkInStore.list(),
    };
    this.storage.setItem(STORAGE_KEY, JSON.stringify(data));
  }

  // h1, h2, h3... skipping ids that loaded habits already use
  private newId(): string {
    let id: string;
    do {
      id = `h${this.nextNumber}`;
      this.nextNumber++;
    } while (this.habitStore.has(id));
    return id;
  }
}
