None of it knows about web pages, and that's exactly why this last part is mostly wiring. You'll build a page with a form for new habits, a list of the day's habits with check buttons and streak badges, and buttons to move between days.

This part uses [Typing the DOM](/learn/typescript/typing-the-dom): the `query` helper, typed events, `dataset` and event delegation. And, of course, all of your code from Parts 1 and 2.

## One file here, modules in real life

On PandaDev the whole app lives in one editor, so the code from Parts 1 and 2 sits at the top of the file, unchanged. In a real project, you'd split it into [modules](/learn/typescript/modules-and-declaration-files), roughly one per part of this capstone:

```ts title="src/main.ts"
import { addDays, isIsoDate, type IsoDate } from "./dates";
import { describeSchedule, type Schedule } from "./habits";
import { HabitTracker, errorMessage } from "./tracker";
import { query } from "./dom";

const tracker = new HabitTracker(localStorage);
// ...the page code from this part
```

Only `main.ts` would touch the page. `dates.ts`, `habits.ts` and `tracker.ts` have no DOM code at all, so their tests (`habits.test.ts`, `tracker.test.ts`) run with `vitest` in the terminal, without a browser. That's also why the Vitest tests from Parts 1 and 2 aren't in this part's editor: code on a page can't import anything here, and in a real project they'd live in their own files anyway.

## The edge of the app

In Part 1 we made a rule: no logic reads the real date. Something has to, though! That something is the **edge** of the app: the few lines that connect your clean, tested code to the messy real world. Here the edge is two things:

```ts
const tracker = new HabitTracker(localStorage);

let currentDay: IsoDate = localToday();
```

`localStorage` fits `StorageLike` thanks to structural typing, as you saw in Part 2. And `localToday()` asks the browser for the date, in the **user's own time zone**:

```ts
// Today in the user's own time zone, as "YYYY-MM-DD"
function localToday(): IsoDate {
  const now = new Date();
  const month = String(now.getMonth() + 1).padStart(2, "0");
  const day = String(now.getDate()).padStart(2, "0");
  return `${now.getFullYear()}-${month}-${day}`;
}
```

Why not `toIsoDate(new Date())`? Because `toISOString()` gives the date in **UTC**. At 00:30 in Tokyo it's still yesterday in UTC, so a Tokyo user would tick off the wrong day. `getMonth()` and `getDate()` (without "UTC") use the user's own clock. Watch out: `getMonth()` counts from **0** (January is 0), hence the `+ 1`. `padStart(2, "0")` turns `3` into `"03"`.

From then on, the page keeps the chosen day in `currentDay` and passes it to the tracker, so ◀ and ▶ can look at any day, past or future. Try it: press the buttons or pick a date.

## Reading the form into a Schedule

The form has a `<select>` for the kind of schedule, checkboxes for weekdays and a number box for "times a week". Its values are all **strings**, but `addHabit` wants a real `Schedule`. TypeScript won't let a plain string through:

```ts
const schedule: Schedule = { kind: kindSelect.value };
// ❌ Error: Type 'string' is not assignable to type '"daily" | "weekly" | "timesPerWeek"'.
```

Notice the type in that message: `"daily" | "weekly" | "timesPerWeek"`. We can get exactly that type from `Schedule` itself with an **indexed access type**, `Schedule["kind"]`, like `T[K]` from [Generic Functions](/learn/typescript/generic-functions). A small type guard then turns the select's string into a `Kind`:

```ts
type Kind = Schedule["kind"]; // "daily" | "weekly" | "timesPerWeek"

function isKind(value: string): value is Kind {
  return (
    value === "daily" || value === "weekly" || value === "timesPerWeek"
  );
}
```

After `isKind`, a `switch` on the kind builds the right kind of `Schedule`, and TypeScript checks every case. A typo in a `case` is caught (`Type '"weekley"' is not comparable to type '"daily" | "weekly" | "timesPerWeek"'.`), and `assertNever` makes sure a new kind of schedule gets a case here too.

For a weekly habit, the days are the values of the **checked** boxes. `daysBox.querySelectorAll("input")` uses a tag name, so TypeScript knows they're `HTMLInputElement`s with `checked` and `value`. Their values are plain strings, so `filter(isWeekday)` (from Part 2) keeps the real weekdays and gives a `Weekday[]`. Choose a kind, tick some days, and press the button:

## Drawing the day

The page follows the same pattern as the JavaScript to-do app: **state lives in one place** (the tracker), and `render()` redraws the page from it. `tracker.statsFor(currentDay)` returns everything one row needs, and `createRow(stats)` turns a `HabitStats` into a list item:

```html

  <div class="info">
    <span class="name">Read 10 pages</span>
    <span class="schedule">Every day</span>
  </div>
  <span class="badge">🔥 2 days</span>
  <button class="check" data-id="h1">✓ Done</button>
  <button class="delete" data-id="h1">✕</button>
</li>
```

The badge text depends on the kind of schedule, which makes it one more `switch` with `assertNever`:

| Schedule | No streak yet | With a streak |
| --- | --- | --- |
| daily, weekly | *(empty)* | `🔥 1 day`, `🔥 3 days` |
| times per week | `1/2 this week` | `2/2 this week · 🔥 1 week` |

A small `plural(count, word)` helper gives `1 day` but `3 days`.

## One listener for the whole list

Every row has a check button and a delete button, and rows are redrawn after every change. Instead of adding listeners to each button, **one** listener on the list handles them all, like the voting example in Typing the DOM. TypeScript makes you prove what was clicked:

```ts
list.addEventListener("click", (event) => {
  const button = event.target; // EventTarget | null
  if (!(button instanceof HTMLButtonElement)) return;
  const id = button.dataset.id; // string | undefined
  if (id === undefined) return;

  if (button.classList.contains("check")) {
    const result = tracker.isDone(id, currentDay)
      ? tracker.undo(id, currentDay)
      : tracker.checkIn(id, currentDay);
    message.textContent = result.ok ? "" : errorMessage(result.error);
  } else if (button.classList.contains("delete")) {
    tracker.removeHabit(id);
  }
});
```

Both `undo` and `checkIn` return a `Result<CheckIn, TrackerError>`, so the `? :` gives one type, and one `errorMessage` call handles every failure. With the page's buttons, these calls should never fail, but if they ever do (say, a bug shows a habit on a day off), the user gets a clear message instead of a silent nothing.

## Changes flow one way

Notice that the click listener never calls `render()`. It doesn't need to. In Part 2, the tracker saves after every change to its stores and then calls its `onChange` listeners, so one line connects the page:

```ts
tracker.onChange(render);
```

Now every change takes the same path, whatever caused it:

```text
click ✓ → tracker.checkIn() → check-in store "added" event
        → tracker saves to localStorage → onChange → render()
```

Nobody can forget to save or to redraw, because nobody does either by hand. Only things that **don't** change the data, like moving to another day, call `render()` themselves (through `goTo`).

// ===== Part 1: streaks =====
function doneDates(

  return checkIns
    .filter((c) => c.habitId === habitId)
    .map((c) => c.date);

// How many dates fall in the week that starts on monday
function timesInWeek(dates: IsoDate[], monday: IsoDate): number {
  const sunday = addDays(monday, 6);
  return dates.filter((d) => d >= monday && d <= sunday).length;
}

// Due days in a row that were done, counting back from today
function dayStreak(
  habit: Habit,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0) return 0;
  const first = [...dates].sort()[0];
  let count = 0;
  for (let day = today; day >= first; day = addDays(day, -1)) {
    if (!isDue(habit, day)) continue; // a day off
    if (dates.includes(day)) {
      count++;
    } else if (day !== today) {
      break; // a missed day ends the streak
    }
  }
  return count;
}

// Weeks in a row that reached the target
function weekStreak(
  times: number,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0 || times < 1) return 0;
  const first = startOfWeek([...dates].sort()[0]);
  const thisMonday = startOfWeek(today);
  let count = 0;
  let monday = thisMonday;
  while (monday >= first) {
    if (timesInWeek(dates, monday) >= times) {
      count++;
    } else if (monday !== thisMonday) {
      break; // a missed week ends the streak
    }
    monday = addDays(monday, -7);
  }
  return count;
}

function streak(
  habit: Habit,
  checkIns: readonly CheckIn[],
  today: IsoDate,
): number {
  // Check-ins after today don't count (yet)
  const dates = doneDates(habit.id, checkIns)
    .filter((d) => d <= today);
  const schedule = habit.schedule;
  switch (schedule.kind) {
    case "daily":
    case "weekly":
      return dayStreak(habit, dates, today);
    case "timesPerWeek":
      return weekStreak(schedule.times, dates, today);
    default:
      return assertNever(schedule);
  }
}

type Result<T, E> =
  | { ok: true; value: T }
  | { ok: false; error: E };

function ok<T>(value: T): { ok: true; value: T } {
  return { ok: true, value };
}

function err<E>(error: E): { ok: false; error: E } {
  return { ok: false, error };
}

// ===== Part 2: a generic store =====
type StoreError =
  | { type: "duplicate-id"; id: string }
  | { type: "not-found"; id: string };

type StoreEvent<T> =
  | { type: "added"; item: T }
  | { type: "removed"; item: T };

type Listener<T> = (event: StoreEvent<T>) => void;

class Store<T extends { id: string }> {
  private items = new Map<string, T>();
  private listeners: Listener<T>[] = [];

  add(item: T): Result<T, StoreError> {
    if (this.items.has(item.id)) {
      return err({ type: "duplicate-id", id: item.id });
    }
    this.items.set(item.id, item);
    this.emit({ type: "added", item });
    return ok(item);
  }

  get(id: string): T | undefined {
    return this.items.get(id);
  }

  has(id: string): boolean {
    return this.items.has(id);
  }

  remove(id: string): Result<T, StoreError> {
    const item = this.items.get(id);
    if (item === undefined) {
      return err({ type: "not-found", id });
    }
    this.items.delete(id);
    this.emit({ type: "removed", item });
    return ok(item);
  }

  // Remove every matching item; returns what was removed
  removeWhere(predicate: (item: T) => boolean): T[] {
    const doomed = this.find(predicate);
    for (const item of doomed) {
      this.remove(item.id);
    }
    return doomed;
  }

  find(predicate: (item: T) => boolean): T[] {
    return this.list().filter(predicate);
  }

  list(): readonly T[] {
    return [...this.items.values()];
  }

  subscribe(listener: Listener<T>): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private emit(event: StoreEvent<T>): void {
    for (const listener of this.listeners) {
      listener(event);
    }

function isObject(value: unknown): value is Record<string, unknown> {
  return (
    typeof value === "object" && value !== null && !Array.isArray(value)
  );
}

function isWeekday(value: unknown): value is Weekday {
  return WEEKDAYS.some((day) => day === value);
}

function isIsoDate(value: unknown): value is IsoDate {
  if (typeof value !== "string") return false;
  const date = toDate(value);
  // Invalid text gives NaN; "2026-02-30" rolls over to March
  return !Number.isNaN(date.getTime()) && toIsoDate(date) === value;
}

function isSchedule(value: unknown): value is Schedule {
  if (!isObject(value)) return false;
  switch (value.kind) {
    case "daily":
      return true;
    case "weekly":
      return Array.isArray(value.days) && value.days.every(isWeekday);
    case "timesPerWeek":
      return typeof value.times === "number";
    default:
      return false; // a kind we don't know
  }
}

function isHabit(value: unknown): value is Habit {
  return (
    isObject(value) &&
    typeof value.id === "string" &&
    typeof value.name === "string" &&
    isSchedule(value.schedule)
  );
}

function isCheckIn(value: unknown): value is CheckIn {
  return (
    isObject(value) &&
    typeof value.habitId === "string" &&
    isIsoDate(value.date) &&
    value.id === checkInId(value.habitId, value.date)
  );
}

interface SavedData {
  habits: readonly Habit[];
  checkIns: readonly CheckIn[];
}

// Whatever is saved, give back valid data (maybe empty)
function parseSaved(text: string | null): SavedData {
  const empty: SavedData = { habits: [], checkIns: [] };
  if (text === null) return empty; // nothing saved yet
  let data: unknown;
  try {
    data = JSON.parse(text);
  } catch {
    return empty; // not even JSON
  }
  if (!isObject(data)) return empty;
  const { habits, checkIns } = data;
  return {
    habits: Array.isArray(habits) ? habits.filter(isHabit) : [],
    checkIns: Array.isArray(checkIns) ? checkIns.filter(isCheckIn) : [],
  };
}

  | { type: "unknown-habit"; habitId: string }

function errorMessage(error: TrackerError): string {
  switch (error.type) {
    case "invalid-habit":
      return error.reason;
    case "unknown-habit":
      return \`There's no habit with id \${error.habitId}\`;
    case "not-due":
      return \`That habit isn't due on \${error.date}\`;
    case "already-done":

// What's wrong with a new habit, or null if nothing is
function habitProblem(input: NewHabit): string | null {
  const name = input.name.trim();
  if (name === "") return "Give the habit a name";
  if (name.length > 40) return "Keep the name to 40 characters";
  const schedule = input.schedule;
  switch (schedule.kind) {
    case "daily":
      return null;
    case "weekly":
      return schedule.days.length > 0 ? null : "Pick at least one day";
    case "timesPerWeek": {
      const { times } = schedule;
      const valid = Number.isInteger(times) && times >= 1 && times <= 7;
      return valid ? null : "Times a week must be from 1 to 7";
    }
    default:
      return assertNever(schedule);
  }
}

    }

  }

  removeHabit(habitId: string): Result<Habit, TrackerError> {

    if (!removed.ok) {
      return err({ type: "unknown-habit", habitId });
    }
    this.checkInStore.removeWhere((c) => c.habitId === habitId);
    return ok(removed.value);
  }

  checkIn(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const habit = this.habitStore.get(habitId);
    if (habit === undefined) {
      return err({ type: "unknown-habit", habitId });
    }
    if (!isDue(habit, date)) {
      return err({ type: "not-due", habitId, date });
    }
    const id = checkInId(habitId, date);
    const added = this.checkInStore.add({ id, habitId, date });
    if (!added.ok) {
      return err({ type: "already-done", habitId, date });
    }
    return ok(added.value);
  }

  undo(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const removed = this.checkInStore.remove(checkInId(habitId, date));
    if (!removed.ok) {
      return err({ type: "not-done", habitId, date });
    }
    return ok(removed.value);
  }

  isDone(habitId: string, date: IsoDate): boolean {
    return this.checkInStore.has(checkInId(habitId, date));
  }

  listHabits(): readonly Habit[] {
    return this.habitStore.list();
  }

  // The habits due on date, with their numbers
  statsFor(date: IsoDate): HabitStats[] {
    const checkIns = this.checkInStore.list();
    const monday = startOfWeek(date);
    return this.habitStore
      .find((habit) => isDue(habit, date))
      .map((habit) => {
        const dates = doneDates(habit.id, checkIns)
          .filter((d) => d <= date);
        return {
          id: habit.id,
          name: habit.name,
          schedule: habit.schedule,
          done: this.isDone(habit.id, date),
          streak: streak(habit, checkIns, date),
          thisWeek: timesInWeek(dates, monday),
        };
      });
  }

  // Call listener after every change; returns "unsubscribe"
  onChange(listener: () => void): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private changed(): void {
    this.save();
    for (const listener of this.listeners) {
      listener();
    }
  }

  private save(): void {
    const data: SavedData = {
      habits: this.habitStore.list(),
      checkIns: this.checkInStore.list(),
    };
    this.storage.setItem(STORAGE_KEY, JSON.stringify(data));
  }

      id = \`h\${this.nextNumber}\`;
      this.nextNumber++;
    } while (this.habitStore.has(id));
    return id;
  }

  return dates.filter((d) => d >= monday && d <= sunday).length;
}

// Due days in a row that were done, counting back from today
function dayStreak(
  habit: Habit,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0) return 0;
  const first = [...dates].sort()[0];
  let count = 0;
  for (let day = today; day >= first; day = addDays(day, -1)) {
    if (!isDue(habit, day)) continue; // a day off
    if (dates.includes(day)) {
      count++;
    } else if (day !== today) {
      break; // a missed day ends the streak
    }
  }
  return count;
}

// Weeks in a row that reached the target
function weekStreak(
  times: number,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0 || times < 1) return 0;
  const first = startOfWeek([...dates].sort()[0]);
  const thisMonday = startOfWeek(today);
  let count = 0;
  let monday = thisMonday;
  while (monday >= first) {
    if (timesInWeek(dates, monday) >= times) {
      count++;
    } else if (monday !== thisMonday) {
      break; // a missed week ends the streak
    }
    monday = addDays(monday, -7);
  }
  return count;
}

function streak(
  habit: Habit,
  checkIns: readonly CheckIn[],
  today: IsoDate,
): number {
  // Check-ins after today don't count (yet)
  const dates = doneDates(habit.id, checkIns)
    .filter((d) => d <= today);
  const schedule = habit.schedule;
  switch (schedule.kind) {
    case "daily":
    case "weekly":
      return dayStreak(habit, dates, today);
    case "timesPerWeek":
      return weekStreak(schedule.times, dates, today);
    default:
      return assertNever(schedule);
  }
}

type Result<T, E> =
  | { ok: true; value: T }
  | { ok: false; error: E };

function ok<T>(value: T): { ok: true; value: T } {
  return { ok: true, value };
}

function err<E>(error: E): { ok: false; error: E } {
  return { ok: false, error };
}

// ===== Part 2: a generic store =====
type StoreError =
  | { type: "duplicate-id"; id: string }
  | { type: "not-found"; id: string };

type StoreEvent<T> =
  | { type: "added"; item: T }
  | { type: "removed"; item: T };

type Listener<T> = (event: StoreEvent<T>) => void;

class Store<T extends { id: string }> {
  private items = new Map<string, T>();
  private listeners: Listener<T>[] = [];

  add(item: T): Result<T, StoreError> {
    if (this.items.has(item.id)) {
      return err({ type: "duplicate-id", id: item.id });
    }
    this.items.set(item.id, item);
    this.emit({ type: "added", item });
    return ok(item);
  }

  get(id: string): T | undefined {
    return this.items.get(id);
  }

  has(id: string): boolean {
    return this.items.has(id);
  }

  remove(id: string): Result<T, StoreError> {
    const item = this.items.get(id);
    if (item === undefined) {
      return err({ type: "not-found", id });
    }
    this.items.delete(id);
    this.emit({ type: "removed", item });
    return ok(item);
  }

  // Remove every matching item; returns what was removed
  removeWhere(predicate: (item: T) => boolean): T[] {
    const doomed = this.find(predicate);
    for (const item of doomed) {
      this.remove(item.id);
    }
    return doomed;
  }

  find(predicate: (item: T) => boolean): T[] {
    return this.list().filter(predicate);
  }

  list(): readonly T[] {
    return [...this.items.values()];
  }

  subscribe(listener: Listener<T>): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private emit(event: StoreEvent<T>): void {
    for (const listener of this.listeners) {
      listener(event);
    }
  }
}

// ===== Part 2: validating saved data =====
function isObject(value: unknown): value is Record<string, unknown> {
  return (
    typeof value === "object" && value !== null && !Array.isArray(value)
  );
}

function isWeekday(value: unknown): value is Weekday {
  return WEEKDAYS.some((day) => day === value);
}

function isIsoDate(value: unknown): value is IsoDate {
  if (typeof value !== "string") return false;
  const date = toDate(value);
  // Invalid text gives NaN; "2026-02-30" rolls over to March
  return !Number.isNaN(date.getTime()) && toIsoDate(date) === value;
}

function isSchedule(value: unknown): value is Schedule {
  if (!isObject(value)) return false;
  switch (value.kind) {
    case "daily":
      return true;
    case "weekly":
      return Array.isArray(value.days) && value.days.every(isWeekday);
    case "timesPerWeek":
      return typeof value.times === "number";
    default:
      return false; // a kind we don't know
  }
}

function isHabit(value: unknown): value is Habit {
  return (
    isObject(value) &&
    typeof value.id === "string" &&
    typeof value.name === "string" &&
    isSchedule(value.schedule)
  );
}

function isCheckIn(value: unknown): value is CheckIn {
  return (
    isObject(value) &&
    typeof value.habitId === "string" &&
    isIsoDate(value.date) &&
    value.id === checkInId(value.habitId, value.date)
  );
}

interface SavedData {
  habits: readonly Habit[];
  checkIns: readonly CheckIn[];
}

// Whatever is saved, give back valid data (maybe empty)
function parseSaved(text: string | null): SavedData {
  const empty: SavedData = { habits: [], checkIns: [] };
  if (text === null) return empty; // nothing saved yet
  let data: unknown;
  try {
    data = JSON.parse(text);
  } catch {
    return empty; // not even JSON
  }
  if (!isObject(data)) return empty;
  const { habits, checkIns } = data;
  return {
    habits: Array.isArray(habits) ? habits.filter(isHabit) : [],
    checkIns: Array.isArray(checkIns) ? checkIns.filter(isCheckIn) : [],
  };
}

interface StorageLike {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
}

// ===== Part 2: the tracker =====
type NewHabit = Omit<Habit, "id">;

type TrackerError =
  | { type: "invalid-habit"; reason: string }
  | { type: "unknown-habit"; habitId: string }
  | { type: "not-due"; habitId: string; date: IsoDate }
  | { type: "already-done"; habitId: string; date: IsoDate }
  | { type: "not-done"; habitId: string; date: IsoDate };

function errorMessage(error: TrackerError): string {
  switch (error.type) {
    case "invalid-habit":
      return error.reason;
    case "unknown-habit":
      return `There's no habit with id ${error.habitId}`;
    case "not-due":
      return `That habit isn't due on ${error.date}`;
    case "already-done":
      return `Already done on ${error.date}`;
    case "not-done":
      return `Not done on ${error.date}, so there's nothing to undo`;
    default:
      return assertNever(error);
  }
}

// What's wrong with a new habit, or null if nothing is
function habitProblem(input: NewHabit): string | null {
  const name = input.name.trim();
  if (name === "") return "Give the habit a name";
  if (name.length > 40) return "Keep the name to 40 characters";
  const schedule = input.schedule;
  switch (schedule.kind) {
    case "daily":
      return null;
    case "weekly":
      return schedule.days.length > 0 ? null : "Pick at least one day";
    case "timesPerWeek": {
      const { times } = schedule;
      const valid = Number.isInteger(times) && times >= 1 && times <= 7;
      return valid ? null : "Times a week must be from 1 to 7";
    }
    default:
      return assertNever(schedule);
  }
}

// One row of the day's list
interface HabitStats extends Pick<Habit, "id" | "name" | "schedule"> {
  done: boolean; // checked in on that day
  streak: number;
  thisWeek: number; // check-ins that week, up to that day
}

const STORAGE_KEY = "pandadev-habits";

class HabitTracker {
  private readonly habitStore = new Store<Habit>();
  private readonly checkInStore = new Store<CheckIn>();
  private listeners: (() => void)[] = [];
  private nextNumber = 1;

  constructor(private readonly storage: StorageLike) {
    const saved = parseSaved(storage.getItem(STORAGE_KEY));
    for (const habit of saved.habits) {
      this.habitStore.add(habit);
    }
    for (const checkIn of saved.checkIns) {
      if (this.habitStore.has(checkIn.habitId)) {
        this.checkInStore.add(checkIn);
      }
    }
    // Only now: loading isn't a change that needs saving
    this.habitStore.subscribe(() => this.changed());
    this.checkInStore.subscribe(() => this.changed());
  }

  addHabit(input: NewHabit): Result<Habit, TrackerError> {
    const problem = habitProblem(input);
    if (problem !== null) {
      return err({ type: "invalid-habit", reason: problem });
    }
    const habit: Habit = {
      id: this.newId(),
      name: input.name.trim(),
      schedule: input.schedule,
    };
    this.habitStore.add(habit);
    return ok(habit);
  }

  removeHabit(habitId: string): Result<Habit, TrackerError> {
    const removed = this.habitStore.remove(habitId);
    if (!removed.ok) {
      return err({ type: "unknown-habit", habitId });
    }
    this.checkInStore.removeWhere((c) => c.habitId === habitId);
    return ok(removed.value);
  }

  checkIn(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const habit = this.habitStore.get(habitId);
    if (habit === undefined) {
      return err({ type: "unknown-habit", habitId });
    }
    if (!isDue(habit, date)) {
      return err({ type: "not-due", habitId, date });
    }
    const id = checkInId(habitId, date);
    const added = this.checkInStore.add({ id, habitId, date });
    if (!added.ok) {
      return err({ type: "already-done", habitId, date });
    }
    return ok(added.value);
  }

  undo(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const removed = this.checkInStore.remove(checkInId(habitId, date));
    if (!removed.ok) {
      return err({ type: "not-done", habitId, date });
    }
    return ok(removed.value);
  }

  isDone(habitId: string, date: IsoDate): boolean {
    return this.checkInStore.has(checkInId(habitId, date));
  }

  listHabits(): readonly Habit[] {
    return this.habitStore.list();
  }

  // The habits due on date, with their numbers
  statsFor(date: IsoDate): HabitStats[] {
    const checkIns = this.checkInStore.list();
    const monday = startOfWeek(date);
    return this.habitStore
      .find((habit) => isDue(habit, date))
      .map((habit) => {
        const dates = doneDates(habit.id, checkIns)
          .filter((d) => d <= date);
        return {
          id: habit.id,
          name: habit.name,
          schedule: habit.schedule,
          done: this.isDone(habit.id, date),
          streak: streak(habit, checkIns, date),
          thisWeek: timesInWeek(dates, monday),
        };
      });
  }

  // Call listener after every change; returns "unsubscribe"
  onChange(listener: () => void): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private changed(): void {
    this.save();
    for (const listener of this.listeners) {
      listener();
    }
  }

  private save(): void {
    const data: SavedData = {
      habits: this.habitStore.list(),
      checkIns: this.checkInStore.list(),
    };
    this.storage.setItem(STORAGE_KEY, JSON.stringify(data));
  }

  // h1, h2, h3... skipping ids that loaded habits already use
  private newId(): string {
    let id: string;
    do {
      id = `h${this.nextNumber}`;
      this.nextNumber++;
    } while (this.habitStore.has(id));
    return id;
  }
}

function readSchedule(): Schedule | null {

function badgeText(stats: HabitStats): string {
  const schedule = stats.schedule;

    case "daily":

      return assertNever(schedule);
