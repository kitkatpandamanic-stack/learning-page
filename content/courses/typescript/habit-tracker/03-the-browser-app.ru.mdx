## Здесь один файл, в жизни — модули

На PandaDev всё приложение живёт в одном редакторе, поэтому код из частей 1 и 2 лежит в начале файла без изменений. В настоящем проекте вы разбили бы его на [модули](/learn/typescript/modules-and-declaration-files) (modules), примерно по одному на каждую часть этого проекта:

```ts title="src/main.ts"
import { addDays, isIsoDate, type IsoDate } from "./dates";
import { describeSchedule, type Schedule } from "./habits";
import { HabitTracker, errorMessage } from "./tracker";
import { query } from "./dom";

const tracker = new HabitTracker(localStorage);
// ...код страницы из этой части
```

Со страницей работал бы только `main.ts`. В `dates.ts`, `habits.ts` и `tracker.ts` вообще нет кода для DOM, поэтому их тесты (`habits.test.ts`, `tracker.test.ts`) запускаются через `vitest` в терминале, без браузера. По этой же причине тестов Vitest из частей 1 и 2 нет в редакторе этой части: код на странице здесь ничего не может импортировать, а в настоящем проекте тесты всё равно жили бы в своих файлах.

## Граница приложения

В части 1 мы ввели правило: никакая логика не читает настоящую дату. Но кто-то же должен это делать! Этот кто-то — **граница** (edge) приложения: несколько строк, которые соединяют ваш чистый, протестированный код с беспорядочным реальным миром. Здесь граница — это две вещи:

```ts
const tracker = new HabitTracker(localStorage);

let currentDay: IsoDate = localToday();
```

`localStorage` подходит под `StorageLike` благодаря структурной типизации, как вы видели в части 2. А `localToday()` спрашивает у браузера дату в **часовом поясе самого пользователя**:

```ts
// Сегодня в часовом поясе пользователя, в виде "YYYY-MM-DD"
function localToday(): IsoDate {
  const now = new Date();
  const month = String(now.getMonth() + 1).padStart(2, "0");
  const day = String(now.getDate()).padStart(2, "0");
  return `${now.getFullYear()}-${month}-${day}`;
}
```

Почему не `toIsoDate(new Date())`? Потому что `toISOString()` возвращает дату по **UTC**. В 00:30 в Токио по UTC ещё вчера, и пользователь из Токио отметил бы не тот день. `getMonth()` и `getDate()` (без «UTC») используют часы самого пользователя. Осторожно: `getMonth()` считает с **0** (январь — это 0), отсюда `+ 1`. `padStart(2, "0")` превращает `3` в `"03"`.

Дальше страница хранит выбранный день в `currentDay` и передаёт его трекеру, так что ◀ и ▶ позволяют посмотреть на любой день, прошлый или будущий. Попробуйте: нажимайте кнопки или выберите дату.

## Читаем форму в Schedule

В форме есть `<select>` для вида расписания, флажки для дней недели и числовое поле для «раз в неделю». Все их значения — **строки**, а `addHabit` нужен настоящий `Schedule`. Простую строку TypeScript не пропустит:

```ts
const schedule: Schedule = { kind: kindSelect.value };
// ❌ Error: Type 'string' is not assignable to type '"daily" | "weekly" | "timesPerWeek"'.
```

Обратите внимание на тип в этом сообщении: `"daily" | "weekly" | "timesPerWeek"`. Ровно этот тип можно получить из самого `Schedule` с помощью **типа доступа по индексу** (indexed access type) `Schedule["kind"]`, как `T[K]` из урока [Обобщённые функции](/learn/typescript/generic-functions). Затем маленький защитник типа превращает строку из select в `Kind`:

```ts
type Kind = Schedule["kind"]; // "daily" | "weekly" | "timesPerWeek"

function isKind(value: string): value is Kind {
  return (
    value === "daily" || value === "weekly" || value === "timesPerWeek"
  );
}
```

После `isKind` оператор `switch` по виду собирает нужный вариант `Schedule`, и TypeScript проверяет каждую ветку. Опечатка в `case` будет поймана (`Type '"weekley"' is not comparable to type '"daily" | "weekly" | "timesPerWeek"'.`), а `assertNever` гарантирует, что новый вид расписания получит ветку и здесь.

Для еженедельной привычки дни — это значения **отмеченных** флажков. `daysBox.querySelectorAll("input")` ищет по имени тега, поэтому TypeScript знает, что это `HTMLInputElement` со свойствами `checked` и `value`. Их значения — обычные строки, так что `filter(isWeekday)` (из части 2) оставляет настоящие дни недели и даёт `Weekday[]`. Выберите вид, отметьте несколько дней и нажмите кнопку:

## Рисуем день

Страница устроена так же, как список дел на JavaScript: **состояние живёт в одном месте** (в трекере), а `render()` перерисовывает страницу по нему. `tracker.statsFor(currentDay)` возвращает всё, что нужно одной строке, а `createRow(stats)` превращает `HabitStats` в элемент списка:

```html
<li data-id="h1" class="done">
  <div class="info">
    <span class="name">Читать 10 страниц</span>
    <span class="schedule">Каждый день</span>
  </div>
  <span class="badge">🔥 2 дня</span>
  <button class="check" data-id="h1">✓ Готово</button>
  <button class="delete" data-id="h1">✕</button>
</li>
```

Текст значка зависит от вида расписания, так что это ещё один `switch` с `assertNever`:

| Расписание | Серии пока нет | Есть серия |
| --- | --- | --- |
| daily, weekly | *(пусто)* | `🔥 1 день`, `🔥 3 дня` |
| timesPerWeek | `1/2 за неделю` | `2/2 за неделю · 🔥 1 неделя` |

В русском у существительного после числа три формы: «1 день», «2 дня», «5 дней» (а ещё «11 дней», но «21 день»). Поэтому помощник `plural(count, forms)` принимает **кортеж** (tuple) из трёх форм, `WordForms`, и сам выбирает нужную по последним цифрам числа: `plural(3, DAY_FORMS)` даёт `3 дня`.

## Один обработчик на весь список

В каждой строке есть кнопка отметки и кнопка удаления, а строки перерисовываются после каждого изменения. Вместо того чтобы вешать обработчики на каждую кнопку, **один** обработчик на списке обслуживает их все, как в примере с голосованием из урока «Типизируем DOM». TypeScript заставляет доказать, что именно было нажато:

```ts
list.addEventListener("click", (event) => {
  const button = event.target; // EventTarget | null
  if (!(button instanceof HTMLButtonElement)) return;
  const id = button.dataset.id; // string | undefined
  if (id === undefined) return;

  if (button.classList.contains("check")) {
    const result = tracker.isDone(id, currentDay)
      ? tracker.undo(id, currentDay)
      : tracker.checkIn(id, currentDay);
    message.textContent = result.ok ? "" : errorMessage(result.error);
  } else if (button.classList.contains("delete")) {
    tracker.removeHabit(id);
  }
});
```

И `undo`, и `checkIn` возвращают `Result<CheckIn, TrackerError>`, поэтому у `? :` один тип, и один вызов `errorMessage` обрабатывает любую неудачу. С кнопками на странице эти вызовы не должны проваливаться, но если такое всё же случится (скажем, из-за бага привычка покажется в выходной), пользователь увидит понятное сообщение, а не молчаливое ничего.

## Изменения текут в одну сторону

Заметьте, что обработчик клика никогда не вызывает `render()`. Ему это и не нужно. В части 2 трекер сохраняет данные после каждого изменения в хранилищах, а затем вызывает своих слушателей `onChange`, так что страницу подключает одна строка:

```ts
tracker.onChange(render);
```

Теперь каждое изменение проходит один и тот же путь, что бы его ни вызвало:

```text
клик ✓ → tracker.checkIn() → событие "added" хранилища отметок
       → трекер сохраняет в localStorage → onChange → render()
```

Никто не может забыть сохранить или перерисовать, потому что никто не делает ни того, ни другого вручную. Только действия, которые **не** меняют данные, например переход на другой день, вызывают `render()` сами (через `goTo`).

<Callout type="note" title="Проверки начинаются с фиксированного дня">

В упражнении поле даты в HTML начинается со значения `value="2026-03-16"`, поэтому проверки каждый раз видят один и тот же понедельник. Ваш код берёт значение поля даты, если это корректная дата, а иначе — `localToday()`. В своей копии приложения удалите `value`, и оно будет открываться на настоящем сегодняшнем дне.

</Callout>

function weekdayOf(date: IsoDate): Weekday {
  return WEEKDAYS[toDate(date).getUTCDay()];
}

// Понедельник той недели, в которую попадает date
function startOfWeek(date: IsoDate): IsoDate {
  const daysSinceMonday = (toDate(date).getUTCDay() + 6) % 7;
  return addDays(date, -daysSinceMonday);
}

type Schedule =
  | { kind: "daily" }
  | { kind: "weekly"; days: Weekday[] }
  | { kind: "timesPerWeek"; times: number };

interface Habit {
  readonly id: string;
  name: string;
  schedule: Schedule;
}

interface CheckIn {
  readonly id: string; // одна на привычку в день
  readonly habitId: string;
  readonly date: IsoDate;
}

function checkInId(habitId: string, date: IsoDate): string {
  return \`\${habitId}@\${date}\`;
}

function assertNever(value: never): never {
  throw new Error(\`Неожиданное значение: \${JSON.stringify(value)}\`);
}

const DAY_NAMES: Record<Weekday, string> = {
  mon: "Пн", tue: "Вт", wed: "Ср", thu: "Чт",
  fri: "Пт", sat: "Сб", sun: "Вс",
};

function describeSchedule(schedule: Schedule): string {
  switch (schedule.kind) {
    case "daily":
      return "Каждый день";
    case "weekly":
      return schedule.days.map((day) => DAY_NAMES[day]).join(", ");
    case "timesPerWeek":
      return \`\${schedule.times}× в неделю\`;
    default:
      return assertNever(schedule);
  }
}

function isDue(habit: Habit, date: IsoDate): boolean {
  const schedule = habit.schedule;
  switch (schedule.kind) {
    case "daily":
      return true;
    case "weekly":
      return schedule.days.includes(weekdayOf(date));
    case "timesPerWeek":
      return true; // к цели засчитывается любой день
    default:
      return assertNever(schedule);
  }
}

// ===== Часть 1: серии =====
function doneDates(
  habitId: string,
  checkIns: readonly CheckIn[],
): IsoDate[] {
  return checkIns
    .filter((c) => c.habitId === habitId)
    .map((c) => c.date);
}

// Сколько дат попадает в неделю, начинающуюся с monday
function timesInWeek(dates: IsoDate[], monday: IsoDate): number {
  const sunday = addDays(monday, 6);
  return dates.filter((d) => d >= monday && d <= sunday).length;
}

// Выполненные подряд дни по плану, считая назад от today
function dayStreak(
  habit: Habit,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0) return 0;
  const first = [...dates].sort()[0];
  let count = 0;
  for (let day = today; day >= first; day = addDays(day, -1)) {
    if (!isDue(habit, day)) continue; // выходной
    if (dates.includes(day)) {
      count++;
    } else if (day !== today) {
      break; // пропущенный день обрывает серию
    }
  }
  return count;
}

// Недели подряд, в которые цель достигнута
function weekStreak(
  times: number,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0 || times < 1) return 0;
  const first = startOfWeek([...dates].sort()[0]);
  const thisMonday = startOfWeek(today);
  let count = 0;
  let monday = thisMonday;
  while (monday >= first) {
    if (timesInWeek(dates, monday) >= times) {
      count++;
    } else if (monday !== thisMonday) {
      break; // пропущенная неделя обрывает серию
    }
    monday = addDays(monday, -7);
  }
  return count;
}

function streak(
  habit: Habit,
  checkIns: readonly CheckIn[],
  today: IsoDate,
): number {
  // Отметки после today (пока) не считаются
  const dates = doneDates(habit.id, checkIns)
    .filter((d) => d <= today);
  const schedule = habit.schedule;
  switch (schedule.kind) {
    case "daily":
    case "weekly":
      return dayStreak(habit, dates, today);
    case "timesPerWeek":
      return weekStreak(schedule.times, dates, today);
    default:
      return assertNever(schedule);
  }
}

type Result<T, E> =
  | { ok: true; value: T }
  | { ok: false; error: E };

function ok<T>(value: T): { ok: true; value: T } {
  return { ok: true, value };
}

function err<E>(error: E): { ok: false; error: E } {
  return { ok: false, error };
}

// ===== Часть 2: дженерик-хранилище =====
type StoreError =
  | { type: "duplicate-id"; id: string }
  | { type: "not-found"; id: string };

type StoreEvent<T> =
  | { type: "added"; item: T }
  | { type: "removed"; item: T };

type Listener<T> = (event: StoreEvent<T>) => void;

class Store<T extends { id: string }> {
  private items = new Map<string, T>();
  private listeners: Listener<T>[] = [];

  add(item: T): Result<T, StoreError> {
    if (this.items.has(item.id)) {
      return err({ type: "duplicate-id", id: item.id });
    }
    this.items.set(item.id, item);
    this.emit({ type: "added", item });
    return ok(item);
  }

  get(id: string): T | undefined {
    return this.items.get(id);
  }

  has(id: string): boolean {
    return this.items.has(id);
  }

  remove(id: string): Result<T, StoreError> {
    const item = this.items.get(id);
    if (item === undefined) {
      return err({ type: "not-found", id });
    }
    this.items.delete(id);
    this.emit({ type: "removed", item });
    return ok(item);
  }

  // Удаляет все подходящие элементы; возвращает удалённые
  removeWhere(predicate: (item: T) => boolean): T[] {
    const doomed = this.find(predicate);
    for (const item of doomed) {
      this.remove(item.id);
    }
    return doomed;
  }

  find(predicate: (item: T) => boolean): T[] {
    return this.list().filter(predicate);
  }

  list(): readonly T[] {
    return [...this.items.values()];
  }

  subscribe(listener: Listener<T>): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private emit(event: StoreEvent<T>): void {
    for (const listener of this.listeners) {
      listener(event);
    }
  }
}

// ===== Часть 2: проверка сохранённых данных =====
function isObject(value: unknown): value is Record<string, unknown> {
  return (
    typeof value === "object" && value !== null && !Array.isArray(value)
  );
}

function isWeekday(value: unknown): value is Weekday {
  return WEEKDAYS.some((day) => day === value);
}

function isIsoDate(value: unknown): value is IsoDate {
  if (typeof value !== "string") return false;
  const date = toDate(value);
  // Неверный текст даёт NaN; "2026-02-30" перескочит на март
  return !Number.isNaN(date.getTime()) && toIsoDate(date) === value;
}

function isSchedule(value: unknown): value is Schedule {
  if (!isObject(value)) return false;
  switch (value.kind) {
    case "daily":
      return true;
    case "weekly":
      return Array.isArray(value.days) && value.days.every(isWeekday);
    case "timesPerWeek":
      return typeof value.times === "number";
    default:
      return false; // незнакомый вид
  }
}

function isHabit(value: unknown): value is Habit {
  return (
    isObject(value) &&
    typeof value.id === "string" &&
    typeof value.name === "string" &&
    isSchedule(value.schedule)
  );
}

function isCheckIn(value: unknown): value is CheckIn {
  return (
    isObject(value) &&
    typeof value.habitId === "string" &&
    isIsoDate(value.date) &&
    value.id === checkInId(value.habitId, value.date)
  );
}

interface SavedData {
  habits: readonly Habit[];
  checkIns: readonly CheckIn[];
}

// Что бы ни было сохранено, вернуть корректные данные (может, пустые)
function parseSaved(text: string | null): SavedData {
  const empty: SavedData = { habits: [], checkIns: [] };
  if (text === null) return empty; // пока ничего не сохранено
  let data: unknown;
  try {
    data = JSON.parse(text);
  } catch {
    return empty; // это даже не JSON
  }
  if (!isObject(data)) return empty;
  const { habits, checkIns } = data;
  return {
    habits: Array.isArray(habits) ? habits.filter(isHabit) : [],
    checkIns: Array.isArray(checkIns) ? checkIns.filter(isCheckIn) : [],
  };
}

function errorMessage(error: TrackerError): string {
  switch (error.type) {
    case "invalid-habit":
      return error.reason;
    case "unknown-habit":
      return \`Нет привычки с id \${error.habitId}\`;

// Что не так с новой привычкой, или null, если всё в порядке
function habitProblem(input: NewHabit): string | null {
  const name = input.name.trim();
  if (name === "") return "Дайте привычке название";
  if (name.length > 40) return "Название — не длиннее 40 символов";
  const schedule = input.schedule;
  switch (schedule.kind) {
    case "daily":
      return null;
    case "weekly":
      return schedule.days.length > 0 ? null : "Выберите хотя бы один день";
    case "timesPerWeek": {
      const { times } = schedule;
      const valid = Number.isInteger(times) && times >= 1 && times <= 7;
      return valid ? null : "Число раз в неделю — от 1 до 7";
    }
    default:
      return assertNever(schedule);
  }
}

interface HabitStats extends Pick<Habit, "id" | "name" | "schedule"> {
  done: boolean; // отмечена в этот день
  streak: number;
  thisWeek: number; // отметки за ту неделю до этого дня
}

const STORAGE_KEY = "pandadev-habits";

class HabitTracker {
  private readonly habitStore = new Store<Habit>();
  private readonly checkInStore = new Store<CheckIn>();
  private listeners: (() => void)[] = [];
  private nextNumber = 1;

  constructor(private readonly storage: StorageLike) {
    const saved = parseSaved(storage.getItem(STORAGE_KEY));
    for (const habit of saved.habits) {
      this.habitStore.add(habit);
    }
    for (const checkIn of saved.checkIns) {
      if (this.habitStore.has(checkIn.habitId)) {
        this.checkInStore.add(checkIn);
      }
    }
    // Только теперь: загрузку сохранять не нужно
    this.habitStore.subscribe(() => this.changed());
    this.checkInStore.subscribe(() => this.changed());
  }

  addHabit(input: NewHabit): Result<Habit, TrackerError> {
    const problem = habitProblem(input);
    if (problem !== null) {
      return err({ type: "invalid-habit", reason: problem });
    }
    const habit: Habit = {
      id: this.newId(),
      name: input.name.trim(),
      schedule: input.schedule,
    };
    this.habitStore.add(habit);
    return ok(habit);
  }

  removeHabit(habitId: string): Result<Habit, TrackerError> {
    const removed = this.habitStore.remove(habitId);
    if (!removed.ok) {
      return err({ type: "unknown-habit", habitId });
    }
    this.checkInStore.removeWhere((c) => c.habitId === habitId);
    return ok(removed.value);
  }

  checkIn(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const habit = this.habitStore.get(habitId);
    if (habit === undefined) {
      return err({ type: "unknown-habit", habitId });
    }
    if (!isDue(habit, date)) {
      return err({ type: "not-due", habitId, date });
    }
    const id = checkInId(habitId, date);
    const added = this.checkInStore.add({ id, habitId, date });
    if (!added.ok) {
      return err({ type: "already-done", habitId, date });
    }
    return ok(added.value);
  }

  undo(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const removed = this.checkInStore.remove(checkInId(habitId, date));
    if (!removed.ok) {
      return err({ type: "not-done", habitId, date });
    }
    return ok(removed.value);
  }

  isDone(habitId: string, date: IsoDate): boolean {
    return this.checkInStore.has(checkInId(habitId, date));
  }

  listHabits(): readonly Habit[] {
    return this.habitStore.list();
  }

  // Привычки на дату date и их показатели
  statsFor(date: IsoDate): HabitStats[] {
    const checkIns = this.checkInStore.list();
    const monday = startOfWeek(date);
    return this.habitStore
      .find((habit) => isDue(habit, date))
      .map((habit) => {
        const dates = doneDates(habit.id, checkIns)
          .filter((d) => d <= date);
        return {
          id: habit.id,
          name: habit.name,
          schedule: habit.schedule,
          done: this.isDone(habit.id, date),
          streak: streak(habit, checkIns, date),
          thisWeek: timesInWeek(dates, monday),
        };
      });
  }

  // Вызывать listener после каждого изменения; вернёт "отписку"
  onChange(listener: () => void): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private changed(): void {
    this.save();
    for (const listener of this.listeners) {
      listener();
    }
  }

  private save(): void {
    const data: SavedData = {
      habits: this.habitStore.list(),
      checkIns: this.checkInStore.list(),
    };
    this.storage.setItem(STORAGE_KEY, JSON.stringify(data));
  }

  // h1, h2, h3... пропуская id, занятые загруженными привычками
  private newId(): string {
    let id: string;
    do {
      id = \`h\${this.nextNumber}\`;
      this.nextNumber++;
    } while (this.habitStore.has(id));
    return id;
  }
}

type IsoDate = string; // "2026-03-16": год-месяц-день

type Weekday = "mon" | "tue" | "wed" | "thu" | "fri" | "sat" | "sun";

// getUTCDay() считает от воскресенья (0) до субботы (6)
const WEEKDAYS: Weekday[] = [
  "sun", "mon", "tue", "wed", "thu", "fri", "sat",
];

function toDate(date: IsoDate): Date {
  return new Date(`${date}T00:00:00Z`); // полночь по UTC
}

function toIsoDate(date: Date): IsoDate {
  return date.toISOString().slice(0, 10);
}

function addDays(date: IsoDate, days: number): IsoDate {
  const d = toDate(date);
  d.setUTCDate(d.getUTCDate() + days);
  return toIsoDate(d);
}

function weekdayOf(date: IsoDate): Weekday {
  return WEEKDAYS[toDate(date).getUTCDay()];
}

// Понедельник той недели, в которую попадает date
function startOfWeek(date: IsoDate): IsoDate {
  const daysSinceMonday = (toDate(date).getUTCDay() + 6) % 7;
  return addDays(date, -daysSinceMonday);
}

type Schedule =
  | { kind: "daily" }
  | { kind: "weekly"; days: Weekday[] }
  | { kind: "timesPerWeek"; times: number };

interface Habit {
  readonly id: string;
  name: string;

  readonly id: string; // одна на привычку в день

function assertNever(value: never): never {
  throw new Error(`Неожиданное значение: ${JSON.stringify(value)}`);
}

const DAY_NAMES: Record<Weekday, string> = {
  mon: "Пн", tue: "Вт", wed: "Ср", thu: "Чт",
  fri: "Пт", sat: "Сб", sun: "Вс",
};

function describeSchedule(schedule: Schedule): string {
  switch (schedule.kind) {
    case "daily":
      return "Каждый день";
    case "weekly":
      return schedule.days.map((day) => DAY_NAMES[day]).join(", ");
    case "timesPerWeek":
      return `${schedule.times}× в неделю`;
    default:
      return assertNever(schedule);
  }
}

function isDue(habit: Habit, date: IsoDate): boolean {
  const schedule = habit.schedule;
  switch (schedule.kind) {
    case "daily":
      return true;
    case "weekly":
      return schedule.days.includes(weekdayOf(date));
    case "timesPerWeek":
      return true; // к цели засчитывается любой день
    default:
      return assertNever(schedule);
  }
}

function doneDates(
  habitId: string,
  checkIns: readonly CheckIn[],
): IsoDate[] {
  return checkIns
    .filter((c) => c.habitId === habitId)
    .map((c) => c.date);
}

// Сколько дат попадает в неделю, начинающуюся с monday
function timesInWeek(dates: IsoDate[], monday: IsoDate): number {
  const sunday = addDays(monday, 6);
  return dates.filter((d) => d >= monday && d <= sunday).length;
}

// Выполненные подряд дни по плану, считая назад от today
function dayStreak(
  habit: Habit,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0) return 0;
  const first = [...dates].sort()[0];
  let count = 0;
  for (let day = today; day >= first; day = addDays(day, -1)) {
    if (!isDue(habit, day)) continue; // выходной
    if (dates.includes(day)) {
      count++;
    } else if (day !== today) {
      break; // пропущенный день обрывает серию
    }
  }
  return count;
}

// Недели подряд, в которые цель достигнута
function weekStreak(
  times: number,
  dates: IsoDate[],
  today: IsoDate,
): number {
  if (dates.length === 0 || times < 1) return 0;
  const first = startOfWeek([...dates].sort()[0]);
  const thisMonday = startOfWeek(today);
  let count = 0;
  let monday = thisMonday;
  while (monday >= first) {
    if (timesInWeek(dates, monday) >= times) {
      count++;
    } else if (monday !== thisMonday) {
      break; // пропущенная неделя обрывает серию
    }
    monday = addDays(monday, -7);
  }
  return count;
}

function streak(
  habit: Habit,
  checkIns: readonly CheckIn[],
  today: IsoDate,
): number {
  // Отметки после today (пока) не считаются
  const dates = doneDates(habit.id, checkIns)
    .filter((d) => d <= today);
  const schedule = habit.schedule;
  switch (schedule.kind) {
    case "daily":
    case "weekly":
      return dayStreak(habit, dates, today);
    case "timesPerWeek":
      return weekStreak(schedule.times, dates, today);
    default:
      return assertNever(schedule);
  }
}

type Result<T, E> =
  | { ok: true; value: T }
  | { ok: false; error: E };

function ok<T>(value: T): { ok: true; value: T } {
  return { ok: true, value };
}

function err<E>(error: E): { ok: false; error: E } {
  return { ok: false, error };
}

// ===== Часть 2: дженерик-хранилище =====
type StoreError =
  | { type: "duplicate-id"; id: string }
  | { type: "not-found"; id: string };

type StoreEvent<T> =
  | { type: "added"; item: T }
  | { type: "removed"; item: T };

type Listener<T> = (event: StoreEvent<T>) => void;

class Store<T extends { id: string }> {
  private items = new Map<string, T>();
  private listeners: Listener<T>[] = [];

  add(item: T): Result<T, StoreError> {
    if (this.items.has(item.id)) {
      return err({ type: "duplicate-id", id: item.id });
    }
    this.items.set(item.id, item);
    this.emit({ type: "added", item });
    return ok(item);
  }

  get(id: string): T | undefined {
    return this.items.get(id);
  }

  has(id: string): boolean {
    return this.items.has(id);
  }

  remove(id: string): Result<T, StoreError> {
    const item = this.items.get(id);
    if (item === undefined) {
      return err({ type: "not-found", id });
    }
    this.items.delete(id);
    this.emit({ type: "removed", item });
    return ok(item);
  }

  // Удаляет все подходящие элементы; возвращает удалённые
  removeWhere(predicate: (item: T) => boolean): T[] {
    const doomed = this.find(predicate);
    for (const item of doomed) {
      this.remove(item.id);
    }
    return doomed;
  }

  find(predicate: (item: T) => boolean): T[] {
    return this.list().filter(predicate);
  }

  list(): readonly T[] {
    return [...this.items.values()];
  }

  subscribe(listener: Listener<T>): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private emit(event: StoreEvent<T>): void {
    for (const listener of this.listeners) {
      listener(event);
    }
  }
}

function isObject(value: unknown): value is Record<string, unknown> {
  return (
    typeof value === "object" && value !== null && !Array.isArray(value)
  );
}

function isWeekday(value: unknown): value is Weekday {
  return WEEKDAYS.some((day) => day === value);
}

function isIsoDate(value: unknown): value is IsoDate {
  if (typeof value !== "string") return false;
  const date = toDate(value);
  // Неверный текст даёт NaN; "2026-02-30" перескочит на март
  return !Number.isNaN(date.getTime()) && toIsoDate(date) === value;
}

function isSchedule(value: unknown): value is Schedule {
  if (!isObject(value)) return false;
  switch (value.kind) {
    case "daily":
      return true;
    case "weekly":
      return Array.isArray(value.days) && value.days.every(isWeekday);
    case "timesPerWeek":
      return typeof value.times === "number";
    default:
      return false; // незнакомый вид
  }
}

function isHabit(value: unknown): value is Habit {
  return (
    isObject(value) &&
    typeof value.id === "string" &&
    typeof value.name === "string" &&
    isSchedule(value.schedule)
  );
}

    isObject(value) &&
    typeof value.habitId === "string" &&
    isIsoDate(value.date) &&

function parseSaved(text: string | null): SavedData {
  const empty: SavedData = { habits: [], checkIns: [] };
  if (text === null) return empty; // пока ничего не сохранено
  let data: unknown;
  try {
    data = JSON.parse(text);
  } catch {
    return empty; // это даже не JSON

  if (!isObject(data)) return empty;

const STORAGE_KEY = "pandadev-habits";

class HabitTracker {
  private readonly habitStore = new Store<Habit>();
  private readonly checkInStore = new Store<CheckIn>();
  private listeners: (() => void)[] = [];
  private nextNumber = 1;

  constructor(private readonly storage: StorageLike) {
    const saved = parseSaved(storage.getItem(STORAGE_KEY));
    for (const habit of saved.habits) {
      this.habitStore.add(habit);
    }
    for (const checkIn of saved.checkIns) {
      if (this.habitStore.has(checkIn.habitId)) {
        this.checkInStore.add(checkIn);
      }
    }
    // Только теперь: загрузку сохранять не нужно
    this.habitStore.subscribe(() => this.changed());
    this.checkInStore.subscribe(() => this.changed());
  }

  addHabit(input: NewHabit): Result<Habit, TrackerError> {
    const problem = habitProblem(input);
    if (problem !== null) {
      return err({ type: "invalid-habit", reason: problem });
    }
    const habit: Habit = {
      id: this.newId(),
      name: input.name.trim(),
      schedule: input.schedule,
    };
    this.habitStore.add(habit);
    return ok(habit);
  }

  removeHabit(habitId: string): Result<Habit, TrackerError> {
    const removed = this.habitStore.remove(habitId);
    if (!removed.ok) {
      return err({ type: "unknown-habit", habitId });
    }
    this.checkInStore.removeWhere((c) => c.habitId === habitId);
    return ok(removed.value);
  }

  checkIn(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const habit = this.habitStore.get(habitId);
    if (habit === undefined) {
      return err({ type: "unknown-habit", habitId });
    }
    if (!isDue(habit, date)) {
      return err({ type: "not-due", habitId, date });
    }
    const id = checkInId(habitId, date);
    const added = this.checkInStore.add({ id, habitId, date });
    if (!added.ok) {
      return err({ type: "already-done", habitId, date });
    }
    return ok(added.value);
  }

  undo(
    habitId: string,
    date: IsoDate,
  ): Result<CheckIn, TrackerError> {
    const removed = this.checkInStore.remove(checkInId(habitId, date));
    if (!removed.ok) {
      return err({ type: "not-done", habitId, date });
    }
    return ok(removed.value);
  }

  isDone(habitId: string, date: IsoDate): boolean {
    return this.checkInStore.has(checkInId(habitId, date));
  }

    return this.habitStore.list();

      .find((habit) => isDue(habit, date))
      .map((habit) => {
        const dates = doneDates(habit.id, checkIns)
          .filter((d) => d <= date);
        return {
          id: habit.id,
          name: habit.name,
          schedule: habit.schedule,
          done: this.isDone(habit.id, date),
          streak: streak(habit, checkIns, date),
          thisWeek: timesInWeek(dates, monday),
        };
      });
  }

  // Вызывать listener после каждого изменения; вернёт "отписку"
  onChange(listener: () => void): () => void {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter((l) => l !== listener);
    };
  }

  private changed(): void {
    this.save();
    for (const listener of this.listeners) {
      listener();
    }
  }

  private save(): void {
    const data: SavedData = {
      habits: this.habitStore.list(),
      checkIns: this.checkInStore.list(),
    };
    this.storage.setItem(STORAGE_KEY, JSON.stringify(data));
  }

  // h1, h2, h3... пропуская id, занятые загруженными привычками
  private newId(): string {
    let id: string;
    do {
      id = `h${this.nextNumber}`;
      this.nextNumber++;
    } while (this.habitStore.has(id));
    return id;
  }
}

  selector: string,
  type: new () => T,

  const element = document.querySelector(selector);

type Kind = Schedule["kind"]; // "daily" | "weekly" | "timesPerWeek"

function isKind(value: string): value is Kind {
  return (
    value === "daily" || value === "weekly" || value === "timesPerWeek"
  );
}

// Показать только поля, нужные выбранному виду расписания

function readSchedule(): Schedule | null {
  const kind = kindSelect.value;
  if (!isKind(kind)) return null;
  switch (kind) {
    case "daily":
      return { kind };
    case "weekly": {
      const days = [...daysBox.querySelectorAll("input")]
        .filter((box) => box.checked)
        .map((box) => box.value)
        .filter(isWeekday);
      return { kind, days };
    }
    case "timesPerWeek":
      return { kind, times: timesInput.valueAsNumber };
    default:
      return assertNever(kind);
  }
}

// Формы слова для 1, 2 и 5: "день", "дня", "дней"
type WordForms = [one: string, few: string, many: string];

const DAY_FORMS: WordForms = ["день", "дня", "дней"];
const WEEK_FORMS: WordForms = ["неделя", "недели", "недель"];

function plural(count: number, [one, few, many]: WordForms): string {
  const last = count % 10;
  const lastTwo = count % 100;
  if (last === 1 && lastTwo !== 11) return `${count} ${one}`;
  if (last >= 2 && last <= 4 && (lastTwo < 12 || lastTwo > 14)) {
    return `${count} ${few}`;
  }
  return `${count} ${many}`;
}

function badgeText(stats: HabitStats): string {
  const schedule = stats.schedule;
  switch (schedule.kind) {
    case "daily":
    case "weekly":
      return stats.streak > 0 ? `🔥 ${plural(stats.streak, DAY_FORMS)}` : "";
    case "timesPerWeek": {
      const progress = `${stats.thisWeek}/${schedule.times} за неделю`;
      if (stats.streak === 0) return progress;
      return `${progress} · 🔥 ${plural(stats.streak, WEEK_FORMS)}`;
    }
    default:
      return assertNever(schedule);
  }
}

## Что вы построили

- Типизированную страницу поверх нетронутой протестированной логики: **граница** читает настоящую дату (`localToday`, в часовом поясе пользователя) и передаёт настоящий `localStorage`, и больше никто этого не делает.
- Форму, чьи строки превращаются в настоящий `Schedule` через `Schedule["kind"]`, защитник `isKind` и исчерпывающий `switch`, а значения флажков фильтруются через `isWeekday`.
- Вид дня, который `render()` рисует по `tracker.statsFor(currentDay)`, со значками серий, зависящими от вида расписания.
- Один делегированный обработчик кликов на все строки, который сужает `event.target` и читает id из `dataset`.
- Однонаправленный поток данных: каждое изменение проходит через трекер, который сохраняет его и просит страницу перерисоваться.
