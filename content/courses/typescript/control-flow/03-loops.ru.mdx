Компьютеры прекрасно умеют делать одно и то же много раз и не скучать. **Цикл** (loop) повторяет блок кода, а TypeScript следит за типами всего, что внутри, так что по спискам можно проходить уверенно. 🔁

## Цикл `for`

У цикла `for` в скобках три части: с чего **начать**, при каком **условии** продолжать и что делать **после каждого круга** — каждой **итерации** (iteration):

<CodeExample output={`Круг 1
Круг 2
Круг 3`}>

```ts
for (let lap = 1; lap <= 3; lap++) {
  console.log(`Круг ${lap}`);
}
```

</CodeExample>

- `let lap = 1` создаёт счётчик. TypeScript выводит, что это `number`.
- `lap <= 3` проверяется перед каждым кругом; цикл останавливается, когда условие становится `false`.
- `lap++` прибавляет 1 к `lap` после каждого круга.

## Цикл `while`

Цикл `while` продолжается, **пока** его условие истинно. Он удобен, когда заранее неизвестно, сколько кругов понадобится:

<CodeExample output="Часов игры: 4">

```ts
let energy: number = 10;
let hours: number = 0;

while (energy > 0) {
  energy -= 3; // то же самое, что energy = energy - 3
  hours++;
}

console.log(`Часов игры: ${hours}`);
```

</CodeExample>

<Callout type="warning" title="Бесконечные циклы">

Убедитесь, что что-то внутри цикла `while` рано или поздно сделает условие ложным (`false`). Если бы `energy` никогда не уменьшалась, цикл работал бы вечно, а страница бы зависла. PandaDev останавливает зациклившийся код через несколько секунд, но лучше на это не полагаться!

</Callout>

## `for...of` по типизированным массивам

Чаще всего вам нужен просто **каждый элемент** списка. `for...of` выдаёт их по одному, без всякого счётчика. Раз массив имеет тип `number[]`, TypeScript знает, что каждый элемент — `number`:

<CodeExample output="9.75">

```ts
const prices: number[] = [4.5, 2, 3.25];
let total = 0;

for (const price of prices) {
  total += price; // price: number
}

console.log(total);
```

</CodeExample>

Поэтому TypeScript ловит ошибки и внутри цикла:

```ts
for (const price of prices) {
  console.log(price.toUpperCase());
  // ❌ Error: Property 'toUpperCase' does not exist on type 'number'.
}
```

## `break` и `continue`

- `continue` пропускает остаток **текущего** круга и переходит к следующему элементу.
- `break` сразу останавливает весь цикл.

<CodeExample output={`12
30`}>

```ts
const scores: number[] = [12, -1, 30, 999, 8];

for (const score of scores) {
  if (score < 0) {
    continue; // пропускаем некорректные результаты
  }
  if (score === 999) {
    break; // 999 означает «конец данных»
  }
  console.log(score);
}
```

</CodeExample>

`-1` пропускается, а на `999` цикл останавливается, поэтому `8` так и не выводится.

## Собираем результаты

Очень частый приём: до цикла создать **пустой** результат, а потом дополнять его на каждом круге. Дайте пустым массивам аннотацию типа, чтобы TypeScript знал, что в них может лежать:

<CodeExample output={`[ 'панда', 'много', 'бамбука' ]
20`}>

```ts
const words: string[] = ["панда", "ест", "много", "бамбука"];
const longWords: string[] = [];
let letterCount = 0;

for (const word of words) {
  letterCount += word.length;
  if (word.length > 3) {
    longWords.push(word);
  }
}

console.log(longWords);
console.log(letterCount);
```

</CodeExample>

Здесь `letterCount` — это **аккумулятор** (accumulator): число, в котором копится промежуточная сумма. `longWords` собирает подходящие элементы. Оба полностью типизированы, поэтому `longWords.push(42)` будет ошибкой типа.

<Callout type="tip" title="Какой цикл выбрать?">

Используйте `for...of`, чтобы пройти по каждому элементу списка (самый частый случай), `for` — когда нужен счётчик или заданное число повторов, а `while` — когда повторяете, пока что-то не произойдёт.

</Callout>

function weeklyReport(steps: number[], goal: number): string {
  let total = 0;
  let daysMet = 0;

  for (const day of steps) {
    total += day;
    if (day >= goal) {
      daysMet++;

## Итоги

- `for (let i = 1; i <= 3; i++)` повторяет код со счётчиком; TypeScript выводит, что `i` — это `number`.
- `while (condition)` повторяет код, пока условие не станет `false`; убедитесь, что когда-нибудь станет.
- `for (const item of list)` проходит по каждому элементу, и элемент получает тип элементов массива.
- `continue` переходит к следующему кругу; `break` останавливает цикл.
- Собирайте результаты в типизированный пустой массив (`const result: string[] = []`) или в числовой аккумулятор.
