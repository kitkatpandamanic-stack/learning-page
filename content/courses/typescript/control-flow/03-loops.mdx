Computers are brilliant at doing the same thing many times without getting bored. A **loop** repeats a block of code, and TypeScript keeps track of the types of everything inside it, so you can loop over lists with confidence. 🔁

## The `for` loop

A `for` loop has three parts in its brackets: where to **start**, the **condition** to keep going, and what to do **after each round**:

<CodeExample output={`Lap 1
Lap 2
Lap 3`}>

```ts
for (let lap = 1; lap <= 3; lap++) {
  console.log(`Lap ${lap}`);
}
```

</CodeExample>

- `let lap = 1` creates the counter. TypeScript infers it's a `number`.
- `lap <= 3` is checked before every round; the loop stops when it's `false`.
- `lap++` adds 1 to `lap` after each round.

## The `while` loop

A `while` loop keeps going **as long as** its condition is true. It's handy when you don't know in advance how many rounds you'll need:

<CodeExample output="Played for 4 hours">

```ts
let energy: number = 10;
let hours: number = 0;

while (energy > 0) {
  energy -= 3; // same as energy = energy - 3
  hours++;
}

console.log(`Played for ${hours} hours`);
```

</CodeExample>

<Callout type="warning" title="Infinite loops">

Make sure something inside a `while` loop eventually makes the condition `false`. If `energy` never went down, the loop would run forever and the page would freeze. PandaDev stops runaway code after a few seconds, but it's best not to rely on that!

</Callout>

## `for...of` over typed arrays

Most of the time you just want **each item** of a list. `for...of` gives you them one by one, with no counter needed. Because the array is a `number[]`, TypeScript knows every item is a `number`:

<CodeExample output="9.75">

```ts
const prices: number[] = [4.5, 2, 3.25];
let total = 0;

for (const price of prices) {
  total += price; // price: number
}

console.log(total);
```

</CodeExample>

So TypeScript can catch mistakes inside the loop too:

```ts
for (const price of prices) {
  console.log(price.toUpperCase());
  // ❌ Error: Property 'toUpperCase' does not exist on type 'number'.
}
```

## `break` and `continue`

- `continue` skips the rest of **this** round and moves on to the next item.
- `break` stops the whole loop immediately.

<CodeExample output={`12
30`}>

```ts
const scores: number[] = [12, -1, 30, 999, 8];

for (const score of scores) {
  if (score < 0) {
    continue; // skip invalid scores
  }
  if (score === 999) {
    break; // 999 means "end of data"
  }
  console.log(score);
}
```

</CodeExample>

`-1` is skipped, and the loop stops at `999`, so `8` is never printed.

## Building results

A very common pattern: start with an **empty** result before the loop, then add to it on each round. Give empty arrays a type annotation so TypeScript knows what belongs in them:

<CodeExample output={`[ 'panda', 'very', 'fluffy' ]
17`}>

```ts
const words: string[] = ["panda", "is", "very", "fluffy"];
const longWords: string[] = [];
let letterCount = 0;

for (const word of words) {
  letterCount += word.length;
  if (word.length > 3) {
    longWords.push(word);
  }
}

console.log(longWords);
console.log(letterCount);
```

</CodeExample>

Here `letterCount` is an **accumulator**: a number that collects a running total. `longWords` collects matching items. Both are fully typed, so `longWords.push(42)` would be a type error.

<Callout type="tip" title="Which loop should I use?">

Use `for...of` for each item in a list (most common), `for` when you need a counter or a set number of repeats, and `while` when you repeat until something happens.

</Callout>

Write `weeklyReport(steps, goal)` for a fitness app. It gets the step counts for each day and the daily goal, and returns a summary. For the week in the starter and a goal of `10000`, it should return `"40500 steps, goal met on 2 days"`. <Hint>

Before the loop, create `let total = 0;` and `let daysMet = 0;`. Inside `for (const day of steps)`, add `day` to `total`, and if `day >= goal`, add 1 to `daysMet`. Finally return a template literal using both.

<Solution>

```ts
function weeklyReport(steps: number[], goal: number): string {
  let total = 0;
  let daysMet = 0;

  for (const day of steps) {
    total += day;
    if (day >= goal) {
      daysMet++;
    }
  }

  return `${total} steps, goal met on ${daysMet} days`;
}

const week: number[] = [8000, 12000, 6500, 10000, 4000];
console.log(weeklyReport(week, 10000));
```

## Recap

- `for (let i = 1; i <= 3; i++)` repeats with a counter; TypeScript infers `i` is a `number`.
- `while (condition)` repeats until the condition is `false`; make sure it eventually is.
- `for (const item of list)` visits every item, and the item gets the array's item type.
- `continue` skips to the next round; `break` stops the loop.
- Build results with a typed empty array (`const result: string[] = []`) or a number accumulator.
