Большинство программ работают со **списками**: оценки, имена, цены. В этом уроке вы узнаете, как TypeScript типизирует массивы (arrays), как запретить их изменять и как **кортежи** (tuples) описывают короткие списки фиксированной формы.

## `T[]` и `Array<T>`

Тип массива — это тип его элементов, за которым идут `[]`. Список чисел — это `number[]`, а список строк — `string[]`. Есть и более длинная запись, `Array<number>`, которая означает ровно то же самое:

<CodeExample output={`[ 72, 95, 88, 61 ]
2 Lagos`}>

```ts
const scores: number[] = [72, 95, 88];
const names: Array<string> = ["Mei", "Sam"];
const cities = ["Paris", "Lagos"]; // выведен тип: string[]

scores.push(61);
console.log(scores);
console.log(names.length, cities[1]);
```

</CodeExample>

Чаще используют короткую форму `number[]`. В любом случае TypeScript теперь следит за тем, что попадает в массив:

```ts
scores.push("ten");
// ❌ Error: Argument of type 'string' is not assignable to parameter of type 'number'.
```

Если в списке могут быть значения разных типов, возьмите объединение типов (union type) в скобках: `(string | number)[]`. Скобки важны: `string | number[]` означало бы «строка или массив чисел».

## Массивы только для чтения

Добавьте **`readonly`** перед типом массива, и получится список, который нельзя изменить. Методы вроде `push`, `pop` и `sort` (они меняют массив) просто становятся недоступны:

```ts
const days: readonly string[] = ["Пн", "Вт"];
days.push("Ср");
// ❌ Error: Property 'push' does not exist on type 'readonly string[]'.
```

Особенно это полезно для параметров функций: так вы обещаете вызывающему коду, что функция только **читает** его массив. При этом по нему всё так же можно пройти циклом, вызвать `map`, `filter` или скопировать его:

<CodeExample output={`9.5
[ 2.5, 3, 4 ]
[ 4, 2.5, 3 ]`}>

```ts
function total(prices: readonly number[]): number {
  let sum = 0;
  for (const price of prices) {
    sum += price;
  }
  return sum;
}

const basket: readonly number[] = [4, 2.5, 3];
console.log(total(basket));

const sorted = [...basket].sort((a, b) => a - b); // сортируем копию
console.log(sorted);
console.log(basket); // не изменился
```

</CodeExample>

## Кортежи: массивы фиксированной длины

**Кортеж** — это массив с фиксированным количеством элементов, где у каждой позиции свой тип. Типы пишутся в квадратных скобках:

<CodeExample output={`Очки игрока Mei: 42
3 1
[ 3, 4 ]`}>

```ts
const point: [number, number] = [3, 4];
const entry: [string, number] = ["Mei", 42];

const [player, score] = entry; // player: string, score: number
console.log(`Очки игрока ${player}: ${score}`);

function divide(a: number, b: number): [number, number] {
  return [Math.floor(a / b), a % b]; // [частное, остаток]
}

const [result, remainder] = divide(10, 3);
console.log(result, remainder);
console.log(point);
```

</CodeExample>

Кортежи удобны, когда функция должна вернуть два значения, как `divide` выше. TypeScript проверяет и длину, и тип на каждой позиции:

```ts
const p: [number, number] = [1, 2, 3];
// ❌ Error: Type '[number, number, number]' is not assignable to type '[number, number]'.
```

## Методы массивов знают ваши типы

Методы массивов сами вычисляют типы своих результатов. `map` возвращает новый массив из того, что возвращает ваш колбэк (callback), `filter` сохраняет тип элементов, а `find` возвращает **один элемент или `undefined`**, потому что может ничего не найти:

<CodeExample output={`[ '12 ₽', '5 ₽', '30 ₽', '8 ₽' ]
[ 5, 8 ]
30 undefined`}>

```ts
const prices = [12, 5, 30, 8];

const labels = prices.map((p) => `${p} ₽`); // string[]
const cheap = prices.filter((p) => p < 10); // number[]
const big = prices.find((p) => p > 20); // number | undefined
const huge = prices.find((p) => p > 100); // number | undefined

console.log(labels);
console.log(cheap);
console.log(big, huge);
```

</CodeExample>

Раз `find` возвращает `T | undefined`, TypeScript заставляет обработать случай «ничего не нашлось», прежде чем использовать результат:

```ts
const names = ["Mei", "Sam", "Ana"];
const found = names.find((n) => n.startsWith("S"));
found.toUpperCase();
// ❌ Error: 'found' is possibly 'undefined'.
```

Сузьте тип проверкой, и ошибка исчезнет:

<CodeExample output={`SAM
Никого не нашли`}>

```ts
function shoutFirst(names: string[], letter: string): string {
  const found = names.find((n) => n.startsWith(letter));
  if (found === undefined) {
    return "Никого не нашли";
  }
  return found.toUpperCase(); // здесь found: string
}

console.log(shoutFirst(["Mei", "Sam", "Ana"], "S"));
console.log(shoutFirst(["Mei", "Sam", "Ana"], "Z"));
```

</CodeExample>

<Callout type="warning" title="Индексы не проверяются">

Элемент, прочитанный по позиции, например `scores[10]`, имеет тип `number`, даже если массив короче, — и во время выполнения вы получите `undefined`. Если не уверены, что элемент существует, сначала проверьте `length` или используйте `find`.

</Callout>

Допишите три небольшие вспомогательные функции для работы со списком слов:

1. `longWords(words, minLength)` возвращает слова, в которых **не меньше** `minLength` букв.
2. `firstStartingWith(words, letter)` возвращает первое слово, которое начинается с `letter`, или `undefined`.
3. `lengthRange(words)` возвращает кортеж `[длина самого короткого, длина самого длинного]`.

<Hint>

Для первой функции используйте `filter`, для второй — `find` (`find` уже возвращает `undefined`, если ничего не нашлось). Для третьей: `words.map((w) => w.length)` даёт `number[]`; разверните его в `Math.min(...)` и `Math.max(...)`.

</Hint>

<Solution>

```ts
function longWords(
  words: readonly string[],
  minLength: number,
): string[] {
  return words.filter((w) => w.length >= minLength);
}

function firstStartingWith(
  words: readonly string[],
  letter: string,
): string | undefined {
  return words.find((w) => w.startsWith(letter));
}

function lengthRange(words: readonly string[]): [number, number] {
  const lengths = words.map((w) => w.length);
  return [Math.min(...lengths), Math.max(...lengths)];
}

const words = ["panda", "bamboo", "tea", "pebble"];
console.log(longWords(words, 6)); // [ 'bamboo', 'pebble' ]
console.log(firstStartingWith(words, "b")); // bamboo
console.log(lengthRange(words)); // [ 3, 6 ]
```

</Solution>

## Итоги

- `number[]` и `Array<number>` означают одно и то же: «массив чисел».
- `readonly string[]` можно читать, но нельзя менять; отлично подходит для параметров функций.
- У кортежа вроде `[string, number]` фиксированная длина и свой тип на каждой позиции.
- `map` и `filter` возвращают новые массивы с выведенными типами; `find` возвращает `T | undefined`, поэтому проверяйте результат перед использованием.
