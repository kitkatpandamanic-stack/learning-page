Time for the part people actually see. 🎨 In this last part you'll build the React app on top of the typed client from Part 2. It loads the to-dos, adds, ticks and deletes them, and it feels **instant**: every change shows up before the server has answered, and quietly goes back if the server says no.

You'll use status unions, reducers and custom hooks from [Reducers, Context and Custom Hooks](/learn/typescript/reducers-context-and-hooks), typed forms and events from [State, Events and Forms](/learn/typescript/state-events-and-forms), typed props from [Typed Components and Props](/learn/typescript/typed-components-and-props), and of course the `TodosClient`.

## The plan

```text
App                 props: client      state: useTodos(client)
├── (loading)       Loading...
├── (failed)        😿 the message
└── (ready)
    ├── AddTodoForm   state: title      props: onAdd
    ├── notice        what went wrong, with ✕ to dismiss it
    ├── TodoItem      props: todo, onToggle, onRemove   (one per to-do)
    └── Saving...     one per title on its way to the server
```

The decisions behind it:

- **`App` receives the client as a prop.** That's dependency injection again: the real app passes `createTodosClient()`, while a demo or a test can pass a fake.
- **All the to-do state lives in one reducer**, inside a custom hook, `useTodos(client)`. Components get the state and four functions: `add`, `toggle`, `remove` and `dismissNotice`.
- **Changes are optimistic.** The screen changes first, then the request goes out, and only a failure changes it back.

## Step 1: the state and its actions

The screen is in one of three situations, so the state is a **status union**, like `FetchState` in the hooks lesson:

- **`loading`**: nothing to show yet.
- **`failed`**: the list couldn't load, with a `message`.
- **`ready`**: the `todos`, plus two extras. `adding` holds the titles that are on their way to the server, and `notice` explains the latest change that failed (or is `null`).

Every change is an action named after what happened, and each **failure** action carries what the reducer needs to undo the change: the to-do as it was before, or the title that never got saved. Since a reducer is plain TypeScript, you can replay a whole session without React:

<CodeExample output={`loaded       [ 'Nap', 'Tea' ] [] null
changed      [ '✓ Nap', 'Tea' ] [] null
changeFailed [ 'Nap', 'Tea' ] [] Server is busy
removed      [ 'Tea' ] [] Server is busy
removeFailed [ 'Nap', 'Tea' ] [] Still busy

```ts
// From shared/ (Todo really comes from TodoSchema)
type Todo = { id: number; title: string; done: boolean };

// ========== web/todos-state.ts ==========
type TodosState =
  | { status: "loading" }
  | { status: "failed"; message: string }
  | {
      status: "ready";
      todos: Todo[];
      adding: string[]; // titles on their way to the server
      notice: string | null; // what went wrong with the last change
    };

type TodosAction =
  | { type: "loaded"; todos: Todo[] }
  | { type: "loadFailed"; message: string }
  | { type: "addStarted"; title: string }
  | { type: "added"; title: string; todo: Todo }
  | { type: "addFailed"; title: string; message: string }
  | { type: "changed"; todo: Todo }
  | { type: "changeFailed"; todo: Todo; message: string }
  | { type: "removed"; id: number }
  | { type: "removeFailed"; todo: Todo; message: string }
  | { type: "noticeDismissed" };

function assertNever(value: never): never {
  throw new Error(`Unhandled action: ${JSON.stringify(value)}`);
}

// Removes the first copy of title (two adds may share a title)
function withoutFirst(list: string[], title: string): string[] {
  const index = list.indexOf(title);
  return index === -1 ? list : list.filter((_, i) => i !== index);
}

function replaceTodo(todos: Todo[], todo: Todo): Todo[] {
  return todos.map((t) => (t.id === todo.id ? todo : t));
}

function todosReducer(
  state: TodosState,
  action: TodosAction,
): TodosState {
  switch (action.type) {
    case "loaded":
      return {
        status: "ready",
        todos: action.todos,
        adding: [],
        notice: null,
      };
    case "loadFailed":
      return { status: "failed", message: action.message };
  }
  // Every other action changes a list that has loaded
  if (state.status !== "ready") return state;

  switch (action.type) {
    case "addStarted":
      return { ...state, adding: [...state.adding, action.title] };
    case "added":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        todos: [...state.todos, action.todo],
      };
    case "addFailed":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        notice: action.message,
      };
    case "changed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
      };
    case "changeFailed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
        notice: action.message,
      };
    case "removed":
      return {
        ...state,
        todos: state.todos.filter((t) => t.id !== action.id),
      };
    case "removeFailed":
      return {
        ...state,
        // Back where it was: the list is sorted by id
        todos: [...state.todos, action.todo].sort(
          (a, b) => a.id - b.id,
        ),
        notice: action.message,
      };
    case "noticeDismissed":
      return { ...state, notice: null };
    default:
      return assertNever(action);
  }
}

// ========== replaying a session ==========
const nap: Todo = { id: 1, title: "Nap", done: false };
const tea: Todo = { id: 2, title: "Tea", done: false };

const session: TodosAction[] = [
  { type: "loaded", todos: [nap, tea] },
  { type: "changed", todo: { ...nap, done: true } }, // optimistic
  { type: "changeFailed", todo: nap, message: "Server is busy" },
  { type: "removed", id: 1 }, // optimistic
  { type: "removeFailed", todo: nap, message: "Still busy" },
  { type: "addStarted", title: "Bamboo" },
];

const show = (t: Todo) => (t.done ? "✓ " : "") + t.title;

let state: TodosState = { status: "loading" };
for (const action of session) {
  state = todosReducer(state, action);
  if (state.status !== "ready") continue;
  console.log(action.type.padEnd(12), state.todos.map(show),
    state.adding, state.notice);
}
```

</CodeExample>

The replay is an optimistic session in miniature: Nap is ticked at once, the server refuses and `changeFailed` puts it back; Nap is deleted at once, the server refuses again and `removeFailed` puts it back **in its place** (the server's list is sorted by id, so sorting puts it where it was). The notice always shows the latest problem.

A few type details make this reducer safe:

- **Two switches, one narrowing.** The first `switch` handles the actions that work in any state. Then `if (state.status !== "ready") return state;` narrows `state` to the ready shape, so every `case` below can use `state.todos`. TypeScript narrowed `action` too: after the returns in the first `switch`, it knows `action` can't be `"loaded"` or `"loadFailed"`, so the `assertNever` in `default` still compiles.
- **Pending titles aren't to-dos.** It's tempting to give an unsaved to-do a temporary id like `-1` and put it in `todos`. But then the rest of the code would treat it as saved: tick it, and the app sends `PATCH /todos/-1`. As a plain `string` in a separate list, it can't be ticked or deleted by mistake, because `toggle` and `remove` take a `Todo` and the compiler won't accept a string. That's "make impossible states impossible" again.
- **`withoutFirst` removes one copy.** Add "Tea" twice quickly and two "Tea"s are pending; when the first one is saved, only one of them may disappear.

## Step 2: loading in a custom hook

`useTodos` owns the reducer and talks to the client. Here's how it loads the list and adds a to-do:

```tsx title="web/use-todos.ts"
// ========== web/use-todos.ts ==========
function useTodos(client: TodosClient) {
  const [state, dispatch] = useReducer(todosReducer, {
    status: "loading",
  });

  useEffect(() => {
    let ignore = false; // true once this effect is cleaned up
    async function load() {
      const result = await client.list();
      if (ignore) return;
      if (result.ok) {
        dispatch({ type: "loaded", todos: result.value });
      } else {
        const message = errorMessage(result.error);
        dispatch({ type: "loadFailed", message });
      }
    }
    load();
    return () => {
      ignore = true;
    };
  }, [client]);

  async function add(title: string) {
    dispatch({ type: "addStarted", title }); // shown at once
    const result = await client.create({ title });
    if (result.ok) {
      dispatch({ type: "added", title, todo: result.value });
    } else {
      const message = errorMessage(result.error);
      dispatch({ type: "addFailed", title, message });
    }
  }
  // ...toggle, remove and dismissNotice follow
}
```

- **`useReducer` is typed by the reducer.** `state` is a `TodosState` and `dispatch` only accepts `TodosAction`s, without a single type argument.
- **The effect loads the list once per client.** If the component disappears before the answer arrives, its cleanup sets `ignore`, and the late answer is dropped instead of updating a component that's gone. (The [`useFetch` hook](/learn/typescript/reducers-context-and-hooks) did the same with an `AbortController`.)
- **`client` is a dependency of the effect**, so it must be the **same** object on every render. Create it once, outside any component, as you'll see in Step 4. A client created inside `App` would be new on every render, and the effect would load the list again, and again.
- **`add` is optimistic too.** `addStarted` makes the title appear at once as "Saving...", and `added` swaps it for the server's to-do, with its real id.

## Step 3: optimistic updates with rollback

A request takes 100 ms on a good connection and several seconds on a train. If the checkbox only ticks when the server has answered, the app feels broken. But most requests **succeed**, so you can show the result straight away and only undo it in the rare case that the request fails. That's an **optimistic update**:

1. Remember how things were.
2. Change the screen at once.
3. Send the request.
4. If it succeeds, take the server's version. If it fails, put back what you remembered, and **tell the user**: a change that silently disappears is worse than a slow one.

Here is the idea on its own, with a fake server that takes 1.5 seconds. Tick a few boxes, then tick **Pretend the server is down** and try again:

`useTodos` does the same thing through reducer actions:

```tsx
  async function toggle(todo: Todo) {
    const done = !todo.done;
    // Optimistic: show the change before the server answers
    dispatch({ type: "changed", todo: { ...todo, done } });
    const result = await client.update(todo.id, { done });
    if (result.ok) {
      dispatch({ type: "changed", todo: result.value });
    } else {
      // Roll back to the to-do as it was, and say why
      const message = errorMessage(result.error);
      dispatch({ type: "changeFailed", todo, message });
    }
  }
```

`remove` follows the same steps, and you'll write it in the exercise: dispatch `"removed"` at once, call `client.remove`, and if that fails, dispatch `"removeFailed"` with the to-do, so the reducer can put it back.

<Callout type="warning" title="Not every change should be optimistic">

Optimistic updates suit changes that almost always succeed and are easy to undo: ticks, likes, renames, deletes from a list. Don't use them when the server decides the outcome (a payment, booking the last seat, a username that might be taken), or when a wrong "done!" would cost the user something. Show "Saving..." and wait for the answer instead.

</Callout>

## Step 4: the real client

The components never import `fetch`, URLs or schemas: they only know `TodosClient`. So switching from a fake to the real thing is two lines at the very bottom of the app:

```tsx
// One client for the whole app, created once (not on every render)
const client = createTodosClient();
createRoot(document.getElementById("root")!).render(
  <App client={client} />,
);
```

`createTodosClient()` talks to the practice API, standing in for your deployed server. In a real project, you'd pass your server's address from the build configuration, for example `createTodosClient({ baseUrl: import.meta.env.VITE_API_URL })` in a Vite app. And remember the `!`: `getElementById` returns `HTMLElement | null`, and only you know that `#root` exists.

## Shipping it

On your machine, the three parts become one repository with three **workspaces**, so the shared code is a package that both sides import:

```text
todo-app/
├── package.json        "workspaces": ["shared", "server", "web"]
├── shared/             schemas.ts, contract.ts      (package @todo/shared)
├── server/             Express API + Vitest tests   (imports @todo/shared)
└── web/                Vite + React app + tests     (imports @todo/shared)
```

```ts title="web/src/todos-client.ts"
import { TodoSchema, array, nothing } from "@todo/shared/schemas";
import type {
  NewTodo,
  TodoPatch,
  TodosApi,
} from "@todo/shared/contract";
```

`import type` disappears from the compiled code, so the contract costs the browser nothing; the schemas are real code that both sides run. Then let CI check the **whole** repository on every push. If someone changes the contract, every place that no longer fits, on either side, fails the build:

```yaml title=".github/workflows/ci.yml"
name: CI
on: [push, pull_request]
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: npm ci
      - run: npx tsc --noEmit -p server && npx tsc --noEmit -p web
      - run: npx vitest run
```

Two things change when the app goes online:

- **The server and the web app usually live on different addresses** (say `api.example.com` and `todos.example.com`), and browsers block such requests unless the server allows them, with **CORS** headers. The `cors` package does it in one line: `app.use(cors({ origin: "https://todos.example.com" }))`. (Or serve both from the same address, with the API under `/api`.)
- **The memory repository forgets everything on restart.** Write a `TodoRepository` backed by a real database (SQLite or Postgres, for example) and pass it to `createApp`. Nothing else in the server changes, and the tests keep using the memory one.

// ========== shared/schemas.ts ==========
// The schema library from Runtime Validation
class ValidationError extends Error {
  constructor(path: string, expected: string, got: unknown) {
    const where = path || "value";
    super(\`\${where}: expected \${expected}, got \${JSON.stringify(got)}\`);
    this.name = "ValidationError";
  }
}

type Schema<T> = { parse: (value: unknown, path?: string) => T };
type Infer<S extends Schema<unknown>> = ReturnType<S["parse"]>;

function primitive<T>(
  expected: string,
  test: (value: unknown) => value is T,
): Schema<T> {
  return {
    parse(value, path = "") {
      if (!test(value)) {
        throw new ValidationError(path, expected, value);
      }
      return value;
    },
  };
}

const string = () =>
  primitive("a string", (v): v is string => typeof v === "string");
const number = () =>
  primitive("a number", (v): v is number => typeof v === "number");
const boolean = () =>
  primitive("a boolean", (v): v is boolean => typeof v === "boolean");

function array<T>(item: Schema<T>): Schema<T[]> {
  return {
    parse(value, path = "") {
      if (!Array.isArray(value)) {
        throw new ValidationError(path, "an array", value);
      }
      return value.map((v, i) => item.parse(v, \`\${path}[\${i}]\`));
    },
  };
}

function isRecord(value: unknown): value is Record<string, unknown> {
  return (
    typeof value === "object" && value !== null && !Array.isArray(value)
  );
}

type Shape = Record<string, Schema<unknown>>;

function object<S extends Shape>(
  shape: S,
): Schema<{ [K in keyof S]: Infer<S[K]> }> {
  return {
    parse(value, path = "") {
      if (!isRecord(value)) {
        throw new ValidationError(path, "an object", value);
      }
      const result: Record<string, unknown> = {};
      for (const key in shape) {
        const where = path ? \`\${path}.\${key}\` : key;
        result[key] = shape[key].parse(value[key], where);
      }
      // every key was checked, so this cast is safe
      return result as { [K in keyof S]: Infer<S[K]> };
    },
  };
}

const TodoSchema = object({
  id: number(),
  title: string(),
  done: boolean(),
});
type Todo = Infer<typeof TodoSchema>;

// ========== shared/contract.ts ==========
// What clients send
type NewTodo = { title: string; done?: boolean };
type TodoPatch = Partial<NewTodo>;

// Every error answer, e.g. { "error": "title is required" }
interface ErrorBody {
  error: string;
}

type Result<T, E> = { ok: true; value: T } | { ok: false; error: E };

interface Endpoint {
  params?: Record<string, string>;
  body?: object;
  response: unknown;
}

type TodosApi = {
  "GET /todos": { response: Todo[] };
  "POST /todos": { body: NewTodo; response: Todo };
  "GET /todos/:id": { params: { id: string }; response: Todo };
  "PATCH /todos/:id": {
    params: { id: string };
    body: TodoPatch;
    response: Todo;
  };
  "DELETE /todos/:id": { params: { id: string }; response: null };
};

// ========== web/api.ts: a client for ANY contract ==========
type ApiError =
  | { kind: "network"; message: string }
  | { kind: "http"; status: number; message: string }
  | { kind: "invalid"; message: string };

// One schema per route, checked against the contract
type ResponseSchemas<Api extends Record<keyof Api, Endpoint>> = {
  [R in keyof Api]: Schema<Api[R]["response"]>;
};

type ClientOptions = {
  baseUrl?: string;
  fetch?: typeof fetch;
};

function apiMessage(body: unknown): string | undefined {
  if (isRecord(body) && typeof body.error === "string") {
    return body.error;
  }
  return undefined;
}

function createApi<Api extends Record<keyof Api, Endpoint>>(
  schemas: ResponseSchemas<Api>,
  options: ClientOptions = {},
) {
  const baseUrl = options.baseUrl ?? "https://api.pandadev.test";
  const fetchFn = options.fetch ?? fetch;

  return async function call<R extends keyof Api & string>(
    route: R,
    input: Omit<Api[R], "response">,
  ): Promise<Result<Api[R]["response"], ApiError>> {
    const { params = {}, body }: Omit<Endpoint, "response"> = input;
    const [method, pattern] = route.split(" ");
    const path = pattern.replace(/:(\\w+)/g, (_, name: string) =>
      encodeURIComponent(params[name] ?? ""),
    );
    const init: RequestInit = { method };
    if (body !== undefined) {
      init.headers = { "Content-Type": "application/json" };
      init.body = JSON.stringify(body);
    }

    let res: Response;
    try {
      res = await fetchFn(baseUrl + path, init);
    } catch (error) {
      const message =
        error instanceof Error ? error.message : String(error);
      return { ok: false, error: { kind: "network", message } };
    }

    const data: unknown =
      res.status === 204 ? null : await res.json().catch(() => null);
    if (!res.ok) {
      const message = apiMessage(data) ?? \`HTTP \${res.status}\`;
      return {
        ok: false,
        error: { kind: "http", status: res.status, message },
      };
    }
    try {
      return { ok: true, value: schemas[route].parse(data) };
    } catch (error) {
      if (error instanceof ValidationError) {
        return {
          ok: false,

type TodosState =
  | { status: "loading" }
  | { status: "failed"; message: string }
  | {
      status: "ready";
      todos: Todo[];
      adding: string[]; // titles on their way to the server
      notice: string | null; // what went wrong with the last change
    };

type TodosAction =
  | { type: "loaded"; todos: Todo[] }
  | { type: "loadFailed"; message: string }
  | { type: "addStarted"; title: string }
  | { type: "added"; title: string; todo: Todo }
  | { type: "addFailed"; title: string; message: string }
  | { type: "changed"; todo: Todo }
  | { type: "changeFailed"; todo: Todo; message: string }
  | { type: "removed"; id: number }
  | { type: "removeFailed"; todo: Todo; message: string }
  | { type: "noticeDismissed" };

function assertNever(value: never): never {
  throw new Error(\`Unhandled action: \${JSON.stringify(value)}\`);
}

// Removes the first copy of title (two adds may share a title)
function withoutFirst(list: string[], title: string): string[] {
  const index = list.indexOf(title);
  return index === -1 ? list : list.filter((_, i) => i !== index);
}

function replaceTodo(todos: Todo[], todo: Todo): Todo[] {
  return todos.map((t) => (t.id === todo.id ? todo : t));
}

function todosReducer(
  state: TodosState,
  action: TodosAction,
): TodosState {
  switch (action.type) {
    case "loaded":
      return {
        status: "ready",
        todos: action.todos,
        adding: [],
        notice: null,
      };
    case "loadFailed":
      return { status: "failed", message: action.message };
  }
  // Every other action changes a list that has loaded
  if (state.status !== "ready") return state;

  switch (action.type) {
    case "addStarted":
      return { ...state, adding: [...state.adding, action.title] };
    case "added":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        todos: [...state.todos, action.todo],
      };
    case "addFailed":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        notice: action.message,
      };
    case "changed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
      };
    case "changeFailed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
        notice: action.message,
      };
    case "removed":
      return {
        ...state,
        todos: state.todos.filter((t) => t.id !== action.id),
      };
    case "removeFailed":
      return {
        ...state,
        // Back where it was: the list is sorted by id
        todos: [...state.todos, action.todo].sort(
          (a, b) => a.id - b.id,
        ),
        notice: action.message,
      };
    case "noticeDismissed":
      return { ...state, notice: null };
    default:
      return assertNever(action);
  }
}

// ========== web/use-todos.ts ==========
function useTodos(client: TodosClient) {
  const [state, dispatch] = useReducer(todosReducer, {
    status: "loading",
  });

  useEffect(() => {
    let ignore = false; // true once this effect is cleaned up
    async function load() {
      const result = await client.list();
      if (ignore) return;
      if (result.ok) {
        dispatch({ type: "loaded", todos: result.value });
      } else {
        const message = errorMessage(result.error);
        dispatch({ type: "loadFailed", message });
      }
    }
    load();
    return () => {
      ignore = true;
    };
  }, [client]);

  async function add(title: string) {
    dispatch({ type: "addStarted", title }); // shown at once
    const result = await client.create({ title });
    if (result.ok) {
      dispatch({ type: "added", title, todo: result.value });
    } else {
      const message = errorMessage(result.error);
      dispatch({ type: "addFailed", title, message });
    }
  }

  async function toggle(todo: Todo) {
    const done = !todo.done;
    // Optimistic: show the change before the server answers
    dispatch({ type: "changed", todo: { ...todo, done } });
    const result = await client.update(todo.id, { done });
    if (result.ok) {
      dispatch({ type: "changed", todo: result.value });
    } else {
      // Roll back to the to-do as it was, and say why
      const message = errorMessage(result.error);
      dispatch({ type: "changeFailed", todo, message });
    }
  }

  // TODO 1: an optimistic remove that rolls back on errors
  async function remove(todo: Todo) {}

  function dismissNotice() {
    dispatch({ type: "noticeDismissed" });
  }

  return { state, add, toggle, remove, dismissNotice };
}

    const init: RequestInit = { method };
    if (body !== undefined) {
      init.headers = { "Content-Type": "application/json" };
      init.body = JSON.stringify(body);
    }

    let res: Response;
    try {
      res = await fetchFn(baseUrl + path, init);
    } catch (error) {
      const message =
        error instanceof Error ? error.message : String(error);
      return { ok: false, error: { kind: "network", message } };
    }

    const data: unknown =
      res.status === 204 ? null : await res.json().catch(() => null);
    if (!res.ok) {
      const message = apiMessage(data) ?? `HTTP ${res.status}`;
      return {
        ok: false,
        error: { kind: "http", status: res.status, message },
      };
    }
    try {
      return { ok: true, value: schemas[route].parse(data) };
    } catch (error) {
      if (error instanceof ValidationError) {
        return {
          ok: false,
          error: { kind: "invalid", message: error.message },
        };
      }
      throw error;
    }
  };
}

// ========== web/todos-client.ts ==========
const todoSchemas: ResponseSchemas<TodosApi> = {
  "GET /todos": array(TodoSchema),
  "POST /todos": TodoSchema,
  "GET /todos/:id": TodoSchema,
  "PATCH /todos/:id": TodoSchema,
  "DELETE /todos/:id": nothing(),
};

// What the rest of the app may do with the server
interface TodosClient {
  list(): Promise<Result<Todo[], ApiError>>;
  get(id: number): Promise<Result<Todo, ApiError>>;
  create(input: NewTodo): Promise<Result<Todo, ApiError>>;
  update(
    id: number,
    patch: TodoPatch,
  ): Promise<Result<Todo, ApiError>>;
  remove(id: number): Promise<Result<null, ApiError>>;
}

function createTodosClient(options: ClientOptions = {}): TodosClient {
  const call = createApi<TodosApi>(todoSchemas, options);
  const params = (id: number) => ({ id: String(id) });
  return {
    list: () => call("GET /todos", {}),
    get: (id) => call("GET /todos/:id", { params: params(id) }),
    create: (input) => call("POST /todos", { body: input }),
    update: (id, patch) =>
      call("PATCH /todos/:id", { params: params(id), body: patch }),
    remove: (id) => call("DELETE /todos/:id", { params: params(id) }),
  };
}

// One friendly sentence for every kind of error
function errorMessage(error: ApiError): string {
  switch (error.kind) {
    case "network":
      return "Can't reach the server. Are you online?";
    case "http":
      return `${error.message} (HTTP ${error.status})`;
    case "invalid":
      return "The server sent something unexpected.";
    default: {
      const unhandled: never = error;
      return unhandled;
    }
  }
}

// ========== web/todos-state.ts ==========
type TodosState =
  | { status: "loading" }
  | { status: "failed"; message: string }
  | {
      status: "ready";
      todos: Todo[];
      adding: string[]; // titles on their way to the server
      notice: string | null; // what went wrong with the last change
    };

type TodosAction =
  | { type: "loaded"; todos: Todo[] }
  | { type: "loadFailed"; message: string }
  | { type: "addStarted"; title: string }
  | { type: "added"; title: string; todo: Todo }
  | { type: "addFailed"; title: string; message: string }
  | { type: "changed"; todo: Todo }
  | { type: "changeFailed"; todo: Todo; message: string }
  | { type: "removed"; id: number }
  | { type: "removeFailed"; todo: Todo; message: string }
  | { type: "noticeDismissed" };

function assertNever(value: never): never {
  throw new Error(`Unhandled action: ${JSON.stringify(value)}`);
}

// Removes the first copy of title (two adds may share a title)
function withoutFirst(list: string[], title: string): string[] {
  const index = list.indexOf(title);
  return index === -1 ? list : list.filter((_, i) => i !== index);
}

function replaceTodo(todos: Todo[], todo: Todo): Todo[] {
  return todos.map((t) => (t.id === todo.id ? todo : t));
}

function todosReducer(
  state: TodosState,
  action: TodosAction,
): TodosState {
  switch (action.type) {
    case "loaded":
      return {
        status: "ready",
        todos: action.todos,
        adding: [],
        notice: null,
      };
    case "loadFailed":
      return { status: "failed", message: action.message };
  }
  // Every other action changes a list that has loaded
  if (state.status !== "ready") return state;

  switch (action.type) {
    case "addStarted":
      return { ...state, adding: [...state.adding, action.title] };
    case "added":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        todos: [...state.todos, action.todo],
      };
    case "addFailed":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        notice: action.message,
      };
    case "changed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
      };
    case "changeFailed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
        notice: action.message,
      };
    case "removed":
      return {
        ...state,
        todos: state.todos.filter((t) => t.id !== action.id),
      };
    case "removeFailed":
      return {
        ...state,
        // Back where it was: the list is sorted by id
        todos: [...state.todos, action.todo].sort(
          (a, b) => a.id - b.id,
        ),
        notice: action.message,
      };
    case "noticeDismissed":
      return { ...state, notice: null };
    default:
      return assertNever(action);
  }
}

// ========== web/use-todos.ts ==========
function useTodos(client: TodosClient) {
  const [state, dispatch] = useReducer(todosReducer, {
    status: "loading",
  });

  useEffect(() => {
    let ignore = false; // true once this effect is cleaned up
    async function load() {
      const result = await client.list();
      if (ignore) return;
      if (result.ok) {
        dispatch({ type: "loaded", todos: result.value });
      } else {
        const message = errorMessage(result.error);
        dispatch({ type: "loadFailed", message });
      }
    }
    load();
    return () => {
      ignore = true;
    };
  }, [client]);

  async function add(title: string) {
    dispatch({ type: "addStarted", title }); // shown at once
    const result = await client.create({ title });
    if (result.ok) {
      dispatch({ type: "added", title, todo: result.value });
    } else {
      const message = errorMessage(result.error);
      dispatch({ type: "addFailed", title, message });
    }
  }

  async function toggle(todo: Todo) {
    const done = !todo.done;
    // Optimistic: show the change before the server answers
    dispatch({ type: "changed", todo: { ...todo, done } });
    const result = await client.update(todo.id, { done });
    if (result.ok) {
      dispatch({ type: "changed", todo: result.value });
    } else {
      // Roll back to the to-do as it was, and say why
      const message = errorMessage(result.error);
      dispatch({ type: "changeFailed", todo, message });
    }
  }

  async function remove(todo: Todo) {
    dispatch({ type: "removed", id: todo.id }); // optimistic
    const result = await client.remove(todo.id);
    if (!result.ok) {
      const message = errorMessage(result.error);
      dispatch({ type: "removeFailed", todo, message });
    }
  }

  function dismissNotice() {
    dispatch({ type: "noticeDismissed" });
  }

  return { state, add, toggle, remove, dismissNotice };
}

// ========== web/components.tsx ==========
function AddTodoForm({ onAdd }: { onAdd: (title: string) => void }) {
  const [title, setTitle] = useState("");

  function handleSubmit(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const clean = title.trim();
    if (clean === "") return;
    onAdd(clean);
    setTitle("");
  }

  return (
    <form className="add" onSubmit={handleSubmit}>
      <input
        name="title"
        value={title}
        onChange={(e) => setTitle(e.target.value)}
        placeholder="What needs doing?"
      />
      <button type="submit">Add</button>
    </form>
  );
}

type TodoItemProps = {
  todo: Todo;
  onToggle: (todo: Todo) => void;
  onRemove: (todo: Todo) => void;
};

function TodoItem({ todo, onToggle, onRemove }: TodoItemProps) {
  return (
    <li className={todo.done ? "todo done" : "todo"}>
      <label>
        <input
          type="checkbox"
          checked={todo.done}
          onChange={() => onToggle(todo)}
        />
        <span className="title">{todo.title}</span>
      </label>
      <button
        className="delete"
        aria-label={`Delete ${todo.title}`}
        onClick={() => onRemove(todo)}
      >
        ✕
      </button>
    </li>
  );
}

function App({ client }: { client: TodosClient }) {
  const todos = useTodos(client);
  const { state } = todos;

  switch (state.status) {
    case "loading":
      return <p className="status">Loading...</p>;
    case "failed":
      return <p className="error">😿 {state.message}</p>;
    case "ready": {
      const left = state.todos.filter((t) => !t.done).length;
      const empty = state.todos.length + state.adding.length === 0;
      return (
        <main>
          <AddTodoForm onAdd={todos.add} />
          {state.notice !== null && (
            <p className="notice" role="alert">
              <span>{state.notice}</span>
              <button
                aria-label="Dismiss"
                onClick={todos.dismissNotice}
              >
                ✕
              </button>
            </p>
          )}
          {empty && <p className="empty">Nothing to do 🎉</p>}
          <ul className="todos">
            {state.todos.map((todo) => (
              <TodoItem
                key={todo.id}
                todo={todo}
                onToggle={todos.toggle}
                onRemove={todos.remove}
              />
            ))}
            {state.adding.map((title, i) => (
              <li key={`adding-${i}`} className="todo saving">
                <span className="title">{title}</span>
                <small>Saving...</small>
              </li>
            ))}
          </ul>
          <p className="count">
            {left} of {state.todos.length} left to do
          </p>
        </main>
      );
    }
  }
}

// One client for the whole app, created once (not on every render)
const client = createTodosClient();
createRoot(document.getElementById("root")!).render(
  <App client={client} />,
);

## What you built

- A **status union** for the screen, and a reducer whose actions carry everything needed to undo a change.
- **`useTodos`**, a custom hook that loads the list once per client and turns every change into an **optimistic update** with a rollback and a notice.
- Typed components (`AddTodoForm`, `TodoItem`, `App`) that only know the `TodosClient` interface, so the same app runs on a fake server or the real one.
- Loading, error, empty and "Saving..." states for every moment of the app's life.

Together with Parts 1 and 2, that's a complete full-stack TypeScript app: one contract shared by an Express API and a React front end, checked by the compiler on both sides, by schemas at runtime, and by tests against fakes and against a real server.

## Take it further

Ideas for your own copy (create the web app with `npm create vite@latest`, choosing React and TypeScript):

- **Edit titles.** Double-click a title to edit it, and send `update(id, { title })` optimistically. The server trims titles, so use its answer (`"changed"` with `result.value`), not your own copy.
- **Filters.** Add "All", "Open" and "Done" buttons with a `Filter` union, and **derive** the visible list from it instead of storing a second list.
- **Try again.** Give the failed state a "Try again" button, and retry network errors with backoff, using the `withRetry` helper and its injected `sleep` from [Dependency Injection and Fakes](/learn/typescript/dependency-injection-and-fakes).
- **Cancel stale requests.** Let `createApi` accept an `AbortSignal` and abort the list request in the effect's cleanup, like `useFetch` did.
- **Ship it for real.** Set up the workspaces from "Shipping it", put the server on a Node host with a database repository, deploy the web app as static files, and let CI run `tsc --noEmit` and both test suites on every push.
