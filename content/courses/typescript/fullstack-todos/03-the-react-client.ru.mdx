Пора заняться той частью, которую люди действительно видят. 🎨 В этой последней части вы соберёте приложение на React поверх типизированного клиента из части 2. Оно загружает задачи, добавляет, отмечает и удаляет их — и ощущается **мгновенным**: каждое изменение появляется на экране раньше, чем ответит сервер, и тихо откатывается, если сервер скажет «нет».

Вам пригодятся объединения статусов, редьюсеры и собственные хуки из урока [Редьюсеры, контекст и собственные хуки](/learn/typescript/reducers-context-and-hooks), типизированные формы и события из [Состояния, событий и форм](/learn/typescript/state-events-and-forms), типизированные пропсы из [Типизированных компонентов и пропсов](/learn/typescript/typed-components-and-props) и, конечно, `TodosClient`.

## План

```text
App                 пропсы: client     состояние: useTodos(client)
├── (loading)       Загрузка...
├── (failed)        😿 сообщение
└── (ready)
    ├── AddTodoForm   состояние: title   пропсы: onAdd
    ├── уведомление   что пошло не так, с ✕, чтобы его закрыть
    ├── TodoItem      пропсы: todo, onToggle, onRemove   (на каждую задачу)
    └── Сохраняем...  на каждое название, которое идёт на сервер
```

Решения, которые за этим стоят:

- **`App` получает клиент через пропсы (props).** Это снова внедрение зависимостей: настоящее приложение передаёт `createTodosClient()`, а демо или тест могут передать фейк.
- **Всё состояние (state) задач живёт в одном редьюсере (reducer)** внутри собственного хука (custom hook) `useTodos(client)`. Компоненты получают состояние и четыре функции: `add`, `toggle`, `remove` и `dismissNotice`.
- **Изменения оптимистичны.** Сначала меняется экран, потом уходит запрос, и только сбой возвращает всё назад.

## Шаг 1: состояние и его действия

Экран находится в одной из трёх ситуаций, поэтому состояние — это **объединение статусов**, как `FetchState` в уроке про хуки:

- **`loading`**: показывать пока нечего.
- **`failed`**: список не загрузился, есть `message`.
- **`ready`**: задачи `todos` и ещё два поля. `adding` хранит названия, которые идут на сервер, а `notice` объясняет, какое последнее изменение не удалось (или равно `null`).

Каждое изменение — это действие, названное по тому, что произошло, а каждое действие о **сбое** несёт то, что нужно редьюсеру, чтобы отменить изменение: задачу в прежнем виде или название, которое так и не сохранилось. Поскольку редьюсер — это обычный TypeScript, можно проиграть целый сеанс без всякого React:

```ts
// Из shared/ (на деле Todo выводится из TodoSchema)
type Todo = { id: number; title: string; done: boolean };

// ========== web/todos-state.ts ==========
type TodosState =
  | { status: "loading" }
  | { status: "failed"; message: string }
  | {
      status: "ready";
      todos: Todo[];
      adding: string[]; // названия, которые ещё идут на сервер
      notice: string | null; // что не так с последним изменением
    };

type TodosAction =
  | { type: "loaded"; todos: Todo[] }
  | { type: "loadFailed"; message: string }
  | { type: "addStarted"; title: string }
  | { type: "added"; title: string; todo: Todo }
  | { type: "addFailed"; title: string; message: string }
  | { type: "changed"; todo: Todo }
  | { type: "changeFailed"; todo: Todo; message: string }
  | { type: "removed"; id: number }
  | { type: "removeFailed"; todo: Todo; message: string }
  | { type: "noticeDismissed" };

function assertNever(value: never): never {
  throw new Error(`Unhandled action: ${JSON.stringify(value)}`);
}

// Удаляет первую копию title (названия могут совпадать)
function withoutFirst(list: string[], title: string): string[] {
  const index = list.indexOf(title);
  return index === -1 ? list : list.filter((_, i) => i !== index);
}

function replaceTodo(todos: Todo[], todo: Todo): Todo[] {
  return todos.map((t) => (t.id === todo.id ? todo : t));
}

function todosReducer(
  state: TodosState,
  action: TodosAction,
): TodosState {
  switch (action.type) {
    case "loaded":
      return {
        status: "ready",
        todos: action.todos,
        adding: [],
        notice: null,
      };
    case "loadFailed":
      return { status: "failed", message: action.message };
  }
  // Все остальные действия меняют уже загруженный список
  if (state.status !== "ready") return state;

  switch (action.type) {
    case "addStarted":
      return { ...state, adding: [...state.adding, action.title] };
    case "added":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        todos: [...state.todos, action.todo],
      };
    case "addFailed":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        notice: action.message,
      };
    case "changed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
      };
    case "changeFailed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
        notice: action.message,
      };
    case "removed":
      return {
        ...state,
        todos: state.todos.filter((t) => t.id !== action.id),
      };
    case "removeFailed":
      return {
        ...state,
        // Обратно на своё место: список отсортирован по id
        todos: [...state.todos, action.todo].sort(
          (a, b) => a.id - b.id,
        ),
        notice: action.message,
      };
    case "noticeDismissed":
      return { ...state, notice: null };
    default:
      return assertNever(action);
  }
}

// ========== проигрываем сеанс ==========
const nap: Todo = { id: 1, title: "Вздремнуть", done: false };
const tea: Todo = { id: 2, title: "Чай", done: false };

const session: TodosAction[] = [
  { type: "loaded", todos: [nap, tea] },
  { type: "changed", todo: { ...nap, done: true } }, // оптимистично
  { type: "changeFailed", todo: nap, message: "Сервер занят" },
  { type: "removed", id: 1 }, // оптимистично
  { type: "removeFailed", todo: nap, message: "Всё ещё занят" },
  { type: "addStarted", title: "Бамбук" },
];

const show = (t: Todo) => (t.done ? "✓ " : "") + t.title;

let state: TodosState = { status: "loading" };
for (const action of session) {
  state = todosReducer(state, action);
  if (state.status !== "ready") continue;
  console.log(action.type.padEnd(12), state.todos.map(show),
    state.adding, state.notice);
}
```

Этот проигрыш — оптимистичный сеанс в миниатюре: «Вздремнуть» отмечается сразу, сервер отказывает, и `changeFailed` возвращает всё назад; «Вздремнуть» сразу удаляется, сервер снова отказывает, и `removeFailed` возвращает задачу **на её место** (список сервера отсортирован по id, так что сортировка ставит её туда, где она была). Уведомление всегда показывает последнюю проблему.

Несколько деталей типов делают этот редьюсер надёжным:

- **Два switch, одно сужение.** Первый `switch` обрабатывает действия, которые работают в любом состоянии. Затем `if (state.status !== "ready") return state;` сужает `state` до формы ready, так что каждый `case` ниже может пользоваться `state.todos`. TypeScript сузил и `action`: после `return` в первом `switch` он знает, что `action` не может быть `"loaded"` или `"loadFailed"`, поэтому `assertNever` в `default` по-прежнему компилируется.
- **Ожидающие названия — не задачи.** Соблазнительно дать несохранённой задаче временный id вроде `-1` и положить её в `todos`. Но тогда остальной код будет считать её сохранённой: отметьте её — и приложение отправит `PATCH /todos/-1`. Как обычная `string` в отдельном списке она не может быть случайно отмечена или удалена, потому что `toggle` и `remove` принимают `Todo`, а строку компилятор не пропустит. Это снова «сделайте невозможные состояния невозможными».
- **`withoutFirst` убирает одну копию.** Быстро добавьте «Чай» дважды — и в ожидании будут два «Чая»; когда первый сохранится, исчезнуть должен только один из них.

## Шаг 2: загрузка в собственном хуке

`useTodos` владеет редьюсером и общается с клиентом. Вот как он загружает список и добавляет задачу:

```tsx title="web/use-todos.ts"
// ========== web/use-todos.ts ==========
function useTodos(client: TodosClient) {
  const [state, dispatch] = useReducer(todosReducer, {
    status: "loading",
  });

  useEffect(() => {
    let ignore = false; // true, когда эффект уже очищен
    async function load() {
      const result = await client.list();
      if (ignore) return;
      if (result.ok) {
        dispatch({ type: "loaded", todos: result.value });
      } else {
        const message = errorMessage(result.error);
        dispatch({ type: "loadFailed", message });
      }
    }
    load();
    return () => {
      ignore = true;
    };
  }, [client]);

  async function add(title: string) {
    dispatch({ type: "addStarted", title }); // сразу на экране
    const result = await client.create({ title });
    if (result.ok) {
      dispatch({ type: "added", title, todo: result.value });
    } else {
      const message = errorMessage(result.error);
      dispatch({ type: "addFailed", title, message });
    }
  }
  // ...дальше идут toggle, remove и dismissNotice
}
```

- **`useReducer` типизируется редьюсером.** `state` — это `TodosState`, а `dispatch` принимает только `TodosAction`, без единого аргумента типа.
- **Эффект загружает список один раз на клиент.** Если компонент исчезнет до прихода ответа, его функция очистки выставит `ignore`, и опоздавший ответ будет отброшен, а не обновит компонент, которого уже нет. ([Хук `useFetch`](/learn/typescript/reducers-context-and-hooks) делал то же самое с помощью `AbortController`.)
- **`client` — зависимость эффекта**, поэтому при каждом рендере он должен быть **тем же самым** объектом. Создайте его один раз, вне всех компонентов, как вы увидите в шаге 4. Клиент, созданный внутри `App`, был бы новым при каждом рендере, и эффект загружал бы список снова и снова.
- **`add` тоже оптимистичен.** `addStarted` сразу показывает название с пометкой «Сохраняем...», а `added` заменяет его задачей от сервера с настоящим id.

## Шаг 3: оптимистичные обновления с откатом

Запрос занимает 100 мс на хорошем соединении и несколько секунд в поезде. Если галочка ставится только после ответа сервера, приложение кажется сломанным. Но большинство запросов **успешны**, так что результат можно показать сразу и отменить его лишь в редком случае, когда запрос не удался. Это и есть **оптимистичное обновление** (optimistic update):

1. Запомните, как всё было.
2. Сразу измените экран.
3. Отправьте запрос.
4. Если он успешен, возьмите версию сервера. Если нет — верните то, что запомнили, и **сообщите пользователю**: изменение, которое молча исчезает, хуже медленного.

Вот эта идея сама по себе, с фейковым сервером, который думает 1,5 секунды. Поставьте несколько галочек, затем включите **«Сделать вид, что сервер упал»** и попробуйте снова:

`useTodos` делает то же самое через действия редьюсера:

```tsx
  async function toggle(todo: Todo) {
    const done = !todo.done;
    // Оптимистично: показываем изменение до ответа сервера
    dispatch({ type: "changed", todo: { ...todo, done } });
    const result = await client.update(todo.id, { done });
    if (result.ok) {
      dispatch({ type: "changed", todo: result.value });
    } else {
      // Откатываемся к прежней задаче и объясняем почему
      const message = errorMessage(result.error);
      dispatch({ type: "changeFailed", todo, message });
    }
  }
```

`remove` следует тем же шагам, и вы напишете его в упражнении: сразу отправьте действие `"removed"`, вызовите `client.remove`, а если не получилось — отправьте `"removeFailed"` с задачей, чтобы редьюсер мог вернуть её на место.

<Callout type="warning" title="Не каждое изменение должно быть оптимистичным">

Оптимистичные обновления подходят для изменений, которые почти всегда успешны и легко отменяются: галочки, лайки, переименования, удаление из списка. Не используйте их, когда исход решает сервер (оплата, бронирование последнего места, имя пользователя, которое может быть занято) или когда ошибочное «готово!» чего-то стоило бы пользователю. В таких случаях показывайте «Сохраняем...» и ждите ответа.

</Callout>

## Шаг 4: настоящий клиент

Компоненты никогда не импортируют `fetch`, URL или схемы: они знают только `TodosClient`. Поэтому переход с фейка на настоящий клиент — это две строки в самом низу приложения:

```tsx
// Один клиент на всё приложение, создан один раз (не в рендере)
const client = createTodosClient();
createRoot(document.getElementById("root")!).render(
  <App client={client} />,
);
```

`createTodosClient()` общается с учебным API, который заменяет ваш развёрнутый сервер. В настоящем проекте адрес сервера передавался бы из конфигурации сборки, например `createTodosClient({ baseUrl: import.meta.env.VITE_API_URL })` в приложении на Vite. И не забудьте про `!`: `getElementById` возвращает `HTMLElement | null`, и только вы знаете, что `#root` существует.

## Выпускаем приложение

На вашем компьютере три части становятся одним репозиторием с тремя **воркспейсами** (workspaces), так что общий код — это пакет, который импортируют обе стороны:

```text
todo-app/
├── package.json        "workspaces": ["shared", "server", "web"]
├── shared/             schemas.ts, contract.ts      (пакет @todo/shared)
├── server/             Express API + тесты Vitest   (импортирует @todo/shared)
└── web/                Vite + React + тесты         (импортирует @todo/shared)
```

```ts title="web/src/todos-client.ts"
import { TodoSchema, array, nothing } from "@todo/shared/schemas";
import type {
  NewTodo,
  TodoPatch,
  TodosApi,
} from "@todo/shared/contract";
```

`import type` исчезает из скомпилированного кода, так что контракт ничего не стоит браузеру; схемы же — настоящий код, который выполняют обе стороны. Дальше пусть CI проверяет **весь** репозиторий при каждом пуше. Если кто-то изменит контракт, каждое место, которое ему больше не соответствует, на любой стороне, сломает сборку:

```yaml title=".github/workflows/ci.yml"
name: CI
on: [push, pull_request]
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: npm ci
      - run: npx tsc --noEmit -p server && npx tsc --noEmit -p web
      - run: npx vitest run
```

Когда приложение выходит в сеть, меняются две вещи:

- **Сервер и веб-приложение обычно живут по разным адресам** (скажем, `api.example.com` и `todos.example.com`), а браузеры блокируют такие запросы, если сервер их не разрешил заголовками **CORS**. Пакет `cors` делает это одной строкой: `app.use(cors({ origin: "https://todos.example.com" }))`. (Или раздавайте оба с одного адреса, а API — по пути `/api`.)
- **Репозиторий в памяти всё забывает при перезапуске.** Напишите `TodoRepository` на настоящей базе данных (например, SQLite или Postgres) и передайте его в `createApp`. Больше на сервере ничего не меняется, а тесты продолжают пользоваться репозиторием в памяти.

class ValidationError extends Error {
  constructor(path: string, expected: string, got: unknown) {

type Infer<S extends Schema<unknown>> = ReturnType<S["parse"]>;

function primitive<T>(
  expected: string,

): Schema<T> {
  return {

    route: R,
    input: Omit<Api[R], "response">,

    const { params = {}, body }: Omit<Endpoint, "response"> = input;
    const [method, pattern] = route.split(" ");
    const path = pattern.replace(/:(\\w+)/g, (_, name: string) =>
      encodeURIComponent(params[name] ?? ""),
    );
    const init: RequestInit = { method };

      init.body = JSON.stringify(body);
    }

    let res: Response;
    try {
      res = await fetchFn(baseUrl + path, init);

      const message =
        error instanceof Error ? error.message : String(error);
      return { ok: false, error: { kind: "network", message } };

type TodosState =

type TodosAction =
  | { type: "loaded"; todos: Todo[] }
  | { type: "loadFailed"; message: string }
  | { type: "addStarted"; title: string }
  | { type: "added"; title: string; todo: Todo }
  | { type: "addFailed"; title: string; message: string }
  | { type: "changed"; todo: Todo }
  | { type: "changeFailed"; todo: Todo; message: string }
  | { type: "removed"; id: number }
  | { type: "removeFailed"; todo: Todo; message: string }
  | { type: "noticeDismissed" };

function assertNever(value: never): never {
  throw new Error(\`Unhandled action: \${JSON.stringify(value)}\`);

// Удаляет первую копию title (названия могут совпадать)
function withoutFirst(list: string[], title: string): string[] {
  const index = list.indexOf(title);
  return index === -1 ? list : list.filter((_, i) => i !== index);
}

function replaceTodo(todos: Todo[], todo: Todo): Todo[] {
  return todos.map((t) => (t.id === todo.id ? todo : t));
}

function todosReducer(
  state: TodosState,
  action: TodosAction,
): TodosState {
  switch (action.type) {
    case "loaded":
      return {
        status: "ready",
        todos: action.todos,
        adding: [],
        notice: null,
      };
    case "loadFailed":
      return { status: "failed", message: action.message };
  }
  // Все остальные действия меняют уже загруженный список
  if (state.status !== "ready") return state;

  switch (action.type) {
    case "addStarted":
      return { ...state, adding: [...state.adding, action.title] };
    case "added":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        todos: [...state.todos, action.todo],
      };
    case "addFailed":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        notice: action.message,
      };
    case "changed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
      };
    case "changeFailed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
        notice: action.message,
      };
    case "removed":
      return {
        ...state,
        todos: state.todos.filter((t) => t.id !== action.id),
      };
    case "removeFailed":
      return {
        ...state,
        // Обратно на своё место: список отсортирован по id
        todos: [...state.todos, action.todo].sort(
          (a, b) => a.id - b.id,
        ),
        notice: action.message,
      };
    case "noticeDismissed":
      return { ...state, notice: null };
    default:
      return assertNever(action);
  }
}

// ========== web/use-todos.ts ==========
function useTodos(client: TodosClient) {
  const [state, dispatch] = useReducer(todosReducer, {
    status: "loading",
  });

  useEffect(() => {
    let ignore = false; // true, когда эффект уже очищен
    async function load() {
      const result = await client.list();
      if (ignore) return;
      if (result.ok) {
        dispatch({ type: "loaded", todos: result.value });
      } else {
        const message = errorMessage(result.error);
        dispatch({ type: "loadFailed", message });
      }
    }
    load();
    return () => {
      ignore = true;
    };
  }, [client]);

  async function add(title: string) {
    dispatch({ type: "addStarted", title }); // сразу на экране
    const result = await client.create({ title });
    if (result.ok) {
      dispatch({ type: "added", title, todo: result.value });
    } else {
      const message = errorMessage(result.error);
      dispatch({ type: "addFailed", title, message });
    }
  }

  async function toggle(todo: Todo) {
    const done = !todo.done;
    // Оптимистично: показываем изменение до ответа сервера
    dispatch({ type: "changed", todo: { ...todo, done } });
    const result = await client.update(todo.id, { done });
    if (result.ok) {
      dispatch({ type: "changed", todo: result.value });
    } else {
      // Откатываемся к прежней задаче и объясняем почему
      const message = errorMessage(result.error);
      dispatch({ type: "changeFailed", todo, message });
    }
  }

  // TODO 1: оптимистичное удаление с откатом при ошибке
  async function remove(todo: Todo) {}

  function dismissNotice() {
    dispatch({ type: "noticeDismissed" });
  }

  return { state, add, toggle, remove, dismissNotice };
}

class ValidationError extends Error {
  constructor(path: string, expected: string, got: unknown) {
    const where = path || "value";
    super(`${where}: expected ${expected}, got ${JSON.stringify(got)}`);
    this.name = "ValidationError";
  }

type Schema<T> = { parse: (value: unknown, path?: string) => T };
type Infer<S extends Schema<unknown>> = ReturnType<S["parse"]>;

function primitive<T>(
  expected: string,
  test: (value: unknown) => value is T,
): Schema<T> {
  return {
    parse(value, path = "") {
      if (!test(value)) {
        throw new ValidationError(path, expected, value);
      }
      return value;
    },
  };
}

const string = () =>
  primitive("a string", (v): v is string => typeof v === "string");
const number = () =>
  primitive("a number", (v): v is number => typeof v === "number");
const boolean = () =>
  primitive("a boolean", (v): v is boolean => typeof v === "boolean");

function array<T>(item: Schema<T>): Schema<T[]> {
  return {
    parse(value, path = "") {
      if (!Array.isArray(value)) {
        throw new ValidationError(path, "an array", value);
      }
      return value.map((v, i) => item.parse(v, `${path}[${i}]`));
    },
  };
}

function isRecord(value: unknown): value is Record<string, unknown> {
  return (
    typeof value === "object" && value !== null && !Array.isArray(value)
  );
}

type Shape = Record<string, Schema<unknown>>;

function object<S extends Shape>(
  shape: S,
): Schema<{ [K in keyof S]: Infer<S[K]> }> {
  return {
    parse(value, path = "") {
      if (!isRecord(value)) {
        throw new ValidationError(path, "an object", value);
      }
      const result: Record<string, unknown> = {};

      }

    },
  };

type ApiError =
  | { kind: "network"; message: string }
  | { kind: "http"; status: number; message: string }
  | { kind: "invalid"; message: string };

// По схеме на каждый маршрут, сверенной с контрактом
type ResponseSchemas<Api extends Record<keyof Api, Endpoint>> = {
  [R in keyof Api]: Schema<Api[R]["response"]>;
};

type ClientOptions = {
  baseUrl?: string;
  fetch?: typeof fetch;
};

function apiMessage(body: unknown): string | undefined {
  if (isRecord(body) && typeof body.error === "string") {
    return body.error;
  }
  return undefined;
}

function createApi<Api extends Record<keyof Api, Endpoint>>(
  schemas: ResponseSchemas<Api>,
  options: ClientOptions = {},
) {
  const baseUrl = options.baseUrl ?? "https://api.pandadev.test";
  const fetchFn = options.fetch ?? fetch;

  return async function call<R extends keyof Api & string>(
    route: R,
    input: Omit<Api[R], "response">,
  ): Promise<Result<Api[R]["response"], ApiError>> {
    const { params = {}, body }: Omit<Endpoint, "response"> = input;
    const [method, pattern] = route.split(" ");
    const path = pattern.replace(/:(\w+)/g, (_, name: string) =>
      encodeURIComponent(params[name] ?? ""),
    );
    const init: RequestInit = { method };
    if (body !== undefined) {
      init.headers = { "Content-Type": "application/json" };
      init.body = JSON.stringify(body);
    }

    let res: Response;
    try {
      res = await fetchFn(baseUrl + path, init);
    } catch (error) {
      const message =
        error instanceof Error ? error.message : String(error);
      return { ok: false, error: { kind: "network", message } };
    }

    const data: unknown =
      res.status === 204 ? null : await res.json().catch(() => null);
    if (!res.ok) {
      const message = apiMessage(data) ?? `HTTP ${res.status}`;
      return {
        ok: false,
        error: { kind: "http", status: res.status, message },
      };
    }
    try {
      return { ok: true, value: schemas[route].parse(data) };
    } catch (error) {
      if (error instanceof ValidationError) {
        return {
          ok: false,
          error: { kind: "invalid", message: error.message },
        };
      }
      throw error;
    }
  };
}

type TodosState =
  | { status: "loading" }
  | { status: "failed"; message: string }
  | {
      status: "ready";
      todos: Todo[];
      adding: string[]; // названия, которые ещё идут на сервер

type TodosAction =
  | { type: "loaded"; todos: Todo[] }
  | { type: "loadFailed"; message: string }
  | { type: "addStarted"; title: string }
  | { type: "added"; title: string; todo: Todo }
  | { type: "addFailed"; title: string; message: string }
  | { type: "changed"; todo: Todo }
  | { type: "changeFailed"; todo: Todo; message: string }
  | { type: "removed"; id: number }
  | { type: "removeFailed"; todo: Todo; message: string }
  | { type: "noticeDismissed" };

function assertNever(value: never): never {
  throw new Error(`Unhandled action: ${JSON.stringify(value)}`);
}

// Удаляет первую копию title (названия могут совпадать)
function withoutFirst(list: string[], title: string): string[] {
  const index = list.indexOf(title);
  return index === -1 ? list : list.filter((_, i) => i !== index);
}

function replaceTodo(todos: Todo[], todo: Todo): Todo[] {
  return todos.map((t) => (t.id === todo.id ? todo : t));
}

function todosReducer(
  state: TodosState,
  action: TodosAction,
): TodosState {
  switch (action.type) {
    case "loaded":
      return {
        status: "ready",
        todos: action.todos,
        adding: [],
        notice: null,
      };
    case "loadFailed":
      return { status: "failed", message: action.message };
  }
  // Все остальные действия меняют уже загруженный список
  if (state.status !== "ready") return state;

  switch (action.type) {
    case "addStarted":
      return { ...state, adding: [...state.adding, action.title] };
    case "added":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        todos: [...state.todos, action.todo],
      };
    case "addFailed":
      return {
        ...state,
        adding: withoutFirst(state.adding, action.title),
        notice: action.message,
      };
    case "changed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
      };
    case "changeFailed":
      return {
        ...state,
        todos: replaceTodo(state.todos, action.todo),
        notice: action.message,
      };
    case "removed":
      return {
        ...state,
        todos: state.todos.filter((t) => t.id !== action.id),
      };
    case "removeFailed":
      return {
        ...state,
        // Обратно на своё место: список отсортирован по id
        todos: [...state.todos, action.todo].sort(
          (a, b) => a.id - b.id,
        ),
        notice: action.message,
      };
    case "noticeDismissed":
      return { ...state, notice: null };
    default:
      return assertNever(action);
  }
}

// ========== web/use-todos.ts ==========
function useTodos(client: TodosClient) {
  const [state, dispatch] = useReducer(todosReducer, {
    status: "loading",
  });

  useEffect(() => {
    let ignore = false; // true, когда эффект уже очищен
    async function load() {
      const result = await client.list();
      if (ignore) return;
      if (result.ok) {
        dispatch({ type: "loaded", todos: result.value });
      } else {
        const message = errorMessage(result.error);
        dispatch({ type: "loadFailed", message });
      }
    }
    load();
    return () => {
      ignore = true;
    };
  }, [client]);

  async function add(title: string) {
    dispatch({ type: "addStarted", title }); // сразу на экране
    const result = await client.create({ title });
    if (result.ok) {
      dispatch({ type: "added", title, todo: result.value });
    } else {
      const message = errorMessage(result.error);
      dispatch({ type: "addFailed", title, message });
    }
  }

  async function toggle(todo: Todo) {
    const done = !todo.done;
    // Оптимистично: показываем изменение до ответа сервера
    dispatch({ type: "changed", todo: { ...todo, done } });
    const result = await client.update(todo.id, { done });
    if (result.ok) {
      dispatch({ type: "changed", todo: result.value });
    } else {
      // Откатываемся к прежней задаче и объясняем почему
      const message = errorMessage(result.error);
      dispatch({ type: "changeFailed", todo, message });
    }
  }

  async function remove(todo: Todo) {
    dispatch({ type: "removed", id: todo.id }); // оптимистично
    const result = await client.remove(todo.id);
    if (!result.ok) {
      const message = errorMessage(result.error);
      dispatch({ type: "removeFailed", todo, message });
    }
  }

  function dismissNotice() {
    dispatch({ type: "noticeDismissed" });
  }

  return { state, add, toggle, remove, dismissNotice };
}

- **`useTodos`** — собственный хук, который загружает список один раз на клиент и превращает каждое изменение в **оптимистичное обновление** с откатом и уведомлением.
- Типизированные компоненты (`AddTodoForm`, `TodoItem`, `App`), которые знают только интерфейс `TodosClient`, так что одно и то же приложение работает и с фейковым сервером, и с настоящим.
- Состояния загрузки, ошибки, пустого списка и «Сохраняем...» для каждого момента жизни приложения.

Вместе с частями 1 и 2 это законченное full-stack приложение на TypeScript: один контракт, общий для Express API и фронтенда на React, который проверяют компилятор на обеих сторонах, схемы во время выполнения и тесты — и с фейками, и на настоящем сервере.

## Что дальше

Идеи для вашей собственной копии (создайте веб-приложение командой `npm create vite@latest`, выбрав React и TypeScript):

- **Редактирование названий.** По двойному щелчку по названию открывайте редактирование и отправляйте `update(id, { title })` оптимистично. Сервер обрезает названия, поэтому берите его ответ (`"changed"` с `result.value`), а не свою копию.
- **Фильтры.** Добавьте кнопки «Все», «Открытые» и «Готовые» с объединением `Filter` и **вычисляйте** видимый список из него, а не храните второй список.
- **Повторить попытку.** Дайте состоянию сбоя кнопку «Попробовать снова» и повторяйте сетевые ошибки с нарастающей задержкой (backoff) с помощью помощника `withRetry` и его внедрённого `sleep` из [Внедрения зависимостей и фейков](/learn/typescript/dependency-injection-and-fakes).
- **Отмена устаревших запросов.** Научите `createApi` принимать `AbortSignal` и отменяйте запрос списка в функции очистки эффекта, как это делал `useFetch`.
- **Выпустите его по-настоящему.** Настройте воркспейсы из раздела «Выпускаем приложение», разместите сервер на Node-хостинге с репозиторием на базе данных, разверните веб-приложение как статические файлы и пусть CI при каждом пуше запускает `tsc --noEmit` и оба набора тестов.
