До сих пор каждая команда делала что-то одно. Но большинство команд умеют гораздо больше, если попросить: показать скрытые файлы, добавить подробности, поработать с другой папкой. Просят об этом с помощью **опций**. В этом уроке вы узнаете, как устроена любая команда, как выяснить, что она умеет, и как читать сообщения об ошибках. 🧠

## Из чего состоит команда

Командная строка — это несколько слов, разделённых **пробелами**:

```bash
ls -l photos
```

- **`ls`** — это **команда** (command): программа, которую нужно запустить. Она всегда идёт первой.
- **`-l`** — **опция** (option), её ещё называют **флагом** (flag). Она меняет то, **как** работает команда, здесь — «покажи подробности». Опции начинаются с дефиса.
- **`photos`** — **аргумент** (argument): то, **с чем** работает команда, здесь — папка, которую нужно показать.

Аргументы вам уже встречались: в `cd projects` и `echo "Привет"` слова после команды — это аргументы. Обычно порядок такой: команда, потом опции, потом аргументы. Пробелы важны: `ls-l` — одно незнакомое слово, а `ls -l` — команда и опция.

Опции бывают двух видов:

- **Короткие**: один дефис и одна буква, например `-a` или `-l`.
- **Длинные**: два дефиса и целое слово, например `--all` или `--help`. Их легче читать, но дольше набирать.

## Скрытые файлы: ls -a

Имена, которые начинаются с точки, например `.secret` или `.config`, — **скрытые** (hidden): `ls` их не показывает, чтобы не загромождать список. В таких файлах программы хранят свои настройки. Git тоже: вся его история живёт в скрытой папке `.git`, вы увидите её позже в курсе.

Опция **`-a`** (от «all» — «все») показывает и скрытые имена. В этом примере в домашней папке лежат `notes.txt`, папка `photos`, скрытый файл `.secret` и скрытая папка `.config`:

<CodeExample setup={`mkdir -p .config photos
echo "Купить бамбук" > notes.txt
echo "Торт в холодильнике" > .secret
touch photos/beach.jpg`} output={`notes.txt  photos
.  ..  .config  .secret  notes.txt  photos`}>

```bash
ls
ls -a
```

</CodeExample>

`ls -a` показывает ещё `.` и `..` — имена «эта папка» и «уровнем выше» из прошлого урока. `--all` — длинная форма `-a`, так что `ls --all` напечатает то же самое. На некоторых компьютерах скрытые имена стоят не в начале, а вперемешку с остальными; сами имена от этого не меняются.

## Подробности: ls -l

Опция **`-l`** (от «long» — «длинный») выводит по строке на каждое имя, с подробностями:

<CodeExample setup={`mkdir -p .config photos
echo "Купить бамбук" > notes.txt
echo "Торт в холодильнике" > .secret
touch photos/beach.jpg`} output={`total 8
-rw-r--r-- 1 panda panda   26 Jan  5 09:00 notes.txt
drwxr-xr-x 2 panda panda 4096 Jan  5 09:00 photos`}>

```bash
ls -l
```

</CodeExample>

Разберём строку `notes.txt` слева направо:

| Часть          | Что значит                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| `-rw-r--r--`   | Первый символ — тип: `-` для файла, `d` для каталога (directory). Остальное — права доступа.               |
| `1`            | Число ссылок на файл. На него можно не обращать внимания.                                                  |
| `panda`        | **Владелец** (owner): пользователь, которому принадлежит файл.                                             |
| `panda`        | **Группа** (group), к которой он относится.                                                                |
| `26`           | **Размер** в байтах. В `Купить бамбук` 13 символов, но каждая русская буква занимает 2 байта, плюс невидимый перенос строки. |
| `Jan  5 09:00` | Когда файл последний раз меняли.                                                                           |
| `notes.txt`    | Имя.                                                                                                       |

Строка `total` вверху — это занятое место на диске, её тоже можно пропустить. Права доступа (кто может читать, менять или запускать файл) будут позже в курсе. На вашем компьютере числа и даты будут другими, но столбцы те же.

## Несколько опций сразу

Можно передать несколько опций одновременно, а короткие — склеить за одним дефисом. Все эти команды делают одно и то же:

```bash
ls -l -a
ls -la
ls -al
```

Опции и аргументы тоже работают вместе. `ls -la photos` показывает подробности обо всём в `photos`, включая скрытые файлы:

<CodeExample setup={`mkdir -p .config photos
echo "Купить бамбук" > notes.txt
echo "Торт в холодильнике" > .secret
touch photos/beach.jpg`} output={`total 8
drwxr-xr-x 2 panda panda 4096 Jan  5 09:00 .
drwxr-xr-x 4 panda panda 4096 Jan  5 09:00 ..
-rw-r--r-- 1 panda panda    0 Jan  5 09:00 beach.jpg`}>

```bash
ls -la photos
```

</CodeExample>

У `beach.jpg` 0 байт, потому что это пустой учебный файл.

## Где взять справку

Все опции не помнит никто. Разработчики постоянно их подсматривают, и вам тоже стоит:

- **`ls --help`**: большинство команд с `--help` печатают краткую справку по своим опциям.
- **`help`**: в учебном терминале выводит все команды, которые он знает, с главными опциями.
- **`git help`**: выводит команды Git.

<CodeExample output={`Usage: ls [-a] [-A] [-l] [-F] [path] list a folder (-a: hidden files too, -l: details)`}>

```bash
ls --help
```

</CodeExample>

<Callout type="note" title="На вашем компьютере">

В Linux и в Git Bash `ls --help` печатает длинный список опций. На Mac `ls` не знает `--help`; там пользуйтесь **`man ls`** — эта команда открывает полное руководство (выйти — клавиша **q**). А в настоящем bash `help` показывает только встроенные команды самой оболочки, вроде `cd`, а не все программы.

</Callout>

## history: что я запускал?

**`history`** выводит пронумерованный список команд, которые вы запускали. В учебном терминале это команды текущего запуска:

<CodeExample output={`/home/panda
panda
    1  pwd
    2  whoami
    3  history`}>

```bash
pwd
whoami
history
```

</CodeExample>

На вашем компьютере история сохраняется между сеансами. Нажмите **стрелку вверх**, и последняя команда вернётся: её можно поправить и нажать Enter, не набирая заново.

## Как читать сообщения об ошибках

Когда что-то идёт не так, сообщение обычно состоит из трёх частей: **кто** жалуется, **что** пошло не так и иногда **что попробовать**.

<CodeExample setup={`mkdir -p .config photos
echo "Купить бамбук" > notes.txt
echo "Торт в холодильнике" > .secret
touch photos/beach.jpg`} output={`ls: cannot access 'photo': No such file or directory
ls: invalid option -- 'z'
Try 'ls --help' for more information.`}>

```bash
ls photo
ls -z
```

</CodeExample>

- `ls:` в начале говорит, что жалуется `ls`, а не оболочка.
- **`No such file or directory`**: здесь нет `photo`. Ошибка в **аргументе** (правильно `photos`).
- **`invalid option -- 'z'`** («недопустимая опция»): у `ls` нет опции `-z`. Ошибка в **опции**, и следующая строка подсказывает, куда смотреть: `ls --help`.

Сообщение говорит, какую часть команды исправить. Прочитайте его спокойно, прежде чем что-то менять.

<Callout type="warning" title="Частые ошибки">

- Нет пробела между частями: `ls-a` или `ls -lphotos`.
- Пробел внутри опции: `ls - a`. Дефис и буква пишутся слитно.
- Один дефис у длинной опции: `-all` означает `-a -l -l`, а не `--all`.
- Угадывать опцию вместо того, чтобы заглянуть в `--help` или `man`.

</Callout>

## Итоги

- Командная строка — это **команда**, потом **опции** (флаги, начинаются с `-` или `--`), которые меняют её работу, потом **аргументы**: то, с чем она работает. Части разделяются пробелами.
- `ls -a` показывает скрытые имена (они начинаются с точки), а `ls -l` — подробности: тип и права, владельца, размер, дату и имя.
- Короткие опции склеиваются: `ls -la` — это `ls -l -a`.
- `--help`, `help` и (на вашем компьютере) `man` рассказывают, что умеет команда. `history` показывает, что вы запускали.
- Сообщение об ошибке говорит, кто жалуется и что не так: `No such file or directory` — про имя, `invalid option` — про опцию.
