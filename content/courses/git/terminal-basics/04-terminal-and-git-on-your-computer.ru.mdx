Учебный терминал отлично подходит для учёбы: ничего не нужно устанавливать и ничего нельзя сломать. Но настоящие проекты будут жить на вашем компьютере, так что рано или поздно терминал и Git понадобятся и там. В этом уроке разберёмся, как их получить и как **представиться Git** — это первое, что все делают после установки. 💻

<Callout type="tip" title="Шаги, которые делаются на вашем компьютере">

Разделы с пометкой **На вашем компьютере** выполняются в настоящем терминале, а не на этой странице. Можно пройти их сейчас, а можно пропустить и вернуться позже: весь курс работает в браузере. Упражнение в конце, как обычно, выполняется в учебном терминале.

</Callout>

## На вашем компьютере: открываем терминал

**macOS.** Откройте приложение **Терминал** (Terminal): нажмите **⌘ + пробел**, наберите `Терминал` или `Terminal` и нажмите Enter (ещё оно лежит в «Программы» → «Утилиты»). Оболочка там — **zsh**, а приглашение заканчивается на `%`, например `panda@MacBook ~ %`. Все команды этого курса работают в ней так же.

**Windows.** Собственные оболочки Windows (командная строка и PowerShell) используют другие команды. Для этого курса берите **Git Bash**: это bash с теми же командами, что и в учебном терминале, и он ставится вместе с Git для Windows (см. следующий раздел). После установки откройте **Git Bash** из меню «Пуск». В его приглашении видно ваше имя, `MINGW64` и путь, а `$` стоит на следующей строке.

Есть ещё **WSL** (Windows Subsystem for Linux, подсистема Windows для Linux): она запускает полноценный Linux внутри Windows. Открывают её в приложении **Windows Terminal**. Позже, для профессиональной работы, это отличный вариант, но начать проще с Git Bash.

**Linux.** Откройте приложение **Терминал** из меню программ. В Ubuntu и многих других системах его открывает сочетание **Ctrl + Alt + T**. Оболочка там обычно bash.

## На вашем компьютере: устанавливаем Git

Сначала проверьте, может быть, Git уже установлен. Наберите и нажмите Enter:

```bash
git --version
```

Если команда напечатала номер версии, переходите к следующему разделу. Если она ответила `command not found`, установите Git:

**macOS.** Проще всего установить инструменты командной строки Apple (Command Line Tools), в них уже есть Git. Часто `git --version` сам предлагает их установить; если нет, выполните:

```bash
xcode-select --install
```

Если вы пользуетесь менеджером пакетов Homebrew, подойдёт и `brew install git` — так вы получите более новую версию Git.

**Windows.** Зайдите на [git-scm.com](https://git-scm.com), скачайте **Git for Windows** и запустите установщик. Настройки по умолчанию подойдут. Заодно установится и **Git Bash**.

**Linux.** Воспользуйтесь менеджером пакетов своей системы. В Ubuntu или Debian:

```bash
sudo apt install git
```

В Fedora выполните `sudo dnf install git`. **`sudo`** запускает команду от имени администратора компьютера, поэтому спрашивает ваш пароль. Пока вы его набираете, на экране ничего не появляется, даже точек. Это нормально: наберите пароль и нажмите Enter.

## Проверяем, что Git работает

Закройте терминал, откройте новый и снова выполните `git --version`. В учебном терминале это выглядит так:

<CodeExample output={`git version 2.47.1`}>

```bash
git --version
```

</CodeExample>

У вас номер, скорее всего, будет другим. Для этого курса подойдёт любая свежая версия.

## Представьтесь Git

Git сохраняет каждую версию проекта как **коммит** (commit), и каждый коммит записывает, **кто его сделал**: имя и email. Так команда видит, кто что поменял, и через несколько уроков вы увидите эти имена в истории. Поэтому до первого коммита сообщите Git свои данные с помощью **`git config`**:

<CodeExample output={`Мэй Линь
user.name=Мэй Линь
user.email=mei@example.com`}>

```bash
git config --global user.name "Мэй Линь"
git config --global user.email "mei@example.com"
git config --global user.name
git config --list
```

</CodeExample>

- `git config --global user.name "Мэй Линь"` сохраняет ваше **имя**. Кавычки держат два слова вместе. Как и `cd`, при успехе команда ничего не печатает.
- `git config --global user.email "mei@example.com"` сохраняет ваш **email**.
- **`--global`** значит «для меня, во **всех** проектах на этом компьютере». Это делается один раз на каждом компьютере.
- `git config --global user.name` без значения **читает** настройку.
- **`git config --list`** показывает все ваши настройки, по одной `ключ=значение` в строке.

На вашем компьютере `git config --list` покажет больше строк: у Git есть и другие настройки, а установщик может добавить свои. Если список не помещается на экране и внизу видно `:`, нажмите **q**, чтобы вернуться.

<Callout type="note" title="Какой email указать?">

Укажите email, которым будете пользоваться на GitHub или в команде, чтобы коммиты были связаны с вами. Если не хотите показывать свой адрес, GitHub может выдать вам специальный адрес «noreply», и его можно указать здесь. Git никогда не проверяет email и ничего на него не отправляет: адрес просто записывается в ваши коммиты.

</Callout>

### Частая ошибка: забыть кавычки

Без кавычек имя с пробелом обрезается. Здесь Git берёт `Мэй` как имя, а `Линь` теряется:

<CodeExample output={`Мэй`}>

```bash
git config --global user.name Мэй Линь
git config --global user.name
```

</CodeExample>

Если так случилось, просто выполните команду ещё раз, с кавычками: новое значение заменит старое.

В учебном терминале настройки живут только один запуск, как и всё остальное. В следующих уроках коммиты делает готовый пользователь по имени **Panda**, так что задавать имя каждый раз не придётся. А на вашем компьютере настройки `--global` сохраняются, пока вы их не поменяете.

## Итоги

- **На вашем компьютере**: Терминал в macOS (zsh), **Git Bash** в Windows (ставится вместе с Git for Windows), приложение Терминал в Linux (Ctrl + Alt + T в Ubuntu).
- Git устанавливается через `xcode-select --install` или `brew install git` (macOS), установщик с git-scm.com (Windows) или `sudo apt install git` / `sudo dnf install git` (Linux). Проверка — `git --version`.
- Каждый коммит записывает, кто его сделал, поэтому один раз на каждом компьютере выполните `git config --global user.name "Ваше Имя"` и `git config --global user.email "you@example.com"`.
- `--global` значит «во всех проектах на этом компьютере». `git config --global user.name` читает настройку, `git config --list` показывает все.
- Берите в кавычки значения с пробелами, иначе Git сохранит только первое слово.
