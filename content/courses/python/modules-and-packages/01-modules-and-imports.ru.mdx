**Модуль (module)** — это просто файл Python с кодом, который можно переиспользовать. Вместе с Python поставляются сотни модулей — это **стандартная библиотека (standard library)**, «батарейки в комплекте». Нужна математика, даты, случайные числа или подсчёт? Кто-то уже всё написал. Вам остаётся только **импортировать (import)** нужное. 🔋

## import

`import math` загружает модуль `math`. Дальше его содержимым пользуются через точку: `math.something`.

<CodeExample output={`9.0
5 4
3.1416
5.0`}>

```python
import math

print(math.sqrt(81))
print(math.ceil(4.2), math.floor(4.8))
print(round(math.pi, 4))
print(math.dist((0, 0), (3, 4)))
```

</CodeExample>

`ceil` округляет **вверх**, `floor` — **вниз**, а `dist` измеряет расстояние между двумя точками.

## from … import и as

Есть три распространённых способа импорта:

```python
import math                       # пишем math.sqrt(...)
from math import sqrt, pi         # пишем sqrt(...) и pi напрямую
import statistics as stats        # короткое прозвище: stats.mean(...)
```

- **`from module import name`** подключает конкретные имена, и префикс больше не нужен.
- **`as`** даёт модулю (или имени) прозвище.

<CodeExample output={`80.8
88
88
12.0`}>

```python
import statistics as stats
from math import sqrt

scores = [72, 95, 88, 61, 88]
print(stats.mean(scores))
print(stats.median(scores))
print(stats.mode(scores))
print(sqrt(144))
```

</CodeExample>

<Callout type="tip" title="Какой стиль выбрать?">

`import math` — самый понятный: любой, кто видит `math.sqrt`, знает, откуда это взялось. `from … import` используйте для нескольких имён, которые встречаются часто. Избегайте `from math import *`: такая строка вываливает в ваш файл всё подряд, и становится трудно понять, откуда берутся имена. Все импорты пишите в **начале** файла.

</Callout>

## Экскурсия по стандартной библиотеке

### random

Модуль `random` выбирает что-нибудь случайно. Вывод меняется при каждом запуске, поэтому здесь просто пример кода:

```python
import random

print(random.randint(1, 6))            # бросок кубика, например 4
print(random.choice(["камень", "ножницы", "бумага"]))
print(random.random())                 # дробное число от 0 до 1

cards = ["A", "K", "Q", "J"]
random.shuffle(cards)                  # перемешивает сам список
print(cards)                           # например ['Q', 'A', 'J', 'K']
```

Если сначала вызвать `random.seed(42)`, «случайные» результаты будут одинаковыми при каждом запуске — это удобно для тестирования.

### datetime

`datetime` работает с датами и временем. `date.today()` возвращает сегодняшнюю дату; здесь мы берём фиксированные даты, чтобы вывод не менялся:

<CodeExample output={`2026-10-01
01 October 2026
Thursday
30`}>

```python
from datetime import date, timedelta

start = date(2026, 9, 1)
deadline = start + timedelta(days=30)

print(deadline)
print(deadline.strftime("%d %B %Y"))
print(deadline.strftime("%A"))
print((deadline - start).days)
```

</CodeExample>

- `timedelta(days=30)` — это промежуток времени, который можно прибавить к дате или вычесть из неё.
- Разность двух дат — это `timedelta`; `.days` — количество дней.
- `strftime` форматирует дату: `%d` — день, `%B` — название месяца, `%Y` — год, `%A` — день недели. По умолчанию названия месяцев и дней недели выводятся по-английски.
- `date.fromisoformat("2026-09-01")` превращает текст в дату.

### collections: Counter и defaultdict

**`Counter`** считает за вас. **`defaultdict`** — это словарь, который сам создаёт начальное значение (например, пустой список), когда вы впервые обращаетесь к новому ключу:

<CodeExample output={`3 0
[('панда', 3), ('ест', 2)]
{'п': ['панда', 'панда', 'панда'], 'е': ['ест', 'ест'], 'б': ['бамбук'], 'и': ['и', 'и'], 'я': ['яблоко'], 'с': ['спит']}`}>

```python
from collections import Counter, defaultdict

words = "панда ест бамбук и панда ест яблоко и панда спит".split()

counts = Counter(words)
print(counts["панда"], counts["киви"])
print(counts.most_common(2))

by_letter = defaultdict(list)
for word in words:
    by_letter[word[0]].append(word)
print(dict(by_letter))
```

</CodeExample>

Отсутствующий ключ в `Counter` даёт `0`, а не `KeyError`, а `defaultdict(list)` избавляет от необходимости каждый раз писать `if key not in d: d[key] = []`.

## Пишем собственный модуль

Любой файл `.py` — это модуль. Положите несколько функций в `helpers.py`:

```python title="helpers.py"
def shout(text):
    return text.upper() + "!"

def average(numbers):
    return sum(numbers) / len(numbers)
```

Затем в другом файле **в той же папке** импортируйте его по имени файла без `.py`:

```python title="main.py"
import helpers
from helpers import average

print(helpers.shout("привет"))    # ПРИВЕТ!
print(average([2, 4, 6]))         # 4.0
```

Запустите `python main.py`, и Python найдёт `helpers.py` рядом. Если разбить большую программу на модули, каждый файл останется коротким и сосредоточенным на одной задаче.

<Callout type="note" title="Один файл на PandaDev">

Здешний редактор запускает **один файл** за раз, поэтому импортировать свой `helpers.py` в браузере не получится. Модули стандартной библиотеки вроде `math` и `json` работают без проблем. Версию из двух файлов попробуйте на своём компьютере.

</Callout>

## Запуск или импорт: `if __name__ == "__main__":`

Когда Python импортирует модуль, он **выполняет весь файл**. Если бы в конце `helpers.py` стоял `print("testing...")`, он печатал бы это при каждом импорте! Решение — специальная проверка.

У каждого модуля есть переменная (variable) `__name__`. Когда вы **запускаете** файл напрямую, она равна `"__main__"`. Когда файл **импортируют**, в ней имя модуля, например `"helpers"`.

<CodeExample output={`__main__
Запущен как программа: ПРИВЕТ!`}>

```python
def shout(text):
    return text.upper() + "!"

def main():
    print(f"Запущен как программа: {shout('привет')}")

print(__name__)

if __name__ == "__main__":
    main()
```

</CodeExample>

Код внутри `if __name__ == "__main__":` выполняется, только когда вы запускаете **именно этот** файл. Когда его импортирует другой файл, вы получаете `shout` и `main`, но ничего не запускается само по себе. Этот шаблон встречается почти в каждом скрипте на Python.

## Исследуем модули с dir() и help()

**`dir(module)`** перечисляет все имена внутри модуля. Это быстрый способ осмотреться:

<CodeExample output="['fabs', 'factorial', 'floor', 'fma', 'fmod', 'frexp', 'fsum']">

```python
import math

print([name for name in dir(math) if name.startswith("f")])
```

</CodeExample>

**`help()`** печатает документацию модуля или функции. Удобнее всего пользоваться им в интерактивной оболочке Python на своём компьютере:

```python
import math
help(math.floor)
# floor(x, /)
#     Return the floor of x as an Integral.
```

<Hint>

`Counter` умеет складывать числа: `totals[topic] += minutes`. Тогда `totals.most_common(1)[0][0]` — самая популярная тема. Для дат превратите каждую текстовую дату в `date` через `date.fromisoformat(text)`, затем вычтите `min(...)` из `max(...)` и возьмите `.days`.

</Hint>

<Solution>

```python
from collections import Counter
from datetime import date

log = [
    ("2026-09-01", "python", 30),
    ("2026-09-02", "математика", 45),
    ("2026-09-04", "python", 25),
    ("2026-09-07", "рисование", 20),
    ("2026-09-08", "python", 40),
]

def minutes_by_topic(log):
    totals = Counter()
    for day, topic, minutes in log:
        totals[topic] += minutes
    return dict(totals)

def top_topic(log):
    totals = Counter(minutes_by_topic(log))
    return totals.most_common(1)[0][0]

def days_spanned(log):
    dates = [date.fromisoformat(day) for day, _, _ in log]
    return (max(dates) - min(dates)).days

print(minutes_by_topic(log))
print(top_topic(log))
print(days_spanned(log))
```

</Solution>

## Итоги

- **Модуль** — это файл `.py`; в **стандартной библиотеке** сотни готовых модулей.
- `import math`, `from math import sqrt`, `import statistics as stats`.
- Полезные модули: `math`, `random`, `datetime`, `collections` (`Counter`, `defaultdict`), `statistics`.
- Свой файл `helpers.py` импортируется через `import helpers`.
- Код под `if __name__ == "__main__":` выполняется, только когда файл запущен напрямую.
- `dir()` показывает, что лежит внутри модуля; `help()` выводит его документацию.
