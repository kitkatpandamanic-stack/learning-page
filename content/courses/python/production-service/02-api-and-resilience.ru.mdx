В части 1 вы построили ядро PandaLink: объекты-значения, `LinkService` и репозиторий в памяти — всё быстрое и полностью покрытое тестами. Но пользоваться им пока никто не может. В этой части ядро встречается с внешним миром. 🌐

Всё, что мы добавим, — это **адаптеры (adapters)** вокруг ядра, ровно как обещала [Чистая архитектура](/learn/python/clean-architecture): домен и сервис не изменятся ни на строчку. Мы добавим:

- **SQL-репозиторий**, который реализует тот же порт, что и репозиторий в памяти;
- слой **cache-aside** с TTL перед ним — для быстрых перенаправлений ([Проектирование систем](/learn/python/designing-systems));
- **ограничитель частоты запросов (rate limiter) на token bucket** для каждого клиента ([Шаблоны отказоустойчивости](/learn/python/resilience-patterns));
- **API-ключи**, которые хранятся в виде хешей ([Безопасный код](/learn/python/secure-coding), [Аутентификация и авторизация в API](/learn/python/auth-for-apis));
- **приложение FastAPI** с перенаправлениями, проверками работоспособности и **структурированными логами** ([Контейнеры и развёртывание](/learn/python/containers-and-deployment)).

## SQL-репозиторий

SQL-адаптер превращает строки таблицы `LinkRow` в объекты `ShortLink`, точно как это делал `SqlProductRepository`. (В примерах этой части доменные классы упрощены, чтобы их было легче читать; в упражнении будут настоящие.)

<CodeExample output={`занят: k3Xp9Qa
ShortLink https://pandas.org 3
None True`}>

```python
from dataclasses import dataclass
from datetime import datetime

from sqlalchemy import String, create_engine, text, update
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, mapped_column, sessionmaker,
)
from sqlalchemy.pool import StaticPool

class CodeTaken(Exception):
    pass

@dataclass
class ShortLink:                 # упрощено: str вместо
    code: str                    # ShortCode и TargetUrl
    url: str
    created_at: datetime
    expires_at: datetime | None = None
    clicks: int = 0

class Base(DeclarativeBase):
    pass

class LinkRow(Base):
    __tablename__ = "links"
    code: Mapped[str] = mapped_column(String(16), primary_key=True)
    url: Mapped[str] = mapped_column(String(2048))
    created_at: Mapped[datetime]
    expires_at: Mapped[datetime | None]
    clicks: Mapped[int] = mapped_column(default=0)

class SqlLinkRepository:
    def __init__(self, session_factory):
        self.session_factory = session_factory

    def get(self, code):
        with self.session_factory() as session:
            row = session.get(LinkRow, code)
            if row is None:
                return None
            return ShortLink(row.code, row.url, row.created_at,
                             row.expires_at, row.clicks)

    def add(self, link):
        with self.session_factory() as session:
            session.add(LinkRow(
                code=link.code, url=link.url,
                created_at=link.created_at,
                expires_at=link.expires_at, clicks=link.clicks,
            ))
            try:
                session.commit()
            except IntegrityError:
                raise CodeTaken(link.code) from None

    def record_click(self, code):
        with self.session_factory() as session:
            session.execute(
                update(LinkRow)
                .where(LinkRow.code == code)
                .values(clicks=LinkRow.clicks + 1)
            )
            session.commit()

    def ping(self) -> bool:
        with self.session_factory() as session:
            return session.execute(text("SELECT 1")).scalar() == 1

engine = create_engine(
    "sqlite://", poolclass=StaticPool,
    connect_args={"check_same_thread": False},
)
Base.metadata.create_all(engine)
repo = SqlLinkRepository(sessionmaker(engine))

now = datetime(2026, 1, 1, 12, 0)
repo.add(ShortLink("k3Xp9Qa", "https://pandas.org", now))
try:
    repo.add(ShortLink("k3Xp9Qa", "https://evil.example", now))
except CodeTaken as error:
    print("занят:", error)
for _ in range(3):
    repo.record_click("k3Xp9Qa")
link = repo.get("k3Xp9Qa")
print(type(link).__name__, link.url, link.clicks)
print(repo.get("nope123"), repo.ping())
```

</CodeExample>

Три решения стоит рассмотреть подробнее:

- **Каждый метод — одна короткая транзакция (transaction).** В уроке о чистой архитектуре репозиторий никогда не делал commit: когда сценарий использования завершён, решала **единица работы (unit of work)**. Здесь каждый сценарий меняет ровно **одну** ссылку, а агрегат и так является границей транзакции, поэтому репозиторий открывает сессию, делает своё единственное дело и фиксирует изменения. Это сознательное упрощение. Если какому-то будущему сценарию понадобится менять две ссылки вместе (скажем, «поменять местами два псевдонима»), единицу работы придётся вернуть.
- **Ошибки инфраструктуры становятся доменными ошибками.** SQLAlchemy выбрасывает `IntegrityError`, когда первичный ключ уже занят. Сервис не должен ничего знать о SQLAlchemy, поэтому адаптер переводит эту ошибку в `CodeTaken` — ту, что обещал порт. Гонку из части 1 теперь закрывает сама база данных.
- **Клики считаются в базе данных**: `UPDATE links SET clicks = clicks + 1` — одна атомарная инструкция, поэтому засчитываются оба клика, даже если они пришли одновременно. `ping()` выполняет `SELECT 1` через **`text()`**, который оборачивает фиксированную строку SQL (никогда не собранную из пользовательского ввода) для проверки готовности.

Как и в [итоговом проекте уровня 2](/learn/python/the-endpoints), базе SQLite в памяти нужны `StaticPool` и `check_same_thread=False`, чтобы все сессии и рабочие потоки FastAPI использовали одно соединение. С PostgreSQL не понадобится ни то, ни другое.

## Cache-aside перед репозиторием

При 3 500 перенаправлениях в секунду мы не хотим, чтобы база данных каждый раз отвечала на вопрос «куда ведёт `k3Xp9Qa`?». Кэш — это ещё один класс с **теми же методами, что у порта**, который оборачивает любой репозиторий. Сервис не видит разницы: он просто получает более быстрый репозиторий. Это паттерн **«декоратор» (decorator)** — объект, который оборачивает другой объект с тем же интерфейсом и добавляет поведение, — и это класс `CacheAside` из урока о проектировании систем, приспособленный для ссылок.

`FakeClock` получает один новый метод, `time()`, который возвращает секунды, как `time.monotonic()` в продакшене, — так кэш и ограничитель частоты могут пользоваться теми же тестовыми часами, что и сервис:

<CodeExample output={`чтений из базы: 1 | попаданий: 4
кликов видно: 5
после TTL чтений из базы: 2
None None 4`}>

```python
from dataclasses import dataclass, replace
from datetime import datetime, timedelta

@dataclass
class ShortLink:
    code: str
    url: str
    clicks: int = 0

class FakeClock:
    def __init__(self, now: datetime):
        self.now = now

    def __call__(self) -> datetime:
        return self.now

    def advance(self, **kwargs) -> None:
        self.now += timedelta(**kwargs)

    def time(self) -> float:          # секунды, как time.monotonic
        return self.now.timestamp()

class SlowRepository:                  # изображает базу данных
    def __init__(self):
        self.links = {"k3Xp9Qa": ShortLink("k3Xp9Qa", "https://a.io")}
        self.reads = 0

    def get(self, code):
        self.reads += 1
        link = self.links.get(code)
        return replace(link) if link else None

    def record_click(self, code):
        self.links[code].clicks += 1

class CachedLinkRepository:
    """Cache-aside с TTL перед любым LinkRepository."""

    def __init__(self, inner, ttl, clock):
        self.inner = inner
        self.ttl = ttl
        self.clock = clock
        self.hits = 0
        self.misses = 0
        self._entries = {}      # код -> (ссылка, expires_at)

    def get(self, code):
        now = self.clock()
        entry = self._entries.get(code)
        if entry is not None and now < entry[1]:
            self.hits += 1
            return replace(entry[0])
        self.misses += 1
        link = self.inner.get(code)
        if link is not None:
            self._entries[code] = (replace(link), now + self.ttl)
        return link

    def add(self, link):
        self.inner.add(link)

    def record_click(self, code):
        self.inner.record_click(code)
        if code in self._entries:            # не даём копии отстать
            self._entries[code][0].clicks += 1

clock = FakeClock(datetime(2026, 1, 1, 12, 0))
db = SlowRepository()
cache = CachedLinkRepository(db, ttl=60, clock=clock.time)

for _ in range(5):
    cache.get("k3Xp9Qa")
    cache.record_click("k3Xp9Qa")
print("чтений из базы:", db.reads, "| попаданий:", cache.hits)
print("кликов видно:", cache.get("k3Xp9Qa").clicks)
clock.advance(seconds=60)
cache.get("k3Xp9Qa")
print("после TTL чтений из базы:", db.reads)
print(cache.get("nope123"), cache.get("nope123"), db.reads)
```

</CodeExample>

Пять перенаправлений стоят **одного** чтения из базы данных. Через 60 секунд TTL запись истекает, и следующий запрос загружает её заново. Важные детали:

- **Истёкшие ссылки всё равно истекают.** Кэш хранит ссылку целиком, вместе с `expires_at`, а сервис при каждом перенаправлении проверяет её по своим часам. Кэш на 60 секунд не может продлить жизнь мёртвой ссылке.
- **Промахи не кэшируются** (`nope123` дважды дошёл до базы данных). Кэшировать «не найдено» (**негативное кэширование, negative caching**) — рабочий приём против сканеров, но ему нужен свой короткий TTL, иначе совсем новый псевдоним мог бы выглядеть несуществующим, пока запись не истечёт.
- **Клики**: `record_click` пишет в базу данных и заодно обновляет нашу копию в кэше, так что на этом сервере статистика остаётся верной. Если серверов несколько, у каждого свой кэш, и копия на другом сервере может отставать до 60 секунд. Это и есть строчка «счётчики кликов могут отставать», которую мы записали в дизайн-документ.
- `get` возвращает **копии**, чтобы никто снаружи не мог случайно изменить объект в кэше.

В продакшене словаря на процесс недостаточно: каждый воркер прогревал бы собственный кэш. В части 3 класс той же формы переедет в **Redis**, общий для всех серверов.

## Ограничение частоты запросов для каждого клиента

Создание ссылок — это запись, а открытый эндпоинт для записи — приглашение для спама. Мы даём каждому клиенту **token bucket** («ведро с токенами»): всплеск до `capacity` запросов, который пополняется со скоростью `per_second`. `RateLimiter` хранит по ведру на имя клиента, создаёт его при первом обращении и сообщает клиентам, сколько нужно подождать:

<CodeExample output={`mei: [True, True, True, False]
kai: [True, True]
повторить через 2 с
mei: [True, False]`}>

```python
import math
from datetime import datetime, timedelta

class FakeClock:
    def __init__(self, now: datetime):
        self.now = now

    def advance(self, **kwargs) -> None:
        self.now += timedelta(**kwargs)

    def time(self) -> float:
        return self.now.timestamp()

class TokenBucket:                   # из урока про отказоустойчивость
    def __init__(self, capacity, per_second, clock):
        self.capacity = capacity
        self.per_second = per_second
        self.clock = clock
        self.tokens = capacity
        self.updated = clock()

    def allow(self):
        now = self.clock()
        earned = (now - self.updated) * self.per_second
        self.tokens = min(self.capacity, self.tokens + earned)
        self.updated = now
        if self.tokens >= 1:
            self.tokens -= 1
            return True
        return False

class RateLimiter:
    """Своё ведро токенов (token bucket) у каждого клиента."""

    def __init__(self, capacity, per_second, clock):
        self.capacity = capacity
        self.per_second = per_second
        self.clock = clock
        self._buckets: dict[str, TokenBucket] = {}

    def allow(self, client: str) -> bool:
        bucket = self._buckets.get(client)
        if bucket is None:
            bucket = TokenBucket(self.capacity, self.per_second,
                                 self.clock)
            self._buckets[client] = bucket
        return bucket.allow()

    @property
    def retry_after(self) -> int:
        return math.ceil(1 / self.per_second)

clock = FakeClock(datetime(2026, 1, 1, 12, 0))
limiter = RateLimiter(capacity=3, per_second=0.5, clock=clock.time)

print("mei:", [limiter.allow("mei") for _ in range(4)])
print("kai:", [limiter.allow("kai") for _ in range(2)])
print("повторить через", limiter.retry_after, "с")
clock.advance(seconds=2)
print("mei:", [limiter.allow("mei") for _ in range(2)])
```

</CodeExample>

Четвёртый запрос Mei отклонён, а у Kai, другого клиента, ведро всё ещё полное. Две секунды при 0,5 токена в секунду дают ровно один новый токен. Когда запрос отклонён, API отвечает **429 Too Many Requests** с заголовком **`Retry-After`** (здесь — 2 секунды), чтобы добросовестные клиенты знали, когда вернуться, а не долбили нас запросами.

Мы ограничиваем **создание** ссылок, а не перенаправления: популярная ссылка вполне законно может получать тысячи кликов в секунду. Защищать перенаправления от потоков запросов — работа обратного прокси или CDN перед приложением.

## API-ключи

Создавать ссылки могут только известные клиенты. Каждый клиент получает **API-ключ** — длинную случайную строку из `secrets.token_urlsafe(32)`, которую ему показывают **один раз**. Мы храним только её **хеш SHA-256**: как вы видели в уроке «Безопасный код», быстрый хеш годится для длинных случайных токенов (в отличие от паролей), и тогда утечка базы данных не раздаёт рабочие ключи. Чтобы проверить запрос, хешируем присланный ключ и ищем этот хеш.

Клиенты отправляют ключ стандартным способом, `Authorization: Bearer <key>`, поэтому мы снова берём `HTTPBearer` из урока об аутентификации в API. Новый инструмент FastAPI здесь один: приложение, созданное **фабрикой (factory)**, хранит свои объекты в **`app.state`**, а зависимость может добраться до них, объявив параметр типа **`Request`** (FastAPI передаёт туда текущий запрос, а `request.app` — это приложение):

<CodeExample output={`43 64
401
{'client': 'panda-blog'}
{'client': 'test-client'}`}>

```python
import hashlib
import secrets

from fastapi import Depends, FastAPI, HTTPException, Request
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from fastapi.testclient import TestClient

def hash_key(api_key: str) -> str:
    return hashlib.sha256(api_key.encode()).hexdigest()

new_key = secrets.token_urlsafe(32)   # показываем клиенту ОДИН раз
print(len(new_key), len(hash_key(new_key)))

bearer = HTTPBearer(auto_error=False)

def current_client(
    request: Request,
    creds: HTTPAuthorizationCredentials | None = Depends(bearer),
) -> str:
    keys = request.app.state.api_keys
    client = keys.get(hash_key(creds.credentials)) if creds else None
    if client is None:
        raise HTTPException(401, "Invalid or missing API key",
                            headers={"WWW-Authenticate": "Bearer"})
    return client

def create_app(api_keys: dict[str, str]) -> FastAPI:
    app = FastAPI()
    app.state.api_keys = api_keys       # хеш sha256 -> клиент

    @app.get("/whoami")
    def whoami(client: str = Depends(current_client)):
        return {"client": client}

    return app

app = create_app({hash_key(new_key): "panda-blog"})
client = TestClient(app)
print(client.get("/whoami").status_code)
good = {"Authorization": f"Bearer {new_key}"}
print(client.get("/whoami", headers=good).json())

app.dependency_overrides[current_client] = lambda: "test-client"
print(client.get("/whoami").json())
app.dependency_overrides.clear()
```

</CodeExample>

Так мы получаем лучшее из обоих миров: `create_app(...)` получает все нужные ему объекты (внедрение через конструктор, никаких глобальных переменных), а небольшие **функции-провайдеры (provider functions)** вроде `current_client` и `get_service` читают их из `app.state`. Эндпоинты по-прежнему используют `Depends`, поэтому тесты могут подменить любой провайдер через `app.dependency_overrides`, как показывает последний запрос, — удобно, чтобы тестировать эндпоинты, не настраивая ключи.

## Перенаправления, ошибки и логи

Теперь самый важный эндпоинт: `GET /{code}`. Он публичный, он должен быть быстрым, и он отвечает кодом **307** с заголовком `Location` через **`RedirectResponse`** из FastAPI. Вот его общий вид — с крошечным сервисом-заглушкой и JSON-форматтером логов из урока «Контейнеры и развёртывание»:

<CodeExample output={`{"level": "INFO", "msg": "redirect", "code": "k3Xp9Qa"}
307 https://pandas.org
410
{'detail': 'Link not found'}`}>

```python
import json
import logging
import sys

from fastapi import Depends, FastAPI, HTTPException, Request
from fastapi.responses import RedirectResponse
from fastapi.testclient import TestClient

class JsonFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        entry = {"level": record.levelname, "msg": record.getMessage()}
        entry.update(getattr(record, "fields", {}))
        return json.dumps(entry)

handler = logging.StreamHandler(sys.stdout)
handler.setFormatter(JsonFormatter())
logging.basicConfig(level=logging.INFO, handlers=[handler],
                    force=True)
logging.getLogger("httpx").setLevel(logging.WARNING)  # потише
log = logging.getLogger("pandalink")

class LinkNotFound(Exception):
    pass

class LinkExpired(Exception):
    pass

class TinyService:                    # вместо LinkService
    def __init__(self, links: dict[str, str | None]):
        self.links = links

    def resolve(self, code: str) -> str:
        if code not in self.links:
            raise LinkNotFound(code)
        if self.links[code] is None:
            raise LinkExpired(code)
        return self.links[code]

def get_service(request: Request) -> TinyService:
    return request.app.state.service

def create_app(service: TinyService) -> FastAPI:
    app = FastAPI(title="PandaLink")
    app.state.service = service

    @app.get("/{code}")
    def follow(code: str,
               links: TinyService = Depends(get_service)):
        try:
            url = links.resolve(code)
        except LinkNotFound:
            raise HTTPException(404, "Link not found")
        except LinkExpired:
            raise HTTPException(410, "Link expired")
        log.info("redirect", extra={"fields": {"code": code}})
        return RedirectResponse(url, status_code=307)

    return app

app = create_app(TinyService({"k3Xp9Qa": "https://pandas.org",
                              "old1234": None}))
client = TestClient(app)
r = client.get("/k3Xp9Qa", follow_redirects=False)
print(r.status_code, r.headers["location"])
print(client.get("/old1234").status_code)
print(client.get("/nope123").json())
```

</CodeExample>

- **`TestClient` следует за перенаправлениями** по умолчанию, как браузер, а значит, попытался бы на самом деле загрузить `https://pandas.org`. `follow_redirects=False` останавливается на нашем 307, чтобы тест мог проверить код ответа и заголовок `Location`.
- `/{code}` совпадает ровно с **одним** сегментом пути, поэтому `/links/abc1234` и `/health/ready` до него никогда не доходят. Как раз из-за односегментных имён вроде `/docs` часть 1 сделала зарезервированными `docs`, `redoc`, `links` и `health`.
- `logging.getLogger("httpx").setLevel(logging.WARNING)` приглушает HTTP-библиотеку, которая стоит за `TestClient` и пишет в лог каждый запрос на уровне INFO. Приглушать шумные библиотеки — обычная часть настройки логирования.

У каждой доменной ошибки ровно один HTTP-ответ, и решается это на границе:

| Что выбрасывает ядро | HTTP-ответ |
| --- | --- |
| `ValueError` (плохой URL, псевдоним или ttl) | 422 Unprocessable Content |
| `CodeTaken` | 409 Conflict |
| `LinkNotFound` | 404 Not Found |
| `LinkExpired` | 410 Gone |
| нет API-ключа или он неверный | 401 Unauthorized |
| пустое ведро токенов | 429 Too Many Requests + `Retry-After` |

<Callout type="warning" title="Следите за тем, что пишете в лог">

class LinkService:
    def __init__(self, repo: LinkRepository, clock: Clock,
                 make_code: Callable[[], str] = random_code,
                 max_attempts: int = 5):
        self.repo = repo
        self.clock = clock
        self.make_code = make_code
        self.max_attempts = max_attempts

    def shorten(self, url: str, alias: str | None = None,
                ttl_days: int | None = None) -> ShortLink:
        target = TargetUrl(url)
        if ttl_days is not None and ttl_days < 1:
            raise ValueError("ttl_days must be at least 1")
        now = self.clock()
        expires = None
        if ttl_days:
            expires = now + timedelta(days=ttl_days)
        attempts = 1 if alias else self.max_attempts
        for attempt in range(attempts):
            code = ShortCode(alias or self.make_code())
            link = ShortLink(code, target, now, expires)
            try:
                self.repo.add(link)
                return link
            except CodeTaken:
                if attempt == attempts - 1:
                    raise

    def _find(self, raw_code: str) -> ShortLink:
        try:
            code = ShortCode(raw_code)
        except ValueError:
            raise LinkNotFound(raw_code) from None
        link = self.repo.get(code)
        if link is None:
            raise LinkNotFound(raw_code)
        return link

    def resolve(self, raw_code: str) -> str:
        link = self._find(raw_code)
        if link.is_expired(self.clock()):
            raise LinkExpired(raw_code)
        self.repo.record_click(link.code)
        return link.url.value

    def stats(self, raw_code: str) -> ShortLink:
        return self._find(raw_code)

class SqlLinkRepository:
    """Одна короткая транзакция на вызов: ссылка — один агрегат."""

    def __init__(self, session_factory):
        self.session_factory = session_factory

    def get(self, code):
        with self.session_factory() as session:
            row = session.get(LinkRow, code.value)
            if row is None:
                return None
            return ShortLink(ShortCode(row.code), TargetUrl(row.url),
                             row.created_at, row.expires_at,
                             row.clicks)

    def add(self, link):
        with self.session_factory() as session:
            session.add(LinkRow(
                code=link.code.value, url=link.url.value,
                created_at=link.created_at,
                expires_at=link.expires_at, clicks=link.clicks,
            ))
            try:
                session.commit()
            except IntegrityError:
                raise CodeTaken(link.code.value) from None

    def record_click(self, code):
        with self.session_factory() as session:
            session.execute(
                update(LinkRow)
                .where(LinkRow.code == code.value)
                .values(clicks=LinkRow.clicks + 1)
            )
            session.commit()

    def ping(self) -> bool:
        with self.session_factory() as session:
            return session.execute(text("SELECT 1")).scalar() == 1


class CachedLinkRepository:
    """Cache-aside с TTL перед любым LinkRepository."""

    def __init__(self, inner, ttl: float,
                 clock: Callable[[], float]):
        self.inner = inner
        self.ttl = ttl
        self.clock = clock
        self.hits = 0
        self.misses = 0
        self._entries = {}      # код -> (ссылка, expires_at)

    def get(self, code):
        now = self.clock()
        entry = self._entries.get(code)
        if entry is not None and now < entry[1]:
            self.hits += 1
            return replace(entry[0])
        self.misses += 1
        link = self.inner.get(code)
        if link is not None:
            self._entries[code] = (replace(link), now + self.ttl)
        return link

    def add(self, link):
        self.inner.add(link)

    def record_click(self, code):
        self.inner.record_click(code)
        if code in self._entries:            # не даём копии отстать
            self._entries[code][0].clicks += 1


class TokenBucket:
    def __init__(self, capacity, per_second, clock):
        self.capacity = capacity
        self.per_second = per_second
        self.clock = clock
        self.tokens = capacity
        self.updated = clock()

    def allow(self):
        now = self.clock()
        earned = (now - self.updated) * self.per_second
        self.tokens = min(self.capacity, self.tokens + earned)
        self.updated = now
        if self.tokens >= 1:
            self.tokens -= 1
            return True
        return False


class RateLimiter:
    """Своё ведро токенов (token bucket) у каждого клиента."""

    def __init__(self, capacity: int, per_second: float,
                 clock: Callable[[], float]):
        self.capacity = capacity
        self.per_second = per_second
        self.clock = clock
        self._buckets: dict[str, TokenBucket] = {}

    def allow(self, client: str) -> bool:
        bucket = self._buckets.get(client)
        if bucket is None:
            bucket = TokenBucket(self.capacity, self.per_second,
                                 self.clock)
            self._buckets[client] = bucket
        return bucket.allow()

    @property
    def retry_after(self) -> int:
        return math.ceil(1 / self.per_second)

class LinkService:
    def __init__(self, repo: LinkRepository, clock: Clock,
                 make_code: Callable[[], str] = random_code,
                 max_attempts: int = 5):
        self.repo = repo
        self.clock = clock
        self.make_code = make_code
        self.max_attempts = max_attempts

    def shorten(self, url: str, alias: str | None = None,
                ttl_days: int | None = None) -> ShortLink:
        target = TargetUrl(url)
        if ttl_days is not None and ttl_days < 1:
            raise ValueError("ttl_days must be at least 1")
        now = self.clock()
        expires = None
        if ttl_days:
            expires = now + timedelta(days=ttl_days)
        attempts = 1 if alias else self.max_attempts
        for attempt in range(attempts):
            code = ShortCode(alias or self.make_code())
            link = ShortLink(code, target, now, expires)
            try:
                self.repo.add(link)
                return link
            except CodeTaken:
                if attempt == attempts - 1:
                    raise

    def _find(self, raw_code: str) -> ShortLink:
        try:
            code = ShortCode(raw_code)
        except ValueError:
            raise LinkNotFound(raw_code) from None
        link = self.repo.get(code)
        if link is None:
            raise LinkNotFound(raw_code)
        return link

    def resolve(self, raw_code: str) -> str:
        link = self._find(raw_code)
        if link.is_expired(self.clock()):
            raise LinkExpired(raw_code)
        self.repo.record_click(link.code)
        return link.url.value

    def stats(self, raw_code: str) -> ShortLink:
        return self._find(raw_code)

    request: Request, client: str = Depends(current_client)

    return client

               api_keys: dict[str, str],
               check_db: Callable[[], bool]) -> FastAPI:

    app.state.service = service
    app.state.limiter = limiter
    app.state.api_keys = api_keys       # хеш sha256 -> клиент

    @app.get("/health/live")
    def live():
        return {"status": "ok"}

    @app.get("/health/ready")
    def ready():
        try:
            ok = check_db()
        except Exception:
            ok = False
        if not ok:
            return JSONResponse(
                {"status": "unavailable"}, status_code=503
            )
        return {"status": "ok"}

    @app.post("/links", status_code=201, response_model=LinkOut)
    def create_link(body: LinkIn, links: ServiceDep,
                    client: LimitedClientDep):
        try:
            link = links.shorten(body.url, body.alias, body.ttl_days)
        except CodeTaken:
            raise HTTPException(409, "That code is taken")
        except ValueError as error:
            raise HTTPException(422, str(error))
        log.info("link created", extra={"fields": {
            "code": link.code.value, "client": client}})
        return to_out(link)

    @app.get("/links/{code}", response_model=LinkOut)
    def link_stats(code: str, links: ServiceDep, client: ClientDep):
        try:
            return to_out(links.stats(code))
        except LinkNotFound:
            raise HTTPException(404, "Link not found")

    @app.get("/{code}")
    def follow(code: str, links: ServiceDep):
        try:
            url = links.resolve(code)
        except LinkNotFound:
            raise HTTPException(404, "Link not found")
        except LinkExpired:
            raise HTTPException(410, "Link expired")
        log.info("redirect", extra={"fields": {"code": code}})
        return RedirectResponse(url, status_code=307)

    return app

## Что вы построили

- **`SqlLinkRepository`**, у которого каждый вызов — одна короткая транзакция, который переводит `IntegrityError` в `CodeTaken` и считает клики одним атомарным `UPDATE`, — проверенный **контрактным тестом**, общим с репозиторием в памяти.
- Декоратор **`CachedLinkRepository`**: cache-aside с TTL и внедрёнными часами, без негативного кэширования и с честной пометкой в дизайн-документе об отстающей статистике.
- **`RateLimiter`** с отдельным token bucket для каждого клиента, который отвечает **429** с `Retry-After`.
- **API-ключи**, созданные через `secrets`, хранящиеся как хеши SHA-256 и проверяемые зависимостью с `HTTPBearer`.
- **Фабрику приложения**, которая получает все нужные ей объекты, хранит их в `app.state`, сопоставляет каждой доменной ошибке один HTTP-статус, перенаправляет с кодом **307**, пишет **JSON-логи** и отвечает на проверки **живости и готовности (liveness and readiness)**.

PandaLink теперь работает от начала до конца — в тестах. В **части 3** мы подготовим его к настоящему трафику: конфигурация из окружения, корень композиции, Docker, CI, мониторинг и нагрузочные тесты. 🚀
