In Part 1 you built PandaLink's core: value objects, a `LinkService` and an in-memory repository, all fast and fully tested. But nobody can use it yet. In this part the core meets the outside world. 🌐

Everything we add is an **adapter** around the core, exactly as [Clean Architecture](/learn/python/clean-architecture) promised: the domain and the service don't change by a single line. We'll add:

- a **SQL repository** that implements the same port as the in-memory one,
- a **cache-aside** layer with a TTL in front of it, for fast redirects ([Designing Systems](/learn/python/designing-systems)),
- a **token-bucket rate limiter** per client ([Resilience Patterns](/learn/python/resilience-patterns)),
- **API keys**, stored hashed ([Secure Coding](/learn/python/secure-coding), [Auth for APIs](/learn/python/auth-for-apis)),
- the **FastAPI app** with redirects, health checks and **structured logs** ([Containers and Deployment](/learn/python/containers-and-deployment)).

## A SQL repository

The SQL adapter maps a `LinkRow` table to `ShortLink` objects, just like `SqlProductRepository` did. (The examples in this part shorten the domain classes to keep them readable; the exercise has the real ones.)

<CodeExample output={`taken: k3Xp9Qa
ShortLink https://pandas.org 3
None True`}>

```python
from dataclasses import dataclass
from datetime import datetime

from sqlalchemy import String, create_engine, text, update
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, mapped_column, sessionmaker,
)
from sqlalchemy.pool import StaticPool

class CodeTaken(Exception):
    pass

@dataclass
class ShortLink:                 # shortened: str instead of
    code: str                    # ShortCode and TargetUrl
    url: str
    created_at: datetime
    expires_at: datetime | None = None
    clicks: int = 0

class Base(DeclarativeBase):
    pass

class LinkRow(Base):
    __tablename__ = "links"
    code: Mapped[str] = mapped_column(String(16), primary_key=True)
    url: Mapped[str] = mapped_column(String(2048))
    created_at: Mapped[datetime]
    expires_at: Mapped[datetime | None]
    clicks: Mapped[int] = mapped_column(default=0)

class SqlLinkRepository:
    def __init__(self, session_factory):
        self.session_factory = session_factory

    def get(self, code):
        with self.session_factory() as session:
            row = session.get(LinkRow, code)
            if row is None:
                return None
            return ShortLink(row.code, row.url, row.created_at,
                             row.expires_at, row.clicks)

    def add(self, link):
        with self.session_factory() as session:
            session.add(LinkRow(
                code=link.code, url=link.url,
                created_at=link.created_at,
                expires_at=link.expires_at, clicks=link.clicks,
            ))
            try:
                session.commit()
            except IntegrityError:
                raise CodeTaken(link.code) from None

    def record_click(self, code):
        with self.session_factory() as session:
            session.execute(
                update(LinkRow)
                .where(LinkRow.code == code)
                .values(clicks=LinkRow.clicks + 1)
            )
            session.commit()

    def ping(self) -> bool:
        with self.session_factory() as session:
            return session.execute(text("SELECT 1")).scalar() == 1

engine = create_engine(
    "sqlite://", poolclass=StaticPool,
    connect_args={"check_same_thread": False},
)
Base.metadata.create_all(engine)
repo = SqlLinkRepository(sessionmaker(engine))

now = datetime(2026, 1, 1, 12, 0)
repo.add(ShortLink("k3Xp9Qa", "https://pandas.org", now))
try:
    repo.add(ShortLink("k3Xp9Qa", "https://evil.example", now))
except CodeTaken as error:
    print("taken:", error)
for _ in range(3):
    repo.record_click("k3Xp9Qa")
link = repo.get("k3Xp9Qa")
print(type(link).__name__, link.url, link.clicks)
print(repo.get("nope123"), repo.ping())
```

</CodeExample>

Three design choices are worth a closer look:

- **Each method is one short transaction.** In the Clean Architecture lesson the repository never committed: a **unit of work** decided when a use case was done. Here every use case changes exactly **one** link, and an aggregate is a transaction boundary anyway, so the repository opens a session, does its one thing and commits. That's a deliberate simplification. If a future use case had to change two links together (say, "swap two aliases"), you'd bring the unit of work back.
- **Infrastructure errors become domain errors.** SQLAlchemy raises `IntegrityError` when the primary key is already taken. The service mustn't know about SQLAlchemy, so the adapter translates it into `CodeTaken`, the error the port promised. The race from Part 1 is now closed by the database itself.
- **Clicks are counted in the database**: `UPDATE links SET clicks = clicks + 1` is one atomic statement, so two clicks arriving together are both counted. `ping()` runs `SELECT 1` through **`text()`**, which wraps a fixed SQL string (never one built from user input) for the readiness check.

As in the [Level 2 capstone](/learn/python/the-endpoints), the in-memory SQLite database needs `StaticPool` and `check_same_thread=False` so that every session, and FastAPI's worker threads, share one connection. With PostgreSQL you'd need neither.

## Cache-aside in front of the repository

At 3,500 redirects per second we don't want the database answering "where does `k3Xp9Qa` go?" every time. The cache is another class with the **same methods as the port**, wrapping any repository. The service can't tell the difference: it just gets a faster repository. This is the **decorator** pattern (an object that wraps another with the same interface and adds behaviour), and it's the `CacheAside` class from Designing Systems, specialised for links.

`FakeClock` learns one new method, `time()`, which returns seconds like `time.monotonic()` does in production, so the cache and the rate limiter can share the test clock with the service:

<CodeExample output={`database reads: 1 | hits: 4
clicks seen: 5
after the TTL, database reads: 2
None None 4`}>

```python
from dataclasses import dataclass, replace
from datetime import datetime, timedelta

@dataclass
class ShortLink:
    code: str
    url: str
    clicks: int = 0

class FakeClock:
    def __init__(self, now: datetime):
        self.now = now

    def __call__(self) -> datetime:
        return self.now

    def advance(self, **kwargs) -> None:
        self.now += timedelta(**kwargs)

    def time(self) -> float:          # seconds, like time.monotonic
        return self.now.timestamp()

class SlowRepository:                  # stands in for the database
    def __init__(self):
        self.links = {"k3Xp9Qa": ShortLink("k3Xp9Qa", "https://a.io")}
        self.reads = 0

    def get(self, code):
        self.reads += 1
        link = self.links.get(code)
        return replace(link) if link else None

    def record_click(self, code):
        self.links[code].clicks += 1

class CachedLinkRepository:
    """Cache-aside with a TTL, in front of any LinkRepository."""

    def __init__(self, inner, ttl, clock):
        self.inner = inner
        self.ttl = ttl
        self.clock = clock
        self.hits = 0
        self.misses = 0
        self._entries = {}      # code -> (link, expires_at)

    def get(self, code):
        now = self.clock()
        entry = self._entries.get(code)
        if entry is not None and now < entry[1]:
            self.hits += 1
            return replace(entry[0])
        self.misses += 1
        link = self.inner.get(code)
        if link is not None:
            self._entries[code] = (replace(link), now + self.ttl)
        return link

    def add(self, link):
        self.inner.add(link)

    def record_click(self, code):
        self.inner.record_click(code)
        if code in self._entries:            # keep our copy close
            self._entries[code][0].clicks += 1

clock = FakeClock(datetime(2026, 1, 1, 12, 0))
db = SlowRepository()
cache = CachedLinkRepository(db, ttl=60, clock=clock.time)

for _ in range(5):
    cache.get("k3Xp9Qa")
    cache.record_click("k3Xp9Qa")
print("database reads:", db.reads, "| hits:", cache.hits)
print("clicks seen:", cache.get("k3Xp9Qa").clicks)
clock.advance(seconds=60)
cache.get("k3Xp9Qa")
print("after the TTL, database reads:", db.reads)
print(cache.get("nope123"), cache.get("nope123"), db.reads)
```

</CodeExample>

Five redirects cost **one** database read. After the 60-second TTL the entry expires and the next request reloads it. Some details that matter:

- **Expired links still expire.** The cache stores the whole link, including `expires_at`, and the service checks it with its own clock on every redirect. A 60-second cache can't keep a dead link alive.
- **Misses are not cached** (`nope123` hit the database twice). Caching "not found" (**negative caching**) is a valid trick against scanners, but it needs its own short TTL; otherwise a brand-new alias could look missing until the entry expired.
- **Clicks**: `record_click` writes through to the database and also updates our cached copy, so stats stay right on this server. With several servers, each has its own cache, and another server's copy may be up to 60 seconds behind. That's the "click counts may lag" line we wrote into the design doc.
- `get` returns **copies**, so nobody outside can change the cached object by accident.

In production, a per-process dict isn't enough: every worker would warm its own cache. In Part 3 the same class shape moves into **Redis**, shared by all servers.

## Rate limiting per client

Creating links is a write, and an open write endpoint is an invitation for spam. We give each client a **token bucket**: a burst of `capacity` requests, refilled at `per_second`. `RateLimiter` keeps one bucket per client name, created on first use, and tells clients how long to wait:

<CodeExample output={`mei: [True, True, True, False]
kai: [True, True]
retry after 2 seconds
mei: [True, False]`}>

```python
import math
from datetime import datetime, timedelta

class FakeClock:
    def __init__(self, now: datetime):
        self.now = now

    def advance(self, **kwargs) -> None:
        self.now += timedelta(**kwargs)

    def time(self) -> float:
        return self.now.timestamp()

class TokenBucket:                   # from Resilience Patterns
    def __init__(self, capacity, per_second, clock):
        self.capacity = capacity
        self.per_second = per_second
        self.clock = clock
        self.tokens = capacity
        self.updated = clock()

    def allow(self):
        now = self.clock()
        earned = (now - self.updated) * self.per_second
        self.tokens = min(self.capacity, self.tokens + earned)
        self.updated = now
        if self.tokens >= 1:
            self.tokens -= 1
            return True
        return False

class RateLimiter:
    """One token bucket per client."""

    def __init__(self, capacity, per_second, clock):
        self.capacity = capacity
        self.per_second = per_second
        self.clock = clock
        self._buckets: dict[str, TokenBucket] = {}

    def allow(self, client: str) -> bool:
        bucket = self._buckets.get(client)
        if bucket is None:
            bucket = TokenBucket(self.capacity, self.per_second,
                                 self.clock)
            self._buckets[client] = bucket
        return bucket.allow()

    @property
    def retry_after(self) -> int:
        return math.ceil(1 / self.per_second)

clock = FakeClock(datetime(2026, 1, 1, 12, 0))
limiter = RateLimiter(capacity=3, per_second=0.5, clock=clock.time)

print("mei:", [limiter.allow("mei") for _ in range(4)])
print("kai:", [limiter.allow("kai") for _ in range(2)])
print("retry after", limiter.retry_after, "seconds")
clock.advance(seconds=2)
print("mei:", [limiter.allow("mei") for _ in range(2)])
```

</CodeExample>

Mei's fourth request is refused while Kai, a different client, still has a full bucket. Two seconds at 0.5 tokens per second earn exactly one new token. When a request is refused, the API answers **429 Too Many Requests** with a **`Retry-After`** header (here, 2 seconds), so well-behaved clients know when to come back instead of hammering us.

We limit **creating** links, not redirects: a popular link may legitimately get thousands of clicks a second. Protecting redirects from floods is the job of the reverse proxy or CDN in front of the app.

## API keys

Only known clients may create links. Each client gets an **API key**, a long random string from `secrets.token_urlsafe(32)`, shown to them **once**. We store only its **SHA-256 hash**: as you saw in Secure Coding, a fast hash is fine for long random tokens (unlike passwords), and a database leak then doesn't hand out working keys. To check a request, hash the key it sent and look the hash up.

Clients send the key the standard way, `Authorization: Bearer <key>`, so we reuse `HTTPBearer` from Auth for APIs. There's one new FastAPI tool: an app built by a **factory** keeps its objects on **`app.state`**, and a dependency can reach them by declaring a parameter of type **`Request`** (FastAPI passes in the current request, and `request.app` is the app):

<CodeExample output={`43 64
401
{'client': 'panda-blog'}
{'client': 'test-client'}`}>

```python
import hashlib
import secrets

from fastapi import Depends, FastAPI, HTTPException, Request
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from fastapi.testclient import TestClient

def hash_key(api_key: str) -> str:
    return hashlib.sha256(api_key.encode()).hexdigest()

new_key = secrets.token_urlsafe(32)   # shown to the client ONCE
print(len(new_key), len(hash_key(new_key)))

bearer = HTTPBearer(auto_error=False)

def current_client(
    request: Request,
    creds: HTTPAuthorizationCredentials | None = Depends(bearer),
) -> str:
    keys = request.app.state.api_keys
    client = keys.get(hash_key(creds.credentials)) if creds else None
    if client is None:
        raise HTTPException(401, "Invalid or missing API key",
                            headers={"WWW-Authenticate": "Bearer"})
    return client

def create_app(api_keys: dict[str, str]) -> FastAPI:
    app = FastAPI()
    app.state.api_keys = api_keys       # sha256 hash -> client

    @app.get("/whoami")
    def whoami(client: str = Depends(current_client)):
        return {"client": client}

    return app

app = create_app({hash_key(new_key): "panda-blog"})
client = TestClient(app)
print(client.get("/whoami").status_code)
good = {"Authorization": f"Bearer {new_key}"}
print(client.get("/whoami", headers=good).json())

app.dependency_overrides[current_client] = lambda: "test-client"
print(client.get("/whoami").json())
app.dependency_overrides.clear()
```

</CodeExample>

This gives us the best of both worlds: `create_app(...)` receives every object it needs (constructor injection, no globals), and small **provider functions** like `current_client` and `get_service` read them from `app.state`. Because endpoints still use `Depends`, tests can swap any provider with `app.dependency_overrides`, as the last request shows: handy for testing endpoints without setting up keys.

## Redirects, errors and logs

Now the most important endpoint: `GET /{code}`. It's public, it must be fast, and it answers with a **307** and a `Location` header, using FastAPI's **`RedirectResponse`**. Here's the shape of it, with a tiny stand-in service and the JSON log formatter from Containers and Deployment:

<CodeExample output={`{"level": "INFO", "msg": "redirect", "code": "k3Xp9Qa"}
307 https://pandas.org
410
{'detail': 'Link not found'}`}>

```python
import json
import logging
import sys

from fastapi import Depends, FastAPI, HTTPException, Request
from fastapi.responses import RedirectResponse
from fastapi.testclient import TestClient

class JsonFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        entry = {"level": record.levelname, "msg": record.getMessage()}
        entry.update(getattr(record, "fields", {}))
        return json.dumps(entry)

handler = logging.StreamHandler(sys.stdout)
handler.setFormatter(JsonFormatter())
logging.basicConfig(level=logging.INFO, handlers=[handler],
                    force=True)
logging.getLogger("httpx").setLevel(logging.WARNING)  # quieter
log = logging.getLogger("pandalink")

class LinkNotFound(Exception):
    pass

class LinkExpired(Exception):
    pass

class TinyService:                    # stands in for LinkService
    def __init__(self, links: dict[str, str | None]):
        self.links = links

    def resolve(self, code: str) -> str:
        if code not in self.links:
            raise LinkNotFound(code)
        if self.links[code] is None:
            raise LinkExpired(code)
        return self.links[code]

def get_service(request: Request) -> TinyService:
    return request.app.state.service

def create_app(service: TinyService) -> FastAPI:
    app = FastAPI(title="PandaLink")
    app.state.service = service

    @app.get("/{code}")
    def follow(code: str,
               links: TinyService = Depends(get_service)):
        try:
            url = links.resolve(code)
        except LinkNotFound:
            raise HTTPException(404, "Link not found")
        except LinkExpired:
            raise HTTPException(410, "Link expired")
        log.info("redirect", extra={"fields": {"code": code}})
        return RedirectResponse(url, status_code=307)

    return app

app = create_app(TinyService({"k3Xp9Qa": "https://pandas.org",
                              "old1234": None}))
client = TestClient(app)
r = client.get("/k3Xp9Qa", follow_redirects=False)
print(r.status_code, r.headers["location"])
print(client.get("/old1234").status_code)
print(client.get("/nope123").json())
```

</CodeExample>

- **`TestClient` follows redirects** by default, like a browser, so it would try to fetch `https://pandas.org` for real. `follow_redirects=False` stops at our 307 so the test can check the status and the `Location` header.
- `/{code}` matches exactly **one** path segment, so `/links/abc1234` and `/health/ready` never reach it. One-segment names like `/docs` are why Part 1 made `docs`, `redoc`, `links` and `health` reserved.
- `logging.getLogger("httpx").setLevel(logging.WARNING)` quiets the HTTP library behind `TestClient`, which logs every request at INFO. Turning down noisy libraries is a normal part of setting up logging.

Each domain error has exactly one HTTP answer, decided at the edge:

| Raised by the core | HTTP answer |
| --- | --- |
| `ValueError` (bad URL, alias or ttl) | 422 Unprocessable Content |
| `CodeTaken` | 409 Conflict |
| `LinkNotFound` | 404 Not Found |
| `LinkExpired` | 410 Gone |
| missing or wrong API key | 401 Unauthorized |
| empty token bucket | 429 Too Many Requests + `Retry-After` |

<Callout type="warning" title="Be careful what you log">

Log the **code** and the **client name**, never the API key, and think twice before logging target URLs: people shorten links to password-reset pages and private documents, often with tokens in the query string. A log line is copied to more systems, and kept longer, than almost anything else you store.

</Callout>

## Wiring and testing the app

The finished `create_app` receives everything from outside: `create_app(service, limiter, api_keys, check_db)`. It puts the first three on `app.state` and uses `check_db` for `/health/ready`, so tests can build the whole app with fakes and a `FakeClock`, and Part 3 can build it with the real things:

```python
@pytest.fixture
def app(clock):
    codes = iter(["abc1234", "xyz9876", "Qq77777", "Pp55555"])

                                clock=clock.time)

    limiter = RateLimiter(capacity=3, per_second=0.5,
                          clock=clock.time)
    return create_app(service, limiter,
                      {hash_key(API_KEY): "tester"},
                      check_db=lambda: True)

@pytest.fixture
def client(app):
    auth = {"Authorization": f"Bearer {API_KEY}"}
    return TestClient(app, headers=auth)   # sent with every request
```

These tests run the **real** SQL repository (in memory), the real cache and the real limiter, and only time and randomness are faked. That's a good integration test: fast, deterministic, and close to production. And because the in-memory and SQL repositories pass the same **contract test** (`@pytest.fixture(params=["memory", "sql"])`), we can trust the in-memory one in Part 1's fast tests.

class TokenBucket:
    def __init__(self, capacity, per_second, clock):
        self.capacity = capacity
        self.per_second = per_second
        self.clock = clock
        self.tokens = capacity
        self.updated = clock()

        now = self.clock()
        earned = (now - self.updated) * self.per_second

class LinkService:
    def __init__(self, repo: LinkRepository, clock: Clock,
                 make_code: Callable[[], str] = random_code,
                 max_attempts: int = 5):
        self.repo = repo
        self.clock = clock
        self.make_code = make_code
        self.max_attempts = max_attempts

    def shorten(self, url: str, alias: str | None = None,
                ttl_days: int | None = None) -> ShortLink:
        target = TargetUrl(url)
        if ttl_days is not None and ttl_days < 1:
            raise ValueError("ttl_days must be at least 1")
        now = self.clock()
        expires = None
        if ttl_days:
            expires = now + timedelta(days=ttl_days)
        attempts = 1 if alias else self.max_attempts
        for attempt in range(attempts):
            code = ShortCode(alias or self.make_code())
            link = ShortLink(code, target, now, expires)
            try:
                self.repo.add(link)
                return link
            except CodeTaken:
                if attempt == attempts - 1:
                    raise

    def _find(self, raw_code: str) -> ShortLink:
        try:
            code = ShortCode(raw_code)
        except ValueError:
            raise LinkNotFound(raw_code) from None
        link = self.repo.get(code)
        if link is None:
            raise LinkNotFound(raw_code)
        return link

    def resolve(self, raw_code: str) -> str:
        link = self._find(raw_code)
        if link.is_expired(self.clock()):
            raise LinkExpired(raw_code)
        self.repo.record_click(link.code)
        return link.url.value

    def stats(self, raw_code: str) -> ShortLink:
        return self._find(raw_code)

class SqlLinkRepository:
    """One short transaction per call: a link is one aggregate."""

    def __init__(self, session_factory):
        self.session_factory = session_factory

    def get(self, code):
        with self.session_factory() as session:
            row = session.get(LinkRow, code.value)
            if row is None:
                return None
            return ShortLink(ShortCode(row.code), TargetUrl(row.url),
                             row.created_at, row.expires_at,
                             row.clicks)

    def add(self, link):
        with self.session_factory() as session:
            session.add(LinkRow(
                code=link.code.value, url=link.url.value,
                created_at=link.created_at,
                expires_at=link.expires_at, clicks=link.clicks,
            ))
            try:
                session.commit()
            except IntegrityError:
                raise CodeTaken(link.code.value) from None

    def record_click(self, code):
        with self.session_factory() as session:
            session.execute(
                update(LinkRow)
                .where(LinkRow.code == code.value)
                .values(clicks=LinkRow.clicks + 1)
            )
            session.commit()

    def ping(self) -> bool:
        with self.session_factory() as session:
            return session.execute(text("SELECT 1")).scalar() == 1


class CachedLinkRepository:
    """Cache-aside with a TTL, in front of any LinkRepository."""

    def __init__(self, inner, ttl: float,
                 clock: Callable[[], float]):
        self.inner = inner
        self.ttl = ttl
        self.clock = clock
        self.hits = 0
        self.misses = 0
        self._entries = {}      # code -> (link, expires_at)

    def get(self, code):
        now = self.clock()
        entry = self._entries.get(code)
        if entry is not None and now < entry[1]:
            self.hits += 1
            return replace(entry[0])
        self.misses += 1
        link = self.inner.get(code)
        if link is not None:
            self._entries[code] = (replace(link), now + self.ttl)
        return link

    def add(self, link):
        self.inner.add(link)

    def record_click(self, code):
        self.inner.record_click(code)
        if code in self._entries:            # keep our copy close
            self._entries[code][0].clicks += 1


class TokenBucket:
    def __init__(self, capacity, per_second, clock):
        self.capacity = capacity
        self.per_second = per_second
        self.clock = clock
        self.tokens = capacity
        self.updated = clock()

    def allow(self):
        now = self.clock()
        earned = (now - self.updated) * self.per_second
        self.tokens = min(self.capacity, self.tokens + earned)
        self.updated = now
        if self.tokens >= 1:
            self.tokens -= 1
            return True
        return False


class RateLimiter:
    """One token bucket per client."""

    def __init__(self, capacity: int, per_second: float,
                 clock: Callable[[], float]):
        self.capacity = capacity
        self.per_second = per_second
        self.clock = clock
        self._buckets: dict[str, TokenBucket] = {}

    def allow(self, client: str) -> bool:
        bucket = self._buckets.get(client)
        if bucket is None:
            bucket = TokenBucket(self.capacity, self.per_second,
                                 self.clock)
            self._buckets[client] = bucket
        return bucket.allow()

    @property
    def retry_after(self) -> int:
        return math.ceil(1 / self.per_second)

class LinkService:
    def __init__(self, repo: LinkRepository, clock: Clock,
                 make_code: Callable[[], str] = random_code,
                 max_attempts: int = 5):
        self.repo = repo
        self.clock = clock
        self.make_code = make_code
        self.max_attempts = max_attempts

    def shorten(self, url: str, alias: str | None = None,
                ttl_days: int | None = None) -> ShortLink:
        target = TargetUrl(url)
        if ttl_days is not None and ttl_days < 1:
            raise ValueError("ttl_days must be at least 1")
        now = self.clock()
        expires = None
        if ttl_days:
            expires = now + timedelta(days=ttl_days)
        attempts = 1 if alias else self.max_attempts
        for attempt in range(attempts):
            code = ShortCode(alias or self.make_code())
            link = ShortLink(code, target, now, expires)
            try:
                self.repo.add(link)
                return link
            except CodeTaken:
                if attempt == attempts - 1:
                    raise

    def _find(self, raw_code: str) -> ShortLink:
        try:
            code = ShortCode(raw_code)
        except ValueError:
            raise LinkNotFound(raw_code) from None
        link = self.repo.get(code)
        if link is None:
            raise LinkNotFound(raw_code)
        return link

    def resolve(self, raw_code: str) -> str:
        link = self._find(raw_code)
        if link.is_expired(self.clock()):
            raise LinkExpired(raw_code)
        self.repo.record_click(link.code)
        return link.url.value

    def stats(self, raw_code: str) -> ShortLink:
        return self._find(raw_code)

def current_client(
    request: Request,
    creds: HTTPAuthorizationCredentials | None = Depends(bearer),
) -> str:
    keys = request.app.state.api_keys
    client = keys.get(hash_key(creds.credentials)) if creds else None
    if client is None:
        raise HTTPException(401, "Invalid or missing API key",
                            headers={"WWW-Authenticate": "Bearer"})
    return client


def rate_limited(
    request: Request, client: str = Depends(current_client)
) -> str:
    limiter = request.app.state.limiter
    if not limiter.allow(client):
        raise HTTPException(
            429, "Too many requests",
            headers={"Retry-After": str(limiter.retry_after)},
        )
    return client

def create_app(service: LinkService, limiter: RateLimiter,
               api_keys: dict[str, str],
               check_db: Callable[[], bool]) -> FastAPI:
    app = FastAPI(title="PandaLink")
    app.state.service = service
    app.state.limiter = limiter
    app.state.api_keys = api_keys       # sha256 hash -> client

    @app.get("/health/live")
    def live():
        return {"status": "ok"}

    @app.get("/health/ready")
    def ready():
        try:
            ok = check_db()
        except Exception:
            ok = False
        if not ok:
            return JSONResponse(
                {"status": "unavailable"}, status_code=503
            )
        return {"status": "ok"}

    @app.post("/links", status_code=201, response_model=LinkOut)
    def create_link(body: LinkIn, links: ServiceDep,
                    client: LimitedClientDep):
        try:
            link = links.shorten(body.url, body.alias, body.ttl_days)
        except CodeTaken:
            raise HTTPException(409, "That code is taken")
        except ValueError as error:
            raise HTTPException(422, str(error))
        log.info("link created", extra={"fields": {
            "code": link.code.value, "client": client}})
        return to_out(link)

    @app.get("/links/{code}", response_model=LinkOut)
    def link_stats(code: str, links: ServiceDep, client: ClientDep):
        try:
            return to_out(links.stats(code))
        except LinkNotFound:
            raise HTTPException(404, "Link not found")

    @app.get("/{code}")
    def follow(code: str, links: ServiceDep):
        try:
            url = links.resolve(code)
        except LinkNotFound:
            raise HTTPException(404, "Link not found")
        except LinkExpired:
            raise HTTPException(410, "Link expired")
        log.info("redirect", extra={"fields": {"code": code}})
        return RedirectResponse(url, status_code=307)

    return app

## What you built

- A **`SqlLinkRepository`** that keeps each call to one short transaction, translates `IntegrityError` into `CodeTaken` and counts clicks with one atomic `UPDATE`, checked by a **contract test** shared with the in-memory repository.

- **API keys** made with `secrets`, stored as SHA-256 hashes and checked by an `HTTPBearer` dependency.
- An **app factory** that takes all its collaborators, keeps them on `app.state`, maps every domain error to one HTTP status, redirects with **307**, writes **JSON logs** and serves **liveness and readiness** checks.
