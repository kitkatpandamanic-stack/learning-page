## Начинаем с дизайн-документа

Senior-разработчики начинают не с кода, а с **дизайн-документа (design doc)**: одной-двух страниц о том, что мы строим, чего мы *не* строим и какие компромиссы (trade-offs) выбрали. На него уходит час, а экономит он недели работы над не тем. Вот наш — в той форме, которую вы видели в уроке [Проектирование систем](/learn/python/designing-systems).

### Требования

| Вид | Требование |
| --- | --- |
| Функциональное | Создать короткую ссылку для URL, по желанию со своим псевдонимом (`/pandas`) и сроком действия в днях |
| Функциональное | Открытие короткой ссылки перенаправляет на целевой URL; на неизвестные ссылки ответ 404, на истёкшие — 410 Gone |
| Функциональное | Владелец видит число кликов по ссылке; создавать ссылки могут только клиенты с **API-ключом** |
| Нефункциональное | Перенаправления быстрые: p99 меньше 50 мс, ведь каждый клик ждёт нас |
| Нефункциональное | Доступность перенаправлений 99,9% (у создания ссылок она может быть чуть ниже) |
| Нефункциональное | Коды короткие, никогда не совпадают, и их нельзя подобрать один за другим |
| Нефункциональное | Счётчики кликов могут отставать до минуты (здесь согласованность в конечном счёте (eventual consistency) нас устраивает) |

**Не входит в версию 1:** аккаунты пользователей и веб-интерфейс, изменение адреса, на который ведёт ссылка, собственные домены, подробная аналитика (страны, браузеры). Если записать это явно, проект не будет незаметно разрастаться.

### API

| Запрос | Что делает | Ответы |
| --- | --- | --- |
| `POST /links` | `{"url": ..., "alias": ..., "ttl_days": ...}`, нужен API-ключ | 201 + ссылка, 409 псевдоним занят, 422 некорректные данные, 429 слишком много запросов |
| `GET /{code}` | переход по короткой ссылке, публичный | редирект 307, 404, 410 |
| `GET /links/{code}` | статистика ссылки, нужен API-ключ | 200 + ссылка, 404 |
| `GET /health/live`, `GET /health/ready` | для балансировщика нагрузки | 200 или 503 |

### Модель данных

Хватит одной таблицы: `links(code PRIMARY KEY, url, created_at, expires_at, clicks)`. **Код — это первичный ключ (primary key)**, поэтому сама база данных гарантирует, что у двух ссылок никогда не будет одного кода.

## Прикидочные расчёты

Оценим нагрузку на довольно популярный сервис: миллион новых ссылок в день, и каждую в среднем открывают сто раз. Сокращатель ссылок — классическая система **с преобладанием чтения (read-heavy)**:

<CodeExample output={`Новых ссылок: 12/с (пик 35/с)
Редиректов: 1,157/с (пик 3,472/с)
Данных через 5 лет: 730 ГБ
Кодов из 7 символов: 3,521,614,606,208
Занято через 5 лет: 0.052%`}>

```python
new_links_per_day = 1_000_000
redirects_per_link = 100          # чтений на одну запись
seconds_per_day = 86_400
peak = 3                          # часы пик против среднего

writes = new_links_per_day / seconds_per_day
reads = writes * redirects_per_link
print(f"Новых ссылок: {writes:,.0f}/с (пик {writes * peak:,.0f}/с)")
print(f"Редиректов: {reads:,.0f}/с (пик {reads * peak:,.0f}/с)")

bytes_per_link = 400              # код, URL, даты, счётчик
links_in_5_years = new_links_per_day * 365 * 5
gigabytes = links_in_5_years * bytes_per_link / 1e9
print(f"Данных через 5 лет: {gigabytes:,.0f} ГБ")

possible_codes = 62 ** 7
print(f"Кодов из 7 символов: {possible_codes:,}")
print(f"Занято через 5 лет: {links_in_5_years / possible_codes:.3%}")
```

</CodeExample>

Что говорят нам эти числа:

- **12 записей в секунду** — пустяк для одного сервера PostgreSQL. Никакого шардирования и никаких экзотических баз данных.
- **3 500 перенаправлений в секунду** в пик — это много для одной базы данных, но каждое перенаправление задаёт один и тот же вопрос («куда ведёт `k3Xp9Qa`?»), а ответ почти никогда не меняется. Идеальный случай для **кэша (cache)** и нескольких API-серверов **без состояния (stateless)** за балансировщиком нагрузки.
- **730 ГБ** за пять лет помещаются на один диск. Старые, истёкшие ссылки можно потом отправить в архив.
- **Семь символов base62** дают 3,5 триллиона кодов. Через пять лет мы займём 0,05% из них, так что случайный новый код совпадёт с существующим примерно один раз на 2 000 попыток. Коллизии редки, но возможны, и код должен их обрабатывать.

### Какие компромиссы мы выбрали

| Решение | Мы выбрали | Потому что | Цена |
| --- | --- | --- | --- |
| Коды | случайные, 7 символов | их нельзя угадать или перебрать; не нужен центральный счётчик | приходится обрабатывать (редкие) коллизии |
| Статус перенаправления | 307 Temporary Redirect | браузер каждый раз спрашивает нас заново, поэтому мы можем считать клики и отключать истёкшие ссылки | больше трафика, чем с кэшируемым 301 |
| Хранилище | PostgreSQL | данных немного, и они реляционные; уникальный первичный ключ — ровно то, что нужно | ещё один сервис, который надо поддерживать |
| Быстрые перенаправления | cache-aside с коротким TTL | 100 чтений на одну запись, данные меняются редко | статистика может немного отставать |
| Злоупотребления | API-ключи + token bucket на каждый ключ | ссылки создают только известные клиенты; никто не сможет нас завалить запросами | нужно управлять ключами |

<Callout type="tip" title="301 или 307?">

**301 Moved Permanently** говорит браузеру: «больше никогда не спрашивай меня про этот URL». Это отлично для сайта, который действительно переехал, но для сокращателя ссылок это значит, что второй клик до вас уже не дойдёт: ни счётчика кликов, ни возможности отключить или исправить ссылку — возможно, годами. Временное перенаправление (302 или 307) возвращает к нам каждый клик. Выбор кода ответа — это **продуктовое** решение, поэтому ему место в дизайн-документе.

</Callout>

## Коды base62

Код **base62** состоит из цифр, строчных и заглавных латинских букв: 62 символа, безопасных в любом URL. Есть два классических способа получать коды:

<CodeExample output={`0 -> 0
61 -> Z
62 -> 10
125,000,000 -> 8sud2
3,521,614,606,207 -> ZZZZZZZ
E71Lhfe 8L6HLVy`}>

```python
import random
import string

ALPHABET = string.digits + string.ascii_letters   # 62 символа

def encode_base62(n: int) -> str:
    if n == 0:
        return ALPHABET[0]
    digits = []
    while n:
        n, rest = divmod(n, 62)
        digits.append(ALPHABET[rest])
    return "".join(reversed(digits))

for n in [0, 61, 62, 125_000_000, 62 ** 7 - 1]:
    print(f"{n:,} -> {encode_base62(n)}")

def random_code(length=7, choice=random.choice) -> str:
    return "".join(choice(ALPHABET) for _ in range(length))

rng = random.Random(42)            # seed: каждый раз те же коды
print(random_code(choice=rng.choice), random_code(choice=rng.choice))
```

</CodeExample>

- **Счётчик**: дать каждой ссылке номер (1, 2, 3...) и **закодировать** его в base62 — так же, как число записывают в десятичной или двоичной системе. Коды получаются максимально короткими и никогда не совпадают. Но они **предсказуемы**: любой может пройтись по `8sud1`, `8sud2`, `8sud3`... и прочитать все ссылки, которые сокращали люди, включая личные документы. К тому же нужен один центральный счётчик, о котором договорятся все серверы.
- **Случайность**: выбрать 7 случайных символов. Следующий код никто не угадает, и любой сервер может создавать коды сам. Цена: нужно проверять коллизии.

Мы выбираем случайные коды. В продакшене `choice` должен быть **`secrets.choice`** — криптографически стойким генератором из урока [Безопасный код](/learn/python/secure-coding), а не `random.choice`. Обратите внимание, что `random_code` принимает `choice` как **параметр (parameter)**: именно поэтому пример выше выдаёт одни и те же «случайные» коды при каждом запуске, и именно так тесты остаются детерминированными. Это приём с внедрением часов из урока об отказоустойчивости, только применённый к случайности.

## Объекты-значения для кодов и URL

Код и URL — не просто строки: у каждого есть свои правила. Следуя уроку [Внедрение зависимостей и DDD](/learn/python/dependency-injection-and-ddd), мы превратим их в **объекты-значения (value objects)** — замороженные dataclass, которые сами себя проверяют, так что некорректный объект просто не может существовать. Для URL возьмём один новый инструмент из стандартной библиотеки — **`urllib.parse.urlsplit`**, который разбивает URL на части:

<CodeExample output={`https pandas.org /bamboo size=xl
javascript
True
TargetUrl(value='https://pandas.org/bamboo')
'abc': a code has 4 to 16 characters
'my-link': a code uses only 0-9, a-z, A-Z
'Docs': 'Docs' is reserved
'pandas.org': only http(s) URLs with a host
'javascript:alert(1)': only http(s) URLs with a host`}>

```python
import string
from dataclasses import dataclass
from urllib.parse import urlsplit

ALPHABET = string.digits + string.ascii_letters
RESERVED = {"docs", "redoc", "links", "health"}

parts = urlsplit("https://pandas.org/bamboo?size=xl")
print(parts.scheme, parts.netloc, parts.path, parts.query)
print(urlsplit("javascript:alert(1)").scheme)

@dataclass(frozen=True)
class ShortCode:
    value: str

    def __post_init__(self):
        if not 4 <= len(self.value) <= 16:
            raise ValueError("a code has 4 to 16 characters")
        if any(ch not in ALPHABET for ch in self.value):
            raise ValueError("a code uses only 0-9, a-z, A-Z")
        if self.value.lower() in RESERVED:
            raise ValueError(f"{self.value!r} is reserved")

@dataclass(frozen=True)
class TargetUrl:
    value: str

    def __post_init__(self):
        clean = self.value.strip()
        parts = urlsplit(clean)
        if parts.scheme not in ("http", "https") or not parts.netloc:
            raise ValueError("only http(s) URLs with a host")
        if len(clean) > 2048:
            raise ValueError("URL is too long")
        object.__setattr__(self, "value", clean)

print(ShortCode("pandas") == ShortCode("pandas"))
print(TargetUrl("  https://pandas.org/bamboo "))
for make, raw in [(ShortCode, "abc"), (ShortCode, "my-link"),
                  (ShortCode, "Docs"), (TargetUrl, "pandas.org"),
                  (TargetUrl, "javascript:alert(1)")]:
    try:
        make(raw)
    except ValueError as error:
        print(f"{raw!r}: {error}")
```

</CodeExample>

У каждого правила есть причина:

- **Только `http` и `https`, и обязательно с хостом.** Сокращатель, который перенаправляет на URL вида `javascript:...` или `data:...`, превращает ваш доверенный домен в инструмент для злоумышленников. Это проверка на границе, как с Pydantic в уроке [Безопасный код](/learn/python/secure-coding), только в домене — так её получает каждая точка входа.
- **Не больше 2 048 символов** — распространённое ограничение для URL; заодно оно ограничивает, сколько клиент может заставить нас хранить.
- **Коды — от 4 до 16 символов base62**, а некоторые слова **зарезервированы**: псевдоним `docs` или `health` спрятал бы нашу собственную страницу `/docs` и проверки работоспособности за чьей-то ссылкой. Проверка через `.lower()` резервирует и `Docs` тоже.
- `TargetUrl` сам себя **нормализует**, обрезая пробелы, с помощью идиомы `object.__setattr__` из объекта-значения Email.

## Сущность ссылки и порт репозитория

`ShortLink` — это **сущность (entity)**: у неё есть идентичность (её код), а её данные со временем меняются (счётчик кликов). Ещё ей принадлежит одно бизнес-правило — «истекла ли ссылка?», — и время она получает параметром, а не читает часы сама.

Сервису нужно хранилище, поэтому мы определяем **порт (port)**: `Protocol`, описывающий, что умеет репозиторий ссылок. (В уроке [Чистая архитектура](/learn/python/clean-architecture) мы использовали `abc.ABC`; `Protocol` работает не хуже и не требует наследования. Оба варианта хороши.) Адаптер в памяти хранит ссылки в словаре и, как настоящая база данных, сохраняет и возвращает **копии**. Чтобы пример был коротким, коды и URL здесь — обычные строки:

<CodeExample output={`True False
None
занят: pandas
False
True`}>

```python
from dataclasses import dataclass, replace
from datetime import datetime, timedelta
from typing import Protocol

class CodeTaken(Exception):
    pass

@dataclass
class ShortLink:
    code: str                 # в настоящем коде ShortCode
    url: str                  # и TargetUrl; str для краткости
    created_at: datetime
    expires_at: datetime | None = None
    clicks: int = 0

    def is_expired(self, now: datetime) -> bool:
        return self.expires_at is not None and now >= self.expires_at

class LinkRepository(Protocol):
    def get(self, code: str) -> ShortLink | None: ...
    def add(self, link: ShortLink) -> None: ...  # или CodeTaken
    def record_click(self, code: str) -> None: ...

class InMemoryLinkRepository:
    def __init__(self):
        self._links: dict[str, ShortLink] = {}

    def get(self, code):
        link = self._links.get(code)
        return replace(link) if link else None

    def add(self, link):
        if link.code in self._links:
            raise CodeTaken(link.code)
        self._links[link.code] = replace(link)

now = datetime(2026, 1, 1, 12, 0)
link = ShortLink("pandas", "https://pandas.org", now,
                 expires_at=now + timedelta(days=30))
repo = InMemoryLinkRepository()
repo.add(link)
print(repo.get("pandas") == link, repo.get("pandas") is link)
print(repo.get("koalas"))
try:
    repo.add(ShortLink("pandas", "https://evil.example", now))
except CodeTaken as error:
    print("занят:", error)
print(link.is_expired(now + timedelta(days=29)))
print(link.is_expired(now + timedelta(days=30)))
```

</CodeExample>

Присмотритесь к `add`. Здесь нет отдельного метода `exists(code)`, который сервис вызывал бы сначала. Почему?

<Callout type="warning" title="«Проверить, потом вставить» — это гонка">

«Если код свободен — вставь его» звучит надёжно, но с двумя серверами это не так: оба одновременно проверяют `k3Xp9Qa`, оба видят, что он свободен, оба вставляют — и одна ссылка молча затирает другую. Решение — доверить выбор **хранилищу**: `add` либо сохраняет ссылку, либо выбрасывает `CodeTaken`, за один шаг. В PostgreSQL этим занимается ограничение уникальности первичного ключа; в части 2 вы превратите его `IntegrityError` в `CodeTaken`. С кликами то же самое: `record_click(code)` просит хранилище прибавить единицу, вместо «прочитай счётчик, прибавь один, сохрани», что теряет клики, когда два приходят одновременно.

</Callout>

## LinkService

**Сервис** — это слой сценариев использования (use cases): по одному методу на каждое действие клиента. Всё необходимое он получает через конструктор: репозиторий, **часы** и **генератор кодов**. Тесты передают `FakeClock` и список заранее заданных кодов, поэтому одной строкой могут устроить коллизию или перескочить на 30 дней вперёд. Вот `shorten` с добавленным `print`, чтобы было видно повторную попытку:

<CodeExample output={`k3Xp9Qa 2026-01-01 12:00:00 None
  k3Xp9Qa занят, попытка 1
Zt81bYc 2026-01-01 12:05:00 2026-01-08 12:05:00
  about занят, попытка 1
псевдоним занят: about`}>

```python
from dataclasses import dataclass, replace
from datetime import datetime, timedelta

class CodeTaken(Exception):
    pass

@dataclass
class ShortLink:
    code: str
    url: str
    created_at: datetime
    expires_at: datetime | None = None
    clicks: int = 0

class InMemoryLinkRepository:
    def __init__(self):
        self._links = {}

    def get(self, code):
        link = self._links.get(code)
        return replace(link) if link else None

    def add(self, link):
        if link.code in self._links:
            raise CodeTaken(link.code)
        self._links[link.code] = replace(link)

class FakeClock:
    """Время идёт, только когда так решит тест."""

    def __init__(self, now: datetime):
        self.now = now

    def __call__(self) -> datetime:
        return self.now

    def advance(self, **kwargs) -> None:
        self.now += timedelta(**kwargs)

class LinkService:
    def __init__(self, repo, clock, make_code, max_attempts=5):
        self.repo = repo
        self.clock = clock
        self.make_code = make_code
        self.max_attempts = max_attempts

    def shorten(self, url, alias=None, ttl_days=None):
        now = self.clock()
        expires = None
        if ttl_days:
            expires = now + timedelta(days=ttl_days)

                return link
            except CodeTaken:
                print(f"  {code} занят, попытка {attempt + 1}")
                if attempt == attempts - 1:
                    raise

Свой **псевдоним** не повторяется никогда: клиент попросил именно это имя, поэтому он получает ошибку, которую API превратит в **409 Conflict**.

`FakeClock` — небольшое улучшение часов из уроков об отказоустойчивости: вызов возвращает `datetime`, поэтому их можно передать везде, где ожидается функция `clock`, а `advance(days=30)` принимает те же аргументы, что и `timedelta`. В продакшене сервис получает вместо них настоящую функцию часов.

Два других сценария вы напишете сами в упражнении:

- **`resolve(code)`** — это перенаправление: найти ссылку, отказать с `LinkExpired`, если она истекла, засчитать клик и вернуть целевой URL.
- **`stats(code)`** возвращает ссылку с её счётчиком кликов.

Оба выбрасывают **`LinkNotFound`** для неизвестного кода, а также для кода, который даже не является корректным (`/no`, `/bad code!`). Снаружи «это не может быть кодом» и «такого кода нет» — одно и то же: по этому адресу ничего нет.
