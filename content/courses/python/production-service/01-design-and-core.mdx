## Start with a design doc

Seniors don't start with code, they start with a **design doc**: one or two pages that say what we're building, what we're *not* building, and which trade-offs we chose. Writing it takes an hour; it saves weeks of building the wrong thing. Here is ours, in the shape you saw in [Designing Systems](/learn/python/designing-systems).

### Requirements

| Kind | Requirement |
| --- | --- |
| Functional | Create a short link for a URL, with an optional custom alias (`/pandas`) and an optional expiry in days |
| Functional | Opening a short link redirects to the target URL; unknown links answer 404, expired ones 410 Gone |
| Functional | The owner can see a link's click count; only clients with an **API key** can create links |
| Non-functional | Redirects are fast: p99 under 50 ms, because every click waits for us |
| Non-functional | 99.9% availability for redirects (creating links may be a little less available) |
| Non-functional | Codes are short, never collide and can't be guessed one after another |
| Non-functional | Click counts may lag by up to a minute (eventual consistency is fine here) |

**Out of scope for v1:** user accounts and a web UI, editing a link's target, custom domains, detailed analytics (countries, browsers). Writing these down stops the project from quietly growing.

### The API

| Request | Does | Answers |
| --- | --- | --- |
| `POST /links` | `{"url": ..., "alias": ..., "ttl_days": ...}`, API key required | 201 + the link, 409 alias taken, 422 bad input, 429 too many requests |
| `GET /{code}` | follow a short link, public | 307 redirect, 404, 410 |
| `GET /links/{code}` | a link's stats, API key required | 200 + the link, 404 |
| `GET /health/live`, `GET /health/ready` | for the load balancer | 200 or 503 |

### The data model

One table is enough: `links(code PRIMARY KEY, url, created_at, expires_at, clicks)`. The **code is the primary key**, so the database itself guarantees that two links can never share a code.

## Back-of-the-envelope numbers

Let's estimate the load for a fairly popular service: a million new links a day, and each link opened a hundred times on average. A shortener is a classic **read-heavy** system:

<CodeExample output={`New links: 12/s (peak 35/s)
Redirects: 1,157/s (peak 3,472/s)
Storage after 5 years: 730 GB
7-character codes: 3,521,614,606,208
Used after 5 years: 0.052%`}>

```python
new_links_per_day = 1_000_000
redirects_per_link = 100          # reads per write
seconds_per_day = 86_400
peak = 3                          # busy hours vs the average

writes = new_links_per_day / seconds_per_day
reads = writes * redirects_per_link
print(f"New links: {writes:,.0f}/s (peak {writes * peak:,.0f}/s)")
print(f"Redirects: {reads:,.0f}/s (peak {reads * peak:,.0f}/s)")

bytes_per_link = 400              # code, URL, dates, counter
links_in_5_years = new_links_per_day * 365 * 5
gigabytes = links_in_5_years * bytes_per_link / 1e9
print(f"Storage after 5 years: {gigabytes:,.0f} GB")

possible_codes = 62 ** 7
print(f"7-character codes: {possible_codes:,}")
print(f"Used after 5 years: {links_in_5_years / possible_codes:.3%}")
```

</CodeExample>

What the numbers tell us:

- **12 writes per second** is nothing for one PostgreSQL server. No sharding, no exotic database.
- **3,500 redirects per second** at peak is a lot for one database, but every redirect asks the same question ("where does `k3Xp9Qa` go?") and the answer almost never changes. That's a perfect fit for a **cache**, with several **stateless** API servers behind a load balancer.
- **730 GB** in five years fits on one disk. Old, expired links can be archived later.
- **Seven base62 characters** give 3.5 trillion codes. After five years we'd have used 0.05% of them, so a random new code collides with an existing one about once in 2,000 tries. Collisions are rare, but not impossible, so the code must handle them.

### Trade-offs we chose

| Decision | We chose | Because | The price |
| --- | --- | --- | --- |
| Codes | random, 7 characters | can't be guessed or counted; no central counter | must handle (rare) collisions |
| Redirect status | 307 Temporary Redirect | browsers ask us again every time, so we can count clicks and expire links | more traffic than a cached 301 |
| Storage | PostgreSQL | small, relational data; a unique primary key is exactly what we need | one more thing to run |
| Fast redirects | cache-aside with a short TTL | 100 reads per write, rarely changing data | stats may be a little stale |
| Abuse | API keys + a token bucket per key | only known clients create links; no one can flood us | key management |

<Callout type="tip" title="301 or 307?">

A **301 Moved Permanently** tells the browser "never ask me about this URL again". That's great for a site that really moved, but for a shortener it means the second click never reaches you: no click count, and no way to expire or fix the link, possibly for years. A temporary redirect (302 or 307) keeps every click coming back to us. Choosing the status code is a **product** decision, so it belongs in the design doc.

</Callout>

## Base62 codes

A **base62** code uses the digits and the lower- and upper-case letters: 62 characters that are safe in any URL. There are two classic ways to make codes:

<CodeExample output={`0 -> 0
61 -> Z
62 -> 10
125,000,000 -> 8sud2
3,521,614,606,207 -> ZZZZZZZ
E71Lhfe 8L6HLVy`}>

```python
import random
import string

ALPHABET = string.digits + string.ascii_letters   # 62 characters

def encode_base62(n: int) -> str:
    if n == 0:
        return ALPHABET[0]
    digits = []
    while n:
        n, rest = divmod(n, 62)
        digits.append(ALPHABET[rest])
    return "".join(reversed(digits))

for n in [0, 61, 62, 125_000_000, 62 ** 7 - 1]:
    print(f"{n:,} -> {encode_base62(n)}")

def random_code(length=7, choice=random.choice) -> str:
    return "".join(choice(ALPHABET) for _ in range(length))

rng = random.Random(42)            # seeded: same codes every run
print(random_code(choice=rng.choice), random_code(choice=rng.choice))
```

</CodeExample>

- **Counting**: give every link an id (1, 2, 3...) and **encode** it in base62, the same way you'd write a number in base 10 or base 2. Codes are as short as possible and never collide. But they're **predictable**: anyone can walk through `8sud1`, `8sud2`, `8sud3`... and read every link people shortened, including private documents. You also need one central counter that every server agrees on.
- **Random**: pick 7 random characters. Nobody can guess the next code, and any server can create codes on its own. The price: we must check for collisions.

We choose random codes. In production, `choice` must be **`secrets.choice`**, the cryptographically secure generator from [Secure Coding](/learn/python/secure-coding), not `random.choice`. Notice that `random_code` takes `choice` as a **parameter**: that's how the example above gets the same "random" codes every run, and how tests stay deterministic. It's the clock-injection trick from the resilience lesson, applied to randomness.

## Value objects for codes and URLs

A code and a URL are not just strings: each has rules. Following [DI and DDD](/learn/python/dependency-injection-and-ddd), we turn them into **value objects**, frozen dataclasses that validate themselves, so an invalid one can't exist. For URLs we use one new tool from the standard library, **`urllib.parse.urlsplit`**, which splits a URL into its parts:

<CodeExample output={`https pandas.org /bamboo size=xl
javascript
True
TargetUrl(value='https://pandas.org/bamboo')
'abc': a code has 4 to 16 characters
'my-link': a code uses only 0-9, a-z, A-Z
'Docs': 'Docs' is reserved
'pandas.org': only http(s) URLs with a host
'javascript:alert(1)': only http(s) URLs with a host`}>

```python
import string
from dataclasses import dataclass
from urllib.parse import urlsplit

ALPHABET = string.digits + string.ascii_letters
RESERVED = {"docs", "redoc", "links", "health"}

parts = urlsplit("https://pandas.org/bamboo?size=xl")
print(parts.scheme, parts.netloc, parts.path, parts.query)
print(urlsplit("javascript:alert(1)").scheme)

@dataclass(frozen=True)
class ShortCode:
    value: str

    def __post_init__(self):
        if not 4 <= len(self.value) <= 16:
            raise ValueError("a code has 4 to 16 characters")
        if any(ch not in ALPHABET for ch in self.value):
            raise ValueError("a code uses only 0-9, a-z, A-Z")
        if self.value.lower() in RESERVED:
            raise ValueError(f"{self.value!r} is reserved")

@dataclass(frozen=True)
class TargetUrl:
    value: str

    def __post_init__(self):
        clean = self.value.strip()
        parts = urlsplit(clean)
        if parts.scheme not in ("http", "https") or not parts.netloc:
            raise ValueError("only http(s) URLs with a host")
        if len(clean) > 2048:
            raise ValueError("URL is too long")
        object.__setattr__(self, "value", clean)

print(ShortCode("pandas") == ShortCode("pandas"))
print(TargetUrl("  https://pandas.org/bamboo "))
for make, raw in [(ShortCode, "abc"), (ShortCode, "my-link"),
                  (ShortCode, "Docs"), (TargetUrl, "pandas.org"),
                  (TargetUrl, "javascript:alert(1)")]:
    try:
        make(raw)
    except ValueError as error:
        print(f"{raw!r}: {error}")
```

</CodeExample>

Each rule is there for a reason:

- **Only `http` and `https`, with a host.** A shortener that redirects to `javascript:...` or `data:...` URLs turns your trusted domain into a tool for attackers. This is validation at the boundary, like you did with Pydantic in [Secure Coding](/learn/python/secure-coding), but in the domain, so every entry point gets it.
- **At most 2,048 characters**, a common limit for URLs; it also caps how much a client can make us store.
- **Codes are 4 to 16 base62 characters** and some words are **reserved**: an alias called `docs` or `health` would hide our own `/docs` page and health checks behind someone's link. Checking `.lower()` makes `Docs` reserved too.
- `TargetUrl` **normalises** itself by stripping spaces, with the `object.__setattr__` idiom from the Email value object.

## The link entity and the repository port

A `ShortLink` is an **entity**: it has an identity (its code), and its data changes over time (the click count). It also owns one business rule, "has this link expired?", and takes the time as a parameter instead of reading the clock itself.

The service needs storage, so we define a **port**: a `Protocol` that says what a link repository can do. (In the [Clean Architecture](/learn/python/clean-architecture) lesson we used `abc.ABC`; a `Protocol` works just as well and needs no inheritance. Both are fine choices.) The in-memory adapter keeps links in a dict and, like a real database, stores and returns **copies**. To keep the example short, codes and URLs are plain strings here:

<CodeExample output={`True False
None
taken: pandas
False
True`}>

```python
from dataclasses import dataclass, replace
from datetime import datetime, timedelta
from typing import Protocol

class CodeTaken(Exception):
    pass

@dataclass
class ShortLink:
    code: str                 # ShortCode and TargetUrl in the
    url: str                  # real thing; str keeps this short
    created_at: datetime
    expires_at: datetime | None = None
    clicks: int = 0

    def is_expired(self, now: datetime) -> bool:
        return self.expires_at is not None and now >= self.expires_at

class LinkRepository(Protocol):
    def get(self, code: str) -> ShortLink | None: ...
    def add(self, link: ShortLink) -> None: ...  # or CodeTaken
    def record_click(self, code: str) -> None: ...

class InMemoryLinkRepository:
    def __init__(self):
        self._links: dict[str, ShortLink] = {}

    def get(self, code):
        link = self._links.get(code)
        return replace(link) if link else None

    def add(self, link):
        if link.code in self._links:
            raise CodeTaken(link.code)
        self._links[link.code] = replace(link)

now = datetime(2026, 1, 1, 12, 0)
link = ShortLink("pandas", "https://pandas.org", now,
                 expires_at=now + timedelta(days=30))
repo = InMemoryLinkRepository()
repo.add(link)
print(repo.get("pandas") == link, repo.get("pandas") is link)
print(repo.get("koalas"))
try:
    repo.add(ShortLink("pandas", "https://evil.example", now))
except CodeTaken as error:
    print("taken:", error)
print(link.is_expired(now + timedelta(days=29)))
print(link.is_expired(now + timedelta(days=30)))
```

</CodeExample>

Look closely at `add`. There's no separate `exists(code)` method that the service calls first. Why not?

<Callout type="warning" title="Check-then-insert is a race">

"If the code is free, insert it" sounds safe, but with two servers it isn't: both check `k3Xp9Qa` at the same moment, both see it's free, both insert, and one link silently replaces the other. The fix is to let the **storage** decide: `add` either stores the link or raises `CodeTaken`, in one step. In PostgreSQL that's the primary key's unique constraint; in Part 2 you'll turn its `IntegrityError` into `CodeTaken`. The same goes for clicks: `record_click(code)` asks the storage to add one, instead of "read the count, add one, save it", which loses clicks when two arrive together.

</Callout>

## The LinkService

The **service** is the use-case layer: one method per thing a client can do. It receives everything it needs through its constructor: the repository, a **clock** and a **code generator**. Tests pass a `FakeClock` and a list of scripted codes, so they can force a collision or jump 30 days ahead in one line. Here is `shorten`, with a print added so you can watch the retry:

<CodeExample output={`k3Xp9Qa 2026-01-01 12:00:00 None
  k3Xp9Qa is taken, attempt 1
Zt81bYc 2026-01-01 12:05:00 2026-01-08 12:05:00
  about is taken, attempt 1
alias taken: about`}>

```python
from dataclasses import dataclass, replace
from datetime import datetime, timedelta

class CodeTaken(Exception):
    pass

@dataclass
class ShortLink:
    code: str
    url: str
    created_at: datetime
    expires_at: datetime | None = None
    clicks: int = 0

class InMemoryLinkRepository:
    def __init__(self):
        self._links = {}

    def get(self, code):
        link = self._links.get(code)
        return replace(link) if link else None

    def add(self, link):
        if link.code in self._links:
            raise CodeTaken(link.code)
        self._links[link.code] = replace(link)

class FakeClock:
    """Time only moves when a test says so."""

    def __init__(self, now: datetime):
        self.now = now

    def __call__(self) -> datetime:
        return self.now

    def advance(self, **kwargs) -> None:
        self.now += timedelta(**kwargs)

class LinkService:
    def __init__(self, repo, clock, make_code, max_attempts=5):
        self.repo = repo
        self.clock = clock
        self.make_code = make_code
        self.max_attempts = max_attempts

    def shorten(self, url, alias=None, ttl_days=None):
        now = self.clock()
        expires = None
        if ttl_days:
            expires = now + timedelta(days=ttl_days)
        attempts = 1 if alias else self.max_attempts
        for attempt in range(attempts):
            code = alias or self.make_code()
            link = ShortLink(code, url, now, expires)
            try:
                self.repo.add(link)
                return link
            except CodeTaken:
                print(f"  {code} is taken, attempt {attempt + 1}")
                if attempt == attempts - 1:
                    raise

clock = FakeClock(datetime(2026, 1, 1, 12, 0))
codes = iter(["k3Xp9Qa", "k3Xp9Qa", "Zt81bYc"])
links = LinkService(InMemoryLinkRepository(), clock,
                    make_code=lambda: next(codes))

first = links.shorten("https://pandas.org")
print(first.code, first.created_at, first.expires_at)
clock.advance(minutes=5)
second = links.shorten("https://bamboo.shop", ttl_days=7)
print(second.code, second.created_at, second.expires_at)
links.shorten("https://pandas.org/about", alias="about")
try:
    links.shorten("https://evil.example", alias="about")
except CodeTaken as error:
    print("alias taken:", error)
```

</CodeExample>

The scripted generator returned `k3Xp9Qa` twice, so the second link hit `CodeTaken` and the loop simply tried the next code. A **generated** code is retried up to `max_attempts` times (if five random codes in a row are all taken, something else is wrong, and an error is the right answer). A custom **alias** is never retried: the client asked for that exact name, so they get the error, which the API will turn into **409 Conflict**.

`FakeClock` is a small upgrade of the one from the resilience lessons: calling it returns a `datetime`, so it can be passed anywhere a `clock` function is expected, and `advance(days=30)` takes the same arguments as `timedelta`. In production the service gets a real clock function instead.

The other two use cases are yours to write in the exercise:

- **`resolve(code)`** is the redirect: find the link, refuse it with `LinkExpired` if it has expired, record a click and return the target URL.
- **`stats(code)`** returns the link with its click count.

Both raise **`LinkNotFound`** for an unknown code, and also for a code that isn't even valid (`/no`, `/bad code!`). From the outside, "that can't be a code" and "no such code" are the same thing: there's nothing at that address.

## Testing the core

Because the core is plain Python with injected dependencies, its tests need no database, no HTTP and no mocks. Two fixtures do all the setup. The `links` fixture scripts the codes, including a deliberate collision on the second one:

```python

    return FakeClock(START)

@pytest.fixture

    codes = iter(["abc1234", "abc1234", "xyz9876", "Qq77777"])
    return LinkService(InMemoryLinkRepository(), clock,
                       make_code=lambda: next(codes))

    links.shorten("https://pandas.org/a")       # abc1234
    second = links.shorten("https://pandas.org/b")
    assert second.code.value == "xyz9876"       # skipped the dupe
```

A test that needs time to pass asks for both fixtures, `def test_...(links, clock):`, and pytest gives it the **same** clock the service uses, so `clock.advance(days=30)` moves time for the service too.

import secrets
import string
from collections.abc import Callable
from dataclasses import dataclass, replace
from datetime import datetime, timedelta
from typing import Protocol
from urllib.parse import urlsplit

import pytest

ALPHABET = string.digits + string.ascii_letters   # 62 characters
CODE_LENGTH = 7
RESERVED = {"docs", "redoc", "links", "health"}


# ---------- domain ----------

class LinkNotFound(Exception):
    pass


class LinkExpired(Exception):
    pass


class CodeTaken(Exception):
    pass


@dataclass(frozen=True)
class ShortCode:
    value: str

    def __post_init__(self):
        if not 4 <= len(self.value) <= 16:
            raise ValueError("a code has 4 to 16 characters")
        if any(ch not in ALPHABET for ch in self.value):
            raise ValueError("a code uses only 0-9, a-z, A-Z")
        if self.value.lower() in RESERVED:
            raise ValueError(f"{self.value!r} is reserved")


@dataclass(frozen=True)
class TargetUrl:
    value: str

    def __post_init__(self):
        clean = self.value.strip()
        parts = urlsplit(clean)
        if parts.scheme not in ("http", "https") or not parts.netloc:
            raise ValueError("only http(s) URLs with a host")
        if len(clean) > 2048:
            raise ValueError("URL is too long")
        object.__setattr__(self, "value", clean)


@dataclass
class ShortLink:
    code: ShortCode
    url: TargetUrl
    created_at: datetime
    expires_at: datetime | None = None
    clicks: int = 0

    def is_expired(self, now: datetime) -> bool:
        return self.expires_at is not None and now >= self.expires_at


def random_code(length=CODE_LENGTH, choice=secrets.choice) -> str:
    return "".join(choice(ALPHABET) for _ in range(length))

    """Time only moves when a test says so."""

    def __call__(self) -> datetime:
        return self.now

    def advance(self, **kwargs) -> None:
        self.now += timedelta(**kwargs)

    def get(self, code: ShortCode) -> ShortLink | None: ...
    def add(self, link: ShortLink) -> None: ...  # or CodeTaken
    def record_click(self, code: ShortCode) -> None: ...


Clock = Callable[[], datetime]


# ---------- adapters ----------

class InMemoryLinkRepository:
    def __init__(self):
        self._links: dict[ShortCode, ShortLink] = {}

    def get(self, code):
        link = self._links.get(code)
        return replace(link) if link else None

    def add(self, link):
        if link.code in self._links:
            raise CodeTaken(link.code.value)
        self._links[link.code] = replace(link)

    def record_click(self, code):
        self._links[code].clicks += 1


# ---------- service ----------

class LinkService:
    def __init__(self, repo: LinkRepository, clock: Clock,
                 make_code: Callable[[], str] = random_code,
                 max_attempts: int = 5):
        self.repo = repo
        self.clock = clock
        self.make_code = make_code
        self.max_attempts = max_attempts

    def shorten(self, url: str, alias: str | None = None,
                ttl_days: int | None = None) -> ShortLink:
        target = TargetUrl(url)
        if ttl_days is not None and ttl_days < 1:
            raise ValueError("ttl_days must be at least 1")
        now = self.clock()
        expires = None
        if ttl_days:
            expires = now + timedelta(days=ttl_days)
        attempts = 1 if alias else self.max_attempts
        for attempt in range(attempts):
            code = ShortCode(alias or self.make_code())
            link = ShortLink(code, target, now, expires)
            try:
                self.repo.add(link)
                return link
            except CodeTaken:
                if attempt == attempts - 1:
                    raise

    def _find(self, raw_code: str) -> ShortLink:
        try:
            code = ShortCode(raw_code)
        except ValueError:
            raise LinkNotFound(raw_code) from None
        link = self.repo.get(code)
        if link is None:
            raise LinkNotFound(raw_code)
        return link

    def resolve(self, raw_code: str) -> str:
        link = self._find(raw_code)
        if link.is_expired(self.clock()):
            raise LinkExpired(raw_code)
        self.repo.record_click(link.code)
        return link.url.value

    def stats(self, raw_code: str) -> ShortLink:
        return self._find(raw_code)
