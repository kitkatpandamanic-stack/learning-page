Every programmer starts by making the computer say **"Hello, World!"**. In Python, it takes just one line.

## Your first line of code

<CodeExample output="Hello, World!">

```python title="hello.py"
print("Hello, World!")
```

</CodeExample>

- `print(...)` is a built-in **function** that shows whatever you put inside the brackets.
- `"Hello, World!"` is a piece of text, called a **string**. Strings go inside quotes.
- Unlike many languages, Python needs **no semicolon** at the end of a line.

<Callout type="tip" title="Where does this run?">

Right here! Python runs inside your browser on PandaDev. Every exercise has a **Run** button, and the [playground](/playground) lets you experiment freely.

</Callout>

## Printing more than one line

Python runs your program **from top to bottom**, one line at a time:

<CodeExample output={`Hello, World!
I am learning Python.
This is line three.`}>

```python
print("Hello, World!")
print("I am learning Python.")
print("This is line three.")
```

</CodeExample>

You can also print several things at once, separated by commas. Python puts a space between them:

<CodeExample output="Python is fun">

```python
print("Python", "is", "fun")
```

</CodeExample>

## Comments

Anything after a `#` is a **comment**. Python ignores it; comments are notes for humans.

```python
# This line is ignored by Python
print("But this one runs!")  # comments can go at the end of a line too
```

<Callout type="warning">

Text needs quotes. `print(Hello)` without quotes is an error, because Python thinks `Hello` is the name of something it doesn't know.

</Callout>

- `print()` shows output.
- Text goes inside quotes and is called a string.
