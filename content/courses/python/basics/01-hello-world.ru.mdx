Каждый программист начинает с того, что заставляет компьютер сказать **«Привет, мир!»** (Hello, World!). В Python для этого нужна всего одна строка.

## Ваша первая строка кода

<CodeExample output="Привет, мир!">

```python title="hello.py"
print("Привет, мир!")
```

</CodeExample>

- `print(...)` — это встроенная **функция** (function), которая показывает всё, что вы поместили в скобки.
- `"Привет, мир!"` — это фрагмент текста, он называется **строкой** (string). Строки записываются в кавычках.
- В отличие от многих языков, Python **не требует точки с запятой** в конце строки.

<Callout type="tip" title="Где это запускается?">

Прямо здесь! На PandaDev Python работает внутри вашего браузера. В каждом упражнении есть кнопка **«Запустить»**, а в [песочнице](/playground) можно свободно экспериментировать.

</Callout>

## Вывод нескольких строк

Python выполняет программу **сверху вниз**, по одной строке за раз:

<CodeExample output={`Привет, мир!
Я изучаю Python.
Это третья строка.`}>

```python
print("Привет, мир!")
print("Я изучаю Python.")
print("Это третья строка.")
```

</CodeExample>

Можно вывести сразу несколько значений через запятую. Python поставит между ними пробел:

<CodeExample output="Python — это весело">

```python
print("Python", "—", "это", "весело")
```

</CodeExample>

## Комментарии

Всё, что стоит после `#`, — это **комментарий** (comment). Python его игнорирует: комментарии пишут для людей.

```python
# Python игнорирует эту строку
print("А эта выполнится!")  # комментарий можно написать и в конце строки
```

<Callout type="warning">

Текст нужно брать в кавычки. `print(Hello)` без кавычек вызовет ошибку: Python решит, что `Hello` — это имя чего-то, о чём он не знает.

</Callout>

## Итоги

- `print()` выводит данные.
- Текст записывается в кавычках и называется строкой.
- Код выполняется сверху вниз.
- `#` начинает комментарий.
