A **variable** is a name that points to a value. Store something once, then use it by name as often as you like.

## Creating a variable

<CodeExample output="Panda">

```python
name = "Panda"
print(name)
```

</CodeExample>

- `name` is the variable's name.
- `=` puts the value on the right into the name on the left.
- There's no special keyword: just write the name and `=`.

<Callout type="note">

Notice there are no quotes around `name` inside `print`. Without quotes, Python looks up the variable and prints its **value**. With quotes, `"name"` would just print the word *name*.

</Callout>

## Changing a value

Assign a new value whenever you like:

<CodeExample output={`0
10`}>

```python {4}
score = 0
print(score)

score = 10
print(score)
```

</CodeExample>

## Constants

Python has no way to lock a variable, so programmers use a **convention**: names in `ALL_CAPS` mean "please don't change this".

```python
MAX_LIVES = 3
```

## Several at once

You can assign several variables in one line:

<CodeExample output={`1 2`}>

```python
x, y = 1, 2
print(x, y)
```

</CodeExample>

## Naming rules

- Names can contain letters, digits and `_`, but **cannot start with a digit**.
- Names are case-sensitive: `score` and `Score` are different variables.
- Python uses **snake_case** for multi-word names: `player_name`, `high_score`.

```python
player_name = "Mei"
high_score = 120
```

## Recap

- `name = value` creates or updates a variable.
- Use `snake_case` names, and `ALL_CAPS` for values that shouldn't change.
- `x, y = 1, 2` assigns several variables at once.
