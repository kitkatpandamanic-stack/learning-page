Programs work with text all the time: names, messages, search terms. Here are the most useful string skills. At the end, you'll use everything from this module to build your first mini-project: a **Mad Libs story generator** that turns a handful of random words into a silly story. 📖

## f-strings

Put an `f` before the quotes and drop values straight into the text with `{...}`:

<CodeExample output="Panda is 5 years old.">

```python
name = "Panda"
age = 5
print(f"{name} is {age} years old.")
```

</CodeExample>

You can even calculate inside the braces:

<CodeExample output="Next year Panda will be 6.">

```python
name = "Panda"
age = 5
print(f"Next year {name} will be {age + 1}.")
```

</CodeExample>

<Callout type="tip">

f-strings are the modern way to build text in Python. You can also join strings with `+`, but every piece must already be a string.

</Callout>

## Joining and repeating

<CodeExample output={`Hello, Panda!
hahaha`}>

```python
print("Hello, " + "Panda" + "!")
print("ha" * 3)
```

</CodeExample>

## Length, indexing and slicing

`len()` counts characters. Positions start at **0**, and negative positions count from the end:

<CodeExample output={`6
P
n
Pyt`}>

```python
word = "Python"
print(len(word))
print(word[0])
print(word[-1])
print(word[0:3])
```

</CodeExample>

A **slice** `word[start:end]` takes characters from `start` up to, **but not including**, `end`.

## String methods

<CodeExample output={`Hello World
HELLO WORLD
hello world
True
Hello Panda`}>

```python
text = "  Hello World  "
clean = text.strip()
print(clean)
print(clean.upper())
print(clean.lower())
print("World" in clean)
print(clean.replace("World", "Panda"))
```

</CodeExample>

| Method / operator      | What it does                         |
| ---------------------- | ------------------------------------ |
| `.strip()`             | Removes spaces from both ends        |
| `.upper()`, `.lower()` | All capitals / all lowercase         |
| `.replace(a, b)`       | Replaces `a` with `b`                |
| `"x" in text`          | `True` if the text contains `"x"`    |

<Callout type="note">

Methods **don't change** the original string; they give you a new one. Strings in Python can never be modified in place.

</Callout>

## Chaining methods

Because a method gives you back a new string, you can call another method on that result straight away. This is called **chaining**:

<CodeExample output={`HELLO PANDA
15
11`}>

```python
typed = "  Hello Panda  "
print(typed.strip().upper())
print(len(typed))
print(len(typed.strip()))
```

</CodeExample>

Read a chain from left to right: `typed.strip()` makes a tidy copy, then `.upper()` works on that copy. Notice that the spaces count too: `typed` is 15 characters long, but only 11 are left once you strip it.

## Common mistakes

These three trip up almost everyone at first:

<CodeExample output={`[  london ]
Hello, {hero}!
77`}>

```python
city = "  london "
city.strip()  # the tidy copy is thrown away
print(f"[{city}]")

hero = "Mei"
print("Hello, {hero}!")  # forgot the f

number = "7"
print(number * 2)  # "7" is text, so it repeats
```

</CodeExample>

- `city.strip()` on its own line does nothing useful: the original never changes. Keep the result in a variable, for example `clean_city = city.strip()`.
- Without the `f` in front, the braces are just text.
- A number in quotes is a string. `* 2` repeats it instead of doubling it. Convert it with `int()` first, as you did in the last lesson.

Time to build the module project! Use the words at the top of the starter to print this story:

```text
MEI AND THE SPARKLY DRAGON
==========================
One morning in Tashkent, Mei met a sparkly dragon.
The dragon looked hungry, so Mei shared 7 dumplings.
It gobbled them up, asked for 14 more and shouted: DUMPLINGS!
The end.
```

- The title is the hero and the creature, all in capitals.
- Under it goes a line of `=`, exactly as long as the title. Let `len()` count; don't count by hand.
- In the story, the hero has no extra spaces and the adjective is in lowercase.
- "14 more" is the number doubled, worked out by the code.

Press **Check**. Then swap the words (try `"  Ada "`, `"GIGGLY"`, `"cat"`, `"pancakes"`, `"3"` and `"London"`) and press **Run** again: a whole new story, and even the underline grows or shrinks to fit the new title.

<Hint>

Build the title first and keep it in a variable before you print it. Then `len()` of that variable tells you how many `=` signs the line underneath needs.

</Hint>

<Hint>

`number` is text, so turn it into a whole number before you double it. Everywhere else, the words go into f-strings just as they are, or with `.strip()`, `.lower()` or `.upper()` called inside the braces.

</Hint>

<Solution>

```python
hero = "  Mei  "
adjective = "SPARKLY"
animal = "dragon"
food = "dumplings"
number = "7"
place = "Tashkent"

name = hero.strip()  # "Mei"
title = f"{name} and the {adjective} {animal}".upper()

print(title)
print("=" * len(title))
print(f"One morning in {place}, {name} met a {adjective.lower()} {animal}.")
print(f"The {animal} looked hungry, so {name} shared {number} {food}.")
print(f"It gobbled them up, asked for {int(number) * 2} more and shouted: {food.upper()}!")
print("The end.")
```

</Solution>

<Callout type="note" title="Why the grammar sometimes goes wrong">

Try `number = "1"` or `adjective = "orange"`: you'll get "1 dumplings" and "a orange dragon". Choosing "dumpling" or "dumplings", "a" or "an", means your program has to **make a decision**. That's exactly what `if` does, and it's coming up in the next module. On your own computer you could also ask a friend for the words with `input()`; you'll meet it at the end of Level 0.

</Callout>

## Recap

- f-strings: `f"Hi, {name}!"` drop values into text.
- `len()` counts characters; positions start at `0`, and `-1` is the last one.
- Slices `text[start:end]` stop *before* `end`.
- Methods like `.upper()` and `.strip()` return new strings, so keep the result in a variable.
- Chain methods to do several steps in one go: `text.strip().upper()`.
- You built a Mad Libs generator: change the words at the top and the whole story follows.
