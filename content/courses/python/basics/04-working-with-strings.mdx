Programs work with text all the time: names, messages, search terms. Here are the most useful string skills.

## f-strings

Put an `f` before the quotes and drop values straight into the text with `{...}`:

<CodeExample output="Panda is 5 years old.">

```python
name = "Panda"
age = 5
print(f"{name} is {age} years old.")
```

</CodeExample>

You can even calculate inside the braces:

<CodeExample output="Next year Panda will be 6.">

```python
name = "Panda"
age = 5
print(f"Next year {name} will be {age + 1}.")
```

</CodeExample>

<Callout type="tip">

f-strings are the modern way to build text in Python. You can also join strings with `+`, but every piece must already be a string.

</Callout>

## Joining and repeating

<CodeExample output={`Hello, Panda!
hahaha`}>

```python
print("Hello, " + "Panda" + "!")
print("ha" * 3)
```

</CodeExample>

## Length, indexing and slicing

`len()` counts characters. Positions start at **0**, and negative positions count from the end:

<CodeExample output={`6
P
n
Pyt`}>

```python
word = "Python"
print(len(word))
print(word[0])
print(word[-1])
print(word[0:3])
```

</CodeExample>

A **slice** `word[start:end]` takes characters from `start` up to, **but not including**, `end`.

## String methods

<CodeExample output={`Hello World
HELLO WORLD
hello world
True
Hello Panda`}>

```python
text = "  Hello World  "
clean = text.strip()
print(clean)
print(clean.upper())
print(clean.lower())
print("World" in clean)
print(clean.replace("World", "Panda"))
```

</CodeExample>

| Method / operator      | What it does                         |
| ---------------------- | ------------------------------------ |
| `.strip()`             | Removes spaces from both ends        |
| `.upper()`, `.lower()` | All capitals / all lowercase         |
| `.replace(a, b)`       | Replaces `a` with `b`                |
| `"x" in text`          | `True` if the text contains `"x"`    |

<Callout type="note">

Methods **don't change** the original string; they give you a new one. Strings in Python can never be modified in place.

</Callout>

## Recap

- f-strings: `f"Hi, {name}!"` drop values into text.
- `len()` counts characters; positions start at `0`, and `-1` is the last one.
- Slices `text[start:end]` stop *before* `end`.
- Methods like `.upper()` and `.strip()` return new strings.
