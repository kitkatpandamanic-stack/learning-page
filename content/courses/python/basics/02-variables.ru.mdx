**Переменная** (variable) — это имя, которое указывает на **значение** (value). Сохраните что-то один раз, а потом обращайтесь к этому по имени сколько угодно.

## Создание переменной

<CodeExample output="Панда">

```python
name = "Панда"
print(name)
```

</CodeExample>

- `name` — имя переменной.
- `=` помещает значение справа в имя слева.
- Никакого специального ключевого слова не нужно: просто напишите имя и `=`.

<Callout type="note">

Обратите внимание: внутри `print` вокруг `name` нет кавычек. Без кавычек Python находит переменную и выводит её **значение**. С кавычками `"name"` просто вывело бы слово *name*.

</Callout>

## Изменение значения

Присвоить новое значение можно в любой момент:

<CodeExample output={`0
10`}>

```python {4}
score = 0
print(score)

score = 10
print(score)
```

</CodeExample>

## Константы

В Python нельзя «заблокировать» переменную, поэтому программисты используют **соглашение** (convention): имена в стиле `ALL_CAPS` (только заглавные буквы) означают «пожалуйста, не меняйте это». Такие переменные называют **константами** (constant).

```python
MAX_LIVES = 3
```

## Несколько сразу

Можно присвоить значения нескольким переменным в одной строке:

<CodeExample output={`1 2`}>

```python
x, y = 1, 2
print(x, y)
```

</CodeExample>

## Правила именования

- Имена могут содержать буквы, цифры и `_`, но **не могут начинаться с цифры**.
- Регистр важен: `score` и `Score` — это разные переменные.
- Для имён из нескольких слов в Python используют **snake_case**: `player_name`, `high_score`.

```python
player_name = "Мэй"
high_score = 120
```

## Итоги

- `name = value` создаёт или обновляет переменную.
- Используйте имена в стиле `snake_case`, а для значений, которые не должны меняться, — `ALL_CAPS`.
- `x, y = 1, 2` присваивает значения сразу нескольким переменным.
