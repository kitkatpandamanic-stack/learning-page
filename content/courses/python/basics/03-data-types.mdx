Every value in Python has a **type**. The type decides what you can do with it: you can multiply numbers, but not sentences.

## The basic types

```python
age = 12          # int: whole numbers
price = 9.99      # float: numbers with a decimal point
name = "Panda"    # str: text
is_happy = True   # bool: True or False
nickname = None   # None: "no value"
```

## Checking a type with `type()`

<CodeExample output={`<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>`}>

```python
print(type(12))
print(type(9.99))
print(type("Panda"))
print(type(True))
print(type(None))
```

</CodeExample>

<Callout type="note">

`True`, `False` and `None` start with a **capital letter** in Python. `true` (lowercase) is an error.

</Callout>

## Numbers in quotes are text

`"12"` and `12` are different! Adding text to a number is an error:

```python
print("12" + 1)  # TypeError: can only concatenate str (not "int") to str
```

## Converting between types

Use the type's name as a function to convert:

<CodeExample output={`13
55
2.5
12`}>

```python
print(int("12") + 1)
print(str(5) + "5")
print(float("2.5"))
print(int(12.9))
```

</CodeExample>

<Callout type="warning">

`int(12.9)` gives `12`: it cuts off the decimal part instead of rounding. Use `round(12.9)` if you want `13`.

</Callout>
