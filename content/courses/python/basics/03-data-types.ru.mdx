У каждого значения в Python есть **тип** (type). Тип определяет, что можно делать со значением: числа можно умножать, а предложения — нет.

## Основные типы данных

```python
age = 12          # int: целые числа
price = 9.99      # float: числа с десятичной точкой
name = "Панда"    # str: текст
is_happy = True   # bool: True или False
nickname = None   # None: «нет значения»
```

- `int` и `float` — это **числа** (number).
- `str` — **строка** (string).
- `bool` — **логическое значение** (boolean): `True` или `False`.

## Проверка типа с помощью `type()`

<CodeExample output={`<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>`}>

```python
print(type(12))
print(type(9.99))
print(type("Панда"))
print(type(True))
print(type(None))
```

</CodeExample>

<Callout type="note">

В Python `True`, `False` и `None` пишутся с **заглавной буквы**. `true` (со строчной) — это ошибка.

</Callout>

## Числа в кавычках — это текст

`"12"` и `12` — разные вещи! Если сложить текст с числом, будет ошибка:

```python
print("12" + 1)  # TypeError: can only concatenate str (not "int") to str
```

Сообщение означает, что к строке можно присоединить только другую строку, а не `int`.

## Преобразование типов

Чтобы преобразовать значение, используйте имя типа как функцию:

<CodeExample output={`13
55
2.5
12`}>

```python
print(int("12") + 1)
print(str(5) + "5")
print(float("2.5"))
print(int(12.9))
```

</CodeExample>

<Callout type="warning">

`int(12.9)` даёт `12`: дробная часть отбрасывается, а не округляется. Если нужно получить `13`, используйте `round(12.9)`.

</Callout>
