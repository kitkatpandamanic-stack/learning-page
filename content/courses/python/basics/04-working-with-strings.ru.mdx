Программы постоянно работают с текстом: именами, сообщениями, поисковыми запросами. Вот самые полезные навыки работы со **строками** (string). А в конце вы соберёте всё, что узнали в этом модуле, в свой первый мини-проект — **генератор историй Mad Libs**, который превращает горстку случайных слов в забавную историю. 📖

## f-строки

Поставьте `f` перед кавычками и вставляйте значения прямо в текст с помощью `{...}`:

<CodeExample output="Меня зовут Панда, мне 5 лет.">

```python
name = "Панда"
age = 5
print(f"Меня зовут {name}, мне {age} лет.")
```

</CodeExample>

Внутри фигурных скобок можно даже вычислять:

<CodeExample output="Панда: через год будет 6.">

```python
name = "Панда"
age = 5
print(f"{name}: через год будет {age + 1}.")
```

</CodeExample>

<Callout type="tip">

f-строки (f-strings) — современный способ собирать текст в Python. Строки можно соединять и с помощью `+`, но тогда каждая часть уже должна быть строкой.

</Callout>

## Соединение и повторение

<CodeExample output={`Привет, Панда!
хахаха`}>

```python
print("Привет, " + "Панда" + "!")
print("ха" * 3)
```

</CodeExample>

## Длина, индексы и срезы

`len()` считает символы. Позиции (индексы) начинаются с **0**, а отрицательные позиции отсчитываются с конца:

<CodeExample output={`6
P
n
Pyt`}>

```python
word = "Python"
print(len(word))
print(word[0])
print(word[-1])
print(word[0:3])
```

</CodeExample>

**Срез** (slice) `word[start:end]` берёт символы от `start` до `end`, **не включая** `end`.

## Строковые методы

**Методы** (method) — это функции, которые вызываются у значения через точку:

<CodeExample output={`Привет мир
ПРИВЕТ МИР
привет мир
True
Привет Панда`}>

```python
text = "  Привет мир  "
clean = text.strip()
print(clean)
print(clean.upper())
print(clean.lower())
print("мир" in clean)
print(clean.replace("мир", "Панда"))
```

</CodeExample>

| Метод / оператор       | Что делает                                |
| ---------------------- | ----------------------------------------- |
| `.strip()`             | Убирает пробелы с обоих концов            |
| `.upper()`, `.lower()` | Все буквы заглавные / все строчные        |
| `.replace(a, b)`       | Заменяет `a` на `b`                       |
| `"x" in text`          | `True`, если в тексте есть `"x"`          |

<Callout type="note">

Методы **не изменяют** исходную строку — они возвращают новую. Строки в Python вообще нельзя изменить на месте.

</Callout>

## Цепочки методов

Раз метод возвращает новую строку, у этого результата можно сразу вызвать следующий метод. Это называется **цепочкой вызовов** (chaining):

<CodeExample output={`ПРИВЕТ, ПАНДА
17
13`}>

```python
typed = "  Привет, Панда  "
print(typed.strip().upper())
print(len(typed))
print(len(typed.strip()))
```

</CodeExample>

Цепочку читают слева направо: `typed.strip()` делает аккуратную копию без пробелов по краям, а `.upper()` работает уже с этой копией. Заметьте, что пробелы тоже считаются: в `typed` 17 символов, а после `strip()` остаётся 13.

## Частые ошибки

На этих трёх ошибках поначалу спотыкаются почти все:

<CodeExample output={`[  москва ]
Привет, {hero}!
77`}>

```python
city = "  москва "
city.strip()  # аккуратная копия просто теряется
print(f"[{city}]")

hero = "Мэй"
print("Привет, {hero}!")  # забыли f

number = "7"
print(number * 2)  # "7" — это текст, поэтому он повторяется
```

</CodeExample>

- `city.strip()` в отдельной строке ничего не даёт: исходная строка не меняется. Сохраните результат в переменную, например `clean_city = city.strip()`.
- Без `f` перед кавычками фигурные скобки — просто текст.
- Число в кавычках — это строка. `* 2` повторяет её, а не удваивает. Сначала превратите её в число с помощью `int()`, как в прошлом уроке.

Пора собрать проект модуля! Возьмите слова из начала стартового кода и выведите вот такую историю:

```text
МЭЙ И СВЕРКАЮЩИЙ ДРАКОН
=======================
```

- Заголовок — это герой и животное, всё заглавными буквами.
- Под ним идёт черта из `=` ровно той же длины, что и заголовок. Пусть считает `len()`, а не вы.
- В самой истории имя героя без лишних пробелов, а прилагательное написано строчными.
- «Ещё 14» — это удвоенное число, и считает его код.

## Итоги

- f-строки: `f"Привет, {name}!"` вставляют значения в текст.
- `len()` считает символы; позиции начинаются с `0`, а `-1` — последняя.
- Срезы `text[start:end]` заканчиваются *перед* `end`.
- Методы вроде `.upper()` и `.strip()` возвращают новые строки, поэтому сохраняйте результат в переменную.
- Цепочка методов делает несколько шагов сразу: `text.strip().upper()`.
- Вы собрали генератор историй Mad Libs: меняете слова вверху — и вся история меняется вслед за ними.
