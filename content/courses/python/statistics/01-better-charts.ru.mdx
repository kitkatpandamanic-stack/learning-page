В уроке [Очистка и группировка данных](/learn/python/cleaning-and-grouping) вы нарисовали первые графики (charts) с помощью `series.plot()` и `plt.title(...)`. Для быстрого взгляда на данные этого достаточно. Но графикам для отчёта, слайда или дашборда нужно больше: несколько графиков рядом, подписи, которые говорят сами за себя, цвета, которые различает каждый, и файл, который можно приложить к письму.

В этом модуле вы научитесь **описывать данные** с помощью статистики, оценивать, насколько **уверенно** можно говорить о результате, а в конце сделаете настоящий **отчёт по A/B-тесту**. Показывать всё это вы будете графиками, поэтому начнём с того, чтобы рисовать их как профессионалы. 📊

## Figure и Axes

В matplotlib есть два способа рисовать. Знакомый вам стиль `plt.title()` обращается к «текущему графику», где бы он ни был. **Объектно-ориентированный** стиль, которым пользуются профессионалы, даёт вам сами объекты графика:

- **Figure** — это всё изображение целиком: холст, который показывают или сохраняют.
- **Axes** — это один график внутри фигуры, со своими осями x и y, заголовком и данными. (Да, «Axes» во множественном числе даже для одного графика. Это не то же самое, что *axis* — ось.)

**`fig, ax = plt.subplots()`** создаёт фигуру с одним Axes, а дальше вы вызываете методы `ax`. Нажмите **«Запустить»**, а потом попробуйте `marker="s"` или `linestyle="--"`:

<TryIt language="python" code={`import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
visitors = [1200, 1350, 1280, 1600, 1750, 1900]

fig, ax = plt.subplots(figsize=(7, 4))   # ширина и высота в дюймах
ax.plot(months, visitors, marker="o")
ax.set_title("Посетители по месяцам")
ax.set_xlabel("Месяц")
ax.set_ylabel("Посетители")
plt.show()`}
/>

У большинства функций `plt.something()` есть двойник `ax.set_something()`: `plt.title` превращается в `ax.set_title`, `plt.xlabel` — в `ax.set_xlabel`, `plt.ylim` — в `ax.set_ylim`. Функции рисования сохраняют свои имена: `ax.plot`, `ax.bar`, `ax.scatter`...

Зачем всё это? С `ax` вы всегда знаете, **какой именно** график меняете, а это важно, как только в фигуре их больше одного. Кроме того, функция может построить фигуру и **вернуть** её, чтобы другой код (и тесты!) мог заглянуть внутрь:

<CodeExample output={`1
Посетители по месяцам
Посетители
[1200, 1350, 1280]`}>

```python
import matplotlib.pyplot as plt

def visitors_chart(months, visitors):
    fig, ax = plt.subplots()
    ax.plot(months, visitors, marker="o")
    ax.set_title("Посетители по месяцам")
    ax.set_ylabel("Посетители")
    return fig

fig = visitors_chart(["Jan", "Feb", "Mar"], [1200, 1350, 1280])
ax = fig.axes[0]
print(len(fig.axes))
print(ax.get_title())
print(ax.get_ylabel())
print(ax.lines[0].get_ydata().tolist())
plt.close(fig)   # фигура больше не нужна: освобождаем память
```

</CodeExample>

`fig.axes` — это список графиков в фигуре, `ax.lines` — линии на графике, а у каждого `set_...` есть свой `get_...`. Именно так, проверяя **данные** графика, реальные проекты тестируют код отрисовки: сравнивать пиксели слишком ненадёжно.

## Несколько графиков в одной фигуре

`plt.subplots(rows, cols)` создаёт **сетку** графиков и возвращает их массивом Axes. Если строка одна, графики — это `axes[0]` и `axes[1]`; если строк несколько, используйте `axes[row, col]`.

Графики с одинаковыми значениями по x (например, месяцами) должны стоять ровно друг под другом, поэтому передайте **`sharex=True`**: у графиков будет общая ось x, и при масштабировании одного масштабируются все. Попробуйте заменить сетку на `plt.subplots(1, 2)` и убрать `sharex`:

<TryIt language="python" code={`import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
visitors = [1200, 1350, 1280, 1600, 1750, 1900]
orders = [96, 101, 90, 136, 140, 171]

fig, axes = plt.subplots(2, 1, figsize=(7, 5), sharex=True)

axes[0].plot(months, visitors, marker="o")
axes[0].set_title("Посетители")

axes[1].bar(months, orders, color="#0072B2")
axes[1].set_title("Заказы")
axes[1].set_xlabel("Месяц")

fig.suptitle("Panda Shop, первая половина 2026 года")
fig.tight_layout()     # чтобы заголовки и подписи не налезали друг на друга
plt.show()`}
/>

- **`fig.suptitle()`** даёт заголовок всей фигуре; у каждого Axes остаётся свой.
- **`fig.tight_layout()`** раздвигает графики, чтобы подписи не перекрывались. Вызывайте его прямо перед показом или сохранением.
- **`figsize=(width, height)`** задаётся в дюймах. Для сеток «бок о бок» лучше подходят широкие фигуры.

## Выбираем правильный график

Лучший график зависит от **вопроса**, на который вы отвечаете. Пять видов графиков покрывают почти все случаи:

| Вопрос | График | matplotlib |
| --- | --- | --- |
| Как это меняется со временем? | линейный | `ax.plot(x, y)` |
| Как сравниваются группы? | столбчатый | `ax.bar(names, values)` или `ax.barh` |
| Как распределены значения? | гистограмма | `ax.hist(values, bins=...)` |
| Меняются ли два показателя вместе? | диаграмма рассеяния | `ax.scatter(x, y)` |
| Как сравнивается разброс у групп? | ящик с усами | `ax.boxplot([group1, group2])` |

Вот остальные четыре на одной фигуре. Данные придуманы с помощью **NumPy** — библиотеки для чисел, на которой построена pandas: `rng.normal(...)` выдаёт случайные числа вокруг заданного среднего, а seed `42` делает их одинаковыми при каждом запуске. С NumPy вы как следует познакомитесь в следующих уроках.

<TryIt language="python" code={`import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
order_values = rng.normal(35, 10, size=300)          # £ за заказ
distance = rng.uniform(1, 30, size=60)               # км
days = 1 + distance / 10 + rng.normal(0, 0.4, 60)    # доставка
web = rng.normal(33, 8, size=200)
app = rng.normal(39, 12, size=200)

fig, axes = plt.subplots(2, 2, figsize=(9, 7))

axes[0, 0].bar(["Tea", "Mugs", "Snacks", "Books"], [340, 210, 480, 150])
axes[0, 0].set_title("Столбцы: заказы по категориям")

axes[0, 1].hist(order_values, bins=20, edgecolor="white")
axes[0, 1].set_title("Гистограмма: суммы заказов (£)")

axes[1, 0].scatter(distance, days, alpha=0.7)
axes[1, 0].set_title("Рассеяние: расстояние и дни доставки")
axes[1, 0].set_xlabel("Расстояние (км)")

axes[1, 1].boxplot([web, app], tick_labels=["Web", "App"])
axes[1, 1].set_title("Ящик с усами: суммы заказов по каналам")

fig.tight_layout()
plt.show()`}
/>

- **Гистограмма (histogram)** делит значения на интервалы `bins` и считает, сколько попало в каждый, — так видна *форма* данных: большинство заказов около £35, а заказов меньше £10 или больше £60 мало. Попробуйте `bins=5` и `bins=60`: при слишком малом числе интервалов форма теряется, при слишком большом график становится шумным.
- **Диаграмма рассеяния (scatter plot)** показывает по точке на каждую доставку. `alpha=0.7` делает точки слегка прозрачными, поэтому места, где они накладываются, выглядят темнее.
- **Ящик с усами (box plot)** рисует среднюю половину каждой группы прямоугольником, медиану — линией, а выбросы — отдельными точками. Как именно он устроен, вы узнаете в следующем уроке. Это самый быстрый способ сравнить разброс нескольких групп.

## Заголовки, подписи, легенды и аннотации

График должен быть понятен человеку, который больше ничего не читал. Значит, нужен заголовок, который говорит, что показано, подписи осей **с единицами измерения**, легенда, если рядов данных больше одного, и **аннотация**, которая указывает на то, что вы хотите показать:

<TryIt language="python" code={`import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
y2025 = [1100, 1150, 1210, 1240, 1300, 1320]
y2026 = [1200, 1350, 1280, 1600, 1750, 1900]

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(months, y2025, marker="o", color="#999999", label="2025")
ax.plot(months, y2026, marker="o", color="#0072B2", label="2026")
ax.axhline(1500, linestyle="--", color="#D55E00", label="Цель")

ax.annotate("Начало весенней распродажи",
            xy=(3, 1600),          # точка (Apr стоит на позиции 3)
            xytext=(0.3, 1750),    # где разместить текст
            arrowprops=dict(arrowstyle="->"))

ax.set_title("Посетители по месяцам: после распродажи 2026 обогнал 2025")
ax.set_ylabel("Посетители")
ax.set_ylim(0, 2100)
ax.grid(axis="y", alpha=0.3)
ax.legend(loc="lower right")
plt.show()`}
/>

- **`label=`** даёт имя каждому ряду данных, а **`ax.legend()`** показывает их. `loc=` убирает легенду туда, где она не мешает.
- **`ax.axhline()`** рисует горизонтальную опорную линию, например цель (`ax.axvline()` рисует вертикальную, скажем, на дату запуска).
- **`ax.annotate(text, xy=..., xytext=..., arrowprops=...)`** пишет текст со стрелкой, указывающей на `xy`. Если на оси x текстовые подписи, их позиции — 0, 1, 2...
- Заголовок может сообщать **вывод**, а не только тему. «После распродажи 2026 обогнал 2025» сразу говорит занятому читателю, на что смотреть.

## Графики, которые вводят в заблуждение

График может быть формально верным и всё равно создавать ложное впечатление. Иногда это делают намеренно, но чаще — случайно. Вот классические приёмы:

**Обрезанные оси.** **Длина** столбца — это его значение, поэтому столбчатые графики должны начинаться с нуля. Эти два графика показывают одну и ту же конверсию:

<TryIt language="python" code={`import matplotlib.pyplot as plt

variants = ["Button A", "Button B"]
rates = [10.2, 10.8]     # % посетителей, которые купили

fig, (left, right) = plt.subplots(1, 2, figsize=(8, 3.5))

left.bar(variants, rates, color=["#999999", "#0072B2"])
left.set_ylim(10, 11)
left.set_title("Обманчиво: начинается с 10%")

right.bar(variants, rates, color=["#999999", "#0072B2"])
right.set_ylim(0, 12)
right.set_title("Честно: начинается с 0%")

for ax in (left, right):
    ax.set_ylabel("Конверсия (%)")
fig.tight_layout()
plt.show()`}
/>

Слева B выглядит **в четыре раза** лучше, а на самом деле он лучше на 0,6 процентного пункта. (Обратите внимание на удобный приём для двух Axes: `fig, (left, right) = plt.subplots(1, 2)` сразу раскладывает их по именам.) С линейными графиками иначе: они показывают *изменение*, поэтому приближать ось y можно, если она чётко подписана.

**Две оси y.** `ax.twinx()` добавляет справа вторую ось y со своим масштабом. Подбирая два масштаба, можно заставить любые две линии выглядеть так, будто они меняются вместе или пересекаются где угодно. Лучше поставьте два графика друг под другом с `sharex=True`, как посетителей и заказы выше.

**3D-графики и круговые диаграммы.** Из-за перспективы передние доли 3D-«пирога» кажутся больше, чем есть, а сравнивать углы людям трудно даже на плоском «пироге». **Отсортированный столбчатый график** показывает то же самое точнее.

**Выборочно подобранные диапазоны.** Например, показать только месяцы, когда продажи росли, или ось y, которая меняется между графиками, которые нужно сравнивать (именно от этого защищает `sharey=True`).

<Callout type="warning" title="Чек-лист честного графика">

Столбцы начинаются с нуля. У графиков, которые сравнивают, общие оси. У осей есть подписи и единицы измерения. Источник данных и размер выборки где-то указаны. Если график приходится объяснять вслух, чтобы его не поняли неправильно, — перерисуйте его.

</Callout>

## Цвета, которые различает каждый

Примерно **1 из 12 мужчин** и 1 из 200 женщин в той или иной мере не различают цвета, чаще всего **красный и зелёный**. График «красное против зелёного» может оказаться для них нечитаемым, а ещё он плохо выглядит на чёрно-белом принтере. Профессионалы делают три вещи:

1. **Берут палитру, безопасную для дальтоников.** Цвета **Okabe-Ito** (они использованы в графиках выше: `#0072B2` синий, `#D55E00` оранжево-красный, `#009E73` зелёный, `#E69F00` оранжевый, `#56B4E9` голубой, `#CC79A7` розовый) подобраны так, чтобы их различал каждый. В matplotlib есть и готовые безопасные стили: `"tableau-colorblind10"` и `"petroff10"`.
2. **Не полагаются только на цвет.** Добавляют разные маркеры или стили линий либо подписывают линии прямо на графике.
3. **Используют серый для фона, а один цвет — для главного.** Взгляд сразу падает на выделенный столбец.

Для цветовых **шкал** (тепловые карты, карты) используйте `cmap="viridis"` или `"cividis"`: они равномерно идут от тёмного к светлому и работают даже в чёрно-белом виде. Избегайте радужной `"jet"`.

<TryIt language="python" code={`import matplotlib.pyplot as plt

categories = ["Books", "Mugs", "Tea", "Snacks"]
orders = [150, 210, 340, 480]
colours = ["#BBBBBB"] * len(orders)
colours[3] = "#0072B2"              # выделяем Snacks

months = ["Jan", "Feb", "Mar", "Apr"]

# Стиль действует только внутри блока with
with plt.style.context("tableau-colorblind10"):
    fig, (left, right) = plt.subplots(1, 2, figsize=(9, 3.5))

    left.barh(categories, orders, color=colours)
    left.set_title("Больше всего заказов у Snacks")
    left.set_xlabel("Заказы")

    channels = [("Web", "o", "-"), ("App", "s", "--"),
                   ("Shop", "^", ":")]
    data = [[50, 55, 61, 70], [30, 41, 52, 66], [40, 38, 41, 39]]
    for (name, marker, style), values in zip(channels, data):
        right.plot(months, values, marker=marker, linestyle=style,
                   label=name)
    right.set_title("Заказы по каналам")
    right.legend()

    fig.tight_layout()
    plt.show()`}
/>

Обратите внимание на **`with plt.style.context(...)`**: стиль действует только внутри блока. `plt.style.use(...)` изменил бы все графики, нарисованные после него, — это удобно в блокноте, но неожиданно в общем коде.

## Графики pandas на ваших собственных Axes

Под капотом графиков pandas — тот же matplotlib. Передайте **`ax=`**, и pandas нарисует график на выбранном вами Axes, — так удобство pandas сочетается с вашей собственной компоновкой:

<TryIt language="python" code={`import pandas as pd
import matplotlib.pyplot as plt

sales = pd.DataFrame({
    "web": [50, 55, 61, 70, 74, 80],
    "app": [30, 41, 52, 66, 71, 90],
}, index=["Jan", "Feb", "Mar", "Apr", "May", "Jun"])

fig, axes = plt.subplots(1, 2, figsize=(9, 3.5))

sales.plot(ax=axes[0], marker="o")    # по линии на каждый столбец
axes[0].set_title("Заказы по месяцам")

sales.sum().plot.bar(ax=axes[1], color=["#0072B2", "#E69F00"],
                     rot=0)
axes[1].set_title("Заказы с января по июнь")

fig.tight_layout()
plt.show()`}
/>

DataFrame рисует **по линии на каждый столбец**: индекс идёт на ось x, а имена столбцов — в легенду. `sales.sum()` — это Series (по одной сумме на столбец), а `.plot.bar()` — то же самое, что `.plot(kind="bar")`. Каждый метод рисования pandas возвращает Axes, на котором он рисовал, так что график можно настраивать дальше.

## Сохраняем графики для отчётов

**`fig.savefig("name.png", dpi=...)`** записывает фигуру в файл. Формат определяется по расширению:

- **PNG** — изображение из пикселей. Его размер — `figsize × dpi`: фигура 6 × 4 дюйма при `dpi=200` — это 1200 × 800 пикселей. Для отчётов и слайдов берите от 150 до 300.
- **SVG** и **PDF** — **векторные** форматы: они остаются чёткими при любом размере, что отлично подходит для печати и веб-страниц.

<CodeExample output={`b'\\x89PNG'
1200 800
True`}>

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(6, 4))
ax.bar(["A", "B"], [10.2, 10.8])
ax.set_title("Конверсия (%)")

fig.savefig("conversion.png", dpi=200)
plt.close(fig)

data = open("conversion.png", "rb").read()
print(data[:4])                      # так начинается любой PNG
width = int.from_bytes(data[16:20], "big")
height = int.from_bytes(data[20:24], "big")
print(width, height)

fig.savefig("conversion.svg")        # векторная версия
print(open("conversion.svg").read().startswith("<?xml"))
```

</CodeExample>

Две настройки, которые вам часто пригодятся: **`bbox_inches="tight"`** обрезает пустое место вокруг графика, а **`transparent=True`** убирает белый фон — для слайдов с цветной темой. На вашем компьютере файлы появятся рядом со скриптом, а здесь они сохраняются во встроенную файловую систему браузера.

<Callout type="tip" title="Одна функция на график">

В реальных проектах оформляйте каждый график функцией, которая принимает данные и **возвращает фигуру**, как `visitors_chart` выше. Тогда одна и та же функция пригодится и в блокноте, и в скрипте отчёта, который вызывает `savefig`, и в тесте, который проверяет данные. Никогда не считайте *внутри* кода графика числа, которые не использует остальной отчёт.

</Callout>

Руководителю нужна фигура из двух графиков для ежемесячного отчёта. 📈 Напишите `report_figure(months, visitors, orders)`, которая **возвращает** Figure с двумя Axes рядом:

1. **Слева:** линейный график `visitors` по `months` с заголовком `"Visitors"` и подписью оси y `"Visitors"`.
2. **Справа:** столбчатый график `orders` по месяцам с заголовком `"Orders"` и подписью оси y `"Orders"`.
3. У всей фигуры заголовок `"Shop report"`.

Проверки заглядывают внутрь вашей фигуры (данные линии, высоты столбцов, заголовки), а ещё вызывают функцию с другими данными. Можете добавить маркеры, цвета и `tight_layout()`: проверяются только данные и текст.

```python
import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
visitors = [1200, 1350, 1280, 1600, 1750, 1900]
orders = [96, 101, 90, 136, 140, 171]

def report_figure(months, visitors, orders):
    fig, (left, right) = plt.subplots(1, 2, figsize=(9, 3.5))

    left.plot(months, visitors, marker="o", color="#0072B2")
    left.set_title("Visitors")
    left.set_ylabel("Visitors")

    right.bar(months, orders, color="#E69F00")
    right.set_title("Orders")
    right.set_ylabel("Orders")

    fig.suptitle("Shop report")
    fig.tight_layout()
    return fig

fig = report_figure(months, visitors, orders)
plt.show()
```

## Итоги

- **`fig, ax = plt.subplots()`**: Figure — это всё изображение, Axes — один график в нём. Используйте `ax.plot`, `ax.set_title`, `ax.set_xlabel`... вместо функций `plt.`.
- **`plt.subplots(rows, cols, sharex=True)`** строит сетку; `fig.suptitle()` даёт заголовок фигуре, а `fig.tight_layout()` убирает наложения.
- Выбирайте график по вопросу: **линейный** — для изменений во времени, **столбчатый** — для сравнения групп, **гистограмма** — для распределения, **рассеяние** — для связей, **ящик с усами** — для сравнения разброса.
- Подписывайте всё с единицами измерения, добавляйте **легенду** для нескольких рядов и **аннотации** к важному; заголовок может сообщать вывод.
- Честные графики: столбцы начинаются с нуля, сравниваемые графики делят оси, никаких двух осей y и 3D-«пирогов».
- Берите цвета, безопасные для дальтоников (Okabe-Ito, `"tableau-colorblind10"`, `viridis`), не полагайтесь только на цвет, выделяйте цветом одно, а остальное делайте серым.
- `df.plot(ax=ax)` рисует графики pandas на ваших Axes; **`fig.savefig("chart.png", dpi=200)`** сохраняет их для отчётов.
- Оформляйте графики функциями, которые возвращают фигуру, — тогда их данные можно тестировать.
