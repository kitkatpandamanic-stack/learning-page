График показывает всю картину целиком, а несколько удачно выбранных чисел позволяют пересказать её одной фразой: *«Обычно доставка занимает 2 дня, и 9 из 10 заказов приходят за 4 дня»*. Эти числа называются **описательной статистикой (descriptive statistics)**, и любой аналитик считает их первым делом, когда получает новые данные.

В этом уроке вы узнаете, какие числа выбирать, когда каждое из них **вводит в заблуждение** и как их считать тремя инструментами, которые встречаются повсюду: встроенным модулем Python **`statistics`** для небольших списков, **NumPy** для массивов чисел и **pandas** для таблиц. 🔎

## Середина: среднее, медиана и мода

Есть три распространённых способа сказать, какое значение «типичное»:

- **Среднее (mean)**: сложить всё и разделить на количество.
- **Медиана (median)**: отсортировать значения и взять среднее по порядку (или среднее двух средних).
- **Мода (mode)**: самое частое значение. Только она работает для категорий вроде размеров футболок.

Посмотрите, что происходит с зарплатами команды, когда в список попадает основатель:

<CodeExample output={`35.875
35.5
137.4
36
M
[1, 2]`}>

```python
import statistics

salaries = [28, 31, 33, 35, 36, 38, 41, 45]   # тысячи £ в год
print(statistics.mean(salaries))
print(statistics.median(salaries))

salaries.append(950)       # в таблицу добавляется основатель
print(round(statistics.mean(salaries), 1))
print(statistics.median(salaries))

sizes = ["M", "L", "M", "S", "M", "L"]
print(statistics.mode(sizes))
print(statistics.multimode([1, 1, 2, 2, 3]))
```

</CodeExample>

Одна очень высокая зарплата подняла среднее примерно с 36 до 137: восемь человек из девяти получают гораздо меньше «средней зарплаты». А медиана почти не сдвинулась. Поэтому в новостях говорят о **медианном доходе**, а цены на жильё приводят как медианы.

- Берите **среднее**, когда значения примерно симметричны и без крайних значений или когда важна сумма (средний чек × число заказов = выручка).
- Берите **медиану** для скошенных данных: доходов, цен, времени ожидания и загрузки страниц.
- `statistics.mode` возвращает одно самое частое значение, а **`multimode`** — все такие значения, если их несколько.

## Разброс: насколько различаются значения?

В двух кафе среднее время ожидания — 5 минут. В какой очереди вы бы предпочли стоять, в A или в B?

<CodeExample output={`A: среднее 5, размах 2, std 0.76
B: среднее 5, размах 9, std 3.55`}>

```python
import statistics

cafe_a = [4, 5, 5, 6, 5, 4, 6, 5]     # минуты
cafe_b = [1, 9, 2, 8, 5, 10, 3, 2]

for name, waits in [("A", cafe_a), ("B", cafe_b)]:
    mean = statistics.mean(waits)
    spread = max(waits) - min(waits)
    std = statistics.stdev(waits)
    print(f"{name}: среднее {mean}, размах {spread}, std {std:.2f}")
```

</CodeExample>

Среднее одинаковое, а впечатления совсем разные. Нужно число и для **разброса (spread)**:

- **Размах (range)** — это `max - min`. Просто, но одно крайнее значение меняет его полностью.
- **Дисперсия (variance)** — это среднее **квадратов расстояний** от среднего. Возведение в квадрат делает все расстояния положительными и сильнее «наказывает» большие.
- **Стандартное отклонение (standard deviation, std)** — это квадратный корень из дисперсии, он возвращает нас к исходным единицам (минутам, а не минутам²). Примерно: *насколько типичное значение отстоит от среднего.*

Вот дисперсия вручную, чтобы формула не казалась магией:

<CodeExample output={`отклонения: [-4, 4, -3, 3, 0, 5, -2, -3]
квадраты:   [16, 16, 9, 9, 0, 25, 4, 9]
дисперсия:  12.57
std:        3.55`}>

```python
import math

waits = [1, 9, 2, 8, 5, 10, 3, 2]
mean = sum(waits) / len(waits)                # 5.0

deviations = [round(w - mean) for w in waits]
squared = [d ** 2 for d in deviations]
variance = sum(squared) / (len(waits) - 1)    # n - 1, см. ниже
print("отклонения:", deviations)
print("квадраты:  ", squared)
print(f"дисперсия:  {variance:.2f}")
print(f"std:        {math.sqrt(variance):.2f}")
```

</CodeExample>

Почему делим на `n - 1`, а не на `n`? Когда данные — это **выборка (sample)** из чего-то большего (8 ожиданий из всех ожиданий в кафе B), собственное среднее выборки чуть *слишком* близко к её значениям, поэтому деление на `n` занижает настоящий разброс. Деление на `n - 1` это исправляет. На больших данных разница крошечная.

## Разброс в NumPy и pandas

**NumPy** — это библиотека для чисел, на которой построена pandas. Её главный тип, **массив (array)**, похож на список чисел, к которому математика применяется сразу ко всем значениям, — совсем как к столбцу pandas. Подробно вы пройдёте его в уроке [Массивы NumPy](/learn/python/numpy-arrays), а для статистики хватит нескольких методов:

<CodeExample output={`3.32 3.55
3.32 3.55
3.55
[-4.  4. -3.]`}>

```python
import statistics
import numpy as np
import pandas as pd

waits = [1, 9, 2, 8, 5, 10, 3, 2]
print(round(statistics.pstdev(waits), 2),
      round(statistics.stdev(waits), 2))

arr = np.array(waits)
print(round(arr.std(), 2), round(arr.std(ddof=1), 2))

print(round(pd.Series(waits).std(), 2))

print(arr[:3] - arr.mean())     # математика сразу над всеми значениями
```

</CodeExample>

<Callout type="warning" title="Три библиотеки, два стандартных отклонения">

`statistics.stdev` и `.std()` из pandas делят на `n - 1` (это **выборочное** стандартное отклонение). `.std()` из NumPy делит на `n`, если не передать **`ddof=1`**, и `statistics.pstdev` тоже делит на `n` («p» — от *population*, генеральная совокупность). Данные одни, а ответы разные: если ваши числа не совпадают с числами коллеги, проверьте это первым делом.

</Callout>

## Перцентили и IQR

**p-й перцентиль (percentile)** — это значение, ниже которого лежат p% данных. Один вы уже знаете: медиана — это 50-й перцентиль. 25-й и 75-й перцентили называются **квартилями (quartiles)** (Q1 и Q3), а расстояние между ними — **межквартильным размахом (interquartile range, IQR)**: это разброс средней половины данных. В отличие от размаха, крайние значения на него не влияют.

<CodeExample output={`Q1 1.6, медиана 2.15, Q3 3.25
IQR 1.65
90-й перцентиль 3.97
count    12.000000
mean      2.591667
std       1.569284
min       0.800000
10%       1.240000
50%       2.150000
90%       3.970000
max       6.500000
dtype: float64`}>

```python
import numpy as np
import pandas as pd

days = np.array([1.2, 2.0, 1.6, 3.1, 2.3, 0.8, 6.5,
                 1.7, 2.6, 4.0, 1.6, 3.7])   # дни доставки

q1, median, q3 = np.percentile(days, [25, 50, 75])
print(f"Q1 {q1:.1f}, медиана {median:.2f}, Q3 {q3:.2f}")
print(f"IQR {q3 - q1:.2f}")
print(f"90-й перцентиль {np.percentile(days, 90):.2f}")

print(pd.Series(days).describe(percentiles=[0.1, 0.5, 0.9]))
```

</CodeExample>

Итак: типичная доставка занимает около 2 дней, средняя половина заказов приходит за 1,6–3,25 дня, а 90% — за 4 дня. Последним видом чисел профессионалы описывают, например, скорость сайта: *«p95 latency — 300 мс»* означает, что 95% запросов выполняются быстрее 300 мс. Средние значения прячут медленные запросы, которые раздражают пользователей, а высокие перцентили их показывают.

В pandas `series.quantile(0.9)` даёт один перцентиль (в долях), а `describe()`, с которым вы познакомились в уроке [Series и DataFrame](/learn/python/dataframes), по умолчанию показывает квартили.

## Форма распределения

**Распределение (distribution)** столбца — это то, как разбросаны его значения, и гистограмма его показывает. Снова и снова встречаются три формы:

- **Симметричное**: большинство значений в середине, а к краям их одинаково становится меньше (как у роста людей). Среднее ≈ медиана.
- **Скошенное вправо (right-skewed)**: большинство значений небольшие, и есть длинный «хвост» больших (доходы, суммы заказов, время ожидания). Хвост тянет **среднее выше медианы**.
- **Бимодальное (bimodal)**: два пика. Обычно это значит, что смешались две разные группы (обеды и ужины, два типа покупателей). Ни среднее, ни медиана никого толком не описывают.

Запустите код, а потом поменяйте числа, которые задают каждую форму:

<TryIt language="python" code={`import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)
shapes = {

    "Бимодальное: время заказа (час)": np.concatenate([
        rng.normal(12.5, 0.8, 500), rng.normal(19, 1.2, 500)]),

`rng.normal`, `rng.lognormal` и их родственники выдают случайные числа с заданной формой распределения; как устроены генераторы случайных чисел, объяснит следующий урок. А ещё pandas умеет выразить перекос числом с помощью **`.skew()`**: около 0 — симметрично, положительное значение — длинный хвост справа.

## Выбросы

**Выброс (outlier)** — это значение, далёкое от остальных. Это может быть опечатка (доставка, которая шла 95 дней), особый случай (оптовый заказ) или самая интересная точка в данных. Сначала найдите выбросы, *потом* решайте, что с ними делать. Два распространённых правила:

1. **Правило IQR** (его используют ящики с усами): всё, что ниже `Q1 - 1.5 × IQR` или выше `Q3 + 1.5 × IQR`, — выброс.
2. **z-оценки (z-scores)**: на сколько стандартных отклонений значение отстоит от среднего, `z = (x - mean) / std`. Значения с `|z| > 3` (или 2 для маленьких данных) подозрительны.

NumPy фильтрует массивы **масками**, точно так же, как pandas фильтрует строки: сравнение даёт массив из `True`/`False`, а `arr[mask]` оставляет элементы с `True`.

<CodeExample output={`границы: 20.0 до 30.0
правило IQR: [95]
z-оценки: [-0.4 -0.3 -0.3 -0.2 -0.4 -0.2 -0.3 -0.3  3.3 -0.1 -0.5 -0.2]
правило z: [95]
со вторым выбросом: [95 90] а правило z: []`}>

```python
import numpy as np

def iqr_outliers(values):
    q1, q3 = np.percentile(values, [25, 75])
    iqr = q3 - q1
    low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
    return values[(values < low) | (values > high)]

times = np.array([22, 25, 24, 27, 23, 26, 25, 24, 95, 28, 21, 26])
q1, q3 = np.percentile(times, [25, 75])
iqr = q3 - q1
print("границы:", q1 - 1.5 * iqr, "до", q3 + 1.5 * iqr)
print("правило IQR:", iqr_outliers(times))

z = (times - times.mean()) / times.std()
print("z-оценки:", z.round(1))
print("правило z:", times[np.abs(z) > 3])

more = np.append(times, 90)
z_more = (more - more.mean()) / more.std()
print("со вторым выбросом:", iqr_outliers(more),
      "а правило z:", more[np.abs(z_more) > 3])
```

</CodeExample>

Посмотрите на последнюю строку: когда выбросов **два**, правило z не находит **ни одного**. Выбросы раздувают среднее и стандартное отклонение, относительно которых их же и измеряют, поэтому они прячут друг друга. Правило IQR опирается на квартили, которые выбросы почти не сдвигают, поэтому по умолчанию оно надёжнее.

<Callout type="tip" title="Не удаляйте выбросы просто так">

Удалить все выбросы — классический способ обмануть самого себя. Посмотрите на каждый: исправьте опечатки, уберите невозможные значения (отрицательный возраст), но настоящие крайние значения оставьте и упомяните в отчёте. Если они важны, покажите результаты **с ними и без них** или используйте статистики, на которые они не влияют, например медиану и IQR.

</Callout>

## Корреляция

Меняются ли два показателя вместе? Это покажет диаграмма рассеяния, а **коэффициент корреляции (correlation coefficient)** (**r** Пирсона) выразит это числом от -1 до 1:

- **r около 1**: когда один растёт, растёт и другой, почти по прямой линии.
- **r около 0**: прямолинейной связи нет.
- **r около -1**: когда один растёт, другой падает.

Идея формулы такая: для каждой точки умножаем «насколько x выше своего среднего» на «насколько y выше своего среднего». Если большим x обычно соответствуют большие y, эти произведения в основном положительные. r — это среднее произведение, отмасштабированное так, чтобы всегда попадать между -1 и 1.

<TryIt language="python" code={`import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(3)
x = rng.uniform(0, 10, 80)
pairs = {
    "сильная положительная": 2 * x + rng.normal(0, 2, 80),
    "нет связи": rng.normal(10, 5, 80),
    "отрицательная": 20 - 1.5 * x + rng.normal(0, 4, 80),
    "кривая (r её не видит!)": (x - 5) ** 2 + rng.normal(0, 1, 80),
}

fig, axes = plt.subplots(1, 4, figsize=(13, 3.2))
for ax, (name, y) in zip(axes, pairs.items()):
    r = np.corrcoef(x, y)[0, 1]
    ax.scatter(x, y, s=12, color="#0072B2")
    ax.set_title(f"{name}\\nr = {r:.2f}", fontsize=10)

fig.tight_layout()
plt.show()`}
/>

На последнем графике связь сильная, но r близок к 0, потому что r Пирсона измеряет только **прямолинейные** связи. Всегда смотрите на диаграмму рассеяния. Для связей, которые идут в одну сторону, но не по прямой, используйте корреляцию **Спирмена**: `df.corr(method="spearman")`.

В коде `np.corrcoef(x, y)` возвращает таблицу 2 × 2 (x с x, x с y...), поэтому `[0, 1]` выбирает нужное число. А **`df.corr()`** в pandas сразу даёт все пары столбцов:

<CodeExample output={`0.96
          ad_spend  visitors  returns
ad_spend      1.00      0.96     0.14
visitors      0.96      1.00    -0.07
returns       0.14     -0.07     1.00
visitors    0.96
returns     0.14
Name: ad_spend, dtype: float64`}>

```python

import pandas as pd

weeks = pd.DataFrame({
    "ad_spend": [200, 450, 300, 600, 250, 500, 350, 700],
    "visitors": [1100, 1900, 1300, 2600, 1350, 1800, 1700, 2500],
    "returns": [12, 9, 15, 11, 10, 14, 8, 13],

```

</CodeExample>

На диагонали всегда 1 (каждый столбец идеально коррелирует сам с собой), а таблица симметрична. Расходы на рекламу (`ad_spend`) и посетители (`visitors`) тесно связаны, а возвраты (`returns`), похоже, не связаны ни с тем, ни с другим.

## Корреляция — не причинность

Продажи мороженого и солнечные ожоги сильно коррелируют. Вызывает ли мороженое ожоги? Конечно, нет: и то и другое вызывает **жаркая солнечная погода**. Скрытая переменная, которая влияет на обе величины, называется **конфаундером (confounder)**, или скрытой общей причиной:

<CodeExample output={`           temp  ice_cream  sunburn
temp       1.00       0.96     0.92
ice_cream  0.96       1.00     0.86
sunburn    0.92       0.86     1.00
похожие дни: 0.05`}>

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
temp = rng.uniform(5, 32, 200)                    # °C, 200 дней
days = pd.DataFrame({
    "temp": temp,
    "ice_cream": 20 + 6 * temp + rng.normal(0, 15, 200),
    "sunburn": 0.8 * temp + rng.normal(0, 3, 200),
})
print(days.corr().round(2))

# Сравниваем только дни с примерно одинаковой температурой
similar = days[days["temp"].between(24, 28)]
r = similar["ice_cream"].corr(similar["sunburn"])
print("похожие дни:", round(r, 2))
```

</CodeExample>

По всем дням у мороженого и ожогов r = 0,86. Но если сравнить только дни с **похожей температурой**, связь почти исчезает: мороженое ничьей коже не вредило. Зафиксировать конфаундер (хотя бы примерно) — один из способов проверить подозрительную корреляцию. А самый надёжный способ доказать причину и следствие — **эксперимент**: вы намеренно меняете одну вещь и случайно решаете, кто её получит. Именно это делает A/B-тест в конце модуля.

## Всегда рисуйте свои данные

В 1973 году статистик Фрэнсис Энскомб опубликовал четыре крошечных набора данных (datasets), которые теперь называют **квартетом Энскомба (Anscombe's quartet)**. Их сводные статистики практически одинаковы:

```python
import numpy as np
import pandas as pd

days = [1.2, 2.0, 1.6, 3.1, 2.3, 0.8, 9.5, 1.7, 2.6, 4.0, 1.6, 3.7]

def summary(values):
    q1, q3 = np.percentile(values, [25, 75])
    stats = {
        "mean": np.mean(values),
        "median": np.median(values),
        "std": np.std(values, ddof=1),
        "q1": q1,
        "q3": q3,
        "iqr": q3 - q1,
    }
    return {name: round(float(v), 2) for name, v in stats.items()}

def outliers(values):
    q1, q3 = np.percentile(values, [25, 75])
    iqr = q3 - q1
    low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
    return [v for v in values if v < low or v > high]

def strongest_link(df, target):
    r = df.corr()[target].drop(target)
    return r.abs().idxmax()

orders = pd.DataFrame({
    "days": [1, 2, 3, 4, 5, 6],
    "rating": [5.0, 4.8, 4.1, 3.9, 3.0, 2.2],
    "price": [20, 35, 15, 40, 25, 30],
    "items": [2, 1, 3, 2, 1, 2],
})

print(summary(days))
print(outliers(days))
print(strongest_link(orders, "days"))
```

## Итоги

- **Среднее** — для симметричных данных и сумм, **медиана** — для скошенных данных (доходы, цены, время ожидания), **мода** — для категорий.
- **Разброс**: размах, дисперсия (средний квадрат расстояния от среднего) и **стандартное отклонение** (корень из дисперсии, в исходных единицах).
- Выборочное std делит на `n - 1`: так делают `statistics.stdev` и pandas, а NumPy нужен **`ddof=1`**.
- **Перцентили** (`np.percentile`, `quantile`) говорят: «p% значений ниже этого»; **IQR** — разброс средней половины, крайние значения его не трогают.
- Читайте **форму**: симметричное, скошенное вправо (среднее > медианы) или бимодальное (смешались две группы).
- Ищите **выбросы** правилом IQR (надёжнее) или z-оценками; разберитесь с ними, прежде чем что-то удалять.
- **Корреляция** (`np.corrcoef`, `df.corr()`) измеряет прямолинейные связи от -1 до 1. Это не причинность: ищите конфаундеры.
- Сводные числа могут скрыть всё самое интересное: **всегда рисуйте свои данные**.
