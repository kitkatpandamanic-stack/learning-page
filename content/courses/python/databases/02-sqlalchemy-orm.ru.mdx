Чистый SQL работает, но в большом приложении он становится однообразным: вы снова и снова пишете одни и те же строки с `INSERT`, строки результата приходят обычными кортежами, а опечатка в имени столбца обнаруживается, только когда выполнится именно эта строка кода. **ORM** (Object-Relational Mapper, объектно-реляционное отображение) позволяет работать с **объектами Python**, а SQL пишет за вас. 🧩

**SQLAlchemy** — самый популярный инструмент для работы с базами данных в Python. Именно его обычно используют в проектах на FastAPI, и он работает с SQLite, PostgreSQL, MySQL и другими базами. В этом уроке мы пишем в современном стиле **SQLAlchemy 2.0**.

## Зачем нужна ORM?

В ORM **класс** описывает таблицу, а каждый **объект** этого класса — одну строку:

- `Book(title="Dune")` вместо `INSERT INTO books ...`
- `book.title` вместо `row[1]`
- `select(Book).where(Book.pages > 300)` вместо строки, написанной вручную (и по-прежнему с безопасными параметрами, так что SQL-инъекций не будет)
- один и тот же код работает с SQLite в тестах и с PostgreSQL в продакшене

Понимать SQL всё равно нужно (именно он выполняется под капотом, и при отладке вы будете его читать), но писать его придётся гораздо меньше.

## Описываем модель

**Модель (model)** — это класс, унаследованный от `DeclarativeBase` вашего проекта. Каждый атрибут с аннотацией **`Mapped[...]`** становится столбцом:

<CodeExample output={`Book(id=None, title='Dune')
Book(id=1, title='Dune')`}>

```python
from sqlalchemy import create_engine, String
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, mapped_column, Session,
)

class Base(DeclarativeBase):
    pass

class Book(Base):
    __tablename__ = "books"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(200))
    author: Mapped[str]
    year: Mapped[int | None]    # NULL разрешён

    def __repr__(self):
        return f"Book(id={self.id}, title={self.title!r})"

engine = create_engine("sqlite://")   # SQLite в памяти
Base.metadata.create_all(engine)      # CREATE TABLE books ...

with Session(engine) as session:
    dune = Book(title="Dune", author="Frank Herbert", year=1965)
    print(dune)
    session.add(dune)
    session.commit()
    print(dune)
```

</CodeExample>

Разберём по шагам:

- **`class Base(DeclarativeBase)`**: в каждом проекте создают один базовый класс; от него наследуются все модели, а он хранит список их таблиц в `Base.metadata`.
- **`__tablename__`** — имя таблицы в базе данных.
- **`Mapped[int]`** выбирает тип столбца по аннотации типа (type annotation). `Mapped[str]` — обязательное значение (`NOT NULL`); `Mapped[int | None]` может быть пустым (`NULL`).
- **`mapped_column(...)`** добавляет дополнительные настройки: `primary_key=True`, максимальную длину через `String(200)`, `default=...`, `unique=True`, `index=True`. Если ничего из этого не нужно, его можно не писать.
- **`create_engine("sqlite://")`**: **движок (engine)** знает, как подключиться к базе данных. В настоящем приложении URL указывал бы на файл или сервер, например `"sqlite:///library.db"` или `"postgresql+psycopg://user:pw@host/db"`.
- **`Base.metadata.create_all(engine)`** создаёт все таблицы, которых ещё нет. SQLAlchemy пишет за вас примерно такой SQL:

```sql
CREATE TABLE books (
    id INTEGER NOT NULL,
    title VARCHAR(200) NOT NULL,
    author VARCHAR NOT NULL,
    year INTEGER,
    PRIMARY KEY (id)
)
```

Ещё вы бесплатно получаете `__init__`, который принимает столбцы как именованные аргументы. `__repr__` писать необязательно, но с ним печатать объекты (и отлаживать код) гораздо приятнее.

## Сессия: add и commit

С базой данных вы общаетесь через **сессию (session)** — объект **`Session`**. Представьте её как корзину в магазине: `session.add(obj)` кладёт в корзину новые или изменённые объекты, а **`session.commit()`** отправляет всё в базу данных одной транзакцией. Обратите внимание: в примере выше `dune.id` был `None` до коммита, а потом база выдала id `1`, и SQLAlchemy его подставила.

`with Session(engine) as session:` закрывает сессию в конце блока. Всё, что вы не закоммитили, **выбрасывается**:

<CodeExample output={`[]
['Emma']`}>

```python
from sqlalchemy import create_engine, select
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, mapped_column, Session,
)

class Base(DeclarativeBase):
    pass

class Book(Base):
    __tablename__ = "books"
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str]

engine = create_engine("sqlite://")
Base.metadata.create_all(engine)

with Session(engine) as session:
    session.add(Book(title="Dune"))
    # упс: нет session.commit()

with Session(engine) as session:
    print(session.scalars(select(Book)).all())

with Session(engine) as session:
    session.add(Book(title="Emma"))
    session.commit()

with Session(engine) as session:
    print(session.scalars(select(Book.title)).all())
```

</CodeExample>

<Callout type="warning" title="Забыли закоммитить?">

Самый частый баг при работе с ORM: код выполняется без ошибок, но данные потом так и не появляются. Если вы вызвали `add()` или изменили объекты, обязательно сделайте `session.commit()`. Если что-то пошло не так на полпути, `session.rollback()` (или просто выход из блока `with` с исключением) отменяет всю транзакцию — точно так же, как `with conn:` в sqlite3.

</Callout>

## Запросы через select()

Чтобы прочитать данные, соберите инструкцию с помощью **`select()`** и выполните её через **`session.scalars()`**. К ней по цепочке добавляются `.where()`, `.order_by()` и `.limit()`, а атрибуты модели участвуют в обычных сравнениях Python:

<CodeExample output={`[Book('The BFG', 208), Book('Matilda', 240), Book('Dune', 412)]
Book('Matilda', 240)
Book('Emma', 474)
None
['Dune', 'Emma', 'Matilda', 'The BFG']
4`}>

```python
from sqlalchemy import create_engine, select, func
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, mapped_column, Session,
)

class Base(DeclarativeBase):
    pass

class Book(Base):
    __tablename__ = "books"
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str]
    author: Mapped[str]
    pages: Mapped[int]

    def __repr__(self):
        return f"Book({self.title!r}, {self.pages})"

engine = create_engine("sqlite://")
Base.metadata.create_all(engine)

with Session(engine) as session:
    session.add_all([
        Book(title="Dune", author="Frank Herbert", pages=412),
        Book(title="Emma", author="Jane Austen", pages=474),
        Book(title="Matilda", author="Roald Dahl", pages=240),
        Book(title="The BFG", author="Roald Dahl", pages=208),
    ])
    session.commit()

    stmt = select(Book).where(Book.pages < 450).order_by(Book.pages)
    print(session.scalars(stmt).all())

    dahl = select(Book).where(Book.author == "Roald Dahl")
    print(session.scalars(dahl.limit(1)).first())

    print(session.get(Book, 2))
    print(session.get(Book, 99))

    titles = session.scalars(select(Book.title)).all()
    print(titles)

    count = session.scalar(select(func.count()).select_from(Book))
    print(count)
```

</CodeExample>

- **`session.scalars(stmt)`** выполняет запрос и отдаёт объекты; `.all()` делает из них список, `.first()` возвращает первый (или `None`). По результату можно и просто пройти циклом.
- **`session.get(Book, 2)`** — быстрый способ загрузить одну строку **по первичному ключу**. Если такой строки нет, вернётся `None`.
- `select(Book.title)` выбирает только один столбец, поэтому в ответ приходят обычные строки.
- **`func`** даёт доступ к функциям SQL: `func.count()`, `func.sum(Book.pages)`, `func.avg(...)`. **`session.scalar()`** (без s на конце) возвращает одно значение.
- Другие фильтры: `Book.title.like("D%")`, `Book.id.in_([1, 3])`, `Book.year.is_(None)`, несколько условий через `.where(a, b)` (должны выполняться оба) и `.order_by(Book.pages.desc())`, чтобы сначала шли самые большие значения.

## Обновление и удаление

Чтобы **обновить** строку, загрузите объект, измените его атрибуты и закоммитьте: SQLAlchemy сама заметит, что изменилось, и выполнит `UPDATE`. Чтобы **удалить**, передайте объект в **`session.delete()`**. А для изменения сразу многих строк выполните инструкцию `update()` или `delete()` через `session.execute()`:

<CodeExample output={`обновлено: 2
1 Dune (deluxe) 422
2 Emma 484`}>

```python
from sqlalchemy import create_engine, select, update, delete
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, mapped_column, Session,
)

class Base(DeclarativeBase):
    pass

class Book(Base):
    __tablename__ = "books"
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str]
    pages: Mapped[int]

engine = create_engine("sqlite://")
Base.metadata.create_all(engine)

with Session(engine) as session:
    session.add_all([Book(title="Dune", pages=412),
                     Book(title="Emma", pages=474),
                     Book(title="Up", pages=48)])
    session.commit()

    dune = session.get(Book, 1)
    dune.title = "Dune (deluxe)"   # просто меняем атрибут
    session.delete(session.get(Book, 3))
    session.commit()

    result = session.execute(
        update(Book).values(pages=Book.pages + 10)
    )
    print("обновлено:", result.rowcount)
    session.commit()

    for book in session.scalars(select(Book)):
        print(book.id, book.title, book.pages)
```

</CodeExample>

`delete(Book).where(Book.pages < 100)` работает так же, как инструкция `update()`. И, как в чистом SQL, `update()` или `delete()` **без** `.where()` затрагивает все строки.

<Callout type="tip" title="Как это устроено в реальных проектах">

В настоящем приложении модели живут в `models.py`, движок создаётся один раз в `database.py`, а вы пишете небольшие функции вроде `get_book(session, book_id)`, которые принимают сессию как параметр. Тогда эндпоинт FastAPI может передавать свою сессию для каждого запроса, а тест — сессию со свежей базой в памяти. Именно так вы и сделаете в итоговом проекте.

</Callout>

```python
from sqlalchemy import create_engine, select
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, mapped_column, Session,
)

class Base(DeclarativeBase):
    pass


class Movie(Base):
    __tablename__ = "movies"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str]
    year: Mapped[int]
    rating: Mapped[int | None]

    def __repr__(self):
        return f"Movie({self.title!r}, rating={self.rating})"


def new_session():
    engine = create_engine("sqlite://")
    Base.metadata.create_all(engine)
    return Session(engine)


def add_movie(session, title, year):
    movie = Movie(title=title, year=year)
    session.add(movie)
    session.commit()
    return movie


def rate_movie(session, movie_id, rating):
    movie = session.get(Movie, movie_id)
    if movie is None:
        return False
    movie.rating = rating
    session.commit()
    return True


def top_rated(session, limit):
    stmt = (
        select(Movie.title)
        .where(Movie.rating.is_not(None))
        .order_by(Movie.rating.desc(), Movie.title)
        .limit(limit)
    )
    return list(session.scalars(stmt))


def delete_movie(session, movie_id):
    movie = session.get(Movie, movie_id)
    if movie is None:
        return False
    session.delete(movie)
    session.commit()
    return True


with new_session() as session:
    up = add_movie(session, "Up", 2009)
    add_movie(session, "Coco", 2017)
    rate_movie(session, up.id, 8)
    print(top_rated(session, 5))
```

## Итоги

- **ORM** связывает классы с таблицами, а объекты — со строками, пишет SQL за вас и всегда использует безопасные параметры.
- Модели наследуются от подкласса `DeclarativeBase`; столбцы объявляются как `Mapped[type]`, а `mapped_column()` задаёт настройки вроде `primary_key=True`. `Mapped[int | None]` разрешает `NULL`.
- `create_engine(url)` подключается к базе; `Base.metadata.create_all(engine)` создаёт таблицы.
- Работайте внутри `with Session(engine) as session:`: `add()` / `add_all()`, затем **`commit()`**. Незакоммиченная работа откатывается.
- Читайте через `session.scalars(select(Model).where(...).order_by(...).limit(...))`, одну строку по ключу — через `session.get(Model, id)`, одиночные значения — через `session.scalar()`.
- Обновляйте, меняя атрибуты и делая коммит; удаляйте через `session.delete(obj)`; массовые изменения — инструкциями `update()` / `delete()` в `session.execute()`.
