Use `for` when you know **how many times** to repeat. Use `while` when you only know **when to stop**.

## while

<CodeExample output={`Balance: 100
Balance: 75
Balance: 50
Balance: 25
Out of money!`}>

```python
balance = 100

while balance > 0:
    print(f"Balance: {balance}")
    balance -= 25

print("Out of money!")
```

</CodeExample>

<Callout type="danger" title="Infinite loops">

If the condition never becomes `False`, the loop runs **forever**. Make sure something inside moves it towards the end, like `balance -= 25`. (PandaDev stops runaway code after a few seconds.)

</Callout>

## break: stop early

<CodeExample output={`Checking 3
Checking 8
Found the first even number: 8`}>

```python
numbers = [3, 8, 5, 12]

for n in numbers:
    print(f"Checking {n}")
    if n % 2 == 0:
        print(f"Found the first even number: {n}")
        break
```

</CodeExample>

`[3, 8, 5, 12]` is a **list**. You'll meet lists properly in the next lesson.

## continue: skip to the next round

<CodeExample output={`1
3
5`}>

```python
for i in range(1, 7):
    if i % 2 == 0:
        continue  # skip even numbers
    print(i)
```

</CodeExample>

## Repeat until: while True + break

Python has no `do...while` loop. Instead, loop forever and `break` when you're done:

<CodeExample output="Rolled: 6">

```python
import random

while True:
    roll = random.randint(1, 6)  # a dice roll from 1 to 6
    if roll == 6:
        break

print(f"Rolled: {roll}")
```

</CodeExample>

`import random` loads Python's built-in module for random numbers.

<Exercise

steps = 0

# Double n until it is bigger than 1000, counting the steps
`}
  expectedOutput="1024 after 10 doublings"

Starting from `n = 1`, keep doubling `n` in a `while` loop until it is bigger than `1000`. Then print the result like `1024 after 10 doublings`.

<Solution>

```python
n = 1
steps = 0

while n <= 1000:
    n *= 2
    steps += 1

print(f"{n} after {steps} doublings")
```

</Solution>

</Exercise>

## Recap

- `while condition:` repeats until the condition is `False`.
- `break` leaves a loop; `continue` skips to the next round.
- `while True:` + `break` is Python's "repeat until".
