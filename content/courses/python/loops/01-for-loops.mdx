Printing the numbers 1 to 100 by hand would take 100 lines. A **loop** does it in two.

## for + range

<CodeExample output={`1
2
3
4
5`}>

```python
for i in range(1, 6):
    print(i)
```

</CodeExample>

- `range(1, 6)` produces the numbers 1, 2, 3, 4, 5. The **stop value is not included**.
- On each round (an **iteration**), `i` takes the next number.
- The indented block is what gets repeated.

## Three ways to call range

| Call                  | Numbers               |
| --------------------- | --------------------- |
| `range(5)`            | 0, 1, 2, 3, 4         |
| `range(1, 6)`         | 1, 2, 3, 4, 5         |
| `range(10, 0, -2)`    | 10, 8, 6, 4, 2        |

<CodeExample output={`10 8 6 4 2
Lift-off! 🚀`}>

```python
line = ""
for i in range(10, 0, -2):
    line += str(i) + " "
print(line.strip())
print("Lift-off! 🚀")
```

</CodeExample>

## Doing work in a loop

Add up the numbers 1 to 100:

<CodeExample output="5050">

```python
total = 0
for i in range(1, 101):
    total += i
print(total)
```

</CodeExample>

<Callout type="note">

`total` is created **before** the loop. If you created it inside, it would be reset to `0` on every iteration.

</Callout>

## Looping over a string

A `for` loop can walk through any sequence, like the letters of a string:

<CodeExample output={`P
a
n
d
a`}>

```python
for letter in "Panda":
    print(letter)
```

</CodeExample>

<Callout type="tip">

`range(1, 101)` stops at 100. Forgetting that the stop value is excluded is a classic **off-by-one error**.

</Callout>

## Recap

- `for i in range(start, stop, step):` repeats code; `stop` is excluded.
- Create accumulators like `total` before the loop.
- `for` can loop over strings (and lists, next lessons).
