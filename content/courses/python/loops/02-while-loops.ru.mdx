Используйте `for`, когда знаете, **сколько раз** нужно повторить. Используйте `while`, когда знаете только, **когда остановиться**.

## while

Цикл (loop) `while` повторяется, пока его условие (condition) истинно:

<CodeExample output={`Баланс: 100
Баланс: 75
Баланс: 50
Баланс: 25
Деньги закончились!`}>

```python
balance = 100

while balance > 0:
    print(f"Баланс: {balance}")
    balance -= 25

print("Деньги закончились!")
```

</CodeExample>

<Callout type="danger" title="Бесконечные циклы">

Если условие никогда не станет `False`, цикл будет работать **вечно**. Убедитесь, что что-то внутри цикла приближает его к концу, например `balance -= 25`. (PandaDev останавливает зависший код через несколько секунд.)

</Callout>

## break: досрочный выход

<CodeExample output={`Проверяю 3
Проверяю 8
Первое чётное число: 8`}>

```python
numbers = [3, 8, 5, 12]

for n in numbers:
    print(f"Проверяю {n}")
    if n % 2 == 0:
        print(f"Первое чётное число: {n}")
        break
```

</CodeExample>

`[3, 8, 5, 12]` — это **список** (list). Как следует вы познакомитесь со списками в следующем уроке.

## continue: переход к следующему кругу

<CodeExample output={`1
3
5`}>

```python
for i in range(1, 7):
    if i % 2 == 0:
        continue  # пропускаем чётные числа
    print(i)
```

</CodeExample>

## «Повторять, пока не»: while True + break

В Python нет цикла `do...while`. Вместо него запустите бесконечный цикл и выйдите из него с помощью `break`, когда закончите:

<CodeExample output="Выпало: 6">

```python
import random

while True:
    roll = random.randint(1, 6)  # бросок кубика: от 1 до 6
    if roll == 6:
        break

print(f"Выпало: {roll}")
```

</CodeExample>

`import random` загружает встроенный **модуль** (module) Python для работы со случайными числами.

Начните с `n = 1` и удваивайте `n` в цикле `while`, пока оно не станет больше `1000`. Затем выведите результат в виде `1024 после 10 удвоений`.

<Solution>

```python
n = 1
steps = 0

while n <= 1000:
    n *= 2
    steps += 1

print(f"{n} после {steps} удвоений")
```

</Solution>

## Итоги

- `while condition:` повторяет код, пока условие не станет `False`.
- `break` выходит из цикла; `continue` переходит к следующему кругу.
- `while True:` + `break` — это «повторять, пока не» в Python.
