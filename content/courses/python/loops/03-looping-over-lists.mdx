A **list** holds several values in order. Loops and lists are best friends.

## Making a list

<CodeExample output={`['apples', 'bananas', 'mangoes']
3
apples`}>

```python
fruits = ["apples", "bananas"]
fruits.append("mangoes")   # add to the end
print(fruits)
print(len(fruits))
print(fruits[0])
```

</CodeExample>

Lists use square brackets. Like strings, positions start at `0`, and `len()` counts the items.

## for over a list

<CodeExample output={`I like apples
I like bananas
I like mangoes`}>

```python
fruits = ["apples", "bananas", "mangoes"]

for fruit in fruits:
    print(f"I like {fruit}")
```

</CodeExample>

Read it as *"for each fruit in fruits"*. No counter, no off-by-one errors.

## Numbering items with enumerate

Need the position too? `enumerate` gives you both:

<CodeExample output={`1. apples
2. bananas
3. mangoes`}>

```python
fruits = ["apples", "bananas", "mangoes"]

for number, fruit in enumerate(fruits, start=1):
    print(f"{number}. {fruit}")
```

</CodeExample>

## Counting with a loop

<CodeExample output="3">

```python
count = 0
for letter in "banana":
    if letter == "a":
        count += 1
print(count)
```

</CodeExample>

<Callout type="tip" title="Built-in helpers">

Python has shortcuts for common jobs: `sum(numbers)`, `max(numbers)`, `min(numbers)` and `"banana".count("a")`. Writing the loop yourself first helps you understand what they do.

</Callout>

<Exercise

# Find the highest score with a for loop (no max()!) and print it
`}
  expectedOutput="95"

Using a `for` loop (not `max()`), find the **highest** score in `scores` and print it.

<Hint>

Start with `highest = 0` before the loop. Inside, if the current score is bigger than `highest`, replace it.

</Hint>

<Solution>

```python
scores = [72, 95, 88, 61]
highest = 0

for score in scores:
    if score > highest:
        highest = score

print(highest)
```

</Solution>

</Exercise>

## Recap

- Lists: `[1, 2, 3]`, `.append()`, `len()`, `items[0]`.
- `for item in items:` visits every item.
- `enumerate(items, start=1)` adds a position number.
