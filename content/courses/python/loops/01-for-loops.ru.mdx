Чтобы вывести числа от 1 до 100 вручную, понадобилось бы 100 строк. **Цикл** (loop) справится за две.

## for + range

<CodeExample output={`1
2
3
4
5`}>

```python
for i in range(1, 6):
    print(i)
```

</CodeExample>

- `range(1, 6)` выдаёт числа 1, 2, 3, 4, 5. **Конечное значение не включается**.
- На каждом круге (**итерации**, iteration) `i` принимает следующее число.
- Повторяется блок с отступом.

## Три способа вызвать range

| Вызов                 | Числа                 |
| --------------------- | --------------------- |
| `range(5)`            | 0, 1, 2, 3, 4         |
| `range(1, 6)`         | 1, 2, 3, 4, 5         |
| `range(10, 0, -2)`    | 10, 8, 6, 4, 2        |

<CodeExample output={`10 8 6 4 2
Старт! 🚀`}>

```python
line = ""
for i in range(10, 0, -2):
    line += str(i) + " "
print(line.strip())
print("Старт! 🚀")
```

</CodeExample>

## Работа внутри цикла

Сложим числа от 1 до 100:

<CodeExample output="5050">

```python
total = 0
for i in range(1, 101):
    total += i
print(total)
```

</CodeExample>

<Callout type="note">

`total` создаётся **до** цикла. Если создать его внутри, он будет сбрасываться в `0` на каждой итерации.

</Callout>

## Перебор строки

Цикл `for` может пройти по любой последовательности, например по буквам строки:

<CodeExample output={`П
а
н
д
а`}>

```python
for letter in "Панда":
    print(letter)
```

</CodeExample>

<Callout type="tip">

`range(1, 101)` останавливается на 100. Если забыть, что конечное значение не включается, получится классическая **ошибка на единицу** (off-by-one error).

</Callout>

## Итоги

- `for i in range(start, stop, step):` повторяет код; `stop` не включается.
- Переменные-накопители вроде `total` создавайте до цикла.
- `for` умеет перебирать строки (и списки — о них в следующих уроках).
