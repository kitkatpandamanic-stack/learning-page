**Список** (list) хранит несколько значений по порядку. Циклы и списки — лучшие друзья.

## Создание списка

<CodeExample output={`['яблоки', 'бананы', 'манго']
3
яблоки`}>

```python
fruits = ["яблоки", "бананы"]
fruits.append("манго")   # добавляем в конец
print(fruits)
print(len(fruits))
print(fruits[0])
```

</CodeExample>

Списки записываются в квадратных скобках. Как и в строках, позиции начинаются с `0`, а `len()` считает элементы.

## for по списку

<CodeExample output={`Я люблю яблоки
Я люблю бананы
Я люблю манго`}>

```python
fruits = ["яблоки", "бананы", "манго"]

for fruit in fruits:
    print(f"Я люблю {fruit}")
```

</CodeExample>

Читайте это как *«для каждого fruit в fruits»*. Никаких счётчиков и ошибок на единицу.

## Нумерация элементов с enumerate

Нужна ещё и позиция? `enumerate` даёт и то и другое:

<CodeExample output={`1. яблоки
2. бананы
3. манго`}>

```python
fruits = ["яблоки", "бананы", "манго"]

for number, fruit in enumerate(fruits, start=1):
    print(f"{number}. {fruit}")
```

</CodeExample>

## Подсчёт с помощью цикла

<CodeExample output="3">

```python
count = 0
for letter in "ананас":
    if letter == "а":
        count += 1
print(count)
```

</CodeExample>

<Callout type="tip" title="Встроенные помощники">

В Python есть готовые решения для частых задач: `sum(numbers)`, `max(numbers)`, `min(numbers)` и `"ананас".count("а")`. Если сначала написать цикл самостоятельно, станет понятнее, что они делают.

</Callout>

С помощью цикла `for` (не используя `max()`) найдите **наибольший** результат в `scores` и выведите его.

<Hint>

Перед циклом задайте `highest = 0`. Внутри цикла, если текущий результат больше `highest`, замените его.

</Hint>

<Solution>

```python
scores = [72, 95, 88, 61]
highest = 0

for score in scores:
    if score > highest:
        highest = score

print(highest)
```

</Solution>

</Exercise>

## Итоги

- Списки: `[1, 2, 3]`, `.append()`, `len()`, `items[0]`.
- `for item in items:` проходит по каждому элементу.
- `enumerate(items, start=1)` добавляет номер позиции.
