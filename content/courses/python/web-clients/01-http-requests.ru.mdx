В уроке [Ваш первый API на FastAPI](/learn/python/first-api) вы написали **серверную** сторону HTTP: эндпоинты, которые принимают запросы и отвечают JSON. Теперь вы перейдёте на другую сторону и напишете **клиент (client)** — код на Python, который обращается к чужому API. Сервисы погоды, платёжные системы, GitHub, AI-модели, другие сервисы вашей компании — все они говорят на том же HTTP, который вы уже знаете, поэтому несколько строк на Python могут общаться с любым из них. 🌍

Вы будете использовать самую популярную HTTP-библиотеку Python — **requests**, а также её современную родственницу **httpx**.

## Учебный API

Настоящие сайты из уроков на этом сайте недоступны, поэтому у PandaDev есть **учебный API** по адресу `https://api.pandadev.test`. Ваш код действительно обращается к нему через `requests` или `httpx`, но отвечает ваш браузер, и ничего не покидает ваш компьютер. В нём есть фильмы, погода, рецепты, пользователи, посты и полноценный список дел (`GET`, `POST`, `PATCH`, `PUT`, `DELETE`), а каждый запуск начинается со свежих данных.

На своём компьютере вы сначала установили бы библиотеки, и тогда подойдёт любой URL:

```bash
pip install requests httpx
```

```python
import requests

r = requests.get("https://api.github.com/repos/python/cpython", timeout=10)
print(r.json()["stargazers_count"])
```

## Ваш первый запрос

`requests.get(url)` отправляет запрос `GET` и возвращает объект **ответа (response)**:

<CodeExample output={`200
application/json; charset=utf-8
{'id': 1, 'name': 'Mei Lin', 'username': 'mei', 'email': 'mei@pandadev.test'}
Mei Lin — логин mei`}>

```python
import requests

response = requests.get(
    "https://api.pandadev.test/users/1", timeout=5
)
print(response.status_code)
print(response.headers["Content-Type"])

user = response.json()
print(user)
print(user["name"], "— логин", user["username"])
```

</CodeExample>

Это зеркальное отражение ваших приложений на FastAPI: там вы **возвращали** словарь, а FastAPI превращал его в JSON; здесь `response.json()` превращает JSON обратно в словарь. `timeout=5` означает «сдаться через 5 секунд». Чуть позже вы увидите, почему тайм-аут нужен каждому запросу.

## Параметры запроса через params=

Чтобы отфильтровать результаты или листать их постранично, API принимают **параметры запроса (query parameters)** после `?`. Можно склеить URL f-строкой, но лучше поручить это `params=`:

<CodeExample output={`https://api.pandadev.test/movies?genre=comedy&limit=2
Найдено: 4 | страница 1 из 2
2019 The Bamboo Heist
2021 The Last Dumpling
https://api.pandadev.test/recipes?search=soy+sauce
['Bamboo Shoot Stir-fry']`}>

```python
import requests

BASE = "https://api.pandadev.test"

params = {"genre": "comedy", "limit": 2}
r = requests.get(f"{BASE}/movies", params=params, timeout=5)
print(r.url)

data = r.json()
print("Найдено:", data["total"], "| страница", data["page"], "из",
      data["totalPages"])
for movie in data["results"]:
    print(movie["year"], movie["title"])

r = requests.get(f"{BASE}/recipes",
                 params={"search": "soy sauce"}, timeout=5)
print(r.url)
print([recipe["name"] for recipe in r.json()])
```

</CodeExample>

`r.url` показывает URL, который был запрошен на самом деле. Обратите внимание: пробел в `soy sauce` превратился в `+`. Внутри значения в URL не может быть пробелов, `&`, `#` или `?`, поэтому их нужно **кодировать (encode)**. С f-строкой вроде `f"{BASE}/recipes?search={text}"` поиск `fish & chips` молча превратился бы в два сломанных параметра. `params=` всегда кодирует правильно, а параметры со значением `None` просто пропускает.

Кроме того, список фильмов **разбит на страницы (paginated)**: нашлось 4 комедии, но вы получили только страницу 1 из 2. Как пройти по всем страницам, вы узнаете в следующем уроке.

## Читаем ответ

В ответе есть всё, что прислал сервер:

| Атрибут | Что это |
| --- | --- |
| `r.status_code` | `200`, `404`, ... |
| `r.reason` | то же словами: `"OK"`, `"Not Found"` |
| `r.ok` | `True` для любого кода меньше 400 |
| `r.headers` | заголовки ответа (словарь, которому не важен регистр букв) |
| `r.text` | тело ответа в виде строки |
| `r.json()` | тело ответа, разобранное как JSON |
| `r.url` | итоговый URL |

Самое важное, что нужно понять: **404 или 500 — это не исключение**. Запрос прошёл успешно, просто сервер ответил «нет». Ваш код спокойно продолжит работу, если вы не проверите ответ. Короткий путь — **`raise_for_status()`**: этот метод выбрасывает `requests.HTTPError` для любого ответа 4xx или 5xx и ничего не делает в остальных случаях:

<CodeExample output={`404 Not Found False
{"error":"Movie not found"}
{'error': 'Movie not found'}
Ошибка: 404 Client Error: Not Found for url: https://api.pandadev.test/movies/99
Midnight in the Forest`}>

```python
import requests

BASE = "https://api.pandadev.test"

r = requests.get(f"{BASE}/movies/99", timeout=5)
print(r.status_code, r.reason, r.ok)
print(r.text)
print(r.json())

try:
    r.raise_for_status()
except requests.HTTPError as error:
    print("Ошибка:", error)

r = requests.get(f"{BASE}/movies/3", timeout=5)
r.raise_for_status()   # 200: ничего не делает
print(r.json()["title"])
```

</CodeExample>

<Callout type="warning" title="Проверяйте код ответа до того, как брать данные">

Очень частая ошибка — `r.json()["title"]` на ответе с ошибкой. Тело там `{"error": "Movie not found"}`, и вы получаете непонятную `KeyError: 'title'` далеко от настоящей проблемы. Вызывайте `r.raise_for_status()` (или проверяйте `r.status_code`) **сразу после** каждого запроса, чтобы сбои проявлялись там, где они случились.

</Callout>

## Отправляем данные: POST, PATCH и DELETE

`requests.post`, `requests.put`, `requests.patch` и `requests.delete` работают так же, как `get`. Чтобы отправить тело в формате JSON, передайте словарь в **`json=`**. requests сам превратит его в JSON и выставит заголовок `Content-Type: application/json`. Вот список дел учебного API — такой же API вы создали в [проекте «API списка дел»](/learn/python/todo-api):

<CodeExample output={`201 {'id': 4, 'title': 'Полить бамбук', 'done': False}
application/json
200 {'id': 4, 'title': 'Полить бамбук', 'done': True}
204 ''
404 {'error': 'Todo not found'}
400 {'error': 'title is required'}`}>

```python
import requests

BASE = "https://api.pandadev.test"

new = {"title": "Полить бамбук", "done": False}
r = requests.post(f"{BASE}/todos", json=new, timeout=5)
print(r.status_code, r.json())
print(r.request.headers["Content-Type"])
todo_id = r.json()["id"]

r = requests.patch(f"{BASE}/todos/{todo_id}",
                   json={"done": True}, timeout=5)
print(r.status_code, r.json())

r = requests.delete(f"{BASE}/todos/{todo_id}", timeout=5)
print(r.status_code, repr(r.text))

r = requests.get(f"{BASE}/todos/{todo_id}", timeout=5)
print(r.status_code, r.json())

r = requests.post(f"{BASE}/todos", json={"done": True}, timeout=5)
print(r.status_code, r.json())
```

</CodeExample>

- `r.request` — это запрос, который был отправлен на самом деле. Удобно, чтобы проверить, что именно ушло по сети.
- У ответа `204 No Content` пустое тело, поэтому вызов `r.json()` на нём упадёт. Сначала проверяйте код ответа.
- В последнем запросе забыли название, поэтому API ответил `400 Bad Request`. (Ваши приложения на FastAPI отвечали на неверные данные кодом 422; разные API ведут себя по-разному, так что читайте их документацию.)

Не путайте `json=` и `data=`: `data={"title": "..."}` отправляет данные в старом формате **формы** (`title=...`), как это делает HTML-форма. Большинству API нужен `json=`.

## Заголовки запроса: кто вы и чего хотите

Заголовки (headers) передаются с каждым запросом. Вот три, которые вы будете задавать часто:

- **`Accept: application/json`** сообщает, в каком формате вы хотите получить ответ.
- **`User-Agent`** сообщает, какая программа обращается к серверу. По умолчанию requests отправляет `python-requests/<version>`; вежливые клиенты называют себя и оставляют контакт.
- **`Authorization: Bearer <token>`** подтверждает, кто вы. Большинство API выдают вам секретный **API-ключ (API key)** или **токен (token)**, который нужно отправлять с каждым запросом.

<CodeExample output={`200 пользователей: 3
panda-report/1.0 (mei@example.com)
True
python-requests`}>

```python
import os
import requests

# Только для этого примера: делаем вид, что переменную задали в терминале
os.environ.setdefault("PANDA_API_TOKEN", "demo-token-123")

token = os.environ["PANDA_API_TOKEN"]
headers = {
    "Accept": "application/json",
    "User-Agent": "panda-report/1.0 (mei@example.com)",
    "Authorization": f"Bearer {token}",
}
r = requests.get("https://api.pandadev.test/users",
                 headers=headers, timeout=5)
print(r.status_code, "пользователей:", len(r.json()))

sent = r.request.headers
print(sent["User-Agent"])
print(sent["Authorization"].startswith("Bearer "))

r = requests.get("https://api.pandadev.test/users", timeout=5)
print(r.request.headers["User-Agent"].split("/")[0])
```

</CodeExample>

Учебный API токены не проверяет, а настоящие без действующего токена отвечают `401 Unauthorized`.

<Callout type="danger" title="Никогда не пишите токен в коде">

Токены — это пароли. Код попадает на GitHub, его вставляют в чаты, он навсегда остаётся в истории git, а боты находят ключи в публичных репозиториях за считаные минуты. Вместо этого читайте секреты из **переменной окружения (environment variable)**, которая задаётся вне кода (или загружается из файла `.env`, указанного в `.gitignore`):

```bash
export PANDA_API_TOKEN="paste-your-token-here"
python report.py
```

Тогда `os.environ["PANDA_API_TOKEN"]` громко упадёт с `KeyError`, если переменной нет, — именно это вам и нужно. И никогда не печатайте токен, даже «просто для отладки».

</Callout>

## Сессии: общие настройки для многих запросов

Настоящие клиенты делают много запросов к одному и тому же API с одними и теми же заголовками. **`requests.Session`** запоминает заголовки (и cookie) для каждого запроса, сделанного через неё, и повторно использует сетевое соединение, поэтому повторные запросы к тому же серверу заметно быстрее:

<CodeExample output={`Sam Ortiz
['Debugging like a detective', "CSS is hard, and that's fine"]
31
panda-report/1.0`}>

```python
import requests

BASE = "https://api.pandadev.test"

session = requests.Session()
session.headers.update({
    "User-Agent": "panda-report/1.0",
    "Accept": "application/json",
})

def api_get(path, **params):
    r = session.get(BASE + path, params=params, timeout=5)
    r.raise_for_status()
    return r.json()

print(api_get("/users/2")["name"])
print([p["title"] for p in api_get("/posts", userId=3)])
print(api_get("/weather", city="Cairo")["temperature"])

r = session.get(BASE + "/users", timeout=5)
print(r.request.headers["User-Agent"])
session.close()
```

</CodeExample>

Маленький помощник `api_get` — приём, который встречается во многих проектах: **одно место**, которое знает базовый URL, тайм-аут и то, как обрабатывать ошибки. `Session` также работает как менеджер контекста (`with requests.Session() as session:`) и сам закрывается в конце блока.

## Всегда задавайте тайм-аут

Вот сюрприз: по умолчанию requests ждёт **вечно**. Если сервер принял соединение и так и не ответил, ваша программа зависнет, а задача по расписанию может простоять так несколько дней. Всегда передавайте `timeout=`. Эндпоинт `/delay/<ms>` учебного API нарочно отвечает медленно:

<CodeExample output={`Не дождались: ReadTimeout
{'waited': 200}`}>

```python
import requests

BASE = "https://api.pandadev.test"

try:
    requests.get(f"{BASE}/delay/500", timeout=0.2)
except requests.Timeout as error:
    print("Не дождались:", type(error).__name__)

r = requests.get(f"{BASE}/delay/200", timeout=2)
print(r.json())
```

</CodeExample>

Первому запросу нужно было 0,5 с, а разрешили только 0,2 с, поэтому он выбросил **`requests.Timeout`** (точнее, `ReadTimeout`). Второй уложился вовремя. Можно передать и два числа, `timeout=(3, 10)`: до 3 с на подключение и до 10 с на ожидание ответа.

## httpx: современная альтернатива

У **httpx** почти такой же API, как у requests, плюс несколько современных возможностей: тайм-аут 5 секунд по умолчанию, `base_url` для клиентов, HTTP/2 и **асинхронный** клиент (вы воспользуетесь им в следующем уроке). Его `Client` — это аналог `Session`:

<CodeExample output={`200 True
Tokyo: 22°C, Rain
201 {'id': 4, 'title': 'Попробовать httpx', 'done': False}
Ошибка: 404 {'error': 'Movie not found'}`}>

```python
import httpx

client = httpx.Client(
    base_url="https://api.pandadev.test",
    headers={"User-Agent": "panda-report/1.0"},
    timeout=5,
)
with client:
    r = client.get("/weather", params={"city": "Tokyo"})
    print(r.status_code, r.is_success)
    w = r.json()
    print(f"{w['city']}: {w['temperature']}°C, {w['condition']}")

    r = client.post("/todos", json={"title": "Попробовать httpx"})
    print(r.status_code, r.json())

    r = client.get("/movies/99")
    try:
        r.raise_for_status()
    except httpx.HTTPStatusError as error:
        print("Ошибка:", error.response.status_code,
              error.response.json())
```

</CodeExample>

| | requests | httpx |
| --- | --- | --- |
| Быстрый вызов | `requests.get(url, timeout=5)` | `httpx.get(url)` |
| Общие настройки | `requests.Session()` | `httpx.Client(base_url=...)` |
| Тайм-аут по умолчанию | нет (ждёт вечно) | 5 секунд |
| Ошибка по коду ответа | `requests.HTTPError` | `httpx.HTTPStatusError` |
| Асинхронность | нет | `httpx.AsyncClient` |
| Перенаправления | выполняются | не выполняются без `follow_redirects=True` |

Какую выбрать? Обе отличные. requests встречается повсюду в существующем коде и учебниках; httpx — прекрасный выбор для новых проектов, особенно асинхронных. Если вы знаете одну, вы знаете 95% другой.

Напишите три небольшие функции для клиента учебного API. Передавайте `timeout=5` в каждый запрос.

1. `make_session(token)` возвращает `requests.Session`, которая отправляет `Accept: application/json` и `Authorization: Bearer <token>` с каждым запросом.
2. `find_movies(session, search, genre=None)` вызывает `GET /movies` через сессию с параметрами запроса `search`, `limit=50` и — только если он не `None` — `genre`. Она возвращает список названий из `results`. (Без `limit=50` вы получите только первые 5 совпадений!)
3. `add_todo(session, title)` отправляет `POST /todos` с телом JSON `{"title": title, "done": False}`. Если API отвечает кодом ошибки, функция выбрасывает `requests.HTTPError`, иначе возвращает новую задачу в виде словаря.

Программа должна напечатать два списка названий и новую задачу `{'id': 4, 'title': 'Почитать про сессии', 'done': False}`.

<Hint>

В `make_session` создайте `requests.Session()` и вызовите `session.headers.update({...})` с f-строкой для токена. В `find_movies` соберите словарь `params` с `search` и `limit`, внутри `if` добавьте `params["genre"] = genre`, затем вызовите `session.get(f"{BASE}/movies", params=params, timeout=5)` и пройдитесь списковым включением по `r.json()["results"]`. В `add_todo` используйте `session.post(..., json={...}, timeout=5)`, а затем `r.raise_for_status()` перед `return r.json()`.

</Hint>

<Solution>

```python
import requests

BASE = "https://api.pandadev.test"

def make_session(token):
    session = requests.Session()
    session.headers.update({
        "Accept": "application/json",
        "Authorization": f"Bearer {token}",
    })
    return session

def find_movies(session, search, genre=None):
    params = {"search": search, "limit": 50}
    if genre is not None:
        params["genre"] = genre
    r = session.get(f"{BASE}/movies", params=params, timeout=5)
    r.raise_for_status()
    return [movie["title"] for movie in r.json()["results"]]

def add_todo(session, title):
    r = session.post(f"{BASE}/todos",
                     json={"title": title, "done": False}, timeout=5)
    r.raise_for_status()
    return r.json()

session = make_session("demo-token")
print(find_movies(session, "bamboo"))
print(find_movies(session, "", genre="family"))
print(add_todo(session, "Почитать про сессии"))
```

</Solution>

</Exercise>

## Итоги

- **requests** — это клиентская сторона HTTP: `requests.get/post/put/patch/delete(url, ...)` возвращают ответ с `.status_code`, `.headers`, `.text`, `.json()` и `.url`.
- Используйте **`params=`** для параметров запроса (правильное кодирование, значения `None` пропускаются) и **`json=`**, чтобы отправить тело в формате JSON.
- Ответ 4xx/5xx — **не** исключение: вызывайте **`r.raise_for_status()`** сразу после запроса.
- Заголовки вроде `Accept`, `User-Agent` и **`Authorization: Bearer <token>`** передаются в `headers=`. Токены берутся из **переменных окружения**, а не из кода и не из логов.
- **`Session`** использует общие заголовки и соединения для всех запросов; оберните её в небольшой помощник, который знает базовый URL, тайм-аут и обработку ошибок.
- **Всегда задавайте тайм-аут**: по умолчанию requests ждёт вечно, а при превышении лимита выбрасывает **`requests.Timeout`**.
- **httpx** работает почти так же (`httpx.Client(base_url=..., timeout=...)`), но у него есть тайм-аут по умолчанию и асинхронный клиент.
