Не у каждого сайта есть API. Цены в интернет-магазине, расписания, таблицы результатов, объявления о вакансиях — часто эти данные есть только на **веб-страницах**, сделанных для людей. **Веб-скрапинг (web scraping)** — это когда вы загружаете такие страницы кодом и выбираете данные из HTML. С `requests` и библиотекой **Beautiful Soup** небольшой скрапер занимает около 20 строк. 🥣

В этом уроке вы будете собирать данные с сайта **Panda Books** — выдуманного букинистического магазина, который живёт в учебном API по адресу `https://api.pandadev.test/shop`: 18 книг на 3 страницах, категории и отдельная страница для каждой книги.

## Скрапить или использовать API?

**Всегда сначала ищите API.** API отдаёт чистый JSON в задокументированном стабильном формате. Веб-страница сделана для человеческих глаз: её HTML может измениться в любой день, когда кто-то переделает дизайн сайта, и ваш скрапер молча сломается. Скрапьте, только когда API нет (или в нём нет нужных данных), и сначала проверьте правила сайта:

- **Условия использования (terms of service).** Многие сайты прямо пишут, разрешён ли автоматический доступ. Следуйте этим правилам.
- **robots.txt.** В файле `/robots.txt` сайты перечисляют пути, которые роботам (краулерам и скраперам) можно и нельзя посещать. Позже в этом уроке вы прочитаете его на Python.
- **Будьте деликатны.** Скрипт может отправлять сотни запросов в секунду — этого достаточно, чтобы небольшой сайт начал тормозить у всех. Делайте паузы между запросами и не скачивайте одну и ту же страницу снова и снова.
- **Персональные данные.** Имена, адреса электронной почты и фотографии людей защищены законами вроде GDPR, даже если они видны всем. Не собирайте их без ясного законного основания.
- **Авторское право.** Факты вроде цен обычно можно собирать для анализа, а вот перепубликовывать чужие статьи или фотографии — нельзя.

## HTML за две минуты и ваш первый «суп»

HTML состоит из **элементов (elements)** вроде `<li class="book" data-id="4">...</li>`: имя **тега (tag)** (`li`), **атрибуты (attributes)** (`class`, `data-id`) и содержимое, в котором могут быть другие элементы. Beautiful Soup читает HTML-текст и превращает его в дерево объектов Python, по которому можно искать. Устанавливается она командой `pip install beautifulsoup4`, а импортируется как `bs4`:

<CodeExample output={`Меню на сегодня
Бамбуковый суп ['dish', 'veggie'] 4.50
- Бамбуковый суп 4.50
- Пельмени новинка! None
- Зелёный чай 3.00
2
/order
None`}>

```python
from bs4 import BeautifulSoup

html = """
<div id="menu">
  <h2>Меню на сегодня</h2>
  <ul>
    <li class="dish veggie" data-price="4.50">Бамбуковый суп</li>
    <li class="dish">Пельмени <b>новинка!</b></li>
    <li class="dish veggie" data-price="3.00">Зелёный чай</li>
  </ul>
  <a href="/order">Заказать</a>
</div>
"""
soup = BeautifulSoup(html, "html.parser")

print(soup.h2.get_text())
first = soup.find("li")
print(first.get_text(), first["class"], first["data-price"])

for dish in soup.find_all("li", class_="dish"):
    print("-", dish.get_text(" ", strip=True),
          dish.get("data-price"))

print(len(soup.find_all("li", class_="veggie")))
print(soup.find("a")["href"])
print(soup.find("table"))
```

</CodeExample>

- `BeautifulSoup(html, "html.parser")` разбирает текст встроенным в Python HTML-парсером.
- `soup.h2` — короткая запись для первого `<h2>`; **`find(...)`** возвращает первый подходящий элемент (или **`None`**), **`find_all(...)`** — список всех подходящих.
- `class_="dish"` (с подчёркиванием, потому что `class` — ключевое слово Python) находит элементы с этим классом, даже если классов у элемента несколько.
- **`get_text()`** возвращает текст внутри элемента, включая вложенные элементы. `get_text(" ", strip=True)` склеивает кусочки через пробел и обрезает пробельные символы.
- Элемент работает как словарь для своих **атрибутов**: `first["data-price"]`. `class` возвращается списком, потому что классов может быть несколько. `dish.get("data-price")` возвращает `None` вместо того, чтобы выбросить `KeyError`, если атрибута нет.

## CSS-селекторы на настоящей странице

Писать `find` внутри `find` получается длинно. **CSS-селекторы (CSS selectors)** — те же шаблоны, что веб-дизайнеры используют в таблицах стилей, — описывают путь одной строкой. **`select(...)`** возвращает все совпадения, **`select_one(...)`** — первое (или `None`):

| Селектор | Что находит |
| --- | --- |
| `li` | каждый `<li>` |
| `.price` | элементы с `class="price"` |
| `li.book` | элементы `<li>` с классом `book` |
| `#menu` | элемент с `id="menu"` |
| `.title a` | `<a>` где угодно **внутри** `.title` |
| `ul.books > li` | `<li>` **непосредственно** внутри `ul.books` |
| `a[rel="next"]` | `<a>`, у которого атрибут `rel` равен `next` |
| `[data-stars]` | любой элемент с атрибутом `data-stars` |

Вот первая страница магазина. (Совет: на настоящем сайте щёлкните по элементу правой кнопкой мыши в браузере и выберите **Inspect** («Посмотреть код» / «Проверить»), чтобы увидеть его HTML и классы.)

<CodeExample output={`200 text/html; charset=utf-8
All books · Panda Books
Showing 1–6 of 18 books
Page 1 of 3
книг на этой странице: 6
1 The Bamboo Code /shop/1
2 Midnight Library Cats /shop/2
3 Stars for Beginners /shop/3
['Fiction', 'Science', 'Programming', 'Kids']
/shop?page=2`}>


## Очищаем значения

Всё, что вы собираете, — это **текст** для людей: `"$6.50"`, `"by Kenji Mori"`, `"★★★★★"`. Прежде чем что-то сортировать или усреднять, превратите это в нормальные значения Python. Ищите самый простой надёжный источник: звёзды в `★★★★☆` считать неудобно, зато в атрибуте `data-stars` лежит обычное число, а наличие товара указано в классе:

<CodeExample output={`{'id': 7, 'title': 'Why the Sky Is Blue', 'author': 'Ada Brooks', 'price': 11.0, 'stars': 5, 'in_stock': True}
{'id': 8, 'title': "Dragons Can't Dance", 'author': 'Ravi Patel', 'price': 7.25, 'stars': 4, 'in_stock': False}
{'id': 9, 'title': 'Algorithms in Pictures', 'author': 'Kenji Mori', 'price': 29.0, 'stars': 5, 'in_stock': True}
Самая дешёвая: Counting with Coco 5.99`}>

```python
import requests
from bs4 import BeautifulSoup

def parse_book(li):
    price_text = li.select_one(".price").get_text(strip=True)
    author_text = li.select_one(".author").get_text(strip=True)
    stock = li.select_one(".stock")
    return {
        "id": int(li["data-id"]),
        "title": li.select_one(".title a").get_text(strip=True),
        "author": author_text.removeprefix("by "),
        "price": float(price_text.removeprefix("$")),
        "stars": int(li.select_one(".rating")["data-stars"]),
        "in_stock": "in-stock" in stock["class"],
    }

r = requests.get("https://api.pandadev.test/shop?page=2",
                 timeout=5)
soup = BeautifulSoup(r.text, "html.parser")
books = [parse_book(li) for li in soup.select("li.book")]
for book in books[:3]:
    print(book)
cheapest = min(books, key=lambda b: b["price"])
print("Самая дешёвая:", cheapest["title"], cheapest["price"])
```

</CodeExample>

`str.removeprefix` удаляет префикс, только если он есть, — это надёжнее, чем отрезать фиксированное число символов. На настоящих сайтах вам попадётся текст и посложнее, например `"£1,299.00"`, `"Only 3 left!"` или `"12 Jan 2026"`: методы строк, регулярные выражения и разбор дат через `datetime` из уроков [Регулярные выражения](/learn/python/regular-expressions) и [Даты и время](/learn/python/dates-and-times) — как раз подходящие инструменты. Для денег в настоящем бухгалтерском коде используйте `Decimal`, а не `float`.

## Переходим по ссылкам между страницами

Ссылки на веб-страницах обычно **относительные (relative)**: `href="/shop/4"` означает «на этом же сайте». Чтобы запросить их, превратите их в полные URL с помощью **`urllib.parse.urljoin(page_url, href)`** — она разрешает ссылки точно так же, как браузер:

<CodeExample output={`https://api.pandadev.test/shop/4
https://api.pandadev.test/shop?page=3
https://api.pandadev.test/reviews
https://example.com/x`}>

```python
from urllib.parse import urljoin

page = "https://api.pandadev.test/shop?page=2"
print(urljoin(page, "/shop/4"))
print(urljoin(page, "?page=3"))
print(urljoin(page, "reviews"))
print(urljoin(page, "https://example.com/x"))
```

</CodeExample>

Теперь скрапер может **обходить сайт (crawl)**: загрузить страницу, перейти по её ссылке «Next» (`a[rel="next"]`) и остановиться, когда такой ссылки нет. Это HTML-версия цикла постраничной загрузки из [прошлого урока](/learn/python/robust-api-clients), и снова генератор делает код аккуратным:

<CodeExample output={`/shop -> книг: 6
/shop?page=2 -> книг: 6
/shop?page=3 -> книг: 6
названий: 18, последнее: The Map of Lost Things`}>

```python
import requests
from bs4 import BeautifulSoup
from urllib.parse import urljoin

BASE = "https://api.pandadev.test"

def crawl_pages(session, url):
    while url:
        r = session.get(url, timeout=5)
        r.raise_for_status()
        soup = BeautifulSoup(r.text, "html.parser")
        yield url, soup
        next_link = soup.select_one('a[rel="next"]')
        url = urljoin(url, next_link["href"]) if next_link else None

titles = []
with requests.Session() as session:
    session.headers["User-Agent"] = "panda-scraper/1.0"
    for url, soup in crawl_pages(session, BASE + "/shop"):
        links = soup.select("li.book .title a")
        print(url.removeprefix(BASE), "-> книг:", len(links))
        titles += [a.get_text() for a in links]
print(f"названий: {len(titles)}, последнее:", titles[-1])
```

</CodeExample>

Переходить по собственной ссылке сайта «Next» надёжнее, чем угадывать URL вроде `?page=4`: если сайт поменяет нумерацию страниц, ваш краулер всё равно будет работать и остановится ровно на последней странице.

## Страницы с подробностями

Страницы-списки показывают краткую сводку, а полная информация лежит на **странице с подробностями (detail page)** каждого элемента. Там часто встречаются таблицы, и словарное включение (dict comprehension) превращает таблицу из двух столбцов в словарь:

<CodeExample output={`Panda Goes to School
{'Category': 'Kids', 'Published': '2022', 'Pages': '32'}
Mei (5/5): My daughter asks for it every night.
Ravi (5/5): Lovely drawings.
Ada (4/5): Sweet story.
404 Book not found`}>

```python
import requests
from bs4 import BeautifulSoup

r = requests.get("https://api.pandadev.test/shop/4", timeout=5)
soup = BeautifulSoup(r.text, "html.parser")
book = soup.select_one("article.book-detail")

print(book.h2.get_text())
details = {
    row.th.get_text(): row.td.get_text()
    for row in book.select("table.details tr")
}
print(details)

for review in book.select("section.reviews li.review"):
    name = review.select_one(".reviewer").get_text()
    stars = review.select_one(".stars")["data-stars"]
    text = review.p.get_text()
    print(f"{name} ({stars}/5): {text}")

missing = requests.get("https://api.pandadev.test/shop/99",
                       timeout=5)
print(missing.status_code,
      BeautifulSoup(missing.text, "html.parser").h2.get_text())
```

</CodeExample>

Обратите внимание на последний запрос: на отсутствующую страницу веб-серверы отвечают **кодом 404 и дружелюбной HTML-страницей**. Если не проверить `status_code` (или не вызвать `raise_for_status()`), скрапер радостно разберёт страницу ошибки так, будто это книга.

Чтобы обойти все страницы с подробностями, нужен один запрос на каждый элемент. Для 18 книг это нормально, но для 10 000 товаров подумайте дважды: может быть, нужные данные уже есть на страницах-списках?

## Читаем robots.txt

Правила магазина для роботов лежат в `/robots.txt`. Стандартная библиотека Python умеет их читать с помощью **`urllib.robotparser`**. Обычно `RobotFileParser` сам скачивает файл через `rp.set_url(...)` и `rp.read()`, но он использует `urllib` вместо requests и не может достучаться до учебного API, поэтому здесь вы скачиваете текст через requests и передаёте его строки в **`parse()`**. Это в любом случае хорошая привычка: ваш запрос использует вашу сессию, тайм-аут и User-Agent:

<CodeExample output={`# Rules for robots (scrapers and crawlers) on this site
User-agent: *
Allow: /shop
Disallow: /todos
Crawl-delay: 1

/shop True
/shop/7 True
/shop?page=2 True
/todos False
Пауза между запросами: 1`}>

```python
import requests
from urllib.robotparser import RobotFileParser

BASE = "https://api.pandadev.test"
AGENT = "panda-scraper/1.0"

text = requests.get(BASE + "/robots.txt", timeout=5).text
print(text)

robots = RobotFileParser()
robots.parse(text.splitlines())
for path in ["/shop", "/shop/7", "/shop?page=2", "/todos"]:
    print(path, robots.can_fetch(AGENT, BASE + path))
print("Пауза между запросами:", robots.crawl_delay(AGENT))
```

</CodeExample>

- `User-agent: *` означает, что правила действуют для всех роботов. Для отдельных ботов у сайта могут быть свои правила.
- `Allow` и `Disallow` перечисляют **префиксы** путей: `/shop` распространяется и на `/shop/7`, и на `/shop?page=2`.
- **`can_fetch(agent, url)`** отвечает на вопрос, который скрапер должен задавать перед **каждым** запросом.
- `Crawl-delay: 1` просит роботов выжидать 1 секунду между запросами.

## Ведём себя вежливо

Вежливый скрапер ведёт себя как аккуратный посетитель-человек, а не как атака:

- **Представляйтесь**: `User-Agent` должен называть ваш проект и давать контакт, например `panda-report/1.0 (mei@example.com)`. Никогда не притворяйтесь браузером, чтобы обойти блокировку.
- **Делайте паузы между запросами**: `time.sleep(robots.crawl_delay(AGENT) or 1)` между страницами. (Примеры здесь пропускают паузу, чтобы выполняться мгновенно; настоящий скрапер так делать не должен.)
- **Используйте одну `Session`**, чтобы соединения переиспользовались, и **сохраняйте уже скачанные страницы**, а не загружайте их заново, пока отлаживаете парсер.
- **Останавливайтесь при ошибках.** Много ответов 429 или 503 означает «помедленнее»; делайте паузы, как вы научились в [прошлом уроке](/learn/python/robust-api-clients).
- Запускайте большие задачи в спокойное время и собирайте только то, что нужно.

## Скраперы, которые не ломаются от любой мелочи

Веб-страницы меняются. Скрапер, который вчера работал, сегодня может возвращать чепуху, и хуже всего — **тихий** сбой: никакой ошибки, просто неверные или пропавшие данные в вашем отчёте. Помогут несколько привычек:

<CodeExample output={`The Bamboo Code | $12.50
The Bamboo Code | ?
Магазин сообщает: книг — 18`}>

```python
import re
from bs4 import BeautifulSoup

def text_of(element, selector, default=None):
    found = element.select_one(selector)
    if found is None:
        return default
    return found.get_text(strip=True)

before = """<li class="book" data-id="1">
  <h3 class="title"><a href="/shop/1">The Bamboo Code</a></h3>
  <p class="price">$12.50</p></li>"""
after = """<li class="book" data-id="1">
  <h3 class="title"><a href="/shop/1">The Bamboo Code</a></h3>
  <p class="price-now">$11.90</p></li>"""

for html in [before, after]:
    li = BeautifulSoup(html, "html.parser").li
    print(text_of(li, ".title a"), "|", text_of(li, ".price", "?"))

summary = "Showing 1–6 of 18 books"
match = re.search(r"of (\d+) books", summary)
print("Магазин сообщает: книг —", int(match.group(1)))
```

</CodeExample>

- **Выбирайте стабильные «зацепки».** Осмысленные классы (`.price`), id и атрибуты `data-` меняются реже, чем вёрстка. Избегайте селекторов вроде `div > div:nth-child(3) > span`: они ломаются, стоит чему-нибудь сдвинуться.
- **Будьте готовы к тому, что чего-то не будет.** `select_one` возвращает `None`, когда совпадений нет, а `None.get_text()` падает с `AttributeError`. Помощник вроде `text_of` делает необязательные поля явными.
- **Проверяйте результаты.** Сравнивайте собранное с тем, что пишет сама страница («Showing 1–6 of **18** books»), проверяйте, что цены положительные, и **громко падайте**, когда числа не сходятся.
- **Тестируйте парсер офлайн.** Сохраните копию настоящей страницы в файл и напишите тесты pytest, которые запускают на ней ваши функции разбора. Держите загрузку и разбор в разных функциях, чтобы парсер можно было тестировать без сети.

<Callout type="note" title="Страницы, которые строит JavaScript">

Некоторые сайты присылают почти пустую HTML-страницу и строят содержимое с помощью JavaScript прямо в браузере. `requests` не выполняет JavaScript, поэтому Beautiful Soup ничего не увидит. Сначала загляните на вкладку **Network** в инструментах разработчика браузера: часто страница загружает данные из JSON API, к которому можно обратиться напрямую, — так гораздо проще. Если нет, инструмент **автоматизации браузера (browser automation)** вроде Playwright управляет настоящим браузером за вас (на своём компьютере: `pip install playwright`, затем `playwright install chromium`):

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com/books")
    page.wait_for_selector("li.book")
    html = page.content()       # HTML после выполнения JavaScript
    browser.close()
```

```python
import requests
from bs4 import BeautifulSoup
from urllib.parse import urljoin
from urllib.robotparser import RobotFileParser

BASE = "https://api.pandadev.test"
AGENT = "panda-scraper/1.0"

def parse_books(html, page_url):
    soup = BeautifulSoup(html, "html.parser")
    books = []
    for li in soup.select("li.book"):
        link = li.select_one(".title a")
        price = li.select_one(".price").get_text(strip=True)
        author = li.select_one(".author").get_text(strip=True)
        stock = li.select_one(".stock")
        books.append({
            "id": int(li["data-id"]),
            "title": link.get_text(strip=True),
            "author": author.removeprefix("by "),
            "price": float(price.removeprefix("$")),
            "stars": int(li.select_one(".rating")["data-stars"]),
            "in_stock": "in-stock" in stock["class"],
            "url": urljoin(page_url, link["href"]),
        })
    return books

def crawl(session, start_url, robots):
    books = []
    url = start_url
    while url and robots.can_fetch(AGENT, url):
        r = session.get(url, timeout=5)
        r.raise_for_status()
        books += parse_books(r.text, url)
        soup = BeautifulSoup(r.text, "html.parser")
        next_link = soup.select_one('a[rel="next"]')
        url = urljoin(url, next_link["href"]) if next_link else None
    return books

robots = RobotFileParser()
robots.parse(requests.get(BASE + "/robots.txt", timeout=5)
             .text.splitlines())
with requests.Session() as session:
    session.headers["User-Agent"] = AGENT
    books = crawl(session, BASE + "/shop", robots)
print(len(books), "книг")
print(books[3:4])
print(sum(book["in_stock"] for book in books), "в наличии")
```
