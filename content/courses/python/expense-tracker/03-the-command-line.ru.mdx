У вас есть модель с проверками (часть 1) и файлы, которые всё помнят (часть 2). Пора добавить последний слой — **командную строку**. 🎉 Пользователь вводит команды вроде `add 12.50 food Lunch`, `list`, `report` или `delete 2`, а трекер отвечает.

В этой части пригодятся **методы строк** вроде `split()`, **f-строки** со спецификаторами формата, **словари** для группировки, **`try`/`except`** для понятных сообщений об ошибках и `if __name__ == "__main__"` из урока про модули.

`input()` в браузере не работает, поэтому наша функция `run(commands, path)` принимает **список команд**, который заменяет то, что ввёл бы пользователь. В конце вы увидите настоящую версию с `input()`, которую можно запустить на своём компьютере.

Как и раньше, команды, категории и все сообщения трекера остаются на английском — переводим только комментарии в коде.

| Команда                  | Что она делает                                 |
| ------------------------ | ---------------------------------------------- |
| `add 12.50 food Lunch`   | Добавить расход с сегодняшней датой            |
| `list`                   | Показать все расходы с номерами                |
| `total`                  | Показать общую сумму трат                      |
| `report`                 | Итоги по месяцам и категориям                  |
| `delete 2`               | Удалить расход номер 2                         |
| `save`                   | Сохранить в файл                               |
| `quit`                   | Выйти                                          |

## Разбиваем команду на слова

`split()` разбивает команду на слова. Но в описании тоже могут быть пробелы («Lunch with Sam»), поэтому для `add` мы используем **`maxsplit=3`**: разбить не больше трёх раз, а остаток оставить целиком:

<CodeExample output={`['add', '12.50', 'food', 'Lunch', 'with', 'Sam']
['add', '12.50', 'food', 'Lunch with Sam']`}>

```python
command = "add 12.50 food Lunch with Sam"
print(command.split())
print(command.split(maxsplit=3))
```

</CodeExample>

Первое слово — это **действие**. Мы переводим его в нижний регистр с помощью `.lower()`, чтобы `ADD` и `Add` тоже работали.

## Понятные ошибки при неверном вводе

Люди вводят что-нибудь вроде `add lots food Cake`. `float("lots")` выбрасывает `ValueError` с довольно техническим сообщением. Мы перехватываем его и выбрасываем собственное **`ExpenseError`** с более понятным:

<CodeExample output={`12.5
Error: '3,25' is not a number
Error: 'lots' is not a number`}>

```python
class ExpenseError(Exception):
    pass

def parse_amount(text):
    try:
        return float(text)
    except ValueError:
        raise ExpenseError(f"'{text}' is not a number")

for text in ["12.50", "3,25", "lots"]:
    try:
        print(parse_amount(text))
    except ExpenseError as err:
        print("Error:", err)
```

</CodeExample>

Обратите внимание на `'3,25'`: Python понимает только точку в качестве десятичного разделителя, поэтому сумму с запятой он числом не считает.

Вот функция `add_command` из проекта. Она использует ту же идею, а остальное (сумму, категорию и дату) проверяет `Expense` из первой части:

```python
def add_command(tracker, command, today):
    words = command.split(maxsplit=3)
    if len(words) < 4:
        raise ExpenseError("Try: add AMOUNT CATEGORY DESCRIPTION")
    try:
        amount = float(words[1])
    except ValueError:
        raise ExpenseError(f"'{words[1]}' is not a number")
    expense = Expense(amount, words[2].lower(), words[3], today)
    tracker.add(expense)
    print(f"Added {amount:.2f} for {expense.description}")
```

Любая проблема превращается в `ExpenseError`, поэтому один `except ExpenseError` в цикле команд может аккуратно напечатать **их все**. `today` передаётся как строка `"YYYY-MM-DD"`, а не вычисляется внутри — так функцию легко тестировать (тот же трюк, что и с передачей случайных чисел).

## Выравниваем столбцы

Список или отчёт гораздо легче читать, когда столбцы выровнены. Внутри фигурных скобок f-строки **спецификатор формата (format spec)** после двоеточия управляет шириной:

<CodeExample output={`|food        |   17.25|
|transport   |    3.25|
|fun         |  120.00|`}>

```python
rows = [("food", 17.25), ("transport", 3.25), ("fun", 120)]
for category, amount in rows:
    print(f"|{category:<12}|{amount:>8.2f}|")
```

</CodeExample>

- **`:<12`** выравнивает текст по левому краю в поле шириной 12 символов.
- **`:>8.2f`** выравнивает число по правому краю в поле из 8 символов, с 2 знаками после точки. Суммы, выровненные по правому краю, ставят десятичные точки друг под другом.
- **`:>3`** для числа (например, `f"{number:>3}."`) выравнивает `1.` и `10.` в команде `list`.

Символы `|` нужны только для того, чтобы показать вам пробелы.

## Группировка по месяцам

Для отчёта нам нужны расходы **по месяцам**. Месяц — это первые семь символов даты, а сгруппировать их поможет словарь, как в шаблоне подсчёта:

<CodeExample output="{'2026-03': ['2026-03-02', '2026-03-14'], '2026-04': ['2026-04-01']}">

```python
dates = ["2026-03-02", "2026-04-01", "2026-03-14"]

    if month not in months:

print(months)
```

</CodeExample>

## Цикл команд

Теперь сердце программы. `handle_command()` выполняет **одну** команду и возвращает `False`, когда пора остановиться. `run()` передаёт ей команды одну за другой и **повторяет** каждую после `> `, чтобы вывод выглядел как настоящая сессия. Вот этот шаблон на крошечной игрушечной программе:

<CodeExample output={`> hello
Hi there!
> shout good morning
GOOD MORNING
> dance
Error: Unknown command 'dance'
> quit
Bye!`}>

```python
def handle_command(command):
    """Runs one command. Returns False when it's time to quit."""
    words = command.split()
    if not words:
        return True
    action = words[0].lower()
    if action == "quit":
        print("Bye!")
        return False
    elif action == "hello":
        print("Hi there!")
    elif action == "shout":
        print(" ".join(words[1:]).upper())
    else:
        print(f"Error: Unknown command '{action}'")
    return True

def run(commands):
    for command in commands:
        print(f"> {command}")
        if not handle_command(command):
            break

run(["hello", "shout good morning", "dance", "quit", "hello"])
```

</CodeExample>

Последний `hello` так и не выполняется: `quit` вернул `False`, и `break` завершил цикл.

В трекере `handle_command(tracker, command, path, today)` оборачивает всю цепочку `if`/`elif` в **`try`/`except ExpenseError as err`** и печатает `Error: {err}`. Неизвестная команда тоже просто **выбрасывает** `ExpenseError`. Как бы ни ошибся пользователь, он получит одну понятную строку, а программа продолжит работу. 💪

<Callout type="tip" title="Зачем разделять handle_command и run?">

`run()` читает команды из списка, а настоящая программа — из `input()`. Обе просто вызывают `handle_command()`, поэтому вся логика общая, а версию со списком можно тестировать автоматически.

</Callout>

## Запуск на своём компьютере

Скопируйте готовый код в файл `tracker.py`, добавьте `import sys` к импортам вверху и замените демонстрацию внизу этой функцией `main()`. Она крутится бесконечно в `while True`, читая настоящие команды через `input()`:

```python
def main():
    path = sys.argv[1] if len(sys.argv) > 1 else "expenses.csv"
    today = datetime.date.today().isoformat()
    tracker = load(path)
    print(f"Loaded {len(tracker)} expenses from {path}.")
    print("Commands: add, list, total, report, delete, save, quit")
    while True:
        try:
            command = input("> ")
        except (EOFError, KeyboardInterrupt):
            command = "quit"
        if not handle_command(tracker, command, path, today):
            break


if __name__ == "__main__":
    main()
```

- **`sys.argv`** — это список слов, введённых после `python` в терминале (terminal). `sys.argv[0]` — имя скрипта, так что `sys.argv[1]` — необязательное имя файла.
- Нажатие **Ctrl+C** (или Ctrl+D) обычно обрывает программу с трассировкой (traceback); мы считаем его командой `quit`.
- `if __name__ == "__main__":` означает, что `main()` запускается, только когда вы запускаете файл напрямую, а не когда другой файл импортирует ваши классы.

```python
import csv
import datetime
import json
from dataclasses import asdict, dataclass
from pathlib import Path

CATEGORIES = ["food", "transport", "bills", "fun", "other"]


class ExpenseError(Exception):
    """Raised when an expense or a command isn't valid."""


@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str  # "YYYY-MM-DD"

    def __post_init__(self):
        if self.amount <= 0:
            raise ExpenseError(
                f"Amount must be more than 0, not {self.amount}"
            )
        if self.category not in CATEGORIES:
            options = ", ".join(CATEGORIES)
            raise ExpenseError(
                f"Unknown category '{self.category}'"
                f" (use one of: {options})"
            )
        try:
            datetime.date.fromisoformat(self.date)
        except ValueError:
            raise ExpenseError(
                f"Date must look like YYYY-MM-DD, not '{self.date}'"
            )

    @classmethod
    def from_dict(cls, data):
        return cls(
            float(data["amount"]),
            data["category"],
            data["description"],
            data["date"],
        )


class ExpenseTracker:
    def __init__(self):
        self.expenses = []

    def add(self, expense):
        self.expenses.append(expense)

    def total(self):
        amounts = [e.amount for e in self.expenses]
        return round(sum(amounts), 2)

    def by_category(self):
        totals = {}
        for e in self.expenses:
            totals[e.category] = totals.get(e.category, 0) + e.amount
        return {cat: round(t, 2) for cat, t in totals.items()}

    def delete(self, number):
        if not 1 <= number <= len(self.expenses):
            raise ExpenseError(f"There is no expense number {number}")
        return self.expenses.pop(number - 1)

    def __len__(self):
        return len(self.expenses)


FIELDS = ["date", "amount", "category", "description"]


def save_csv(tracker, path):
    with open(path, "w", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=FIELDS)
        writer.writeheader()
        for expense in tracker.expenses:
            writer.writerow(asdict(expense))


def load_csv(path):
    tracker = ExpenseTracker()
    try:
        with open(path, newline="") as file:
            rows = list(csv.DictReader(file))
    except FileNotFoundError:
        return tracker
    for line, row in enumerate(rows, start=2):
        try:
            tracker.add(Expense.from_dict(row))
        except (KeyError, ValueError, TypeError, ExpenseError) as err:
            print(f"Warning: skipped line {line}: {err}")
    return tracker


def save_json(tracker, path):
    data = [asdict(expense) for expense in tracker.expenses]
    with open(path, "w") as file:
        json.dump(data, file, indent=2)


def load_json(path):
    tracker = ExpenseTracker()
    try:
        with open(path) as file:
            data = json.load(file)
    except FileNotFoundError:
        return tracker
    for number, item in enumerate(data, start=1):
        try:
            tracker.add(Expense.from_dict(item))
        except (KeyError, ValueError, TypeError, ExpenseError) as err:
            print(f"Warning: skipped expense {number}: {err}")
    return tracker


def save(tracker, path):
    if Path(path).suffix == ".json":
        save_json(tracker, path)
    else:
        save_csv(tracker, path)


def load(path):
    if Path(path).suffix == ".json":
        return load_json(path)
    return load_csv(path)


def make_report(tracker):
    months = {}
    for expense in tracker.expenses:
        month = expense.date[:7]
        if month not in months:
            months[month] = ExpenseTracker()
        months[month].add(expense)

    lines = []
    for month in sorted(months):
        lines.append(month)
        totals = months[month].by_category()
        for category, amount in sorted(totals.items()):
            lines.append(f"  {category:<12}{amount:>8.2f}")
        lines.append(f"  {'total':<12}{months[month].total():>8.2f}")
    lines.append(f"{'All months':<14}{tracker.total():>8.2f}")
    return lines


def add_command(tracker, command, today):
    words = command.split(maxsplit=3)
    if len(words) < 4:
        raise ExpenseError("Try: add AMOUNT CATEGORY DESCRIPTION")
    try:
        amount = float(words[1])
    except ValueError:
        raise ExpenseError(f"'{words[1]}' is not a number")
    expense = Expense(amount, words[2].lower(), words[3], today)
    tracker.add(expense)
    print(f"Added {amount:.2f} for {expense.description}")


def list_command(tracker):
    if len(tracker) == 0:
        print("No expenses yet.")
    for number, e in enumerate(tracker.expenses, start=1):
        print(
            f"{number:>3}. {e.date}  {e.category:<10}"
            f"{e.amount:>8.2f}  {e.description}"
        )


def delete_command(tracker, words):
    if len(words) != 2:
        raise ExpenseError("Try: delete NUMBER")
    try:
        number = int(words[1])
    except ValueError:
        raise ExpenseError(f"'{words[1]}' is not a whole number")
    expense = tracker.delete(number)
    print(f"Deleted {expense.description}")


def handle_command(tracker, command, path, today):
    """Runs one command. Returns False when it's time to quit."""
    words = command.split()
    if not words:
        return True
    action = words[0].lower()
    try:
        if action == "quit":
            print("Bye!")
            return False
        elif action == "total":
            print(f"Total: {tracker.total():.2f}")
        elif action == "add":
            add_command(tracker, command, today)
        elif action == "list":
            list_command(tracker)
        elif action == "delete":
            delete_command(tracker, words)
        elif action == "report":
            for line in make_report(tracker):
                print(line)
        elif action == "save":
            save(tracker, path)
            print(f"Saved {len(tracker)} expenses to {path}")
        else:
            raise ExpenseError(
                f"Unknown command '{action}'. Try: add, list, "
                "total, report, delete, save, quit"
            )
    except ExpenseError as err:
        print(f"Error: {err}")
    return True


def run(commands, path, today=None):
    if today is None:
        today = datetime.date.today().isoformat()
    tracker = load(path)
    for command in commands:
        print(f"> {command}")
        if not handle_command(tracker, command, path, today):
            break
    return tracker
```
