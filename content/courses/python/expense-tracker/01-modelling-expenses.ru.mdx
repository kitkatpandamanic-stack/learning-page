## Пара слов о деньгах и дробных числах

Компьютеры хранят дробные числа (float) в двоичном виде, и некоторые десятичные дроби (например, `0.1`) нельзя сохранить точно. Обычно это незаметно, но при сложении денежных сумм могут вылезти крошечные ошибки:

<CodeExample output={`0.30000000000000004
0.3
15.75`}>

```python
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))
print(12.5 + 3.25)
```

</CodeExample>

Мы не будем усложнять: итоговые суммы пропускаем через **`round(..., 2)`**, а в примерах используем суммы вроде `12.5` и `3.25`, которые складываются точно. При выводе денег `:.2f` показывает два знака после точки: `f"{12.5:.2f}"` даёт `12.50`.

<Callout type="note" title="Как поступают настоящие приложения">

Банковские программы обычно хранят деньги в целых **центах** (`1250` вместо `12.5`) или используют модуль Python `decimal`, который считает десятичные дроби точно. Для личного трекера вполне хватит float с округлением.

</Callout>

## Dataclass Expense

У расхода четыре части данных: **сумма** (amount), **категория** (category), **описание** (description) и **дата** (date). Класс, который в основном хранит данные, — идеальная работа для **`@dataclass`**:

<CodeExample output={`Expense(amount=12.5, category='food', description='Lunch', date='2026-03-02')
12.5 2026-03
True`}>

```python
from dataclasses import dataclass

@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str  # "YYYY-MM-DD"

lunch = Expense(12.5, "food", "Lunch", "2026-03-02")
print(lunch)
print(lunch.amount, lunch.date[:7])
print(lunch == Expense(12.5, "food", "Lunch", "2026-03-02"))
```

</CodeExample>

`@dataclass` сам пишет за нас `__init__`, читаемый вывод при печати и `==`. Это `==` понадобится нам во второй части, чтобы проверить, что после сохранения и загрузки мы получаем **те же самые** расходы.

Дату мы храним как текст в формате **`"YYYY-MM-DD"`** (год-месяц-день, например `"2026-03-02"`). Текст легко записать в файл, даты в этом формате правильно сортируются как строки, а месяц — это просто первые семь символов: `date[:7]` даёт `"2026-03"`.

## Проверяем дату

Существует ли дата `"2026-02-30"`? Модуль `datetime` знает ответ. **`datetime.date.fromisoformat(text)`** превращает текст вида `"YYYY-MM-DD"` в дату, а если не может — выбрасывает `ValueError`:

<CodeExample output={`2026-03-02: OK
2026-02-30: not a real date
last Tuesday: not a real date`}>

```python
import datetime

for text in ["2026-03-02", "2026-02-30", "last Tuesday"]:
    try:
        datetime.date.fromisoformat(text)
        print(f"{text}: OK")
    except ValueError:
        print(f"{text}: not a real date")
```

</CodeExample>

Мы используем этот метод только для **проверки** текста, а храним по-прежнему исходную строку.

## Проверка в `__post_init__`

Сейчас `Expense(-4, "sweets", "?", "someday")` спокойно создаёт бессмыслицу. Мы хотим, чтобы плохие данные **отклонялись** в тот самый момент, когда их пытаются создать, — с нашим собственным типом ошибки **`ExpenseError`**.

Одна новая деталь: dataclass сам пишет `__init__`, так куда же поместить проверки? В метод под названием **`__post_init__`**. Dataclass вызывает его автоматически сразу **после** того, как его `__init__` сохранил поля:

<CodeExample output={`Added: Lunch
Error: Amount must be more than 0, not -4
Error: Unknown category 'sweets' (use one of: food, transport, bills, fun, other)
Error: Date must look like YYYY-MM-DD, not '2026-02-30'`}>

```python
import datetime
from dataclasses import dataclass

CATEGORIES = ["food", "transport", "bills", "fun", "other"]

class ExpenseError(Exception):
    """Raised when an expense isn't valid."""

@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str  # "YYYY-MM-DD"

    def __post_init__(self):
        if self.amount <= 0:
            raise ExpenseError(
                f"Amount must be more than 0, not {self.amount}"
            )
        if self.category not in CATEGORIES:
            options = ", ".join(CATEGORIES)
            raise ExpenseError(
                f"Unknown category '{self.category}'"
                f" (use one of: {options})"
            )
        try:
            datetime.date.fromisoformat(self.date)
        except ValueError:
            raise ExpenseError(
                f"Date must look like YYYY-MM-DD, not '{self.date}'"
            )

attempts = [
    (12.5, "food", "Lunch", "2026-03-02"),
    (-4, "food", "Refund?", "2026-03-02"),
    (3.25, "sweets", "Cake", "2026-03-02"),
    (3.25, "food", "Cake", "2026-02-30"),
]
for amount, category, description, day in attempts:
    try:
        expense = Expense(amount, category, description, day)
        print("Added:", expense.description)
    except ExpenseError as err:
        print("Error:", err)
```

</CodeExample>

На что стоит обратить внимание:

- **`ExpenseError`** — собственное исключение, просто подкласс `Exception`. Один тип ошибки на весь проект означает, что в части 3 можно поймать **любую** проблему «плохого расхода» одним `except ExpenseError`.
- Сообщения об ошибках говорят, **что** не так и **что мы получили**. Понятные сообщения сейчас — это дружелюбная командная строка потом.
- Для даты мы **ловим** `ValueError` из `fromisoformat` и вместо него **выбрасываем** своё `ExpenseError`, поэтому вызывающему коду достаточно знать об одном типе исключения.
- Две f-строки, записанные рядом внутри скобок, склеиваются в одну строку. Это удобный способ не допускать слишком длинных строк кода.

<Callout type="warning" title="Проверяйте на входе">

Поскольку проверки живут в `__post_init__`, создать некорректный `Expense` **невозможно**. Любая другая часть программы может доверять тому, что сумма положительная, а категория известна, и не проверять это заново.

</Callout>

## Класс ExpenseTracker

От одного расхода толку немного — нужна **коллекция**. Класс `ExpenseTracker` хранит список и отвечает на вопросы о нём:

<CodeExample output={`2
15.75`}>

```python
from dataclasses import dataclass

@dataclass
class Expense:  # короткая версия без проверок
    amount: float
    category: str
    description: str
    date: str

class ExpenseTracker:
    def __init__(self):
        self.expenses = []

    def add(self, expense):
        self.expenses.append(expense)

    def total(self):
        amounts = [e.amount for e in self.expenses]
        return round(sum(amounts), 2)

    def __len__(self):
        return len(self.expenses)

tracker = ExpenseTracker()
tracker.add(Expense(12.5, "food", "Lunch", "2026-03-02"))
tracker.add(Expense(3.25, "transport", "Bus", "2026-03-02"))
print(len(tracker))
print(tracker.total())
```

</CodeExample>

- `total()` собирает суммы с помощью **спискового включения**, складывает их через `sum()` и округляет до 2 знаков после точки.
- Метод **`__len__`** позволяет писать `len(tracker)` — точно так же, как для списка.

## Итоги по категориям

Последний метод, `by_category()`, должен возвращать словарь вроде `{'food': 17.25, 'transport': 3.25}`. Это **шаблон подсчёта** из урока о словарях, только мы прибавляем суммы, а не `1`:

<CodeExample output="{'food': 17.25, 'transport': 3.25}">

```python
spending = [("food", 12.5), ("transport", 3.25), ("food", 4.75)]

totals = {}
for category, amount in spending:
    totals[category] = totals.get(category, 0) + amount
print(totals)
```

</CodeExample>

`totals.get(category, 0)` даёт `0`, когда категория встречается впервые. В трекере перебирайте `self.expenses`, а в конце округлите каждую сумму (это удобно сделать **словарным включением** — dict comprehension).

import datetime
from dataclasses import dataclass

CATEGORIES = ["food", "transport", "bills", "fun", "other"]


class ExpenseError(Exception):
    """Raised when an expense or a command isn't valid."""


@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str  # "YYYY-MM-DD"

    def __post_init__(self):
        if self.amount <= 0:
            raise ExpenseError(
                f"Amount must be more than 0, not {self.amount}"
            )
        if self.category not in CATEGORIES:
            options = ", ".join(CATEGORIES)
            raise ExpenseError(
                f"Unknown category '{self.category}'"
                f" (use one of: {options})"
            )
        try:
            datetime.date.fromisoformat(self.date)
        except ValueError:
            raise ExpenseError(
                f"Date must look like YYYY-MM-DD, not '{self.date}'"
            )


class ExpenseTracker:
    def __init__(self):
        self.expenses = []

    def add(self, expense):
        self.expenses.append(expense)

    def total(self):
        amounts = [e.amount for e in self.expenses]
        return round(sum(amounts), 2)

    def by_category(self):
        totals = {}
        for e in self.expenses:
            totals[e.category] = totals.get(e.category, 0) + e.amount
        return {cat: round(t, 2) for cat, t in totals.items()}

    def __len__(self):
        return len(self.expenses)


tracker = ExpenseTracker()
tracker.add(Expense(12.5, "food", "Lunch", "2026-03-02"))
tracker.add(Expense(3.25, "transport", "Bus", "2026-03-02"))
tracker.add(Expense(4.75, "food", "Coffee", "2026-03-03"))
print(len(tracker), tracker.total())
print(tracker.by_category())
