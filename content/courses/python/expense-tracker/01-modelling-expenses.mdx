## A word about money and floats

Computers store floats in binary, and some decimals (like `0.1`) can't be stored exactly. Usually you never notice, but adding money can show tiny errors:

<CodeExample output={`0.30000000000000004
0.3
15.75`}>

```python
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))
print(12.5 + 3.25)
```

</CodeExample>

We'll keep it simple: totals go through **`round(..., 2)`**, and our examples use amounts like `12.5` and `3.25` that add up exactly. When we print money, `:.2f` shows two decimal places: `f"{12.5:.2f}"` gives `12.50`.

<Callout type="note" title="What real apps do">

Banking software usually stores money as whole **cents** (`1250` instead of `12.5`) or uses Python's `decimal` module, which does exact decimal maths. Floats plus rounding are fine for a personal tracker.

</Callout>

## The Expense dataclass

An expense has four pieces of data: an **amount**, a **category**, a **description** and a **date**. A class that mostly stores data is the perfect job for **`@dataclass`**:

<CodeExample output={`Expense(amount=12.5, category='food', description='Lunch', date='2026-03-02')
12.5 2026-03
True`}>

```python
from dataclasses import dataclass

@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str  # "YYYY-MM-DD"

lunch = Expense(12.5, "food", "Lunch", "2026-03-02")
print(lunch)
print(lunch.amount, lunch.date[:7])
print(lunch == Expense(12.5, "food", "Lunch", "2026-03-02"))
```

</CodeExample>

`@dataclass` writes `__init__`, a readable printout and `==` for us. We'll need that `==` in part 2 to check that saving and loading gives back the **same** expenses.

We store the date as text in the **`"YYYY-MM-DD"`** format (like `"2026-03-02"`). Text is easy to write to a file, dates in this format sort correctly as strings, and the month is just the first seven characters: `date[:7]` gives `"2026-03"`.

## Checking a date

Is `"2026-02-30"` a real date? The `datetime` module knows. **`datetime.date.fromisoformat(text)`** turns `"YYYY-MM-DD"` text into a date, and raises a `ValueError` if it can't:

<CodeExample output={`2026-03-02: OK
2026-02-30: not a real date
last Tuesday: not a real date`}>

```python
import datetime

for text in ["2026-03-02", "2026-02-30", "last Tuesday"]:
    try:
        datetime.date.fromisoformat(text)
        print(f"{text}: OK")
    except ValueError:
        print(f"{text}: not a real date")
```

</CodeExample>

We only use it to **check** the text; we keep storing the original string.

## Validating with `__post_init__`

Right now `Expense(-4, "sweets", "?", "someday")` happily creates nonsense. We want bad data to be **rejected** the moment someone tries to create it, with our own error type, **`ExpenseError`**.

One new thing: a dataclass writes `__init__` for you, so where do the checks go? Into a method called **`__post_init__`**. The dataclass calls it automatically right **after** its `__init__` has stored the fields:

<CodeExample output={`Added: Lunch
Error: Amount must be more than 0, not -4
Error: Unknown category 'sweets' (use one of: food, transport, bills, fun, other)
Error: Date must look like YYYY-MM-DD, not '2026-02-30'`}>

```python
import datetime
from dataclasses import dataclass

CATEGORIES = ["food", "transport", "bills", "fun", "other"]

class ExpenseError(Exception):
    """Raised when an expense isn't valid."""

@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str  # "YYYY-MM-DD"

    def __post_init__(self):
        if self.amount <= 0:
            raise ExpenseError(
                f"Amount must be more than 0, not {self.amount}"
            )
        if self.category not in CATEGORIES:
            options = ", ".join(CATEGORIES)
            raise ExpenseError(
                f"Unknown category '{self.category}'"
                f" (use one of: {options})"
            )
        try:
            datetime.date.fromisoformat(self.date)
        except ValueError:
            raise ExpenseError(
                f"Date must look like YYYY-MM-DD, not '{self.date}'"
            )

attempts = [
    (12.5, "food", "Lunch", "2026-03-02"),
    (-4, "food", "Refund?", "2026-03-02"),
    (3.25, "sweets", "Cake", "2026-03-02"),
    (3.25, "food", "Cake", "2026-02-30"),
]
for amount, category, description, day in attempts:
    try:
        expense = Expense(amount, category, description, day)
        print("Added:", expense.description)
    except ExpenseError as err:
        print("Error:", err)
```

</CodeExample>

A few things to notice:

- **`ExpenseError`** is a custom exception, just a subclass of `Exception`. One error type for the whole project means part 3 can catch **every** "bad expense" problem with a single `except ExpenseError`.
- The error messages say **what** was wrong and **what we got**. Friendly messages now mean a friendly command line later.
- For the date we **catch** the `ValueError` from `fromisoformat` and **raise** our own `ExpenseError` instead, so callers only need to know about one exception type.
- Two f-strings written next to each other inside the brackets are joined into one string. It's a neat way to keep long lines short.

<Callout type="warning" title="Validate at the door">

Because the checks live in `__post_init__`, it is **impossible** to create an invalid `Expense`. Every other part of the program can trust that an amount is positive and a category is known, without checking again.

</Callout>

## The ExpenseTracker class

One expense isn't much use; we need a **collection** of them. The `ExpenseTracker` class keeps a list and answers questions about it:

<CodeExample output={`2
15.75`}>

```python
from dataclasses import dataclass

@dataclass
class Expense:  # short version without the checks
    amount: float
    category: str
    description: str
    date: str

class ExpenseTracker:
    def __init__(self):
        self.expenses = []

    def add(self, expense):
        self.expenses.append(expense)

    def total(self):
        amounts = [e.amount for e in self.expenses]
        return round(sum(amounts), 2)

    def __len__(self):
        return len(self.expenses)

tracker = ExpenseTracker()
tracker.add(Expense(12.5, "food", "Lunch", "2026-03-02"))
tracker.add(Expense(3.25, "transport", "Bus", "2026-03-02"))
print(len(tracker))
print(tracker.total())
```

</CodeExample>

- `total()` collects the amounts with a **list comprehension**, adds them with `sum()` and rounds to 2 decimal places.
- Defining **`__len__`** lets us write `len(tracker)`, just like for a list.

## Totals per category

The last method, `by_category()`, should return a dict like `{'food': 17.25, 'transport': 3.25}`. It's the **counting pattern** from the dictionaries lesson, except we add amounts instead of `1`:

<CodeExample output="{'food': 17.25, 'transport': 3.25}">

```python
spending = [("food", 12.5), ("transport", 3.25), ("food", 4.75)]

totals = {}
for category, amount in spending:
    totals[category] = totals.get(category, 0) + amount
print(totals)
```

</CodeExample>

`totals.get(category, 0)` gives `0` the first time a category appears. In the tracker, loop over `self.expenses` instead, and round each total at the end (a **dict comprehension** does that nicely).

import datetime
from dataclasses import dataclass

CATEGORIES = ["food", "transport", "bills", "fun", "other"]


class ExpenseError(Exception):
    """Raised when an expense or a command isn't valid."""


@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str  # "YYYY-MM-DD"

    def __post_init__(self):
        if self.amount <= 0:
            raise ExpenseError(
                f"Amount must be more than 0, not {self.amount}"
            )
        if self.category not in CATEGORIES:
            options = ", ".join(CATEGORIES)
            raise ExpenseError(
                f"Unknown category '{self.category}'"
                f" (use one of: {options})"
            )
        try:
            datetime.date.fromisoformat(self.date)
        except ValueError:
            raise ExpenseError(
                f"Date must look like YYYY-MM-DD, not '{self.date}'"
            )


class ExpenseTracker:
    def __init__(self):
        self.expenses = []

    def add(self, expense):
        self.expenses.append(expense)

    def total(self):
        amounts = [e.amount for e in self.expenses]
        return round(sum(amounts), 2)

    def by_category(self):

        for e in self.expenses:
            totals[e.category] = totals.get(e.category, 0) + e.amount
        return {cat: round(t, 2) for cat, t in totals.items()}

    def __len__(self):
        return len(self.expenses)
