You have a validated model (Part 1) and files that remember everything (Part 2). Time for the last layer: the **command line**. 🎉 The user types commands like `add 12.50 food Lunch`, `list`, `report` or `delete 2`, and the tracker answers.

This part uses **string methods** like `split()`, **f-strings** with format specs, **dicts** for grouping, **`try`/`except`** for friendly errors, and `if __name__ == "__main__"` from the Modules lesson.

`input()` doesn't work in the browser, so our `run(commands, path)` function takes a **list of commands** that stands in for what the user would type. At the end you'll see the real `input()` version to run on your own computer.

| Command                  | What it does                                   |
| ------------------------ | ---------------------------------------------- |
| `add 12.50 food Lunch`   | Add an expense dated today                     |
| `list`                   | Show every expense with a number               |
| `total`                  | Show the total spent                           |
| `report`                 | Totals per month and category                  |
| `delete 2`               | Delete expense number 2                        |
| `save`                   | Save to the file                               |
| `quit`                   | Stop                                           |

## Splitting a command into words

`split()` breaks a command into words. But the description can contain spaces too ("Lunch with Sam"), so for `add` we use **`maxsplit=3`**: split at most 3 times and keep the rest together:

<CodeExample output={`['add', '12.50', 'food', 'Lunch', 'with', 'Sam']
['add', '12.50', 'food', 'Lunch with Sam']`}>

```python
command = "add 12.50 food Lunch with Sam"
print(command.split())
print(command.split(maxsplit=3))
```

</CodeExample>

The first word is the **action**. We lower-case it with `.lower()` so `ADD` and `Add` work too.

## Friendly errors for bad input

People type things like `add lots food Cake`. `float("lots")` raises a `ValueError` with a rather technical message. We catch it and raise our own **`ExpenseError`** with a clearer one:

<CodeExample output={`12.5
Error: '3,25' is not a number
Error: 'lots' is not a number`}>

```python
class ExpenseError(Exception):
    pass

def parse_amount(text):
    try:
        return float(text)
    except ValueError:
        raise ExpenseError(f"'{text}' is not a number")

for text in ["12.50", "3,25", "lots"]:
    try:
        print(parse_amount(text))
    except ExpenseError as err:
        print("Error:", err)
```

</CodeExample>

Here's the project's `add_command`. It uses the same idea, and the `Expense` checks from Part 1 do the rest (amount, category and date):

```python
def add_command(tracker, command, today):
    words = command.split(maxsplit=3)
    if len(words) < 4:
        raise ExpenseError("Try: add AMOUNT CATEGORY DESCRIPTION")
    try:
        amount = float(words[1])
    except ValueError:
        raise ExpenseError(f"'{words[1]}' is not a number")
    expense = Expense(amount, words[2].lower(), words[3], today)
    tracker.add(expense)
    print(f"Added {amount:.2f} for {expense.description}")
```

Every problem becomes an `ExpenseError`, so one `except ExpenseError` in the command loop can print **all** of them nicely. `today` is passed in as a `"YYYY-MM-DD"` string instead of being looked up inside, which keeps the function easy to test (the same trick as passing in random numbers).

## Lining up columns

A list or report is much easier to read when the columns line up. Inside an f-string's braces, a **format spec** after the colon controls the width:

<CodeExample output={`|food        |   17.25|
|transport   |    3.25|
|fun         |  120.00|`}>

```python
rows = [("food", 17.25), ("transport", 3.25), ("fun", 120)]
for category, amount in rows:
    print(f"|{category:<12}|{amount:>8.2f}|")
```

</CodeExample>

- **`:<12`** left-aligns the text in a space 12 characters wide.
- **`:>8.2f`** right-aligns the number in 8 characters, with 2 decimal places. Right-aligned amounts put the decimal points under each other.
- **`:>3`** on a number (like `f"{number:>3}."`) makes `1.` and `10.` line up in the `list` command.

The `|` characters are only there to show you the spaces.

## Grouping by month

For the report we need the expenses **per month**. The month is the first seven characters of the date, and a dict groups them, just like the counting pattern:

<CodeExample output="{'2026-03': ['2026-03-02', '2026-03-14'], '2026-04': ['2026-04-01']}">

```python
dates = ["2026-03-02", "2026-04-01", "2026-03-14"]

months = {}
for day in dates:
    month = day[:7]
    if month not in months:
        months[month] = []
    months[month].append(day)
print(months)
```

</CodeExample>

Here's a trick for the tracker: instead of a list per month, store an **`ExpenseTracker` per month**. Then each month already has `by_category()` and `total()`, and the report is mostly printing. Loop over `sorted(months)` so the months come out in order. The finished report looks like this:

```text
2026-02
  bills          45.00
  fun             9.50
  total          54.50
2026-03
  food           17.25
  total          17.25
All months       71.75
```

## The command loop

Now the heart of the program. `handle_command()` runs **one** command and returns `False` when it's time to stop. `run()` feeds it the commands one by one and **echoes** each one after a `> ` so the output reads like a real session. Here's the pattern on a tiny toy program:

<CodeExample output={`> hello
Hi there!
> shout good morning
GOOD MORNING
> dance
Error: Unknown command 'dance'
> quit
Bye!`}>

```python
def handle_command(command):
    """Runs one command. Returns False when it's time to quit."""
    words = command.split()
    if not words:
        return True
    action = words[0].lower()
    if action == "quit":
        print("Bye!")
        return False
    elif action == "hello":
        print("Hi there!")
    elif action == "shout":
        print(" ".join(words[1:]).upper())
    else:
        print(f"Error: Unknown command '{action}'")
    return True

def run(commands):
    for command in commands:
        print(f"> {command}")
        if not handle_command(command):
            break

run(["hello", "shout good morning", "dance", "quit", "hello"])
```

</CodeExample>

The last `hello` never runs: `quit` returned `False` and `break` ended the loop.

In the tracker, `handle_command(tracker, command, path, today)` wraps its whole `if`/`elif` chain in **`try`/`except ExpenseError as err`** and prints `Error: {err}`. An unknown command simply **raises** an `ExpenseError` too. However the input is wrong, the user gets one clear line and the program carries on. 💪

<Callout type="tip" title="Why split handle_command from run?">

`run()` reads commands from a list; the real program reads them from `input()`. Both just call `handle_command()`, so all the logic is shared and the list version can be tested automatically.

</Callout>

## Running it on your computer

Copy your finished code into a file called `tracker.py`, add `import sys` to the imports at the top, and replace the demo at the bottom with this `main()` function. It loops forever with `while True`, reading real commands with `input()`:

```python
def main():
    path = sys.argv[1] if len(sys.argv) > 1 else "expenses.csv"
    today = datetime.date.today().isoformat()
    tracker = load(path)
    print(f"Loaded {len(tracker)} expenses from {path}.")
    print("Commands: add, list, total, report, delete, save, quit")
    while True:
        try:
            command = input("> ")
        except (EOFError, KeyboardInterrupt):
            command = "quit"
        if not handle_command(tracker, command, path, today):
            break


if __name__ == "__main__":
    main()
```

- **`sys.argv`** is the list of words typed after `python` in the terminal. `sys.argv[0]` is the script name, so `sys.argv[1]` is an optional file name.
- Pressing **Ctrl+C** (or Ctrl+D) would normally crash with a traceback; we treat it as `quit`.
- `if __name__ == "__main__":` means `main()` only runs when you start the file directly, not when another file imports your classes.

```bash
python tracker.py
python tracker.py march.json
```

The first command uses `expenses.csv`; the second keeps a separate JSON file. Open the CSV in a spreadsheet app and you'll see your spending there too.

        raise ExpenseError(f"'{words[1]}' is not a number")
    expense = Expense(amount, words[2].lower(), words[3], today)
    tracker.add(expense)
    print(f"Added {amount:.2f} for {expense.description}")


def list_command(tracker):
    if len(tracker) == 0:
        print("No expenses yet.")
    for number, e in enumerate(tracker.expenses, start=1):
        print(
            f"{number:>3}. {e.date}  {e.category:<10}"
            f"{e.amount:>8.2f}  {e.description}"
        )


def delete_command(tracker, words):
    if len(words) != 2:
        raise ExpenseError("Try: delete NUMBER")
    try:
        number = int(words[1])
    except ValueError:
        raise ExpenseError(f"'{words[1]}' is not a whole number")
    expense = tracker.delete(number)
    print(f"Deleted {expense.description}")


def handle_command(tracker, command, path, today):
    """Runs one command. Returns False when it's time to quit."""
    words = command.split()
    if not words:
        return True
    action = words[0].lower()
    try:
        if action == "quit":
            print("Bye!")
            return False
        elif action == "total":
            print(f"Total: {tracker.total():.2f}")
        elif action == "add":
            add_command(tracker, command, today)
        elif action == "list":
            list_command(tracker)
        elif action == "delete":
            delete_command(tracker, words)
        elif action == "report":
            for line in make_report(tracker):
                print(line)
        elif action == "save":
            save(tracker, path)
            print(f"Saved {len(tracker)} expenses to {path}")
        else:
            raise ExpenseError(
                f"Unknown command '{action}'. Try: add, list, "
                "total, report, delete, save, quit"
            )
    except ExpenseError as err:
        print(f"Error: {err}")
    return True


def run(commands, path, today=None):
    if today is None:
        today = datetime.date.today().isoformat()
    tracker = load(path)
    for command in commands:
        print(f"> {command}")
        if not handle_command(tracker, command, path, today):
            break
    return tracker
