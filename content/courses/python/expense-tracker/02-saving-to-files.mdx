In Part 1 you built the **model**: `Expense`, `ExpenseError` and `ExpenseTracker`. It works, but every expense vanishes when the program stops. 😱 Now we'll make the tracker **remember**: save to a file, load it back next time.

This part uses the **Files & Exceptions** lessons: `with open(...)`, `csv.DictWriter` and `csv.DictReader`, `json.dump` and `json.load`, `pathlib`, and `try`/`except` for things that go wrong. We'll support **both** CSV and JSON and pick one from the file name.

| Format | Good for                                                        |
| ------ | --------------------------------------------------------------- |
| CSV    | Opening your spending in a spreadsheet app like Excel           |
| JSON   | Keeping types (numbers stay numbers) and nesting data later     |

## From an expense to a dict

Both `csv.DictWriter` and `json.dump` work with **dicts**. The `dataclasses` module has a helper that turns a dataclass object into one: **`asdict()`**.

<CodeExample output="{'amount': 12.5, 'category': 'food', 'description': 'Lunch', 'date': '2026-03-02'}">

```python
from dataclasses import asdict, dataclass

@dataclass
class Expense:  # short version without the checks
    amount: float
    category: str
    description: str
    date: str

lunch = Expense(12.5, "food", "Lunch", "2026-03-02")
print(asdict(lunch))
```

</CodeExample>

To keep the examples in this part short, they use this cut-down `Expense` without the checks. In the exercise you'll plug everything into your full Part 1 code.

## Writing a CSV file

`csv.DictWriter` writes one dict per row. We choose the column order with a `FIELDS` list:

<CodeExample output={`date,amount,category,description
2026-03-02,12.5,food,Lunch with Sam
2026-03-02,3.25,transport,"Bus, then tram"`}>

```python
import csv
from dataclasses import asdict, dataclass
from pathlib import Path

@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str

FIELDS = ["date", "amount", "category", "description"]
expenses = [
    Expense(12.5, "food", "Lunch with Sam", "2026-03-02"),
    Expense(3.25, "transport", "Bus, then tram", "2026-03-02"),
]

with open("demo-expenses.csv", "w", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=FIELDS)
    writer.writeheader()
    for expense in expenses:
        writer.writerow(asdict(expense))

print(Path("demo-expenses.csv").read_text())
```

</CodeExample>

Look at the last row: the description contains a comma, so the `csv` module wrapped it in quotes. That's exactly why we use `csv` instead of joining strings with commas ourselves.

## Reading it back: everything is text

`csv.DictReader` gives each row as a dict, but a CSV file is just text, so **every value is a string**:

<CodeExample output={`{'date': '2026-03-02', 'amount': '12.5', 'category': 'food', 'description': 'Lunch'}
12.512.5
25.0`}>

```python
import csv
from pathlib import Path

Path("demo-read.csv").write_text(
    "date,amount,category,description\n"
    "2026-03-02,12.5,food,Lunch\n"
)

with open("demo-read.csv", newline="") as file:
    rows = list(csv.DictReader(file))

row = rows[0]
print(row)
print(row["amount"] + row["amount"])
print(float(row["amount"]) * 2)
```

</CodeExample>

`'12.5' + '12.5'` glues two strings together. Before we build an `Expense`, we must **convert** the amount back to a number with `float()`. (Our dates are strings anyway, so they need no conversion.)

The neatest home for "build an `Expense` from a dict" is a **`@classmethod`** on `Expense` itself:

<CodeExample output="Expense(amount=12.5, category='food', description='Lunch', date='2026-03-02')">

```python
from dataclasses import dataclass

@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str

    @classmethod
    def from_dict(cls, data):
        return cls(
            float(data["amount"]),
            data["category"],
            data["description"],
            data["date"],
        )

row = {"date": "2026-03-02", "amount": "12.5",
       "category": "food", "description": "Lunch"}
print(Expense.from_dict(row))
```

</CodeExample>

`cls(...)` calls the class, so it goes through `__init__` and, in the real version, through `__post_init__` too. A loaded expense gets the **same checks** as a new one. ✅

## When the file doesn't exist yet

The very first time someone runs the tracker, there's no file. That's not an error, it just means "no expenses yet". Catch **`FileNotFoundError`** and start empty:

<CodeExample output="[]">

```python
import csv

def load_rows(path):
    try:
        with open(path, newline="") as file:
            return list(csv.DictReader(file))
    except FileNotFoundError:
        return []

print(load_rows("not-created-yet.csv"))
```

</CodeExample>

## Surviving a broken row

Files get edited by hand, copied halfway or damaged. One bad row shouldn't stop the whole program from starting, so we **skip it with a warning** and keep the good rows:

<CodeExample output={`Warning: skipped line 3: could not convert string to float: 'lots'
Warning: skipped line 4: float() argument must be a string or a real number, not 'NoneType'
Loaded 2 expenses`}>

```python
import csv
from pathlib import Path

Path("demo-broken.csv").write_text(
    "date,amount,category,description\n"
    "2026-03-02,12.5,food,Lunch\n"
    "2026-03-03,lots,food,Cake\n"
    "2026-03-04\n"
    "2026-03-05,3.25,transport,Bus\n"
)

with open("demo-broken.csv", newline="") as file:
    rows = list(csv.DictReader(file))

amounts = []
for line, row in enumerate(rows, start=2):
    try:
        amounts.append(float(row["amount"]))
    except (KeyError, ValueError, TypeError) as err:
        print(f"Warning: skipped line {line}: {err}")
print(f"Loaded {len(amounts)} expenses")
```

</CodeExample>

- `enumerate(rows, start=2)` gives each row its **line number** in the file: line 1 is the header, so the first data row is line 2. That makes the warning easy to act on.
- `float("lots")` raises a **`ValueError`**. A row with missing columns gets `None` for them, and `float(None)` raises a **`TypeError`**. A missing column name in the header would give a **`KeyError`**.
- In the tracker, `Expense.from_dict` can also raise **`ExpenseError`** (an unknown category, say), so we'll add that to the tuple.

<Callout type="warning" title="Catch only what you expect">

We list the exact exceptions a bad row can cause. A bare `except:` would also hide **our own bugs**, like a typo in a variable name, and the tracker would silently load nothing.

</Callout>

## Saving and loading JSON

JSON is even easier: `json.dump` writes a whole **list of dicts** in one go, and `json.load` gives it back. Numbers stay numbers in JSON, but running them through `from_dict` (and its `float()`) does no harm and keeps one way in for every format:

<CodeExample output={`[
  {
    "amount": 3.25,
    "category": "transport",
    "description": "Bus",
    "date": "2026-03-02"
  }
]
True`}>

```python
import json
from dataclasses import asdict, dataclass
from pathlib import Path

@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str

expenses = [Expense(3.25, "transport", "Bus", "2026-03-02")]

data = [asdict(expense) for expense in expenses]
with open("demo-expenses.json", "w") as file:
    json.dump(data, file, indent=2)
print(Path("demo-expenses.json").read_text())

with open("demo-expenses.json") as file:
    loaded = [Expense(**item) for item in json.load(file)]
print(loaded == expenses)
```

</CodeExample>

`loaded == expenses` is `True` because dataclasses compare field by field. (`Expense(**item)` passes each dict key as a keyword argument. It's handy here, but in the tracker we'll use `from_dict` so the amount is always converted.)

## Picking the format from the file name

`Path(path).suffix` gives a file's extension. Two small functions, **`save()`** and **`load()`**, can look at it and call the right CSV or JSON function, so the rest of the program never has to care:

<CodeExample output={`expenses.csv -> .csv
expenses.json -> .json
backup/2026.json -> .json`}>

```python
from pathlib import Path

for name in ["expenses.csv", "expenses.json", "backup/2026.json"]:
    print(name, "->", Path(name).suffix)
```

</CodeExample>

## Round-trip tests

How do we know saving and loading really work? Save a tracker, load it back and compare: if `loaded.expenses == tracker.expenses`, nothing was lost or changed on the way. This is called a **round-trip test**, and it catches lots of bugs (a forgotten `float()`, a missing column, a swapped field).

Python's **`assert`** statement is a quick way to write such a check. If the condition is `True`, nothing happens; if it's `False`, it raises an `AssertionError` with your message:

<CodeExample output="All checks passed!">

```python
saved = [12.5, 3.25]
loaded = [float(text) for text in ["12.5", "3.25"]]

assert loaded == saved, "the amounts changed!"
assert len(loaded) == 2, "an expense went missing!"
print("All checks passed!")
```

</CodeExample>

```python
assert ["12.5"] == [12.5], "the amounts changed!"
# AssertionError: the amounts changed!
```

<Callout type="note" title="Two dangers worth knowing">

A skipped row is **gone** the next time you save, and a file that isn't valid JSON at all makes `json.load` raise `json.JSONDecodeError`. A careful app would keep a backup copy before saving. For our tracker, warnings are enough.

</Callout>

import csv
import datetime
import json
from dataclasses import asdict, dataclass
from pathlib import Path

CATEGORIES = ["food", "transport", "bills", "fun", "other"]


class ExpenseError(Exception):
    """Raised when an expense or a command isn't valid."""


@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str  # "YYYY-MM-DD"

    def __post_init__(self):
        if self.amount <= 0:
            raise ExpenseError(
                f"Amount must be more than 0, not {self.amount}"
            )
        if self.category not in CATEGORIES:
            options = ", ".join(CATEGORIES)
            raise ExpenseError(
                f"Unknown category '{self.category}'"
                f" (use one of: {options})"
            )
        try:
            datetime.date.fromisoformat(self.date)
        except ValueError:
            raise ExpenseError(
                f"Date must look like YYYY-MM-DD, not '{self.date}'"
            )

    @classmethod
    def from_dict(cls, data):
        return cls(
            float(data["amount"]),
            data["category"],
            data["description"],
            data["date"],
        )


class ExpenseTracker:
    def __init__(self):
        self.expenses = []

    def add(self, expense):
        self.expenses.append(expense)

    def total(self):
        amounts = [e.amount for e in self.expenses]
        return round(sum(amounts), 2)

    def by_category(self):
        totals = {}
        for e in self.expenses:
            totals[e.category] = totals.get(e.category, 0) + e.amount
        return {cat: round(t, 2) for cat, t in totals.items()}

    def __len__(self):
        return len(self.expenses)


FIELDS = ["date", "amount", "category", "description"]


def save_csv(tracker, path):
    with open(path, "w", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=FIELDS)
        writer.writeheader()
        for expense in tracker.expenses:
            writer.writerow(asdict(expense))


def load_csv(path):
    tracker = ExpenseTracker()
    try:
        with open(path, newline="") as file:
            rows = list(csv.DictReader(file))
    except FileNotFoundError:
        return tracker
    for line, row in enumerate(rows, start=2):
        try:
            tracker.add(Expense.from_dict(row))
        except (KeyError, ValueError, TypeError, ExpenseError) as err:
            print(f"Warning: skipped line {line}: {err}")
    return tracker


def save_json(tracker, path):
    data = [asdict(expense) for expense in tracker.expenses]
    with open(path, "w") as file:
        json.dump(data, file, indent=2)


def load_json(path):
    tracker = ExpenseTracker()
    try:
        with open(path) as file:
            data = json.load(file)
    except FileNotFoundError:
        return tracker
    for number, item in enumerate(data, start=1):
        try:
            tracker.add(Expense.from_dict(item))
        except (KeyError, ValueError, TypeError, ExpenseError) as err:
            print(f"Warning: skipped expense {number}: {err}")
    return tracker


def save(tracker, path):
    if Path(path).suffix == ".json":
        save_json(tracker, path)
    else:
        save_csv(tracker, path)


def load(path):
    if Path(path).suffix == ".json":
        return load_json(path)
    return load_csv(path)
