В первой части вы построили **модель**: `Expense`, `ExpenseError` и `ExpenseTracker`. Она работает, но все расходы исчезают, как только программа завершается. 😱 Теперь научим трекер **запоминать**: сохранять данные в файл (file) и загружать их обратно при следующем запуске.

В этой части пригодятся уроки из модуля **«Файлы и исключения»**: `with open(...)`, `csv.DictWriter` и `csv.DictReader`, `json.dump` и `json.load`, `pathlib`, а также `try`/`except` на случай, если что-то пойдёт не так. Мы поддержим **оба** формата, CSV и JSON, и будем выбирать нужный по имени файла.

| Формат | Для чего подходит                                                    |
| ------ | -------------------------------------------------------------------- |
| CSV    | Открыть свои траты в программе для таблиц, например в Excel          |
| JSON   | Сохранить типы (числа остаются числами) и позже хранить вложенные данные |

Как и в первой части, все данные в коде — категории (`food`, `transport`…), описания расходов и сообщения программы — остаются на английском. Переводим только комментарии.

## От расхода к словарю

И `csv.DictWriter`, и `json.dump` работают со **словарями (dictionaries)**. В модуле `dataclasses` есть помощник, который превращает объект датакласса в словарь: **`asdict()`**.

<CodeExample output="{'amount': 12.5, 'category': 'food', 'description': 'Lunch', 'date': '2026-03-02'}">

```python
from dataclasses import asdict, dataclass

@dataclass
class Expense:  # укороченная версия без проверок
    amount: float
    category: str
    description: str
    date: str

lunch = Expense(12.5, "food", "Lunch", "2026-03-02")
print(asdict(lunch))
```

</CodeExample>

Чтобы примеры в этой части были короткими, в них используется этот урезанный `Expense` без проверок. В упражнении вы подключите всё к своему полному коду из первой части.

## Запись CSV-файла

`csv.DictWriter` записывает по одному словарю в строку. Порядок столбцов мы задаём списком `FIELDS`:

<CodeExample output={`date,amount,category,description
2026-03-02,12.5,food,Lunch with Sam
2026-03-02,3.25,transport,"Bus, then tram"`}>

```python
import csv
from dataclasses import asdict, dataclass
from pathlib import Path

@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str

FIELDS = ["date", "amount", "category", "description"]
expenses = [
    Expense(12.5, "food", "Lunch with Sam", "2026-03-02"),
    Expense(3.25, "transport", "Bus, then tram", "2026-03-02"),
]

with open("demo-expenses.csv", "w", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=FIELDS)
    writer.writeheader()
    for expense in expenses:
        writer.writerow(asdict(expense))

print(Path("demo-expenses.csv").read_text())
```

</CodeExample>

Посмотрите на последнюю строку: в описании есть запятая, поэтому модуль `csv` заключил его в кавычки. Именно поэтому мы используем `csv`, а не склеиваем строки через запятую сами.

## Чтение обратно: всё — текст

`csv.DictReader` возвращает каждую строку в виде словаря, но CSV-файл — это просто текст, поэтому **каждое значение — строка**:

<CodeExample output={`{'date': '2026-03-02', 'amount': '12.5', 'category': 'food', 'description': 'Lunch'}
12.512.5
25.0`}>

```python
import csv
from pathlib import Path

Path("demo-read.csv").write_text(
    "date,amount,category,description\n"
    "2026-03-02,12.5,food,Lunch\n"
)

with open("demo-read.csv", newline="") as file:
    rows = list(csv.DictReader(file))

row = rows[0]
print(row)
print(row["amount"] + row["amount"])
print(float(row["amount"]) * 2)
```

</CodeExample>

`'12.5' + '12.5'` склеивает две строки. Прежде чем создавать `Expense`, нужно **преобразовать** сумму обратно в число с помощью `float()`. (Даты у нас и так строки, их преобразовывать не нужно.)

Самое удобное место для «создать `Expense` из словаря» — **`@classmethod`** в самом классе `Expense`:

<CodeExample output="Expense(amount=12.5, category='food', description='Lunch', date='2026-03-02')">

```python
from dataclasses import dataclass

@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str

    @classmethod
    def from_dict(cls, data):
        return cls(
            float(data["amount"]),
            data["category"],
            data["description"],
            data["date"],
        )

row = {"date": "2026-03-02", "amount": "12.5",
       "category": "food", "description": "Lunch"}
print(Expense.from_dict(row))
```

</CodeExample>

`cls(...)` вызывает сам класс, поэтому проходит через `__init__`, а в настоящей версии — ещё и через `__post_init__`. Загруженный расход проходит **те же проверки**, что и новый. ✅

## Когда файла ещё нет

При самом первом запуске трекера файла нет. Это не ошибка, а просто «расходов пока нет». Перехватите **`FileNotFoundError`** и начните с пустого списка:

<CodeExample output="[]">

```python
import csv

def load_rows(path):
    try:
        with open(path, newline="") as file:
            return list(csv.DictReader(file))
    except FileNotFoundError:
        return []

print(load_rows("not-created-yet.csv"))
```

</CodeExample>

## Как пережить битую строку

Файлы правят вручную, копируют не до конца или повреждают. Одна плохая строка не должна мешать запуску всей программы, поэтому мы **пропускаем её с предупреждением** и оставляем хорошие строки:

<CodeExample output={`Warning: skipped line 3: could not convert string to float: 'lots'
Warning: skipped line 4: float() argument must be a string or a real number, not 'NoneType'
Loaded 2 expenses`}>

```python
import csv
from pathlib import Path

Path("demo-broken.csv").write_text(
    "date,amount,category,description\n"
    "2026-03-02,12.5,food,Lunch\n"
    "2026-03-03,lots,food,Cake\n"
    "2026-03-04\n"
    "2026-03-05,3.25,transport,Bus\n"
)

with open("demo-broken.csv", newline="") as file:
    rows = list(csv.DictReader(file))

amounts = []
for line, row in enumerate(rows, start=2):
    try:
        amounts.append(float(row["amount"]))
    except (KeyError, ValueError, TypeError) as err:
        print(f"Warning: skipped line {line}: {err}")
print(f"Loaded {len(amounts)} expenses")
```

</CodeExample>

- `enumerate(rows, start=2)` даёт каждой строке её **номер строки** в файле: строка 1 — это заголовок, так что первая строка с данными — строка 2. С таким предупреждением легко понять, что исправлять.
- `float("lots")` выбрасывает **`ValueError`**. Строка, в которой не хватает столбцов, получает для них `None`, а `float(None)` выбрасывает **`TypeError`**. Если в заголовке нет нужного столбца, будет **`KeyError`**.
- В трекере `Expense.from_dict` может выбросить ещё и **`ExpenseError`** (например, из-за неизвестной категории), так что добавим его в кортеж.

<Callout type="warning" title="Перехватывайте только то, чего ожидаете">

Мы перечисляем ровно те исключения (exceptions), которые может вызвать плохая строка. Голый `except:` скрыл бы и **наши собственные ошибки**, например опечатку в имени переменной, и трекер молча ничего бы не загрузил.

</Callout>

## Сохранение и загрузка JSON

С JSON ещё проще: `json.dump` записывает весь **список словарей** за один раз, а `json.load` возвращает его обратно. В JSON числа остаются числами, но пропустить их через `from_dict` (и его `float()`) не повредит, зато у всех форматов будет один общий путь загрузки:

<CodeExample output={`[
  {
    "amount": 3.25,
    "category": "transport",
    "description": "Bus",
    "date": "2026-03-02"
  }
]
True`}>

```python
import json
from dataclasses import asdict, dataclass
from pathlib import Path

@dataclass
class Expense:
    amount: float
    category: str
    description: str
    date: str

expenses = [Expense(3.25, "transport", "Bus", "2026-03-02")]

data = [asdict(expense) for expense in expenses]
with open("demo-expenses.json", "w") as file:
    json.dump(data, file, indent=2)
print(Path("demo-expenses.json").read_text())

with open("demo-expenses.json") as file:
    loaded = [Expense(**item) for item in json.load(file)]
print(loaded == expenses)
```

</CodeExample>

`loaded == expenses` равно `True`, потому что датаклассы сравниваются поле за полем. (`Expense(**item)` передаёт каждый ключ словаря как именованный аргумент. Здесь это удобно, но в трекере мы используем `from_dict`, чтобы сумма всегда преобразовывалась.)

## Выбор формата по имени файла

`Path(path).suffix` возвращает расширение файла. Две небольшие функции, **`save()`** и **`load()`**, могут посмотреть на него и вызвать нужную функцию для CSV или JSON, так что остальной программе об этом думать не придётся:

<CodeExample output={`expenses.csv -> .csv
expenses.json -> .json
backup/2026.json -> .json`}>

```python
from pathlib import Path

for name in ["expenses.csv", "expenses.json", "backup/2026.json"]:
    print(name, "->", Path(name).suffix)
```

</CodeExample>

## Тесты «туда и обратно»

Как убедиться, что сохранение и загрузка действительно работают? Сохраните трекер, загрузите его обратно и сравните: если `loaded.expenses == tracker.expenses`, по дороге ничего не потерялось и не изменилось. Это называется **тестом «туда и обратно» (round-trip test)**, и он ловит множество ошибок (забытый `float()`, пропавший столбец, перепутанные поля).

Инструкция (statement) **`assert`** в Python — быстрый способ записать такую проверку. Если условие `True`, ничего не происходит; если `False`, выбрасывается `AssertionError` с вашим сообщением:

<CodeExample output="All checks passed!">

```python
saved = [12.5, 3.25]
loaded = [float(text) for text in ["12.5", "3.25"]]

assert loaded == saved, "the amounts changed!"
assert len(loaded) == 2, "an expense went missing!"
print("All checks passed!")
```

</CodeExample>

```python
assert ["12.5"] == [12.5], "the amounts changed!"
# AssertionError: the amounts changed!
```

<Callout type="note" title="Две опасности, о которых стоит знать">

Пропущенная строка **исчезнет** при следующем сохранении, а файл, который вообще не является корректным JSON, заставит `json.load` выбросить `json.JSONDecodeError`. Аккуратное приложение сохранило бы резервную копию перед записью. Для нашего трекера достаточно предупреждений.

</Callout>

        return len(self.expenses)


FIELDS = ["date", "amount", "category", "description"]


def save_csv(tracker, path):
    with open(path, "w", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=FIELDS)
        writer.writeheader()
        for expense in tracker.expenses:
            writer.writerow(asdict(expense))


def load_csv(path):
    tracker = ExpenseTracker()
    try:
        with open(path, newline="") as file:
            rows = list(csv.DictReader(file))
    except FileNotFoundError:
        return tracker
    for line, row in enumerate(rows, start=2):
        try:
            tracker.add(Expense.from_dict(row))
        except (KeyError, ValueError, TypeError, ExpenseError) as err:
            print(f"Warning: skipped line {line}: {err}")
    return tracker


def save_json(tracker, path):
    data = [asdict(expense) for expense in tracker.expenses]
    with open(path, "w") as file:
        json.dump(data, file, indent=2)


def load_json(path):
    tracker = ExpenseTracker()
    try:
        with open(path) as file:
            data = json.load(file)
    except FileNotFoundError:
        return tracker
    for number, item in enumerate(data, start=1):
        try:
            tracker.add(Expense.from_dict(item))
        except (KeyError, ValueError, TypeError, ExpenseError) as err:
            print(f"Warning: skipped expense {number}: {err}")
    return tracker


def save(tracker, path):
    if Path(path).suffix == ".json":
        save_json(tracker, path)
    else:
        save_csv(tracker, path)


def load(path):
    if Path(path).suffix == ".json":
        return load_json(path)
    return load_csv(path)

## Что вы построили

- **`asdict()`** и **`Expense.from_dict()`**, чтобы превращать расходы в словари и обратно, преобразуя сумму с помощью `float()`.
- **`save_csv` / `load_csv`** на основе `csv.DictWriter` и `csv.DictReader` и **`save_json` / `load_json`** на основе `json`.
- **Отсутствующий файл** означает пустой трекер; **битая строка** пропускается с предупреждением, в котором указан её номер.
- **`save()` и `load()`**, которые выбирают формат по расширению файла с помощью `Path(path).suffix`.
- **Тесты «туда и обратно»**, которые доказывают, что по дороге в файл и обратно ничего не теряется.
