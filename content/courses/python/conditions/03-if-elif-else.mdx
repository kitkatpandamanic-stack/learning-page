Time to make your programs **act** on True/False answers.

## if

The indented lines only run when the condition is `True`:

<CodeExample output="You won! 🏆">

```python
score = 120

if score > 100:
    print("You won! 🏆")
```

</CodeExample>

<Callout type="note" title="Indentation matters">

Python uses **indentation** (4 spaces) instead of curly braces to group code. The colon `:` at the end of the `if` line starts the block. Forgetting either gives an error.

</Callout>

## else and elif

`else` runs when the condition is `False`. `elif` ("else if") adds more choices, checked **top to bottom**; only the first match runs:

<CodeExample output="Grade: B">

```python
marks = 78

if marks >= 90:
    print("Grade: A")
elif marks >= 70:
    print("Grade: B")
elif marks >= 50:
    print("Grade: C")
else:
    print("Grade: F")
```

</CodeExample>

<Callout type="tip">

Order matters. If you checked `marks >= 50` first, a mark of 95 would get a C, because that block would match before the others are checked.

</Callout>

## Conditional expressions

For a quick choice between two **values**, write the condition inline:

<CodeExample output="Good evening">

```python
hour = 19
greeting = "Good morning" if hour < 12 else "Good evening"
print(greeting)
```

</CodeExample>

## match

When you compare one value against several exact options, `match` can be tidier:

<CodeExample output="Weekend! 🎉">

```python
day = "Sat"

match day:
    case "Sat" | "Sun":
        print("Weekend! 🎉")
    case "Fri":
        print("Almost there")
    case _:
        print("Weekday")
```

</CodeExample>

`|` means "or", and `case _` catches everything else.

## Recap

- `if`, `elif`, `else`, each ending with `:` and followed by an indented block.
- Only the first matching branch runs.
- `a if condition else b` picks between two values.
- `match` compares one value to many cases.
