Пора научить программы **действовать** в зависимости от ответов True/False.

## if

Строки с отступом выполняются, только если **условие** (condition) равно `True`:

<CodeExample output="Вы победили! 🏆">

```python
score = 120

if score > 100:
    print("Вы победили! 🏆")
```

</CodeExample>

<Callout type="note" title="Отступы важны">

Чтобы сгруппировать код, Python использует **отступы** (indentation, 4 пробела) вместо фигурных скобок. Двоеточие `:` в конце строки с `if` открывает блок. Если забыть отступ или двоеточие, будет ошибка.

</Callout>

## else и elif

`else` выполняется, когда условие равно `False`. `elif` («else if», «иначе если») добавляет новые варианты, которые проверяются **сверху вниз**; выполняется только первый подходящий:

<CodeExample output="Оценка: B">

```python
marks = 78

if marks >= 90:
    print("Оценка: A")
elif marks >= 70:
    print("Оценка: B")
elif marks >= 50:
    print("Оценка: C")
else:
    print("Оценка: F")
```

</CodeExample>

<Callout type="tip">

Порядок важен. Если сначала проверить `marks >= 50`, то за 95 баллов поставят C: этот блок сработает раньше, чем дело дойдёт до остальных проверок.

</Callout>

## Условные выражения

Чтобы быстро выбрать одно из двух **значений**, запишите условие в одну строку:

<CodeExample output="Добрый вечер">

```python
hour = 19
greeting = "Доброе утро" if hour < 12 else "Добрый вечер"
print(greeting)
```

</CodeExample>

## match

Когда одно значение нужно сравнить с несколькими точными вариантами, `match` бывает аккуратнее:

<CodeExample output="Выходной! 🎉">

```python
day = "Сб"

match day:
    case "Сб" | "Вс":
        print("Выходной! 🎉")
    case "Пт":
        print("Почти выходные")
    case _:
        print("Будний день")
```

</CodeExample>

`|` означает «или», а `case _` ловит все остальные случаи.

Выведите оценку для `marks`: `A` за 90 и больше, `B` за 70 и больше, `C` за 50 и больше и `F` в остальных случаях. Если `marks` меньше 0 или больше 100, вместо оценки выведите `Неверные баллы`. Нажмите **«Проверить»** с `marks = 85`, а потом попробуйте `95`, `30` и `150`.

<Hint>

Проверку на неверные баллы поставьте **первой** и объедините два условия с помощью `or`.

</Hint>

```python
marks = 85

if marks < 0 or marks > 100:
    print("Неверные баллы")
elif marks >= 90:
    print("A")
elif marks >= 70:
    print("B")
elif marks >= 50:
    print("C")
else:
    print("F")
```

</Solution>

## Итоги

- `if`, `elif`, `else` заканчиваются на `:`, а за ними идёт блок с отступом.
- Выполняется только первая подходящая ветка.
- `a if condition else b` выбирает одно из двух значений.
- `match` сравнивает одно значение со многими вариантами.
