Чтобы принимать решения, программа сначала задаёт вопросы вроде *«счёт больше 100?»*. Сравнения отвечают на них `True` или `False` — это **логические значения** (boolean).

## Операторы сравнения

<CodeExample output={`True
False
True
True
False`}>

```python
age = 15
print(age > 12)
print(age < 12)
print(age >= 15)
print(age == 15)
print(age != 15)
```

</CodeExample>

**Операторы сравнения** (comparison operators): `>` больше, `<` меньше, `>=` больше или равно, `<=` меньше или равно, `==` равно, `!=` не равно.

<Callout type="warning" title="= или ==">

Один знак `=` **присваивает** значение (`age = 15`). Два знака `==` **сравнивают** значения (`age == 15`). Путаница между ними — самая частая ошибка новичков.

</Callout>

Значения разных типов никогда не равны, поэтому текст `"5"` и число `5` не совпадают:

<CodeExample output="False">

```python
print("5" == 5)
```

</CodeExample>

## Цепочки сравнений

Python позволяет записывать диапазоны так же, как в математике:

<CodeExample output="True">

```python
age = 15
print(13 <= age <= 19)
```

</CodeExample>

## and, or, not

| Оператор | `True`, когда…                       |
| -------- | ------------------------------------ |
| `and`    | истинны **обе** стороны              |
| `or`     | истинна **хотя бы одна** сторона     |
| `not`    | меняет `True` ↔ `False`              |

<CodeExample output={`True
False
True`}>

```python
age = 15
has_ticket = True

print(age >= 12 and has_ticket)
print(age >= 18 or not has_ticket)
print(not False)
```

</CodeExample>

## Истинные и ложные значения

Python может считать любое значение истинным (truthy) или ложным (falsy). **Пустые** и **нулевые** значения ложны: `False`, `0`, `0.0`, `""`, `[]` и `None`. Всё остальное истинно.

<CodeExample output={`False
False
True
False`}>

```python
print(bool(0))
print(bool(""))
print(bool("0"))
print(bool([]))
```

</CodeExample>

## Итоги

- `> < >= <= == !=` сравнивают значения и дают `True` или `False`.
- Цепочки вроде `13 <= age <= 19` проверяют диапазоны.
- `and` требует обе стороны, `or` — хотя бы одну, `not` меняет значение на противоположное.
- Нулевые и пустые значения ложны.
