To make decisions, a program first asks questions like *"is the score above 100?"*. Comparisons answer with `True` or `False`.

## Comparison operators

<CodeExample output={`True
False
True
True
False`}>

```python
age = 15
print(age > 12)
print(age < 12)
print(age >= 15)
print(age == 15)
print(age != 15)
```

</CodeExample>

<Callout type="warning" title="= vs ==">

One `=` **assigns** a value (`age = 15`). Two `==` **compare** values (`age == 15`). Mixing them up is the most common beginner bug.

</Callout>

Different types are never equal, so the text `"5"` and the number `5` don't match:

<CodeExample output="False">

```python
print("5" == 5)
```

</CodeExample>

## Chained comparisons

Python lets you write ranges the way you would in maths:

<CodeExample output="True">

```python
age = 15
print(13 <= age <= 19)
```

</CodeExample>

## and, or, not

| Operator | `True` when…                  |
| -------- | ----------------------------- |
| `and`    | **both** sides are true       |
| `or`     | **at least one** side is true |
| `not`    | flips `True` ↔ `False`        |

<CodeExample output={`True
False
True`}>

```python
age = 15
has_ticket = True

print(age >= 12 and has_ticket)
print(age >= 18 or not has_ticket)
print(not False)
```

</CodeExample>

## Truthy and falsy

Python can treat any value as true or false. **Empty** and **zero** values are falsy: `False`, `0`, `0.0`, `""`, `[]` and `None`. Everything else is truthy.

<CodeExample output={`False
False
True
False`}>

```python
print(bool(0))
print(bool(""))
print(bool("0"))
print(bool([]))
```

</CodeExample>

## Recap

- `> < >= <= == !=` compare values and give `True` or `False`.
- Chains like `13 <= age <= 19` check ranges.
- `and` needs both, `or` needs one, `not` flips.
- Zero and empty values are falsy.
