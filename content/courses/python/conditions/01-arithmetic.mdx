Python makes a great calculator. Here are its **arithmetic operators**.

## The operators

<CodeExample output={`13
7
30
3.3333333333333335
3
1
1000`}>

```python
print(10 + 3)   # addition
print(10 - 3)   # subtraction
print(10 * 3)   # multiplication
print(10 / 3)   # division
print(10 // 3)  # floor division (whole part)
print(10 % 3)   # remainder
print(10 ** 3)  # power
```

</CodeExample>

## Two kinds of division

- `/` **always** gives a `float`, even when the answer is whole.
- `//` gives the whole number part, rounded down.

<CodeExample output={`3.0
3`}>

```python
print(6 / 2)
print(6 // 2)
```

</CodeExample>

The remainder operator `%` is perfect for checking whether a number is even: `n % 2` is `0` for even numbers.

<Callout type="note" title="Why 3.3333333333333335?">

Computers store decimals in binary, so some results are very slightly off. Use `round()` when you show them: `round(10 / 3, 2)` gives `3.33`.

</Callout>

## Order of operations

`**` happens first, then `*`, `/`, `//`, `%`, then `+` and `-`. Brackets let you choose:

<CodeExample output={`14
20`}>

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

</CodeExample>

## Updating variables

<CodeExample output={`15
30`}>

```python
score = 10
score += 5   # same as: score = score + 5
print(score)
score *= 2   # same as: score = score * 2
print(score)
```

</CodeExample>

<Callout type="warning" title="No ++ in Python">

Python has no `score++`. Write `score += 1` instead.

</Callout>

A pizza costs `12` and you have `3` friends (plus you, so 4 people). Store these in variables and print how much each person pays with an f-string: `Each person pays 3.0`. Notice that `/` gives a float!

<Solution>

```python
pizza_price = 12
people = 3 + 1
share = pizza_price / people
print(f"Each person pays {share}")
```

</Solution>

</Exercise>

## Recap

- `+ - * / // % **` cover all basic maths.
- `/` always returns a float; `//` gives the whole-number part.
- `+=`, `-=`, `*=` update a variable; there is no `++`.
