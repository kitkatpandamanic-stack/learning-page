Python — отличный калькулятор. Вот его **арифметические операторы** (arithmetic operators).

## Операторы

<CodeExample output={`13
7
30
3.3333333333333335
3
1
1000`}>

```python
print(10 + 3)   # сложение
print(10 - 3)   # вычитание
print(10 * 3)   # умножение
print(10 / 3)   # деление
print(10 // 3)  # целочисленное деление (целая часть)
print(10 % 3)   # остаток от деления
print(10 ** 3)  # возведение в степень
```

</CodeExample>

## Два вида деления

- `/` **всегда** даёт `float`, даже если результат целый.
- `//` даёт целую часть, округлённую вниз.

<CodeExample output={`3.0
3`}>

```python
print(6 / 2)
print(6 // 2)
```

</CodeExample>

Оператор остатка `%` идеально подходит, чтобы проверить, чётное ли число: для чётных чисел `n % 2` равно `0`.

<Callout type="note" title="Откуда 3.3333333333333335?">

Компьютеры хранят дробные числа в двоичном виде, поэтому некоторые результаты получаются чуть-чуть неточными. Когда показываете такие числа, используйте `round()`: `round(10 / 3, 2)` даёт `3.33`.

</Callout>

## Порядок действий

Сначала выполняется `**`, затем `*`, `/`, `//`, `%`, а потом `+` и `-`. Скобки позволяют задать свой порядок:

<CodeExample output={`14
20`}>

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

</CodeExample>

## Обновление переменных

<CodeExample output={`15
30`}>

```python
score = 10
score += 5   # то же, что score = score + 5
print(score)
score *= 2   # то же, что score = score * 2
print(score)
```

</CodeExample>

<Callout type="warning" title="В Python нет ++">

В Python нет `score++`. Вместо этого пишите `score += 1`.

</Callout>

<Exercise
  language="python"
  starter={`# Пицца стоит 12, а ещё есть 3 друга плюс вы
`}
  expectedOutput="Каждый платит 3.0"

Пицца стоит `12`, и у вас `3` друга (плюс вы — итого 4 человека). Сохраните эти данные в переменные и с помощью f-строки выведите, сколько платит каждый: `Каждый платит 3.0`. Обратите внимание: `/` даёт float!

<Solution>

```python
pizza_price = 12
people = 3 + 1
share = pizza_price / people
print(f"Каждый платит {share}")
```

</Solution>

</Exercise>

## Итоги

- `+ - * / // % **` покрывают всю базовую математику.
- `/` всегда возвращает float; `//` даёт целую часть.
- `+=`, `-=`, `*=` обновляют переменную; `++` в Python нет.
