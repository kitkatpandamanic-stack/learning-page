До сих пор вы создавали новые списки с помощью цикла: заводили пустой список, запускали цикл, вызывали `.append()`. Этот шаблон встречается так часто, что в Python для него есть сокращённая запись — **списковое включение** (list comprehension). В этом уроке вы освоите включения, два удобных помощника `enumerate` и `zip`, а затем соберёте **счётчик частоты слов**.

## Списковые включения

Вот один и тот же список, созданный дважды: сначала циклом, а потом **списковым включением**:

<CodeExample output={`[1, 4, 9, 16, 25]
[1, 4, 9, 16, 25]`}>

```python
squares = []
for n in range(1, 6):
    squares.append(n * n)
print(squares)

squares = [n * n for n in range(1, 6)]
print(squares)
```

</CodeExample>

Читайте это так: *«`n * n` **для** каждого `n` **из** `range(1, 6)`»*. Форма всегда одна и та же:

```python
[expression for item in iterable]
```

**Выражение** (expression) в начале говорит, каким должен быть каждый новый элемент. Это может быть что угодно, например вызов метода:

<CodeExample output="['MEI', 'SAM', 'ALI']">

```python
names = ["mei", "sam", "ali"]
shouting = [name.upper() for name in names]
print(shouting)
```

</CodeExample>

## Фильтрация с if

Добавьте `if` в конце, чтобы оставить только часть элементов:

<CodeExample output={`[2, 4, 6]
['kiwi', 'fig']
['зачёт', 'незачёт', 'зачёт']`}>

```python
numbers = [1, 2, 3, 4, 5, 6]
evens = [n for n in numbers if n % 2 == 0]
print(evens)

fruits = ["banana", "kiwi", "fig", "mango"]
short = [f for f in fruits if len(f) <= 4]
print(short)

scores = [72, 45, 90]
results = ["зачёт" if s >= 50 else "незачёт" for s in scores]
print(results)
```

</CodeExample>

<Callout type="note" title="Два разных if">

`if` в **конце** фильтрует: элементы, не прошедшие проверку, отбрасываются. Условное выражение `a if condition else b` в **начале** сохраняет все элементы, но выбирает, во что каждый из них превратится. В последнем примере выше используется именно такой `if` — в начале.

</Callout>

## Включения для словарей и множеств

Фигурные скобки с парой `key: value` создают **включение для словаря** (dict comprehension). Фигурные скобки с одним выражением создают **включение для множества** (set comprehension):

<CodeExample output={`{'mei': 3, 'sam': 3, 'alex': 4}
{'apple': 0.5, 'bread': 1.0}
[3, 4]`}>

```python
names = ["mei", "sam", "alex"]
lengths = {name: len(name) for name in names}
print(lengths)

prices = {"apple": 1, "bread": 2, "cake": 5}
sale = {item: price / 2 for item, price in prices.items()
        if price < 5}
print(sale)

unique_lengths = {len(name) for name in names}
print(sorted(unique_lengths))
```

</CodeExample>

Длинное включение можно разбить на несколько строк внутри скобок, как в примере с `sale`.

## Вложенные включения

Во включении может быть несколько `for`. Они читаются **в том же порядке**, в каком вы записали бы вложенные циклы. Частый случай — **«выпрямление»** (flattening) списка списков:

<CodeExample output={`[1, 2, 3, 4, 5, 6]
[(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]`}>

```python
grid = [[1, 2], [3, 4], [5, 6]]
flat = [n for row in grid for n in row]
print(flat)

pairs = [(n, letter) for n in [1, 2] for letter in "ab"]
print(pairs)
```

</CodeExample>

Не увлекайтесь вложенными включениями: два `for` — это примерно предел, после которого обычный цикл читается легче.

## enumerate и zip

С `enumerate` вы уже встречались, когда работали со списками: он связывает каждый элемент с его позицией. Его напарник **`zip`** проходит **по двум (или более) спискам одновременно** и каждый раз даёт по одному элементу из каждого:

<CodeExample output={`Результат Mei: 88
Результат Sam: 75
Результат Ali: 93
{'Mei': 88, 'Sam': 75, 'Ali': 93}
['1. Mei', '2. Sam', '3. Ali']`}>

```python
names = ["Mei", "Sam", "Ali"]
scores = [88, 75, 93]

for name, score in zip(names, scores):
    print(f"Результат {name}: {score}")

print(dict(zip(names, scores)))

ranked = [f"{i}. {name}" for i, name in enumerate(names, start=1)]
print(ranked)
```

</CodeExample>

`dict(zip(keys, values))` — изящный способ собрать словарь из двух списков.

<Callout type="warning" title="zip останавливается на самом коротком списке">

Если списки разной длины, `zip` молча останавливается, как только заканчивается самый короткий из них. Лишние элементы длинного списка игнорируются. Передайте в `zip` аргумент `strict=True`, чтобы вместо этого получить ошибку.

</Callout>

## Когда включения не нужны

Включения нужны, чтобы **создать новую коллекцию**. Не используйте их только ради того, чтобы выполнить код для каждого элемента, и не втискивайте сложную логику в одну строку:

```python
# ❌ Создаёт бесполезный список из None только ради печати
[print(name) for name in names]

# ✅ Обычный цикл прямо говорит, что вы имеете в виду
for name in names:
    print(name)
```

<Callout type="tip" title="Главное — читаемость">

Если во включении нужно несколько `if`, вложенные условия или больше двух `for`, напишите обычный цикл. Код читают гораздо чаще, чем пишут, поэтому выбирайте то, что будет проще всего понять **следующему человеку**.

</Callout>

Соберите **счётчик частоты слов** из трёх небольших функций:

1. `clean_words(text)` возвращает список слов в нижнем регистре без знаков препинания. Замените каждый символ, который не является буквой, на пробел, а затем вызовите `.split()`.
2. `count_words(words)` возвращает словарь, в котором каждому слову сопоставлено, сколько раз оно встречается.
3. `top_words(counts, n=3)` возвращает список из `n` самых частых кортежей `(word, count)`, начиная с самого частого. Слова с одинаковым количеством идут в **алфавитном** порядке.

Для текста из примера ответ — `[('panda', 3), ('the', 3), ('bamboo', 2)]`. Попробуйте и на своём тексте!

<Hint>

- **clean_words**: `"".join([ch if ch.isalpha() else " " for ch in text.lower()])` даёт очищенную строку. `.split()` без аргументов разбивает строку по любому количеству пробельных символов.
- **count_words**: используйте шаблон подсчёта из урока о словарях: `counts.get(word, 0) + 1`.
- **top_words**: отсортируйте `counts.items()` с `key=lambda pair: (-pair[1], pair[0])`. Кортежи сравниваются поэлементно, поэтому так вы отсортируете сначала по количеству (по убыванию — благодаря минусу), а затем по слову. В конце возьмите срез `[:n]`.

</Hint>

<Solution>

```python
text = """The panda eats bamboo. The panda sleeps!
Bamboo is tasty, and the panda knows it."""

def clean_words(text):
    letters = [ch if ch.isalpha() else " " for ch in text.lower()]
    return "".join(letters).split()

def count_words(words):
    counts = {}
    for word in words:
        counts[word] = counts.get(word, 0) + 1
    return counts

def top_words(counts, n=3):
    ranked = sorted(counts.items(),
                    key=lambda pair: (-pair[1], pair[0]))
    return ranked[:n]

for word, count in top_words(count_words(clean_words(text))):
    print(f"{word}: {count}")
```

</Solution>

<Callout type="tip" title="Бонус: collections.Counter">

Подсчёт нужен так часто, что в стандартной библиотеке Python для него есть готовый инструмент. `Counter` из модуля `collections` — это словарь, который считает за вас:

```python
from collections import Counter

counts = Counter(["a", "b", "a", "c", "a"])
print(counts["a"])            # 3
print(counts.most_common(1))  # [('a', 3)]
```

Его полезно знать, но если сначала написать счётчик самостоятельно, вы будете понимать, как он устроен внутри.

</Callout>

## Итоги

- `[expr for item in items]` создаёт список; добавьте `if condition` в конце, чтобы отфильтровать элементы.
- `{k: v for ...}` создаёт словарь, а `{expr for ...}` — множество.
- Несколько `for` в одном включении работают как вложенные циклы; ограничивайтесь двумя.
- `enumerate` связывает элементы с позициями; `zip` проходит по спискам одновременно.
- Используйте включения для создания коллекций, а обычные циклы — для действий и сложной логики.
- Подсчёт слов = очистить текст, посчитать слова словарём, а затем отсортировать с `key=`.
