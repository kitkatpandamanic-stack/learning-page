So far you've built new lists with a loop: create an empty list, loop, `.append()`. That pattern is so common that Python has a shortcut for it, called a **comprehension**. In this lesson you'll learn comprehensions, two handy helpers called `enumerate` and `zip`, and then build a **word frequency counter**.

## List comprehensions

Here's the same list built twice, first with a loop and then with a **list comprehension**:

<CodeExample output={`[1, 4, 9, 16, 25]
[1, 4, 9, 16, 25]`}>

```python
squares = []
for n in range(1, 6):
    squares.append(n * n)
print(squares)

squares = [n * n for n in range(1, 6)]
print(squares)
```

</CodeExample>

Read it as *"`n * n` **for** each `n` **in** `range(1, 6)`"*. The shape is always:

```python
[expression for item in iterable]
```

The **expression** at the front says what each new item should be. It can be anything, like a method call:

<CodeExample output="['MEI', 'SAM', 'ALI']">

```python
names = ["mei", "sam", "ali"]
shouting = [name.upper() for name in names]
print(shouting)
```

</CodeExample>

## Filtering with if

Add an `if` at the end to keep only some items:

<CodeExample output={`[2, 4, 6]
['kiwi', 'fig']
['pass', 'fail', 'pass']`}>

```python
numbers = [1, 2, 3, 4, 5, 6]
evens = [n for n in numbers if n % 2 == 0]
print(evens)

fruits = ["banana", "kiwi", "fig", "mango"]
short = [f for f in fruits if len(f) <= 4]
print(short)

scores = [72, 45, 90]
results = ["pass" if s >= 50 else "fail" for s in scores]
print(results)
```

</CodeExample>

<Callout type="note" title="Two different ifs">

An `if` at the **end** filters: items that fail are left out. A conditional expression `a if condition else b` at the **front** keeps every item but chooses what it becomes. The last example above uses the front kind.

</Callout>

## Dict and set comprehensions

Curly braces with a `key: value` pair make a **dict comprehension**. Curly braces with a single expression make a **set comprehension**:

<CodeExample output={`{'mei': 3, 'sam': 3, 'alex': 4}
{'apple': 0.5, 'bread': 1.0}
[3, 4]`}>

```python
names = ["mei", "sam", "alex"]
lengths = {name: len(name) for name in names}
print(lengths)

prices = {"apple": 1, "bread": 2, "cake": 5}
sale = {item: price / 2 for item, price in prices.items()
        if price < 5}
print(sale)

unique_lengths = {len(name) for name in names}
print(sorted(unique_lengths))
```

</CodeExample>

A long comprehension can be split over several lines inside its brackets, like the `sale` example.

## Nested comprehensions

A comprehension can have more than one `for`. The `for`s are read **in the same order** as nested loops would be written. A common use is **flattening** a list of lists:

<CodeExample output={`[1, 2, 3, 4, 5, 6]
[(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]`}>

```python
grid = [[1, 2], [3, 4], [5, 6]]
flat = [n for row in grid for n in row]
print(flat)

pairs = [(n, letter) for n in [1, 2] for letter in "ab"]
print(pairs)
```

</CodeExample>

Use nested comprehensions sparingly: two `for`s is about the limit before a normal loop becomes easier to read.

## enumerate and zip

You met `enumerate` with lists: it pairs every item with its position. Its partner **`zip`** walks through **two (or more) lists side by side**, giving you one item from each at a time:

<CodeExample output={`Mei scored 88
Sam scored 75
Ali scored 93
{'Mei': 88, 'Sam': 75, 'Ali': 93}
['1. Mei', '2. Sam', '3. Ali']`}>

```python
names = ["Mei", "Sam", "Ali"]
scores = [88, 75, 93]

for name, score in zip(names, scores):
    print(f"{name} scored {score}")

print(dict(zip(names, scores)))

ranked = [f"{i}. {name}" for i, name in enumerate(names, start=1)]
print(ranked)
```

</CodeExample>

`dict(zip(keys, values))` is a neat way to build a dict from two lists.

<Callout type="warning" title="zip stops at the shortest list">

If the lists have different lengths, `zip` quietly stops when the shortest one runs out. Extra items in the longer list are ignored. Pass `strict=True` to `zip` to get an error instead.

</Callout>

## When not to use a comprehension

Comprehensions are for **building a new collection**. Don't use them just to run code for each item, and don't cram complicated logic into one line:

```python
# ❌ Builds a useless list of None values just to print
[print(name) for name in names]

# ✅ A plain loop says what you mean
for name in names:
    print(name)
```

<Callout type="tip" title="Readability wins">

If a comprehension needs several `if`s, nested conditions or more than two `for`s, write a normal loop. Code is read far more often than it's written, so pick whatever is easiest for the **next person** to understand.

</Callout>

Build a **word frequency counter** from three small functions:

1. `clean_words(text)` returns a list of lowercase words with the punctuation gone. Turn every character that isn't a letter into a space, then `.split()`.
2. `count_words(words)` returns a dict mapping each word to how many times it appears.
3. `top_words(counts, n=3)` returns a list of the `n` most common `(word, count)` tuples, most common first. Words with the same count go in **alphabetical** order.

With the example text, the answer is `[('panda', 3), ('the', 3), ('bamboo', 2)]`. Try it on your own text too!

<Hint>

- **clean_words**: `"".join([ch if ch.isalpha() else " " for ch in text.lower()])` gives a cleaned string. `.split()` with no arguments splits on any amount of whitespace.
- **count_words**: use the counting pattern from the dictionaries lesson, `counts.get(word, 0) + 1`.
- **top_words**: sort `counts.items()` with `key=lambda pair: (-pair[1], pair[0])`. Tuples are compared item by item, so this sorts by count (highest first, thanks to the minus) and then by word. Finish with a slice `[:n]`.

</Hint>

<Solution>

```python
text = """The panda eats bamboo. The panda sleeps!
Bamboo is tasty, and the panda knows it."""

def clean_words(text):
    letters = [ch if ch.isalpha() else " " for ch in text.lower()]
    return "".join(letters).split()

def count_words(words):
    counts = {}
    for word in words:
        counts[word] = counts.get(word, 0) + 1
    return counts

def top_words(counts, n=3):
    ranked = sorted(counts.items(),
                    key=lambda pair: (-pair[1], pair[0]))
    return ranked[:n]

for word, count in top_words(count_words(clean_words(text))):
    print(f"{word}: {count}")
```

</Solution>

<Callout type="tip" title="Bonus: collections.Counter">

Counting is so common that Python's standard library has a ready-made tool for it. `Counter` from the `collections` module is a dict that counts for you:

```python
from collections import Counter

counts = Counter(["a", "b", "a", "c", "a"])
print(counts["a"])            # 3
print(counts.most_common(1))  # [('a', 3)]
```

It's worth knowing, but building the counter yourself first means you understand what it does underneath.

</Callout>

## Recap

- `[expr for item in items]` builds a list; add `if condition` at the end to filter.
- `{k: v for ...}` builds a dict and `{expr for ...}` builds a set.
- Several `for`s in one comprehension work like nested loops; keep it to two at most.
- `enumerate` pairs items with positions; `zip` walks through lists side by side.
- Use comprehensions to build collections, and plain loops for actions or complex logic.
- Counting words = clean the text, count with a dict, then sort with `key=`.
