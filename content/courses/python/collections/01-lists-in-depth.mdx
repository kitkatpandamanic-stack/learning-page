You already know how to make a list, `.append()` to it and loop over it. Lists can do a lot more. In this lesson you'll learn the tools Python programmers use with lists **every single day**.

## Indexing from both ends

Positions (called **indexes**) start at `0`. **Negative indexes** count from the end, so `-1` is always the last item:

<CodeExample output={`red
blue
green`}>

```python
colours = ["red", "green", "blue"]
print(colours[0])
print(colours[-1])
print(colours[-2])
```

</CodeExample>

Unlike strings, lists are **mutable**: you can change an item in place by assigning to its index.

<CodeExample output="['red', 'gold', 'blue']">

```python
colours = ["red", "green", "blue"]
colours[1] = "gold"
print(colours)
```

</CodeExample>

<Callout type="warning" title="IndexError">

Asking for a position that doesn't exist, like `colours[3]` on a three-item list, stops your program with an `IndexError: list index out of range`. The last valid index is always `len(colours) - 1`.

</Callout>

## Slicing

Slices work exactly like they do on strings: `items[start:end]` takes items from `start` up to, **but not including**, `end`. Leave a number out to mean "from the beginning" or "to the end". A third number is the **step**:

<CodeExample output={`[20, 30, 40]
[10, 20]
[40, 50, 60]
[10, 30, 50]
[60, 50, 40, 30, 20, 10]`}>

```python
numbers = [10, 20, 30, 40, 50, 60]
print(numbers[1:4])
print(numbers[:2])
print(numbers[-3:])
print(numbers[::2])
print(numbers[::-1])
```

</CodeExample>

A slice always gives you a **new list** and never changes the original. `numbers[::-1]` is a handy way to get a reversed copy.

## Adding items

| Method                 | What it does                                 |
| ---------------------- | -------------------------------------------- |
| `.append(x)`           | Adds `x` to the end                          |
| `.insert(i, x)`        | Adds `x` at position `i`, shifting the rest  |
| `.extend(other_list)`  | Adds every item of another list to the end   |

<CodeExample output={`['Mei', 'Sam', 'Ali']
['Zoe', 'Mei', 'Sam', 'Ali']
['Zoe', 'Mei', 'Sam', 'Ali', 'Ben', 'Lia']`}>

```python
queue = ["Mei", "Sam"]
queue.append("Ali")
print(queue)

queue.insert(0, "Zoe")   # jump to the front
print(queue)

queue.extend(["Ben", "Lia"])
print(queue)
```

</CodeExample>

<Callout type="note" title="append vs extend">

`queue.append(["Ben", "Lia"])` would add the whole list as **one** item, giving a list inside a list. `extend` adds the items one by one.

</Callout>

## Removing and finding items

- `.remove(x)` deletes the **first** item equal to `x`.
- `.pop()` removes the last item and **returns** it; `.pop(i)` removes the item at position `i`.
- `.index(x)` tells you the position of the first `x`.
- `.count(x)` tells you how many times `x` appears.

<CodeExample output={`['eggs', 'tea', 'milk', 'bread']
bread
eggs
['tea', 'milk']
1
1`}>

```python
shopping = ["eggs", "milk", "tea", "milk", "bread"]

shopping.remove("milk")   # only the first "milk" goes
print(shopping)

last = shopping.pop()
print(last)

first = shopping.pop(0)
print(first)
print(shopping)

print(shopping.index("milk"))
print(shopping.count("tea"))
```

</CodeExample>

<Callout type="warning">

`.remove(x)` and `.index(x)` raise a `ValueError` if `x` isn't in the list. Check first with `if x in shopping:` when you're not sure.

</Callout>

## Sorting: sort() vs sorted()

There are two ways to sort, and the difference matters:

- `items.sort()` sorts the list **in place** (it changes the list) and returns `None`.
- `sorted(items)` leaves the original alone and returns a **new** sorted list.

Both accept `reverse=True` for largest first. `.reverse()` simply flips the list in place, without sorting.

<CodeExample output={`[1, 3, 7, 9]
[7, 3, 9, 1]
[1, 9, 3, 7]
[9, 7, 3, 1]`}>

```python
scores = [7, 3, 9, 1]

print(sorted(scores))  # a new list
print(scores)          # unchanged

scores.reverse()       # just flipped, not sorted
print(scores)

scores.sort(reverse=True)
print(scores)          # sorted in place
```

</CodeExample>

<Callout type="danger" title="A classic bug">

`scores = scores.sort()` sets `scores` to `None`, because `.sort()` returns nothing. Either call `scores.sort()` on its own line, or write `scores = sorted(scores)`.

</Callout>

### Sorting with key=

By default, Python compares the items themselves. Pass a **`key`** function to sort by something else. Python calls the function on each item and sorts by the results:

<CodeExample output={`['fig', 'kiwi', 'mango', 'banana']
['apple', 'Banana', 'cherry']
[('Sam', 19), ('Mei', 12), ('Ali', 15)]
[('Mei', 12), ('Ali', 15), ('Sam', 19)]`}>

```python
fruits = ["banana", "fig", "kiwi", "mango"]
print(sorted(fruits, key=len))

names = ["cherry", "Banana", "apple"]
print(sorted(names, key=str.lower))

people = [("Sam", 19), ("Mei", 12), ("Ali", 15)]
print(people)
print(sorted(people, key=lambda person: person[1]))
```

</CodeExample>

Notice that you pass the function **itself** (`len`, not `len()`). A `lambda` is perfect for small keys like "the second item".

<Callout type="tip">

Without `key=str.lower`, capital letters sort **before** all lowercase letters, so `"Zebra"` would come before `"apple"`.

</Callout>

## Nested lists

A list can hold other lists. This is a simple way to store a grid or a table. Use two indexes: first the row, then the column.

<CodeExample output={`6
[7, 8, 9]
1 2 3
4 5 6
7 8 9`}>

```python
grid = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]
print(grid[1][2])   # row 1, column 2
print(grid[-1])

for row in grid:
    print(row[0], row[1], row[2])
```

</CodeExample>

## Copying vs aliasing

This one surprises everyone at first. `b = a` does **not** copy a list. It gives the **same** list a second name (an **alias**). Change it through one name and you'll see the change through the other:

<CodeExample output={`['Mei', 'Sam', 'Ali']
['Mei', 'Sam', 'Ali']
['Mei', 'Sam']`}>

```python
team = ["Mei", "Sam"]
same_team = team        # an alias, not a copy
same_team.append("Ali")
print(team)
print(same_team)

team = ["Mei", "Sam"]
copy = team.copy()      # a real copy
copy.append("Ali")
print(team)
```

</CodeExample>

There are three common ways to make a copy, and they all do the same thing:

```python
copy1 = team.copy()
copy2 = list(team)
copy3 = team[:]
```

<Callout type="note" title="Shallow copies">

These are **shallow** copies: a copy of a nested list still shares the inner lists with the original. For a fully independent copy of nested data, use `copy.deepcopy()` from the `copy` module.

</Callout>

## Checking with in, and unpacking

`in` checks whether a value is in a list (and `not in` checks the opposite). **Unpacking** puts the items of a list into separate variables in one go. A `*` name collects "everything else":

<CodeExample output={`True
True
Mei 12 Tashkent
1
[2, 3, 4]`}>

```python
pets = ["cat", "dog", "panda"]
print("panda" in pets)
print("snake" not in pets)

name, age, city = ["Mei", 12, "Tashkent"]
print(name, age, city)

first, *rest = [1, 2, 3, 4]
print(first)
print(rest)
```

</CodeExample>

The number of names must match the number of items, unless you use a `*` name.

## Recap

- Negative indexes count from the end; `items[-1]` is the last item.
- Slices `items[start:end:step]` return a new list; `items[::-1]` reverses.
- `.append()`, `.insert()`, `.extend()` add; `.remove()`, `.pop()` take away; `.index()` and `.count()` search.
- `.sort()` changes the list and returns `None`; `sorted()` returns a new list. Both take `key=` and `reverse=True`.
- `b = a` is an alias; `a.copy()`, `list(a)` and `a[:]` make copies.
- `x in items` checks membership, and `first, *rest = items` unpacks.
