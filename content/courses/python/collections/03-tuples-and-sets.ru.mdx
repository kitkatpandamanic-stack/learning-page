Больше всего внимания достаётся спискам и словарям, но в Python есть ещё две коллекции, которыми вы будете пользоваться постоянно: **кортежи** (tuples) для небольших фиксированных групп значений и **множества** (sets) для наборов уникальных элементов.

## Кортежи: списки, которые нельзя изменить

**Кортеж** (tuple) записывается в круглых скобках. Читать из него можно так же, как из списка, — по индексам и срезам:

<CodeExample output={`(3, 4)
3
2
<class 'tuple'>`}>

```python
point = (3, 4)
print(point)
print(point[0])
print(len(point))
print(type(point))
```

</CodeExample>

Главное отличие: кортежи **неизменяемые** (immutable). Созданный кортеж нельзя дополнить, нельзя удалить или заменить в нём элементы:

```python
point[0] = 10   # TypeError: 'tuple' object does not support item assignment
```

Звучит как ограничение, но на самом деле это полезное свойство. Кортеж говорит: *«эти значения — единое целое, и они не изменятся»*. Например, точка `(x, y)`, цвет `(255, 128, 0)` или дата `(2026, 10, 1)`.

<Callout type="warning" title="Кортежи из одного элемента">

Кортеж создаёт **запятая**, а не скобки. `(5)` — это просто число 5. Кортежу из одного элемента нужна запятая в конце: `(5,)`.

</Callout>

## Упаковка и распаковка

Если записать значения через запятую, они **упаковываются** (packing) в кортеж, даже без скобок. **Распаковка** (unpacking) снова разбирает кортеж на отдельные имена. Вместе они дают знаменитый питоновский обмен значений в одну строку:

<CodeExample output={`(12, 'Mei')
12 Mei
2 1`}>

```python
info = 12, "Mei"      # упаковка
print(info)

age, name = info      # распаковка
print(age, name)

a, b = 1, 2
a, b = b, a           # обмен значениями!
print(a, b)
```

</CodeExample>

Распаковка работает и в циклах `for` — это идеально подходит для списка кортежей:

<CodeExample output={`Результат Mei: 88
Результат Sam: 75`}>

```python
results = [("Mei", 88), ("Sam", 75)]

for name, score in results:
    print(f"Результат {name}: {score}")
```

</CodeExample>

## Возврат нескольких значений

В модуле о функциях вы возвращали несколько значений через `return min(numbers), max(numbers)`. Теперь вы знаете секрет: это упаковка! Функция возвращает **один кортеж**, и его можно распаковать или оставить целым:

<CodeExample output={`(61, 95)
61 95`}>

```python
def lowest_and_highest(numbers):
    return min(numbers), max(numbers)

result = lowest_and_highest([72, 95, 88, 61])
print(result)

low, high = lowest_and_highest([72, 95, 88, 61])
print(low, high)
```

</CodeExample>

## Кортежи как ключи словаря

Ключи словаря никогда не должны меняться, поэтому списки не могут быть ключами, а кортежи — могут. Это отлично подходит, например, для позиций на игровом поле:

<CodeExample output={`сокровище
None
2`}>

```python
board = {
    (0, 0): "старт",
    (2, 3): "сокровище",
}
print(board[(2, 3)])
print(board.get((1, 1)))
print(len(board))
```

</CodeExample>

Попытка написать `{[2, 3]: "сокровище"}` даст ошибку `TypeError: unhashable type: 'list'`. «Хешируемый» (hashable) примерно означает «неизменяемый», а именно это и нужно ключам.

## Множества: только уникальные элементы

**Множество** (set) записывается в фигурных скобках (как словарь, но без двоеточий). Множество хранит **только одну копию** каждого значения и **не имеет порядка**:

<CodeExample output={`{1, 2, 3}
3
[1, 2, 3, 5]`}>

```python
numbers = {3, 1, 3, 2, 1}
print(numbers)        # повторы исчезли
print(len(numbers))

rolls = [5, 1, 3, 5, 2, 1]
unique = set(rolls)   # превращаем список во множество
print(sorted(unique))
```

</CodeExample>

`set(some_list)` — самый быстрый способ убрать повторы. Оберните результат в `sorted()`, если нужен список в предсказуемом порядке.

<Callout type="warning" title="Пустое множество">

`{}` создаёт пустой **словарь**, а не пустое множество. Для пустого множества используйте `set()`.

</Callout>

<Callout type="note" title="У множеств нет порядка">

Поскольку множества не хранят порядок, к ним нельзя обращаться по индексу вроде `my_set[0]`, а множество строк при каждом запуске программы может печататься в другом порядке. Если порядок важен, используйте `sorted(my_set)`.

</Callout>

## Добавление, удаление и проверка

Используйте `.add()`, чтобы добавить один элемент, и `.discard()` или `.remove()`, чтобы убрать его. `.remove()` выбрасывает `KeyError`, если элемента нет, а `.discard()` молча ничего не делает. Проверка через `in` во множестве работает **очень быстро** — так же, как для ключей словаря:

<CodeExample output={`['панда', 'собака']
True
False`}>

```python
seen = set()
seen.add("панда")
seen.add("собака")
seen.add("панда")      # уже есть: ничего не меняется
seen.add("кошка")
seen.remove("кошка")
seen.discard("змея")   # такого нет: ошибки не будет
print(sorted(seen))

print("панда" in seen)
print("кошка" in seen)
```

</CodeExample>

## Операции над множествами

Множества можно комбинировать, как круги на диаграмме Венна:

| Операция          | Оператор | Метод                 | Результат                              |
| ----------------- | -------- | --------------------- | -------------------------------------- |
| **Объединение**   | `a \| b` | `a.union(b)`          | Всё, что есть хотя бы в одном множестве |
| **Пересечение**   | `a & b`  | `a.intersection(b)`   | Только то, что есть в **обоих**        |
| **Разность**      | `a - b`  | `a.difference(b)`     | Есть в `a`, но **нет** в `b`           |

<CodeExample output={`['Ali', 'Ben', 'Mei', 'Sam', 'Zoe']
['Sam', 'Zoe']
['Ali', 'Mei']
['Ben']`}>

```python
chess = {"Mei", "Sam", "Zoe", "Ali"}
art = {"Sam", "Zoe", "Ben"}

print(sorted(chess | art))   # хотя бы в одном кружке
print(sorted(chess & art))   # в обоих кружках
print(sorted(chess - art))   # только шахматы
print(sorted(art.difference(chess)))  # только рисование
```

</CodeExample>

## Как выбрать коллекцию

| Коллекция  | Как выглядит          | Упорядочена? | Изменяемая? | Повторы?           | Для чего                                              |
| ---------- | --------------------- | ------------ | ----------- | ------------------ | ----------------------------------------------------- |
| **list**   | `[1, 2, 2]`           | Да           | Да          | Да                 | Упорядоченная последовательность, которую вы дополняете или сортируете |
| **tuple**  | `(3, 4)`              | Да           | Нет         | Да                 | Фиксированная группа значений, ключи словаря          |
| **dict**   | `{"a": 1}`            | Да           | Да          | Ключи уникальны    | Поиск по имени, подсчёт                               |
| **set**    | `{1, 2}`              | Нет          | Да          | Нет                | Уникальные элементы, быстрая проверка `in`, операции над множествами |

<Callout type="tip" title="Простое правило">

Спросите себя: *ищу ли я данные по имени?* Берите **словарь**. *Важно ли мне только, есть ли что-то в наборе?* Берите **множество**. *Эта группа значений никогда не изменится?* Берите **кортеж**. Во всех остальных случаях **список** — хороший выбор по умолчанию.

</Callout>

Шахматный кружок и кружок рисования хранят своих участников в списках, и в этих списках могут быть повторы. Допишите `club_report(chess, art)` так, чтобы функция **возвращала кортеж** из трёх значений:

1. **отсортированный список** людей, которые ходят в **оба** кружка;
2. **отсортированный список** людей, которые ходят **только** в шахматы;
3. **количество** разных людей, которые ходят хотя бы в один кружок.

Для примера ответ — `(['Ali', 'Sam'], ['Mei'], 4)`.

<Hint>

Сначала превратите оба списка во множества: `a = set(chess)`. Затем используйте `a & b`, `a - b` и `len(a | b)`. Оберните первые два результата в `sorted()` и верните все три через запятую.

</Hint>

<Solution>

```python
def club_report(chess, art):
    a = set(chess)
    b = set(art)
    both = sorted(a & b)
    only_chess = sorted(a - b)
    total = len(a | b)
    return both, only_chess, total

chess = ["Mei", "Sam", "Ali"]
art = ["Sam", "Zoe", "Ali", "Sam"]
print(club_report(chess, art))
```

</Solution>

## Итоги

- **Кортежи** `(3, 4)` похожи на списки, которые нельзя изменить. Кортеж создаёт запятая: `(5,)`.
- Упаковка `x = 1, 2` и распаковка `a, b = x` позволяют менять значения местами, перебирать пары в цикле и возвращать несколько значений.
- Кортежи могут быть ключами словаря, а списки — нет.
- **Множества** `{1, 2, 3}` хранят уникальные элементы без порядка. Пустое множество — это `set()`.
- `|` — объединение, `&` — пересечение, `-` — разность.
- Выбирайте коллекцию под задачу: список, кортеж, словарь или множество.
