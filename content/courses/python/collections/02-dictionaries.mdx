A list finds things by **position**. A **dictionary** (or **dict**) finds things by **name**. It stores **key–value pairs**, like a real dictionary stores a word and its meaning. Dicts are everywhere in Python: settings, user profiles, JSON data, counters and more.

## Creating a dictionary

Write pairs inside curly braces, with a colon between each **key** and its **value**:

<CodeExample output={`{'name': 'Mei', 'age': 12, 'city': 'Tashkent'}
3`}>

```python
student = {
    "name": "Mei",
    "age": 12,
    "city": "Tashkent",
}
print(student)
print(len(student))   # the number of pairs
```

</CodeExample>

- Keys are usually strings, but numbers and tuples work too.
- Values can be anything: numbers, strings, lists, even other dicts.
- Each key appears **only once**. An empty dict is just `{}`.

## Reading values with [] and .get()

Put a key in square brackets to get its value:

<CodeExample output={`Mei
12`}>

```python
student = {"name": "Mei", "age": 12}
print(student["name"])
print(student["age"])
```

</CodeExample>

If the key doesn't exist, square brackets stop your program with a `KeyError`:

```python
print(student["email"])   # KeyError: 'email'
```

When a key might be missing, use **`.get()`**. It returns `None` instead of crashing, or a **default** value that you choose:

<CodeExample output={`None
no email
Mei`}>

```python
student = {"name": "Mei", "age": 12}
print(student.get("email"))
print(student.get("email", "no email"))
print(student.get("name", "unknown"))
```

</CodeExample>

## Adding, updating and deleting

Assigning to a key **adds** it if it's new, or **replaces** its value if it already exists. Use `del` or `.pop()` to remove a pair:

<CodeExample output={`{'name': 'Mei', 'age': 13, 'email': 'mei@example.com'}
{'name': 'Mei', 'email': 'mei@example.com'}
mei@example.com
{'name': 'Mei'}`}>

```python
student = {"name": "Mei", "age": 12}

student["age"] = 13                   # update
student["email"] = "mei@example.com"  # add
print(student)

del student["age"]
print(student)

email = student.pop("email")  # remove and return the value
print(email)
print(student)
```

</CodeExample>

## Checking for a key with in

`in` checks the **keys** of a dict, not the values:

<CodeExample output={`True
False
False`}>

```python
stock = {"apples": 5, "pears": 0}
print("apples" in stock)
print("bananas" in stock)
print(5 in stock)   # 5 is a value, not a key
```

</CodeExample>

<Callout type="tip">

Looking up a key in a dict is **very fast**, even with millions of pairs. Searching through a list gets slower the longer the list is. That speed is one big reason dicts are so popular.

</Callout>

## Looping over a dictionary

A plain `for` loop gives you the **keys**. Use `.values()` for just the values, or **`.items()`** for both at once (the one you'll use most):

<CodeExample output={`apples
pears
5
2
apples: 5
pears: 2
Total fruit: 7`}>

```python
stock = {"apples": 5, "pears": 2}

for fruit in stock:          # same as stock.keys()
    print(fruit)

for amount in stock.values():
    print(amount)

for fruit, amount in stock.items():
    print(f"{fruit}: {amount}")

print(f"Total fruit: {sum(stock.values())}")
```

</CodeExample>

<Callout type="warning" title="Don't change size while looping">

Adding or deleting keys while you loop over a dict raises `RuntimeError: dictionary changed size during iteration`. Loop over a copy instead: `for key in list(stock):`.

</Callout>

## Counting with a dictionary

Counting things is one of the most common jobs for a dict. Use each thing as a key and its count as the value. The trick is `.get(key, 0)`: it gives `0` the first time you see something.

<CodeExample output={`{'red': 3, 'blue': 2, 'green': 1}
red was voted 3 times`}>

```python
votes = ["red", "blue", "red", "green", "blue", "red"]
counts = {}

for colour in votes:
    counts[colour] = counts.get(colour, 0) + 1

print(counts)
print(f"red was voted {counts['red']} times")
```

</CodeExample>

<Callout type="note" title="Quotes inside f-strings">

`counts['red']` uses single quotes because the f-string itself uses double quotes. Mixing them stops Python getting confused about where the string ends.

</Callout>

## Nested dictionaries

Values can be dicts or lists themselves. That's how you model richer data, like a class of students. Chain the square brackets to dig in:

<CodeExample output={`12
[88, 94]
Mei: average 91.0
Sam: average 75.0`}>

```python
students = {
    "Mei": {"age": 12, "scores": [88, 94]},
    "Sam": {"age": 13, "scores": [70, 80]},
}
print(students["Mei"]["age"])
print(students["Mei"]["scores"])

for name, info in students.items():
    average = sum(info["scores"]) / len(info["scores"])
    print(f"{name}: average {average}")
```

</CodeExample>

## Dicts remember their order

Dicts keep pairs in the order you **inserted** them. Updating a value keeps its place; a new key goes at the end:

<CodeExample output={`{'b': 2, 'a': 10, 'c': 3}
{'a': 10, 'b': 2, 'c': 3}`}>

```python
d = {"b": 2, "a": 1}
d["c"] = 3
d["a"] = 10      # keeps its position
print(d)
print(dict(sorted(d.items())))   # a new dict sorted by key
```

</CodeExample>

    total = 0
    for item, quantity in basket.items():

    return total

## Recap

- A dict stores **key–value pairs**: `{"name": "Mei", "age": 12}`.
- `d[key]` reads a value (or raises `KeyError`); `d.get(key, default)` is the safe way.
- `d[key] = value` adds or updates; `del d[key]` and `d.pop(key)` remove.
- `key in d` checks keys; loop with `.keys()`, `.values()` and `.items()`.
- Count things with `counts[x] = counts.get(x, 0) + 1`.
- Dicts can nest, and they keep insertion order.
