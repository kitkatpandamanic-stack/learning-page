Список находит данные по **позиции**. **Словарь** (dictionary, или **dict**) находит их по **имени**. Он хранит **пары «ключ — значение»** (key–value pairs) — так же, как настоящий словарь хранит слово и его значение. Словари в Python повсюду: настройки, профили пользователей, данные в формате JSON, счётчики и многое другое.

## Создание словаря

Запишите пары в фигурных скобках, разделяя каждый **ключ** (key) и его **значение** (value) двоеточием:

<CodeExample output={`{'name': 'Mei', 'age': 12, 'city': 'Ташкент'}
3`}>

```python
student = {
    "name": "Mei",
    "age": 12,
    "city": "Ташкент",
}
print(student)
print(len(student))   # количество пар
```

</CodeExample>

- Ключи обычно бывают строками, но подойдут и числа, и кортежи.
- Значения могут быть любыми: числа, строки, списки и даже другие словари.
- Каждый ключ встречается **только один раз**. Пустой словарь — это просто `{}`.

## Чтение значений через [] и .get()

Укажите ключ в квадратных скобках, чтобы получить его значение:

<CodeExample output={`Mei
12`}>

```python
student = {"name": "Mei", "age": 12}
print(student["name"])
print(student["age"])
```

</CodeExample>

Если такого ключа нет, квадратные скобки остановят программу с ошибкой `KeyError`:

```python
print(student["email"])   # KeyError: 'email'
```

Когда ключа может не оказаться, используйте **`.get()`**. Этот метод вместо падения программы возвращает `None` или выбранное вами **значение по умолчанию** (default):

<CodeExample output={`None
нет почты
Mei`}>

```python
student = {"name": "Mei", "age": 12}
print(student.get("email"))
print(student.get("email", "нет почты"))
print(student.get("name", "неизвестно"))
```

</CodeExample>

## Добавление, изменение и удаление

Присваивание по ключу **добавляет** пару, если ключ новый, или **заменяет** значение, если ключ уже есть. Чтобы удалить пару, используйте `del` или `.pop()`:

<CodeExample output={`{'name': 'Mei', 'age': 13, 'email': 'mei@example.com'}
{'name': 'Mei', 'email': 'mei@example.com'}
mei@example.com
{'name': 'Mei'}`}>

```python
student = {"name": "Mei", "age": 12}

student["age"] = 13                   # изменить
student["email"] = "mei@example.com"  # добавить
print(student)

del student["age"]
print(student)

email = student.pop("email")  # удалить и вернуть значение
print(email)
print(student)
```

</CodeExample>

## Проверка ключа через in

`in` проверяет **ключи** словаря, а не значения:

<CodeExample output={`True
False
False`}>

```python
stock = {"apples": 5, "pears": 0}
print("apples" in stock)
print("bananas" in stock)
print(5 in stock)   # 5 — это значение, а не ключ
```

</CodeExample>

<Callout type="tip">

Поиск ключа в словаре работает **очень быстро**, даже если пар миллионы. А поиск по списку тем медленнее, чем длиннее список. Эта скорость — одна из главных причин популярности словарей.

</Callout>

## Перебор словаря в цикле

Обычный цикл `for` перебирает **ключи**. Используйте `.values()`, чтобы получить только значения, или **`.items()`**, чтобы получить и то и другое сразу (этот вариант вам понадобится чаще всего):

<CodeExample output={`apples
pears
5
2
apples: 5
pears: 2
Всего фруктов: 7`}>

```python
stock = {"apples": 5, "pears": 2}

for fruit in stock:          # то же самое, что stock.keys()
    print(fruit)

for amount in stock.values():
    print(amount)

for fruit, amount in stock.items():
    print(f"{fruit}: {amount}")

print(f"Всего фруктов: {sum(stock.values())}")
```

</CodeExample>

<Callout type="warning" title="Не меняйте размер во время цикла">

Если добавлять или удалять ключи, пока вы перебираете словарь, возникнет ошибка `RuntimeError: dictionary changed size during iteration`. Вместо этого перебирайте копию: `for key in list(stock):`.

</Callout>

## Подсчёт с помощью словаря

Подсчёт — одна из самых частых задач для словаря. Используйте каждую вещь как ключ, а её количество — как значение. Главный трюк — `.get(key, 0)`: он даёт `0`, когда вы встречаете что-то впервые.

<CodeExample output={`{'red': 3, 'blue': 2, 'green': 1}
Голосов за red: 3`}>

```python
votes = ["red", "blue", "red", "green", "blue", "red"]
counts = {}

for colour in votes:
    counts[colour] = counts.get(colour, 0) + 1

print(counts)
print(f"Голосов за red: {counts['red']}")
```

</CodeExample>

<Callout type="note" title="Кавычки внутри f-строк">

В `counts['red']` используются одинарные кавычки, потому что сама f-строка записана в двойных. Если не смешивать их так, Python может запутаться, где заканчивается строка.

</Callout>

## Вложенные словари

Значениями могут быть словари или списки. Так описывают более сложные данные, например класс учеников. Чтобы добраться до нужного значения, ставьте квадратные скобки цепочкой:

<CodeExample output={`12
[88, 94]
Mei: средний балл 91.0
Sam: средний балл 75.0`}>

```python
students = {
    "Mei": {"age": 12, "scores": [88, 94]},
    "Sam": {"age": 13, "scores": [70, 80]},
}
print(students["Mei"]["age"])
print(students["Mei"]["scores"])

for name, info in students.items():
    average = sum(info["scores"]) / len(info["scores"])
    print(f"{name}: средний балл {average}")
```

</CodeExample>

## Словари помнят порядок

Словари хранят пары в том порядке, в котором вы их **добавили**. Изменённое значение остаётся на своём месте, а новый ключ попадает в конец:

<CodeExample output={`{'b': 2, 'a': 10, 'c': 3}
{'a': 10, 'b': 2, 'c': 3}`}>

```python
d = {"b": 2, "a": 1}
d["c"] = 3
d["a"] = 10      # остаётся на своём месте
print(d)
print(dict(sorted(d.items())))   # новый словарь, отсортированный по ключам
```

</CodeExample>

prices = {"apple": 0.5, "bread": 1.2, "milk": 0.9}
basket = {"apple": 4, "milk": 2, "cake": 1}

def basket_total(basket, prices):
    total = 0
    for item, quantity in basket.items():
        total += quantity * prices.get(item, 0)
    return total

print(basket_total(basket, prices))

## Итоги

- Словарь хранит **пары «ключ — значение»**: `{"name": "Mei", "age": 12}`.
- `d[key]` читает значение (или выбрасывает `KeyError`); `d.get(key, default)` — безопасный способ.
- `d[key] = value` добавляет или изменяет пару; `del d[key]` и `d.pop(key)` удаляют.
- `key in d` проверяет ключи; перебирайте словарь через `.keys()`, `.values()` и `.items()`.
- Считайте с помощью `counts[x] = counts.get(x, 0) + 1`.
- Словари могут быть вложенными и сохраняют порядок добавления.
