Вы уже умеете создавать список (list), добавлять в него элементы через `.append()` и перебирать его в цикле. Но списки умеют гораздо больше. В этом уроке вы освоите инструменты, которыми Python-программисты пользуются **каждый день**.

## Индексы с обоих концов

Позиции элементов называются **индексами** (indexes) и начинаются с `0`. **Отрицательные индексы** считают с конца, поэтому `-1` — это всегда последний элемент:

<CodeExample output={`красный
синий
зелёный`}>

```python
colours = ["красный", "зелёный", "синий"]
print(colours[0])
print(colours[-1])
print(colours[-2])
```

</CodeExample>

В отличие от строк, списки **изменяемые** (mutable): элемент можно заменить прямо на месте, присвоив новое значение по его индексу.

<CodeExample output="['красный', 'золотой', 'синий']">

```python
colours = ["красный", "зелёный", "синий"]
colours[1] = "золотой"
print(colours)
```

</CodeExample>

<Callout type="warning" title="IndexError">

Если обратиться к несуществующей позиции, например `colours[3]` в списке из трёх элементов, программа остановится с ошибкой `IndexError: list index out of range`. Последний допустимый индекс — всегда `len(colours) - 1`.

</Callout>

## Срезы

Срезы (slices) работают точно так же, как у строк: `items[start:end]` берёт элементы от `start` до `end`, **не включая** `end`. Если пропустить число, это значит «с начала» или «до конца». Третье число — это **шаг** (step):

<CodeExample output={`[20, 30, 40]
[10, 20]
[40, 50, 60]
[10, 30, 50]
[60, 50, 40, 30, 20, 10]`}>

```python
numbers = [10, 20, 30, 40, 50, 60]
print(numbers[1:4])
print(numbers[:2])
print(numbers[-3:])
print(numbers[::2])
print(numbers[::-1])
```

</CodeExample>

Срез всегда возвращает **новый список** и никогда не меняет исходный. `numbers[::-1]` — удобный способ получить перевёрнутую копию.

## Добавление элементов

| Метод                  | Что делает                                        |
| ---------------------- | ------------------------------------------------- |
| `.append(x)`           | Добавляет `x` в конец                             |
| `.insert(i, x)`        | Вставляет `x` на позицию `i`, сдвигая остальные   |
| `.extend(other_list)`  | Добавляет в конец все элементы другого списка     |

<CodeExample output={`['Mei', 'Sam', 'Ali']
['Zoe', 'Mei', 'Sam', 'Ali']
['Zoe', 'Mei', 'Sam', 'Ali', 'Ben', 'Lia']`}>

```python
queue = ["Mei", "Sam"]
queue.append("Ali")
print(queue)

queue.insert(0, "Zoe")   # встать в начало очереди
print(queue)

queue.extend(["Ben", "Lia"])
print(queue)
```

</CodeExample>

<Callout type="note" title="append или extend">

`queue.append(["Ben", "Lia"])` добавил бы весь список **одним** элементом — получился бы список внутри списка. `extend` добавляет элементы по одному.

</Callout>

## Удаление и поиск элементов

- `.remove(x)` удаляет **первый** элемент, равный `x`.
- `.pop()` удаляет последний элемент и **возвращает** его; `.pop(i)` удаляет элемент на позиции `i`.
- `.index(x)` сообщает позицию первого `x`.
- `.count(x)` сообщает, сколько раз встречается `x`.

<CodeExample output={`['яйца', 'чай', 'молоко', 'хлеб']
хлеб
яйца
['чай', 'молоко']
1
1`}>

```python
shopping = ["яйца", "молоко", "чай", "молоко", "хлеб"]

shopping.remove("молоко")   # удаляется только первое "молоко"
print(shopping)

last = shopping.pop()
print(last)

first = shopping.pop(0)
print(first)
print(shopping)

print(shopping.index("молоко"))
print(shopping.count("чай"))
```

</CodeExample>

<Callout type="warning">

`.remove(x)` и `.index(x)` выбрасывают `ValueError`, если `x` нет в списке. Если не уверены, сначала проверьте: `if x in shopping:`.

</Callout>

## Сортировка: sort() или sorted()

Отсортировать список можно двумя способами, и разница между ними важна:

- `items.sort()` сортирует список **на месте** (то есть изменяет его) и возвращает `None`.
- `sorted(items)` не трогает исходный список и возвращает **новый** отсортированный список.

Оба принимают `reverse=True`, чтобы самые большие значения шли первыми. А `.reverse()` просто переворачивает список на месте, ничего не сортируя.

<CodeExample output={`[1, 3, 7, 9]
[7, 3, 9, 1]
[1, 9, 3, 7]
[9, 7, 3, 1]`}>

```python
scores = [7, 3, 9, 1]

print(sorted(scores))  # новый список
print(scores)          # не изменился

scores.reverse()       # просто перевёрнут, не отсортирован
print(scores)

scores.sort(reverse=True)
print(scores)          # отсортирован на месте
```

</CodeExample>

<Callout type="danger" title="Классическая ошибка">

`scores = scores.sort()` записывает в `scores` значение `None`, потому что `.sort()` ничего не возвращает. Либо вызовите `scores.sort()` отдельной строкой, либо напишите `scores = sorted(scores)`.

</Callout>

### Сортировка с key=

По умолчанию Python сравнивает сами элементы. Чтобы сортировать по какому-то другому признаку, передайте функцию **`key`**. Python вызовет её для каждого элемента и отсортирует по полученным результатам:

<CodeExample output={`['fig', 'kiwi', 'mango', 'banana']
['apple', 'Banana', 'cherry']
[('Sam', 19), ('Mei', 12), ('Ali', 15)]
[('Mei', 12), ('Ali', 15), ('Sam', 19)]`}>

```python
fruits = ["banana", "fig", "kiwi", "mango"]
print(sorted(fruits, key=len))

names = ["cherry", "Banana", "apple"]
print(sorted(names, key=str.lower))

people = [("Sam", 19), ("Mei", 12), ("Ali", 15)]
print(people)
print(sorted(people, key=lambda person: person[1]))
```

</CodeExample>

Обратите внимание: передаётся **сама** функция (`len`, а не `len()`). Для небольших ключей вроде «второй элемент» идеально подходит `lambda`.

<Callout type="tip">

Без `key=str.lower` заглавные буквы оказываются **перед** всеми строчными, поэтому `"Zebra"` встал бы раньше, чем `"apple"`.

</Callout>

## Вложенные списки

Список может содержать другие списки. Это простой способ хранить сетку или таблицу. Используйте два индекса: сначала строку, потом столбец.

<CodeExample output={`6
[7, 8, 9]
1 2 3
4 5 6
7 8 9`}>

```python
grid = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]
print(grid[1][2])   # строка 1, столбец 2
print(grid[-1])

for row in grid:
    print(row[0], row[1], row[2])
```

</CodeExample>

## Копия или второе имя

Поначалу это удивляет всех. `b = a` **не** копирует список. Эта строка даёт **тому же самому** списку второе имя — **псевдоним** (alias). Измените список через одно имя, и вы увидите изменение через другое:

<CodeExample output={`['Mei', 'Sam', 'Ali']
['Mei', 'Sam', 'Ali']
['Mei', 'Sam']`}>

```python
team = ["Mei", "Sam"]
same_team = team        # псевдоним, а не копия
same_team.append("Ali")
print(team)
print(same_team)

team = ["Mei", "Sam"]
copy = team.copy()      # настоящая копия
copy.append("Ali")
print(team)
```

</CodeExample>

Есть три распространённых способа сделать копию, и все они делают одно и то же:

```python
copy1 = team.copy()
copy2 = list(team)
copy3 = team[:]
```

<Callout type="note" title="Поверхностные копии">

Это **поверхностные** (shallow) копии: копия вложенного списка по-прежнему делит внутренние списки с оригиналом. Для полностью независимой копии вложенных данных используйте `copy.deepcopy()` из модуля `copy`.

</Callout>

## Проверка через in и распаковка

`in` проверяет, есть ли значение в списке (а `not in` — что его там нет). **Распаковка** (unpacking) раскладывает элементы списка по отдельным переменным за один шаг. Имя со `*` собирает «всё остальное»:

<CodeExample output={`True
True
Mei 12 Ташкент
1
[2, 3, 4]`}>

```python
pets = ["кошка", "собака", "панда"]
print("панда" in pets)
print("змея" not in pets)

name, age, city = ["Mei", 12, "Ташкент"]
print(name, age, city)

first, *rest = [1, 2, 3, 4]
print(first)
print(rest)
```

</CodeExample>

Количество имён должно совпадать с количеством элементов, если только вы не используете имя со `*`.

## Итоги

- Отрицательные индексы считают с конца; `items[-1]` — последний элемент.
- Срезы `items[start:end:step]` возвращают новый список; `items[::-1]` переворачивает его.
- `.append()`, `.insert()`, `.extend()` добавляют; `.remove()`, `.pop()` удаляют; `.index()` и `.count()` ищут.
- `.sort()` изменяет список и возвращает `None`; `sorted()` возвращает новый список. Оба принимают `key=` и `reverse=True`.
- `b = a` создаёт псевдоним; `a.copy()`, `list(a)` и `a[:]` создают копии.
- `x in items` проверяет наличие элемента, а `first, *rest = items` распаковывает список.
