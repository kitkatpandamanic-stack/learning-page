A **function** is a named, reusable block of code. You've been using one all along: `print`!

## Defining and calling

<CodeExample output={`Hello! 👋
Hello! 👋`}>

```python
def say_hello():
    print("Hello! 👋")

say_hello()
say_hello()
```

</CodeExample>

- `def say_hello():` **defines** the function. The indented block is its body. Nothing runs yet.
- `say_hello()` **calls** it. The brackets are what make it run.

## Parameters

**Parameters** are the inputs listed in the brackets. When you call the function, you pass **arguments** for them:

<CodeExample output={`Hello, Mei!
Hello, Sam!`}>

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Mei")
greet("Sam")
```

</CodeExample>

## return: giving a value back

Usually you want a result you can store and reuse. That's what `return` does:

<CodeExample output={`12
24`}>

```python
def area(width, height):
    return width * height

small = area(3, 4)
print(small)
print(area(4, 6))
```

</CodeExample>

<Callout type="note" title="return ends the function">

As soon as `return` runs, the function stops. A function without `return` gives back `None`.

</Callout>

<Callout type="tip">

Name functions with a **verb** in snake_case: `calculate_total`, `is_even`, `format_date`.

</Callout>

```python
    tip = total * tip_percent / 100
    return (total + tip) / people

print(split_bill(100, 4, 10))
```

## Recap

- `def name(params):` defines a function; `name(args)` calls it.
- Parameters are inputs; `return` sends a value back and ends the function.
- No `return` means the function returns `None`.
