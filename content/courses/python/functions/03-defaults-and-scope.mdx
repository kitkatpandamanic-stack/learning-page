Let's make functions more flexible, and understand an important idea: **scope**.

## Default values

Give a parameter a fallback value in case the caller leaves it out:

<CodeExample output={`Hello, friend!
Hello, Sam!`}>

```python
def greet(name="friend"):
    return f"Hello, {name}!"

print(greet())
print(greet("Sam"))
```

</CodeExample>

## Keyword arguments

You can pass arguments **by name**, in any order. It makes calls easier to read:

<CodeExample output="Panda is 5 years old.">

```python
def introduce(name, age):
    return f"{name} is {age} years old."

print(introduce(age=5, name="Panda"))
```

</CodeExample>

## Returning several values

Return several values separated by commas, and unpack them on the other side:

<CodeExample output="61 95">

```python
def lowest_and_highest(numbers):
    return min(numbers), max(numbers)

low, high = lowest_and_highest([72, 95, 88, 61])
print(low, high)
```

</CodeExample>

## Short functions with lambda

For tiny one-line functions, Python has `lambda`:

<CodeExample output="25">

```python
square = lambda n: n * n
print(square(5))
```

</CodeExample>

Use `def` for anything more than a quick expression; it's easier to read.

## Scope: where variables live

A variable created **inside** a function only exists inside it:

```python
def make_tea():
    water = "hot"
    print(water)   # works: we're inside the function

make_tea()
print(water)       # NameError: name 'water' is not defined
```

Code inside a function **can** read variables from outside:

<CodeExample output="Score: 10">

```python
label = "Score"

def show(points):
    print(f"{label}: {points}")

show(10)
```

</CodeExample>

<Callout type="tip" title="Why scope is good">

Scope stops different parts of a program from accidentally changing each other's variables. If a function needs to give something back, `return` it.

</Callout>

Write `is_even(n)` returning `True` or `False`, then `describe(n)` that **uses** `is_even` to return `"4 is even"` or `"7 is odd"`.

<Hint>

`n % 2 == 0` is already `True` or `False`. In `describe`, a conditional expression keeps it short: `"even" if is_even(n) else "odd"`.

</Hint>

<Solution>

```python
def is_even(n):
    return n % 2 == 0

def describe(n):
    kind = "even" if is_even(n) else "odd"
    return f"{n} is {kind}"

print(describe(4))
print(describe(7))
```

</Solution>

## Recap

- Default values: `def greet(name="friend"):`.
- Keyword arguments: `introduce(age=5, name="Panda")`.
- Return several values with commas and unpack them.
- Variables created inside a function stay inside it.
