Сделаем функции гибче и разберёмся с важной идеей — **областью видимости** (scope).

## Значения по умолчанию

Задайте **параметру** (parameter) запасное значение на случай, если при вызове его не передадут:

<CodeExample output={`Привет, друг!
Привет, Сэм!`}>

```python
def greet(name="друг"):
    return f"Привет, {name}!"

print(greet())
print(greet("Сэм"))
```

</CodeExample>

## Именованные аргументы

**Аргументы** (arguments) можно передавать **по имени** и в любом порядке. Так вызовы читаются легче — это именованные аргументы (keyword arguments):

<CodeExample output="Меня зовут Панда, мне 5 лет.">

```python
def introduce(name, age):
    return f"Меня зовут {name}, мне {age} лет."

print(introduce(age=5, name="Панда"))
```

</CodeExample>

## Возврат нескольких значений

Верните несколько значений через запятую, а на стороне вызова распакуйте их:

<CodeExample output="61 95">

```python
def lowest_and_highest(numbers):
    return min(numbers), max(numbers)

low, high = lowest_and_highest([72, 95, 88, 61])
print(low, high)
```

</CodeExample>

## Короткие функции с lambda

Для крошечных однострочных функций в Python есть `lambda`:

<CodeExample output="25">

```python
square = lambda n: n * n
print(square(5))
```

</CodeExample>

Для всего, что сложнее короткого выражения, используйте `def` — так код легче читать.

## Область видимости: где живут переменные

Переменная, созданная **внутри** функции, существует только внутри неё:

```python
def make_tea():
    water = "горячая"
    print(water)   # работает: мы внутри функции

make_tea()
print(water)       # NameError: name 'water' is not defined
```

Python сообщает, что имя `water` не определено: снаружи функции такой переменной нет.

Код внутри функции **может** читать переменные, созданные снаружи:

<CodeExample output="Очки: 10">

```python
label = "Очки"

def show(points):
    print(f"{label}: {points}")

show(10)
```

</CodeExample>

<Callout type="tip" title="Чем хороша область видимости">

Область видимости не даёт разным частям программы случайно менять переменные друг друга. Если функция должна что-то отдать наружу, верните это через `return`.

</Callout>

Напишите функцию `is_even(n)`, которая возвращает `True` или `False`, а затем функцию `describe(n)`, которая **использует** `is_even` и возвращает `"4 — чётное"` или `"7 — нечётное"`.

<Hint>

`n % 2 == 0` уже равно `True` или `False`. В `describe` код получится коротким с условным выражением: `"чётное" if is_even(n) else "нечётное"`.

</Hint>

<Solution>

```python
def is_even(n):
    return n % 2 == 0

def describe(n):
    kind = "чётное" if is_even(n) else "нечётное"
    return f"{n} — {kind}"

print(describe(4))
print(describe(7))
```

</Solution>

## Итоги

- Значения по умолчанию: `def greet(name="друг"):`.
- Именованные аргументы: `introduce(age=5, name="Панда")`.
- Несколько значений можно вернуть через запятую и распаковать.
- Переменные, созданные внутри функции, остаются внутри неё.
