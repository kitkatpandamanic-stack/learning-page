**Функция** (function) — это именованный блок кода, который можно использовать много раз. Одной функцией вы пользуетесь с самого начала: это `print`!

## Определение и вызов

<CodeExample output={`Привет! 👋
Привет! 👋`}>

```python
def say_hello():
    print("Привет! 👋")

say_hello()
say_hello()
```

</CodeExample>

- `def say_hello():` **определяет** функцию. Блок с отступом — её тело. Пока ничего не выполняется.
- `say_hello()` **вызывает** её. Именно скобки запускают функцию.

## Параметры

**Параметры** (parameters) — это входные данные, перечисленные в скобках. Когда вы вызываете функцию, вы передаёте для них **аргументы** (arguments):

<CodeExample output={`Привет, Мэй!
Привет, Сэм!`}>

```python
def greet(name):
    print(f"Привет, {name}!")

greet("Мэй")
greet("Сэм")
```

</CodeExample>

## return: возвращаем значение

Обычно нужен результат, который можно сохранить и использовать дальше. Для этого и нужен `return` — он отдаёт **возвращаемое значение** (return value):

<CodeExample output={`12
24`}>

```python
def area(width, height):
    return width * height

small = area(3, 4)
print(small)
print(area(4, 6))
```

</CodeExample>

<Callout type="note" title="return завершает функцию">

Как только выполняется `return`, функция останавливается. Функция без `return` возвращает `None`.

</Callout>

<Callout type="tip">

Называйте функции **глаголом** в стиле snake_case: `calculate_total`, `is_even`, `format_date`.

</Callout>

Допишите `split_bill(total, people, tip_percent)`, чтобы функция **возвращала**, сколько платит каждый человек с учётом чаевых. `split_bill(100, 4, 10)` должна вернуть `27.5`. (`pass` означает «ничего не делать»; замените его своим кодом.)

<Hint>

Чаевые — это `total * tip_percent / 100`. Прибавьте их к сумме, а затем разделите на `people`.

</Hint>

<Solution>

```python
def split_bill(total, people, tip_percent):
    tip = total * tip_percent / 100
    return (total + tip) / people

print(split_bill(100, 4, 10))
```

</Solution>

## Итоги

- `def name(params):` определяет функцию; `name(args)` вызывает её.
- Параметры — это входные данные; `return` возвращает значение и завершает функцию.
- Если `return` нет, функция возвращает `None`.
