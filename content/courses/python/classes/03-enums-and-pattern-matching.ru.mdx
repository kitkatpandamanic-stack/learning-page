Заказ может ожидать отправки, быть отправленным или доставленным. Можно хранить это строкой вроде `"shipped"`, но у строк есть проблема: Python не знает, какие из них допустимы, поэтому опечатка проходит незамеченной. В этом уроке вы исправите это с помощью **перечислений** (enums), а затем познакомитесь со всей силой **`match`/`case`**: эта конструкция умеет одновременно проверять *форму* данных и доставать из них значения. 🧩

## Магические строки и чем они вредны

**Магическая строка** (magic string) — это особое значение, которое работает, только если каждый раз и везде набрать его в точности правильно:

<CodeExample output={`True
False
False`}>

```python
def can_cancel(status):
    return status == "pending"

print(can_cancel("pending"))
print(can_cancel("Pending"))   # заглавная P
print(can_cancel("pendng"))    # опечатка
```

</CodeExample>

Ошибки нет, просто неверный ответ. Такой баг может прятаться неделями. А чтобы узнать, какие вообще бывают статусы, пришлось бы обыскать всю программу.

## Первое перечисление

**Перечисление** (enum, сокращение от *enumeration*) — это класс, который один раз перечисляет все допустимые значения. Каждое значение называется **членом** (member) перечисления:

<CodeExample output={`Status.SHIPPED
SHIPPED
2
<Status.SHIPPED: 2>
AttributeError: type object 'Status' has no attribute 'SHIPED'`}>

```python
from enum import Enum

class Status(Enum):
    PENDING = 1
    SHIPPED = 2
    DELIVERED = 3

order = Status.SHIPPED
print(order)
print(order.name)
print(order.value)
print(repr(order))

try:
    Status.SHIPED
except AttributeError as error:
    print(f"AttributeError: {error}")
```

</CodeExample>

- Унаследуйтесь от `Enum` и перечислите члены ЗАГЛАВНЫМИ буквами — это ведь константы.
- `.name` — имя члена в виде строки; `.value` — то значение, которое вы ему дали.
- Опечатка вроде `Status.SHIPED` теперь **сразу приводит к падению** с `AttributeError`, а не тихо даёт неверный ответ. К тому же редактор может сам подсказать варианты после `Status.`.

## auto(), перебор и поиск

Часто сами значения не важны — важно лишь, чтобы члены различались. `auto()` пронумерует их за вас. Класс перечисления можно перебирать в цикле, а члены можно искать по имени или по значению — это удобно, когда данные приходят из файла или JSON:

<CodeExample output={`PENDING 1
SHIPPED 2
DELIVERED 3
3
Status.SHIPPED
Status.DELIVERED
ValueError: 7 is not a valid Status`}>

```python
from enum import Enum, auto

class Status(Enum):
    PENDING = auto()
    SHIPPED = auto()
    DELIVERED = auto()

for status in Status:
    print(status.name, status.value)

print(len(Status))
print(Status["SHIPPED"])   # поиск по имени
print(Status(3))           # поиск по значению

try:
    Status(7)
except ValueError as error:
    print(f"ValueError: {error}")
```

</CodeExample>

Плохие данные не проскочат: `Status(7)` сразу выбрасывает `ValueError`.

## Сравнение членов

Каждый член существует ровно **в одном** экземпляре, поэтому сравнивать можно через `is` (так принято) или `==`. Перечисление — это класс, так что у него могут быть методы и свойства, а члены отлично подходят в качестве ключей словаря:

<CodeExample output={`True
True
False
False True
🚚`}>

```python
from enum import Enum, auto

class Status(Enum):
    PENDING = auto()
    SHIPPED = auto()
    DELIVERED = auto()

    @property
    def is_final(self):
        return self is Status.DELIVERED

order = Status.SHIPPED
print(order is Status.SHIPPED)
print(order == Status.SHIPPED)
print(order == 2)
print(order.is_final, Status.DELIVERED.is_final)

labels = {Status.PENDING: "📝", Status.SHIPPED: "🚚"}
print(labels[order])
```

</CodeExample>

Обратите внимание: `order == 2` даёт `False`. Член обычного перечисления **не равен** своему значению. Так задумано, чтобы перечисление никогда не путалось с обычными числами или строками.

### StrEnum и IntEnum

Иногда *нужно*, чтобы члены вели себя как строки или числа — например, чтобы отправить их в JSON или отсортировать. Для этого есть `StrEnum` и `IntEnum`:

<CodeExample output={`True
Размер: large
{"size": "small"}
True
[<Priority.LOW: 1>, <Priority.NORMAL: 2>, <Priority.URGENT: 3>]`}>

```python
from enum import StrEnum, IntEnum, auto
import json

class Size(StrEnum):
    SMALL = auto()     # значение "small"
    LARGE = auto()

class Priority(IntEnum):
    LOW = 1
    NORMAL = 2
    URGENT = 3

print(Size.SMALL == "small")
print(f"Размер: {Size.LARGE}")
print(json.dumps({"size": Size.SMALL}))
print(Priority.URGENT > Priority.LOW)
print(sorted([Priority.URGENT, Priority.LOW, Priority.NORMAL]))
```

</CodeExample>

В `StrEnum` функция `auto()` берёт в качестве значения имя члена в нижнем регистре. Начинайте с обычного `Enum`, а эти два используйте, только когда действительно нужно поведение строки или числа.

<Callout type="tip" title="Чем перечисления лучше магических строк">

- **Опечатки сразу приводят к падению**, а не прячутся.
- **Один список** всех допустимых значений в одном месте.
- **Автодополнение** в редакторе — и никаких догадок о написании или заглавных буквах.
- Варианты можно **перебрать** в цикле, например чтобы построить меню.

Как только заметите, что пишете одни и те же несколько особых строк во многих местах, — создайте перечисление.

</Callout>

## match с членами перечисления

Вы уже встречали `match` в уроке [Принимаем решения](/learn/python/if-elif-else) — с обычными строками, `|` и `case _`. С членами перечисления он работает так же хорошо:

<CodeExample output={`PENDING: Упаковать посылку
SHIPPED: Ждать курьера
DELIVERED: Делать ничего не нужно
CANCELLED: Делать ничего не нужно`}>

```python
from enum import Enum, auto

class Status(Enum):
    PENDING = auto()
    SHIPPED = auto()
    DELIVERED = auto()
    CANCELLED = auto()

def next_step(status):
    match status:
        case Status.PENDING:
            return "Упаковать посылку"
        case Status.SHIPPED:
            return "Ждать курьера"
        case Status.DELIVERED | Status.CANCELLED:
            return "Делать ничего не нужно"

for status in Status:
    print(f"{status.name}: {next_step(status)}")
```

</CodeExample>

### Осторожно: голое имя ловит всё

В `case` имя с точкой, например `Status.PENDING`, означает *«сравнить с этим значением»*. А **голое** имя вроде `PENDING` означает *«подходит что угодно, сохрани это в переменную PENDING»*:

<CodeExample output={`Упаковать
shipped`}>

```python
PENDING = "pending"
status = "shipped"

match status:
    case PENDING:        # это не сравнение!
        print("Упаковать")

print(PENDING)
```

</CodeExample>

Шаблон совпал с `"shipped"` и перезаписал `PENDING`. Если после него идут ещё варианты, Python вообще откажется запускать код с ошибкой `SyntaxError: name capture 'PENDING' makes remaining patterns unreachable`.

<Callout type="warning" title="Сравнивайте с именами через точку или литералами">

Чтобы сравнить со значением в `case`, используйте член перечисления (`Status.PENDING`) или литерал (`"pending"`), но никогда не простое имя переменной.

</Callout>

## Шаблоны последовательностей: сопоставляем списки

`match` умеет гораздо больше, чем сравнивать значения. Каждый `case` — это **шаблон** (pattern): описание того, как данные должны *выглядеть*. Если данные подходят, Python может ещё и разложить их части по переменным.

Если разбить команду на слова, получится список, а **шаблон последовательности** (sequence pattern) проверяет, сколько в нём элементов и какие они. Имена внутри шаблона **захватывают** (capture) значения:

<CodeExample output={`Вы видите тихую библиотеку.
Вы идёте: north.
Вы берёте: map, lamp, key.
Скажите что-нибудь!
Пока!
Не понимаю.`}>

```python
def handle(command):
    match command.split():
        case []:
            return "Скажите что-нибудь!"
        case ["look"]:
            return "Вы видите тихую библиотеку."
        case ["go", direction]:
            return f"Вы идёте: {direction}."
        case ["take", *things]:
            return f"Вы берёте: {', '.join(things)}."
        case ["quit" | "exit"]:
            return "Пока!"
        case _:
            return "Не понимаю."

for command in ["look", "go north", "take map lamp key",
                "", "exit", "dance wildly"]:
    print(handle(command))
```

</CodeExample>

- `["look"]` подходит к списку ровно из одного элемента — `"look"`.
- `["go", direction]` подходит к списку ровно из двух элементов, где первый — `"go"`, и **захватывает** второй в `direction`.
- `*things` захватывает **все оставшиеся** элементы в список, поэтому `["take", *things]` подходит и для одного предмета, и для двух, и для десяти.
- `"quit" | "exit"` внутри списка означает «любое из этих слов».
- `case _` — это **подстановочный шаблон** (wildcard): он подходит ко всему и ничего не захватывает. Варианты проверяются сверху вниз, поэтому он идёт последним.

Сравните это с ручным разбиением, проверкой `len(words)` и обращением к `words[1]`: шаблоны *показывают*, как выглядит каждая команда.

### Охранные условия: дополнительные проверки через if

Шаблон проверяет форму, а **охранное условие** (guard) добавляет любое условие, какое захотите. Вариант срабатывает, только если подходит шаблон **и** условие истинно:

<CodeExample output={`Вы идёте: north.
Туда не пройти: up.
Куда идти?`}>

```python
EXITS = ["north", "south"]

def handle(command):
    match command.split():
        case ["go", direction] if direction in EXITS:
            return f"Вы идёте: {direction}."
        case ["go", direction]:
            return f"Туда не пройти: {direction}."
        case ["go"]:
            return "Куда идти?"
        case _:
            return "Не понимаю."

print(handle("go north"))
print(handle("go up"))
print(handle("go"))
```

</CodeExample>

Если условие не выполнено, Python просто переходит к следующему варианту.

## Шаблоны отображений: сопоставляем словари

Данные из веб-API и JSON-файлов обычно приходят в виде словарей. **Шаблон отображения** (mapping pattern) проверяет наличие ключей и захватывает их значения. Это одно из лучших применений `match`:

<CodeExample output={`Заказ 7: товаров — 2
Возврат 4.5 по заказу 7
Возврат 250 требует одобрения менеджера
Пропускаем событие ping
Это не событие: {'kind': 'mystery'}`}>

```python
events = [
    {"type": "order", "id": 7, "items": ["tea", "cake"]},
    {"type": "refund", "id": 7, "amount": 4.5, "reason": "cold"},
    {"type": "refund", "id": 8, "amount": 250},
    {"type": "ping"},
    {"kind": "mystery"},
]

for event in events:
    match event:
        case {"type": "order", "id": order_id, "items": items}:
            print(f"Заказ {order_id}: товаров — {len(items)}")
        case {"type": "refund", "amount": amount} if amount > 100:
            print(f"Возврат {amount} требует одобрения менеджера")
        case {"type": "refund", "id": order_id, "amount": amount}:
            print(f"Возврат {amount} по заказу {order_id}")
        case {"type": other}:
            print(f"Пропускаем событие {other}")
        case _:
            print(f"Это не событие: {event}")
```

</CodeExample>

- В шаблоне перечислены только нужные вам ключи. **Лишние ключи игнорируются** (у первого возврата есть ещё `"reason"`).
- Если ключа из шаблона **нет**, этот вариант просто не срабатывает, так что о `KeyError` можно не беспокоиться.
- Литеральные значения вроде `"order"` должны совпадать, а имена вроде `amount` захватывают то, что там лежит.

## Шаблоны классов: сопоставляем объекты

**Шаблон класса** (class pattern) проверяет, является ли что-то экземпляром класса (как `isinstance`), и может захватывать его атрибуты. Он отлично подходит для датаклассов из урока [Наследование](/learn/python/inheritance):

<CodeExample output={`Dune: книга
It: долгое чтение
Up: DVD на 96 минут
Что-то другое
('title', 'minutes')`}>

```python
from dataclasses import dataclass

@dataclass
class Book:
    title: str
    pages: int

@dataclass
class DVD:
    title: str
    minutes: int

def describe(item):
    match item:
        case Book(title=title, pages=pages) if pages > 500:
            return f"{title}: долгое чтение"
        case Book(title=title):
            return f"{title}: книга"
        case DVD(title, minutes):
            return f"{title}: DVD на {minutes} минут"
        case _:
            return "Что-то другое"

items = [Book("Dune", 412), Book("It", 1138), DVD("Up", 96), 42]
for item in items:
    print(describe(item))
print(DVD.__match_args__)
```

</CodeExample>

- `Book(title=title)` означает *«объект Book; захвати его атрибут `title`»*. Такие **именованные шаблоны** (keyword patterns) работают с любым классом.
- `DVD(title, minutes)` использует **позиции**. Это работает, потому что `@dataclass` сам создаёт `__match_args__` — порядок атрибутов, как видно в последней строке.
- Всегда пишите скобки: `case Book():` означает *«любой Book»*, а `case Book:` — это голое имя, которое ловит всё!

Для обычного класса используйте именованные шаблоны или задайте `__match_args__` сами:

<CodeExample output={`начало координат
на оси y в точке 5
на оси x в точке 3
где-то в другом месте`}>

```python
class Point:
    __match_args__ = ("x", "y")

    def __init__(self, x, y):
        self.x = x
        self.y = y

def where(point):
    match point:
        case Point(0, 0):
            return "начало координат"
        case Point(0, y):
            return f"на оси y в точке {y}"
        case Point(x=x, y=0):
            return f"на оси x в точке {x}"
        case Point():
            return "где-то в другом месте"

for p in [Point(0, 0), Point(0, 5), Point(3, 0), Point(2, 2)]:
    print(where(p))
```

</CodeExample>

## Когда использовать match (и когда нет)

`match` раскрывается, когда вы спрашиваете **«какой формы эти данные?»**: команды, разбитые на слова, словари в духе JSON, объекты разных видов или фиксированный набор членов перечисления. Один `case` проверяет форму *и* распаковывает значения — а через `if`, `len()` и индексы на это ушло бы несколько строк.

Но он **не** лучше во всём:

- **Диапазоны и сравнения** естественнее читаются через `if`/`elif`: `if score >= 90:` лучше, чем `case s if s >= 90:`.
- **Простое сопоставление «значение → значение»** часто — это просто словарь: `emoji = {"tea": "🍵", "cake": "🍰"}[food]`.
- Когда условий всего одно-два, обычный `if` короче и так же понятен.

<Callout type="note" title="Python 3.10 и новее">

`match`/`case` появились в Python 3.10 (2021). На PandaDev у вас Python 3.14, но если на другом компьютере увидите `SyntaxError` на строке с `match`, проверьте версию Python.

</Callout>

| Команда | Что происходит | Возвращает |
| --- | --- | --- |
| `insert 50` | Сумма добавляется к `credit`, состояние становится `HAS_CREDIT` | `"Баланс: 50"` |
| `insert` + что угодно, кроме целого числа больше 0 | Ничего не меняется | `"Неверная монета"` |
| `buy pizza` (нет в `PRICES`) | Ничего не меняется | `"Неизвестный товар: pizza"` |
| `buy crisps` (денег не хватает) | Ничего не меняется | `"Не хватает: 30"` |
| `buy crisps` (денег хватает) | Баланс снова 0, состояние становится `IDLE` | `"Приятного аппетита: crisps! Сдача: 20"` |
| `refund` в состоянии `IDLE` | Ничего не меняется | `"Нечего возвращать"` |
| `refund` в остальных случаях | Баланс снова 0, состояние становится `IDLE` | `"Возвращено: 30"` |
| `service` в состоянии `IDLE` | Состояние становится `MAINTENANCE` | `"Режим обслуживания"` |
| `service` в состоянии `MAINTENANCE` | Состояние становится `IDLE` | `"Готов к работе"` |
| `service` в состоянии `HAS_CREDIT` | Ничего не меняется | `"Сначала заберите деньги"` |
| что угодно другое | Ничего не меняется | `"Неизвестная команда"` |

В состоянии `MAINTENANCE` каждая команда, кроме `service`, возвращает `"Не работает"`.

<Hint>

Сначала проверьте режим обслуживания: `if self.state is State.MAINTENANCE and words != ["service"]: return "Не работает"`. Затем используйте шаблоны последовательностей с охранными условиями — от самых точных к самым общим: `case ["insert", amount] if amount.isdigit() and int(amount) > 0:` перед `case ["insert", _]:`, и `case ["buy", snack] if snack not in PRICES:` перед `case ["buy", snack]:`. Для `service` хорошо подойдёт второй `match self.state:` с `case State.IDLE:` и остальными состояниями. Закончите вариантом `case _:`.

</Hint>

<Solution>

```python
from enum import Enum, auto

PRICES = {"crisps": 80, "water": 100, "chocolate": 120}


class State(Enum):
    IDLE = auto()
    HAS_CREDIT = auto()
    MAINTENANCE = auto()


class VendingMachine:
    def __init__(self):
        self.credit = 0
        self.state = State.IDLE

    def handle(self, command):
        words = command.lower().split()
        if self.state is State.MAINTENANCE and words != ["service"]:
            return "Не работает"

        match words:
            case ["insert", amount] if amount.isdigit() and int(amount) > 0:
                self.credit += int(amount)
                self.state = State.HAS_CREDIT
                return f"Баланс: {self.credit}"
            case ["insert", _]:
                return "Неверная монета"
            case ["buy", snack] if snack not in PRICES:
                return f"Неизвестный товар: {snack}"
            case ["buy", snack]:
                price = PRICES[snack]
                if self.credit < price:
                    return f"Не хватает: {price - self.credit}"
                change = self.credit - price
                self.credit = 0
                self.state = State.IDLE
                return f"Приятного аппетита: {snack}! Сдача: {change}"
            case ["refund"]:
                if self.state is State.IDLE:
                    return "Нечего возвращать"
                refund = self.credit
                self.credit = 0
                self.state = State.IDLE
                return f"Возвращено: {refund}"
            case ["service"]:
                match self.state:
                    case State.IDLE:
                        self.state = State.MAINTENANCE
                        return "Режим обслуживания"
                    case State.MAINTENANCE:
                        self.state = State.IDLE
                        return "Готов к работе"
                    case State.HAS_CREDIT:
                        return "Сначала заберите деньги"
            case _:
                return "Неизвестная команда"


machine = VendingMachine()
for command in ["insert 50", "buy water", "insert 50",
                "buy water", "buy pizza", "refund"]:
    print(f"{command} -> {machine.handle(command)}")
```

</Solution>

## Итоги

- **Перечисление** (enum) один раз перечисляет все допустимые значения: `class Status(Enum): PENDING = auto()`. Опечатки приводят к падению, а не прячутся.
- У членов есть `.name` и `.value`; перебирайте их через `for s in Status`, ищите через `Status["PENDING"]` или `Status(1)`.
- Сравнивайте члены через `is`; член обычного `Enum` никогда не равен своему значению. `StrEnum` и `IntEnum` ведут себя как строки и числа.
- Шаблоны `match`/`case`: литералы и `|`, захват (`direction`), подстановочный шаблон `_` и охранные условия (`if ...`).
- Шаблоны **последовательностей** (`["go", direction]`, `*rest`), **отображений** (`{"type": "order", "id": order_id}`) и **классов** (`Book(title=title)` или позиционные с `__match_args__`).
- В вариантах используйте имена с точкой вроде `Status.PENDING`: голое имя ловит всё.
- Используйте `match` для *формы* данных, а для диапазонов и простых условий оставайтесь с `if`/`elif`.
