Строковые методы вроде `find()`, `split()` и `startswith()` отлично работают, когда вы знаете **точный** текст, который ищете. А если нужен «любой номер телефона», «каждая дата» или «слово с заглавной буквы»? Тогда нужно описать **шаблон** (pattern). Именно этим занимаются **регулярные выражения** (regular expressions, сокращённо regex), и встроенный модуль Python `re` прекрасно их понимает. 🔍

## Зачем нужны регулярные выражения?

Допустим, вам нужны все числа из сообщения. Со строковыми методами пришлось бы разбить текст, убрать знаки препинания и проверить `isdigit()` для каждого кусочка. С регулярным выражением это одна строка:

<CodeExample output={`['3', '12', '2026']
['mei@example.com', 'sam@panda.dev']`}>

```python
import re

text = "Order 3 bamboo sticks for 12 pandas by 2026!"
print(re.findall(r"\d+", text))

contacts = "Email mei@example.com or sam@panda.dev today"
print(re.findall(r"\S+@\S+", contacts))
```

</CodeExample>

`\d+` означает «одна или больше цифр», а `\S+@\S+` — «несколько непробельных символов, затем `@`, затем ещё непробельные символы». `re.findall(pattern, text)` возвращает **все** совпавшие куски текста в виде списка строк.

<Callout type="tip" title="Сначала строки, потом regex">

Если задачу решает строковый метод (`"@" in email`, `line.startswith("ERROR")`), используйте его: такой код быстрее читается. Берите регулярные выражения, когда у нужного текста есть **форма**, а не точное значение.

</Callout>

## Сырые строки: r"..."

В обычных строках обратная косая черта начинает экранирование: `"\n"` — это перевод строки. В регулярных выражениях обратные косые черты повсюду (`\d`, `\s`, `\b`), поэтому шаблоны записывают **сырыми строками** (raw strings) с буквой `r` в начале. В сырой строке обратная косая черта — это просто обратная косая черта:

<CodeExample output={`1
2
\\n`}>

```python
print(len("\n"))    # один символ: перевод строки
print(len(r"\n"))   # два символа: \ и n
print(r"\n")
```

</CodeExample>

Без `r` одни шаблоны тихо ломаются (`"\b"` — это символ backspace, а не граница слова), а на другие Python выводит `SyntaxWarning`. **Всегда записывайте шаблоны регулярных выражений сырыми строками.**

## search, match и fullmatch

Эти три функции ищут **одно** совпадение и возвращают **объект совпадения** (match object) или `None`, если совпадения нет:

- **`re.search(pattern, text)`** находит первое совпадение **в любом месте** текста.
- **`re.match(pattern, text)`** ищет совпадение только в **начале** текста.
- **`re.fullmatch(pattern, text)`** срабатывает, только если шаблону соответствует **весь** текст.

<CodeExample output={`Найдено 42 на позиции 7
None
<re.Match object; span=(0, 4), match='2026'>
None
True`}>

```python
import re

m = re.search(r"\d+", "Panda #42 is hungry")
print(f"Найдено {m.group()} на позиции {m.start()}")

print(re.match(r"\d+", "Room 101"))
print(re.match(r"\d+", "2026 was fun"))
print(re.fullmatch(r"\d+", "2026 was fun"))
print(re.fullmatch(r"\d+", "2026") is not None)
```

</CodeExample>

- `m.group()` — совпавший текст, а `m.start()` / `m.end()` говорят, где он находится.
- Поскольку «нет совпадения» даёт `None`, всегда проверяйте результат перед использованием: `if m:`. Вызов `.group()` у `None` выбросит `AttributeError`.

## Классы символов

**Класс символов** (character class) совпадает с одним символом из набора. Вот те, что нужны чаще всего:

| Шаблон | Совпадает с одним… |
| --- | --- |
| `\d` | цифрой от `0` до `9` |
| `\w` | символом «слова»: буквой, цифрой или `_` |
| `\s` | пробельным символом: пробелом, табуляцией, переводом строки |
| `\D`, `\W`, `\S` | любым символом, **кроме** цифры, символа слова, пробельного символа |
| `.` | любым символом, кроме перевода строки |
| `[aeiou]` | одним из перечисленных символов |
| `[a-z]`, `[A-Z0-9]` | одним символом из диапазона |
| `[^0-9]` | любым символом, которого **нет** в списке (`^` в начале `[...]`) |

Чтобы найти специальный символ буквально, поставьте перед ним обратную косую черту: `\.` — настоящая точка, `\$` — знак доллара, `\(` — скобка.

<CodeExample output={`['e', 'i', 'o', 'e', 'a', 'o', 'o']
['A1', 'B2']
['3.50', '12.00']`}>

```python
import re

print(re.findall(r"[aeiou]", "Mei loves bamboo"))
print(re.findall(r"[A-Z]\d", "Seats A1, B2 and c3"))
print(re.findall(r"\d+\.\d\d", "Tea 3.50, cake 12.00, 7 forks"))
```

</CodeExample>

## Квантификаторы: сколько раз?

**Квантификатор** (quantifier) после символа (или класса) говорит, сколько раз он повторяется:

| Квантификатор | Значит |
| --- | --- |
| `*` | 0 или больше |
| `+` | 1 или больше |
| `?` | 0 или 1 (необязательно) |
| `{3}` | ровно 3 |
| `{2,4}` | от 2 до 4 |
| `{2,}` | 2 или больше |

<CodeExample output={`['colour', 'color']
['07700 900123']
['hmm', 'hmmmm']`}>

```python
import re

print(re.findall(r"colou?r", "colour or color?"))
print(re.findall(r"\d{5} \d{6}", "Call 07700 900123 or 123"))
print(re.findall(r"hm+", "hmm... hmmmm. h"))
```

</CodeExample>

### Жадные и ленивые

Квантификаторы **жадные** (greedy): они захватывают как можно больше текста. Если добавить после них `?`, они станут **ленивыми** (lazy) и возьмут как можно меньше:

<CodeExample output={`['<b>bold</b> and <i>italic</i>']
['<b>', '</b>', '<i>', '</i>']`}>

```python
import re

html = "<b>bold</b> and <i>italic</i>"
print(re.findall(r"<.+>", html))    # жадный: одно огромное совпадение
print(re.findall(r"<.+?>", html))   # ленивый: каждый тег отдельно
```

</CodeExample>

Жадный `.+` дошёл до самой **последней** `>`. Если совпадение неожиданно длинное, обычно дело в пропущенном `?`. (Здесь ещё понятнее вариант `<[^>]+>`: «`<`, потом что угодно, кроме `>`, потом `>`».)

## Якоря: где находится совпадение

**Якоря** (anchors) совпадают не с символами, а с **позициями**:

- `^` — начало текста, а `$` — конец.
- `\b` — **граница слова** (word boundary): место между символом слова и чем-то другим.

<CodeExample output={`['cat']
['cat', 'cat', 'cat']
True
False`}>

```python
import re

text = "cat, category, concat"
print(re.findall(r"\bcat\b", text))   # только слово "cat"
print(re.findall(r"cat", text))       # cat где угодно

print(bool(re.search(r"^Hello", "Hello there")))
print(bool(re.search(r"^Hello", "Oh, Hello")))
```

</CodeExample>

## Группы: достаём части

Скобки `( )` создают **группу** (group). Совпасть по-прежнему должен весь шаблон, но часть каждой группы можно прочитать отдельно. Так вы переходите от *поиска* текста к *извлечению* данных:

<CodeExample output={`2026-10-04
2026 10 04
('2026', '10', '04')
[('Mei', '92'), ('Sam', '78')]`}>

```python
import re

m = re.search(r"(\d{4})-(\d\d)-(\d\d)", "Due: 2026-10-04!")
print(m.group())       # всё совпадение (то же, что m.group(0))
print(m.group(1), m.group(2), m.group(3))
print(m.groups())

scores = "Mei=92, Sam=78"
print(re.findall(r"(\w+)=(\d+)", scores))
```

</CodeExample>

Если в шаблоне есть группы, `findall` возвращает **группы** каждого совпадения: список кортежей, который удобно перебирать в цикле.

Внутри группы `|` означает «или»: `(cat|dog)s?` совпадает с `cat`, `dogs` и так далее. А ещё группы позволяют повторить квантификатором несколько символов: `(ha)+` совпадает с `hahaha`.

### Именованные группы

Номера вроде `group(3)` легко перепутать. **Именованная группа** (named group) `(?P<name>...)` даёт каждой части имя, а `groupdict()` превращает совпадение в словарь:

<CodeExample output={`Sam
{'user': 'Sam', 'action': 'login', 'hour': '09'}`}>

```python
import re

pattern = r"(?P<user>\w+) did (?P<action>\w+) at (?P<hour>\d\d):\d\d"
m = re.search(pattern, "Sam did login at 09:15")

print(m.group("user"))
print(m.groupdict())
```

</CodeExample>

Помните, что группы всегда дают **строки**: если нужны числа, преобразуйте их через `int()`.

## finditer, sub и split

**`re.finditer()`** похожа на `findall`, но для каждого совпадения даёт полноценный объект совпадения, так что можно пользоваться именованными группами и позициями:

<CodeExample output={`Mei набирает 92
Sam набирает 78`}>

```python
import re

scores = "Mei=92, Sam=78"
for m in re.finditer(r"(?P<name>\w+)=(?P<score>\d+)", scores):
    print(m["name"], "набирает", int(m["score"]))
```

</CodeExample>

(`m["name"]` — короткая запись для `m.group("name")`.)

**`re.sub(pattern, replacement, text)`** заменяет каждое совпадение. В строке замены `\1` (или `\g<name>`) подставляет текст группы. **`re.split(pattern, text)`** разбивает текст везде, где совпадает шаблон, — это удобно, когда разделители неаккуратные:

<CodeExample output={`Too many spaces here
04/10/2026
['milk', 'eggs', 'bamboo', 'tea']`}>

```python
import re

print(re.sub(r"\s+", " ", "Too   many \t spaces   here"))
print(re.sub(r"(\d{4})-(\d\d)-(\d\d)", r"\3/\2/\1", "2026-10-04"))
print(re.split(r"\s*[,;]\s*", "milk, eggs;bamboo ,  tea"))
```

</CodeExample>

## Флаги

**Флаги** (flags) меняют поведение шаблона. Передавайте их последним аргументом:

- **`re.IGNORECASE`** (или `re.I`): заглавные и строчные буквы считаются одинаковыми.
- **`re.MULTILINE`** (или `re.M`): `^` и `$` совпадают с началом и концом **каждой строки**, а не только всего текста.
- **`re.VERBOSE`** (или `re.X`): пробелы и переводы строк в шаблоне игнорируются, а `#` начинает комментарий, так что длинные шаблоны можно аккуратно разложить.

<CodeExample output={`['Panda', 'PANDA', 'panda']
['ERROR disk full', 'ERROR no bamboo']
('2026', '10', '04')`}>

```python
import re

print(re.findall(r"panda", "Panda PANDA panda", re.IGNORECASE))

log = "INFO start\nERROR disk full\nINFO ok\nERROR no bamboo"
print(re.findall(r"^ERROR.*$", log, re.MULTILINE))

date = re.compile(r"""
    (\d{4})   # год
    -(\d\d)   # месяц
    -(\d\d)   # день
""", re.VERBOSE)
print(date.search("Due 2026-10-04").groups())
```

</CodeExample>

Флаги объединяются через `|`, например `re.IGNORECASE | re.MULTILINE`.

## Компиляция шаблонов

**`re.compile(pattern)`** превращает шаблон в переиспользуемый **объект шаблона** (pattern object) с теми же методами: `.search()`, `.findall()`, `.sub()` и другими. Если дать шаблону хорошее имя, код читается гораздо легче, а использовать шаблон можно снова и снова:

<CodeExample output={`['#python', '#regex']
['#bamboo']`}>

```python
import re

HASHTAG = re.compile(r"#\w+")

posts = ["Learning #python and #regex", "Lunch: #bamboo"]
for post in posts:
    print(HASHTAG.findall(post))
```

</CodeExample>

(Python и так кэширует шаблоны, которые вы передаёте в `re.search` и другие функции, поэтому компиляция нужна в основном ради **читаемости**.)

## Проверка или извлечение

У регулярных выражений две большие задачи, и для них нужны разные функции:

- **Проверка** (validation): «Является ли вся эта строка правильным кодом / именем пользователя / почтовым индексом?» Используйте **`fullmatch`**, чтобы ни с одного конца не проскочило ничего лишнего.
- **Извлечение** (extraction): «Найди в этом тексте нужные мне кусочки». Используйте **`search`**, **`findall`** или **`finditer`** с группами.

<CodeExample output={`True
False
True`}>

```python
import re

def is_valid_pin(text):
    return re.fullmatch(r"\d{4}", text) is not None

print(is_valid_pin("2580"))
print(is_valid_pin("25801"))           # слишком длинный
print(re.search(r"\d{4}", "25801") is not None)  # а search говорит «да»!
```

</CodeExample>

`search` спокойно нашла четыре цифры **внутри** `"25801"` — вот почему для проверки нужна `fullmatch` (или `^...$`).

<Callout type="warning" title="Знайте, когда остановиться">

Регулярные выражения прекрасно подходят для небольших однородных форм: дат, кодов, строк логов. Но это **неподходящий инструмент** для вложенных форматов вроде **HTML** или **JSON** (используйте парсер: `html.parser`, BeautifulSoup или модуль `json`), а полные правила для **адресов электронной почты** печально известны своим объёмом. Для почты простая проверка вроде `\S+@\S+\.\S+` плюс письмо с подтверждением лучше, чем шаблон на 500 символов, который никто не может прочитать.

</Callout>

## Тестируем шаблоны

Шаблон легко написать *почти* правильно. Прежде чем ему доверять, проверьте его на нескольких строках, которые **должны** совпасть, и нескольких, которые **не должны**, включая хитрые пограничные случаи:

<CodeExample output="Все тесты шаблона пройдены">

```python
import re

TIME = re.compile(r"([01]\d|2[0-3]):[0-5]\d")

good = ["00:00", "09:30", "23:59"]
bad = ["24:00", "9:30", "12:60", "12:30pm"]

for text in good:
    assert TIME.fullmatch(text), f"должно совпасть: {text}"
for text in bad:
    assert not TIME.fullmatch(text), f"не должно совпасть: {text}"
print("Все тесты шаблона пройдены")
```

</CodeExample>

Сайты вроде **regex101.com** (выберите вариант Python) показывают, что делает каждая часть шаблона, и подсвечивают совпадения прямо во время ввода. Они отлично подходят, чтобы собирать шаблон шаг за шагом.

Для заказа используйте именованные группы вроде `(?P<id>\d+)`, `(?P<item>.+)` и `(?P<price>\d+\.\d+)`, а затем преобразуйте их через `int()` и `float()`. `tidy` — это `re.sub(r"\s+", " ", text).strip()`.

import re

USERNAME = re.compile(r"[A-Za-z]\w{2,15}")
HASHTAG = re.compile(r"#(\w+)")
ORDER = re.compile(
    r"Order #(?P<id>\d+): (?P<qty>\d+) x (?P<item>.+) at (?P<price>\d+\.\d+)"
)

def is_valid_username(name):
    return USERNAME.fullmatch(name) is not None

def find_hashtags(text):
    return [tag.lower() for tag in HASHTAG.findall(text)]

def parse_order(line):
    m = ORDER.fullmatch(line)
    if not m:
        return None
    return {
        "id": int(m["id"]),
        "qty": int(m["qty"]),
        "item": m["item"],
        "price": float(m["price"]),
    }

def tidy(text):
    return re.sub(r"\s+", " ", text).strip()

print(is_valid_username("mei_2026"))

## Итоги

- **Регулярное выражение** описывает **шаблон** текста. Используйте их, когда строковыми методами нужное не описать.
- Записывайте шаблоны **сырыми строками**: `r"\d+"`.
- `search` находит первое совпадение где угодно, `match` — только в начале, `fullmatch` — только всю строку целиком. Если совпадения нет, получаете `None`.
- `findall` возвращает все совпадения (или их группы), `finditer` даёт объекты совпадений, `sub` заменяет, а `split` разбивает.
- Строительные блоки: классы (`\d`, `\w`, `\s`, `[a-z]`), квантификаторы (`*`, `+`, `?`, `{2,4}`, ленивый `+?`), якоря (`^`, `$`, `\b`).
- **Группы** `( )` и **именованные группы** `(?P<name>...)` извлекают части; `groupdict()` даёт словарь строк.
- Флаги: `re.IGNORECASE`, `re.MULTILINE`, `re.VERBOSE`. `re.compile` даёт шаблону имя.
- Проверяйте через `fullmatch`, извлекайте через `search`/`findall`/`finditer`, тестируйте шаблоны на хороших и плохих примерах и не разбирайте HTML регулярными выражениями.
