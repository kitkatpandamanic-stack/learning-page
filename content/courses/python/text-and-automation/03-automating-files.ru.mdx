## Пути и pathlib

Объект **`Path`** представляет место в файловой системе. Вместо того чтобы склеивать строки через `"/"`, вы соединяете пути **оператором `/`**, а Python сам подставляет правильный разделитель для вашей операционной системы (`\` в Windows, `/` в остальных):

<CodeExample output={`reports/2026/october.csv
october.csv
october
.csv
reports/2026
reports/2026/october.json
reports/2026/november.csv`}>

```python
from pathlib import Path

report = Path("reports") / "2026" / "october.csv"

print(report)
print(report.name)     # имя файла
print(report.stem)     # имя без расширения
print(report.suffix)   # расширение вместе с точкой
print(report.parent)   # папка, в которой лежит файл
print(report.with_suffix(".json"))
print(report.with_name("november.csv"))
```

</CodeExample>

Ничто из этого не трогает диск: `Path` — просто имя, пока вы не начнёте читать, записывать или проверять файл. `Path.cwd()` — папка, в которой запущен скрипт, а `Path.home()` — ваша домашняя папка.

## Создаём папки и проверяем, что существует

**`mkdir()`** создаёт папку. Два аргумента делают её безопасной для использования в скриптах:

- **`parents=True`** создаёт и все недостающие папки выше.
- **`exist_ok=True`** не ругается, если папка уже есть.

<CodeExample output={`True True
False
True False
Привет!`}>

```python
import shutil
from pathlib import Path

base = Path("demo-project")
shutil.rmtree(base, ignore_errors=True)

notes = base / "docs" / "notes"
notes.mkdir(parents=True, exist_ok=True)
print(base.exists(), notes.is_dir())

readme = base / "README.md"
print(readme.exists())
readme.write_text("Привет!\n")
print(readme.is_file(), readme.is_dir())
print(readme.read_text().strip())
```

</CodeExample>

## Заглядываем в папки: iterdir, glob и rglob

- **`folder.iterdir()`** даёт все файлы и папки, лежащие непосредственно в `folder`.
- **`folder.glob("*.txt")`** даёт пути, подходящие под **шаблон с подстановочными знаками** (wildcard): `*` означает «что угодно», поэтому `*.txt` — это «каждый файл `.txt`».
- **`folder.rglob("*.txt")`** делает то же самое, но ищет ещё и **во всех подпапках** («рекурсивный glob»).

<CodeExample output={`Внутри demo-files: ['notes.txt', 'photos', 'todo.txt']
Текстовые файлы: ['notes.txt', 'todo.txt']
Все jpg: ['photos/2025/snow.jpg', 'photos/beach.jpg']`}>

```python
import shutil
from pathlib import Path

base = Path("demo-files")
shutil.rmtree(base, ignore_errors=True)
(base / "photos" / "2025").mkdir(parents=True)
for name in ["notes.txt", "todo.txt", "photos/beach.jpg",
             "photos/2025/snow.jpg"]:
    (base / name).write_text("demo")

print("Внутри demo-files:", sorted(p.name for p in base.iterdir()))
print("Текстовые файлы:", sorted(p.name for p in base.glob("*.txt")))
jpgs = [p.relative_to(base).as_posix() for p in base.rglob("*.jpg")]
print("Все jpg:", sorted(jpgs))
```

</CodeExample>

- Порядок `iterdir()` и `glob()` зависит от операционной системы, поэтому оборачивайте их в `sorted()`, когда порядок важен.
- `p.relative_to(base)` отрезает начало пути, а `.as_posix()` даёт текст с `/` на любой системе.
- Шаблоны glob — это **не** регулярные выражения: `*` — «любой текст», а `?` — «любой один символ». В Linux они чувствительны к регистру, поэтому `*.jpg` не найдёт `PHOTO.JPG`.

## Наводим порядок в папке загрузок

Пора сделать что-то полезное: разложим захламлённую папку по подпапкам в зависимости от типа файлов. **`path.rename(new_path)`** перемещает файл под новым именем или в другую папку:

<CodeExample output={`cat.jpg -> images/
notes.txt -> documents/
photo.PNG -> images/
report.pdf -> documents/
setup.exe -> other/
song.mp3 -> music/
documents ['notes.txt', 'report.pdf']
images ['cat.jpg', 'photo.PNG']
music ['song.mp3']
other ['setup.exe']`}>

```python
import shutil
from pathlib import Path

downloads = Path("demo-downloads")
shutil.rmtree(downloads, ignore_errors=True)
downloads.mkdir()
for name in ["cat.jpg", "notes.txt", "song.mp3", "photo.PNG",
             "report.pdf", "setup.exe"]:
    (downloads / name).write_text("demo")

KINDS = {
    ".jpg": "images", ".png": "images",
    ".txt": "documents", ".pdf": "documents",
    ".mp3": "music",
}

for path in sorted(downloads.iterdir()):
    if not path.is_file():
        continue
    folder = KINDS.get(path.suffix.lower(), "other")
    target = downloads / folder
    target.mkdir(exist_ok=True)
    path.rename(target / path.name)
    print(f"{path.name} -> {folder}/")

for folder in sorted(downloads.iterdir()):
    print(folder.name, sorted(p.name for p in folder.iterdir()))
```

</CodeExample>

- `path.suffix.lower()` делает `.PNG` и `.png` одинаковыми.
- Мы перебираем **отсортированный список** содержимого папки, составленный **до** того, как начали что-то перемещать, поэтому новые подпапки тоже не попадают в обработку.

## Безопасное массовое переименование: сначала пробный запуск

Переименовывать много файлов разом рискованно: из-за бага два файла могут получить одно имя, и один из них будет **перезаписан**. Профессионалы делают **пробный запуск** (dry run): сначала **планируют** изменения и выводят их, проверяют план и только потом выполняют его по-настоящему:

<CodeExample output={`будет переименован: IMG_2041.jpg -> holiday-001.jpg
будет переименован: IMG_2042.jpg -> holiday-002.jpg
будет переименован: IMG_2050.jpg -> holiday-003.jpg
Переименовано файлов: 3
['holiday-001.jpg', 'holiday-002.jpg', 'holiday-003.jpg', 'notes.txt']`}>

```python
import shutil
from pathlib import Path

photos = Path("demo-photos")
shutil.rmtree(photos, ignore_errors=True)
photos.mkdir()
for name in ["IMG_2042.jpg", "IMG_2041.jpg", "IMG_2050.jpg",
             "notes.txt"]:
    (photos / name).write_text("demo")

def plan_renames(folder, prefix):
    plan = []
    for number, old in enumerate(sorted(folder.glob("*.jpg")), 1):
        plan.append((old, old.with_name(f"{prefix}-{number:03}.jpg")))
    return plan

def apply_renames(plan, dry_run=True):
    done = 0
    for old, new in plan:
        if new.exists():
            print(f"ПРОПУСК {new.name}: такой файл уже есть")
        elif dry_run:
            print(f"будет переименован: {old.name} -> {new.name}")
        else:
            old.rename(new)
            done += 1
    return done

plan = plan_renames(photos, "holiday")
apply_renames(plan)                       # сначала смотрим...
count = apply_renames(plan, dry_run=False)  # ...потом делаем
print(f"Переименовано файлов: {count}")
print(sorted(p.name for p in photos.iterdir()))
```

</CodeExample>

`{number:03}` дополняет число нулями до трёх цифр, поэтому `holiday-010.jpg` при сортировке идёт после `holiday-009.jpg`. Благодаря тому что `dry_run=True` стоит **по умолчанию**, забытый аргумент безопасен, а не разрушителен.

<Callout type="warning" title="rename может перезаписать файл">

В macOS и Linux `old.rename(new)` молча **заменяет** `new`, если такой файл уже существует. Когда вы не уверены, что имя свободно, всегда сначала проверяйте `new.exists()` (как это делает `apply_renames`).

</Callout>

## Копирование и перемещение с shutil

`pathlib` работает с отдельными файлами и папками. Для копирования и перемещения между дисками используйте модуль **`shutil`** («shell utilities», утилиты оболочки):

| Функция | Что делает |
| --- | --- |
| `shutil.copy(src, dst)` | Копирует файл (под новым именем или в папку) |
| `shutil.copytree(src, dst)` | Копирует целую папку со всем содержимым |
| `shutil.move(src, dst)` | Перемещает файл или папку, даже на другой диск |
| `shutil.rmtree(folder)` | Удаляет папку и всё, что внутри, навсегда |

<CodeExample output={`['draft.txt', 'v1.txt']
['report.txt', 'v1.txt']
['report.txt']`}>

```python
import shutil
from pathlib import Path

base = Path("demo-shutil")
shutil.rmtree(base, ignore_errors=True)
(base / "backup").mkdir(parents=True)
(base / "draft.txt").write_text("Мой отчёт")

shutil.copy(base / "draft.txt", base / "v1.txt")
print(sorted(p.name for p in base.glob("*.txt")))

shutil.move(base / "draft.txt", base / "report.txt")
print(sorted(p.name for p in base.glob("*.txt")))

shutil.copytree(base, Path("demo-shutil-copy"), dirs_exist_ok=True)
shutil.move(base / "v1.txt", base / "backup")
print(sorted(p.name for p in base.glob("*.txt")))
```

</CodeExample>

## Пишем отчёты

Скрипты автоматизации часто заканчиваются записью **отчёта**: CSV для электронной таблицы или JSON для другой программы. Вот сводка по папке, где считаются файлы и байты для каждого типа. `path.stat().st_size` — размер файла в байтах:

<CodeExample output={`{
  ".txt": {
    "files": 1,
    "bytes": 5
  },
  ".jpg": {
    "files": 2,
    "bytes": 3000
  }
}
type,files,bytes
.jpg,2,3000
.txt,1,5`}>

```python
import csv
import json
import shutil
from pathlib import Path

base = Path("demo-report")
shutil.rmtree(base, ignore_errors=True)
(base / "pics").mkdir(parents=True)
(base / "notes.txt").write_text("hello")
(base / "pics" / "a.jpg").write_text("x" * 1000)
(base / "pics" / "b.jpg").write_text("x" * 2000)

summary = {}
for path in sorted(base.rglob("*")):
    if path.is_file():
        stats = summary.setdefault(path.suffix, {"files": 0, "bytes": 0})
        stats["files"] += 1
        stats["bytes"] += path.stat().st_size

out = base / "reports"
out.mkdir(exist_ok=True)
(out / "summary.json").write_text(json.dumps(summary, indent=2))

with open(out / "summary.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["type", "files", "bytes"])
    for kind, stats in sorted(summary.items()):
        writer.writerow([kind, stats["files"], stats["bytes"]])

print((out / "summary.json").read_text())
print((out / "summary.csv").read_text().strip())
```

</CodeExample>

Части с CSV и JSON — ровно то, что вы изучили в уроке [CSV и JSON](/learn/python/csv-and-json). Заметьте: мы записали отчёты в подпапку **после** сканирования, чтобы файлы отчётов не посчитали сами себя.

## Настоящие скрипты на вашем компьютере

На PandaDev ваш код выполняется в браузере. На своём компьютере скрипты автоматизации обычно запускают из **терминала** (terminal), и часто — **по расписанию**.

### Аргументы командной строки с argparse

Жёстко прописанный `Path("demo-downloads")` годится для демонстрации, но настоящий инструмент должен позволять выбрать папку при запуске. Встроенный модуль **`argparse`** читает аргументы командной строки и даже сам создаёт страницу `--help`:

```python title="organise.py"
import argparse
from pathlib import Path

parser = argparse.ArgumentParser(description="Сортирует файлы по типу.")
parser.add_argument("folder", type=Path, help="папка, которую нужно разобрать")
parser.add_argument("--dry-run", action="store_true",
                    help="только показать, что произойдёт")
args = parser.parse_args()

print(f"Сортирую {args.folder} (пробный запуск: {args.dry_run})")
# ... код сортировки из примера выше, но с args.folder ...
```

```bash
python organise.py ~/Downloads --dry-run
python organise.py ~/Downloads
python organise.py --help
```

### Запуск скриптов по расписанию

Чтобы скрипт запускался автоматически, попросите об этом операционную систему:

- **macOS и Linux: cron.** Выполните `crontab -e` и добавьте строку. Пять полей — это минута, час, день месяца, месяц и день недели:

```bash
# каждый понедельник в 08:00 наводим порядок в папке Downloads
0 8 * * 1 /usr/bin/python3 /home/mei/scripts/organise.py /home/mei/Downloads
```

- **Windows: Планировщик заданий** (Task Scheduler). Откройте *Планировщик заданий*, выберите *Создать простую задачу* (Create Basic Task), задайте триггер (например, «Еженедельно, понедельник 08:00»), затем *Запустить программу* (Start a program): в качестве программы укажите `python`, а в аргументах — полный путь к скрипту (и папку).

Скрипты по расписанию работают, когда вы за ними не следите, поэтому используйте **полные пути**, записывайте происходящее в лог-файл и сначала проверяйте всё пробным запуском.

## Мини-проект: Анализатор лог-файлов

Веб-серверы записывают в **журнал доступа** (access log) строку на каждый запрос. Это первое место, куда смотрят разработчики, когда сайт тормозит или сломан. Каждая строка выглядит так:

```text
203.0.113.5 - - [04/Oct/2026:14:05:01 +0000] "GET /api/orders HTTP/1.1" 500 87
```

Слева направо: **IP-адрес** посетителя, два поля, которые мы пропустим (часто там `-`), **время** в квадратных скобках со смещением от UTC, **запрос** в кавычках (метод, путь, протокол), **код ответа** (`200` — OK, `404` — не найдено, `5xx` — ошибки сервера) и **размер** ответа в байтах (`-`, когда тела ответа нет).

Ваш анализатор использует всё из этого модуля: **регулярное выражение** с именованными группами, чтобы прочитать каждую строку, **datetime**, чтобы разобраться со временем, и **pathlib**, чтобы прочитать лог и сохранить отчёт.

LOG_LINE = re.compile(
    r'(?P<ip>\S+) \S+ \S+ \[(?P<time>[^\]]+)\] '
    r'"(?P<method>[A-Z]+) (?P<path>\S+) [^"]*" '
    r'(?P<status>\d{3}) (?P<size>\d+|-)'
)


def parse_line(line):
    m = LOG_LINE.fullmatch(line.strip())
    if not m:
        return None
    time = datetime.strptime(m["time"], "%d/%b/%Y:%H:%M:%S %z")
    size = m["size"]
    return {
        "ip": m["ip"],
        "time": time.astimezone(timezone.utc),
        "method": m["method"],
        "path": m["path"],
        "status": int(m["status"]),
        "size": 0 if size == "-" else int(size),
    }


def load_log(path):
    entries = []
    for line in Path(path).read_text().splitlines():
        entry = parse_line(line)
        if entry is not None:
            entries.append(entry)
    return entries


def status_counts(entries):
    return dict(Counter(e["status"] for e in entries))


def top_paths(entries, n=3):
    counts = Counter(e["path"] for e in entries)
    ranked = sorted(counts.items(), key=lambda item: (-item[1], item[0]))
    return ranked[:n]


def busiest_hour(entries):
    hours = Counter(
        e["time"].replace(minute=0, second=0, microsecond=0)
        for e in entries
    )
    most = max(hours.values())
    return min(hour for hour, count in hours.items() if count == most)


def error_bursts(entries, threshold=3):
    minutes = Counter(
        e["time"].replace(second=0, microsecond=0)
        for e in entries
        if e["status"] >= 500
    )
    return sorted(m for m, count in minutes.items() if count >= threshold)


def write_report(entries, path):
    errors = sum(1 for e in entries if e["status"] >= 500)
    lines = [
        f"Requests: {len(entries)}",
        f"Errors (5xx): {errors}",
        f"Busiest hour: {busiest_hour(entries):%Y-%m-%d %H:%M} UTC",
        "Top paths:",
    ]
    for page, count in top_paths(entries):
        lines.append(f"  {page} {count}")
    lines.append("Error bursts:")
    bursts = error_bursts(entries)
    for minute in bursts:
        lines.append(f"  {minute:%Y-%m-%d %H:%M} UTC")
    if not bursts:
        lines.append("  none")
    text = "\n".join(lines) + "\n"

    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(text)
    return text


entries = load_log("server-logs/access.log")
print(status_counts(entries))
print(write_report(entries, "server-logs/reports/summary.txt"))

## Итоги

- Объекты `Path` соединяются через `/`, и у них есть `.name`, `.stem`, `.suffix`, `.parent`, `.with_suffix()` и `.with_name()`.
- `mkdir(parents=True, exist_ok=True)` безопасно создаёт папки; `exists()`, `is_file()` и `is_dir()` проверяют, что там есть.
- `iterdir()` перечисляет содержимое папки, `glob("*.txt")` фильтрует его, а `rglob()` ищет ещё и в подпапках. Сортируйте результаты.
- `rename()` перемещает или переименовывает; массовые изменения сначала планируйте с **пробным запуском** и никогда не перезаписывайте файлы случайно.
- `shutil` копирует (`copy`, `copytree`), перемещает (`move`) и удаляет (`rmtree` — навсегда!).
- Завершайте автоматизацию **отчётом** в CSV или JSON.
- Настоящие скрипты принимают аргументы через `argparse` и запускаются по расписанию через **cron** или **Планировщик заданий**.
- Регулярные выражения + datetime + pathlib вместе превращают сырой лог-файл в полезные ответы.
