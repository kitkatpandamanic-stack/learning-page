In Part 1 you built the storage: `Project` and `Task` models and a repository of small, tested functions. Now we put a **web API** on top. Each request will get its own database **session** through `Depends`, the data going in and out is checked by **Pydantic schemas**, and missing things answer **404**. 🌐

This part builds on the [Request Bodies and Validation](/learn/python/request-validation) and [To-do API](/learn/python/todo-api) lessons: same tools, but now the data lives in a real database instead of a dict.

## Schemas: what goes in and what comes out

We already have SQLAlchemy **models** that describe the tables. The API needs Pydantic **schemas** that describe the JSON. They're separate on purpose: a client may send a `name`, but it must never choose the `id`, and what we send back may include things that aren't columns at all, like a project's list of tasks. Following the To-do API, there's one schema per job:

```python
class ProjectCreate(BaseModel):     # POST /projects
    name: str = Field(min_length=1, max_length=100)

class TaskCreate(BaseModel):        # POST /projects/{id}/tasks
    title: str = Field(min_length=1, max_length=200)

class TaskUpdate(BaseModel):        # PATCH: every field optional
    title: str | None = Field(
        default=None, min_length=1, max_length=200
    )
    done: bool | None = None
```

The limits match the `String(100)` and `String(200)` columns, so text that's too long is rejected with a 422 before it ever reaches the database.

### Reading SQLAlchemy objects with from_attributes

The output schemas have one new line: **`model_config = ConfigDict(from_attributes=True)`**. Normally Pydantic builds a model from a **dict**. With `from_attributes=True` it can also read the **attributes** of any object, such as a SQLAlchemy `Project`:

<CodeExample output={`id=1 name='Garden'
{'id': 1, 'name': 'Garden', 'tasks': [{'id': 1, 'title': 'Dig', 'done': False, 'project_id': 1}]}
Input should be a valid dictionary or instance of PlainProject`}>

```python
from pydantic import BaseModel, ConfigDict, ValidationError
from sqlalchemy import ForeignKey, String, create_engine
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, Session, mapped_column, relationship,
)

class Base(DeclarativeBase):
    pass

class Project(Base):
    __tablename__ = "projects"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    tasks: Mapped[list["Task"]] = relationship(
        back_populates="project", cascade="all, delete-orphan"
    )

class Task(Base):
    __tablename__ = "tasks"
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(200))
    done: Mapped[bool] = mapped_column(default=False)
    project_id: Mapped[int] = mapped_column(ForeignKey("projects.id"))
    project: Mapped["Project"] = relationship(back_populates="tasks")

class TaskOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    title: str
    done: bool
    project_id: int

class ProjectOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    name: str

class ProjectDetail(ProjectOut):
    tasks: list[TaskOut]

class PlainProject(BaseModel):     # no from_attributes
    id: int
    name: str

engine = create_engine("sqlite://")
Base.metadata.create_all(engine)

with Session(engine) as session:
    garden = Project(name="Garden", tasks=[Task(title="Dig")])
    session.add(garden)
    session.commit()

    print(ProjectOut.model_validate(garden))
    print(ProjectDetail.model_validate(garden).model_dump())
    try:
        PlainProject.model_validate(garden)
    except ValidationError as error:
        print(error.errors()[0]["msg"])
```

</CodeExample>

- **`model_validate(garden)`** reads `garden.id` and `garden.name` and ignores everything else.
- **`ProjectDetail`** inherits `id` and `name` from `ProjectOut` and adds `tasks: list[TaskOut]`. Pydantic follows the `garden.tasks` relationship and turns every `Task` into a `TaskOut`: nested JSON for free.
- Without `from_attributes`, Pydantic refuses the object.

In the endpoints you won't even call `model_validate` yourself: you return the SQLAlchemy object, and FastAPI converts it with the `response_model`.

## One session per request

Every request needs a database session, and the session must be **closed** afterwards, even if the endpoint fails. That's a job for a **dependency with `yield`**: the code before `yield` runs before the endpoint, the yielded value is what the endpoint gets, and the code after `yield` runs when the request is finished. It's the same "setup, yield, clean up" pattern as a pytest fixture or `@contextlib.contextmanager`:

<CodeExample output={`open session
endpoint runs
close session
201 {'id': 1, 'name': 'Garden'}
open session
same session: True
close session
204`}>

```python
from fastapi import Depends, FastAPI
from fastapi.testclient import TestClient
from pydantic import BaseModel, Field
from sqlalchemy import ForeignKey, String, create_engine
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, Session, mapped_column, relationship,
)
from sqlalchemy.pool import StaticPool

class Base(DeclarativeBase):
    pass

class Project(Base):
    __tablename__ = "projects"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    tasks: Mapped[list["Task"]] = relationship(
        back_populates="project", cascade="all, delete-orphan"
    )

class Task(Base):
    __tablename__ = "tasks"
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(200))
    done: Mapped[bool] = mapped_column(default=False)
    project_id: Mapped[int] = mapped_column(ForeignKey("projects.id"))
    project: Mapped["Project"] = relationship(back_populates="tasks")

class ProjectCreate(BaseModel):
    name: str = Field(min_length=1, max_length=100)

engine = create_engine(
    "sqlite://",
    connect_args={"check_same_thread": False},
    poolclass=StaticPool,
)
Base.metadata.create_all(engine)

def get_session():
    print("open session")
    with Session(engine) as session:
        yield session
    print("close session")

def load_project(
    project_id: int, session: Session = Depends(get_session)
) -> Project:
    return session.get(Project, project_id)

app = FastAPI()

@app.post("/projects", status_code=201)
def api_create_project(
    data: ProjectCreate, session: Session = Depends(get_session)
):
    print("endpoint runs")
    project = Project(name=data.name)
    session.add(project)
    session.commit()
    return {"id": project.id, "name": project.name}

@app.delete("/projects/{project_id}", status_code=204)
def api_delete_project(
    project: Project = Depends(load_project),
    session: Session = Depends(get_session),
):
    print("same session:", project in session)
    session.delete(project)
    session.commit()

client = TestClient(app)
response = client.post("/projects", json={"name": "Garden"})
print(response.status_code, response.json())
print(client.delete("/projects/1").status_code)
```

</CodeExample>

Look at the second request: `api_delete_project` needs a session, and so does `load_project`. FastAPI calls `get_session` only **once per request** and gives both the **same** session (`project in session` is `True`). That matters: an object loaded in one session can't simply be deleted with another.

<Callout type="note" title="Why StaticPool and check_same_thread?">

FastAPI runs normal `def` endpoints in a pool of **worker threads**, so one slow request doesn't block the others. Two settings make an **in-memory** SQLite database work with that:

- `connect_args={"check_same_thread": False}`: by default, Python's `sqlite3` refuses to use a connection from a different thread than the one that opened it.
- `poolclass=StaticPool`: an in-memory database lives **inside one connection**. SQLAlchemy normally opens several connections, and each new one would see a brand-new, empty database (`no such table: projects`). `StaticPool` keeps exactly one connection and shares it.

With a database **file** (`"sqlite:///projects.db"`) you only need `check_same_thread`, and PostgreSQL needs neither. Real projects create the engine once, in `database.py`, from a URL in their settings.

</Callout>

## The project endpoints

Now the real thing. The endpoints are thin: they take the request data, call a repository function from Part 1 and return the result. The `response_model` turns SQLAlchemy objects into JSON, and `get_project_or_404` works exactly like `get_todo_or_404` did in the To-do API, except it asks the database:

<CodeExample output={`201 {'id': 1, 'name': 'Garden'}
[{'id': 1, 'name': 'Garden'}, {'id': 2, 'name': 'Kitchen'}]
{'id': 1, 'name': 'Garden', 'tasks': [{'id': 1, 'title': 'Dig', 'done': False, 'project_id': 1}]}
404 {'detail': 'Project not found'}
422 String should have at least 1 character`}>

```python
from fastapi import Depends, FastAPI, HTTPException
from fastapi.testclient import TestClient
from pydantic import BaseModel, ConfigDict, Field
from sqlalchemy import ForeignKey, String, create_engine, select
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, Session, mapped_column, relationship,
)
from sqlalchemy.pool import StaticPool

class Base(DeclarativeBase):
    pass

class Project(Base):
    __tablename__ = "projects"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    tasks: Mapped[list["Task"]] = relationship(
        back_populates="project", cascade="all, delete-orphan"
    )

class Task(Base):
    __tablename__ = "tasks"
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(200))
    done: Mapped[bool] = mapped_column(default=False)
    project_id: Mapped[int] = mapped_column(ForeignKey("projects.id"))
    project: Mapped["Project"] = relationship(back_populates="tasks")

def create_project(session: Session, name: str) -> Project:
    project = Project(name=name)
    session.add(project)
    session.commit()
    return project

def get_project(session: Session, project_id: int) -> Project | None:
    return session.get(Project, project_id)

def list_projects(session: Session) -> list[Project]:
    return list(session.scalars(select(Project).order_by(Project.id)))

def add_task(session: Session, project: Project, title: str) -> Task:
    task = Task(title=title, project=project)
    session.add(task)
    session.commit()
    return task

class ProjectCreate(BaseModel):
    name: str = Field(min_length=1, max_length=100)

class ProjectOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    name: str

class TaskOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    title: str
    done: bool
    project_id: int

class ProjectDetail(ProjectOut):
    tasks: list[TaskOut]

engine = create_engine(
    "sqlite://",
    connect_args={"check_same_thread": False},
    poolclass=StaticPool,
)
Base.metadata.create_all(engine)

def get_session():
    with Session(engine) as session:
        yield session

def get_project_or_404(
    project_id: int, session: Session = Depends(get_session)
) -> Project:
    project = get_project(session, project_id)
    if project is None:
        raise HTTPException(status_code=404, detail="Project not found")
    return project

app = FastAPI(title="Projects API")

@app.post("/projects", status_code=201, response_model=ProjectOut)
def api_create_project(
    data: ProjectCreate, session: Session = Depends(get_session)
):
    return create_project(session, data.name)

@app.get("/projects", response_model=list[ProjectOut])
def api_list_projects(session: Session = Depends(get_session)):
    return list_projects(session)

@app.get("/projects/{project_id}", response_model=ProjectDetail)
def api_get_project(project: Project = Depends(get_project_or_404)):
    return project

client = TestClient(app)
response = client.post("/projects", json={"name": "Garden"})
print(response.status_code, response.json())
client.post("/projects", json={"name": "Kitchen"})
print(client.get("/projects").json())

with Session(engine) as session:          # a task, the Part 1 way
    add_task(session, get_project(session, 1), "Dig")
print(client.get("/projects/1").json())

response = client.get("/projects/99")
print(response.status_code, response.json())
response = client.post("/projects", json={"name": ""})
print(response.status_code, response.json()["detail"][0]["msg"])
```

</CodeExample>

Some details worth noticing:

- Endpoint functions are named **`api_...`** because names like `create_project` are already taken by the repository. In a real project they live in different files (`main.py` would call `repository.create_project(...)`), so there's no clash.
- `api_get_project` is a single line: the dependency already found the project or answered 404, and `response_model=ProjectDetail` adds its tasks.
- The empty name never reaches our code: Pydantic answered **422** with the same `detail` list you met in the validation lesson.

<Callout type="warning" title="Keep SQL out of the endpoints">

It's tempting to write `session.scalars(select(Task)...)` right inside an endpoint. Resist it: every query in an endpoint is a query that can only be tested through HTTP, and similar queries get copied between endpoints. Endpoints translate between HTTP and Python; the repository talks to the database.

</Callout>

## Routes for tasks

Tasks belong to a project, so **creating** and **listing** them happens under the project: `POST /projects/{project_id}/tasks` and `GET /projects/{project_id}/tasks`. Those endpoints use `get_project_or_404`, so adding a task to a project that doesn't exist answers 404.

But once a task exists, it has its own unique id, so `GET`, `PATCH` and `DELETE` use a short path: **`/tasks/{task_id}`**. Longer paths like `/projects/1/tasks/7` repeat information and raise awkward questions (what if task 7 belongs to project 2?). Keeping nesting to one level is a common REST guideline.

Two more things you'll need for the exercise:

- The `?done=` filter is just an optional query parameter, `done: bool | None = None`, passed on to `list_tasks`.
- For `PATCH`, `data.model_dump(exclude_unset=True)` gives a dict of only the fields the client sent, such as `{"done": True}`. That's exactly what `update_task(session, task, changes)` from Part 1 expects.

## Running it for real

On your own computer, install the packages in a virtual environment and start the development server (with all the code in `main.py`):

```bash
pip install "fastapi[standard]" sqlalchemy
fastapi dev main.py
```

Open `http://127.0.0.1:8000/docs` and try the endpoints: create a project, add tasks, tick one off with `PATCH`. To keep the data when the server restarts, switch the engine to a file, `create_engine("sqlite:///projects.db", connect_args={"check_same_thread": False})`, and drop the `StaticPool`.

1. `get_task_or_404(task_id, session)`: the `Task`, or **404** with `detail` `"Task not found"`.
2. `GET /projects/{project_id}`: the project with its tasks (`response_model=ProjectDetail`).
3. `DELETE /projects/{project_id}`: delete it (and so its tasks), answer **204**.
4. `POST /projects/{project_id}/tasks`: body `TaskCreate`, answer **201** with a `TaskOut`.
5. `GET /projects/{project_id}/tasks`: the project's tasks as a list, with an optional `done` query parameter.
6. `GET /tasks/{task_id}`: one task.
7. `PATCH /tasks/{task_id}`: body `TaskUpdate`; change only the fields that were sent and return the task.
8. `DELETE /tasks/{task_id}`: delete it, answer **204**.

Unknown project ids must answer 404 `"Project not found"` everywhere. Every endpoint should call the repository functions from Part 1 instead of writing queries. The checks call your API with `TestClient`.

import pytest
from fastapi import Depends, FastAPI, HTTPException
from fastapi.testclient import TestClient
from pydantic import BaseModel, ConfigDict, Field
from sqlalchemy import ForeignKey, String, create_engine, select
from sqlalchemy.orm import (
    DeclarativeBase, Mapped, Session, mapped_column, relationship,
)
from sqlalchemy.pool import StaticPool


# ---------- models ----------

class Base(DeclarativeBase):
    pass


class Project(Base):
    __tablename__ = "projects"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    tasks: Mapped[list["Task"]] = relationship(
        back_populates="project", cascade="all, delete-orphan"
    )


class Task(Base):
    __tablename__ = "tasks"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(200))
    done: Mapped[bool] = mapped_column(default=False)
    project_id: Mapped[int] = mapped_column(ForeignKey("projects.id"))
    project: Mapped["Project"] = relationship(back_populates="tasks")


# ---------- repository ----------

def create_project(session: Session, name: str) -> Project:
    project = Project(name=name)
    session.add(project)
    session.commit()
    return project


def get_project(session: Session, project_id: int) -> Project | None:
    return session.get(Project, project_id)


def list_projects(session: Session) -> list[Project]:
    return list(session.scalars(select(Project).order_by(Project.id)))


def delete_project(session: Session, project: Project) -> None:
    session.delete(project)
    session.commit()


def add_task(session: Session, project: Project, title: str) -> Task:
    task = Task(title=title, project=project)
    session.add(task)
    session.commit()
    return task


def get_task(session: Session, task_id: int) -> Task | None:
    return session.get(Task, task_id)


def list_tasks(
    session: Session, project_id: int, done: bool | None = None
) -> list[Task]:
    stmt = select(Task).where(Task.project_id == project_id)
    if done is not None:
        stmt = stmt.where(Task.done == done)
    return list(session.scalars(stmt.order_by(Task.id)))


def update_task(session: Session, task: Task, changes: dict) -> Task:
    for field, value in changes.items():
        setattr(task, field, value)
    session.commit()
    return task


def delete_task(session: Session, task: Task) -> None:
    session.delete(task)
    session.commit()


# ---------- schemas ----------

class ProjectCreate(BaseModel):
    name: str = Field(min_length=1, max_length=100)


class ProjectOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    name: str


class TaskCreate(BaseModel):
    title: str = Field(min_length=1, max_length=200)


class TaskUpdate(BaseModel):
    title: str | None = Field(
        default=None, min_length=1, max_length=200
    )
    done: bool | None = None


class TaskOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    title: str
    done: bool
    project_id: int


class ProjectDetail(ProjectOut):
    tasks: list[TaskOut]


# ---------- database and dependencies ----------

engine = create_engine(
    "sqlite://",
    connect_args={"check_same_thread": False},
    poolclass=StaticPool,
)
Base.metadata.create_all(engine)


def get_session():
    with Session(engine) as session:
        yield session


def get_project_or_404(
    project_id: int, session: Session = Depends(get_session)
) -> Project:
    project = get_project(session, project_id)
    if project is None:
        raise HTTPException(status_code=404, detail="Project not found")
    return project


def get_task_or_404(
    task_id: int, session: Session = Depends(get_session)
) -> Task:
    task = get_task(session, task_id)
    if task is None:
        raise HTTPException(status_code=404, detail="Task not found")
    return task


# ---------- endpoints ----------

app = FastAPI(title="Projects API")


@app.post("/projects", status_code=201, response_model=ProjectOut)
def api_create_project(
    data: ProjectCreate, session: Session = Depends(get_session)
):
    return create_project(session, data.name)


@app.get("/projects", response_model=list[ProjectOut])
def api_list_projects(session: Session = Depends(get_session)):
    return list_projects(session)


@app.get("/projects/{project_id}", response_model=ProjectDetail)
def api_get_project(project: Project = Depends(get_project_or_404)):
    return project


@app.delete("/projects/{project_id}", status_code=204)
def api_delete_project(
    project: Project = Depends(get_project_or_404),
    session: Session = Depends(get_session),
):
    delete_project(session, project)


@app.post(
    "/projects/{project_id}/tasks",
    status_code=201,
    response_model=TaskOut,
)
def api_add_task(
    data: TaskCreate,
    project: Project = Depends(get_project_or_404),
    session: Session = Depends(get_session),
):
    return add_task(session, project, data.title)


@app.get("/projects/{project_id}/tasks", response_model=list[TaskOut])
def api_list_tasks(
    done: bool | None = None,
    project: Project = Depends(get_project_or_404),
    session: Session = Depends(get_session),
):
    return list_tasks(session, project.id, done)


@app.get("/tasks/{task_id}", response_model=TaskOut)
def api_get_task(task: Task = Depends(get_task_or_404)):
    return task


@app.patch("/tasks/{task_id}", response_model=TaskOut)
def api_update_task(
    data: TaskUpdate,
    task: Task = Depends(get_task_or_404),
    session: Session = Depends(get_session),
):
    changes = data.model_dump(exclude_unset=True)
    return update_task(session, task, changes)


@app.delete("/tasks/{task_id}", status_code=204)
def api_delete_task(
    task: Task = Depends(get_task_or_404),
    session: Session = Depends(get_session),
):
    delete_task(session, task)

## What you built

- **Pydantic schemas** for input (`ProjectCreate`, `TaskCreate`, `TaskUpdate`) and output (`ProjectOut`, `ProjectDetail`, `TaskOut`), reading SQLAlchemy objects with **`from_attributes=True`**.
- A **`get_session` dependency with `yield`** that gives every request one session and always closes it.
- An engine set up for an in-memory database shared between threads: **`StaticPool`** and **`check_same_thread=False`**.
- Nine **thin endpoints** that call the repository, with `get_project_or_404` and `get_task_or_404` handling every **404**, and Pydantic handling every **422**.
