Добро пожаловать в ваш первый **итоговый проект на Python**! 🗺️ За три части вы соберёте настоящую **текстовую игру-приключение (text adventure)**: игрок исследует старый жуткий дом, вводя команды вроде `go north` и `take key`, находит ключ, отпирает сокровищницу и забирает клад.

Вы уже знаете всё, что для этого нужно: **строки** и **f-строки** из «Основ Python», **if/elif/else** и **match** из «Операторов и условий», **циклы** и **списки**, а также **функции** с возвращаемым значением. В этой первой части мы построим **мир**: комнаты и проходы между ними. Команд пока нет, только карта.

Игрок будет вводить команды по-английски: `go north` («идти на север»), `take key` («взять ключ»). Направления (`north`, `south`, `east`, `west`), названия комнат и предметов в коде — тоже английские слова: именно с ними код сравнивает то, что ввёл игрок. А вот описания комнат и сообщения игры будут на русском.

## Сначала — план карты

Прежде чем писать код, набросайте мир на бумаге. В нашем доме пять комнат. **Холл** (`hall`) — в центре, а все остальные комнаты находятся в одном шаге от него:

```text
               library
                  |
    garden  —   hall   —  kitchen
                  |
                vault
```

- К северу (`north`) от холла — **библиотека** (`library`), к востоку (`east`) — **кухня** (`kitchen`), к западу (`west`) — **сад** (`garden`), к югу (`south`) — **сокровищница** (`vault`).
- Из каждой внешней комнаты единственный выход ведёт обратно в холл.
- Позже в саду будет лежать **ключ** (`key`), а в сокровищнице — **клад** (`treasure`). Сокровищница будет заперта.

Каждую комнату мы будем хранить как простую **строку (string)**, например `"hall"` или `"vault"`. Положение игрока — это просто переменная: `room = "hall"`.

| Функция                  | Её единственная задача                         |
| ------------------------ | ---------------------------------------------- |
| `describe(room)`         | Вернуть предложение с описанием комнаты        |
| `move(room, direction)`  | Вернуть комнату, в которой окажется игрок      |

<Callout type="tip" title="Одна функция — одна задача">

Маленькие функции, каждая из которых делает что-то одно, проще читать, тестировать и исправлять. Если игрок окажется не в той комнате, вы сразу поймёте, в какую функцию смотреть.

</Callout>

## Описание комнаты

`describe` принимает название комнаты и **возвращает** описание. Мы сравниваем одно значение (`room`) с несколькими точными вариантами — как раз то, для чего хорош `match`:

<CodeExample output={`Пыльный холл. Выходы: north, south, east, west.
Сокровищница! Повсюду блестит золото. Выход: north.
Вы заблудились в тумане.`}>

```python
def describe(room):
    match room:
        case "hall":
            return "Пыльный холл. Выходы: north, south, east, west."
        case "library":
            return "Тихая библиотека, полная книг. Выход: south."
        case "kitchen":
            return "Старая кухня, пахнет супом. Выход: west."
        case "garden":
            return "Заросший сад. Выход: east."
        case "vault":
            return "Сокровищница! Повсюду блестит золото. Выход: north."
        case _:
            return "Вы заблудились в тумане."

print(describe("hall"))
print(describe("vault"))
print(describe("attic"))
```

</CodeExample>

`case _` ловит любое другое значение, поэтому даже опечатка вроде `"atic"` получит осмысленный ответ, а не `None`.

Обратите внимание: в описаниях выходы названы по-английски (`north`, `south`…). Так игрок сразу видит, какое слово ввести в команде `go`.

Заметьте ещё, что `describe` **возвращает** текст, а не печатает его. Так остальная часть игры сама решает, когда и как его показать, и позже мы легко сможем дополнить его другим текстом.

<Callout type="note" title="if/elif тоже подойдёт">

То же самое можно написать через `if room == "hall": … elif room == "library": …`. Оба варианта хороши. Просто `match` читается чуть аккуратнее, когда одно значение сравнивается со множеством фиксированных вариантов.

</Callout>

## Перемещение между комнатами

`move(room, direction)` отвечает на вопрос *«если я в этой комнате и иду в эту сторону, где я окажусь?»*. Начнём с холла, у которого четыре выхода:

<CodeExample output={`library
vault
hall`}>

```python
def move(room, direction):
    if room == "hall":
        if direction == "north":
            return "library"
        elif direction == "east":
            return "kitchen"
        elif direction == "west":
            return "garden"
        elif direction == "south":
            return "vault"
    return room

print(move("hall", "north"))
print(move("hall", "south"))
print(move("hall", "up"))
```

</CodeExample>

Главный трюк — последняя строка, `return room`. Если ни один из `return` выше не сработал, значит, **выхода в эту сторону нет**, и игрок просто остаётся на месте. Помните: `return` сразу завершает функцию, поэтому до `return room` дело доходит, только если ничего не совпало.

Теперь добавим путь назад из каждой внешней комнаты. У каждой из них всего один выход, так что с `and` получается коротко:

```python
    elif room == "library" and direction == "south":
        return "hall"
    elif room == "kitchen" and direction == "west":
        return "hall"
    elif room == "garden" and direction == "east":
        return "hall"
    elif room == "vault" and direction == "north":
        return "hall"
    return room
```

## Прогулка по дому

Когда обе функции готовы, цикл `for` может провести игрока по списку направлений. Если `move` вернула **ту же комнату**, путь закрыт, и мы печатаем сообщение об этом:

<CodeExample output={`Пыльный холл. Выходы: north, south, east, west.
Идём: north...
Тихая библиотека, полная книг. Выход: south.
Идём: north...
Туда не пройти.
Идём: south...
Пыльный холл. Выходы: north, south, east, west.
Идём: west...
Заросший сад. Выход: east.`}>

```python
def describe(room):
    match room:
        case "hall":
            return "Пыльный холл. Выходы: north, south, east, west."
        case "library":
            return "Тихая библиотека, полная книг. Выход: south."
        case "kitchen":
            return "Старая кухня, пахнет супом. Выход: west."
        case "garden":
            return "Заросший сад. Выход: east."
        case "vault":
            return "Сокровищница! Повсюду блестит золото. Выход: north."
        case _:
            return "Вы заблудились в тумане."

def move(room, direction):
    if room == "hall":
        if direction == "north":
            return "library"
        elif direction == "east":
            return "kitchen"
        elif direction == "west":
            return "garden"
        elif direction == "south":
            return "vault"
    elif room == "library" and direction == "south":
        return "hall"
    elif room == "kitchen" and direction == "west":
        return "hall"
    elif room == "garden" and direction == "east":
        return "hall"
    elif room == "vault" and direction == "north":
        return "hall"
    return room

room = "hall"
print(describe(room))

for direction in ["north", "north", "south", "west"]:
    print(f"Идём: {direction}...")
    new_room = move(room, direction)
    if new_room == room:
        print("Туда не пройти.")
    else:
        room = new_room
        print(describe(room))
```

</CodeExample>

Пока что переменная `room` — это всё **состояние игры (game state)**: одна строка, которая говорит, где находится игрок. Каждый раз, когда игрок перемещается, мы заменяем её комнатой, которую вернула `move`.

<Callout type="warning" title="Та же комната = путь закрыт">

Наше правило простое: если `move` вернула комнату, в которой вы и так были, путь закрыт. Поэтому `move` должна **всегда** возвращать комнату, даже когда выхода нет. Функция, которая иногда возвращает `None`, заставит остальную игру падать самым запутанным образом.

</Callout>

## Что вы построили

- **Карту** из пяти комнат, спланированную на бумаге ещё до написания кода.
- `describe(room)` с помощью `match` возвращает предложение для каждой комнаты, а `case _` служит страховкой.
- `move(room, direction)` с помощью `if/elif` возвращает следующую комнату или **ту же самую**, если путь закрыт.
- Цикл `for` провёл игрока по дому, а `room` хранила состояние игры.
