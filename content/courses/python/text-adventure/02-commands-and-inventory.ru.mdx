В первой части вы построили мир: пять комнат, `describe(room)` и `move(room, direction)`. Теперь игрок обретает голос. ⌨️ В этой части вы научите игру понимать **введённые команды** вроде `go north` или `take key`, разложите по комнатам **предметы**, дадите игроку носить их в **инвентаре (inventory)** и **запрёте** сокровищницу, пока он не найдёт ключ.

Вам пригодятся **методы строк** (`.lower()`, `.strip()`) из «Основ Python», **match** из «Операторов и условий», **списки** и `in` из урока «Перебор списков», а также функции, которые **возвращают несколько значений**, из урока «Аргументы по умолчанию и область видимости». Плюс три новых небольших инструмента для списков и строк — познакомимся с ними по ходу дела.

Напомним: команды игрок вводит по-английски. Первое слово — это действие (`go` — идти, `take` — взять, `drop` — положить, `look` — осмотреться, `inventory` — инвентарь), второе — направление или предмет (`north`, `key`, `lamp`…).

## Чтение команды

Игрок может ввести `go north`, `Go North` или `  GO north  `. Всё это означает одно и то же, поэтому сначала приведём текст в порядок:

- `.lower()` переводит всё в нижний регистр.
- `.strip()` убирает пробелы с обоих концов.
- `.split()` — **новый** метод: он разрезает строку на **список слов** везде, где есть пробелы.

<CodeExample output={`['go', 'north']
['take', 'key']
['look']
[]`}>

```python
print("  Go NORTH ".lower().strip().split())
print("take key".split())
print("look".split())
print("   ".split())
```

</CodeExample>

Методы можно **вызывать цепочкой**: каждый работает с результатом предыдущего. Обратите внимание на последнюю строку: команда без слов даёт **пустой список**.

Первое слово — это **глагол** (что сделать), второе — **существительное** (с чем это сделать). У некоторых команд, например `look`, существительного нет, поэтому `words[1]` мы читаем, только если оно существует:

<CodeExample output={`[go] [north]
[take] [key]
[look] []
[] []`}>

```python
def parse(command):
    words = command.lower().strip().split()
    if len(words) == 0:
        return "", ""
    verb = words[0]
    noun = ""
    if len(words) > 1:
        noun = words[1]
    return verb, noun

for command in ["Go North", "take key", "LOOK", ""]:
    verb, noun = parse(command)
    print(f"[{verb}] [{noun}]")
```

</CodeExample>

Квадратные скобки в выводе нужны лишь для того, чтобы были видны пустые строки. `parse` возвращает **два значения**, а `verb, noun = parse(command)` распаковывает их — точно так же, как `low, high = lowest_and_highest(...)` в модуле про функции.

<Callout type="warning" title="Пустые команды">

Если игрок просто нажмёт Enter, `words` окажется пустым списком, и `words[0]` упадёт с ошибкой `IndexError`. Поэтому `parse` сначала проверяет `len(words) == 0`. Всегда спрашивайте себя: *«а что, если игрок ничего не введёт?»*

</Callout>

## Где лежат предметы?

В нашем доме три предмета: **ключ** (`key`) в саду, **лампа** (`lamp`) на кухне и **клад** (`treasure`) в сокровищнице. Мы будем следить за ними с помощью одного списка `world`, где каждый элемент — короткая фраза:

```python
world = ["key in garden", "lamp in kitchen", "treasure in vault"]
```

Это читается как обычная английская фраза («ключ в саду»), а проверить, лежит ли где-то предмет, легко с помощью `in`:

<CodeExample output={`True
False`}>

```python
world = ["key in garden", "lamp in kitchen", "treasure in vault"]
print("key in garden" in world)
print("key in hall" in world)
```

</CodeExample>

Чтобы найти **все** предметы в комнате, переберите список в цикле и примените `.split()` к каждому элементу. `"key in garden".split()` даёт `['key', 'in', 'garden']`, так что предмет — это `words[0]`, а комната — `words[2]`:

<CodeExample output={`['key']
['key', 'apple']
[]`}>

```python
def items_in(room, world):
    found = []
    for place in world:
        words = place.split()
        if words[2] == room:
            found.append(words[0])
    return found

world = ["key in garden", "apple in garden", "lamp in kitchen"]
print(items_in("garden", ["key in garden"]))
print(items_in("garden", world))
print(items_in("hall", world))
```

</CodeExample>

<Callout type="note" title="Скоро, на уровне 1">

На уровне 1 вы изучите **словари (dictionaries)** — они созданы как раз для таких данных «что где лежит». А пока список коротких фраз отлично справляется с задачей, используя только то, что вы уже знаете.

</Callout>

## Осмотреться

Когда игрок вводит `look`, он должен услышать описание комнаты **и** узнать, что в ней лежит. `look` опирается на `describe` из первой части и добавляет по одной фразе на каждый предмет:

<CodeExample output={`Заросший сад. Выход: east. Здесь лежит: key.
Тихая библиотека, полная книг. Выход: south.`}>

```python
def describe(room):
    match room:
        case "garden":
            return "Заросший сад. Выход: east."
        case "library":
            return "Тихая библиотека, полная книг. Выход: south."
        case _:
            return "Вы заблудились в тумане."

def items_in(room, world):
    found = []
    for place in world:
        words = place.split()
        if words[2] == room:
            found.append(words[0])
    return found

def look(room, world):
    text = describe(room)
    for item in items_in(room, world):
        text += f" Здесь лежит: {item}."
    return text

world = ["key in garden", "lamp in kitchen"]
print(look("garden", world))
print(look("library", world))
```

</CodeExample>

(Чтобы сэкономить место, в этом примере `describe` укороченная. В вашей игре это полная версия из первой части.)

Предметы в сообщениях называются по-английски (`key`, `lamp`) — так игрок сразу видит, какое слово ввести в команде `take`.

## Взять и положить

**Инвентарь** игрока — это список того, что он несёт с собой. Сначала он пуст: `inventory = []`.

Взять предмет — значит переместить его **из** `world` **в** `inventory`. Для добавления служит знакомый `.append()`. Для удаления — **новый** метод `.remove()`: он удаляет из списка первое совпадающее значение.

<CodeExample output={`Вы взяли: key.
['key']
['lamp in kitchen']
Здесь такого нет.`}>

```python
def take(item, room, inventory, world):
    place = f"{item} in {room}"
    if place not in world:
        return "Здесь такого нет."
    world.remove(place)
    inventory.append(item)
    return f"Вы взяли: {item}."

inventory = []
world = ["key in garden", "lamp in kitchen"]

print(take("key", "garden", inventory, world))
print(inventory)
print(world)
print(take("lamp", "garden", inventory, world))
```

</CodeExample>

`not in` — противоположность `in`: это `True`, когда значения в списке **нет**.

<Callout type="note" title="Функция может изменить переданный ей список">

`take` не возвращает ни `inventory`, ни `world`, но оба списка изменились! Когда вы передаёте список в функцию, она работает с **тем же самым списком**, а не с копией. `.append()` и `.remove()` меняют этот список на месте, поэтому изменения видит и вызывающий код. Со строками так никогда не бывает: их нельзя изменить.

</Callout>

**Положить** предмет — зеркальное действие: предмет покидает инвентарь и оказывается в комнате, где вы стоите. Попробуйте написать `drop` сами в упражнении ниже: проверьте, что предмет есть в `inventory`, удалите его через `.remove()`, а затем добавьте в `world` новую фразу вроде `"key in hall"` через `.append()`.

Чтобы красиво показать инвентарь, нужен ещё один **новый** инструмент: `", ".join(items)` склеивает строки списка, вставляя между ними `", "`. Это противоположность `.split()`:

<CodeExample output={`У вас ничего нет.
У вас с собой: key, lamp.`}>

```python
def show_inventory(inventory):
    if len(inventory) == 0:
        return "У вас ничего нет."
    return "У вас с собой: " + ", ".join(inventory) + "."

print(show_inventory([]))
print(show_inventory(["key", "lamp"]))
```

</CodeExample>

## Запертая дверь

Сокровищница заперта. Пойти на `south` из холла можно, только если в инвентаре есть `"key"`. Маленькая функция отвечает на вопрос *«заперт ли сейчас этот путь?»*:

<CodeExample output={`True
False
False`}>

```python
def is_locked(room, direction, inventory):
    if room == "hall" and direction == "south":
        return "key" not in inventory
    return False

print(is_locked("hall", "south", []))
print(is_locked("hall", "south", ["key"]))
print(is_locked("hall", "north", []))
```

</CodeExample>

## Собираем всё вместе: handle()

Теперь одна функция, `handle`, выполняет **любую** команду. Она разбирает команду, применяет `match` к глаголу и возвращает **два значения**: комнату, в которой теперь находится игрок, и сообщение для него.

```python
def handle(command, room, inventory, world):
    verb, noun = parse(command)
    match verb:
        case "go":
            if is_locked(room, noun, inventory):
                return room, "Дверь сокровищницы заперта. Нужен ключ."
            new_room = move(room, noun)
            if new_room == room:
                return room, "Туда не пройти."
            return new_room, look(new_room, world)
        case "look":
            return room, look(room, world)
        # здесь будут take, drop и inventory
        case _:
            return room, "Не понимаю эту команду."
```

- Для `go` мы проверяем замок **до** перемещения, а затем используем `move` из первой части. Попав в новую комнату, игрок автоматически видит её описание.
- Команды, которые не перемещают игрока, например `look`, возвращают **ту же** `room`.
- `case _` ловит опечатки и неизвестные глаголы, так что игра никогда не падает от странного ввода.

Игра хранит своё состояние в трёх переменных (`room`, `inventory` и `world`) и обновляет `room` после каждой команды:

```python
room, message = handle("go west", room, inventory, world)
print(message)
```

                return room, "Дверь сокровищницы заперта. Нужен ключ."
            new_room = move(room, noun)
            if new_room == room:
                return room, "Туда не пройти."
            return new_room, look(new_room, world)
        case "look":
            return room, look(room, world)
        case "take":
            return room, take(noun, room, inventory, world)
        case "drop":
            return room, drop(noun, room, inventory, world)
        case "inventory":
            return room, show_inventory(inventory)
        case _:
            return room, "Не понимаю эту команду."


room = "hall"

            "inventory", "go east", "drop key", "look"]

for command in commands:
    print(f"> {command}")

## Что вы построили

- `parse` превращает небрежный ввод в чистые **глагол** и **существительное** с помощью `.lower().strip().split()`.
- Список `world` хранит, **где лежит каждый предмет**, а `items_in` и `look` его читают.
- `take` и `drop` перемещают предметы между `world` и **инвентарём** игрока с помощью `.append()` и `.remove()`.
- `is_locked` держит сокровищницу закрытой, пока у игрока нет ключа. 🔑
- `handle` выполняет любую команду и возвращает новую комнату и сообщение.
