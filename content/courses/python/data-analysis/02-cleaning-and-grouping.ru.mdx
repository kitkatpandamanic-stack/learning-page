## Пропущенные значения: isna, dropna, fillna

**`isna()`** даёт `True` для каждого пропущенного значения (missing value). Если добавить `.sum()`, получится количество пропусков в каждом столбце (ведь `True` считается как 1). Это самая быстрая проверка здоровья любого набора данных:

<CodeExample output={`name    0
mood    1
naps    2
dtype: int64
  name   mood  naps
0  Mei  happy   3.0
   name   mood  naps
0   Mei  happy   3.0
2  Yuan    NaN   1.0
   name     mood  naps
0   Mei    happy   3.0
1   Bao   sleepy   0.0
2  Yuan  unknown   1.0
3   Lin   hungry   0.0`}>

```python
import pandas as pd

df = pd.DataFrame({
    "name": ["Mei", "Bao", "Yuan", "Lin"],
    "mood": ["happy", "sleepy", None, "hungry"],
    "naps": [3, None, 1, None],
})
print(df.isna().sum())

print(df.dropna())                  # удалить строки с ЛЮБЫМ пропуском
print(df.dropna(subset=["naps"]))   # смотреть только на naps

filled = df.fillna({"mood": "unknown", "naps": 0})
print(filled)
```

</CodeExample>

- **`dropna()`** удаляет строки с пропущенным значением. С `subset=[...]` метод смотрит только на указанные столбцы.
- **`fillna(value)`** заполняет пропуски. Передайте словарь, чтобы задать своё значение для каждого столбца.

Оба метода возвращают **новый** DataFrame, поэтому присваивайте результат: `df = df.dropna(...)`.

<Callout type="tip" title="Удалить или заполнить — это решение">

Единственно верного ответа нет. Пропущенное **количество** в журнале продаж вполне может означать 0, так что заполнение имеет смысл. Пропущенную **цену** угадать нельзя, поэтому безопаснее удалить такую строку. Заполнение средним по столбцу (`df["x"].fillna(df["x"].mean())`) встречается часто, но может скрывать проблемы. В реальных проектах записывайте, что вы сделали и почему, и считайте, сколько строк удалил каждый шаг.

</Callout>

## Исправляем типы: to_numeric, astype, to_datetime

Три инструмента решают большинство проблем с типами:

- **`pd.to_numeric(column, errors="coerce")`** превращает текст в числа, а всё, что числом не является (например, `"?"`), — в `NaN` вместо падения программы.
- **`.astype(int)`** преобразует столбец в другой тип. Это работает, только если можно преобразовать каждое значение, поэтому сначала заполните или удалите пропуски.
- **`pd.to_datetime(column)`** превращает текст с датами в настоящие даты. После этого **аксессор `.dt`** даёт доступ к частям каждой даты.

## Группировка: разделить, применить, объединить

А теперь самое интересное. «Какая выручка **в каждом городе**?» — это вопрос для **groupby**. pandas:

1. **разделяет (split)** строки на группы (по одной на город),
2. **применяет (apply)** к каждой группе вычисление (например, `sum`),
3. **объединяет (combine)** результаты в новую Series или DataFrame.

Вот весь конвейер очистки, а за ним — немного группировки:

<CodeExample output={`city
Edinburgh    18.0
London        6.4
Vienna       16.0
Name: revenue, dtype: float64
      orders  revenue  avg_qty
item                          
Bun        2     22.4      3.5
Cake       2      8.0      1.0
Tea        2     10.0      2.0
        city  revenue
0  Edinburgh     18.0
1     Vienna     16.0
2     London      6.4`}>

```python
import io
import pandas as pd

csv_text = """date,city,item,price,qty
2026-03-02, edinburgh,Tea,2.50,3
2026-03-02,Vienna,Cake,4.00,
2026-03-09,EDINBURGH ,Cake,4.00,2
2026-03-15,vienna,Tea,?,4
2026-04-01,Vienna,Bun,3.20,5
2026-04-03,Edinburgh,Tea,2.50,1
2026-04-12,London,Bun,3.20,2
"""
sales = pd.read_csv(io.StringIO(csv_text))

# Очистка
sales["city"] = sales["city"].str.strip().str.title()
sales["price"] = pd.to_numeric(sales["price"], errors="coerce")
sales = sales.dropna(subset=["price"])
sales["qty"] = sales["qty"].fillna(0).astype(int)
sales["revenue"] = sales["price"] * sales["qty"]

# Выручка по городам
print(sales.groupby("city")["revenue"].sum())

# Несколько результатов по каждому товару: именованная агрегация
summary = sales.groupby("item").agg(
    orders=("revenue", "count"),
    revenue=("revenue", "sum"),
    avg_qty=("qty", "mean"),
)
print(summary)

# Аккуратная таблица, лучший город первым
by_city = (sales.groupby("city", as_index=False)["revenue"]
           .sum()
           .sort_values("revenue", ascending=False)
           .reset_index(drop=True))
print(by_city)
```

</CodeExample>

- **`df.groupby("city")["revenue"].sum()`** читается как предложение: *сгруппируй по городу, возьми выручку, сложи*. Названия групп становятся индексом.
- **`.agg(new_name=("column", "function"))`** называется **именованной агрегацией (named aggregation)**. Она строит сразу несколько итоговых столбцов. Частые функции: `"sum"`, `"mean"`, `"count"`, `"min"`, `"max"`, `"median"`.
- **`as_index=False`** оставляет группы обычным столбцом, что удобно для графиков и объединения таблиц. `reset_index(drop=True)` заново нумерует строки с 0.

Группировать можно и по нескольким столбцам: `sales.groupby(["city", "item"])["qty"].sum()`.

## Объединение таблиц с merge

Данные часто лежат в нескольких таблицах (tables). Допустим, во второй таблице записан **управляющий** каждого кафе. **`pd.merge()`** объединяет два DataFrame по общему столбцу — совсем как `JOIN` в SQL:

<CodeExample output={`        city  revenue manager
0  Edinburgh     17.5     Ana
1     London      6.4     NaN
2     Vienna     16.0   Felix
        city  revenue manager
0  Edinburgh     17.5     Ana
1     Vienna     16.0   Felix`}>

```python
import pandas as pd

revenue = pd.DataFrame({
    "city": ["Edinburgh", "London", "Vienna"],
    "revenue": [17.5, 6.4, 16.0],
})
managers = pd.DataFrame({
    "city": ["Vienna", "Edinburgh", "Paris"],
    "manager": ["Felix", "Ana", "Chloé"],
})

print(pd.merge(revenue, managers, on="city", how="left"))
print(pd.merge(revenue, managers, on="city"))   # how="inner"
```

</CodeExample>

Аргумент **`how`** решает, какие строки останутся:

- **`"inner"`** (по умолчанию) оставляет только города, которые есть в **обеих** таблицах, поэтому London и Paris исчезают.
- **`"left"`** оставляет **все** строки левой таблицы и заполняет пробелы значением `NaN`. У London пока нет управляющего.
- `"right"` и `"outer"` работают так же для правой таблицы или для обеих таблиц.

<Callout type="warning" title="Очистите ключ перед merge">

`merge` сравнивает значения **точно**. Если в одной таблице написано `"Edinburgh "` с пробелом в конце, строки не совпадут, и вы молча потеряете данные. Сначала почистите ключевые столбцы через `.str.strip()` (и приведите заглавные буквы к одному виду), а также сравните количество строк до и после объединения.

</Callout>

Фермерский рынок прислал вам журнал продаж, и в нём полный беспорядок. 🍎🥖🧀 Напишите две функции:

1. `clean(df)` возвращает очищенную копию:
   - `stall`: лишние пробелы убраны, регистр — Title Case (`"  fruit"` превращается в `"Fruit"`),
   - `price`: преобразован в числа, а всё, что не является числом (например, `"free"`), становится `NaN`,
   - строки с пропущенной ценой `price` удалены,
   - `qty`: пропуски заполнены значением `0`, затем столбец преобразован в `int`,
   - `date`: преобразован в настоящие даты.
2. `revenue_by(df, column)` возвращает **словарь** с общей выручкой (`price * qty`) для каждого значения `column`, округлённой до 2 знаков после запятой. Для очищенных палаток `revenue_by(stalls, "stall")` равно `{'Bakery': 0.0, 'Cheese': 3.8, 'Fruit': 9.3}`.

<Hint>

Начните `clean` с `df = df.copy()`, чтобы не менять оригинал, а затем повторите шаги из урока: `df["stall"].str.strip().str.title()`, `pd.to_numeric(df["price"], errors="coerce")`, `df.dropna(subset=["price"])`, `df["qty"].fillna(0).astype(int)` и `pd.to_datetime(df["date"])`. В `revenue_by` создайте Series с выручкой `df["price"] * df["qty"]`, а затем — `revenue.groupby(df[column]).sum().round(2).to_dict()`. (Или добавьте столбец `"revenue"` в копию и сгруппируйте по `column`.)

<Solution>

```python
import io
import pandas as pd

csv_text = """date,stall,product,price,qty
2026-05-02,  fruit,apples,0.40,10
2026-05-02,Bakery,bread,2.10,
2026-05-03,FRUIT,pears,0.55,6
2026-05-03,bakery ,cake,free,2
2026-05-04,Cheese,brie,3.80,1
2026-05-04,fruit,apples,0.40,5
"""
raw = pd.read_csv(io.StringIO(csv_text))

def clean(df):
    df = df.copy()
    df["stall"] = df["stall"].str.strip().str.title()
    df["price"] = pd.to_numeric(df["price"], errors="coerce")
    df = df.dropna(subset=["price"])
    df["qty"] = df["qty"].fillna(0).astype(int)
    df["date"] = pd.to_datetime(df["date"])
    return df

def revenue_by(df, column):
    revenue = df["price"] * df["qty"]
    totals = revenue.groupby(df[column]).sum()
    return totals.round(2).to_dict()

stalls = clean(raw)
print(stalls)
print(revenue_by(stalls, "stall"))
print(revenue_by(stalls, "product"))
```
