In [CSV and JSON](/learn/python/csv-and-json) you read a CSV file row by row and added things up with loops. That works for ten rows, but real data has thousands, and you want answers like *"the average age per zoo"* in one line, not twenty.

That's what **pandas** is for. It's the library data analysts, scientists and backend developers reach for whenever data looks like a table. In this module you'll load, clean, group and chart data, and finish by analysing a real scientific dataset. 🐼📊

## Installing and importing pandas

pandas is a package, so in a real project you install it into your virtual environment (see [pip and virtual environments](/learn/python/pip-and-virtual-environments)):

```bash
pip install pandas matplotlib
```

On PandaDev it's already available. Everyone imports it with the short name **`pd`**, and you'll see this line at the top of almost every data script in the world:

```python
import pandas as pd
```

## Series: one labelled column

A **Series** is a list of values with a **label** (the **index**) for each one. Think of it as a single spreadsheet column:

<CodeExample output={`Mei     98.5
Bao    110.0
Lin     72.0
Name: weight_kg, dtype: float64
98.5
93.5
Mei    0.0985
Bao    0.1100
Lin    0.0720
Name: weight_kg, dtype: float64`}>

```python
import pandas as pd

weights = pd.Series(
    [98.5, 110.0, 72.0],
    index=["Mei", "Bao", "Lin"],
    name="weight_kg",
)
print(weights)
print(weights["Mei"])        # look up by label
print(weights.mean())
print(weights / 1000)        # maths on every value at once
```

</CodeExample>

Two things make pandas fast and pleasant:

- Every Series has a **dtype**, the type of all its values (`float64` here). pandas stores them in a compact array instead of separate Python objects.
- Operations are **vectorised**: `weights / 1000` divides every value, no loop needed. Methods like `.mean()`, `.sum()`, `.max()` and `.min()` work on the whole column.

## DataFrame: a whole table

A **DataFrame** is a table: several Series that share the same index, one per column. You can build one from a dict of lists, where each key becomes a column name:

<CodeExample output={`  name        zoo  age
0  Mei  Edinburgh    5
1  Bao     Vienna   12
2  Lin  Edinburgh    3
<class 'pandas.Series'>
[5, 12, 3]`}>

```python
import pandas as pd

df = pd.DataFrame({
    "name": ["Mei", "Bao", "Lin"],
    "zoo": ["Edinburgh", "Vienna", "Edinburgh"],
    "age": [5, 12, 3],
})
print(df)

ages = df["age"]             # one column is a Series
print(type(ages))
print(ages.tolist())
```

</CodeExample>

The numbers on the left (`0`, `1`, `2`) are the **index**. If you don't give one, pandas numbers the rows from 0. By convention a DataFrame variable is called **`df`**.

## Reading CSV data

Most data arrives as a file. **`pd.read_csv()`** reads a CSV, uses the first line as column names and works out the types for you. In a real project you'd pass a file name:

```python
df = pd.read_csv("pandas.csv")
```

In these lessons we keep the CSV as text inside the code and wrap it in **`io.StringIO`**, which makes a string behave like an open file:

<CodeExample output={`   name         zoo  age  weight_kg
0   Mei   Edinburgh    5       98.5
1   Bao      Vienna   12      110.0
2   Lin   Edinburgh    3       72.0
3  Tian  Washington    8      121.5
4  Yuan      Vienna   16      105.0
5    Xi  Washington    2       60.5`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""

df = pd.read_csv(io.StringIO(csv_text))
print(df)
```

</CodeExample>

Compare that with the `csv` module: no `newline=""`, no `int()` calls, no loop. The numbers are already numbers.

## A first look at the data

With a new dataset, pros always start with the same quick checks: how big is it, what do the first rows look like, and did every column get the right type?

<CodeExample output={`(6, 4)
  name        zoo  age  weight_kg
0  Mei  Edinburgh    5       98.5
1  Bao     Vienna   12      110.0
['name', 'zoo', 'age', 'weight_kg']
name             str
zoo              str
age            int64
weight_kg    float64
dtype: object`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

print(df.shape)              # (rows, columns)
print(df.head(2))            # first rows (5 by default)
print(df.columns.tolist())
print(df.dtypes)
```

</CodeExample>

- **`shape`** is a tuple `(rows, columns)`. Note: no brackets, it's an attribute, not a method.
- **`head(n)`** shows the first `n` rows, and **`tail(n)`** the last ones. With big data, never just `print(df)`.
- **`dtypes`** shows each column's type: `int64` for whole numbers, `float64` for decimals and `str` for text.

**`describe()`** gives a statistical summary of every number column at once:

<CodeExample output={`             age   weight_kg
count   6.000000    6.000000
mean    7.666667   94.583333
std     5.465040   23.484924
min     2.000000   60.500000
25%     3.500000   78.625000
50%     6.500000  101.750000
75%    11.000000  108.750000
max    16.000000  121.500000`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

print(df.describe())
```

</CodeExample>

`count`, `mean`, `min` and `max` are what they sound like. `std` (standard deviation) measures how spread out the values are, and `50%` is the **median**: half the values are below it.

<Callout type="tip" title="Check the dtypes first">

If a column of numbers shows up as `str`, something in the file isn't a number: a typo, a `"n/a"`, a `£` sign. Maths on it will fail or give nonsense. Spotting this early saves hours; you'll learn to fix it in the next lesson.

</Callout>

## Selecting columns

Use square brackets with **one name** to get a Series, or with a **list of names** to get a smaller DataFrame:

<CodeExample output={`0     Mei
1     Bao
2     Lin
3    Tian
4    Yuan
5      Xi
Name: name, dtype: str
   name  age
0   Mei    5
1   Bao   12
2   Lin    3
3  Tian    8
4  Yuan   16
5    Xi    2
94.58333333333333`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

print(df["name"])                 # a Series
print(df[["name", "age"]])        # a DataFrame (note [[ ]])
print(df["weight_kg"].mean())
```

</CodeExample>

The double brackets look odd at first: the outer ones mean "select", the inner ones are a normal Python list of column names.

## Filtering rows

Comparing a column with a value gives a Series of `True`/`False`, one per row. Put that inside `df[...]` and pandas keeps only the `True` rows. This is called **boolean filtering** (or **boolean indexing**):

<CodeExample output={`0    False
1     True
2    False
3    False
4     True
5    False
Name: age, dtype: bool
   name     zoo  age  weight_kg
1   Bao  Vienna   12      110.0
4  Yuan  Vienna   16      105.0
   name         zoo  age  weight_kg
3  Tian  Washington    8      121.5
   name        zoo  age  weight_kg
0   Mei  Edinburgh    5       98.5
1   Bao     Vienna   12      110.0
2   Lin  Edinburgh    3       72.0
4  Yuan     Vienna   16      105.0`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

print(df["age"] > 10)
print(df[df["age"] > 10])

# Combine conditions with & (and), | (or), ~ (not)
print(df[(df["age"] > 5) & (df["weight_kg"] > 110)])

print(df[df["zoo"].isin(["Edinburgh", "Vienna"])])
```

</CodeExample>

Notice that the filtered rows **keep their original index** (`1`, `4`), so you can always tell where a row came from.

<Callout type="warning" title="Use &, | and brackets, not and/or">

Inside a filter, write `&`, `|` and `~` instead of `and`, `or` and `not`, and put **each condition in brackets**. `df[df["age"] > 5 and df["zoo"] == "Vienna"]` raises *"The truth value of a Series is ambiguous"*, because Python's `and` wants one `True` or `False`, not a whole column of them.

</Callout>

## loc and iloc

Square brackets are a shortcut. For precise selection, pandas has two **indexers**:

- **`df.loc[rows, columns]`** selects by **label**: index labels and column names.
- **`df.iloc[rows, columns]`** selects by **position**: 0, 1, 2... like a list.

<CodeExample output={`Bao
   name  age
1   Bao   12
2   Lin    3
3  Tian    8
   name  weight_kg
1   Bao      110.0
4  Yuan      105.0
name               Mei
zoo          Edinburgh
age                  5
weight_kg         98.5
Name: 0, dtype: object
   name         zoo
4  Yuan      Vienna
5    Xi  Washington`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

print(df.loc[1, "name"])               # one value
print(df.loc[1:3, ["name", "age"]])    # labels 1 to 3 INCLUDED
print(df.loc[df["age"] > 10, ["name", "weight_kg"]])

print(df.iloc[0])                      # first row, as a Series
print(df.iloc[-2:, :2])                # last 2 rows, first 2 cols
```

</CodeExample>

`loc` also takes a boolean filter for the rows, which lets you filter and pick columns in one step. One gotcha: **`loc` slices include the end label** (`1:3` gives 1, 2 and 3), while `iloc` slices work like Python lists and exclude the end.

## Sorting

**`sort_values()`** sorts by one or more columns. It returns a **new** DataFrame; the original stays as it was:

<CodeExample output={`   name         zoo  age
4  Yuan      Vienna   16
1   Bao      Vienna   12
3  Tian  Washington    8
   name         zoo  weight_kg
0   Mei   Edinburgh       98.5
2   Lin   Edinburgh       72.0
1   Bao      Vienna      110.0
4  Yuan      Vienna      105.0
3  Tian  Washington      121.5
5    Xi  Washington       60.5`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

oldest = df.sort_values("age", ascending=False)
print(oldest[["name", "zoo", "age"]].head(3))

by_zoo = df.sort_values(["zoo", "weight_kg"],
                        ascending=[True, False])
print(by_zoo[["name", "zoo", "weight_kg"]])
```

</CodeExample>

"Top 3" questions are just `sort_values(..., ascending=False).head(3)`. (pandas also has `nlargest(3, "age")` as a shortcut.)

## Adding new columns

Assign to a new column name and pandas calculates it **for every row**:

<CodeExample output={`   name  weight_kg  weight_lb  is_adult
0   Mei       98.5      217.2      True
1   Bao      110.0      242.5      True
2   Lin       72.0      158.7     False
3  Tian      121.5      267.9      True
4  Yuan      105.0      231.5      True
5    Xi       60.5      133.4     False`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

df["weight_lb"] = (df["weight_kg"] * 2.2046).round(1)
df["is_adult"] = df["age"] >= 4
print(df[["name", "weight_kg", "weight_lb", "is_adult"]])
```

</CodeExample>

To change some values in place, use `loc` with a filter on the left: `df.loc[df["zoo"] == "Vienna", "zoo"] = "Wien"`.

<Callout type="note" title="Copies, not views (pandas 3)">

A filtered DataFrame like `df[df["age"] > 10]` is its **own copy** (pandas calls this *copy-on-write*). Changing it never changes `df`. That's why "chained" assignment such as `df[df["age"] > 10]["zoo"] = "Wien"` does **nothing** to `df`: you changed a temporary copy. Always change the original in one step with `df.loc[filter, "column"] = value`. Older tutorials show a `SettingWithCopyWarning` here; pandas 3 removed that confusion.

</Callout>

## Why not just loop?

You *can* loop over rows with `for index, row in df.iterrows():`, and sometimes you'll see it. But it's slow (each row becomes a new Series) and long. If you catch yourself writing a loop over a DataFrame, there's almost always a vectorised way: column maths, a filter, or one of the methods from the next lesson. Thinking in **whole columns** is the big mindset change of pandas.

```python
import io
import pandas as pd

csv_text = """item,price,qty
bamboo shoots,2.5,4
leaf tea,4.0,1
panda plush,12.0,2
bamboo sticks,1.5,10
sticker pack,3.0,3
"""
orders = pd.read_csv(io.StringIO(csv_text))

def add_total(df):
    df["total"] = df["price"] * df["qty"]
    return df

def big_orders(df, minimum):
    big = df[df["total"] >= minimum]
    return big.sort_values("total", ascending=False)

def cheapest_item(df):
    return df.sort_values("price")["item"].iloc[0]

orders = add_total(orders)
print(orders)
print(big_orders(orders, 10))
print(cheapest_item(orders))
```

## Recap

- `import pandas as pd`. A **Series** is one labelled column; a **DataFrame** is a table of Series sharing an **index**.
- `pd.read_csv()` reads CSV (a file name, or `io.StringIO(text)`) and detects types for you.
- First look: `shape`, `head()`, `dtypes`, `describe()`.
- `df["col"]` gives a Series, `df[["a", "b"]]` a smaller DataFrame.
- Filter with `df[condition]`, combining conditions with `&`, `|`, `~` and brackets; `isin()` checks against a list.
- `loc` selects by label (slices include the end), `iloc` by position.
- `sort_values()` returns a sorted copy; `df["new"] = ...` adds a column calculated for every row.
- Change values with `df.loc[filter, "col"] = value`, never with chained brackets. Think in whole columns, not loops.
