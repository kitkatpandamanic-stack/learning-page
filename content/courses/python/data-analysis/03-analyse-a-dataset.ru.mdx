Пора побыть настоящим аналитиком данных. 🐧 В этом мини-проекте вы исследуете набор данных (dataset) **Palmer Penguins**: измерения настоящих пингвинов, которые собрали доктор Кристен Горман и программа долгосрочных экологических исследований станции Палмер в Антарктиде с 2007 по 2009 год. Специалисты по данным очень любят его для практики, и пользоваться им можно бесплатно (лицензия CC0).

В полном наборе 344 пингвина трёх видов: **Adelie** (Адели), **Gentoo** (папуанский пингвин) и **Chinstrap** (антарктический пингвин). Мы возьмём срез из 22 особей, записанный как CSV-текст, вместе с **пропущенными значениями (missing values)**, которые есть в настоящих данных.

## Как устроен анализ

Профессиональный анализ проходит примерно одни и те же шаги, и мы тоже по ним пойдём:

1. **Задать вопросы.** Что вы хотите узнать?
2. **Загрузить и осмотреть** данные: размер, типы, пропуски.
3. **Очистить** их, записывая каждое принятое решение.
4. **Проанализировать**: отфильтровать, сгруппировать и посчитать.
5. **Визуализировать** ответы на графиках.
6. **Сделать выводы** — честно, в том числе о том, чего данные сказать *не могут*.

Наши вопросы:

- Сколько у нас пингвинов каждого вида и где они живут?
- Какой вид самый тяжёлый?
- Тяжелее ли самцы, чем самки?
- Отличается ли у видов форма клюва?
- Весят ли пингвины с более длинными ластами больше?

Каждый пример кода ниже повторяет данные, чтобы его можно было запустить отдельно; строки CSV смело пролистывайте.

## Очищаем

Наши решения — в настоящем отчёте мы бы их записали:

- Пингвин без измерений не поможет ответить ни на один наш вопрос, поэтому мы его **удаляем**.

- Массу тела удобнее читать в килограммах, поэтому добавляем столбец `body_mass_kg`.

    mean_kg=("body_mass_kg", "mean"),
    max_kg=("body_mass_kg", "max"),
)
print(summary.sort_values("mean_kg", ascending=False).round(2))

known = df[df["sex"] != "unknown"]
by_sex = known.groupby(["species", "sex"])["body_mass_kg"].mean()
print(by_sex.unstack().round(2))

def load_penguins(text):
    df = pd.read_csv(io.StringIO(text))
    df = df.dropna(subset=["body_mass_g"])
    df["sex"] = df["sex"].fillna("unknown")
    return df

def species_counts(df):
    return df["species"].value_counts().to_dict()

def mean_mass(df):
    means = df.groupby("species")["body_mass_g"].mean()
    return means.round(1).to_dict()

def heaviest_species(df):
    means = df.groupby("species")["body_mass_g"].mean()
    return means.idxmax()

def species_on(df, island):
    on_island = df[df["island"] == island]
    return sorted(on_island["species"].unique())
