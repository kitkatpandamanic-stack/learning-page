В уроке [CSV и JSON](/learn/python/csv-and-json) вы читали CSV-файл построчно и складывали значения в циклах. Для десяти строк это работает, но в реальных данных их тысячи, и на вопрос вроде *«средний возраст в каждом зоопарке»* хочется отвечать одной строкой, а не двадцатью.

Для этого и нужна **pandas**. Это библиотека, за которой аналитики данных, учёные и бэкенд-разработчики тянутся всякий раз, когда данные похожи на таблицу. В этом модуле вы будете загружать, чистить, группировать данные и строить графики, а в конце проанализируете настоящий научный набор данных (dataset). 🐼📊

## Установка и импорт pandas

pandas — это пакет (package), поэтому в реальном проекте вы устанавливаете его в своё виртуальное окружение (см. [pip и виртуальные окружения](/learn/python/pip-and-virtual-environments)):

```bash
pip install pandas matplotlib
```

На PandaDev она уже доступна. Все импортируют её под коротким именем **`pd`**, и эту строку вы увидите в начале почти любого скрипта для работы с данными в мире:

```python
import pandas as pd
```

## Series: один столбец с метками

**Series** — это список значений, у каждого из которых есть **метка (label)**, или **индекс (index)**. Представьте себе один столбец электронной таблицы:

<CodeExample output={`Mei     98.5
Bao    110.0
Lin     72.0
Name: weight_kg, dtype: float64
98.5
93.5
Mei    0.0985
Bao    0.1100
Lin    0.0720
Name: weight_kg, dtype: float64`}>

```python
import pandas as pd

weights = pd.Series(
    [98.5, 110.0, 72.0],
    index=["Mei", "Bao", "Lin"],
    name="weight_kg",
)
print(weights)
print(weights["Mei"])        # поиск по метке
print(weights.mean())
print(weights / 1000)        # вычисления сразу над всеми значениями
```

</CodeExample>

Две вещи делают pandas быстрой и удобной:

- У каждой Series есть **dtype** — тип всех её значений (здесь `float64`). pandas хранит их в компактном массиве, а не как отдельные объекты Python.
- Операции **векторизованы (vectorised)**: `weights / 1000` делит каждое значение, и цикл не нужен. Методы `.mean()`, `.sum()`, `.max()` и `.min()` работают со всем столбцом сразу.

## DataFrame: целая таблица

**DataFrame** — это таблица: несколько Series с общим индексом, по одной на каждый столбец (column). Её можно собрать из словаря списков, где каждый ключ становится именем столбца:

<CodeExample output={`  name        zoo  age
0  Mei  Edinburgh    5
1  Bao     Vienna   12
2  Lin  Edinburgh    3
<class 'pandas.Series'>
[5, 12, 3]`}>

```python
import pandas as pd

df = pd.DataFrame({
    "name": ["Mei", "Bao", "Lin"],
    "zoo": ["Edinburgh", "Vienna", "Edinburgh"],
    "age": [5, 12, 3],
})
print(df)

ages = df["age"]             # один столбец — это Series
print(type(ages))
print(ages.tolist())
```

</CodeExample>

Числа слева (`0`, `1`, `2`) — это **индекс**. Если вы его не задали, pandas нумерует строки (rows) с 0. По соглашению переменную с DataFrame называют **`df`**.

## Чтение CSV

Чаще всего данные приходят в виде файла. **`pd.read_csv()`** читает CSV, берёт первую строку как имена столбцов и сама определяет типы. В реальном проекте вы передаёте имя файла:

```python
df = pd.read_csv("pandas.csv")
```

В этих уроках мы держим CSV как текст прямо в коде и оборачиваем его в **`io.StringIO`** — так строка ведёт себя как открытый файл:

<CodeExample output={`   name         zoo  age  weight_kg
0   Mei   Edinburgh    5       98.5
1   Bao      Vienna   12      110.0
2   Lin   Edinburgh    3       72.0
3  Tian  Washington    8      121.5
4  Yuan      Vienna   16      105.0
5    Xi  Washington    2       60.5`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""

print(df)
```

</CodeExample>

Сравните с модулем `csv`: ни `newline=""`, ни вызовов `int()`, ни цикла. Числа уже являются числами.

## Первый взгляд на данные

Получив новый набор данных, профессионалы всегда начинают с одних и тех же быстрых проверок: какого он размера, как выглядят первые строки и получил ли каждый столбец правильный тип?

<CodeExample output={`(6, 4)
  name        zoo  age  weight_kg

1  Bao     Vienna   12      110.0
['name', 'zoo', 'age', 'weight_kg']
name             str
zoo              str
age            int64
weight_kg    float64
dtype: object`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
```

## Фильтрация строк

Сравнение столбца со значением даёт Series из `True`/`False`, по одному на строку. Поместите её внутрь `df[...]`, и pandas оставит только строки с `True`. Это называется **логической фильтрацией (boolean filtering)**, или **логической индексацией (boolean indexing)**:

<CodeExample output={`0    False
1     True
2    False
3    False
4     True
5    False
Name: age, dtype: bool
   name     zoo  age  weight_kg
1   Bao  Vienna   12      110.0
4  Yuan  Vienna   16      105.0
   name         zoo  age  weight_kg
3  Tian  Washington    8      121.5
   name        zoo  age  weight_kg
0   Mei  Edinburgh    5       98.5
1   Bao     Vienna   12      110.0
2   Lin  Edinburgh    3       72.0
4  Yuan     Vienna   16      105.0`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

print(df["age"] > 10)
print(df[df["age"] > 10])

# Условия объединяются через & (и), | (или), ~ (не)
print(df[(df["age"] > 5) & (df["weight_kg"] > 110)])

print(df[df["zoo"].isin(["Edinburgh", "Vienna"])])
```

</CodeExample>

Заметьте, что отфильтрованные строки **сохраняют исходный индекс** (`1`, `4`), так что всегда видно, откуда взялась строка.

<Callout type="warning" title="Пишите &, | и скобки, а не and/or">

Внутри фильтра пишите `&`, `|` и `~` вместо `and`, `or` и `not` и заключайте **каждое условие в скобки**. `df[df["age"] > 5 and df["zoo"] == "Vienna"]` вызывает ошибку *«The truth value of a Series is ambiguous»*, потому что `and` в Python ожидает одно значение `True` или `False`, а не целый столбец таких значений.

</Callout>

## loc и iloc

Квадратные скобки — это сокращение. Для точного выбора в pandas есть два **индексатора (indexers)**:

- **`df.loc[rows, columns]`** выбирает по **меткам**: меткам индекса и именам столбцов.
- **`df.iloc[rows, columns]`** выбирает по **позиции**: 0, 1, 2... как в списке.

<CodeExample output={`Bao
   name  age
1   Bao   12
2   Lin    3
3  Tian    8
   name  weight_kg
1   Bao      110.0
4  Yuan      105.0
name               Mei
zoo          Edinburgh
age                  5
weight_kg         98.5
Name: 0, dtype: object
   name         zoo
4  Yuan      Vienna
5    Xi  Washington`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

print(df.loc[1, "name"])               # одно значение
print(df.loc[1:3, ["name", "age"]])    # метки с 1 по 3 ВКЛЮЧИТЕЛЬНО
print(df.loc[df["age"] > 10, ["name", "weight_kg"]])

print(df.iloc[0])                      # первая строка в виде Series
print(df.iloc[-2:, :2])                # последние 2 строки, первые 2 столбца
```

</CodeExample>

`loc` принимает для строк и логический фильтр, так что можно отфильтровать строки и выбрать столбцы за один шаг. Одна ловушка: **срезы `loc` включают конечную метку** (`1:3` даёт 1, 2 и 3), а срезы `iloc` работают как у списков Python и конец не включают.

## Сортировка

**`sort_values()`** сортирует по одному или нескольким столбцам. Метод возвращает **новый** DataFrame, а исходный остаётся без изменений:

<CodeExample output={`   name         zoo  age
4  Yuan      Vienna   16
1   Bao      Vienna   12
3  Tian  Washington    8
   name         zoo  weight_kg
0   Mei   Edinburgh       98.5
2   Lin   Edinburgh       72.0
1   Bao      Vienna      110.0
4  Yuan      Vienna      105.0
3  Tian  Washington      121.5
5    Xi  Washington       60.5`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

oldest = df.sort_values("age", ascending=False)
print(oldest[["name", "zoo", "age"]].head(3))

by_zoo = df.sort_values(["zoo", "weight_kg"],
                        ascending=[True, False])
print(by_zoo[["name", "zoo", "weight_kg"]])
```

</CodeExample>

Вопросы вида «топ-3» — это просто `sort_values(..., ascending=False).head(3)`. (В pandas есть и сокращение `nlargest(3, "age")`.)

## Добавление новых столбцов

Присвойте значение новому имени столбца, и pandas вычислит его **для каждой строки**:

<CodeExample output={`   name  weight_kg  weight_lb  is_adult
0   Mei       98.5      217.2      True
1   Bao      110.0      242.5      True
2   Lin       72.0      158.7     False
3  Tian      121.5      267.9      True
4  Yuan      105.0      231.5      True
5    Xi       60.5      133.4     False`}>

```python
import io
import pandas as pd

csv_text = """name,zoo,age,weight_kg
Mei,Edinburgh,5,98.5
Bao,Vienna,12,110.0
Lin,Edinburgh,3,72.0
Tian,Washington,8,121.5
Yuan,Vienna,16,105.0
Xi,Washington,2,60.5
"""
df = pd.read_csv(io.StringIO(csv_text))

df["weight_lb"] = (df["weight_kg"] * 2.2046).round(1)
df["is_adult"] = df["age"] >= 4
print(df[["name", "weight_kg", "weight_lb", "is_adult"]])
```

</CodeExample>

Чтобы изменить часть значений на месте, используйте `loc` с фильтром слева от `=`: `df.loc[df["zoo"] == "Vienna", "zoo"] = "Wien"`.

<Callout type="note" title="Копии, а не представления (pandas 3)">

Отфильтрованный DataFrame вроде `df[df["age"] > 10]` — это **отдельная копия** (pandas называет это *copy-on-write*, «копирование при записи»). Её изменение никогда не меняет `df`. Поэтому «цепочечное» присваивание вроде `df[df["age"] > 10]["zoo"] = "Wien"` **ничего** не делает с `df`: вы изменили временную копию. Всегда меняйте оригинал за один шаг: `df.loc[filter, "column"] = value`. В старых руководствах здесь появляется `SettingWithCopyWarning`; в pandas 3 эту путаницу убрали.

</Callout>

## Почему бы просто не написать цикл?

*Можно* перебирать строки через `for index, row in df.iterrows():`, и иногда вы такое встретите. Но это медленно (каждая строка превращается в новую Series) и многословно. Если вы поймали себя на цикле по DataFrame, почти всегда есть векторизованный способ: вычисления над столбцами, фильтр или один из методов из следующего урока. Мыслить **целыми столбцами** — вот главный сдвиг в мышлении, который требует pandas.

```python
import io
import pandas as pd

csv_text = """item,price,qty
bamboo shoots,2.5,4
leaf tea,4.0,1
panda plush,12.0,2
bamboo sticks,1.5,10
sticker pack,3.0,3
"""
orders = pd.read_csv(io.StringIO(csv_text))

def add_total(df):
    df["total"] = df["price"] * df["qty"]
    return df

def big_orders(df, minimum):
    big = df[df["total"] >= minimum]
    return big.sort_values("total", ascending=False)

def cheapest_item(df):
    return df.sort_values("price")["item"].iloc[0]

orders = add_total(orders)
print(orders)
print(big_orders(orders, 10))
print(cheapest_item(orders))
```

## Итоги

- `import pandas as pd`. **Series** — это один столбец с метками; **DataFrame** — таблица из Series с общим **индексом**.
- `pd.read_csv()` читает CSV (имя файла или `io.StringIO(text)`) и сама определяет типы.
- Первый взгляд: `shape`, `head()`, `dtypes`, `describe()`.
- `df["col"]` даёт Series, `df[["a", "b"]]` — DataFrame поменьше.
- Фильтруйте через `df[условие]`, объединяя условия с помощью `&`, `|`, `~` и скобок; `isin()` проверяет вхождение в список.
- `loc` выбирает по меткам (срезы включают конец), `iloc` — по позиции.
- `sort_values()` возвращает отсортированную копию; `df["new"] = ...` добавляет столбец, вычисленный для каждой строки.
- Меняйте значения через `df.loc[filter, "col"] = value`, а не цепочкой скобок. Мыслите целыми столбцами, а не циклами.
