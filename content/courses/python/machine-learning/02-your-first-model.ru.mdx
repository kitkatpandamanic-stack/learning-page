«Машинное обучение» звучит как магия, но его главная идея умещается в одно предложение: вместо того чтобы писать правила самому, вы показываете компьютеру **примеры** и позволяете ему **найти правила**. В этом уроке вы обучите две настоящие модели с помощью **scikit-learn** — самой популярной библиотеки машинного обучения для Python: одна предсказывает стоимость аренды квартиры, другая узнаёт цветы. 🌸

## Что такое машинное обучение?

Допустим, вам нужна функция, которая оценивает месячную аренду квартиры. Классический способ — написать правило самому:

```python
def estimate_rent(size_m2):
    return 300 + 15 * size_m2      # откуда взялись 300 и 15?
```

Но откуда взять эти числа? Пришлось бы изучать рынок и гадать. Машинное обучение (machine learning) переворачивает подход: вы собираете **примеры** (квартиры, аренда которых известна), а алгоритм **подбирает** числа, которые лучше всего подходят к примерам. Результат — **модель (model)** — это просто функция, которую за вас написал кто-то другой (алгоритм).

Это называется **обучением с учителем (supervised learning)**: к каждому примеру прилагается правильный ответ, как будто учитель проверяет домашнюю работу. Так устроена большая часть машинного обучения в реальном мире, и именно об этом модуль. (Его «родственник», **обучение без учителя (unsupervised learning)**, находит группы и закономерности в данных без всяких ответов — например, группирует покупателей по тому, как они делают покупки.)

## Признаки и метки

У каждой задачи обучения с учителем две одинаковые части:

- **Признаки (features)**: то, что вы знаете о каждом примере (площадь квартиры, расстояние до центра...). По соглашению их хранят в двумерной таблице с именем **`X`** (с заглавной буквы, потому что это матрица): одна **строка на пример**, один **столбец на признак**.
- **Метки (labels)**, или **целевая переменная (target)**: ответ, который нужно предсказать (аренда). Их хранят в одномерном массиве с именем **`y`** — по одному значению на каждую строку `X`.

<CodeExample output={`(8, 2) (8,)
   size_m2  km_to_centre
0       30             1
1       38             5
2       45             2`}>

```python
import pandas as pd

flats = pd.DataFrame({
    "size_m2": [30, 38, 45, 52, 60, 68, 75, 85],
    "km_to_centre": [1, 5, 2, 8, 3, 10, 4, 6],
    "rent": [950, 880, 1080, 1000, 1300, 1150, 1500, 1600],
})
X = flats[["size_m2", "km_to_centre"]]    # 2-D: признаки
y = flats["rent"]                         # 1-D: метки
print(X.shape, y.shape)
print(X.head(3))
```

</CodeExample>

Каждая строка — это один **образец (sample)** (одна квартира). Двойные скобки в `flats[["size_m2", "km_to_centre"]]` выбирают DataFrame (двумерный), а одинарные дают Series (одномерную) — в этом и есть разница между `X` и `y`.

## Регрессия или классификация?

Тип метки, которую вы предсказываете, определяет тип задачи:

- **Регрессия (regression)**: метка — **число** на шкале. Аренда, завтрашняя температура, цена дома, сколько минут займёт доставка.
- **Классификация (classification)**: метка — **категория** из фиксированного набора. Спам или не спам, к какому виду относится цветок, какая цифра на картинке, мошеннический ли платёж.

«Сколько?» означает регрессию; «какой именно?» или «да или нет?» — классификацию. Для каждого типа подходят разные модели, но, как вы увидите, в scikit-learn все они используются одинаково.

## Рецепт scikit-learn

scikit-learn — пакет как любой другой (`pip install scikit-learn`; на PandaDev он уже готов к работе), и импортируется он как **`sklearn`**. Каждая модель следует одним и тем же трём шагам:

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()      # 1. выбрать модель (и её настройки)
model.fit(X, y)                 # 2. обучиться на примерах
model.predict(X_new)            # 3. предсказать для новых данных
```

Выучите этот рецепт один раз — и сможете пользоваться десятками моделей: заменить один алгоритм на другой обычно можно, поменяв одну строку. В scikit-learn модели называются **оценщиками (estimators)**. Шаг 2 — обучить (fit), шаг 3 — предсказать (predict).

## Предсказываем аренду линейной регрессией

**Линейная регрессия (linear regression)** находит прямую, которая лучше всего проходит через точки: `аренда = intercept + наклон × площадь`. Обучим её на восьми квартирах, пока только по площади:

<CodeExample output={`[14.38]
336.91
[1056. 1775.]
1056`}>

```python
import numpy as np
from sklearn.linear_model import LinearRegression

sizes = np.array([30, 38, 45, 52, 60, 68, 75, 85])
rents = np.array([780, 900, 950, 1100, 1180, 1320, 1400, 1580])

X = sizes.reshape(-1, 1)        # 8 строк, 1 столбец-признак
model = LinearRegression()
model.fit(X, rents)

print(model.coef_.round(2))     # наклон: £ за каждый лишний м2
print(round(model.intercept_, 2))
print(model.predict([[50], [100]]).round())

# Модель — это просто такая формула:
print(round(model.intercept_ + model.coef_[0] * 50))
```

</CodeExample>

Модель выяснила, что каждый дополнительный квадратный метр добавляет примерно **£14.38** в месяц, а начинается всё примерно с **£337** (это свободный член, intercept). Квартира площадью 50 м² выходит примерно в £1056.

Обратите внимание на три вещи:

- **`X` должен быть двумерным**, даже если признак один. Поэтому мы использовали `reshape(-1, 1)` из [урока про NumPy](/learn/python/numpy-arrays), и поэтому `predict` получает `[[50], [100]]` — список строк, а не `[50, 100]`. Если забыть об этом, получите самую частую ошибку scikit-learn: `Expected a 2D array, got 1D array instead`.
- Атрибуты, которые заканчиваются **подчёркиванием**, например `coef_` и `intercept_`, — это то, что модель **выучила** во время `fit`. До обучения их не существует.
- `predict` для 100 м² даёт около £1775, хотя самая большая квартира у нас — 85 м². Модели охотно отвечают про ситуации, которых никогда не видели, и чем дальше вы уходите от примеров, тем меньше стоит доверять ответу.

## Больше одного признака

Дадим модели ещё и расстояние до центра. Если `X` — это DataFrame, каждый столбец становится одним признаком, и модель выучивает по одному коэффициенту на признак:

<CodeExample output={`size_m2: +15.58
km_to_centre: -39.01
intercept: 490.43
[1191.  918.]`}>

```python
import pandas as pd
from sklearn.linear_model import LinearRegression

flats = pd.DataFrame({
    "size_m2": [30, 38, 45, 52, 60, 68, 75, 85],
    "km_to_centre": [1, 5, 2, 8, 3, 10, 4, 6],
    "rent": [950, 880, 1080, 1000, 1300, 1150, 1500, 1600],
})
X = flats[["size_m2", "km_to_centre"]]
y = flats["rent"]

model = LinearRegression().fit(X, y)
for name, coef in zip(X.columns, model.coef_):
    print(f"{name}: {coef:+.2f}")
print(f"intercept: {model.intercept_:.2f}")

new_flats = pd.DataFrame({
    "size_m2": [50, 50],
    "km_to_centre": [2, 9],
})
print(model.predict(new_flats).round())
```

</CodeExample>

Теперь модель говорит: каждый м² добавляет около £15.58, а каждый километр от центра отнимает около £39.01. Та же квартира в 50 м² в 9 км от центра стоит примерно на £273 дешевле. (`fit` возвращает саму модель, поэтому `LinearRegression().fit(X, y)` работает в одну строку.)

<Callout type="tip" title="Предсказывайте на тех же столбцах, на которых обучали">

Если обучали на DataFrame, предсказывайте на DataFrame с **теми же столбцами в том же порядке**. Передадите обычный список — scikit-learn выведет предупреждение (`X does not have valid feature names`), а если перепутаете порядок столбцов, она этого вообще не заметит и выдаст бессмыслицу. В реальных проектах от этого спасает одна функция, которая строит `X` из сырых данных и используется и для обучения, **и** для предсказаний.

</Callout>

## Классификатор: что это за ирис?

Теперь классификация. В scikit-learn есть несколько небольших знаменитых наборов данных (datasets) для практики. Набор **iris** содержит измерения 150 цветков ириса трёх видов, собранные в 1930-х:

<CodeExample output={`(150, 4) (150,)
['sepal length (cm)', 'sepal width (cm)', 'petal length (cm)', 'petal width (cm)']
[[5.1 3.5 1.4 0.2]
 [4.9 3.  1.4 0.2]]
[0 1 2]
['setosa' 'versicolor' 'virginica']`}>

```python
from sklearn.datasets import load_iris

iris = load_iris()
print(iris.data.shape, iris.target.shape)
print(iris.feature_names)
print(iris.data[:2])
print(iris.target[[0, 50, 100]])
print(iris.target_names)
```

</CodeExample>

`iris.data` — это `X` (150 цветков × 4 измерения в см: длина и ширина чашелистика (sepal) и лепестка (petal)), а `iris.target` — это `y`. Метки — числа 0, 1 и 2, потому что модели работают с числами; `target_names` переводит их обратно в названия видов.

Мы возьмём **метод k ближайших соседей (k-nearest neighbours, KNN)** — самый интуитивный классификатор: чтобы классифицировать новый цветок, найдите `k` самых похожих цветков в обучающих данных (с самыми близкими измерениями) и позвольте им **проголосовать**:

<CodeExample output={`[0 2 2]
['setosa' 'virginica' 'virginica']
[[1.  0.  0. ]
 [0.  0.  1. ]
 [0.  0.4 0.6]]`}>

```python
from sklearn.datasets import load_iris
from sklearn.neighbors import KNeighborsClassifier

iris = load_iris()
model = KNeighborsClassifier(n_neighbors=5)
model.fit(iris.data, iris.target)

new_flowers = [
    [5.0, 3.4, 1.5, 0.2],
    [6.5, 3.0, 5.5, 2.0],
    [6.0, 2.7, 4.9, 1.6],
]
labels = model.predict(new_flowers)
print(labels)
print(iris.target_names[labels])
print(model.predict_proba(new_flowers))
```

</CodeExample>

Ровно тот же рецепт, что и раньше: создать, `fit`, `predict`. Индексирование `target_names` массивом меток превращает числа в названия (приём NumPy: массив позиций выбирает сразу несколько значений).

**`predict_proba`** показывает, насколько модель уверена: по одному столбцу на класс. Первые два цветка — очевидные случаи (все 5 соседей согласны). Третий — пограничный: 2 соседа говорят versicolor, 3 — virginica, поэтому это virginica с вероятностью 0.6. Измените `n_neighbors` — и ответ для этого цветка может поменяться. Настройки вроде `n_neighbors`, которые выбираете **вы** (а не модель выучивает сама), называются **гиперпараметрами (hyperparameters)**.

## Модель, которую можно прочитать: деревья решений

**Дерево решений (decision tree)** выучивает последовательность вопросов «да/нет». Его правила можно напечатать, поэтому видно, что именно оно выучило:

<CodeExample output={`|--- petal width (cm) <= 0.80
|   |--- class: setosa
|--- petal width (cm) >  0.80
|   |--- petal width (cm) <= 1.75
|   |   |--- class: versicolor
|   |--- petal width (cm) >  1.75
|   |   |--- class: virginica

[1]`}>

```python
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier, export_text

iris = load_iris()
tree = DecisionTreeClassifier(max_depth=2, random_state=0)
tree.fit(iris.data, iris.target)

print(export_text(
    tree,
    feature_names=iris.feature_names,
    class_names=list(iris.target_names),
))
print(tree.predict([[6.0, 2.7, 4.9, 1.6]]))
```

</CodeExample>

Дерево обнаружило, что одна только **ширина лепестка** (petal width) хорошо разделяет виды: меньше 0.8 см — это setosa; иначе меньше 1.75 см — versicolor, а больше — virginica. Никто не рассказывал ему про лепестки: оно вывело это само из 150 примеров. `max_depth=2` ограничивает глубину двумя вопросами; `random_state` делает обучение воспроизводимым — как seed для случайных чисел.

Заметьте: дерево относит наш пограничный цветок к классу `1` (versicolor), а KNN сказал virginica. Разные модели — разные ответы. Так какая модель лучше? Это вопрос следующего урока.

<Callout type="warning" title="Не оценивайте модель по её же домашней работе">

Так и хочется проверить модель, предсказав цветы, на которых она обучалась, и посчитав, сколько ответов верны. Но это число слишком оптимистично: модель **видела** эти ответы. Модель с одним ближайшим соседом набрала бы 100%, ведь ближайший сосед каждого цветка — он сам! В следующем уроке вы будете проверять модели правильно — на данных, которых они никогда не видели.

</Callout>

В `name_flowers` `model.predict(flowers)` даёт числа; `load_iris().target_names[labels]` превращает их в названия, а `.tolist()` делает из них список.

```python
import numpy as np
from sklearn.datasets import load_iris
from sklearn.linear_model import LinearRegression
from sklearn.neighbors import KNeighborsClassifier

def fit_line(xs, ys):
    X = np.array(xs).reshape(-1, 1)
    model = LinearRegression().fit(X, ys)
    return round(model.coef_[0], 2), round(model.intercept_, 2)

def train_iris_model(k):
    iris = load_iris()
    model = KNeighborsClassifier(n_neighbors=k)
    return model.fit(iris.data, iris.target)

def name_flowers(model, flowers):
    labels = model.predict(flowers)
    return load_iris().target_names[labels].tolist()

print(fit_line([1, 2, 3, 4], [3, 5, 7, 9]))
model = train_iris_model(5)
print(name_flowers(model, [[5.0, 3.4, 1.5, 0.2], [6.0, 2.7, 4.9, 1.6]]))
```

## Итоги

- **Машинное обучение** выводит функцию из **примеров**, а не из правил, написанных вручную; в **обучении с учителем** у каждого примера есть правильный ответ.
- **Признаки** `X` — двумерная таблица (строка на образец, столбец на признак); **метки** `y` — одномерный массив, по одной на строку.
- **Регрессия** предсказывает число; **классификация** — категорию.
- Каждая модель scikit-learn следует одному рецепту: создать (с **гиперпараметрами**), `fit(X, y)`, `predict(X_new)`.
- `LinearRegression` выучивает `coef_` (по одному на признак) и `intercept_`; выученные атрибуты заканчиваются на `_`.
- `KNeighborsClassifier` устраивает голосование среди ближайших примеров; `predict_proba` показывает, насколько он уверен. `DecisionTreeClassifier` выучивает читаемые правила (`export_text`).
- `X` должен быть двумерным: для одного признака используйте `reshape(-1, 1)` или `[[value]]` и предсказывайте на тех же столбцах, на которых обучали.
- Оценка на обучающих данных слишком оптимистична; проверяйте на новых данных (следующий урок).
