Когда вы отмечаете задачу в приложении со списком дел на телефоне, приложение не сохраняет её только у себя. Оно отправляет через интернет небольшое сообщение на **сервер (server)**, а сервер присылает в ответ своё небольшое сообщение. Набор сообщений, которые понимает сервер, называется его **API** (Application Programming Interface — программный интерфейс приложения). Сайты, мобильные приложения и другие программы общаются с серверами именно так.

В этом модуле вы будете создавать API на **FastAPI** — одном из самых популярных веб-фреймворков для Python. Он быстрый, код на нём получается коротким, и он построен на уже знакомых вам аннотациях типов. К концу модуля у вас будет рабочий **API списка дел**. 🐼

## HTTP за 5 минут

API в вебе говорят на языке **HTTP**. Каждый разговор — это один **запрос (request)** от клиента и один **ответ (response)** от сервера. Запрос, который получает задачу номер 3, выглядит примерно так:

```text
GET /todos/3?include=notes HTTP/1.1
Host: api.example.com
Accept: application/json
```

А вот ответ сервера:

```text
HTTP/1.1 200 OK
Content-Type: application/json

{"id": 3, "title": "Купить бамбук", "done": false}
```

Главные части:

- **Метод (method)**: что вы хотите сделать. `GET` читает, `POST` создаёт, `PUT`/`PATCH` изменяют, `DELETE` удаляет.
- **Путь (path)**: о какой сущности речь, например `/todos/3`. После `?` идут **параметры запроса (query parameters)** (`include=notes`) — дополнительные настройки в виде пар `key=value`.
- **Заголовки (headers)**: дополнительная информация в виде строк `Name: value`, например `Content-Type: application/json` («тело — это JSON»).
- **Код ответа (status code)**: число, которое говорит, чем всё закончилось. Выучите эти несколько кодов наизусть:

| Код | Значение | Когда |
| --- | --- | --- |
| 200 | OK | Всё получилось |
| 201 | Created | `POST` создал что-то новое |
| 204 | No Content | Получилось, но возвращать нечего (часто после `DELETE`) |
| 404 | Not Found | Такой сущности нет |
| 405 | Method Not Allowed | Путь существует, но не с этим методом |
| 422 | Unprocessable Content | Присланные данные некорректны |
| 500 | Internal Server Error | Сервер упал (это баг!) |

Коды на **2** означают успех, на **4** — клиент сделал что-то не так, а на **5** — ошибся сервер.

- **Тело (body)**: сами данные, в API почти всегда в формате **JSON**. Это тот же JSON, с которым вы работали через `json.dumps`.

## REST: существительные в пути, глаголы в методе

Большинство API следуют стилю под названием **REST**. Идея такая: путь называет **ресурс (resource)** (сущность, существительное во множественном числе), а HTTP-метод говорит, что с ним сделать.

| Запрос | Значение |
| --- | --- |
| `GET /todos` | Получить список всех задач |
| `POST /todos` | Создать новую задачу |
| `GET /todos/3` | Получить задачу номер 3 |
| `PATCH /todos/3` | Изменить часть задачи 3 |
| `DELETE /todos/3` | Удалить задачу 3 |

Пути вроде `/getTodos` или `/deleteTodo?id=3` работают, но глагол в них стоит не на своём месте. Пути в стиле REST предсказуемы: разобравшись с одним ресурсом, вы легко угадаете остальные.

## Первое приложение на FastAPI

Вот полноценный API с одним **эндпоинтом (endpoint)** — одной парой «метод + путь», на которую отвечает сервер:

<CodeExample output={`200
{'message': 'Привет от PandaDev!'}
application/json`}>

```python
from fastapi import FastAPI
from fastapi.testclient import TestClient

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Привет от PandaDev!"}

client = TestClient(app)
response = client.get("/")
print(response.status_code)
print(response.json())
print(response.headers["content-type"])
```

</CodeExample>

Разберём по шагам:

- `app = FastAPI()` создаёт приложение.
- `@app.get("/")` — это **декоратор (decorator)**: он регистрирует `home` как функцию, которую нужно вызвать для `GET /`. Такие функции называют **операциями пути (path operations)** или **эндпоинтами**.
- Вы возвращаете обычный словарь, а FastAPI превращает его в JSON-ответ с кодом 200.
- `TestClient(app)` — это «ненастоящий браузер». `client.get("/")` отправляет запрос прямо в ваше приложение (сеть не нужна) и возвращает ответ с `.status_code`, `.json()` и `.headers`.

В реальных проектах приложения на FastAPI **тестируют** именно через `TestClient`, поэтому вы будете пользоваться им на протяжении всего модуля.

## Запускаем настоящий сервер

На своём компьютере вы бы сохранили приложение в файл `main.py` и запустили настоящий веб-сервер:

```bash
pip install "fastapi[standard]"
fastapi dev main.py
```

FastAPI выведет адрес `http://127.0.0.1:8000`. Откройте его в браузере — и увидите `{"message":"Привет от PandaDev!"}`. Режим `dev` перезапускает сервер каждый раз, когда вы сохраняете файл. Для продакшена вместо него используют `fastapi run main.py`.

<Callout type="note" title="Чтобы учиться, сервер не нужен">

Уроки на этом сайте не могут открывать сетевые порты, поэтому мы вызываем приложение через `TestClient`. Это не упрощение: код вашего приложения остаётся точно таким же, и профессиональные наборы тестов делают ровно это. Настоящий сервер добавляет только одно — прослушивание порта.

</Callout>

## Параметры пути

Напишите имя в фигурных скобках прямо в пути, и FastAPI передаст эту часть URL в вашу функцию как аргумент с тем же именем. Добавьте **аннотацию типа (type hint)** — и FastAPI сам преобразует значение:

<CodeExample output={`{'name': 'Mei', 'greeting': 'Привет, Mei!'}
{'number': 7, 'square': 49}
422
Input should be a valid integer, unable to parse string as an integer`}>

```python
from fastapi import FastAPI
from fastapi.testclient import TestClient

app = FastAPI()

@app.get("/pandas/{name}")
def get_panda(name: str):
    return {"name": name, "greeting": f"Привет, {name}!"}

@app.get("/squares/{number}")
def square(number: int):
    return {"number": number, "square": number * number}

client = TestClient(app)
print(client.get("/pandas/Mei").json())
print(client.get("/squares/7").json())

response = client.get("/squares/seven")
print(response.status_code)
print(response.json()["detail"][0]["msg"])
```

</CodeExample>

URL — это просто текст, но благодаря `number: int` FastAPI превратил `"7"` в целое число `7`. Если текст преобразовать нельзя, ваша функция даже не вызывается: FastAPI отвечает кодом **422** и понятным сообщением (оно на английском: «введите корректное целое число»). Аннотации типов здесь не просто документация — они выполняют настоящую работу.

<Callout type="warning" title="Порядок маршрутов важен">

FastAPI проверяет маршруты **в том порядке, в котором вы их написали**, и берёт первый подходящий. Если `@app.get("/users/{username}")` стоит раньше `@app.get("/users/me")`, то `GET /users/me` попадёт в первый маршрут с `username="me"`. Всегда ставьте фиксированные пути вроде `/users/me` **перед** путями с параметрами.

</Callout>

## Параметры запроса

Любой параметр функции, которого **нет** в пути, становится **параметром запроса**. Задайте ему значение по умолчанию, чтобы сделать его необязательным:

<CodeExample output={`['бамбук', 'мёд', 'яблоко']
['бамбук', 'яблоко']
['мёд']
['бамбук', 'яблоко']`}>

```python
from fastapi import FastAPI
from fastapi.testclient import TestClient

app = FastAPI()

SNACKS = [
    {"name": "бамбук", "price": 2, "vegan": True},
    {"name": "мёд", "price": 5, "vegan": False},
    {"name": "яблоко", "price": 1, "vegan": True},
]

@app.get("/snacks")
def list_snacks(max_price: int = 100, vegan: bool | None = None):
    result = [s for s in SNACKS if s["price"] <= max_price]
    if vegan is not None:
        result = [s for s in result if s["vegan"] == vegan]
    return [s["name"] for s in result]

client = TestClient(app)
print(client.get("/snacks").json())
print(client.get("/snacks?max_price=2").json())
print(client.get("/snacks?vegan=false").json())
print(client.get("/snacks", params={"max_price": 3, "vegan": True}).json())
```

</CodeExample>

На что стоит обратить внимание:

- `vegan: bool | None = None` означает «необязательный параметр, равный `None`, если его не передали». Так можно отличить «без фильтра» от «отфильтровать по `False`».
- Для `bool` FastAPI понимает `true`/`false` (а также `1`/`0`, `yes`/`no`).
- `params={...}` собирает часть `?key=value&...` за вас — это надёжнее, чем склеивать строки вручную.
- Возвращать можно и список, а не только словарь.

Параметр **без** значения по умолчанию обязателен: если его не передать, получите 422.

## Один путь, разные методы

Метод — часть эндпоинта. `GET /likes` и `POST /likes` — это два разных эндпоинта, а на метод, который вы не определили, сервер ответит **405**:

<CodeExample output={`{'count': 0}
{'count': 2}
405`}>

```python
from fastapi import FastAPI
from fastapi.testclient import TestClient

app = FastAPI()
likes = {"count": 0}

@app.get("/likes")
def read_likes():
    return likes

@app.post("/likes")
def add_like():
    likes["count"] += 1
    return likes

client = TestClient(app)
print(client.get("/likes").json())
client.post("/likes")
client.post("/likes")
print(client.get("/likes").json())
print(client.delete("/likes").status_code)
```

</CodeExample>

`GET` должен только **читать**. Браузеры, кэши и поисковые системы считают, что `GET` можно безопасно повторять, поэтому всё, что меняет данные, должно идти через `POST`, `PATCH`, `PUT` или `DELETE`. В следующем уроке эндпоинты `POST` начнут ещё и получать данные в теле запроса.

## Автоматическая документация на /docs

А вот коронный трюк FastAPI. По вашим аннотациям типов он составляет полное описание API в стандартном формате **OpenAPI** и отдаёт его по адресу `/openapi.json`:

<CodeExample output={`API зоопарка панд
['/pandas/{name}']
Найти одну панду по имени.
name path {'type': 'string', 'title': 'Name'}
hungry query {'type': 'boolean', 'default': False, 'title': 'Hungry'}`}>

```python
from fastapi import FastAPI
from fastapi.testclient import TestClient

app = FastAPI(title="API зоопарка панд")

@app.get("/pandas/{name}")
def get_panda(name: str, hungry: bool = False):
    """Найти одну панду по имени."""
    return {"name": name, "hungry": hungry}

client = TestClient(app)
schema = client.get("/openapi.json").json()
print(schema["info"]["title"])
print(list(schema["paths"]))
operation = schema["paths"]["/pandas/{name}"]["get"]
print(operation["description"])
for param in operation["parameters"]:
    print(param["name"], param["in"], param["schema"])
```

</CodeExample>

FastAPI знает, что `name` — строка в пути, а `hungry` — необязательное логическое значение в строке запроса, и даже использовал вашу строку документации (docstring). Если запустить настоящий сервер и открыть `http://127.0.0.1:8000/docs`, вы увидите интерактивную страницу, построенную по этому описанию: там перечислены все эндпоинты, а кнопка **«Try it out»** позволяет отправлять запросы прямо из браузера. Фронтенд-разработчики это обожают: такая документация никогда не отстаёт от кода.

<Callout type="tip" title="Как профессионалы работают с /docs">

Команды делятся страницей `/docs` (или файлом `openapi.json`) вместо того, чтобы писать документацию к API вручную. По этому описанию инструменты даже умеют генерировать клиентский код на других языках. Хорошие имена, аннотации типов и однострочный docstring у каждого эндпоинта делают сгенерированную документацию по-настоящему полезной.

</Callout>

## Итоги

- HTTP-**запрос** состоит из метода, пути (с необязательными параметрами `?query`), заголовков и тела; у **ответа** есть код ответа, заголовки и тело (обычно JSON).
- Коды ответа: **2xx** — успех (200, 201, 204), **4xx** — ошибки клиента (404, 405, 422), **5xx** — баги на сервере.
- **REST**: существительные во множественном числе в пути (`/todos/3`), действие — в методе (`GET`, `POST`, `PATCH`, `DELETE`).
- `app = FastAPI()` и `@app.get(...)` / `@app.post(...)` объявляют эндпоинты; возвращённые словари и списки превращаются в JSON.
- `{name}` в пути — это **параметр пути**; остальные параметры функции — **параметры запроса**; аннотации типов преобразуют и проверяют их (некорректное значение → **422**).
- `TestClient(app)` вызывает приложение без сервера — так же, как это делают настоящие наборы тестов; `fastapi dev main.py` запускает настоящий сервер с документацией на `/docs`.
