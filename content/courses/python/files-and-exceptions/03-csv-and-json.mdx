Plain text is fine for notes, but real data has **structure**: rows and columns, names and values. Two file formats are everywhere:

- **CSV** (comma-separated values): tables, like a spreadsheet. Every line is a row.
- **JSON** (JavaScript Object Notation): nested data, like Python dictionaries and lists.

Python has a module for each, `csv` and `json`, built right in. 📊

## Writing and reading CSV

A CSV file looks like this:

```text title="scores.csv"
name,score
Mei,92
Sam,78
```

`csv.writer` turns lists into lines, and `csv.reader` turns lines back into lists:

<CodeExample output={`['name', 'score']
['Mei', '92']
['Sam', '78']`}>

```python
import csv

rows = [["name", "score"], ["Mei", 92], ["Sam", 78]]

with open("scores.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerows(rows)

with open("scores.csv", newline="") as file:
    for row in csv.reader(file):
        print(row)
```

</CodeExample>

Two things to notice:

- Always open CSV files with **`newline=""`**. The `csv` module handles line endings itself, and this stops blank rows appearing on Windows.
- We wrote the number `92`, but read back the string `'92'`. **Everything in a CSV is text.**

Why not just use `line.split(",")`? Because real data contains commas, like `"Smith, Jane"`. The `csv` module handles quoting for you.

## DictReader: rows as dictionaries

With **`csv.DictReader`**, the first line becomes the keys and every row becomes a dictionary. Much easier to read than `row[1]`:

<CodeExample output={`{'name': 'Mei', 'score': '92'}
Mei: 92
Sam: 78
Ali: 85
Average: 85.0`}>

```python
import csv

with open("scores.csv", "w", newline="") as file:
    file.write("name,score\nMei,92\nSam,78\nAli,85\n")

with open("scores.csv", newline="") as file:
    rows = list(csv.DictReader(file))

print(rows[0])

total = 0
for row in rows:
    score = int(row["score"])   # text -> number
    total += score
    print(f"{row['name']}: {score}")

print(f"Average: {total / len(rows)}")
```

</CodeExample>

<Callout type="warning" title="Convert your types">

`"92" + "78"` is `"9278"`, not `170`! Convert CSV values with `int()`, `float()` or a check like `row["done"] == "yes"` before doing maths or comparisons. If the data might be messy, wrap the conversion in `try` / `except ValueError`.

</Callout>

## DictWriter: writing dictionaries

**`csv.DictWriter`** does the opposite. Tell it the column names with `fieldnames`, write the header row, then the rows:

<CodeExample output={`title,pages
Dune,412
Matilda,240`}>

```python
import csv
from pathlib import Path

books = [
    {"title": "Dune", "pages": 412},
    {"title": "Matilda", "pages": 240},
]

with open("books.csv", "w", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["title", "pages"])
    writer.writeheader()
    writer.writerows(books)

print(Path("books.csv").read_text())
```

</CodeExample>

## JSON strings: dumps and loads

JSON looks almost exactly like Python dictionaries and lists. **`json.dumps()`** ("dump string") turns Python data into JSON text, and **`json.loads()`** ("load string") turns JSON text back into Python data:

<CodeExample output={`{"name": "Mei", "age": 5, "likes": ["bamboo", "naps"], "sleepy": true}
str
bamboo
6`}>

```python
import json

panda = {
    "name": "Mei",
    "age": 5,
    "likes": ["bamboo", "naps"],
    "sleepy": True,
}

text = json.dumps(panda)
print(text)
print(type(text).__name__)

back = json.loads(text)
print(back["likes"][0])
print(back["age"] + 1)
```

</CodeExample>

Unlike CSV, JSON **keeps the types**: numbers stay numbers, lists stay lists. Notice that JSON writes `true`, `false` and `null` where Python has `True`, `False` and `None`, and always uses double quotes.

## JSON files: dump and load

Without the "s", **`json.dump()`** writes straight to a file and **`json.load()`** reads from one. Add `indent=2` to make the file nice for humans to read:

<CodeExample output={`{
  "theme": "dark",
  "volume": 7,
  "favourites": [
    "Python",
    "Pandas"
  ]
}
Volume is 7`}>

```python
import json
from pathlib import Path

settings = {
    "theme": "dark",
    "volume": 7,
    "favourites": ["Python", "Pandas"],
}

with open("settings.json", "w") as file:
    json.dump(settings, file, indent=2)

print(Path("settings.json").read_text())

with open("settings.json") as file:
    loaded = json.load(file)
print(f"Volume is {loaded['volume']}")
```

</CodeExample>

<Callout type="note" title="What JSON can store">

JSON understands dicts, lists, strings, numbers, `True`/`False` and `None`. Tuples come back as **lists**, and dictionary keys always become **strings**: `{1: "a"}` is saved as `{"1": "a"}`. Sets, dates and your own objects can't be saved directly; turn them into lists, strings or dicts first.

</Callout>

## Saving and loading app data

Most apps follow the same pattern: **load** the data when they start (or use a default if there's no file yet), change it, then **save** it. Two small functions do the job:

<CodeExample output={`[]
['Write a poem', 'Learn JSON']`}>

```python
import json

def load_data(filename, default):
    try:
        with open(filename) as file:
            return json.load(file)
    except FileNotFoundError:
        return default

def save_data(filename, data):
    with open(filename, "w") as file:
        json.dump(data, file, indent=2)

print(load_data("no-saved-tasks.json", []))

tasks = ["Write a poem"]
tasks.append("Learn JSON")
save_data("tasks.json", tasks)
print(load_data("tasks.json", []))
```

</CodeExample>

<Callout type="tip" title="CSV or JSON?">

Use **CSV** for flat tables that people might open in a spreadsheet. Use **JSON** for nested data and app settings or saves, where you want types like numbers and lists to survive.

</Callout>

```python
import csv
import json

with open("grades.csv", "w", newline="") as file:
    file.write("name,subject,score\n")
    file.write("Mei,maths,92\nSam,maths,78\nAli,maths,70\n")
    file.write("Mei,art,85\nSam,art,64\n")

def average_scores(filename):
    scores = {}
    with open(filename, newline="") as file:
        for row in csv.DictReader(file):
            name = row["name"]
            scores.setdefault(name, []).append(int(row["score"]))
    return {
        name: round(sum(marks) / len(marks), 1)
        for name, marks in scores.items()
    }

def save_report(averages, filename):
    with open(filename, "w") as file:
        json.dump(averages, file, indent=2)

def load_report(filename):
    with open(filename) as file:
        return json.load(file)

averages = average_scores("grades.csv")
print(averages)
save_report(averages, "report.json")
print(load_report("report.json"))
```

## Recap

- Open CSV files with `newline=""`; use `csv.reader` / `csv.writer` for lists and `csv.DictReader` / `csv.DictWriter` for dicts.
- Everything read from a CSV is a **string**: convert with `int()` or `float()`.
- `json.dumps` / `json.loads` work with strings; `json.dump` / `json.load` work with files.
- `indent=2` makes JSON files readable.
- JSON keeps numbers, lists and dicts, but tuples become lists and keys become strings.
- Load with a default if the file is missing, change the data, then save it again.
