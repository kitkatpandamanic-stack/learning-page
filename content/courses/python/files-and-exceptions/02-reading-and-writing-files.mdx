Variables disappear when your program ends. **Files** let you keep data around: notes, settings, high scores, logs. Python makes reading and writing text files short and friendly. 📄

<Callout type="note" title="Files on PandaDev">

PandaDev runs Python in your browser with a small **pretend file system** that lives in memory. That's why every example here first **writes** a file and then reads it back in the same code. On your own computer, the files would appear next to your script.

</Callout>

## Writing a file

`open(name, mode)` opens a file. The **mode** says what you want to do:

| Mode | Meaning |
| --- | --- |
| `"r"` | **Read** (the default). Error if the file doesn't exist. |
| `"w"` | **Write**. Creates the file, or **empties** it if it exists. |
| `"a"` | **Append**. Adds to the end, keeping what's already there. |

<CodeExample output={`Buy bamboo
Feed the panda`}>

```python
with open("notes.txt", "w") as file:
    file.write("Buy bamboo\n")
    file.write("Feed the panda\n")

with open("notes.txt") as file:
    content = file.read()

print(content)
```

</CodeExample>

- **`with open(...) as file:`** opens the file and gives it the name `file`. When the indented block ends, Python **closes** the file for you, even if an error happens.
- `write()` does **not** add a new line for you. Put `\n` at the end of each line yourself.
- `read()` returns the whole file as one string.

<Callout type="tip" title="Always use with">

You *can* write `file = open(...)` and later `file.close()`, but it's easy to forget the `close()`, and then data might not be saved. A `with` block closes the file automatically. Make it a habit.

</Callout>

## Reading line by line

Looping over a file gives you **one line at a time**. That's great for big files, because Python never has to load everything at once:

<CodeExample output={`1. wash dishes
2. walk dog
3. write code`}>

```python
with open("todo.txt", "w") as file:
    file.write("wash dishes\nwalk dog\nwrite code\n")

with open("todo.txt") as file:
    for number, line in enumerate(file, start=1):
        print(f"{number}. {line.strip()}")
```

</CodeExample>

## Newlines and strip()

Each line you read still has its `\n` at the end. Printing a line between square brackets makes the hidden newline visible:

<CodeExample output={`[wash dishes
]
[wash dishes]
[walk dog]`}>

```python
with open("todo.txt", "w") as file:
    file.write("wash dishes\nwalk dog\nwrite code\n")

with open("todo.txt") as file:
    first = file.readline()
    print(f"[{first}]")
    print(f"[{first.strip()}]")
    second = file.readline().strip()
    print(f"[{second}]")
```

</CodeExample>

- `readline()` reads **the next** line. Call it again and you get the line after.
- `.strip()` removes spaces and newlines from both ends. Without it, `print(line)` would show an extra empty line, because `print` adds its own newline too.
- Want a tidy list of lines? `file.read().splitlines()` splits the text into lines **without** the `\n`.

## Appending and writing many lines

Mode `"a"` adds to the end of a file instead of wiping it. `writelines()` writes a whole list of strings in one go (you still add the `\n` yourself):

<CodeExample output={`Day 1: started Python
Day 2: learned exceptions
Day 3: learned files`}>

```python
with open("diary.txt", "w") as file:
    file.write("Day 1: started Python\n")

entries = ["Day 2: learned exceptions", "Day 3: learned files"]
with open("diary.txt", "a") as file:
    file.writelines([entry + "\n" for entry in entries])

with open("diary.txt") as file:
    for line in file:
        print(line.strip())
```

</CodeExample>

<Callout type="warning" title="w wipes the file">

Opening an existing file with `"w"` **deletes everything in it** straight away, before you write a single character. If you want to keep the old contents, use `"a"`.

</Callout>

## pathlib: the modern way

The `pathlib` module gives you a **`Path`** object with handy methods. For small files, `write_text()` and `read_text()` do the open, write or read, and close in one step:

<CodeExample output={`True
Hello from pathlib!
greeting.txt .txt
False`}>

```python
from pathlib import Path

path = Path("greeting.txt")
path.write_text("Hello from pathlib!\n")

print(path.exists())
print(path.read_text().strip())
print(path.name, path.suffix)
print(Path("no-such-file.txt").exists())
```

</CodeExample>

You'll learn all about `import` in the Modules lesson. For now, `from pathlib import Path` makes `Path` available.

## When the file isn't there

Reading a file that doesn't exist raises **`FileNotFoundError`**. Catch it and fall back to something sensible, like an empty list:

<CodeExample output={`No file called missing-notes.txt yet. Starting fresh.
[]
['Buy bamboo', 'Feed the panda']`}>

```python
def load_lines(filename):
    try:
        with open(filename) as file:
            return file.read().splitlines()
    except FileNotFoundError:
        print(f"No file called {filename} yet. Starting fresh.")
        return []

print(load_lines("missing-notes.txt"))

with open("notes.txt", "w") as file:
    file.write("Buy bamboo\nFeed the panda\n")
print(load_lines("notes.txt"))
```

</CodeExample>

<Callout type="tip" title="Mind the encoding">

On your own computer, add `encoding="utf-8"` when you open text files: `open("notes.txt", "w", encoding="utf-8")`. It makes sure emoji and accented letters like é are saved the same way on every operating system.

</Callout>

Use mode `"w"` in `save_list` and loop over the items, writing `item + "\n"`. In `load_list`, wrap the `with open(filename) as file:` in `try` / `except FileNotFoundError:`. Inside, loop over the lines, `strip()` each one, and only `append` it if it isn't empty (`if clean:`).

```python
def save_list(filename, items):
    with open(filename, "w") as file:
        for item in items:
            file.write(item + "\n")

def load_list(filename):
    try:
        with open(filename) as file:
            items = []
            for line in file:
                clean = line.strip()
                if clean:
                    items.append(clean)
            return items
    except FileNotFoundError:
        return []

save_list("shopping.txt", ["milk", "eggs", "bamboo"])
```

## Recap

- `open(name, mode)`: `"r"` reads, `"w"` overwrites, `"a"` appends.
- Use `with open(...) as file:` so the file is always closed.
- `read()` gets everything, `readline()` gets the next line, and `for line in file:` loops line by line.
- `write()` doesn't add `\n` for you; `strip()` removes it when reading.
- `Path("x.txt").exists()`, `.read_text()` and `.write_text()` are quick shortcuts.
- Catch `FileNotFoundError` when a file might not exist yet.
