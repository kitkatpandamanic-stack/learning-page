Для заметок хватает обычного текста, но у настоящих данных есть **структура**: строки и столбцы, имена и значения. Два формата файлов встречаются повсюду:

- **CSV** (comma-separated values, «значения, разделённые запятыми»): таблицы, как в электронной таблице. Каждая строка файла — это строка таблицы.
- **JSON** (JavaScript Object Notation): вложенные данные, похожие на словари и списки Python.

Для каждого из них в Python есть встроенный модуль (module): `csv` и `json`. 📊

## Запись и чтение CSV

CSV-файл выглядит так:

```text title="scores.csv"
name,score
Mei,92
Sam,78
```

`csv.writer` превращает списки в строки файла, а `csv.reader` превращает строки файла обратно в списки:

<CodeExample output={`['name', 'score']
['Mei', '92']
['Sam', '78']`}>

```python
import csv

rows = [["name", "score"], ["Mei", 92], ["Sam", 78]]

with open("scores.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerows(rows)

with open("scores.csv", newline="") as file:
    for row in csv.reader(file):
        print(row)
```

</CodeExample>

Обратите внимание на две вещи:

- Всегда открывайте CSV-файлы с **`newline=""`**. Модуль `csv` сам обрабатывает переводы строк, а этот аргумент не даёт появляться пустым строкам в Windows.
- Мы записали число `92`, а прочитали строку `'92'`. **В CSV всё хранится как текст.**

Почему бы просто не использовать `line.split(",")`? Потому что в настоящих данных бывают запятые, например `"Smith, Jane"`. Модуль `csv` сам разбирается с кавычками.

## DictReader: строки как словари

С **`csv.DictReader`** первая строка файла становится ключами, а каждая следующая — словарём. Такой код читать гораздо проще, чем `row[1]`:

<CodeExample output={`{'name': 'Mei', 'score': '92'}
Mei: 92
Sam: 78
Ali: 85
Средний балл: 85.0`}>

```python
import csv

with open("scores.csv", "w", newline="") as file:
    file.write("name,score\nMei,92\nSam,78\nAli,85\n")

with open("scores.csv", newline="") as file:
    rows = list(csv.DictReader(file))

print(rows[0])

total = 0
for row in rows:
    score = int(row["score"])   # текст -> число
    total += score
    print(f"{row['name']}: {score}")

print(f"Средний балл: {total / len(rows)}")
```

</CodeExample>

<Callout type="warning" title="Преобразуйте типы">

`"92" + "78"` — это `"9278"`, а не `170`! Прежде чем считать или сравнивать, преобразуйте значения из CSV с помощью `int()`, `float()` или проверки вроде `row["done"] == "yes"`. Если данные могут быть «грязными», оберните преобразование в `try` / `except ValueError`.

</Callout>

## DictWriter: запись словарей

**`csv.DictWriter`** делает обратное. Укажите названия столбцов в `fieldnames`, запишите строку заголовков, а затем сами строки:

<CodeExample output={`title,pages
Дюна,412
Матильда,240`}>

```python
import csv
from pathlib import Path

books = [
    {"title": "Дюна", "pages": 412},
    {"title": "Матильда", "pages": 240},
]

with open("books.csv", "w", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["title", "pages"])
    writer.writeheader()
    writer.writerows(books)

print(Path("books.csv").read_text())
```

</CodeExample>

## JSON-строки: dumps и loads

JSON выглядит почти так же, как словари и списки Python. **`json.dumps()`** (dump string, «выгрузить в строку») превращает данные Python в JSON-текст, а **`json.loads()`** (load string, «загрузить из строки») превращает JSON-текст обратно в данные Python:

<CodeExample output={`{"name": "Mei", "age": 5, "likes": ["bamboo", "naps"], "sleepy": true}
str
bamboo
6`}>

```python
import json

panda = {
    "name": "Mei",
    "age": 5,
    "likes": ["bamboo", "naps"],
    "sleepy": True,
}

text = json.dumps(panda)
print(text)
print(type(text).__name__)

back = json.loads(text)
print(back["likes"][0])
print(back["age"] + 1)
```

</CodeExample>

В отличие от CSV, JSON **сохраняет типы**: числа остаются числами, списки — списками. Заметьте, что JSON пишет `true`, `false` и `null` там, где в Python `True`, `False` и `None`, и всегда использует двойные кавычки.

## JSON-файлы: dump и load

Без буквы «s» **`json.dump()`** записывает данные прямо в файл, а **`json.load()`** читает их из файла. Добавьте `indent=2`, чтобы файл было удобно читать людям:

<CodeExample output={`{
  "theme": "dark",
  "volume": 7,
  "favourites": [
    "Python",
    "Pandas"
  ]
}
Громкость: 7`}>

```python
import json
from pathlib import Path

settings = {
    "theme": "dark",
    "volume": 7,
    "favourites": ["Python", "Pandas"],
}

with open("settings.json", "w") as file:
    json.dump(settings, file, indent=2)

print(Path("settings.json").read_text())

with open("settings.json") as file:
    loaded = json.load(file)
print(f"Громкость: {loaded['volume']}")
```

</CodeExample>

Если в данных есть кириллица, по умолчанию JSON сохранит её в виде кодов вроде `"панда"`. Это по-прежнему правильный JSON, и `json.load()` прочитает его как обычный текст. А чтобы русские буквы были видны в самом файле, передайте `ensure_ascii=False`: `json.dump(data, file, indent=2, ensure_ascii=False)`.

<Callout type="note" title="Что можно хранить в JSON">

JSON понимает словари, списки, строки, числа, `True`/`False` и `None`. Кортежи возвращаются **списками**, а ключи словарей всегда становятся **строками**: `{1: "a"}` сохраняется как `{"1": "a"}`. Множества, даты и ваши собственные объекты напрямую сохранить нельзя — сначала превратите их в списки, строки или словари.

</Callout>

## Сохранение и загрузка данных приложения

Большинство приложений действуют по одной схеме: при запуске **загружают** данные (или берут значение по умолчанию, если файла ещё нет), изменяют их, а затем **сохраняют**. С этим справляются две небольшие функции:

<CodeExample output={`[]
['Написать стихотворение', 'Выучить JSON']`}>

```python
import json

def load_data(filename, default):
    try:
        with open(filename) as file:
            return json.load(file)
    except FileNotFoundError:
        return default

def save_data(filename, data):
    with open(filename, "w") as file:
        json.dump(data, file, indent=2)

print(load_data("no-saved-tasks.json", []))

tasks = ["Написать стихотворение"]
tasks.append("Выучить JSON")
save_data("tasks.json", tasks)
print(load_data("tasks.json", []))
```

</CodeExample>

<Callout type="tip" title="CSV или JSON?">

Используйте **CSV** для плоских таблиц, которые люди могут открыть в электронной таблице. Используйте **JSON** для вложенных данных, настроек и сохранений приложения, когда важно, чтобы такие типы, как числа и списки, не потерялись.

</Callout>

```python
import csv
import json

with open("grades.csv", "w", newline="") as file:
    file.write("name,subject,score\n")
    file.write("Mei,maths,92\nSam,maths,78\nAli,maths,70\n")
    file.write("Mei,art,85\nSam,art,64\n")

def average_scores(filename):
    scores = {}
    with open(filename, newline="") as file:
        for row in csv.DictReader(file):
            name = row["name"]
            scores.setdefault(name, []).append(int(row["score"]))
    return {
        name: round(sum(marks) / len(marks), 1)
        for name, marks in scores.items()
    }

def save_report(averages, filename):
    with open(filename, "w") as file:
        json.dump(averages, file, indent=2)

def load_report(filename):
    with open(filename) as file:
        return json.load(file)

averages = average_scores("grades.csv")
print(averages)
save_report(averages, "report.json")
print(load_report("report.json"))
```

## Итоги

- Открывайте CSV-файлы с `newline=""`; используйте `csv.reader` / `csv.writer` для списков и `csv.DictReader` / `csv.DictWriter` для словарей.
- Всё, что прочитано из CSV, — это **строки**: преобразуйте их через `int()` или `float()`.
- `json.dumps` / `json.loads` работают со строками; `json.dump` / `json.load` — с файлами.
- `indent=2` делает JSON-файлы читаемыми.
- JSON сохраняет числа, списки и словари, но кортежи превращаются в списки, а ключи — в строки.
- Загружайте данные со значением по умолчанию на случай, если файла нет, изменяйте их и сохраняйте снова.
