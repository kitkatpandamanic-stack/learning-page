Переменные исчезают, когда программа завершается. **Файлы** (files) позволяют сохранить данные: заметки, настройки, рекорды, журналы. В Python чтение и запись текстовых файлов получаются короткими и понятными. 📄

<Callout type="note" title="Файлы на PandaDev">

PandaDev запускает Python прямо в браузере с небольшой **игрушечной файловой системой**, которая живёт в памяти. Поэтому в каждом примере здесь код сначала **записывает** файл, а затем читает его обратно. На вашем компьютере файлы появились бы рядом со скриптом.

</Callout>

## Запись в файл

`open(name, mode)` открывает файл. **Режим** (mode) говорит, что вы собираетесь делать:

| Режим | Что означает |
| --- | --- |
| `"r"` | **Чтение** (по умолчанию). Ошибка, если файла нет. |
| `"w"` | **Запись**. Создаёт файл или **очищает** его, если он уже есть. |
| `"a"` | **Дозапись** (append). Добавляет в конец, сохраняя то, что там уже есть. |

<CodeExample output={`Купить бамбук
Покормить панду`}>

```python
with open("notes.txt", "w") as file:
    file.write("Купить бамбук\n")
    file.write("Покормить панду\n")

with open("notes.txt") as file:
    content = file.read()

print(content)
```

</CodeExample>

- **`with open(...) as file:`** открывает файл и даёт ему имя `file`. Когда блок с отступом заканчивается, Python сам **закрывает** файл, даже если произошла ошибка.
- `write()` **не** добавляет перевод строки за вас. Ставьте `\n` в конце каждой строки сами.
- `read()` возвращает весь файл одной строкой.

<Callout type="tip" title="Всегда используйте with">

Можно написать `file = open(...)`, а потом `file.close()`, но про `close()` легко забыть, и тогда данные могут не сохраниться. Блок `with` закрывает файл автоматически. Сделайте это привычкой.

</Callout>

## Чтение по строкам

Цикл по файлу выдаёт **по одной строке за раз**. Это отлично подходит для больших файлов: Python не нужно загружать всё сразу.

<CodeExample output={`1. помыть посуду
2. выгулять собаку
3. написать код`}>

```python
with open("todo.txt", "w") as file:
    file.write("помыть посуду\nвыгулять собаку\nнаписать код\n")

with open("todo.txt") as file:
    for number, line in enumerate(file, start=1):
        print(f"{number}. {line.strip()}")
```

</CodeExample>

## Переводы строк и strip()

В конце каждой прочитанной строки остаётся её `\n`. Если вывести строку в квадратных скобках, невидимый перевод строки станет заметен:

<CodeExample output={`[помыть посуду
]
[помыть посуду]
[выгулять собаку]`}>

```python
with open("todo.txt", "w") as file:
    file.write("помыть посуду\nвыгулять собаку\nнаписать код\n")

with open("todo.txt") as file:
    first = file.readline()
    print(f"[{first}]")
    print(f"[{first.strip()}]")
    second = file.readline().strip()
    print(f"[{second}]")
```

</CodeExample>

- `readline()` читает **следующую** строку. Вызовите его ещё раз — и получите строку после неё.
- `.strip()` убирает пробелы и переводы строк с обоих концов. Без него `print(line)` выводил бы лишнюю пустую строку, ведь `print` добавляет и свой перевод строки.
- Нужен аккуратный список строк? `file.read().splitlines()` разбивает текст на строки **без** `\n`.

## Дозапись и запись нескольких строк

Режим `"a"` добавляет текст в конец файла, а не стирает его. `writelines()` записывает целый список строк за один раз (`\n` по-прежнему добавляете вы):

<CodeExample output={`День 1: начал(а) изучать Python
День 2: разобрался(-ась) с исключениями
День 3: разобрался(-ась) с файлами`}>

```python
with open("diary.txt", "w") as file:
    file.write("День 1: начал(а) изучать Python\n")

entries = ["День 2: разобрался(-ась) с исключениями", "День 3: разобрался(-ась) с файлами"]
with open("diary.txt", "a") as file:
    file.writelines([entry + "\n" for entry in entries])

with open("diary.txt") as file:
    for line in file:
        print(line.strip())
```

</CodeExample>

<Callout type="warning" title="w стирает файл">

Если открыть существующий файл в режиме `"w"`, **всё его содержимое удаляется** сразу же, ещё до того, как вы запишете хоть один символ. Если нужно сохранить старое содержимое, используйте `"a"`.

</Callout>

## pathlib: современный способ

Модуль `pathlib` даёт объект **`Path`** с удобными методами. Для небольших файлов `write_text()` и `read_text()` делают всё за один шаг: открывают файл, записывают или читают и закрывают его.

<CodeExample output={`True
Привет от pathlib!
greeting.txt .txt
False`}>

```python
from pathlib import Path

path = Path("greeting.txt")
path.write_text("Привет от pathlib!\n")

print(path.exists())
print(path.read_text().strip())
print(path.name, path.suffix)
print(Path("no-such-file.txt").exists())
```

</CodeExample>

Всё об `import` вы узнаете в уроке о модулях. Пока достаточно знать, что `from pathlib import Path` делает `Path` доступным.

## Когда файла нет

Чтение несуществующего файла выбрасывает **`FileNotFoundError`**. Перехватите это исключение и используйте разумную замену, например пустой список:

<CodeExample output={`Файла missing-notes.txt пока нет. Начинаем с чистого листа.
[]
['Купить бамбук', 'Покормить панду']`}>

```python
def load_lines(filename):
    try:
        with open(filename) as file:
            return file.read().splitlines()
    except FileNotFoundError:
        print(f"Файла {filename} пока нет. Начинаем с чистого листа.")
        return []

print(load_lines("missing-notes.txt"))

with open("notes.txt", "w") as file:
    file.write("Купить бамбук\nПокормить панду\n")
print(load_lines("notes.txt"))
```

</CodeExample>

<Callout type="tip" title="Помните о кодировке">

На своём компьютере добавляйте `encoding="utf-8"`, когда открываете текстовые файлы: `open("notes.txt", "w", encoding="utf-8")`. Так кириллица, эмодзи и буквы с диакритикой вроде é будут сохраняться одинаково в любой операционной системе.

</Callout>

def save_list(filename, items):
    with open(filename, "w") as file:

def load_list(filename):

## Итоги

- `open(name, mode)`: `"r"` читает, `"w"` перезаписывает, `"a"` дописывает в конец.
- Используйте `with open(...) as file:`, чтобы файл всегда закрывался.
- `read()` читает всё, `readline()` — следующую строку, а `for line in file:` перебирает файл построчно.
- `write()` не добавляет `\n` за вас; при чтении его убирает `strip()`.
- `Path("x.txt").exists()`, `.read_text()` и `.write_text()` — быстрые сокращения.
- Перехватывайте `FileNotFoundError`, если файла может ещё не быть.
