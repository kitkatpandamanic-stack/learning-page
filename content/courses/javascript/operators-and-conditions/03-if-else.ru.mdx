Теперь, когда вы умеете задавать вопросы с ответом true/false, давайте научим программу **действовать** в зависимости от ответа.

## `if`

Код внутри фигурных скобок выполняется, только если условие (condition) истинно:

<CodeExample output="Вы победили! 🏆">

```js
const score = 120;

if (score > 100) {
  console.log("Вы победили! 🏆");
}
```

</CodeExample>

## `else`

`else` выполняется, когда условие **ложно**:

<CodeExample output="Продолжайте в том же духе!">

```js
const score = 40;

if (score > 100) {
  console.log("Вы победили! 🏆");
} else {
  console.log("Продолжайте в том же духе!");
}
```

</CodeExample>

## `else if`: больше двух вариантов

Условия проверяются **сверху вниз**, и выполняется только первый подходящий блок:

<CodeExample output="Оценка: B">

```js
const marks = 78;

if (marks >= 90) {
  console.log("Оценка: A");
} else if (marks >= 70) {
  console.log("Оценка: B");
} else if (marks >= 50) {
  console.log("Оценка: C");
} else {
  console.log("Оценка: F");
}
```

</CodeExample>

<Callout type="tip">

Порядок важен. Если бы вы сначала проверили `marks >= 50`, то 95 баллов получили бы оценку C: этот блок сработал бы раньше, чем до остальных вообще дошла бы очередь.

</Callout>

## Тернарный оператор

Для быстрого выбора между двумя **значениями** есть короткая запись: `условие ? значениеЕслиTrue : значениеЕслиFalse`.

<CodeExample output="Добрый вечер">

```js
const hour = 19;
const greeting = hour < 12 ? "Доброе утро" : "Добрый вечер";
console.log(greeting);
```

</CodeExample>

Используйте его для коротких и простых выборов. Для всего, что сложнее, `if/else` читается легче.

## `switch`

Когда одно значение нужно сравнить со множеством точных вариантов, `switch` может оказаться аккуратнее:

<CodeExample output="Выходные! 🎉">

```js
const day = "Сб";

switch (day) {
  case "Сб":
  case "Вс":
    console.log("Выходные! 🎉");
    break;
  case "Пт":
    console.log("Почти выходные");
    break;
  default:
    console.log("Будний день");
}
```

</CodeExample>

<Callout type="warning">

Не забывайте про `break`! Без него JavaScript продолжит выполнять и следующие варианты (`case`). Именно благодаря такому «проваливанию» (fall-through) `"Сб"` и `"Вс"` выше используют один общий блок.

</Callout>

## Итоги

- `if` выполняет код, когда условие истинно; `else` обрабатывает все остальные случаи.
- Цепочки `else if` проверяются сверху вниз, и выполняется только один блок.
- `cond ? a : b` выбирает одно из двух значений.
- `switch` сравнивает одно значение со множеством вариантов; не забывайте про `break`.
