Now that you can ask true/false questions, let's make the program **act** on the answers.

## `if`

The code inside the curly braces only runs when the condition is true:

<CodeExample output="You won! 🏆">

```js
const score = 120;

if (score > 100) {
  console.log("You won! 🏆");
}
```

</CodeExample>

## `else`

`else` runs when the condition is **false**:

<CodeExample output="Keep going!">

```js
const score = 40;

if (score > 100) {
  console.log("You won! 🏆");
} else {
  console.log("Keep going!");
}
```

</CodeExample>

## `else if`: more than two choices

Conditions are checked **from top to bottom**, and only the first matching block runs:

<CodeExample output="Grade: B">

```js
const marks = 78;

if (marks >= 90) {
  console.log("Grade: A");
} else if (marks >= 70) {
  console.log("Grade: B");
} else if (marks >= 50) {
  console.log("Grade: C");
} else {
  console.log("Grade: F");
}
```

</CodeExample>

<Callout type="tip">

Order matters. If you checked `marks >= 50` first, a mark of 95 would get a C, because that block would match before the others are even checked.

</Callout>

## The ternary operator

For a quick choice between two **values**, there's a shorter form: `condition ? valueIfTrue : valueIfFalse`.

<CodeExample output="Good evening">

```js
const hour = 19;
const greeting = hour < 12 ? "Good morning" : "Good evening";
console.log(greeting);
```

</CodeExample>

Use it for short, simple choices. For anything bigger, `if/else` is easier to read.

## `switch`

When you compare one value against many exact options, `switch` can be tidier:

<CodeExample output="Weekend! 🎉">

```js
const day = "Sat";

switch (day) {
  case "Sat":
  case "Sun":
    console.log("Weekend! 🎉");
    break;
  case "Fri":
    console.log("Almost there");
    break;
  default:
    console.log("Weekday");
}
```

</CodeExample>

<Callout type="warning">

Don't forget `break`! Without it, JavaScript keeps running the next cases too. This "fall-through" is how `"Sat"` and `"Sun"` share one block above.

</Callout>

Write a program with a `marks` variable (0 to 100) that prints the grade: `A` for 90+, `B` for 70+, `C` for 50+ and `F` otherwise. Then add a check: if `marks` is below 0 or above 100, print `Invalid marks` instead. Press **Check** with `marks` set to `85`, then try other values like `95`, `30` and `150`.

Put the invalid check **first**, using `||` to combine the two conditions.

</Hint>

```js
const marks = 85;

if (marks < 0 || marks > 100) {
  console.log("Invalid marks");
} else if (marks >= 90) {
  console.log("A");
} else if (marks >= 70) {
  console.log("B");
} else if (marks >= 50) {
  console.log("C");
} else {
  console.log("F");
}
```

</Solution>

## Recap

- `if` runs code when a condition is true; `else` handles the rest.
- `else if` chains are checked top to bottom, and only one block runs.
- `cond ? a : b` picks between two values.
- `switch` compares one value to many cases; remember `break`.
