Прежде чем программа сможет принимать решения, ей нужно задавать вопросы вроде *«счёт больше 100?»*. Сравнения отвечают логическим значением (boolean): `true` или `false`.

## Операторы сравнения

<CodeExample output={`true
false
true
true`}>

```js
const age = 15;
console.log(age > 12);   // больше
console.log(age < 12);   // меньше
console.log(age >= 15);  // больше или равно
console.log(age <= 18);  // меньше или равно
```

</CodeExample>

## Проверка равенства: всегда используйте `===`

Чтобы проверить, равны ли два значения, используйте **три** знака равенства. Чтобы проверить, что они различаются, — `!==`:

<CodeExample output={`true
false
true`}>

```js
console.log(5 === 5);
console.log(5 === "5");
console.log("кошка" !== "собака");
```

</CodeExample>

<Callout type="warning" title="= или == или ===">

- `=` **присваивает** значение: `let x = 5`.
- `===` **сравнивает** значение *и* тип: `5 === "5"` — это `false`.
- `==` сравнивает нестрого и сначала преобразует типы, поэтому `5 == "5"` — это `true`. Из-за этого возникают запутанные ошибки, так что в профессиональном коде почти всегда используют `===`.

</Callout>

## Объединение условий

Часто одного вопроса недостаточно. **Логические операторы** (logical operators) объединяют логические значения:

| Оператор | Название | `true`, когда…                     |
| -------- | -------- | ---------------------------------- |
| `&&`     | И        | **обе** стороны истинны            |
| `\|\|`   | ИЛИ      | **хотя бы одна** сторона истинна   |
| `!`      | НЕ       | меняет true ↔ false                |

<CodeExample output={`true
false
true`}>

```js
const age = 15;
const hasTicket = true;

console.log(age >= 12 && hasTicket); // обе стороны true
console.log(age >= 18 || !hasTicket); // обе стороны false
console.log(!false);
```

</CodeExample>

## Truthy и falsy

JavaScript может считать *любое* значение истинным или ложным. Эти значения считаются **ложными** (falsy):

`false`, `0`, `""` (пустая строка), `null`, `undefined` и `NaN`.

Всё остальное — **истинное** (truthy), в том числе `"0"`, `"false"` и `[]`. В следующем уроке вы увидите, почему это важно.

<Exercise
  starter={`const height = 130;
const age = 9;

// Сохраните ответ в canRide, затем выведите его
`}
  tests={[
    { name: "canRide — логическое значение", check: 'typeof canRide === "boolean"' },
    { name: "canRide проверяет рост И возраст", check: "canRide === (height >= 120 && age >= 8)" },
    { name: "Выводит ответ", check: "__output.at(-1) === String(canRide)" },
  ]}
>

На аттракцион в парке пускают тех, чей рост не меньше `120` см **и** возраст не меньше `8` лет. Используя переменные `height` и `age`, сохраните в переменную `canRide`, можно ли посетителю прокатиться, а затем выведите её. Поменяйте рост и возраст и посмотрите, как изменится ответ.

<Solution>

```js
const height = 130;
const age = 9;
const canRide = height >= 120 && age >= 8;
console.log(canRide); // true
```

</Solution>

</Exercise>

## Итоги

- `>`, `<`, `>=` и `<=` сравнивают числа.
- Для проверки равенства используйте `===` и `!==`, но никогда `==`.
- `&&` требует, чтобы обе стороны были истинны, `||` — хотя бы одна, а `!` меняет значение на противоположное.
- `0`, `""`, `null`, `undefined`, `NaN` и `false` — ложные (falsy) значения.
