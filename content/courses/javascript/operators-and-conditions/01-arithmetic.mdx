Computers are very good at maths. JavaScript has an **operator** for each basic calculation.

## The arithmetic operators

<CodeExample output={`13
7
30
3.3333333333333335
1
1000`}>

```js
console.log(10 + 3);  // addition
console.log(10 - 3);  // subtraction
console.log(10 * 3);  // multiplication
console.log(10 / 3);  // division
console.log(10 % 3);  // remainder
console.log(10 ** 3); // power (10 × 10 × 10)
```

</CodeExample>

The **remainder** operator `%` gives what's left over after dividing. `10 % 3` is `1` because 3 fits into 10 three times with 1 left over. It's perfect for checking whether a number is even: `n % 2` is `0` for even numbers.

<Callout type="note" title="Why 3.3333333333333335?">

Computers store decimals in binary, so some results are very slightly off. You'll see `0.1 + 0.2` give `0.30000000000000004` too. For money, programmers often count in whole cents instead.

</Callout>

## Order of operations

Just like in school maths, `*` and `/` happen before `+` and `-`. Use brackets to choose the order yourself:

<CodeExample output={`14
20`}>

```js
console.log(2 + 3 * 4);   // 3 * 4 first
console.log((2 + 3) * 4); // brackets first
```

</CodeExample>

## Updating variables

Changing a variable based on its current value is so common that there are shortcuts:

<CodeExample output={`15
30
31`}>

```js
let score = 10;
score += 5;  // same as: score = score + 5
console.log(score);

score *= 2;  // same as: score = score * 2
console.log(score);

score++;     // add 1
console.log(score);
```

</CodeExample>

There's also `-=`, `/=` and `score--` to subtract 1.

## Strings and numbers don't mix well

When you use `+` with a string, JavaScript joins instead of adding:

<CodeExample output={`55
10`}>

```js
console.log("5" + 5); // joins the text: "55"
console.log("5" * 2); // * only works on numbers, so "5" becomes 5
```

</CodeExample>

<Callout type="warning">

This is a classic beginner bug! Values typed by users (from a form, for example) are **strings**. Convert them first with `Number("5")`, which gives the number `5`.

</Callout>

A pizza costs `12` and you have `3` friends (plus you, so 4 people). Store these in variables and print how much each person pays, using a template literal: `Each person pays 3`.

<Solution>

```js
const pizzaPrice = 12;
const people = 3 + 1;
const share = pizzaPrice / people;
console.log(`Each person pays ${share}`);
```

</Solution>

## Recap

- `+ - * /` do what you expect; `%` gives the remainder and `**` the power.
- Brackets control the order of operations.
- `+=`, `-=`, `++` and friends update a variable in place.
- `"5" + 5` joins text; convert strings with `Number()` first.
