Before a program can make decisions, it needs to ask questions like *"is the score above 100?"*. Comparisons answer with a boolean: `true` or `false`.

## Comparison operators

<CodeExample output={`true
false
true
true`}>

```js
const age = 15;
console.log(age > 12);   // greater than
console.log(age < 12);   // less than
console.log(age >= 15);  // greater than or equal
console.log(age <= 18);  // less than or equal
```

</CodeExample>

## Checking equality: always use `===`

To check whether two values are equal, use **three** equals signs. To check they are different, use `!==`:

<CodeExample output={`true
false
true`}>

```js
console.log(5 === 5);
console.log(5 === "5");
console.log("cat" !== "dog");
```

</CodeExample>

<Callout type="warning" title="= vs == vs ===">

- `=` **assigns** a value: `let x = 5`.
- `===` **compares** value *and* type: `5 === "5"` is `false`.
- `==` compares loosely and converts types first, so `5 == "5"` is `true`. This causes confusing bugs, so professional code almost always uses `===`.

</Callout>

## Combining conditions

Often one question isn't enough. **Logical operators** combine booleans:

| Operator | Name | `true` when…                 |
| -------- | ---- | ---------------------------- |
| `&&`     | AND  | **both** sides are true      |
| `\|\|`   | OR   | **at least one** side is true |
| `!`      | NOT  | flips true ↔ false           |

<CodeExample output={`true
false
true`}>

```js
const age = 15;
const hasTicket = true;

console.log(age >= 12 && hasTicket); // both true
console.log(age >= 18 || !hasTicket); // both false
console.log(!false);
```

</CodeExample>

## Truthy and falsy

JavaScript can treat *any* value as true or false. These values count as **falsy**:

`false`, `0`, `""` (empty string), `null`, `undefined` and `NaN`.

Everything else is **truthy**, including `"0"`, `"false"` and `[]`. You'll see why this matters in the next lesson.

## Recap

- `>`, `<`, `>=` and `<=` compare numbers.
- Use `===` and `!==` for equality, never `==`.
- `&&` needs both sides true, `||` needs one, `!` flips.
- `0`, `""`, `null`, `undefined`, `NaN` and `false` are falsy.
