Компьютеры отлично считают. Для каждого базового вычисления в JavaScript есть свой **оператор** (operator).

## Арифметические операторы

<CodeExample output={`13
7
30
3.3333333333333335
1
1000`}>

```js
console.log(10 + 3);  // сложение
console.log(10 - 3);  // вычитание
console.log(10 * 3);  // умножение
console.log(10 / 3);  // деление
console.log(10 % 3);  // остаток от деления
console.log(10 ** 3); // возведение в степень (10 × 10 × 10)
```

</CodeExample>

Оператор **остатка** (remainder) `%` даёт то, что остаётся после деления. `10 % 3` равно `1`, потому что 3 помещается в 10 три раза и остаётся 1. Это идеальный способ проверить, чётное ли число: для чётных чисел `n % 2` равно `0`.

<Callout type="note" title="Почему 3.3333333333333335?">

Компьютеры хранят дробные числа в двоичном виде, поэтому некоторые результаты получаются чуть-чуть неточными. Например, `0.1 + 0.2` даст `0.30000000000000004`. Поэтому с деньгами программисты часто считают в целых копейках или центах.

</Callout>

## Порядок действий

Как и в школьной математике, `*` и `/` выполняются раньше, чем `+` и `-`. Скобки позволяют самим задать порядок:

<CodeExample output={`14
20`}>

```js
console.log(2 + 3 * 4);   // сначала 3 * 4
console.log((2 + 3) * 4); // сначала скобки
```

</CodeExample>

## Обновление переменных

Изменять переменную (variable) на основе её текущего значения приходится так часто, что для этого есть короткие записи:

<CodeExample output={`15
30
31`}>

```js
let score = 10;
score += 5;  // то же, что score = score + 5
console.log(score);

score *= 2;  // то же, что score = score * 2
console.log(score);

score++;     // прибавить 1
console.log(score);
```

</CodeExample>

Есть ещё `-=`, `/=` и `score--`, чтобы вычесть 1.

## Строки и числа плохо смешиваются

Если использовать `+` со строкой, JavaScript не складывает, а соединяет:

<CodeExample output={`55
10`}>

```js
console.log("5" + 5); // соединяет текст: "55"
console.log("5" * 2); // * работает только с числами, поэтому "5" превращается в 5
```

</CodeExample>

<Callout type="warning">

Это классическая ошибка новичков! Значения, которые вводят пользователи (например, в форме), — это **строки**. Сначала преобразуйте их с помощью `Number("5")` — так вы получите число `5`.

</Callout>

Пицца стоит `12`, а у вас `3` друга (плюс вы, то есть 4 человека). Сохраните эти данные в переменных и выведите, сколько платит каждый, с помощью шаблонной строки: `Каждый платит 3`.

```js
const pizzaPrice = 12;
const people = 3 + 1;
const share = pizzaPrice / people;
console.log(`Каждый платит ${share}`);
```

</Solution>

## Итоги

- `+ - * /` работают так, как вы ожидаете; `%` даёт остаток, а `**` — степень.
- Скобки управляют порядком действий.
- `+=`, `-=`, `++` и их «родственники» изменяют переменную на месте.
- `"5" + 5` соединяет текст; сначала преобразуйте строки с помощью `Number()`.
