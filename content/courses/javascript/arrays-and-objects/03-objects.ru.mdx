Массивы отлично подходят для списка похожих вещей. Но как сохранить всё об **одной** панде: её имя, возраст и любимую еду? **Объект (object)** собирает связанные значения вместе и даёт каждому из них имя.

## Создание объекта

Объект записывается в фигурных скобках. Каждая пара `key: value` внутри называется **свойством (property)**:

<CodeExample output={`{ name: 'Bao', age: 4, food: 'бамбук', isSleepy: true }
Bao`}>

```js
const panda = {
  name: "Bao",
  age: 4,
  food: "бамбук",
  isSleepy: true,
};

console.log(panda);
console.log(panda.name);
```

</CodeExample>

**Ключ (key)** — это имя свойства (`name`, `age`…), а **значение (value)** может быть чем угодно: строкой, числом, логическим значением, массивом и даже другим объектом. Запятая после последнего свойства необязательна, но с ней удобнее добавлять новые строки.

## Точка или квадратные скобки

Прочитать свойство можно двумя способами:

<CodeExample output={`Bao
4
бамбук
undefined`}>

```js
const panda = { name: "Bao", age: 4, "favourite food": "бамбук" };

console.log(panda.name);              // через точку
console.log(panda["age"]);            // через квадратные скобки
console.log(panda["favourite food"]); // ключам с пробелами нужны скобки
console.log(panda.colour);            // такого свойства нет
```

</CodeExample>

Запись через точку короче, поэтому в большинстве случаев используйте её. Квадратные скобки **необходимы**, когда в ключе есть пробелы или дефисы или когда ключ хранится в **переменной**:

<CodeExample output={`name: Bao
age: 4`}>

```js
const panda = { name: "Bao", age: 4 };
const fields = ["name", "age"];

for (const field of fields) {
  console.log(`${field}: ${panda[field]}`);
}
```

</CodeExample>

<Callout type="warning" title="panda.field — это не panda[field]">

`panda.field` ищет свойство, которое буквально называется `"field"`, а такого нет. `panda[field]` использует **значение** переменной `field`, например `"name"`. Эта путаница — очень частый источник ошибок.

</Callout>

## Добавление, изменение и удаление свойств

<CodeExample output={`{ name: 'Bao', age: 5, city: 'Чэнду' }
true`}>

```js
const panda = { name: "Bao", age: 4, isSleepy: true };

panda.age = 5;        // изменить
panda.city = "Чэнду"; // добавить
delete panda.isSleepy; // удалить

console.log(panda);
console.log("city" in panda); // есть ли такой ключ?
```

</CodeExample>

Как и массивы, объекты хранятся по **ссылке**. У объекта, объявленного через `const`, всё равно можно менять свойства — нельзя только направить переменную на другой объект.

## Методы и this

Свойство, значение которого — функция, называется **методом (method)**. Внутри метода ключевое слово `this` означает *объект, у которого вызвали метод*:

<CodeExample output={`Привет, я Bao!
Возраст Bao теперь 5`}>

```js
const panda = {
  name: "Bao",
  age: 4,
  greet() {
    return `Привет, я ${this.name}!`;
  },
  haveBirthday() {
    this.age++;
    console.log(`Возраст ${this.name} теперь ${this.age}`);
  },
};

console.log(panda.greet());
panda.haveBirthday();
```

</CodeExample>

Когда вы вызываете `panda.greet()`, `this` — это то, что стоит перед точкой, то есть `panda`. Вы всё это время пользовались методами: `console.log` — это метод `log` объекта `console`!

<Callout type="note" title="Стрелочные функции и this">

У стрелочных функций нет собственного `this`, поэтому `greet: () => this.name` **не** увидит панду. Для методов, которым нужен `this`, используйте короткую запись `greet() { ... }`.

</Callout>

## Перебор объекта

`Object.keys`, `Object.values` и `Object.entries` превращают объект в массивы, и тогда можно применять всё, что вы знаете о массивах:

<CodeExample output={`[ 'apples', 'bread', 'milk' ]
[ 3, 1, 2 ]
apples: 3
bread: 1
milk: 2`}>

```js
const basket = { apples: 3, bread: 1, milk: 2 };

console.log(Object.keys(basket));
console.log(Object.values(basket));

for (const [item, count] of Object.entries(basket)) {
  console.log(`${item}: ${count}`);
}
```

</CodeExample>

`Object.entries` возвращает массив пар `[key, value]`, например `[ [ 'apples', 3 ], [ 'bread', 1 ], [ 'milk', 2 ] ]`. Запись `[item, count]` в цикле распаковывает каждую пару в две переменные. Этот приём называется **деструктуризацией (destructuring)**.

## Деструктуризация

**Деструктуризация** достаёт значения из объекта или массива в переменные одной строкой.

### Объекты

<CodeExample output={`Bao 4
Город Bao: Неизвестно
Bao`}>

```js
const panda = { name: "Bao", age: 4 };

const { name, age } = panda; // то же, что const name = panda.name; ...
console.log(name, age);

const { city = "Неизвестно" } = panda; // значение по умолчанию для отсутствующих ключей
console.log(`Город ${name}: ${city}`);

const { name: pandaName } = panda; // другое имя переменной
console.log(pandaName);
```

</CodeExample>

Это работает и в параметрах функций, причём встречается очень часто:

<CodeExample output="Возраст Bao: 4">

```js
function describe({ name, age }) {
  return `Возраст ${name}: ${age}`;
}

console.log(describe({ name: "Bao", age: 4 }));
```

</CodeExample>

### Массивы

В массивах значения выбираются по **позиции**. `...rest` собирает всё, что осталось:

<CodeExample output={`Mei Sam
[ 'Ali', 'Zoe' ]
2 1`}>

```js
const podium = ["Mei", "Sam", "Ali", "Zoe"];

const [first, second, ...others] = podium;
console.log(first, second);
console.log(others);

let a = 1;
let b = 2;
[a, b] = [b, a]; // поменять две переменные местами
console.log(a, b);
```

</CodeExample>

## Spread: копирование и слияние объектов

Оператор расширения `...` работает и с объектами. Он копирует все свойства в новый объект. Если один и тот же ключ встречается дважды, побеждает **последний**:

<CodeExample output={`{ theme: 'dark', fontSize: 14, sound: true }
{ theme: 'light', fontSize: 14 }
{ theme: 'light', fontSize: 20 }`}>

```js
const defaults = { theme: "light", fontSize: 14 };
const choices = { theme: "dark", sound: true };

const settings = { ...defaults, ...choices };
console.log(settings);
console.log(defaults); // не изменился

const bigger = { ...defaults, fontSize: 20 }; // копия + изменение
console.log(bigger);
```

</CodeExample>

<Callout type="tip" title="Поверхностная копия">

Spread копирует только **верхний уровень**. Если в свойстве лежит массив или другой объект, копия и оригинал по-прежнему делят этот вложенный массив или объект.

</Callout>

## Опциональная цепочка

Попытка прочитать свойство у `undefined` обрушивает программу с ошибкой `TypeError`. Если чего-то может не оказаться, используйте **опциональную цепочку (optional chaining)** `?.`: она останавливается и возвращает `undefined` вместо падения.

<CodeExample output={`Чэнду
undefined
Город не указан`}>

```js
const mei = { name: "Mei", address: { city: "Чэнду" } };
const sam = { name: "Sam" }; // адреса нет!

console.log(mei.address?.city);
console.log(sam.address?.city);
console.log(sam.address?.city ?? "Город не указан");
```

</CodeExample>

Оператор `??` (**оператор нулевого слияния, nullish coalescing**) даёт запасное значение, когда левая часть равна `null` или `undefined`. В отличие от `||`, он сохраняет «ложные, но настоящие» значения, такие как `0` и `""`.

3. `ownerCity(pet)` возвращает город хозяина или `"Неизвестно"`, если у питомца нет `owner` или у хозяина нет `city`.

<Hint>

Для `describePet` напишите `function describePet({ name, type, age })`. Для `birthday` разверните питомца в новый объект через spread, а затем задайте `age: pet.age + 1`. Для `ownerCity` объедините `?.` и `??`.

<Solution>

```js
const pet = {
  name: "Bao",
  type: "панда",
  age: 4,
  owner: { name: "Mei", city: "Чэнду" },
};

function describePet({ name, type, age }) {
  return `${name} — ${type}, возраст: ${age}`;
}

function birthday(pet) {
  return { ...pet, age: pet.age + 1 };
}

function ownerCity(pet) {
  return pet.owner?.city ?? "Неизвестно";
}

console.log(describePet(pet));
console.log(birthday(pet));
console.log(pet.age); // по-прежнему 4
console.log(ownerCity(pet));
console.log(ownerCity({ name: "Pip", type: "кот", age: 2 }));
```

## Итоги

- Объекты группируют связанные значения в **свойства** вида `key: value`.
- Обычно пишите `obj.key`, а `obj[variable]` — когда ключ лежит в переменной или содержит пробелы.
- Добавляйте и меняйте через `obj.key = value`; удаляйте через `delete obj.key`.
- Методы — это функции внутри объектов; `this` — объект перед точкой.
- `Object.keys`, `Object.values` и `Object.entries` превращают объекты в массивы.
- Деструктуризация распаковывает значения: `const { name } = obj` и `const [first] = arr`.
- `{ ...a, ...b }` копирует и объединяет (побеждают последние ключи); `?.` и `??` безопасно обрабатывают отсутствующие данные.
