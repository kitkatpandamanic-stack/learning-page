Вы уже умеете перебирать массив циклом `for...of`. Но некоторые задачи встречаются так часто (*«удвоить каждое число»*, *«оставить только сданные работы»*, *«всё сложить»*), что у массивов для них есть **встроенные методы**.

Каждый из этих методов принимает **функцию** в качестве аргумента. Метод вызывает вашу функцию по одному разу для каждого элемента. Функцию, которую передают в другую функцию, называют **колбэком (callback)**, или функцией обратного вызова, и именно здесь короткие стрелочные функции раскрываются во всей красе.

## forEach: сделать что-то с каждым элементом

<CodeExample output={`1. Mei
2. Sam
3. Ali`}>

```js
const names = ["Mei", "Sam", "Ali"];

names.forEach((name, index) => {
  console.log(`${index + 1}. ${name}`);
});
```

</CodeExample>

Колбэк получает **элемент** и, если нужно, его **индекс**. `forEach` похож на цикл `for...of`, который заодно выдаёт индекс. Он ничего не возвращает.

## map: преобразовать каждый элемент

`map` строит **новый** массив, пропуская каждый элемент через ваш колбэк. Всё, что возвращает колбэк, попадает в новый массив:

<CodeExample output={`[ 2, 4, 6 ]
[ 'MEI', 'SAM' ]
[ 1, 2, 3 ]`}>

```js
const numbers = [1, 2, 3];
const doubled = numbers.map((n) => n * 2);
console.log(doubled);

const loud = ["mei", "sam"].map((name) => name.toUpperCase());
console.log(loud);

console.log(numbers); // оригинал не изменился
```

</CodeExample>

У нового массива всегда **та же длина**, что и у исходного.

<Callout type="warning" title="Не забудьте return">

Если у стрелочной функции есть фигурные скобки, ей нужен `return`. Без него колбэк вернёт `undefined`:

```js
[1, 2, 3].map((n) => { n * 2 });        // [ undefined, undefined, undefined ]
[1, 2, 3].map((n) => { return n * 2; }); // [ 2, 4, 6 ]
[1, 2, 3].map((n) => n * 2);             // [ 2, 4, 6 ]
```

</Callout>

## filter: оставить только некоторые элементы

`filter` оставляет элементы, для которых колбэк возвращает `true`, а остальные отбрасывает:

<CodeExample output={`[ 72, 95, 88 ]
[ 'kiwi', 'fig' ]`}>

```js
const scores = [72, 45, 95, 30, 88];
const passed = scores.filter((score) => score >= 50);
console.log(passed);

const fruits = ["banana", "kiwi", "fig", "mango"];
const short = fruits.filter((fruit) => fruit.length <= 4);
console.log(short);
```

</CodeExample>

## find и findIndex: первое совпадение

Когда нужен только **один** элемент, `find` возвращает первый подходящий. `findIndex` вместо него возвращает его позицию:

<CodeExample output={`45
1
undefined
-1`}>

```js
const scores = [72, 45, 95, 30, 88];

console.log(scores.find((s) => s < 50));
console.log(scores.findIndex((s) => s < 50));

console.log(scores.find((s) => s > 100));      // совпадений нет
console.log(scores.findIndex((s) => s > 100)); // совпадений нет
```

</CodeExample>

Заметьте: `30` тоже меньше 50, но `find` останавливается на **первом** совпадении. Если нужны все, используйте `filter`.

## some и every: вопросы «да или нет»

<CodeExample output={`true
false`}>

```js
const ages = [12, 15, 19, 11];

console.log(ages.some((age) => age >= 18));  // хотя бы один?
console.log(ages.every((age) => age >= 12)); // все?
```

</CodeExample>

## reduce: свести массив к одному значению

`reduce` проходит по массиву и несёт с собой промежуточный результат, который часто называют **аккумулятором (accumulator)**. Колбэк получает аккумулятор и текущий элемент и возвращает новый аккумулятор. Второй аргумент `reduce` — начальное значение:

<CodeExample output={`20
95`}>

```js
const prices = [4, 10, 6];
const total = prices.reduce((sum, price) => sum + price, 0);
console.log(total);

const scores = [72, 45, 95, 30];
const best = scores.reduce((max, s) => (s > max ? s : max), 0);
console.log(best);
```

</CodeExample>

Вот как шаг за шагом вычисляется `total`:

| Шаг  | `sum` (на входе)  | `price` | Колбэк возвращает |
| ---- | ----------------- | ------- | ----------------- |
| 1    | `0` (начало)      | `4`     | `4`               |
| 2    | `4`               | `10`    | `14`              |
| 3    | `14`              | `6`     | `20`              |

<Callout type="tip" title="Всегда задавайте reduce начальное значение">

Передавайте начальное значение вроде `0`, `""`, `[]` или `{}` вторым аргументом. Без него `reduce` на пустом массиве падает с ошибкой `TypeError`.

</Callout>

## Цепочки методов

Раз `map` и `filter` возвращают массивы, можно сразу вызвать следующий метод на результате. Это называется **цепочкой вызовов (chaining)**, и читается она как рецепт:

<CodeExample output="100">

```js
const prices = [12, 5, 30, 8];

const result = prices
  .filter((p) => p >= 8)           // [12, 30, 8]
  .map((p) => p * 2)               // [24, 60, 16]
  .reduce((sum, p) => sum + p, 0); // 100

console.log(result);
```

</CodeExample>

Если записывать каждый шаг на отдельной строке, даже длинные цепочки легко читать.

## Сортировка

`sort()` упорядочивает элементы. Для слов он работает отлично, а вот с числами преподносит неприятный сюрприз:

<CodeExample output={`[ 'Ali', 'Mei', 'Sam', 'Zoe' ]
[ 1, 10, 100, 25, 5 ]`}>

```js
const names = ["Sam", "Zoe", "Ali", "Mei"];
names.sort();
console.log(names);

const numbers = [10, 5, 100, 1, 25];
numbers.sort();
console.log(numbers); // 😱
```

</CodeExample>

По умолчанию `sort` превращает каждый элемент в **строку** и сортирует их как слова в словаре. Как текст `"100"` идёт раньше `"25"`, потому что `"1"` идёт раньше `"2"`.

Чтобы правильно отсортировать числа, передайте `sort` **функцию сравнения (compare function)**. Она получает два элемента, `a` и `b`, и возвращает:

- **отрицательное** число, чтобы поставить первым `a`,
- **положительное** число, чтобы поставить первым `b`,
- `0`, чтобы оставить их как есть.

`a - b` делает ровно это для сортировки по возрастанию, а `b - a` — по убыванию:

<CodeExample output={`[ 1, 5, 10, 25, 100 ]
[ 100, 25, 10, 5, 1 ]
[ 10, 5, 100, 1, 25 ]`}>

```js
const numbers = [10, 5, 100, 1, 25];

const ascending = [...numbers].sort((a, b) => a - b);
const descending = [...numbers].sort((a, b) => b - a);

console.log(ascending);
console.log(descending);
console.log(numbers); // не тронут, ведь мы сортировали копии
```

</CodeExample>

<Callout type="warning" title="sort меняет исходный массив">

В отличие от `map` и `filter`, `sort` переставляет элементы **на месте**. Поэтому в примере выше мы сначала делаем копию через `[...numbers]`. В современных браузерах есть и `toSorted()`, который сам возвращает отсортированную копию.

</Callout>

| Метод               | Что возвращает                        | Меняет оригинал? |
| ------------------- | ------------------------------------- | ---------------- |
| `forEach(fn)`       | ничего (`undefined`)                  | Нет              |
| `map(fn)`           | новый массив той же длины             | Нет              |
| `filter(fn)`        | новый массив с подходящими элементами | Нет              |
| `find(fn)`          | первый подходящий элемент или `undefined` | Нет          |
| `some(fn)` / `every(fn)` | `true` или `false`               | Нет              |
| `reduce(fn, start)` | одно значение                         | Нет              |
| `sort(compare)`     | тот же массив, уже отсортированный    | **Да**           |

Учителю нужны три вспомогательные функции для результатов класса. Используйте методы массивов, а не пишите циклы вручную:

1. `passingScores(scores)` возвращает только баллы от `50` и выше, отсортированные **от большего к меньшему**.
2. `average(scores)` возвращает средний балл (сумму, делённую на количество баллов).
3. `allPassed(scores)` возвращает `true`, если **каждый** балл — `50` или больше.

<Hint>

В первой функции соедините в цепочку `filter` и `sort` и не забудьте функцию сравнения: `(a, b) => b - a`. Для среднего найдите сумму с помощью `reduce`, а в последней функции используйте `every`.

</Hint>

<Solution>

```js
const scores = [72, 45, 95, 30, 88, 60];

function passingScores(scores) {
  return scores
    .filter((score) => score >= 50)
    .sort((a, b) => b - a);
}

function average(scores) {
  const total = scores.reduce((sum, score) => sum + score, 0);
  return total / scores.length;
}

function allPassed(scores) {
  return scores.every((score) => score >= 50);
}

console.log(passingScores(scores)); // [ 95, 88, 72, 60 ]
console.log(average(scores));       // 65
console.log(allPassed(scores));     // false
```

</Solution>

</Exercise>

## Итоги

- Методы массивов принимают **колбэк**, который выполняется по разу для каждого элемента.
- `forEach` просто перебирает; `map` преобразует; `filter` оставляет подходящие.
- `find`/`findIndex` дают первое совпадение; `some`/`every` отвечают «да» или «нет».
- `reduce(fn, start)` сводит всё к одному значению.
- Соединяйте методы в цепочки, чтобы получился пошаговый рецепт.
- `sort` по умолчанию сравнивает как текст и меняет оригинал: для чисел используйте `(a, b) => a - b` и сортируйте копию.
