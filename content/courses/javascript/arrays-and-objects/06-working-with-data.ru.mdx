Данные из реальной жизни обычно приходят в виде **массива объектов**: товары в магазине, сообщения в чате, задачи в списке дел. Каждый объект — это одна **запись (record)**, и у всех записей одинаковые ключи. В этом уроке всё, что вы изучили в модуле, сходится воедино.

## Массивы объектов

Вот небольшой список товаров. Каждый элемент массива — объект, поэтому, чтобы добраться до данных, вы сочетаете индексы массива и имена свойств:

<CodeExample output={`Tea
5
[ 'Tea', 'Juice' ]
{ name: 'Bananas', category: 'fruit', price: 1 }`}>

```js
const products = [
  { name: "Tea", category: "drinks", price: 3 },
  { name: "Apples", category: "fruit", price: 2 },
  { name: "Juice", category: "drinks", price: 4 },
  { name: "Bananas", category: "fruit", price: 1 },
  { name: "Bread", category: "bakery", price: 2.5 },
];

console.log(products[0].name);
console.log(products.length);

const drinks = products.filter((p) => p.category === "drinks");
console.log(drinks.map((p) => p.name));

console.log(products.find((p) => p.price < 2));
```

</CodeExample>

Методы массивов из прошлых уроков работают точно так же. Разница лишь в том, что каждый элемент — объект, поэтому колбэки читают свойства вроде `p.category` и `p.price`.

## Подсчёт сумм

`reduce` идеально подходит для итоговых сумм. У каждого товара в этой корзине есть `price` (цена) и `quantity` (количество):

<CodeExample output={`Товаров: 9
Итого: 11.5`}>

```js
const basket = [
  { name: "Tea", price: 3, quantity: 2 },
  { name: "Apples", price: 0.5, quantity: 6 },
  { name: "Bread", price: 2.5, quantity: 1 },
];

const items = basket.reduce((sum, item) => sum + item.quantity, 0);

const total = basket.reduce(
  (sum, item) => sum + item.price * item.quantity,
  0,
);

console.log(`Товаров: ${items}`);
console.log(`Итого: ${total}`);
```

</CodeExample>

## Подсчёт и группировка

Очень частый вопрос — *«сколько чего?»*. Используйте объект как набор счётчиков, по одному ключу на категорию:

<CodeExample output="{ drinks: 2, fruit: 2, bakery: 1 }">

```js
const products = [
  { name: "Tea", category: "drinks" },
  { name: "Apples", category: "fruit" },
  { name: "Juice", category: "drinks" },
  { name: "Bananas", category: "fruit" },
  { name: "Bread", category: "bakery" },
];

const counts = {};
for (const product of products) {
  const category = product.category;
  counts[category] = (counts[category] ?? 0) + 1;
}

console.log(counts);
```

</CodeExample>

Когда категория встречается впервые, `counts[category]` равно `undefined`, поэтому `?? 0` начинает отсчёт с нуля. Обратите внимание на квадратные скобки: ключ берётся из переменной.

**Группировка (grouping)** устроена так же, только под каждым ключом лежит не число, а массив элементов. На этот раз используем `reduce` с пустым объектом `{}` в качестве начального значения:

<CodeExample output={`drinks: Tea, Juice
fruit: Apples, Bananas
bakery: Bread`}>

```js
const products = [
  { name: "Tea", category: "drinks" },
  { name: "Apples", category: "fruit" },
  { name: "Juice", category: "drinks" },
  { name: "Bananas", category: "fruit" },
  { name: "Bread", category: "bakery" },
];

const groups = products.reduce((acc, product) => {
  acc[product.category] ??= []; // создаём список, если его ещё нет
  acc[product.category].push(product.name);
  return acc;
}, {});

for (const [category, names] of Object.entries(groups)) {
  console.log(`${category}: ${names.join(", ")}`);
}
```

</CodeExample>

Здесь два новых помощника: `a ??= b` присваивает `a` значение `b`, только если `a` равно `null` или `undefined`, а `names.join(", ")` склеивает элементы массива в одну строку, вставляя между ними `", "`.

<Callout type="tip" title="Object.groupBy">

В современных браузерах есть встроенное сокращение `Object.groupBy(products, (p) => p.category)`, которое группирует объекты целиком за вас. Но версию с `reduce` всё равно стоит знать: она работает везде, и её можно приспособить, чтобы считать, суммировать или группировать как угодно.

</Callout>

## Сортировка записей

Чтобы отсортировать объекты, сравнивайте в функции сравнения одно из их свойств. Числа вычитайте. Для текста используйте `localeCompare`: он возвращает отрицательное число, положительное число или `0` — ровно то, что нужно `sort`:

<CodeExample output={`[ 'Bananas', 'Apples', 'Bread', 'Tea', 'Juice' ]
[ 'Apples', 'Bananas', 'Bread', 'Juice', 'Tea' ]`}>

```js
const products = [
  { name: "Tea", price: 3 },
  { name: "Apples", price: 2 },
  { name: "Juice", price: 4 },
  { name: "Bananas", price: 1 },
  { name: "Bread", price: 2.5 },
];

const byPrice = [...products].sort((a, b) => a.price - b.price);
console.log(byPrice.map((p) => p.name));

const byName = [...products].sort((a, b) =>
  a.name.localeCompare(b.name),
);
console.log(byName.map((p) => p.name));
```

</CodeExample>

Не забывайте сортировать **копию** (`[...products]`), чтобы исходный порядок сохранился для всех, кто ещё пользуется этим списком.

## JSON: сохранение и передача данных

Когда данным нужно покинуть вашу программу (сохраниться в файл, в браузер или отправиться на сервер), они путешествуют в виде **текста**. Стандартный текстовый формат для этого — **JSON** (JavaScript Object Notation), и он выглядит почти так же, как объекты JavaScript.

`JSON.stringify` превращает значение в JSON-строку:

<CodeExample output={`{"name":"Tea","price":3,"tags":["hot","drink"]}
string`}>

```js
const tea = { name: "Tea", price: 3, tags: ["hot", "drink"] };

const json = JSON.stringify(tea);
console.log(json);
console.log(typeof json);
```

</CodeExample>

`JSON.parse` делает обратное: превращает JSON-текст снова в настоящие объекты и массивы, с которыми можно работать:

<CodeExample output={`Mei
[ 'математика', 'рисование' ]
2`}>

```js
const text = '{"name":"Mei","subjects":["математика","рисование"]}';

const student = JSON.parse(text);
console.log(student.name);
console.log(student.subjects);
console.log(student.subjects.length);
```

</CodeExample>

Если JSON будут читать люди, передайте два дополнительных аргумента — получится по одному свойству на строку с отступом в 2 пробела:

```js
JSON.stringify(tea, null, 2);
// {
//   "name": "Tea",
//   "price": 3,
//   ...
```

<Callout type="warning" title="JSON строже, чем JavaScript">

В JSON ключи и строки **обязаны** быть в двойных кавычках, а запятые после последнего элемента запрещены. Функции и значения `undefined` `JSON.stringify` просто пропускает. Если передать `JSON.parse` некорректный текст, он выбросит `SyntaxError`. Как безопасно с этим справляться, вы узнаете в модуле **«Ошибки и отладка»**.

</Callout>

Пора собрать мини-проект модуля! Напишите функции, которые анализируют список покупок:

<Hint>

`totalCost` — это `reduce` с начальным значением `0`. `countByCategory` — шаблон подсчёта из этого урока: пустой объект и `(counts[key] ?? 0) + 1`. Для `mostExpensive` отсортируйте копию по `b.price * b.quantity - a.price * a.quantity` и возьмите название первого товара — или используйте `reduce`, чтобы хранить самый дорогой на данный момент.

<Solution>

```js
const shoppingList = [
  { name: "Apples", category: "fruit", price: 0.5, quantity: 6 },
  { name: "Milk", category: "dairy", price: 1.25, quantity: 2 },
  { name: "Bread", category: "bakery", price: 2.5, quantity: 1 },
  { name: "Cheese", category: "dairy", price: 4, quantity: 1 },
  { name: "Bananas", category: "fruit", price: 0.25, quantity: 4 },
];

const lineTotal = (item) => item.price * item.quantity;

function totalCost(list) {
  return list.reduce((sum, item) => sum + lineTotal(item), 0);
}

function countByCategory(list) {
  const counts = {};
  for (const { category } of list) {
    counts[category] = (counts[category] ?? 0) + 1;
  }
  return counts;
}

function mostExpensive(list) {
  const sorted = [...list].sort(
    (a, b) => lineTotal(b) - lineTotal(a),
  );
  return sorted[0].name;
}

function analyse(list) {
  return {
    total: totalCost(list),
    categories: countByCategory(list),
    mostExpensive: mostExpensive(list),
  };
}

console.log(JSON.stringify(analyse(shoppingList)));
```

</Solution>

## Итоги

- Реальные данные обычно представляют собой **массив объектов**; сочетайте индексы и свойства, например `products[0].name`.
- `filter`, `map`, `find` и `reduce` работают с записями так же, как с простыми значениями.
- Считайте и группируйте с помощью объекта со счётчиками или списками: `(counts[key] ?? 0) + 1`.
- Сортируйте записи по свойству: `a.price - b.price` для чисел, `a.name.localeCompare(b.name)` для текста.
- `JSON.stringify` превращает данные в текст; `JSON.parse` — обратно.
