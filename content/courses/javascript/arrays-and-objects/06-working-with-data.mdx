Real-world data usually comes as an **array of objects**: products in a shop, messages in a chat, tasks in a to-do app. Each object is one **record**, and every record has the same keys. In this lesson, everything from the module comes together.

## Arrays of objects

Here is a small product list. Each item in the array is an object, so you combine array indexes and property names to reach the data:

<CodeExample output={`Tea
5
[ 'Tea', 'Juice' ]
{ name: 'Bananas', category: 'fruit', price: 1 }`}>

```js
const products = [
  { name: "Tea", category: "drinks", price: 3 },
  { name: "Apples", category: "fruit", price: 2 },
  { name: "Juice", category: "drinks", price: 4 },
  { name: "Bananas", category: "fruit", price: 1 },
  { name: "Bread", category: "bakery", price: 2.5 },
];

console.log(products[0].name);
console.log(products.length);

const drinks = products.filter((p) => p.category === "drinks");
console.log(drinks.map((p) => p.name));

console.log(products.find((p) => p.price < 2));
```

</CodeExample>

The array methods from earlier work exactly the same way. The only difference is that each item is an object, so the callbacks read properties like `p.category` and `p.price`.

## Adding things up

`reduce` is perfect for totals. Each item in this basket has a `price` and a `quantity`:

<CodeExample output={`Items: 9
Total: 11.5`}>

```js
const basket = [
  { name: "Tea", price: 3, quantity: 2 },
  { name: "Apples", price: 0.5, quantity: 6 },
  { name: "Bread", price: 2.5, quantity: 1 },
];

const items = basket.reduce((sum, item) => sum + item.quantity, 0);

const total = basket.reduce(
  (sum, item) => sum + item.price * item.quantity,
  0,
);

console.log(`Items: ${items}`);
console.log(`Total: ${total}`);
```

</CodeExample>

## Counting and grouping

A very common question is *"how many of each?"*. Use an object as a set of counters, with one key per category:

<CodeExample output="{ drinks: 2, fruit: 2, bakery: 1 }">

```js
const products = [
  { name: "Tea", category: "drinks" },
  { name: "Apples", category: "fruit" },
  { name: "Juice", category: "drinks" },
  { name: "Bananas", category: "fruit" },
  { name: "Bread", category: "bakery" },
];

const counts = {};
for (const product of products) {
  const category = product.category;
  counts[category] = (counts[category] ?? 0) + 1;
}

console.log(counts);
```

</CodeExample>

The first time we see a category, `counts[category]` is `undefined`, so `?? 0` starts it at zero. Notice the brackets: the key comes from a variable.

**Grouping** works the same way, but each key holds an array of items instead of a number. This time we use `reduce` with an empty object `{}` as the starting value:

<CodeExample output={`drinks: Tea, Juice
fruit: Apples, Bananas
bakery: Bread`}>

```js
const products = [
  { name: "Tea", category: "drinks" },
  { name: "Apples", category: "fruit" },
  { name: "Juice", category: "drinks" },
  { name: "Bananas", category: "fruit" },
  { name: "Bread", category: "bakery" },
];

const groups = products.reduce((acc, product) => {
  acc[product.category] ??= []; // create the list if it's missing
  acc[product.category].push(product.name);
  return acc;
}, {});

for (const [category, names] of Object.entries(groups)) {
  console.log(`${category}: ${names.join(", ")}`);
}
```

</CodeExample>

Two new helpers here: `a ??= b` sets `a` to `b` only if `a` is `null` or `undefined`, and `names.join(", ")` glues an array's items into one string with `", "` between them.

<Callout type="tip" title="Object.groupBy">

Modern browsers have a built-in shortcut, `Object.groupBy(products, (p) => p.category)`, which groups the whole objects for you. It's still worth knowing the `reduce` version: it works everywhere, and you can adapt it to count, total or group however you like.

</Callout>

## Sorting records

To sort objects, compare one of their properties inside the compare function. For numbers, subtract. For text, use `localeCompare`, which returns a negative number, a positive number or `0`, exactly what `sort` wants:

<CodeExample output={`[ 'Bananas', 'Apples', 'Bread', 'Tea', 'Juice' ]
[ 'Apples', 'Bananas', 'Bread', 'Juice', 'Tea' ]`}>

```js
const products = [
  { name: "Tea", price: 3 },
  { name: "Apples", price: 2 },
  { name: "Juice", price: 4 },
  { name: "Bananas", price: 1 },
  { name: "Bread", price: 2.5 },
];

const byPrice = [...products].sort((a, b) => a.price - b.price);
console.log(byPrice.map((p) => p.name));

const byName = [...products].sort((a, b) =>
  a.name.localeCompare(b.name),
);
console.log(byName.map((p) => p.name));
```

</CodeExample>

Remember to sort a **copy** (`[...products]`) so the original order is kept for anyone else using the list.

## JSON: saving and sending data

When data has to leave your program (saved to a file, stored in the browser, or sent to a server), it travels as **text**. The standard text format is **JSON** (JavaScript Object Notation), and it looks almost exactly like JavaScript objects.

`JSON.stringify` turns a value into a JSON string:

<CodeExample output={`{"name":"Tea","price":3,"tags":["hot","drink"]}
string`}>

```js
const tea = { name: "Tea", price: 3, tags: ["hot", "drink"] };

const json = JSON.stringify(tea);
console.log(json);
console.log(typeof json);
```

</CodeExample>

`JSON.parse` does the opposite and turns JSON text back into real objects and arrays you can use:

<CodeExample output={`Mei
[ 'maths', 'art' ]
2`}>

```js
const text = '{"name":"Mei","subjects":["maths","art"]}';

const student = JSON.parse(text);
console.log(student.name);
console.log(student.subjects);
console.log(student.subjects.length);
```

</CodeExample>

For JSON that people need to read, pass two extra arguments to get one property per line, indented by 2 spaces:

```js
JSON.stringify(tea, null, 2);
// {
//   "name": "Tea",
//   "price": 3,
//   ...
```

<Callout type="warning" title="JSON is stricter than JavaScript">

In JSON, keys and strings **must** use double quotes, and trailing commas aren't allowed. Functions and `undefined` values are simply left out by `JSON.stringify`. If you give `JSON.parse` invalid text, it throws a `SyntaxError`. You'll learn how to handle that safely in the **Errors & Debugging** module.

</Callout>

4. `analyse(list)` returns a report object `{ total, categories, mostExpensive }` built from the three functions above.

<Hint>

`totalCost` is a `reduce` with a starting value of `0`. `countByCategory` is the counting pattern from this lesson: an empty object and `(counts[key] ?? 0) + 1`. For `mostExpensive`, sort a copy by `b.price * b.quantity - a.price * a.quantity` and take the first item's name, or use `reduce` to keep the biggest so far.

<Solution>

```js
const shoppingList = [
  { name: "Apples", category: "fruit", price: 0.5, quantity: 6 },
  { name: "Milk", category: "dairy", price: 1.25, quantity: 2 },
  { name: "Bread", category: "bakery", price: 2.5, quantity: 1 },
  { name: "Cheese", category: "dairy", price: 4, quantity: 1 },
  { name: "Bananas", category: "fruit", price: 0.25, quantity: 4 },
];

const lineTotal = (item) => item.price * item.quantity;

function totalCost(list) {
  return list.reduce((sum, item) => sum + lineTotal(item), 0);
}

function countByCategory(list) {
  const counts = {};
  for (const { category } of list) {
    counts[category] = (counts[category] ?? 0) + 1;
  }
  return counts;
}

function mostExpensive(list) {
  const sorted = [...list].sort(
    (a, b) => lineTotal(b) - lineTotal(a),
  );
  return sorted[0].name;
}

function analyse(list) {
  return {
    total: totalCost(list),
    categories: countByCategory(list),
    mostExpensive: mostExpensive(list),
  };
}

console.log(JSON.stringify(analyse(shoppingList)));
```

</Solution>

## Recap

- Real data is usually an **array of objects**; combine indexes and properties like `products[0].name`.
- `filter`, `map`, `find` and `reduce` work on records just like on plain values.
- Count and group with an object of counters or lists: `(counts[key] ?? 0) + 1`.
- Sort records by a property: `a.price - b.price` for numbers, `a.name.localeCompare(b.name)` for text.
- `JSON.stringify` turns data into text; `JSON.parse` turns it back.
