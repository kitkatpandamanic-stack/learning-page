До сих пор каждая переменная хранила **одно** значение. Но настоящие программы полны списков: песни в плейлисте, товары в корзине, очки в игре. **Массив (array)** хранит много значений по порядку внутри одной переменной. Вы уже мельком видели массивы в модуле про циклы, а теперь разберёмся с ними как следует.

## Создание массива

Перечислите значения через запятую внутри квадратных скобок. Каждое значение называется **элементом (item, element)**:

<CodeExample output={`[ 'apple', 'banana', 'cherry' ]
3
[]`}>

```js
const fruits = ["apple", "banana", "cherry"];
console.log(fruits);
console.log(fruits.length);

const empty = [];
console.log(empty);
```

</CodeExample>

`.length` показывает, сколько в массиве элементов, — так же, как у строк. Массив может хранить значения любого типа, даже вперемешку, например `["Mei", 12, true]`, но чаще всего в массиве лежат однотипные вещи.

## Индексы: поиск элементов по позиции

Как и символы в строке, позиции в массиве (они называются **индексами (indexes)**) начинаются с **0**:

<CodeExample output={`apple
cherry
cherry
undefined`}>

```js
const fruits = ["apple", "banana", "cherry"];

console.log(fruits[0]);                 // первый элемент
console.log(fruits[fruits.length - 1]); // последний элемент
console.log(fruits.at(-1));             // тоже последний элемент
console.log(fruits[10]);                // здесь ничего нет
```

</CodeExample>

- `.at(-1)` считает с конца: `-1` — последний элемент, `-2` — предпоследний. Читать это гораздо проще, чем `fruits[fruits.length - 1]`.
- Если обратиться к несуществующему индексу, вы получите `undefined`, а не ошибку.

Элемент можно и **изменить**, присвоив значение по его индексу:

<CodeExample output="[ 'apple', 'blueberry', 'cherry' ]">

```js
const fruits = ["apple", "banana", "cherry"];
fruits[1] = "blueberry";
console.log(fruits);
```

</CodeExample>

Погодите, `fruits` — это `const`, как же он может меняться? Запомните этот вопрос: мы ответим на него в конце урока.

## Добавление и удаление элементов

Четыре метода добавляют или удаляют элементы на **концах** массива:

<CodeExample output={`[ 'Mei', 'Sam', 'Ali' ]
[ 'Zoe', 'Mei', 'Sam', 'Ali' ]
Удалён с конца: Ali
Удалён с начала: Zoe
[ 'Mei', 'Sam' ]`}>

```js
const queue = ["Mei", "Sam"];

queue.push("Ali");    // добавить в конец
console.log(queue);

queue.unshift("Zoe"); // добавить в начало
console.log(queue);

const last = queue.pop(); // удалить с конца
console.log(`Удалён с конца: ${last}`);

const first = queue.shift(); // удалить с начала
console.log(`Удалён с начала: ${first}`);
console.log(queue);
```

</CodeExample>

| Метод           | Что делает                   | Что возвращает        |
| --------------- | ---------------------------- | --------------------- |
| `push(item)`    | Добавляет в **конец**        | Новую длину           |
| `pop()`         | Удаляет с **конца**          | Удалённый элемент     |
| `unshift(item)` | Добавляет в **начало**       | Новую длину           |
| `shift()`       | Удаляет с **начала**         | Удалённый элемент     |

<Callout type="tip" title="Пользуйтесь тем, что они возвращают">

`pop()` и `shift()` возвращают удалённый элемент, поэтому его можно сохранить, как `last` и `first` выше. Это идеально подходит для очереди: `shift()` забирает следующего человека в очереди.

</Callout>

## Поиск в массиве

<CodeExample output={`true
false
1
-1`}>

```js
const pets = ["cat", "dog", "panda"];

console.log(pets.includes("panda"));
console.log(pets.includes("lion"));
console.log(pets.indexOf("dog"));
console.log(pets.indexOf("lion"));
```

</CodeExample>

- `includes(value)` отвечает на вопрос «да или нет»: есть ли там такое значение?
- `indexOf(value)` говорит, **где** оно находится, или возвращает `-1`, если его там нет вовсе.

## slice и splice

У этих двух методов почти одинаковые имена, но ведут они себя совсем по-разному.

`slice(start, end)` **копирует** часть массива: от `start` до `end` (не включая `end`). Исходный массив остаётся прежним — точно как `slice` у строк:

<CodeExample output={`[ 'b', 'c' ]
[ 'a', 'b', 'c', 'd', 'e' ]`}>

```js
const letters = ["a", "b", "c", "d", "e"];

const middle = letters.slice(1, 3);
console.log(middle);
console.log(letters); // не изменился
```

</CodeExample>

`splice(start, deleteCount, ...newItems)` **изменяет** исходный массив. Он удаляет элементы, вставляет элементы или делает и то и другое, а возвращает массив удалённых элементов:

<CodeExample output={`[ 'b', 'c' ]
[ 'a', 'd', 'e' ]
[ 'a', 'X', 'd', 'e' ]`}>

```js
const letters = ["a", "b", "c", "d", "e"];

const removed = letters.splice(1, 2); // с индекса 1 удалить 2 элемента
console.log(removed);
console.log(letters); // изменился!

letters.splice(1, 0, "X"); // с индекса 1 удалить 0 элементов и вставить "X"
console.log(letters);
```

</CodeExample>

<Callout type="warning" title="Какой из них меняет мой массив?">

Удобная подсказка для запоминания: s**p**lice — от английского «**p**ermanently», он меняет массив навсегда, а slice просто снимает копию. Если вам нужно только *прочитать* часть массива, используйте `slice`.

</Callout>

## Массивы — это ссылки

Вернёмся к нашей загадке. `const` запрещает **переприсваивать** переменную другому массиву. Но он не мешает менять то, что лежит **внутри** массива:

```js
const scores = [10, 20];
scores.push(30); // можно: тот же массив, просто на один элемент больше
scores = [1, 2]; // TypeError: Assignment to constant variable.
```

Дело в том, что переменная хранит не сам массив, а **ссылку (reference)** на него — что-то вроде адреса. Если скопировать переменную, скопируется адрес, а не массив:

<CodeExample output={`[ 'milk', 'eggs', 'bread' ]
true`}>

```js
const shopping = ["milk", "eggs"];
const sameList = shopping; // это НЕ копия!

sameList.push("bread");
console.log(shopping);
console.log(shopping === sameList);
```

</CodeExample>

Оба имени указывают на **один и тот же** массив, поэтому изменение через одно имя меняет «оба». Чтобы сделать настоящую независимую копию, используйте **оператор расширения (spread)** `...` — он раскладывает элементы в новый массив:

<CodeExample output={`[ 'milk', 'eggs' ]
[ 'milk', 'eggs', 'bread' ]
[ 'milk', 'eggs', 'bread', 'tea', 'jam' ]`}>

```js
const shopping = ["milk", "eggs"];
const copy = [...shopping];
copy.push("bread");

console.log(shopping); // оригинал в безопасности
console.log(copy);

const extras = ["tea", "jam"];
console.log([...copy, ...extras]); // объединяем два массива
```

</CodeExample>

<Callout type="note" title="Сравнение массивов">

`===` для массивов проверяет, указывают ли две переменные на **один и тот же** массив, а не одинаковые ли в них элементы. Поэтому `[1, 2] === [1, 2]` — это `false`: это два разных массива, которые просто выглядят одинаково.

</Callout>

## Итоги

- Массивы создаются с помощью `[ ]`; `.length` считает элементы, а индексы начинаются с `0`.
- `.at(-1)` читает последний элемент; несуществующий индекс даёт `undefined`.
- `push`/`pop` работают с концом массива, `unshift`/`shift` — с началом.
- `includes` проверяет, есть ли значение; `indexOf` находит, где оно (или возвращает `-1`).
- `slice` копирует часть массива; `splice` меняет оригинал.
- Переменные хранят **ссылки** на массивы. Когда нужен независимый массив, копируйте через `[...array]`.
