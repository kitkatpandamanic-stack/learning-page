So far, each variable has held **one** value. But real programs are full of lists: songs in a playlist, items in a basket, scores in a game. An **array** stores many values, in order, inside a single variable. You met arrays briefly in the loops module; now let's learn them properly.

## Creating an array

Put the values inside square brackets, separated by commas. Each value is called an **item** (or **element**):

<CodeExample output={`[ 'apple', 'banana', 'cherry' ]
3
[]`}>

```js
const fruits = ["apple", "banana", "cherry"];
console.log(fruits);
console.log(fruits.length);

const empty = [];
console.log(empty);
```

</CodeExample>

`.length` tells you how many items there are, just like it does for strings. An array can hold any type of value, even a mix like `["Mei", 12, true]`, but most arrays hold one kind of thing.

## Indexes: finding items by position

Just like the characters in a string, array positions (called **indexes**) start at **0**:

<CodeExample output={`apple
cherry
cherry
undefined`}>

```js
const fruits = ["apple", "banana", "cherry"];

console.log(fruits[0]);                 // the first item
console.log(fruits[fruits.length - 1]); // the last item
console.log(fruits.at(-1));             // also the last item
console.log(fruits[10]);                // nothing there
```

</CodeExample>

- `.at(-1)` counts from the end: `-1` is the last item, `-2` the one before it. It's much easier to read than `fruits[fruits.length - 1]`.
- Asking for an index that doesn't exist gives `undefined`, not an error.

You can also **change** an item by assigning to its index:

<CodeExample output="[ 'apple', 'blueberry', 'cherry' ]">

```js
const fruits = ["apple", "banana", "cherry"];
fruits[1] = "blueberry";
console.log(fruits);
```

</CodeExample>

Wait, `fruits` is a `const`, so how can it change? Hold that thought: we'll explain it at the end of this lesson.

## Adding and removing items

Four methods add or remove items at the **ends** of an array:

<CodeExample output={`[ 'Mei', 'Sam', 'Ali' ]
[ 'Zoe', 'Mei', 'Sam', 'Ali' ]
Removed from the end: Ali
Removed from the start: Zoe
[ 'Mei', 'Sam' ]`}>

```js
const queue = ["Mei", "Sam"];

queue.push("Ali");    // add to the end
console.log(queue);

queue.unshift("Zoe"); // add to the start
console.log(queue);

const last = queue.pop(); // remove from the end
console.log(`Removed from the end: ${last}`);

const first = queue.shift(); // remove from the start
console.log(`Removed from the start: ${first}`);
console.log(queue);
```

</CodeExample>

| Method          | What it does                | Gives back            |
| --------------- | --------------------------- | --------------------- |
| `push(item)`    | Adds to the **end**         | The new length        |
| `pop()`         | Removes from the **end**    | The removed item      |
| `unshift(item)` | Adds to the **start**       | The new length        |
| `shift()`       | Removes from the **start**  | The removed item      |

<Callout type="tip" title="Use what they give back">

`pop()` and `shift()` return the item they removed, so you can store it, like `last` and `first` above. That's perfect for a queue: `shift()` takes the next person in line.

</Callout>

## Searching an array

<CodeExample output={`true
false
1
-1`}>

```js
const pets = ["cat", "dog", "panda"];

console.log(pets.includes("panda"));
console.log(pets.includes("lion"));
console.log(pets.indexOf("dog"));
console.log(pets.indexOf("lion"));
```

</CodeExample>

- `includes(value)` answers a yes/no question: is it in there?
- `indexOf(value)` tells you **where** it is, or gives `-1` when it isn't there at all.

## slice vs splice

These two have almost the same name but behave very differently.

`slice(start, end)` **copies** part of an array, from `start` up to (but not including) `end`. The original stays the same, just like `slice` on strings:

<CodeExample output={`[ 'b', 'c' ]
[ 'a', 'b', 'c', 'd', 'e' ]`}>

```js
const letters = ["a", "b", "c", "d", "e"];

const middle = letters.slice(1, 3);
console.log(middle);
console.log(letters); // unchanged
```

</CodeExample>

`splice(start, deleteCount, ...newItems)` **changes** the original array. It removes items, inserts items, or both, and gives back an array of whatever it removed:

<CodeExample output={`[ 'b', 'c' ]
[ 'a', 'd', 'e' ]
[ 'a', 'X', 'd', 'e' ]`}>

```js
const letters = ["a", "b", "c", "d", "e"];

const removed = letters.splice(1, 2); // at index 1, remove 2
console.log(removed);
console.log(letters); // changed!

letters.splice(1, 0, "X"); // at index 1, remove 0, insert "X"
console.log(letters);
```

</CodeExample>

<Callout type="warning" title="Which one changes my array?">

A handy memory trick: s**p**lice **p**ermanently changes the array, while slice just takes a copy. When you only want to *read* part of an array, use `slice`.

</Callout>

## Arrays are references

Back to our mystery. `const` stops you from **reassigning** the variable to a different array. It doesn't stop you from changing what's **inside** the array:

```js
const scores = [10, 20];
scores.push(30); // fine: same array, one more item
scores = [1, 2]; // TypeError: Assignment to constant variable.
```

That's because a variable doesn't hold the array itself. It holds a **reference** to it, a bit like an address. If you copy the variable, you copy the address, not the array:

<CodeExample output={`[ 'milk', 'eggs', 'bread' ]
true`}>

```js
const shopping = ["milk", "eggs"];
const sameList = shopping; // NOT a copy!

sameList.push("bread");
console.log(shopping);
console.log(shopping === sameList);
```

</CodeExample>

Both names point to the **same** array, so changing one changes "both". To make a real, independent copy, use the **spread** syntax `...`, which spreads the items out into a new array:

<CodeExample output={`[ 'milk', 'eggs' ]
[ 'milk', 'eggs', 'bread' ]
[ 'milk', 'eggs', 'bread', 'tea', 'jam' ]`}>

```js
const shopping = ["milk", "eggs"];
const copy = [...shopping];
copy.push("bread");

console.log(shopping); // the original is safe
console.log(copy);

const extras = ["tea", "jam"];
console.log([...copy, ...extras]); // join two arrays
```

</CodeExample>

<Callout type="note" title="Comparing arrays">

`===` on arrays checks whether two variables point to the **same** array, not whether they contain the same items. So `[1, 2] === [1, 2]` is `false`: they are two different arrays that happen to look alike.

</Callout>

Build two helpers for a music app:

1. `addSong(playlist, song)` adds `song` to the **end** of the playlist, but only if it isn't already in it. It returns the playlist's new length.
2. `withoutFirst(playlist)` returns a **new** array with every song except the first one. The original playlist must not change.

<Hint>

In `addSong`, check with `includes` before you `push`, then return `playlist.length`. For `withoutFirst`, which method copies part of an array without changing it? Remember that `shift()` would change the original.

</Hint>

<Solution>

```js
function addSong(playlist, song) {
  if (!playlist.includes(song)) {
    playlist.push(song);
  }
  return playlist.length;
}

function withoutFirst(playlist) {
  return playlist.slice(1);
}

const playlist = ["Intro", "Bamboo Beats"];
console.log(addSong(playlist, "Night Walk")); // 3
console.log(addSong(playlist, "Intro"));      // still 3
console.log(withoutFirst(playlist));
console.log(playlist);
```

</Solution>

## Recap

- Create arrays with `[ ]`; `.length` counts the items and indexes start at `0`.
- `.at(-1)` reads the last item; a missing index gives `undefined`.
- `push`/`pop` work on the end, `unshift`/`shift` on the start.
- `includes` checks if a value is there; `indexOf` finds where (or `-1`).
- `slice` copies part of an array; `splice` changes the original.
- Variables hold **references** to arrays. Copy with `[...array]` when you need an independent array.
