В прошлом уроке ваш код менял страницу один раз, сразу после загрузки. Настоящие страницы ждут, пока пользователь **что-нибудь сделает**: нажмёт кнопку, напечатает текст в поле, нажмёт клавишу, отправит форму. Каждое такое действие вызывает **событие** (event), и вы можете сказать JavaScript, что делать, когда оно происходит. 🖱️

## Слушаем клики

`addEventListener` принимает две вещи: **название события** и **функцию**, которая будет запускаться каждый раз, когда оно происходит. Такая функция называется **обработчиком события** (event listener, или **handler**).

<TryIt
  html={`<button id="like">🤍 Нравится</button>
<p id="info">Пока это никому не понравилось.</p>`}
  code={`const likeButton = document.querySelector("#like");
const info = document.querySelector("#info");
let likes = 0;

likeButton.addEventListener("click", () => {
  likes++;
  info.textContent = \`Понравилось пандам: \${likes}\`;
  likeButton.textContent = "💜 Нравится";
});

console.log("Ждём кликов...");`}
/>

Нажмите **«Запустить»**, а потом несколько раз кликните по кнопке в предпросмотре. Код внутри стрелочной функции выполняется при **каждом** клике, а код снаружи — только один раз.

<Callout type="warning" title="Передавайте функцию, а не вызывайте её">

Пишите `button.addEventListener("click", sayHi)` — **без** скобок после `sayHi`. Со скобками `sayHi()` выполнится сразу же, один раз, и обработчиком станет её возвращаемое значение (обычно `undefined`). Тогда ваша функция никогда не запустится по клику.

</Callout>

## Объект события

Когда событие срабатывает, браузер вызывает ваш обработчик и передаёт ему **объект события** (event object), полный подробностей. Самое полезное его свойство — **`event.target`**: элемент, на котором произошло событие. Благодаря ему одна функция может обслуживать несколько кнопок:

<TryIt
  html={`<p>Как вы себя сегодня чувствуете?</p>
<button class="mood">😄</button>
<button class="mood">😴</button>
<button class="mood">🤩</button>
<p id="result"></p>`}
  code={`const result = document.querySelector("#result");

function pickMood(event) {
  console.log(event.type, event.target);
  result.textContent = \`Ваше настроение: \${event.target.textContent}\`;
}

const buttons = document.querySelectorAll(".mood");
buttons.forEach((button) => {
  button.addEventListener("click", pickMood);
});`}
/>

Параметр можно назвать как угодно, но большинство разработчиков используют `event` (или коротко `e`).

## Ввод текста: input и change

У текстовых полей есть два удобных события:

- **`input`** срабатывает при **каждом изменении** значения: на каждую напечатанную, вставленную или удалённую букву.
- **`change`** срабатывает, когда изменение **завершено**: у текстового поля — когда пользователь уходит из него, а у чекбоксов и выпадающих списков — сразу после выбора нового варианта.

<TryIt
  html={`<p><input id="bio" placeholder="Напишите пару слов о себе"></p>
<p id="counter">0 / 30</p>
<select id="snack">
  <option>Бамбук</option>
  <option>Яблоки</option>
  <option>Морковь</option>
</select>
<p id="choice"></p>`}
  code={`const bio = document.querySelector("#bio");
const counter = document.querySelector("#counter");

bio.addEventListener("input", () => {
  counter.textContent = \`\${bio.value.length} / 30\`;
  counter.style.color = bio.value.length > 30 ? "tomato" : "";
});

const snack = document.querySelector("#snack");
snack.addEventListener("change", () => {
  document.querySelector("#choice").textContent =
    \`Любимое лакомство: \${snack.value}\`;
});`}
/>

Используйте `input`, когда нужны обновления **на лету** — например, для счётчика символов или поиска, который фильтрует результаты прямо во время ввода.

## События клавиатуры

Событие **`keydown`** срабатывает при нажатии клавиши. Чтобы узнать, какой именно, прочитайте **`event.key`**: `"a"`, `"A"`, `"Enter"`, `"Escape"`, `"ArrowUp"` и так далее.

<TryIt
  html={`<p><input id="box" placeholder="Кликните сюда и нажимайте клавиши"></p>
<p id="last">Последняя клавиша: нет</p>`}
  code={`const box = document.querySelector("#box");
const last = document.querySelector("#last");

box.addEventListener("keydown", (event) => {
  last.textContent = \`Последняя клавиша: \${event.key}\`;

  if (event.key === "Enter") {
    console.log("Вы нажали Enter! Текст:", box.value);
    box.value = "";
  }
});`}
/>

Сначала кликните внутри поля: события клавиатуры приходят тому элементу, который находится в **фокусе** (focus).

## Формы и preventDefault

Когда форму отправляют (кликом по её кнопке или нажатием Enter в поле), браузер по умолчанию (**default behaviour**) отправляет данные на сервер и **загружает новую страницу**. Такая перезагрузка сотрёт всё, что только что сделал ваш JavaScript!

Чтобы обработать форму самостоятельно, слушайте событие **`submit`** у `<form>` и первым делом вызывайте **`event.preventDefault()`**. Этот вызов говорит браузеру: «Не делай того, что обычно, я сам разберусь».

<TryIt
  html={`<form id="guestbook">
  <input id="guest" placeholder="Ваше имя">
  <button>Оставить запись в гостевой книге</button>
</form>
<p id="thanks"></p>`}
  code={`const guestbook = document.querySelector("#guestbook");
const guest = document.querySelector("#guest");
const thanks = document.querySelector("#thanks");

guestbook.addEventListener("submit", (event) => {
  event.preventDefault();

  const visitor = guest.value.trim();
  if (visitor === "") {
    thanks.textContent = "Сначала введите своё имя.";
    return;
  }

  thanks.textContent = \`Спасибо, что заглянули, \${visitor}! 🐼\`;
  guest.value = "";
});`}
/>

<Callout type="tip" title="Слушайте форму, а не кнопку">

Слушайте `submit` у `<form>`, а не `click` у её кнопки. Тогда всё сработает **и** при клике по кнопке, **и** при нажатии Enter, а встроенные проверки браузера (например, обязательные поля `required`) продолжат работать.

</Callout>

## Делегирование событий

Представьте список из 100 пунктов. Вместо того чтобы добавлять 100 обработчиков, можно добавить **один** — родительскому элементу. События **всплывают** (bubble up): клик по `<li>` считается и кликом по его `<ul>`. Внутри обработчика `event.target` подскажет, по какому пункту кликнули на самом деле. Этот приём называется **делегированием событий** (event delegation).

<TryIt
  html={`<style>
  li { cursor: pointer; }
  .done { text-decoration: line-through; opacity: 0.5; }
</style>
<p>Кликните по делу, чтобы отметить его выполненным:</p>
<ul id="chores">
  <li>Полить бамбук</li>
  <li>Прибраться в берлоге</li>
  <li>Помыть миски</li>
</ul>`}
  code={`const chores = document.querySelector("#chores");

chores.addEventListener("click", (event) => {
  if (event.target.matches("li")) {
    event.target.classList.toggle("done");
    console.log("Переключено:", event.target.textContent);
  }
});`}
/>

`event.target.matches("li")` проверяет, подходит ли элемент, по которому кликнули, под CSS-селектор, поэтому клики по пустым местам самого списка игнорируются. По-настоящему делегирование раскрывается в следующем уроке, где вы будете добавлять в списки новые пункты: обработчик родителя автоматически сработает и для них.

Соберите небольшую форму регистрации:

1. Пока пользователь печатает в `#username`, показывайте в `#count`, сколько символов он ввёл (используйте событие `input`).
2. Когда форму отправляют, не давайте странице перезагрузиться. Затем:
   - если имя пользователя короче 3 символов, запишите в `#message` текст `Слишком коротко!`;
   - иначе запишите в `#message` текст `Добро пожаловать, <имя>!` (например, `Добро пожаловать, Panda!`), очистите поле и верните `#count` к `0`.

Попробуйте в предпросмотре: введите имя и нажмите Enter или кнопку **«Зарегистрироваться»**.

<Hint>

Добавьте два обработчика: `input.addEventListener("input", ...)` и `form.addEventListener("submit", (event) => { ... })`. Длина текста — это `input.value.length`. В обработчике `submit` сначала вызовите `event.preventDefault()`, а затем проверьте длину с помощью `if...else`.

</Hint>

<Solution>

```js
const form = document.querySelector("#signup");
const input = document.querySelector("#username");
const count = document.querySelector("#count");
const message = document.querySelector("#message");

input.addEventListener("input", () => {
  count.textContent = input.value.length;
});

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const username = input.value;

  if (username.length < 3) {
    message.textContent = "Слишком коротко!";
  } else {
    message.textContent = `Добро пожаловать, ${username}!`;
    input.value = "";
    count.textContent = 0;
  }
});
```

</Solution>

## Итоги

- `element.addEventListener("event", listener)` запускает `listener` каждый раз, когда происходит событие. Передавайте функцию, а не вызывайте её.
- Частые события: `click`, `input` (каждое изменение), `change` (изменение завершено), `keydown` (читайте `event.key`) и `submit`.
- Обработчик получает **объект события**; `event.target` — это элемент, на котором произошло событие.
- В обработчике `submit` вызывайте `event.preventDefault()`, чтобы браузер не перезагружал страницу.
- **Делегирование событий**: благодаря всплытию один обработчик на родителе обрабатывает события всех его дочерних элементов.
