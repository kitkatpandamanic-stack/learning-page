До сих пор ваш код только печатал в консоль. Пора менять **настоящую веб-страницу**! Когда браузер загружает HTML, он превращает его в структуру объектов, которая называется **DOM** (Document Object Model, объектная модель документа). JavaScript может читать и менять эти объекты, и страница сразу же обновляется. 🎨

В этом модуле у примеров есть **живой предпросмотр**: измените код, нажмите **«Запустить»** и посмотрите, как меняется страница.

## Что такое DOM?

Возьмём небольшой кусочек HTML:

```html
<body>
  <h1>Кафе «Панда»</h1>
  <ul>
    <li>Бамбуковый чай</li>
    <li>Пирог из листьев</li>
  </ul>
</body>
```

Браузер строит из него **дерево**. Каждый тег становится объектом-**элементом** (element), а элементы внутри других элементов становятся их **дочерними элементами** (children):

```text
document
└── body
    ├── h1  "Кафе «Панда»"
    └── ul
        ├── li  "Бамбуковый чай"
        └── li  "Пирог из листьев"
```

Всё дерево доступно в JavaScript через глобальный объект `document`. Измените объект в дереве — и браузер перерисует эту часть страницы.

<TryIt
  html={`<h1>Кафе «Панда»</h1>
<ul>
  <li>Бамбуковый чай</li>
  <li>Пирог из листьев</li>
</ul>`}
  code={`const heading = document.querySelector("h1");

console.log(heading);
console.log(heading.textContent);

heading.textContent = "Кафе «Панда» открыто! ☕";`}
/>

Заголовок на странице изменился, хотя в HTML по-прежнему написано «Кафе „Панда“». JavaScript изменил **DOM**, а страница всегда показывает именно DOM.

## Поиск элементов

Прежде чем менять элемент, его нужно **выбрать**. `document.querySelector()` принимает **CSS-селектор** (selector) и возвращает **первый** подходящий элемент:

| Селектор         | Что находит                               |
| ---------------- | ----------------------------------------- |
| `"h1"`           | первый элемент `<h1>`                     |
| `"#menu"`        | элемент с `id="menu"`                     |
| `".price"`       | первый элемент с классом `price`          |
| `"#menu li"`     | первый `<li>` внутри `#menu`              |

Чтобы получить **все** подходящие элементы, используйте `document.querySelectorAll()`. Он возвращает **NodeList** — коллекцию, которая во многом похожа на массив: у неё есть `.length`, можно обращаться по индексам и перебирать её с помощью `forEach` или `for...of`.

<TryIt
  html={`<h2 id="title">Меню на сегодня</h2>
<ul id="menu">
  <li class="item">Бамбуковый чай</li>
  <li class="item">Пирог из листьев</li>
  <li class="item">Бамбуковый суп</li>
</ul>`}
  code={`const title = document.querySelector("#title");
console.log(title);

const items = document.querySelectorAll(".item");
console.log(items);
console.log(items.length);

items.forEach((item, index) => {
  item.textContent = \`\${index + 1}. \${item.textContent}\`;
});

console.log(document.querySelector("#nothing"));`}
/>

Обратите внимание на последнюю строку: если ничего не нашлось, `querySelector` возвращает `null`.

<Callout type="warning" title="Осторожно с null">

Если вы опечатаетесь в селекторе, то получите `null`, и следующая строка упадёт с ошибкой вроде `TypeError: Cannot set properties of null`. Увидели такую ошибку — первым делом проверьте селектор: не забыли ли вы `#` или `.`?

</Callout>

## Меняем текст: textContent и innerHTML

Есть два распространённых способа изменить содержимое элемента:

- **`textContent`** читает или задаёт **обычный текст**. Символы `<` и `>` показываются как есть и никогда не превращаются в теги.
- **`innerHTML`** читает или задаёт **HTML** внутри элемента. Теги в строке становятся настоящими элементами.

<TryIt
  html={`<p id="one"></p>
<p id="two"></p>`}
  code={`const one = document.querySelector("#one");
const two = document.querySelector("#two");

one.textContent = "Я <strong>очень</strong> голоден";
two.innerHTML = "Я <strong>очень</strong> голоден";

console.log(two.innerHTML);
console.log(two.textContent);`}
/>

Первый абзац показывает теги как текст. Второй превращает их в настоящий жирный текст.

<Callout type="danger" title="Никогда не вставляйте пользовательский ввод в innerHTML">

Если вставить в `innerHTML` текст, который ввёл пользователь, он сможет написать HTML, запускающий его собственный код на вашей странице. Такая атака называется **XSS** (cross-site scripting, межсайтовый скриптинг). Для всего, что пришло от пользователя, всегда используйте `textContent`. `innerHTML` подходит только для HTML, который вы написали сами.

</Callout>

## Меняем стили и классы

У каждого элемента есть объект `style` для **встроенных стилей** (inline styles). Названия CSS-свойств с дефисами превращаются в **camelCase**: `background-color` становится `backgroundColor`, а `font-size` — `fontSize`. Значения всегда строки, вместе с единицами измерения.

Но когда встроенных стилей много, код становится запутанным. Аккуратнее описать стили в CSS и включать и выключать **классы** через `classList`:

- `classList.add("name")` добавляет класс.
- `classList.remove("name")` удаляет его.
- `classList.toggle("name")` добавляет класс, если его нет, и удаляет, если он есть.
- `classList.contains("name")` возвращает `true` или `false`.

<TryIt
  html={`<style>
  .card { padding: 12px; border-radius: 12px; border: 2px solid #ffffff33; }
  .sold-out { opacity: 0.4; text-decoration: line-through; }
</style>
<p id="banner">Добро пожаловать в кафе!</p>
<div class="card" id="tea">Бамбуковый чай</div>
<div class="card" id="cake">Пирог из листьев</div>`}
  code={`const banner = document.querySelector("#banner");
banner.style.color = "orange";
banner.style.fontSize = "24px";

const cake = document.querySelector("#cake");
cake.classList.add("sold-out");

console.log(cake.classList.contains("sold-out"));
console.log(cake.className);`}
/>

<Callout type="tip">

Используйте `classList` вместо того, чтобы задавать много свойств `style`. Так внешний вид остаётся в CSS, поведение — в JavaScript, а отменить всё можно одним вызовом `classList.remove()`.

</Callout>

## Атрибуты

HTML-атрибуты (attributes) вроде `href`, `src`, `alt`, `disabled` и `placeholder` тоже можно читать и менять. Для этого есть общие методы `getAttribute()` и `setAttribute()`, а можно обращаться напрямую к соответствующему **свойству** (property) элемента:

<TryIt
  html={`<a id="link" href="#home">На главную</a>
<p><input id="search" placeholder="Поиск..."></p>
<button id="order">Заказать</button>`}
  code={`const link = document.querySelector("#link");
console.log(link.getAttribute("href"));

link.setAttribute("href", "#menu");
link.textContent = "Посмотреть меню";

const search = document.querySelector("#search");
search.placeholder = "Найти бамбук...";

const order = document.querySelector("#order");
order.disabled = true;
console.log(order.disabled);`}
/>

Для атрибутов со значением «да/нет», таких как `disabled`, `checked` и `hidden`, свойство — это **логическое значение** (boolean). `order.disabled = true` делает кнопку серой и неактивной, а `false` снова её включает.

## Читаем значения из полей ввода

Чтобы узнать, что введено в поле формы, прочитайте его свойство **`value`**. У чекбоксов вместо этого читают **`checked`** (логическое значение).

<TryIt
  html={`<p><input id="name" value="Мэй"></p>
<p><input id="age" type="number" value="4"></p>
<label><input id="vip" type="checkbox" checked> VIP</label>`}
  code={`const panda = document.querySelector("#name").value;
const age = document.querySelector("#age").value;
const vip = document.querySelector("#vip").checked;

console.log(panda, age, vip);
console.log(typeof age);
console.log(Number(age) + 1);`}
/>

<Callout type="note" title="value — всегда строка">

Даже для `type="number"` свойство `value` возвращает **строку**. Перед вычислениями преобразуйте её с помощью `Number()`, иначе `"4" + 1` даст `"41"`.

</Callout>

Пока что код выполняется только один раз — при загрузке страницы. В следующем уроке вы узнаете, как запускать код, когда пользователь **кликает** или **печатает**, чтобы страница могла реагировать.

2. Сделайте цвет текста приветствия `"orange"`.
3. Добавьте класс `done` **каждому** элементу с классом `task`.
4. Отключите кнопку `#save`.

<Hint>

Имя можно получить через `document.querySelector("#name").value`, а приветствие собрать с помощью шаблонной строки. Для шага 3 `querySelectorAll(".task")` вернёт NodeList, который можно перебрать через `forEach`. Для шага 4 задайте свойству кнопки `disabled` значение `true`.

## Итоги

- **DOM** — это дерево объектов, которое браузер строит из вашего HTML. `document` — его корень.
- `querySelector(selector)` находит первое совпадение (или `null`); `querySelectorAll(selector)` находит все совпадения и возвращает их в виде NodeList.
- `textContent` задаёт обычный текст, `innerHTML` — HTML. Никогда не вставляйте пользовательский ввод в `innerHTML`.
- Внешний вид меняют через `element.style.camelCaseName` или, что лучше, через `classList.add/remove/toggle`.
- Атрибуты читают и меняют через `getAttribute`/`setAttribute` или через свойства вроде `href`, `disabled` и `placeholder`.
- Поля формы читают через `.value` (это всегда строка), а чекбоксы — через `.checked`.
