До сих пор вы меняли элементы, которые уже были в HTML. Но большинство приложений показывает то, что **заранее неизвестно**: новые сообщения, результаты поиска, товары в корзине. В этом уроке вы будете **создавать** элементы с помощью JavaScript, строить целые списки из массивов и освоите простой шаблон, который держит страницу в согласии с вашими данными. 🏗️

## Создаём элемент

Новый элемент создаётся в три шага:

1. **Создайте** его с помощью `document.createElement("tag")`.
2. **Заполните** его: задайте `textContent`, классы, атрибуты и так далее.
3. **Добавьте** его на страницу с помощью `parent.append(element)`.

До третьего шага элемент существует только в JavaScript. На странице он появится, только когда вы поместите его внутрь элемента, который там уже есть.

<TryIt
  html={`<style>
  .new { color: #22d3ee; font-weight: bold; }
</style>
<h2>Меню на сегодня</h2>
<ul id="menu">
  <li>Бамбуковый чай</li>
  <li>Пирог из листьев</li>
</ul>`}
  code={`const menu = document.querySelector("#menu");

const item = document.createElement("li");
item.textContent = "Бамбуковый смузи ✨";
item.classList.add("new");

console.log(item);
menu.append(item);

console.log(menu.children.length);`}
/>

`menu.children` — это «живая» коллекция элементов внутри `#menu`, поэтому теперь её длина равна 3.

## Добавляем и удаляем: append, prepend и remove

- `parent.append(element)` добавляет элемент **последним** дочерним.
- `parent.prepend(element)` добавляет элемент **первым** дочерним.
- `element.remove()` убирает элемент со страницы.

`append` и `prepend` принимают и обычные строки — они добавляются как текст.

<TryIt
  html={`<button id="add-first">Добавить в начало</button>
<button id="add-last">Добавить в конец</button>
<button id="remove-last">Удалить последнюю</button>
<ol id="queue">
  <li>Мэй</li>
</ol>`}
  code={`const queue = document.querySelector("#queue");
let next = 1;

function makePanda() {
  const li = document.createElement("li");
  li.textContent = \`Панда \${next}\`;
  next++;
  return li;
}

document.querySelector("#add-first").addEventListener("click", () => {
  queue.prepend(makePanda());
});

document.querySelector("#add-last").addEventListener("click", () => {
  queue.append(makePanda());
});

document.querySelector("#remove-last").addEventListener("click", () => {
  const last = queue.lastElementChild;
  if (last) {
    last.remove();
  }
});`}
/>

`lastElementChild` — последний элемент внутри списка или `null`, если список пуст. Поэтому код проверяет его, прежде чем вызывать `remove()`.

## Строим список из данных

Вот где массивы встречаются с DOM. Переберите массив, создайте по одному элементу на каждый пункт и добавьте каждый на страницу:

<TryIt
  html={`<style>
  .price { color: #a78bfa; margin-left: 8px; }
</style>
<h2>Бамбуковая лавка</h2>
<ul id="products"></ul>`}
  code={`const products = [
  { name: "Свежий бамбук", price: 3 },
  { name: "Бамбуковые чипсы", price: 2.5 },
  { name: "Чай из листьев", price: 4 },
];

const list = document.querySelector("#products");

products.forEach((product) => {
  const li = document.createElement("li");
  li.textContent = product.name;

  const price = document.createElement("span");
  price.className = "price";
  price.textContent = \`£\${product.price.toFixed(2)}\`;

  li.append(price);
  list.append(li);
});

console.log("Показано товаров:", list.children.length);`}
/>

Обратите внимание: `<span>` создаётся и добавляется **внутрь** `<li>`. Так можно постепенно, по кусочку, собирать вложенные структуры.

<Callout type="danger" title="Данные — только через textContent">

Очень хочется собирать HTML-строки вроде `` li.innerHTML = `<b>${product.name}</b>` ``. Но если данные когда-нибудь придут от пользователя (комментарий, имя пользователя), это дыра для XSS. Создавать элементы и задавать `textContent` — всегда безопасно.

</Callout>

## Шаблон render

Когда приложение растёт, держать страницу и данные в согласии становится непросто. Популярный шаблон, на котором построены инструменты вроде React, выглядит так:

1. Храните данные в переменной — это **состояние** (state).
2. Напишите одну функцию **`render()`**, которая очищает список и заново строит его из состояния.
3. Когда что-то происходит, **измените состояние**, а затем вызовите `render()`.

Вы никогда не редактируете список вручную. Страница — это всегда просто картинка состояния.

<TryIt
  html={`<form id="add-form">
  <input id="new-item" placeholder="Добавьте лакомство">
  <button>Добавить</button>
</form>
<ul id="snacks"></ul>
<p id="total"></p>`}
  code={`const snacks = ["Бамбук", "Яблоки"];

const list = document.querySelector("#snacks");
const total = document.querySelector("#total");

function render() {
  list.replaceChildren();
  snacks.forEach((snack) => {
    const li = document.createElement("li");
    li.textContent = snack;
    list.append(li);
  });
  total.textContent = \`Лакомств в списке: \${snacks.length}\`;
}

const form = document.querySelector("#add-form");
const input = document.querySelector("#new-item");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  if (input.value.trim() === "") return;

  snacks.push(input.value.trim());
  input.value = "";
  render();
});

render();`}
/>

`list.replaceChildren()` без аргументов удаляет всё содержимое списка, так что `render()` каждый раз начинает с чистого листа. И обратите внимание на вызов `render()` в самом конце: он рисует начальное состояние при загрузке страницы.

<Callout type="tip" title="Сначала измените данные, потом вызовите render">

Когда появляется баг, шаблон render помогает быстро его найти: либо неверно **состояние** (проверьте его через `console.log`), либо `render()` неправильно его рисует. Третьего места, где что-то может разойтись, просто нет.

</Callout>

## Храним дополнительную информацию в dataset

Иногда элементу нужно помнить данные, которые не показываются на странице, — например, ID товара, к которому он относится. Для этого в HTML есть **data-атрибуты** (data attributes): любые атрибуты, начинающиеся с `data-`. В JavaScript их читают и записывают через **`element.dataset`**. Имена с дефисами превращаются в camelCase: `data-panda-name` становится `dataset.pandaName`.

<TryIt
  html={`<button data-panda-name="Мэй" data-age="4">Мэй</button>
<button data-panda-name="Бао" data-age="7">Бао</button>
<p id="about">Кликните по панде.</p>`}
  code={`const about = document.querySelector("#about");

document.querySelectorAll("button").forEach((button) => {
  button.addEventListener("click", () => {
    const { pandaName, age } = button.dataset;
    about.textContent = \`\${pandaName}: возраст — \${age} лет.\`;
    console.log(button.dataset);
  });
});

const first = document.querySelector("button");
first.dataset.favourite = "yes";
console.log(first.getAttribute("data-favourite"));`}
/>

Значения в dataset — всегда **строки**, поэтому для вычислений используйте `Number()`.

Data-атрибуты отлично сочетаются с шаблоном render и делегированием событий. Каждая кнопка удаления ниже хранит **индекс** своего пункта, а один обработчик на списке удаляет нужный пункт из состояния:

<TryIt
  html={`<style>
  li { margin: 6px 0; }
  li button { margin-left: 8px; padding: 2px 8px; }
</style>
<ul id="todos"></ul>`}
  code={`const todos = ["Съесть бамбук", "Поспать", "Скатиться с горки"];
const list = document.querySelector("#todos");

function render() {
  list.replaceChildren();
  todos.forEach((todo, index) => {
    const li = document.createElement("li");
    li.textContent = todo;

    const button = document.createElement("button");
    button.textContent = "✕";
    button.dataset.index = index;

    li.append(button);
    list.append(li);
  });
}

list.addEventListener("click", (event) => {
  if (event.target.matches("button")) {
    const index = Number(event.target.dataset.index);
    console.log("Удаляем:", todos[index]);
    todos.splice(index, 1);
    render();
  }
});

render();`}
/>

Поскольку обработчик висит на `<ul>`, он продолжает работать и для кнопок, которые `render()` создаёт позже. Вот где делегирование событий окупается.

Пора собрать инструмент выбора цвета, который обновляется прямо на ходу! Используйте всё, что узнали в этом модуле:

1. **`showColour(colour)`** задаёт цвет фона `#preview` и записывает в `#hex` шестнадцатеричный код цвета (например, `#7c3aed`). Вызовите её один раз в начале с `picker.value`, чтобы страница показала начальный цвет.
2. Когда picker вызывает событие **`input`**, показывайте новый цвет.
3. По клику на **«Сохранить цвет»** добавьте `picker.value` в массив `savedColours` (**только если его там ещё нет**), а затем вызовите `renderSaved()`.
4. **`renderSaved()`** очищает `#saved` и создаёт по одному `<li>` на каждый сохранённый цвет: с этим цветом в качестве фона и шестнадцатеричным кодом в `data-color` (`li.dataset.color`).
5. Клик по сохранённому образцу ставит этот цвет в picker и снова показывает его. Используйте **один** обработчик на `#saved` (делегирование событий).

<Hint>

`<input type="color">` отдаёт свой цвет шестнадцатеричной строкой в `picker.value`. В `showColour` задайте `preview.style.backgroundColor = colour`. Чтобы не было повторов, проверьте `savedColours.includes(colour)` перед `push`. В обработчике клика на `#saved` используйте `event.target.matches("li")` и читайте `event.target.dataset.color`.

</Hint>

<Solution>

```js
const picker = document.querySelector("#picker");
const preview = document.querySelector("#preview");
const hex = document.querySelector("#hex");
const saveButton = document.querySelector("#save");
const saved = document.querySelector("#saved");

const savedColours = [];

function showColour(colour) {
  preview.style.backgroundColor = colour;
  hex.textContent = colour;
}

function renderSaved() {
  saved.replaceChildren();
  savedColours.forEach((colour) => {
    const swatch = document.createElement("li");
    swatch.style.backgroundColor = colour;
    swatch.dataset.color = colour;
    swatch.title = colour;
    saved.append(swatch);
  });
}

showColour(picker.value);

picker.addEventListener("input", () => {
  showColour(picker.value);
});

saveButton.addEventListener("click", () => {
  const colour = picker.value;
  if (!savedColours.includes(colour)) {
    savedColours.push(colour);
    renderSaved();
  }
});

saved.addEventListener("click", (event) => {
  if (event.target.matches("li")) {
    const colour = event.target.dataset.color;
    picker.value = colour;
    showColour(colour);
  }
});
```

## Итоги

- Создавайте элементы через `document.createElement("tag")`, заполняйте их и добавляйте на страницу с помощью `append` (в конец) или `prepend` (в начало). Убирайте через `element.remove()`.
- Списки из данных строят так: перебирают массив и создают по одному элементу на пункт. Для данных используйте `textContent`, а не `innerHTML`.
- **Шаблон render**: храните данные в переменной состояния, напишите функцию `render()`, которая строит по ним страницу заново, и вызывайте `render()` после каждого изменения.
- Атрибуты `data-*` хранят дополнительную информацию в элементах; читайте и записывайте их через `element.dataset` (имена в camelCase, значения — строки).
- Делегирование событий вместе с `dataset` позволяет одному обработчику обслуживать кнопки, которые `render()` создаёт позже.
