Путь каждого программиста начинается с одной и той же крошечной программы: заставить компьютер сказать **«Привет, мир!»**. Давайте напишем вашу.

## Ваша первая строка кода

<CodeExample output="Привет, мир!">

```js title="hello.js"
console.log("Привет, мир!");
```

</CodeExample>

Вот что делает каждая часть:

- `console` — встроенный инструмент, который показывает сообщения разработчикам.
- `.log(...)` говорит консоли (console) вывести всё, что вы поместили в скобки.
- `"Привет, мир!"` — это кусочек текста, он называется **строкой** (string). Строки пишутся в кавычках.
- Точка с запятой `;` в конце отмечает конец инструкции (statement).

<Callout type="tip" title="Где появляется вывод?">

В каждом браузере есть **консоль**. Нажмите `F12` (или `Cmd + Option + J` на Mac), откройте вкладку **Console**, вставьте код и нажмите Enter. Скоро вы сможете запускать код прямо внутри этих уроков.

</Callout>

## Вывод нескольких строк

Программа выполняется **сверху вниз**, по одной строке за раз:

<CodeExample output={`Привет, мир!
Я изучаю JavaScript.
Это третья строка.`}>

```js
console.log("Привет, мир!");
console.log("Я изучаю JavaScript.");
console.log("Это третья строка.");
```

</CodeExample>

## Комментарии

Строки, которые начинаются с `//`, — это **комментарии** (comments). JavaScript их игнорирует: это заметки для людей.

```js
// Эту строку JavaScript игнорирует
console.log("А эта выполняется!");
```

<Callout type="warning">

Текст нужно брать в кавычки. `console.log(Hello)` без кавычек — это ошибка: JavaScript решит, что `Hello` — имя чего-то, о чём он не знает.

</Callout>

## Итоги

- `console.log()` выводит сообщение.
- Текст пишется в кавычках и называется строкой.
- Код выполняется сверху вниз.
- `//` начинает комментарий.
