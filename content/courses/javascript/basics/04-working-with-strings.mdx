Programs work with text all the time: names, messages, search terms. Let's learn the most useful things you can do with strings. At the end, you'll put everything from this module together and build your first mini-project: a **greeting card generator**. 💌

## Joining strings

The `+` operator glues strings together. This is called **concatenation**:

<CodeExample output="Hello, Panda!">

```js
const name = "Panda";
console.log("Hello, " + name + "!");
```

</CodeExample>

## Template literals

Gluing with `+` gets messy quickly. **Template literals** use backticks and let you drop values straight into the text with `${...}`:

<CodeExample output="Panda is 5 years old.">

```js
const name = "Panda";
const age = 5;
console.log(`${name} is ${age} years old.`);
```

</CodeExample>

You can even put small calculations inside `${...}`:

<CodeExample output="Next year Panda will be 6.">

```js
const name = "Panda";
const age = 5;
console.log(`Next year ${name} will be ${age + 1}.`);
```

</CodeExample>

<Callout type="tip">

Backticks are on the key to the left of `1` on most keyboards. Template literals are the modern way to build strings, so reach for them first.

</Callout>

## Length and characters

Every string knows how long it is. Characters are counted from **0**:

<CodeExample output={`5
P
a`}>

```js
const word = "Panda";
console.log(word.length);
console.log(word[0]);
console.log(word[word.length - 1]);
```

</CodeExample>

## String methods

Strings come with built-in **methods**: actions you call with a dot.

<CodeExample output={`HELLO WORLD
hello world
true
World`}>

```js
const text = "Hello World";
console.log(text.toUpperCase());
console.log(text.toLowerCase());
console.log(text.includes("World"));
console.log(text.slice(6));
```

</CodeExample>

| Method               | What it does                                 |
| -------------------- | -------------------------------------------- |
| `.toUpperCase()`     | All capitals                                 |
| `.toLowerCase()`     | All lowercase                                |
| `.includes("x")`     | `true` if the text contains `"x"`            |
| `.slice(start, end)` | Part of the string from `start` up to `end`  |
| `.trim()`            | Removes spaces from both ends                |

<Callout type="note">

Methods **don't change** the original string; they give you a new one. Strings in JavaScript can never be modified in place.

</Callout>

## Chaining methods

Because a method gives you back a new string, you can call another method on that result straight away. This is called **chaining**:

<CodeExample output={`HELLO PANDA
15
11`}>

```js
const typed = "  Hello Panda  ";
console.log(typed.trim().toUpperCase());
console.log(typed.length);
console.log(typed.trim().length);
```

</CodeExample>

Read a chain from left to right: `typed.trim()` makes a tidy copy, then `.toUpperCase()` works on that copy. Notice that the spaces count too: `typed` is 15 characters long, but only 11 are left once you trim it.

## Common mistakes

These three trip up almost everyone at first:

<CodeExample output={`[  london ]
Hi, function toUpperCase() { [native code] }!
Hi, \${name}!`}>

```js
const city = "  london ";
city.trim(); // the tidy copy is thrown away
console.log(`[${city}]`);

const name = "Zara";
console.log(`Hi, ${name.toUpperCase}!`); // forgot the ()
console.log("Hi, ${name}!"); // normal quotes, not backticks
```

</CodeExample>

- `city.trim()` on its own line does nothing useful: the original never changes. Keep the result in a variable, for example `const cleanCity = city.trim();`.
- A method needs its brackets `()` to run. Without them, you print the method itself.
- `${...}` only works inside backticks. In normal quotes it's just text.

Press **Check**. Then change the details at the top (try `"  TOM"`, `"new year"` and `12`) and press **Run** again: a brand-new card, and you didn't touch a single `console.log`. That's what makes it a generator.

<Hint>

Work in two steps. First make a tidy copy of `friend` and keep it in a new `const`, so every line of the card can reuse it. Then write the seven `console.log` lines, top to bottom, with template literals.

</Hint>

<Hint>

A capitalised name is two pieces glued together: the first character in capitals, plus everything after it in lowercase. You've seen how to get the first character with `[0]`, and `.slice()` with one number gives you everything from that position to the end.

</Hint>

<Solution>

```js
const friend = "  zARA ";
const occasion = "birthday";
const age = 9;
const sender = "Panda";
const border = "*~*~*~*~*~*~*~*~*~*~*~*~*";

// 1. Tidy the name once, then reuse it
const cleanName = friend.trim(); // "zARA"
const niceName = cleanName[0].toUpperCase() + cleanName.slice(1).toLowerCase(); // "Zara"

// 2. Print the card
console.log(border);
console.log(`HAPPY ${occasion.toUpperCase()}, ${cleanName.toUpperCase()}!`);
console.log(border);
console.log(`Dear ${niceName},`);
console.log(`You're ${age} now, and ${age + 1} is just around the corner!`);
console.log(`Fun fact: your name has ${cleanName.length} letters.`);
console.log(`With love from ${sender}`);
```

</Solution>

## Recap

- Join strings with `+` or, better, with template literals and `${...}`.
- `.length` gives the number of characters; positions start at `0`.
- Methods like `.toUpperCase()` and `.includes()` return new values, so keep the result in a variable.
- Chain methods to do several steps in one go: `text.trim().toUpperCase()`.
- You built a greeting card generator: change the values at the top and the whole card follows.
