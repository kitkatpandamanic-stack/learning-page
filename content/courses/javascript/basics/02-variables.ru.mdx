**Переменная** (variable) — это коробка с именем, в которой лежит значение (value). Вместо того чтобы снова и снова писать одно и то же значение, вы сохраняете его один раз и обращаетесь к нему по имени.

## Создаём переменную с `const`

<CodeExample output="Панда">

```js
const name = "Панда";
console.log(name);
```

</CodeExample>

- `const` создаёт переменную, значение которой **нельзя переприсвоить**.
- `name` — это имя переменной.
- `=` кладёт значение справа в коробку слева.

<Callout type="note">

Обратите внимание: внутри `console.log` вокруг `name` нет кавычек. Без кавычек JavaScript находит переменную и выводит её **значение**. С кавычками `"name"` просто вывело бы слово *name*.

</Callout>

## Меняем значения с `let`

Если значение потом нужно будет изменить, используйте `let`:

<CodeExample output={`0
10`}>

```js {4}
let score = 0;
console.log(score);

score = 10;
console.log(score);
```

</CodeExample>

`let` пишется только в первый раз. Дальше используйте просто имя.

Попытка переприсвоить `const` вызывает ошибку:

```js
const lives = 3;
lives = 2; // TypeError: Assignment to constant variable.
```

## Что же выбрать?

По умолчанию используйте `const`. Переходите на `let`, только когда знаете, что значение будет меняться, — например, счёт в игре или счётчик. Так код легче читать: сразу видно, какие значения остаются неизменными.

<Callout type="warning" title="А как же var?">

В старом коде встречается `var`. Он работает по-другому и порой неожиданно, поэтому в современном JavaScript вместо него используют `let` и `const`. Пока можете смело не обращать на `var` внимания.

</Callout>

## Правила именования

- Имена могут содержать буквы, цифры, `_` и `$`, но **не могут начинаться с цифры**.
- Имена чувствительны к регистру: `score` и `Score` — разные переменные.
- Для имён из нескольких слов используйте **camelCase**: `playerName`, `highScore`.

```js
const playerName = "Мэй";
let highScore = 120;
```

## Итоги

- Переменные хранят значения под определённым именем.
- `const` нельзя переприсвоить, а `let` — можно.
- Предпочитайте `const`, а `let` используйте, когда значение меняется.
- Давайте имена в стиле camelCase, например `playerName`.
