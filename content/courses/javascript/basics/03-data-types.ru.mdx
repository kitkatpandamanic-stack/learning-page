У каждого значения в JavaScript есть **тип** (data type). Тип определяет, что можно делать со значением: числа можно умножать, а предложения — нет.

## Строки: текст

```js
const greeting = "Привет";
const name = 'Панда';
const message = `Привет, ${name}!`; // Привет, Панда!
```

Строки (strings) можно записывать в двойных кавычках, одинарных кавычках или обратных кавычках (backticks). Обратные кавычки позволяют вставлять значения через `${...}` — такие строки называются **шаблонными строками** (template literals). В следующем уроке вы будете часто ими пользоваться.

## Числа

В JavaScript один тип и для целых чисел (numbers), и для дробных:

<CodeExample output="24">

```js
const age = 12;
const price = 9.99;
console.log(age * 2);
```

</CodeExample>

<Callout type="warning" title="Числа в кавычках — это строки">

`"12"` и `12` — разные вещи! Первое — это текст, в котором просто оказались цифры. Числа, с которыми вы хотите считать, пишите **без** кавычек.

</Callout>

## Логические значения: true или false

```js
const isLoggedIn = true;
const hasFinished = false;
```

Логические значения (booleans) отвечают на вопросы «да/нет». В следующем модуле вы будете постоянно использовать их с инструкцией `if`.

## `undefined` и `null`

<CodeExample output="undefined">

```js
let nickname;
console.log(nickname);

const middleName = null;
```

</CodeExample>

- `undefined` означает «значение ещё не задано».
- `null` означает «намеренно пусто»: вы, программист, установили его специально.

## Проверяем тип с помощью `typeof`

```js
console.log(typeof "hi");      // "string"
console.log(typeof 42);        // "number"
console.log(typeof true);      // "boolean"
console.log(typeof undefined); // "undefined"
```

<Callout type="note" title="Знаменитая странность">

`typeof null` даёт `"object"`, а не `"null"`. Это ошибка из самой первой версии JavaScript 1995 года, и её уже никогда не исправят: иначе сломаются старые сайты.

</Callout>

| `boolean`   | `true`         |
| `undefined` | `let x;`       |
