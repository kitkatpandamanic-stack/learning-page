Every programmer's journey starts with the same tiny program: making the computer say **"Hello, World!"**. Let's write yours.

## Your first line of code

```js
console.log("Hello, World!");
```

Here is what each part does:

- `console` is a built-in tool for showing messages to developers.
- `.log(...)` tells the console to print whatever you put inside the brackets.
- `"Hello, World!"` is a piece of text, called a **string**. Strings go inside quotes.
- The `;` at the end marks the end of the statement.

When the program runs, you will see this output:

```text
Hello, World!
```

## Printing more than one line

Programs run from top to bottom, one line at a time:

```js
console.log("Hello, World!");
console.log("I am learning JavaScript.");
console.log("This is line three.");
```

## Comments

Lines starting with `//` are **comments**. JavaScript ignores them; they are notes for humans.

```js
// This line is ignored by JavaScript
console.log("But this one runs!");
```

## Recap

- `console.log()` prints a message.
- Text goes inside quotes and is called a string.
- Code runs from top to bottom.
- `//` starts a comment.
