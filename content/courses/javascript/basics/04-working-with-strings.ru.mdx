Программы постоянно работают с текстом: имена, сообщения, поисковые запросы. Давайте разберём самое полезное, что можно делать со строками (strings). А в конце вы соберёте всё, что узнали в этом модуле, в свой первый мини-проект — **генератор открыток**. 💌

## Соединение строк

Оператор (operator) `+` склеивает строки. Это называется **конкатенацией** (concatenation):

<CodeExample output="Привет, Панда!">

```js
const name = "Панда";
console.log("Привет, " + name + "!");
```

</CodeExample>

## Шаблонные строки

Склеивание через `+` быстро превращается в путаницу. **Шаблонные строки** (template literals) пишутся в обратных кавычках и позволяют вставлять значения прямо в текст через `${...}`:

<CodeExample output="Меня зовут Панда, мне 5 лет.">

```js
const name = "Панда";
const age = 5;
console.log(`Меня зовут ${name}, мне ${age} лет.`);
```

</CodeExample>

Внутрь `${...}` можно даже поместить небольшие вычисления:

<CodeExample output="Я Панда, и через год мне будет 6.">

```js
const name = "Панда";
const age = 5;
console.log(`Я ${name}, и через год мне будет ${age + 1}.`);
```

</CodeExample>

<Callout type="tip">

На большинстве клавиатур обратная кавычка находится на клавише слева от `1` (в английской раскладке). Шаблонные строки — современный способ собирать строки, так что используйте их в первую очередь.

</Callout>

## Длина и символы

Каждая строка знает свою длину. Символы нумеруются с **0**:

<CodeExample output={`5
П
а`}>

```js
const word = "Панда";
console.log(word.length);
console.log(word[0]);
console.log(word[word.length - 1]);
```

</CodeExample>

## Методы строк

У строк есть встроенные **методы** (methods) — действия, которые вызываются через точку.

<CodeExample output={`HELLO WORLD
hello world
true
World`}>

```js
const text = "Hello World";
console.log(text.toUpperCase());
console.log(text.toLowerCase());
console.log(text.includes("World"));
console.log(text.slice(6));
```

</CodeExample>

| Метод                | Что делает                                       |
| -------------------- | ------------------------------------------------ |
| `.toUpperCase()`     | Все буквы заглавные                              |
| `.toLowerCase()`     | Все буквы строчные                               |
| `.includes("x")`     | `true`, если текст содержит `"x"`                |
| `.slice(start, end)` | Часть строки от `start` до `end` (не включая)    |
| `.trim()`            | Убирает пробелы с обоих концов                   |

<Callout type="note">

Методы **не меняют** исходную строку — они возвращают новую. Строки в JavaScript вообще нельзя изменить на месте.

</Callout>

## Цепочки методов

Раз метод возвращает новую строку, у этого результата можно сразу вызвать следующий метод. Это называется **цепочкой вызовов** (chaining):

<CodeExample output={`ПРИВЕТ, ПАНДА
17
13`}>

```js
const typed = "  Привет, Панда  ";
console.log(typed.trim().toUpperCase());
console.log(typed.length);
console.log(typed.trim().length);
```

</CodeExample>

Цепочку читают слева направо: `typed.trim()` делает аккуратную копию без пробелов по краям, а `.toUpperCase()` работает уже с этой копией. Заметьте, что пробелы тоже считаются: в `typed` 17 символов, а после `trim()` остаётся 13.

## Частые ошибки

На этих трёх ошибках поначалу спотыкаются почти все:

<CodeExample output={`[  москва ]
Привет, function toUpperCase() { [native code] }!
Привет, \${name}!`}>

```js
const city = "  москва ";
city.trim(); // аккуратная копия просто теряется
console.log(`[${city}]`);

const name = "Зара";
console.log(`Привет, ${name.toUpperCase}!`); // забыли ()
console.log("Привет, ${name}!"); // обычные кавычки, а не обратные
```

</CodeExample>

- `city.trim()` в отдельной строке ничего не даёт: исходная строка не меняется. Сохраните результат в переменную, например `const cleanCity = city.trim();`.
- Чтобы метод сработал, нужны скобки `()`. Без них выводится сам метод.
- `${...}` работает только внутри обратных кавычек. В обычных кавычках это просто текст.

const friend = "  зАРА ";

## Итоги

- Соединяйте строки через `+` или, что лучше, шаблонными строками и `${...}`.
- `.length` даёт количество символов; позиции начинаются с `0`.
- Методы вроде `.toUpperCase()` и `.includes()` возвращают новые значения, поэтому сохраняйте результат в переменную.
- Цепочка методов делает несколько шагов сразу: `text.trim().toUpperCase()`.
- Вы собрали генератор открыток: меняете значения вверху — и вся открытка меняется вслед за ними.
