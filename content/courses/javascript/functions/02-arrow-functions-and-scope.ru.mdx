Вы уже умеете писать функции. Теперь освоим современный короткий синтаксис, который встречается повсюду, и одну важную идею — **область видимости** (scope).

## Стрелочные функции

**Стрелочная функция** (arrow function) — это более короткий способ записать функцию (function) и сохранить её в переменной:

```js
// Обычная функция
function square(n) {
  return n * n;
}

// То же самое в виде стрелочной функции
const squareArrow = (n) => {
  return n * n;
};
```

Если тело функции — одно выражение (expression), можно убрать фигурные скобки **и** `return`:

<CodeExample output={`25
Привет, Мэй!`}>

```js
const square = (n) => n * n;
const greet = (name) => `Привет, ${name}!`;

console.log(square(5));
console.log(greet("Мэй"));
```

</CodeExample>

<Callout type="note">

Работают оба стиля. Многие разработчики используют `function` для основных именованных функций, а стрелочные — для коротких вспомогательных. На Уровне 1, когда вы начнёте передавать функции в другие функции, вы увидите, почему стрелочные функции так удобны.

</Callout>

## Параметры по умолчанию

Задайте параметру (parameter) запасное значение на случай, если при вызове его не передадут:

<CodeExample output={`Привет, друг!
Привет, Сэм!`}>

```js
const greet = (name = "друг") => `Привет, ${name}!`;

console.log(greet());
console.log(greet("Сэм"));
```

</CodeExample>

## Область видимости: где «живут» переменные

Переменная, созданная **внутри** функции (или любого блока `{ }`), существует только внутри него. Это и называется **областью видимости**:

```js
function makeTea() {
  const water = "горячая";
  console.log(water); // работает: мы внутри функции
}

makeTea();
console.log(water); // ReferenceError: water is not defined
```

Код внутри блока **может** видеть переменные снаружи:

<CodeExample output="Счёт: 10">

```js
const label = "Счёт";

function show(points) {
  console.log(`${label}: ${points}`); // label берётся снаружи
}

show(10);
```

</CodeExample>

<Callout type="tip" title="Чем хороша область видимости">

Область видимости не даёт разным частям программы случайно менять переменные друг друга. В двух функциях может быть переменная с именем `total`, и никакого конфликта не возникнет.

</Callout>

Блоки вроде `if` и циклов тоже имеют свою область видимости, если вы используете `let` или `const`:

```js
if (true) {
  const secret = 42;
}
console.log(secret); // ReferenceError: secret is not defined
```

  starter={`const isEven = (n) => {
  // верните true, если n чётное, и false в противном случае
};

const describe = (n) => {

console.log(describe(4));
console.log(describe(7));

    { name: "isEven(0) — true", check: "isEven(0) === true" },
    { name: 'describe(4) возвращает "4 — чётное"', check: 'describe(4) === "4 — чётное"' },
    { name: 'describe(7) возвращает "7 — нечётное"', check: 'describe(7) === "7 — нечётное"' },
  ]}

Напишите стрелочную функцию `isEven`, которая принимает число и возвращает `true`, если оно чётное, и `false` в противном случае. Затем напишите стрелочную функцию `describe(n)`, которая с помощью `isEven` возвращает строку вроде `"4 — чётное"` или `"7 — нечётное"`.

<Hint>

`n % 2 === 0` — это уже логическое значение, так что `isEven` можно записать в одну строку. В `describe` код станет короче с тернарным оператором `? :`.

</Hint>

<Solution>

```js
const isEven = (n) => n % 2 === 0;
const describe = (n) => `${n} — ${isEven(n) ? "чётное" : "нечётное"}`;

console.log(describe(4)); // 4 — чётное
console.log(describe(7)); // 7 — нечётное
```

</Solution>

</Exercise>

## Итоги

- Стрелочные функции: `(params) => expression` для коротких функций.
- Параметры по умолчанию: `(name = "друг") => ...`.
- Переменные существуют только внутри блока, в котором они объявлены.
