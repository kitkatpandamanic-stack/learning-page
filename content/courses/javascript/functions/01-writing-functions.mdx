A **function** is a reusable block of code with a name. Write it once, then **call** it whenever you need it. You've already been using one: `console.log` is a function!

## Declaring and calling a function

<CodeExample output={`Hello! 👋
Hello! 👋`}>

```js
function sayHello() {
  console.log("Hello! 👋");
}

sayHello();
sayHello();
```

</CodeExample>

- `function sayHello() { ... }` **declares** (creates) the function. Nothing runs yet.
- `sayHello()` **calls** it. The brackets are what make it run.

## Parameters: giving a function input

**Parameters** are variables listed in the brackets. When you call the function, you pass **arguments** that fill them in:

<CodeExample output={`Hello, Mei!
Hello, Sam!`}>

```js
function greet(name) {
  console.log(`Hello, ${name}!`);
}

greet("Mei");
greet("Sam");
```

</CodeExample>

Functions can take several parameters, separated by commas:

```js
function introduce(name, age) {
  console.log(`${name} is ${age} years old.`);
}

introduce("Panda", 5); // Panda is 5 years old.
```

## `return`: getting a value back

Printing is nice, but usually you want the function to **give back** a result you can store and reuse. That's what `return` does:

<CodeExample output={`12
24`}>

```js
function area(width, height) {
  return width * height;
}

const small = area(3, 4);
console.log(small);
console.log(area(4, 6));
```

</CodeExample>

<Callout type="note" title="return ends the function">

As soon as `return` runs, the function stops. Any code after it inside the function is skipped. A function without `return` gives back `undefined`.

</Callout>

## Why use functions?

- **Reuse**: write logic once, use it everywhere.
- **Readability**: `calculateTax(price)` explains itself.
- **Fewer bugs**: fix a bug in one place and it's fixed everywhere.

<Callout type="tip">

Name functions with a **verb**: `calculateTotal`, `isEven`, `formatDate`. Functions that answer yes/no questions often start with `is` or `has` and return a boolean.

</Callout>

<Exercise title="Mini-project: Tip and bill splitter">

Write a function `splitBill(total, people, tipPercent)` that returns how much each person pays, including the tip. For example, `splitBill(100, 4, 10)` should return `27.5`.

<Hint>

First work out the tip: `total * tipPercent / 100`. Add it to the total, then divide by `people`.

</Hint>

<Solution>

```js
function splitBill(total, people, tipPercent) {
  const tip = (total * tipPercent) / 100;
  return (total + tip) / people;
}

console.log(splitBill(100, 4, 10)); // 27.5
console.log(splitBill(60, 3, 20));  // 24
```

</Solution>

</Exercise>

## Recap

- Declare with `function name(params) { ... }`, call with `name(args)`.
- Parameters are the function's inputs; arguments are the values you pass.
- `return` sends a value back and ends the function.
