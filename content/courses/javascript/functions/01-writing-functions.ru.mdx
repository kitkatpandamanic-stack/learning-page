**Функция** (function) — это переиспользуемый блок кода с именем. Напишите её один раз, а потом **вызывайте** когда угодно. Одной функцией вы уже пользуетесь: `console.log` — это функция!

## Объявление и вызов функции

<CodeExample output={`Привет! 👋
Привет! 👋`}>

```js
function sayHello() {
  console.log("Привет! 👋");
}

sayHello();
sayHello();
```

</CodeExample>

- `function sayHello() { ... }` **объявляет** (создаёт) функцию. Пока ничего не выполняется.
- `sayHello()` **вызывает** её. Именно скобки заставляют функцию выполниться.

## Параметры: входные данные для функции

**Параметры** (parameters) — это переменные, перечисленные в скобках. Когда вы вызываете функцию, вы передаёте **аргументы** (arguments), которые их заполняют:

<CodeExample output={`Привет, Мэй!
Привет, Сэм!`}>

```js
function greet(name) {
  console.log(`Привет, ${name}!`);
}

greet("Мэй");
greet("Сэм");
```

</CodeExample>

Функция может принимать несколько параметров через запятую:

```js
function introduce(name, age) {
  console.log(`Меня зовут ${name}, мне ${age} лет.`);
}

introduce("Панда", 5); // Меня зовут Панда, мне 5 лет.
```

## `return`: получаем значение обратно

Выводить — это хорошо, но обычно нужно, чтобы функция **вернула** результат, который можно сохранить и использовать дальше. Для этого и нужен `return`, а результат называется возвращаемым значением (return value):

<CodeExample output={`12
24`}>

```js
function area(width, height) {
  return width * height;
}

const small = area(3, 4);
console.log(small);
console.log(area(4, 6));
```

</CodeExample>

<Callout type="note" title="return завершает функцию">

Как только выполняется `return`, функция останавливается. Весь код после него внутри функции пропускается. Функция без `return` возвращает `undefined`.

</Callout>

## Зачем нужны функции?

- **Повторное использование**: напишите логику один раз и используйте её везде.
- **Читаемость**: `calculateTax(price)` говорит сам за себя.
- **Меньше ошибок**: исправьте ошибку в одном месте — и она исправлена везде.

<Callout type="tip">

Называйте функции **глаголами**: `calculateTotal`, `isEven`, `formatDate`. Функции, которые отвечают на вопрос «да/нет», часто начинаются с `is` или `has` и возвращают логическое значение.

</Callout>

Напишите функцию `splitBill(total, people, tipPercent)`, которая возвращает, сколько платит каждый человек, включая чаевые. Например, `splitBill(100, 4, 10)` должна вернуть `27.5`.

<Hint>

Сначала посчитайте чаевые: `total * tipPercent / 100`. Прибавьте их к сумме, а затем разделите на `people`.

</Hint>

<Solution>

```js
function splitBill(total, people, tipPercent) {
  const tip = (total * tipPercent) / 100;
  return (total + tip) / people;
}

console.log(splitBill(100, 4, 10)); // 27.5
console.log(splitBill(60, 3, 20));  // 24
```

</Solution>

</Exercise>

## Итоги

- Объявляйте функцию через `function name(params) { ... }`, вызывайте через `name(args)`.
- Параметры — это входные данные функции; аргументы — значения, которые вы передаёте.
- `return` возвращает значение и завершает функцию.
