You can now write functions. Let's learn the modern short syntax you'll see everywhere, and an important idea: **scope**.

## Arrow functions

An **arrow function** is a shorter way to write a function and store it in a variable:

```js
// Regular function
function square(n) {
  return n * n;
}

// The same thing as an arrow function
const squareArrow = (n) => {
  return n * n;
};
```

When the body is a single expression, you can drop the braces **and** the `return`:

<CodeExample output={`25
Hi, Mei!`}>

```js
const square = (n) => n * n;
const greet = (name) => `Hi, ${name}!`;

console.log(square(5));
console.log(greet("Mei"));
```

</CodeExample>

<Callout type="note">

Both styles work. Many developers use `function` for main, named functions and arrows for short helpers. You'll see why arrows are so handy when you start passing functions to other functions in Level 1.

</Callout>

## Default parameters

Give a parameter a fallback value in case the caller leaves it out:

<CodeExample output={`Hello, friend!
Hello, Sam!`}>

```js
const greet = (name = "friend") => `Hello, ${name}!`;

console.log(greet());
console.log(greet("Sam"));
```

</CodeExample>

## Scope: where variables live

A variable created **inside** a function (or any `{ }` block) only exists inside it. This is called **scope**:

```js
function makeTea() {
  const water = "hot";
  console.log(water); // works: we're inside the function
}

makeTea();
console.log(water); // ReferenceError: water is not defined
```

Code inside a block **can** see variables from outside it:

<CodeExample output="Score: 10">

```js
const label = "Score";

function show(points) {
  console.log(`${label}: ${points}`); // label comes from outside
}

show(10);
```

</CodeExample>

<Callout type="tip" title="Why scope is good">

Scope stops different parts of your program from accidentally changing each other's variables. Two functions can both have a variable called `total` without any conflict.

</Callout>

Blocks like `if` and loops have their own scope too, when you use `let` or `const`:

```js
if (true) {
  const secret = 42;
}
console.log(secret); // ReferenceError: secret is not defined
```

<Exercise
  starter={`const isEven = (n) => {
  // return true if n is even, false otherwise
};

const describe = (n) => {
  // return a string like "4 is even" or "7 is odd"
};

console.log(describe(4));
console.log(describe(7));
`}
  tests={[
    { name: "isEven is an arrow function", check: 'typeof isEven === "function" && isEven.toString().includes("=>")' },
    { name: "isEven(4) is true and isEven(7) is false", check: "isEven(4) === true && isEven(7) === false" },
    { name: "isEven(0) is true", check: "isEven(0) === true" },
    { name: 'describe(4) returns "4 is even"', check: 'describe(4) === "4 is even"' },
    { name: 'describe(7) returns "7 is odd"', check: 'describe(7) === "7 is odd"' },
  ]}
>

Write an arrow function `isEven` that takes a number and returns `true` if it's even and `false` otherwise. Then write an arrow function `describe(n)` that uses `isEven` to return a string like `"4 is even"` or `"7 is odd"`.

<Hint>

`n % 2 === 0` is already a boolean, so `isEven` can be a one-liner. In `describe`, the ternary operator `? :` keeps things short.

</Hint>

<Solution>

```js
const isEven = (n) => n % 2 === 0;
const describe = (n) => `${n} is ${isEven(n) ? "even" : "odd"}`;

console.log(describe(4)); // 4 is even
console.log(describe(7)); // 7 is odd
```

</Solution>

</Exercise>

## Recap

- Arrow functions: `(params) => expression` for short functions.
- Default parameters: `(name = "friend") => ...`.
- Variables only exist inside the block where they're declared.
