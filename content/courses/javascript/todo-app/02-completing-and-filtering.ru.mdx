Ваше приложение умеет показывать и добавлять задачи. Пора сделать список **интерактивным**! В этой части вы добавите флажок, чтобы отмечать задачи выполненными, кнопку ✕ для удаления, кнопки-фильтры **«Все» / «Активные» / «Готовые»**, счётчик «Осталось задач: 2» и кнопку **«Очистить выполненные»**. ✅

Вам пригодятся `find` и `filter` из модуля **«Массивы и объекты»**, а также **делегирование событий (event delegation)** и `dataset` из модуля **«DOM и события»**. И каждая новая возможность строится по тому же рецепту, что и в части 1: **меняем состояние, затем вызываем `render()`**.

## Ищем задачу по id

Любая возможность в этой части начинается одинаково: «пользователь кликнул по задаче номер 3, теперь с ней надо что-то сделать». Основную работу выполняют два метода массивов:

- **`find`** возвращает объект задачи с подходящим id, чтобы мы могли его изменить.
- **`filter`** возвращает новый массив **без** подходящей задачи — а это и есть удаление.

<CodeExample output={`{ id: 1, text: 'Полить бамбук', done: true }
{ id: 3, text: 'Вздремнуть на солнышке', done: false }`}>

```js
let tasks = [
  { id: 1, text: "Полить бамбук", done: false },
  { id: 2, text: "Изучить DOM", done: true },
  { id: 3, text: "Вздремнуть на солнышке", done: false },
];

function toggleTask(id) {
  const task = tasks.find((task) => task.id === id);
  if (task) {
    task.done = !task.done;
  }
}

function deleteTask(id) {
  tasks = tasks.filter((task) => task.id !== id);
}

toggleTask(1);
deleteTask(2);
tasks.forEach((task) => console.log(task));
```

</CodeExample>

На что стоит обратить внимание:

- `task.done = !task.done` **переворачивает** логическое значение: `false` становится `true`, а `true` — `false`. Одна строка отвечает и за то, чтобы отметить задачу, и за то, чтобы снять отметку.
- `find` возвращает **тот же самый объект**, что лежит в массиве (объекты передаются по ссылке), поэтому изменение `task.done` меняет и задачу в `tasks`.
- `filter` создаёт **новый** массив, поэтому `deleteTask` записывает его обратно в `tasks`. Вот почему в части 1 `tasks` объявлен через `let`, а не `const`.
- Благодаря проверке `if (task)` неверный id просто ничего не делает, вместо того чтобы обрушить программу с ошибкой «Cannot set properties of undefined».

## Флажки и кнопки удаления

Каждому элементу нужны два новых элемента управления: **флажок (checkbox)** для отметки о выполнении и **кнопка удаления**. Оба хранят id задачи в `data-id`, поэтому клик по любому из них знает, к какой задаче он относится.

Обернём флажок и текст в **`<label>`**. Это удобный HTML-приём: клик в любом месте текста метки нажимает и флажок внутри неё, так что пользователю не нужно целиться в крошечный квадратик.

```js
const label = document.createElement("label");

const checkbox = document.createElement("input");
checkbox.type = "checkbox";
checkbox.className = "toggle";
checkbox.checked = task.done;
checkbox.dataset.id = task.id;

label.append(checkbox, text);
```

`append` может принимать **несколько** элементов сразу и добавляет их по порядку. Вот весь элемент в действии, с обработчиком, который пока только **выводит в консоль**, по чему кликнули (настоящую работу он будет делать в упражнении):

## Один обработчик на весь список

Этот обработчик — пример **делегирования событий**: один обработчик на `<ul>` обрабатывает клики по всем элементам, даже по тем, которые `render()` создаст позже. Поскольку `render()` каждый раз выбрасывает и заново строит все элементы, вешать обработчики на каждый элемент пришлось бы заново после каждой отрисовки. С делегированием вы добавляете **один** обработчик и только один раз.

Внутри него `event.target.matches(".toggle")` и `event.target.matches(".delete")` говорят, **по чему** кликнули, а `event.target.dataset.id` — **по какой задаче**.

<CodeExample output={`false
true`}>

```js
const idFromPage = "2"; // значения dataset всегда строки

console.log(idFromPage === 2);
console.log(Number(idFromPage) === 2);
```

</CodeExample>

<Callout type="warning" title="Превратите id обратно в число">

Наши id — это **числа**, а `dataset` всегда отдаёт **строки**. `tasks.find((task) => task.id === "2")` ничего не найдёт, потому что `2 === "2"` — это `false`. Всегда преобразуйте значение через `Number(event.target.dataset.id)`, прежде чем искать задачу.

</Callout>

## Фильтруем список

Фильтрация добавляет второй кусочек **состояния**: какие задачи пользователь хочет видеть. Будем хранить его в переменной `filter`, которая равна `"all"`, `"active"` или `"done"`:

<CodeExample output={`[ 'Полить бамбук', 'Изучить DOM', 'Вздремнуть на солнышке' ]
[ 'Полить бамбук', 'Вздремнуть на солнышке' ]
[ 'Изучить DOM' ]`}>

```js
const tasks = [
  { id: 1, text: "Полить бамбук", done: false },
  { id: 2, text: "Изучить DOM", done: true },
  { id: 3, text: "Вздремнуть на солнышке", done: false },
];
let filter = "all";

function visibleTasks() {
  if (filter === "active") return tasks.filter((t) => !t.done);
  if (filter === "done") return tasks.filter((t) => t.done);
  return tasks;
}

console.log(visibleTasks().map((t) => t.text));
filter = "active";
console.log(visibleTasks().map((t) => t.text));
filter = "done";
console.log(visibleTasks().map((t) => t.text));
```

</CodeExample>

(Не путайте нашу **переменную** `filter` с **методом** массива `.filter()`: у них просто одинаковое имя.)

Затем `render()` перебирает `visibleTasks()` вместо `tasks`. Кнопки-фильтры — это три обычные кнопки с атрибутом `data-filter`. Один делегированный обработчик на их контейнере меняет `filter` и перерисовывает список. Чтобы подсветить выбранную кнопку, `classList.toggle` принимает необязательный **второй аргумент**: `true` означает «добавь класс», `false` — «убери его».

<TryIt
  html={`<style>
  #filters { display: flex; gap: 6px; }
  #filters button { background: transparent; }
  #filters button.active { background: #7c3aed; }
</style>
<div id="filters">
  <button data-filter="all">Все</button>
  <button data-filter="active">Активные</button>
  <button data-filter="done">Готовые</button>
</div>
<p id="showing"></p>`}
  code={`const filters = document.querySelector("#filters");
const filterButtons = document.querySelectorAll("#filters button");
const showing = document.querySelector("#showing");
let filter = "all";

function render() {
  filterButtons.forEach((button) => {
    const chosen = button.dataset.filter === filter;
    button.classList.toggle("active", chosen);
  });
  showing.textContent = \`Выбран фильтр: \${filter}\`;
}

filters.addEventListener("click", (event) => {
  if (event.target.matches("button")) {
    filter = event.target.dataset.filter;
    render();
  }
});

render();`}
/>

<Callout type="tip" title="Фильтруйте то, что показываете, а не то, что храните">

Фильтрация никогда не должна **удалять** задачи из `tasks`. Состояние хранит все задачи, а `render()` лишь выбирает, какие из них нарисовать. Переключитесь обратно на **«Все»** — и все задачи на месте.

</Callout>

## Считаем, сколько осталось

Внизу показывается, сколько задач ещё не сделано. Счётчик всегда учитывает **все** невыполненные задачи, а не только видимые. В русском языке у слова «задача» после числа три формы: 1 задача, 2 задачи, 5 задач. Чтобы не усложнять код, используем форму «Осталось задач: N», которая подходит для любого числа, а для ровно одной задачи напишем отдельную, более естественную фразу:

<CodeExample output={`Осталось задач: 0
Осталась 1 задача
Осталось задач: 3`}>

```js
function leftText(count) {
  return count === 1 ? "Осталась 1 задача" : `Осталось задач: ${count}`;
}

console.log(leftText(0));
console.log(leftText(1));
console.log(leftText(3));
```

</CodeExample>

В приложении число считается как `tasks.filter((task) => !task.done).length`, и `render()` при каждом запуске обновляет этим текстом `#count`. Поскольку **любое** изменение проходит через `render()`, счётчик никогда не устареет.

## Очищаем выполненные задачи

Последняя возможность — самая простая. **«Очистить выполненные»** оставляет только невыполненные задачи:

```js
function clearCompleted() {
  tasks = tasks.filter((task) => !task.done);
}
```

Затем, как всегда, вызываем `render()`.

`toggleTask`: `const task = tasks.find((task) => task.id === id);`, затем `if (task) task.done = !task.done;`. И `deleteTask`, и `clearCompleted` перезаписывают `tasks` результатом `tasks.filter(...)`. В обработчике списка начните с `const id = Number(event.target.dataset.id);`, затем используйте `event.target.matches(".toggle")` и `event.target.matches(".delete")`. Для кнопок-фильтров — `button.classList.toggle("active", button.dataset.filter === filter)` внутри `filterButtons.forEach(...)`.

<Solution>

```js
const form = document.querySelector("#add-form");
const input = document.querySelector("#new-task");
const list = document.querySelector("#task-list");
const count = document.querySelector("#count");
const filters = document.querySelector("#filters");
const filterButtons = document.querySelectorAll("#filters button");
const clearButton = document.querySelector("#clear-done");

let tasks = [
  { id: 1, text: "Полить бамбук", done: false },
  { id: 2, text: "Изучить DOM", done: true },
];
let nextId = 3;
let filter = "all";

function addTask(text) {
  const clean = text.trim();
  if (clean === "") return;

  tasks.push({ id: nextId, text: clean, done: false });
  nextId++;
}

function toggleTask(id) {
  const task = tasks.find((task) => task.id === id);
  if (task) {
    task.done = !task.done;
  }
}

function deleteTask(id) {
  tasks = tasks.filter((task) => task.id !== id);
}

function clearCompleted() {
  tasks = tasks.filter((task) => !task.done);
}

function visibleTasks() {
  if (filter === "active") return tasks.filter((t) => !t.done);
  if (filter === "done") return tasks.filter((t) => t.done);
  return tasks;
}

function createTaskItem(task) {
  const li = document.createElement("li");
  li.dataset.id = task.id;
  if (task.done) {
    li.classList.add("done");
  }

  const label = document.createElement("label");
  const checkbox = document.createElement("input");
  checkbox.type = "checkbox";
  checkbox.className = "toggle";
  checkbox.checked = task.done;
  checkbox.dataset.id = task.id;

  const text = document.createElement("span");
  text.className = "text";
  text.textContent = task.text;
  label.append(checkbox, text);

  const remove = document.createElement("button");
  remove.className = "delete";
  remove.textContent = "✕";
  remove.dataset.id = task.id;

  li.append(label, remove);
  return li;
}

function render() {
  list.replaceChildren();
  visibleTasks().forEach((task) => {
    list.append(createTaskItem(task));
  });

  const left = tasks.filter((task) => !task.done).length;
  count.textContent = left === 1 ? "Осталась 1 задача" : `Осталось задач: ${left}`;

  filterButtons.forEach((button) => {
    const chosen = button.dataset.filter === filter;
    button.classList.toggle("active", chosen);
  });
}

form.addEventListener("submit", (event) => {
  event.preventDefault();
  addTask(input.value);
  input.value = "";
  render();
});

list.addEventListener("click", (event) => {
  const id = Number(event.target.dataset.id);
  if (event.target.matches(".toggle")) {
    toggleTask(id);
    render();
  } else if (event.target.matches(".delete")) {
    deleteTask(id);
    render();
  }
});

filters.addEventListener("click", (event) => {
  if (event.target.matches("button")) {
    filter = event.target.dataset.filter;
    render();
  }
});

clearButton.addEventListener("click", () => {
  clearCompleted();
  render();
});

render();
```

## Что вы построили

- **`toggleTask`**, **`deleteTask`** и **`clearCompleted`** меняют состояние с помощью `find` и `filter` и никогда не трогают страницу.
- У каждого элемента есть **флажок** внутри `<label>` и **кнопка удаления**, и оба несут id задачи в `data-id`.
- **Один делегированный обработчик** на списке обслуживает все флажки и кнопки удаления, включая добавленные позже. `Number()` превращает строку из `dataset` обратно в id.
- Переменная состояния **`filter`** и функция **`visibleTasks()`** решают, что нарисует `render()`, а `tasks` при этом хранит всё.
- `render()` заодно обновляет счётчик **«Осталось задач: N»** и подсветку выбранного фильтра, так что они никогда не устаревают.

Осталась всего одна проблема: нажмите **«Запустить»** ещё раз (это как перезагрузить страницу) — и все новые задачи пропадут. В части 3 вы исправите это с помощью `localStorage`.
