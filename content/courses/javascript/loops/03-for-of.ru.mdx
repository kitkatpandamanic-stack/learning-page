Считать с помощью `i` можно, но чаще всего вам нужен просто **каждый элемент** по очереди. Именно это и делает `for...of`.

## Перебор списка

<CodeExample output={`Я люблю яблоки
Я люблю бананы
Я люблю манго`}>

```js
const fruits = ["яблоки", "бананы", "манго"];

for (const fruit of fruits) {
  console.log(`Я люблю ${fruit}`);
}
```

</CodeExample>

Читайте это так: *для каждого `fruit` из `fruits`*. На каждой итерации (iteration) в `fruit` лежит следующий элемент. Не нужно следить за счётчиком, и нет риска ошибиться на единицу.

<Callout type="tip" title="Здесь можно использовать const">

Каждая итерация получает **совершенно новую** переменную `fruit`, поэтому можно использовать `const`, хотя значение каждый раз другое.

</Callout>

## Перебор строки

Со строками это тоже работает — по одному символу за раз:

<CodeExample output="3">

```js
const sentence = "ананас";
let count = 0;

for (const letter of sentence) {
  if (letter === "а") {
    count++;
  }
}

console.log(count);
```

</CodeExample>

## Какой цикл выбрать?

| Ситуация                                           | Цикл          |
| -------------------------------------------------- | ------------- |
| Каждый элемент списка или строки                   | `for...of`    |
| Известное число повторов, или нужен индекс         | `for`         |
| Повторять, пока что-то не произойдёт               | `while`       |

<Exercise

`}

Дан массив `const scores = [72, 95, 88, 61]`. С помощью `for...of` найдите **наибольший** результат и выведите его.

<Hint>

Перед циклом заведите `let highest = 0`. Внутри цикла, если текущий результат больше `highest`, замените его.

</Hint>

<Solution>

```js
const scores = [72, 95, 88, 61];
let highest = 0;

for (const score of scores) {
  if (score > highest) {
    highest = score;
  }
}

console.log(highest); // 95
```

</Solution>

</Exercise>

## Итоги

- `for (const item of list)` проходит по всем элементам по порядку.
- Он работает с массивами и строками.
- Используйте `for`, когда нужен индекс, и `while`, когда неизвестно, сколько будет повторов.
