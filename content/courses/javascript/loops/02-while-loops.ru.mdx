Цикл `for` отлично подходит, когда вы знаете, **сколько раз** нужно повторить. Если же вы знаете только, **когда остановиться**, используйте цикл (loop) `while`.

## `while`

Блок выполняется снова и снова, пока условие (condition) истинно:

<CodeExample output={`Баланс: 100
Баланс: 75
Баланс: 50
Баланс: 25
Деньги закончились!`}>

```js
let balance = 100;

while (balance > 0) {
  console.log(`Баланс: ${balance}`);
  balance -= 25;
}

console.log("Деньги закончились!");
```

</CodeExample>

<Callout type="danger" title="Бесконечные циклы">

Если условие никогда не станет ложным, цикл будет работать **вечно** и страница зависнет. Всегда следите, чтобы что-то внутри цикла приближало его к концу, — как `balance -= 25` в примере выше.

</Callout>

## `do...while`

Цикл `do...while` **сначала один раз** выполняет блок и только потом проверяет условие. Это удобно, когда что-то должно произойти хотя бы один раз:

<CodeExample output="Выпало: 6">

```js
let roll;
do {
  roll = Math.floor(Math.random() * 6) + 1; // случайное число от 1 до 6
} while (roll !== 6);

console.log(`Выпало: ${roll}`);
```

</CodeExample>

`Math.random()` даёт случайное дробное число от 0 до 1, а `Math.floor` округляет его вниз. Вместе они имитируют бросок кубика. Этот цикл бросает кубик, пока не выпадет 6.

## `break`: остановиться раньше

`break` немедленно выходит из цикла:

<CodeExample output={`Проверяем 3
Проверяем 8
Первое чётное число: 8`}>

```js
const numbers = [3, 8, 5, 12];

for (let i = 0; i < numbers.length; i++) {
  console.log(`Проверяем ${numbers[i]}`);
  if (numbers[i] % 2 === 0) {
    console.log(`Первое чётное число: ${numbers[i]}`);
    break;
  }
}
```

</CodeExample>

Квадратные скобки `[3, 8, 5, 12]` создают **массив** (array) — список значений. Подробно массивы вы изучите на Уровне 1, а пока достаточно знать, что `numbers[0]` — первый элемент, а `numbers.length` — их количество.

## `continue`: перейти к следующему повтору

`continue` пропускает остаток текущей итерации (iteration):

<CodeExample output={`1
3
5`}>

```js
for (let i = 1; i <= 6; i++) {
  if (i % 2 === 0) {
    continue; // пропускаем чётные числа
  }
  console.log(i);
}
```

</CodeExample>

```js
let n = 1;
let steps = 0;

while (n <= 1000) {
  n *= 2;
  steps++;
}

console.log(`${n} после ${steps} удвоений`); // 1024 после 10 удвоений
```

## Итоги

- `while (условие)` повторяет код, пока условие не станет ложным.
- `do...while` всегда выполняется хотя бы один раз.
- `break` выходит из цикла; `continue` переходит к следующей итерации.
- Убедитесь, что каждый цикл может закончиться!
