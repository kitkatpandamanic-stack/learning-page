Counting with `i` works, but most of the time you just want **each item**, one after another. That's exactly what `for...of` does.

## Looping over a list

<CodeExample output={`I like apples
I like bananas
I like mangoes`}>

```js
const fruits = ["apples", "bananas", "mangoes"];

for (const fruit of fruits) {
  console.log(`I like ${fruit}`);
}
```

</CodeExample>

Read it as: *for each `fruit` of `fruits`*. On every iteration, `fruit` holds the next item. There's no counter to manage and no chance of an off-by-one error.

<Callout type="tip" title="const is fine here">

Each iteration gets a **brand new** `fruit` variable, so you can use `const` even though the value is different every time.

</Callout>

## Looping over a string

Strings work too, one character at a time:

<CodeExample output="3">

```js
const sentence = "banana";
let count = 0;

for (const letter of sentence) {
  if (letter === "a") {
    count++;
  }
}

console.log(count);
```

</CodeExample>

## Which loop should I use?

| Situation                                   | Loop          |
| ------------------------------------------- | ------------- |
| Each item in a list or string               | `for...of`    |
| A known number of repeats, or need the index | `for`         |
| Repeat until something happens              | `while`       |

<Exercise>

Given `const scores = [72, 95, 88, 61]`, use `for...of` to find the **highest** score and print it.

<Hint>

Keep a `let highest = 0` before the loop. Inside, if the current score is bigger than `highest`, replace it.

</Hint>

<Solution>

```js
const scores = [72, 95, 88, 61];
let highest = 0;

for (const score of scores) {
  if (score > highest) {
    highest = score;
  }
}

console.log(highest); // 95
```

</Solution>

</Exercise>

## Recap

- `for (const item of list)` visits every item in order.
- It works on arrays and strings.
- Use `for` when you need the index and `while` when you don't know how many times.
