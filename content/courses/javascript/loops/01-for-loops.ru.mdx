Представьте, что нужно вывести числа от 1 до 100. *Можно* написать 100 строк с `console.log`… а можно написать **цикл** (loop), который повторит работу за вас.

## Как устроен цикл `for`

<CodeExample output={`1
2
3
4
5`}>

```js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

</CodeExample>

В скобках три части, разделённые точкой с запятой:

1. **Начало**: `let i = 1` создаёт счётчик; выполняется один раз в самом начале.
2. **Условие**: `i <= 5` проверяется перед каждым повтором; цикл останавливается, когда оно становится ложным.
3. **Шаг**: `i++` выполняется после каждого повтора и прибавляет к счётчику 1.

Каждый повтор называется **итерацией** (iteration). Имя `i` — это традиция (сокращение от *index*), но подойдёт любое имя.

## Считаем по-разному

<CodeExample output={`10 8 6 4 2
Поехали! 🚀`}>

```js
let line = "";
for (let i = 10; i > 0; i -= 2) {
  line += i + " ";
}
console.log(line.trim());
console.log("Поехали! 🚀");
```

</CodeExample>

Меняйте начало, условие и шаг, чтобы считать в обратную сторону, пропускать числа или шагать десятками.

## Работа внутри цикла

Циклы особенно хороши, когда каждая итерация опирается на предыдущую. Здесь мы складываем числа от 1 до 100:

<CodeExample output="5050">

```js
let total = 0;
for (let i = 1; i <= 100; i++) {
  total += i;
}
console.log(total);
```

</CodeExample>

<Callout type="note">

Переменная `total` создаётся **снаружи** цикла. Если бы вы создали её внутри, она сбрасывалась бы в `0` на каждой итерации.

</Callout>

## Перебор строки

Объедините счётчик с `.length`, чтобы пройти по каждому символу:

<CodeExample output={`П
а
н
д
а`}>

```js
const word = "Панда";
for (let i = 0; i < word.length; i++) {
  console.log(word[i]);
}
```

</CodeExample>

<Callout type="tip">

Позиции начинаются с `0`, поэтому условие — `i < word.length`, а не `<=`. С `<=` цикл сделал бы на один шаг больше, чем нужно. Эта ошибка настолько распространена, что у неё есть своё название: **ошибка на единицу** (off-by-one error).

</Callout>

  expectedOutput={`7 x 1 = 7
7 x 2 = 14

7 x 9 = 63

Выведите таблицу умножения на 7: от `7 x 1 = 7` до `7 x 10 = 70`.

<Hint>

Пусть `i` идёт от 1 до 10, а для вывода используйте шаблонную строку: `` `7 x ${i} = ${7 * i}` ``.

</Hint>

<Solution>

```js
const n = 7;
for (let i = 1; i <= 10; i++) {
  console.log(`${n} x ${i} = ${n * i}`);
}
```

</Solution>

</Exercise>

## Итоги

- `for (начало; условие; шаг) { ... }` повторяет код.
- Условие проверяется перед каждой итерацией.
- Переменные-накопители вроде `total` создавайте **до** цикла.
- Остерегайтесь ошибок на единицу: `<` или `<=`.
