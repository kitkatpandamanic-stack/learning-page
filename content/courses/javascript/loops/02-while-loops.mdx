A `for` loop is great when you know **how many times** to repeat. When you only know **when to stop**, use a `while` loop.

## `while`

The block keeps running as long as the condition is true:

<CodeExample output={`Balance: 100
Balance: 75
Balance: 50
Balance: 25
Out of money!`}>

```js
let balance = 100;

while (balance > 0) {
  console.log(`Balance: ${balance}`);
  balance -= 25;
}

console.log("Out of money!");
```

</CodeExample>

<Callout type="danger" title="Infinite loops">

If the condition never becomes false, the loop runs **forever** and freezes the page. Always make sure something inside the loop moves it towards the end, like `balance -= 25` above.

</Callout>

## `do...while`

A `do...while` loop runs the block **once first**, then checks the condition. It's useful when something must happen at least once:

<CodeExample output="Rolled: 6">

```js
let roll;
do {
  roll = Math.floor(Math.random() * 6) + 1; // random 1 to 6
} while (roll !== 6);

console.log(`Rolled: ${roll}`);
```

</CodeExample>

`Math.random()` gives a random decimal between 0 and 1, and `Math.floor` rounds it down. Together they make a dice roll. This loop keeps rolling until it gets a 6.

## `break`: stop early

`break` exits the loop immediately:

<CodeExample output={`Checking 3
Checking 8
Found the first even number: 8`}>

```js
const numbers = [3, 8, 5, 12];

for (let i = 0; i < numbers.length; i++) {
  console.log(`Checking ${numbers[i]}`);
  if (numbers[i] % 2 === 0) {
    console.log(`Found the first even number: ${numbers[i]}`);
    break;
  }
}
```

</CodeExample>

The square brackets `[3, 8, 5, 12]` create an **array**, a list of values. You'll study arrays properly in Level 1; for now, know that `numbers[0]` is the first item and `numbers.length` is how many there are.

## `continue`: skip to the next round

`continue` skips the rest of the current iteration:

<CodeExample output={`1
3
5`}>

```js
for (let i = 1; i <= 6; i++) {
  if (i % 2 === 0) {
    continue; // skip even numbers
  }
  console.log(i);
}
```

</CodeExample>

Start with `let n = 1`. Keep doubling it in a `while` loop until it is bigger than `1000`, then print the result and how many doublings it took.

<Solution>

```js
let n = 1;
let steps = 0;

while (n <= 1000) {
  n *= 2;
  steps++;
}

console.log(`${n} after ${steps} doublings`); // 1024 after 10 doublings
```

</Solution>

</Exercise>

## Recap

- `while (condition)` repeats until the condition is false.
- `do...while` always runs at least once.
- `break` leaves the loop; `continue` skips to the next iteration.
- Make sure every loop can end!
