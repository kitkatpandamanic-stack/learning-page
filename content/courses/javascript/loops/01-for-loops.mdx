Imagine printing the numbers 1 to 100. You *could* write 100 `console.log` lines… or you could write a **loop** that repeats the work for you.

## Anatomy of a `for` loop

<CodeExample output={`1
2
3
4
5`}>

```js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

</CodeExample>

The brackets hold three parts, separated by semicolons:

1. **Start**: `let i = 1` creates a counter, run once at the beginning.
2. **Condition**: `i <= 5` is checked before every round; the loop stops when it's false.
3. **Step**: `i++` runs after every round, adding 1 to the counter.

Each repeat is called an **iteration**. The name `i` is a tradition (short for *index*), but any name works.

## Counting in different ways

<CodeExample output={`10 8 6 4 2
Lift-off! 🚀`}>

```js
let line = "";
for (let i = 10; i > 0; i -= 2) {
  line += i + " ";
}
console.log(line.trim());
console.log("Lift-off! 🚀");
```

</CodeExample>

Change the start, the condition and the step to count down, skip numbers or go up in tens.

## Doing work inside the loop

Loops shine when each iteration builds on the last. Here we add up the numbers 1 to 100:

<CodeExample output="5050">

```js
let total = 0;
for (let i = 1; i <= 100; i++) {
  total += i;
}
console.log(total);
```

</CodeExample>

<Callout type="note">

The variable `total` is created **outside** the loop. If you created it inside, it would be reset to `0` on every iteration.

</Callout>

## Looping over a string

Combine the counter with `.length` to visit every character:

<CodeExample output={`P
a
n
d
a`}>

```js
const word = "Panda";
for (let i = 0; i < word.length; i++) {
  console.log(word[i]);
}
```

</CodeExample>

<Callout type="tip">

Positions start at `0`, so the condition is `i < word.length`, not `<=`. Using `<=` would go one step too far. This mistake is so common it has a name: an **off-by-one error**.

</Callout>

Print the 7 times table from `7 x 1 = 7` up to `7 x 10 = 70`.

</Hint>

<Solution>

```js
for (let i = 1; i <= 10; i++) {
  console.log(`${n} x ${i} = ${n * i}`);
}
```

</Solution>

## Recap

- `for (start; condition; step) { ... }` repeats code.
- The condition is checked before each iteration.
- Create accumulators like `total` **before** the loop.
- Watch out for off-by-one errors with `<` vs `<=`.
