Welcome to your first **capstone project**! 🎯 Over three parts you'll build a complete **number-guessing game**: the computer secretly picks a number from 1 to 100, you guess, and it tells you whether you're too high or too low until you find it. By the end of Part 3 you'll be playing it on a real web page.

You already know everything you need: **variables** and **strings** from JavaScript Basics, **comparisons** and **if/else** from Operators & Decisions, **loops**, and **functions**. In this first part we'll build the game's "brain": the functions that decide what happens on each guess. No page yet, just logic.

## Plan before you code

Professional developers rarely start by typing. First, describe the game in plain words:

1. The computer picks a **secret number** from 1 to 100.
2. The player types a **guess**.
3. If the guess isn't a number, or isn't between 1 and 100, ask again.
4. Otherwise, say **Too low**, **Too high** or **Correct!**
5. Repeat until the player wins or runs out of attempts.

Steps 1, 3 and 4 each become a small function. Step 5 (turns and limits) is Part 2.

| Function                    | Its one job                                    |
| --------------------------- | ---------------------------------------------- |
| `randomSecret()`            | Pick a random whole number from 1 to 100       |
| `validateGuess(guess)`      | Check the guess makes sense                    |
| `checkGuess(guess, secret)` | Compare the guess with the secret              |

<Callout type="tip" title="One job per function">

Small functions with one job each are easier to read, test and fix. When something goes wrong, you'll know exactly which function to look at.

</Callout>

## Checking a guess

Let's start with the heart of the game. `checkGuess` compares a guess with the secret and **returns** a message. It's an `if...else if...else` chain, just like the grade calculator:

<CodeExample output={`Too low
Too high
Correct!`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Too low";
  } else if (guess > secret) {
    return "Too high";
  } else {
    return "Correct!";
  }
}

console.log(checkGuess(30, 42));
console.log(checkGuess(80, 42));
console.log(checkGuess(42, 42));
```

</CodeExample>

Notice that the secret is a **parameter**, not something the function picks itself. That makes `checkGuess` easy to test: we can always call it with a secret we know, like `42`, and know exactly what answer to expect. Randomness would make that impossible.

## Picking a random secret

You met `Math.random()` briefly in the while loops lesson. It gives a random decimal from `0` up to (but **never** reaching) `1`, like `0.4237`. To turn that into a whole number from 1 to 100, we need three steps:

1. Multiply by `100`: now it's from `0` up to `99.999…`
2. Round **down** with `Math.floor()`: now it's a whole number from `0` to `99`.
3. Add `1`: now it's from `1` to `100`. 🎉

Here are those steps with a few example "random" values written in by hand, so you can see the smallest and largest possible results:

<CodeExample output={`42
43
1
100`}>

```js
console.log(Math.floor(42.37));          // round down
console.log(Math.floor(0.4237 * 100) + 1);
console.log(Math.floor(0 * 100) + 1);     // smallest
console.log(Math.floor(0.9999 * 100) + 1); // largest
```

</CodeExample>

Now wrap it in a function. Because the result is random, we can't print a fixed answer, but we can check that a thousand secrets **all** land between 1 and 100:

<CodeExample output="All 1000 secrets were from 1 to 100">

```js
function randomSecret() {
  return Math.floor(Math.random() * 100) + 1;
}

let allGood = true;
for (let i = 0; i < 1000; i++) {
  const secret = randomSecret();
  if (secret < 1 || secret > 100) {
    allGood = false;
  }
}

if (allGood) {
  console.log("All 1000 secrets were from 1 to 100");
}
```

</CodeExample>

<Callout type="note" title="Why the + 1?">

Without it, the numbers would go from `0` to `99`. `Math.floor` always rounds **down**, so multiplying by `100` can never give you `100` itself. Adding `1` shifts the whole range up by one.

</Callout>

## Validating guesses

Players type their guesses into a box, and anything typed is a **string**, even `"42"`. You learned in Doing Maths that `Number()` converts text into a number. But players can type anything:

<CodeExample output={`42
NaN
0`}>

```js
console.log(Number("42"));
console.log(Number("banana"));
console.log(Number(""));
```

</CodeExample>

**`NaN`** means **"Not a Number"**: it's what you get when the conversion fails. It's a sneaky value, because **every** comparison with it is `false`. So `NaN < 1` is `false` and `NaN > 100` is `false` too, and a simple range check would let it slip through! 😱

To spot it, use one new tool: **`Number.isNaN(value)`**, which returns `true` only for `NaN`.

<CodeExample output={`false
false
true`}>

```js
const guess = Number("banana");
console.log(guess < 1);
console.log(guess > 100);
console.log(Number.isNaN(guess));
```

</CodeExample>

Now we can write `validateGuess`. It takes the guess **after** it has been converted with `Number()` and returns a message: a friendly problem, or `"OK"` when the guess is fine. The `NaN` check comes **first**:

<CodeExample output={`Please enter a number
Pick a number from 1 to 100
Pick a number from 1 to 100
OK`}>

```js
function validateGuess(guess) {
  if (Number.isNaN(guess)) {
    return "Please enter a number";
  }
  if (guess < 1 || guess > 100) {
    return "Pick a number from 1 to 100";
  }
  return "OK";
}

console.log(validateGuess(Number("banana")));
console.log(validateGuess(Number("150")));
console.log(validateGuess(Number("")));
console.log(validateGuess(Number("42")));
```

</CodeExample>

<Callout type="warning" title="Empty boxes become 0">

`Number("")` gives `0`, not `NaN`. That's why an empty guess gets "Pick a number from 1 to 100": our range check catches it, because `0` is less than `1`.

</Callout>

Each `return` ends the function straight away, so once a problem is found, the rest of the checks are skipped. That's why we don't need any `else` here.

Write the three functions of the game's brain:

1. `randomSecret()` returns a random whole number from `1` to `100`.
2. `checkGuess(guess, secret)` returns `"Too low"`, `"Too high"` or `"Correct!"`.
3. `validateGuess(guess)` takes a guess that has already been through `Number()` and returns `"Please enter a number"` if it's `NaN`, `"Pick a number from 1 to 100"` if it's below 1 or above 100, and `"OK"` otherwise.

Press **Run** a few times: the random secret should change each time.

function randomSecret() {

## What you built

- A plan that splits the game into small functions, each with one job.
- `checkGuess(guess, secret)`, which compares a guess with the secret. Passing the secret in keeps it easy to test.
- `randomSecret()`, using `Math.floor(Math.random() * 100) + 1` for a whole number from 1 to 100.
- `validateGuess(guess)`, which uses `Number.isNaN()` to catch `NaN` before checking the range.

In Part 2 you'll add **turns**: counting attempts, limiting them and giving the player a score.
