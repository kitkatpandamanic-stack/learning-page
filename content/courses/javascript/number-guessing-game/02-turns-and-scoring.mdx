In Part 1 you built the game's brain: it can check **one** guess. A real game is a series of **turns**: the player keeps guessing, we count the attempts, stop when they win or run out, and give them a score. 🏆

In this part you'll write `playGame(secret, guesses)`, which plays a whole game from a list of guesses and returns a summary. You'll use the `for...of` loop, `break` and `continue` from the Loops module, plus `return` from Functions. Every example below reuses `checkGuess` and `validateGuess` from Part 1.

## Counting attempts

To test a whole game without a player, we'll write the guesses down in advance as a **list**, like the lists you looped over in the `for...of` lesson. Then a `for...of` loop plays them one by one, and a counter keeps track of the attempts:

<CodeExample output={`Attempt 1: 50 (Too high)
Attempt 2: 25 (Too low)
Attempt 3: 42 (Correct!)`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Too low";
  } else if (guess > secret) {
    return "Too high";
  } else {
    return "Correct!";
  }
}

const secret = 42;
const guesses = [50, 25, 42];
let attempts = 0;

for (const guess of guesses) {
  attempts++;
  const result = checkGuess(guess, secret);
  console.log(`Attempt ${attempts}: ${guess} (${result})`);
}
```

</CodeExample>

The counter `attempts` is created **before** the loop, just like the `total` in the for loops lesson. If it lived inside the loop, it would start again from `0` on every turn.

## Stopping when the player wins

What if the list has more guesses after the right one? The game should end as soon as the player wins. That's a job for `break`:

<CodeExample output={`Attempt 1: 50 (Too high)
Attempt 2: 42 (Correct!)
The game ended after 2 attempts`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Too low";
  } else if (guess > secret) {
    return "Too high";
  } else {
    return "Correct!";
  }
}

const secret = 42;
const guesses = [50, 42, 10, 99];
let attempts = 0;

for (const guess of guesses) {
  attempts++;
  const result = checkGuess(guess, secret);
  console.log(`Attempt ${attempts}: ${guess} (${result})`);
  if (result === "Correct!") {
    break;
  }
}

console.log(`The game ended after ${attempts} attempts`);
```

</CodeExample>

The guesses `10` and `99` are never played.

## A limit on attempts

A game with unlimited guesses isn't much of a challenge. Let's give the player **7 attempts**. We store that number in a variable so it's easy to change later:

```js
const MAX_ATTEMPTS = 7;
```

Writing a name in `UPPER_CASE` is a common way to say: "this is a fixed setting for the whole program". It's still a normal `const`.

Now the loop can stop at the limit too. The win check comes **first**, so guessing right on your very last attempt still counts as a win:

<CodeExample output={`Attempt 1: 10 (Too low)
Attempt 2: 20 (Too low)
Attempt 3: 30 (Too low)
Out of attempts!`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Too low";
  } else if (guess > secret) {
    return "Too high";
  } else {
    return "Correct!";
  }
}

const MAX_ATTEMPTS = 3; // small, just for this demo
const secret = 42;
const guesses = [10, 20, 30, 40, 42];
let attempts = 0;

for (const guess of guesses) {
  attempts++;
  const result = checkGuess(guess, secret);
  console.log(`Attempt ${attempts}: ${guess} (${result})`);
  if (result === "Correct!") {
    break;
  }
  if (attempts === MAX_ATTEMPTS) {
    console.log("Out of attempts!");
    break;
  }
}
```

</CodeExample>

<Callout type="tip" title="Why 7 attempts?">

There's a clever strategy: always guess the **middle** of the numbers that are left. Start at 50; if that's too high, try 25, and so on. Each guess cuts the possibilities in half: 100, 50, 25, 13, 7, 4, 2, 1. With this strategy, 7 attempts are always enough, so the game is fair but still a challenge.

</Callout>

## Skipping invalid guesses

A typo like `150` shouldn't cost the player a turn. We'll tell them what's wrong and **skip** it without counting an attempt. That's exactly what `continue` does: it jumps straight to the next guess, so `attempts++` never runs for it.

<CodeExample output={`Skipped 150: Pick a number from 1 to 100
Attempt 1: 50 (Too high)
Skipped 0: Pick a number from 1 to 100
Attempt 2: 42 (Correct!)`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Too low";
  } else if (guess > secret) {
    return "Too high";
  } else {
    return "Correct!";
  }
}

function validateGuess(guess) {
  if (Number.isNaN(guess)) {
    return "Please enter a number";
  }
  if (guess < 1 || guess > 100) {
    return "Pick a number from 1 to 100";
  }
  return "OK";
}

const secret = 42;
let attempts = 0;

for (const guess of [150, 50, 0, 42]) {
  const problem = validateGuess(guess);
  if (problem !== "OK") {
    console.log(`Skipped ${guess}: ${problem}`);
    continue;
  }
  attempts++;
  const result = checkGuess(guess, secret);
  console.log(`Attempt ${attempts}: ${guess} (${result})`);
}
```

</CodeExample>

## Keeping score

Fewer attempts should mean a better score. Let's start at **100** points for guessing right first time and take away **10** for every extra attempt:

| Attempts | Score |
| -------- | ----- |
| 1        | 100   |
| 2        | 90    |
| 3        | 80    |
| 7        | 40    |

The first attempt is free, so the number of points lost is `(attempts - 1) * 10`:

<CodeExample output={`100
80
40`}>

```js
function calculateScore(attempts) {
  return 100 - (attempts - 1) * 10;
}

console.log(calculateScore(1));
console.log(calculateScore(3));
console.log(calculateScore(7));
```

</CodeExample>

A player who runs out of attempts doesn't win, so they don't get a score at all.

## Putting it together: playGame

Now combine everything into one function, `playGame(secret, guesses)`. It plays the whole list and **returns** a one-line summary:

- a win returns `You won! Attempts: 3, score: 80`
- a loss returns `Game over! The number was 42`

Here's the plan, step by step:

1. Create `let attempts = 0` inside the function, so every game starts fresh.
2. Loop over the guesses with `for...of`.
3. If `validateGuess` doesn't say `"OK"`, print the problem and `continue`.
4. Otherwise add 1 to `attempts`, check the guess and print the attempt.
5. If it's correct, `return` the win summary with the score.
6. If `attempts` has reached `MAX_ATTEMPTS`, `break`.
7. **After** the loop, `return` the game-over summary.

<Callout type="note" title="return ends the loop too">

When the player wins, `return` doesn't just leave the loop: it leaves the whole **function** straight away. So the code after the loop only runs when the player did **not** win, either because they reached the limit or because the list ran out of guesses. That's the perfect place for the game-over message.

</Callout>

```js
function randomSecret() {
  return Math.floor(Math.random() * 100) + 1;
}

function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Too low";
  } else if (guess > secret) {
    return "Too high";
  } else {
    return "Correct!";
  }
}

function validateGuess(guess) {
  if (Number.isNaN(guess)) {
    return "Please enter a number";
  }
  if (guess < 1 || guess > 100) {
    return "Pick a number from 1 to 100";
  }
  return "OK";
}

const MAX_ATTEMPTS = 7;

function calculateScore(attempts) {
  return 100 - (attempts - 1) * 10;
}

function playGame(secret, guesses) {
  let attempts = 0;

  for (const guess of guesses) {
    const problem = validateGuess(guess);
    if (problem !== "OK") {
      console.log(`Skipped ${guess}: ${problem}`);
      continue;
    }

    attempts++;
    const result = checkGuess(guess, secret);
    console.log(`Attempt ${attempts}: ${guess} (${result})`);

    if (result === "Correct!") {
      const score = calculateScore(attempts);
      return `You won! Attempts: ${attempts}, score: ${score}`;
    }
    if (attempts === MAX_ATTEMPTS) {
      break;
    }
  }

  return `Game over! The number was ${secret}`;
}

console.log(playGame(42, [50, 25, 42]));
console.log(playGame(randomSecret(), [50, 25, 75]));
```

</Solution>

## What you built

- An attempt counter that lives **outside** the loop, so it keeps counting.
- `MAX_ATTEMPTS`, a fixed setting that limits the game to 7 attempts.
- `continue` to skip invalid guesses without using up an attempt, and `break` to stop at the limit.
- `calculateScore(attempts)`, which rewards fewer attempts.
- `playGame(secret, guesses)`, which plays a whole game and returns a summary.
