В части 1 вы собрали «мозг» игры: он умеет проверять **одну** догадку. Настоящая игра — это последовательность **ходов**: игрок угадывает снова и снова, мы считаем попытки, останавливаемся, когда он выиграл или исчерпал попытки, и начисляем очки. 🏆

В этой части вы напишете `playGame(secret, guesses)` — функцию, которая проигрывает целую партию по списку догадок и возвращает итог. Вам пригодятся цикл `for...of`, `break` и `continue` из модуля «Циклы», а также `return` из модуля «Функции». Во всех примерах ниже используются `checkGuess` и `validateGuess` из части 1.

## Считаем попытки

Чтобы протестировать целую партию без живого игрока, запишем догадки заранее в виде **списка** — как те списки, которые вы перебирали в уроке про `for...of`. Цикл `for...of` проиграет их по одной, а счётчик будет вести учёт попыток:

<CodeExample output={`Попытка 1: 50 (Слишком много)
Попытка 2: 25 (Слишком мало)
Попытка 3: 42 (Верно!)`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Слишком мало";
  } else if (guess > secret) {
    return "Слишком много";
  } else {
    return "Верно!";
  }
}

const secret = 42;
const guesses = [50, 25, 42];
let attempts = 0;

for (const guess of guesses) {
  attempts++;
  const result = checkGuess(guess, secret);
  console.log(`Попытка ${attempts}: ${guess} (${result})`);
}
```

</CodeExample>

Счётчик `attempts` создаётся **до** цикла — так же, как `total` в уроке про циклы for. Если бы он жил внутри цикла, то на каждом ходу начинался бы заново с `0`.

## Останавливаемся, когда игрок выиграл

А если в списке есть догадки после правильной? Игра должна закончиться, как только игрок победил. Это работа для `break`:

<CodeExample output={`Попытка 1: 50 (Слишком много)
Попытка 2: 42 (Верно!)
Игра закончилась. Попыток: 2`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Слишком мало";
  } else if (guess > secret) {
    return "Слишком много";
  } else {
    return "Верно!";
  }
}

const secret = 42;
const guesses = [50, 42, 10, 99];
let attempts = 0;

for (const guess of guesses) {
  attempts++;
  const result = checkGuess(guess, secret);
  console.log(`Попытка ${attempts}: ${guess} (${result})`);
  if (result === "Верно!") {
    break;
  }
}

console.log(`Игра закончилась. Попыток: ${attempts}`);
```

</CodeExample>

Догадки `10` и `99` так и не будут сыграны.

## Ограничиваем число попыток

Игра с бесконечными попытками — не очень-то испытание. Дадим игроку **7 попыток**. Сохраним это число в переменной, чтобы его было легко поменять потом:

```js
const MAX_ATTEMPTS = 7;
```

Имя в `UPPER_CASE` — распространённый способ сказать: «это фиксированная настройка для всей программы». При этом это самая обычная `const`.

Теперь цикл может остановиться и на пределе. Проверка победы идёт **первой**, поэтому правильная догадка с самой последней попытки всё равно засчитывается как победа:

<CodeExample output={`Попытка 1: 10 (Слишком мало)
Попытка 2: 20 (Слишком мало)
Попытка 3: 30 (Слишком мало)
Попытки закончились!`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Слишком мало";
  } else if (guess > secret) {
    return "Слишком много";
  } else {
    return "Верно!";
  }
}

const MAX_ATTEMPTS = 3; // маленькое значение, только для этого примера
const secret = 42;
const guesses = [10, 20, 30, 40, 42];
let attempts = 0;

for (const guess of guesses) {
  attempts++;
  const result = checkGuess(guess, secret);
  console.log(`Попытка ${attempts}: ${guess} (${result})`);
  if (result === "Верно!") {
    break;
  }
  if (attempts === MAX_ATTEMPTS) {
    console.log("Попытки закончились!");
    break;
  }
}
```

</CodeExample>

<Callout type="tip" title="Почему именно 7 попыток?">

Есть хитрая стратегия: всегда называйте **середину** оставшихся чисел. Начните с 50; если это слишком много, попробуйте 25, и так далее. Каждая догадка сокращает число вариантов вдвое: 100, 50, 25, 13, 7, 4, 2, 1. С такой стратегией 7 попыток хватает всегда, так что игра честная, но всё равно требует смекалки.

</Callout>

## Пропускаем некорректные догадки

Опечатка вроде `150` не должна стоить игроку хода. Мы скажем ему, что не так, и **пропустим** догадку, не засчитывая попытку. Именно это и делает `continue`: он сразу переходит к следующей догадке, так что `attempts++` для неё не выполняется.

<CodeExample output={`Пропуск 150: Выберите число от 1 до 100
Попытка 1: 50 (Слишком много)
Пропуск 0: Выберите число от 1 до 100
Попытка 2: 42 (Верно!)`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Слишком мало";
  } else if (guess > secret) {
    return "Слишком много";
  } else {
    return "Верно!";
  }
}

function validateGuess(guess) {
  if (Number.isNaN(guess)) {
    return "Введите число";
  }
  if (guess < 1 || guess > 100) {
    return "Выберите число от 1 до 100";
  }
  return "OK";
}

const secret = 42;
let attempts = 0;

for (const guess of [150, 50, 0, 42]) {
  const problem = validateGuess(guess);
  if (problem !== "OK") {
    console.log(`Пропуск ${guess}: ${problem}`);
    continue;
  }
  attempts++;
  const result = checkGuess(guess, secret);
  console.log(`Попытка ${attempts}: ${guess} (${result})`);
}
```

</CodeExample>

## Ведём счёт

Чем меньше попыток, тем больше очков. Начнём со **100** очков за угадывание с первого раза и будем отнимать по **10** за каждую лишнюю попытку:

| Попытки | Очки |
| ------- | ---- |
| 1       | 100  |
| 2       | 90   |
| 3       | 80   |
| 7       | 40   |

Первая попытка бесплатная, поэтому число потерянных очков — `(attempts - 1) * 10`:

<CodeExample output={`100
80
40`}>

```js
function calculateScore(attempts) {
  return 100 - (attempts - 1) * 10;
}

console.log(calculateScore(1));
console.log(calculateScore(3));
console.log(calculateScore(7));
```

</CodeExample>

Игрок, у которого закончились попытки, не выигрывает, поэтому очков он не получает вовсе.

## Собираем всё вместе: playGame

Теперь объединим всё в одну функцию `playGame(secret, guesses)`. Она проигрывает весь список и **возвращает** итог в одну строку:

- при победе — `Вы победили! Попыток: 3, очков: 80`
- при проигрыше — `Игра окончена! Загаданное число: 42`

Вот план по шагам:

1. Создайте `let attempts = 0` внутри функции, чтобы каждая партия начиналась с чистого листа.
2. Переберите догадки с помощью `for...of`.
3. Если `validateGuess` не вернула `"OK"`, выведите проблему и сделайте `continue`.
4. Иначе прибавьте 1 к `attempts`, проверьте догадку и выведите попытку.
5. Если догадка верная, верните (`return`) итог победы с очками.
6. Если `attempts` достиг `MAX_ATTEMPTS`, сделайте `break`.
7. **После** цикла верните (`return`) итог проигрыша.

<Callout type="note" title="return завершает и цикл">

Когда игрок побеждает, `return` не просто выходит из цикла — он сразу выходит из всей **функции**. Поэтому код после цикла выполняется, только если игрок **не** победил: либо он упёрся в предел, либо в списке закончились догадки. Идеальное место для сообщения о проигрыше.

</Callout>

```js
function randomSecret() {
  return Math.floor(Math.random() * 100) + 1;
}

function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Слишком мало";
  } else if (guess > secret) {
    return "Слишком много";
  } else {
    return "Верно!";
  }
}

function validateGuess(guess) {
  if (Number.isNaN(guess)) {
    return "Введите число";
  }
  if (guess < 1 || guess > 100) {
    return "Выберите число от 1 до 100";
  }
  return "OK";
}

const MAX_ATTEMPTS = 7;

function calculateScore(attempts) {
  return 100 - (attempts - 1) * 10;
}

function playGame(secret, guesses) {
  let attempts = 0;

  for (const guess of guesses) {
    const problem = validateGuess(guess);
    if (problem !== "OK") {
      console.log(`Пропуск ${guess}: ${problem}`);
      continue;
    }

    attempts++;
    const result = checkGuess(guess, secret);
    console.log(`Попытка ${attempts}: ${guess} (${result})`);

    if (result === "Верно!") {
      const score = calculateScore(attempts);
      return `Вы победили! Попыток: ${attempts}, очков: ${score}`;
    }
    if (attempts === MAX_ATTEMPTS) {
      break;
    }
  }

  return `Игра окончена! Загаданное число: ${secret}`;
}

console.log(playGame(42, [50, 25, 42]));
console.log(playGame(randomSecret(), [50, 25, 75]));
```

## Что вы построили

- Счётчик попыток, который живёт **снаружи** цикла и поэтому продолжает считать.
- `MAX_ATTEMPTS` — фиксированную настройку, которая ограничивает игру 7 попытками.
- `continue`, чтобы пропускать некорректные догадки, не тратя попытку, и `break`, чтобы остановиться на пределе.
- `calculateScore(attempts)`, которая награждает за меньшее число попыток.
- `playGame(secret, guesses)`, которая проигрывает целую партию и возвращает итог.
