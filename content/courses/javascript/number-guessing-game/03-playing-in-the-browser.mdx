Your game works, but so far only in the console. Time to put it on a **real web page** with a box to type in and a button to click, so anyone can play it. 🕹️

You'll reuse every function from Parts 1 and 2: `randomSecret`, `validateGuess`, `checkGuess`, `calculateScore` and `MAX_ATTEMPTS`. The new idea in this part is **state**: variables that remember how the game is going between one click and the next. It builds on what you learned about **scope** in Arrow Functions & Scope.

## The page and the glue code

A web page is written in **HTML**. Ours needs just three things, each with an `id` so JavaScript can find it:

- `<input id="guess">`, a box to type a guess in
- `<button id="submit">`, the Guess button
- `<p id="message">`, a paragraph to show the answer in

Connecting JavaScript to a page uses a part of the browser called the **DOM**, which you'll study properly in Level 1. For now, we'll give you the small piece of **glue code** that does it. Press **Run**, type a guess and click **Guess**:

You only need to know four things about the glue code:

- **`document.querySelector("#guess")`** finds the element with `id="guess"` on the page, so we can store it in a variable.
- **`guessInput.value`** is whatever the player typed. It's always a **string**, which is why we use `Number()`, just like in Part 1.
- **`guessButton.addEventListener("click", () => { ... })`** runs the arrow function **every time** the button is clicked.
- **`messageText.textContent = ...`** changes the text shown in that paragraph.

## One click is one turn

In Part 2, `playGame` had the whole list of guesses up front and looped through them. On a page, guesses arrive **one at a time**, whenever the player clicks. So instead of a loop, we need a function that plays **one turn** and runs on every click. Let's call it `handleGuess(text)`: it takes the text from the box and returns the message to show.

There's a catch: the attempt counter must **survive** between clicks. A variable created inside `handleGuess` would start from scratch on every click. So the game's **state** lives **outside** any function, at the top of the program, where every function can see and change it:

<CodeExample output={`Too high
Please enter a number
Too low
Correct!
Attempts used: 3`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Too low";
  } else if (guess > secret) {
    return "Too high";
  } else {
    return "Correct!";
  }
}

function validateGuess(guess) {
  if (Number.isNaN(guess)) {
    return "Please enter a number";
  }
  if (guess < 1 || guess > 100) {
    return "Pick a number from 1 to 100";
  }
  return "OK";
}

// The game's state lives outside the functions
let secret = 42;
let attempts = 0;

function handleGuess(text) {
  const guess = Number(text);
  const problem = validateGuess(guess);
  if (problem !== "OK") {
    return problem;
  }
  attempts++;
  return checkGuess(guess, secret);
}

// Pretend the player clicked Guess four times
console.log(handleGuess("50"));
console.log(handleGuess("banana"));
console.log(handleGuess("25"));
console.log(handleGuess("42"));
console.log(`Attempts used: ${attempts}`);
```

</CodeExample>

Notice that `handleGuess` takes the **text** from the box and does the `Number()` conversion itself, and an invalid guess returns early with its problem, before `attempts++` can run.

## Ending the game

The game needs one more piece of state: **`gameOver`**, a boolean that starts as `false`. When the player wins or uses their last attempt, `handleGuess` sets it to `true`. At the very **start** of `handleGuess`, if `gameOver` is already `true`, it returns a message straight away and nothing else happens:

```js
if (gameOver) {
  return "The game is over. Press New game to play again.";
}
```

The win and loss messages are the same as in `playGame`, so a win shows `You won! Attempts: 3, score: 80` and a loss shows `Game over! The number was 42`. A turn that's neither just shows the result: `Too low` or `Too high`.

## Starting a new game

To play again, the state needs resetting: a new secret, `attempts` back to `0` and `gameOver` back to `false`. That's the job of `newGame(newSecret)`.

Why pass the secret in, instead of calling `randomSecret()` inside? It's the same trick as `checkGuess(guess, secret)` in Part 1: the **New game** button calls `newGame(randomSecret())` for a random game, while the checks for your exercise can call `newGame(42)` and know exactly which answers to expect.

<Callout type="warning" title="No let inside newGame">

Inside `newGame`, write `secret = newSecret`, **not** `let secret = newSecret`. With `let`, you'd create a brand-new variable that only exists inside the function, and the real game state outside would never change.

</Callout>

// ----- Parts 1 and 2 -----
function randomSecret() {
  return Math.floor(Math.random() * 100) + 1;
}

function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Too low";
  } else if (guess > secret) {
    return "Too high";
  } else {
    return "Correct!";
  }
}

function validateGuess(guess) {
  if (Number.isNaN(guess)) {
    return "Please enter a number";
  }
  if (guess < 1 || guess > 100) {
    return "Pick a number from 1 to 100";
  }
  return "OK";
}

const MAX_ATTEMPTS = 7;

function calculateScore(attempts) {
  return 100 - (attempts - 1) * 10;
}

function playGame(secret, guesses) {
  let attempts = 0;

  for (const guess of guesses) {
    const problem = validateGuess(guess);
    if (problem !== "OK") {
      console.log(`Skipped ${guess}: ${problem}`);
      continue;
    }

    attempts++;
    const result = checkGuess(guess, secret);
    console.log(`Attempt ${attempts}: ${guess} (${result})`);

    if (result === "Correct!") {
      const score = calculateScore(attempts);
      return `You won! Attempts: ${attempts}, score: ${score}`;
    }
    if (attempts === MAX_ATTEMPTS) {
      break;
    }
  }

  return `Game over! The number was ${secret}`;
}

// ----- Part 3: the game's state -----
let secret = randomSecret();
let attempts = 0;
let gameOver = false;

function newGame(newSecret) {
  secret = newSecret;
  attempts = 0;
  gameOver = false;
}

function handleGuess(text) {
  if (gameOver) {
    return "The game is over. Press New game to play again.";
  }

  const guess = Number(text);
  const problem = validateGuess(guess);
  if (problem !== "OK") {
    return problem;
  }

  attempts++;
  const result = checkGuess(guess, secret);

  if (result === "Correct!") {
    gameOver = true;
    const score = calculateScore(attempts);
    return `You won! Attempts: ${attempts}, score: ${score}`;
  }
  if (attempts === MAX_ATTEMPTS) {
    gameOver = true;
    return `Game over! The number was ${secret}`;
  }
  return result;
}

// ----- Glue code (provided: you'll learn it in Level 1) -----

const guessButton = document.querySelector("#submit");
const restartButton = document.querySelector("#restart");
const messageText = document.querySelector("#message");
const attemptsText = document.querySelector("#attempts-left");

function showAttemptsLeft() {
  const left = MAX_ATTEMPTS - attempts;
  attemptsText.textContent = `Attempts left: ${left}`;
}

guessButton.addEventListener("click", () => {

});

## What you built

- A real web page for your game, connected with a little **glue code**: `querySelector`, `addEventListener`, `.value` and `.textContent`.
- **Game state** (`secret`, `attempts`, `gameOver`) that lives outside the functions, so it lasts between clicks.
- `handleGuess(text)`, which plays one turn per click by reusing `validateGuess`, `checkGuess` and `calculateScore`.
- `newGame(newSecret)`, which resets everything for another round.
