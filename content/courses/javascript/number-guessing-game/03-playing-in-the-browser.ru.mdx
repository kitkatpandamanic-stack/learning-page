Ваша игра работает, но пока только в консоли. Пора перенести её на **настоящую веб-страницу** — с полем для ввода и кнопкой, чтобы сыграть мог кто угодно. 🕹️

Вы снова используете все функции из частей 1 и 2: `randomSecret`, `validateGuess`, `checkGuess`, `calculateScore` и `MAX_ATTEMPTS`. Новая идея этой части — **состояние (state)**: переменные, которые помнят, как идёт игра, от одного клика до следующего. Она опирается на то, что вы узнали об **области видимости (scope)** в уроке о стрелочных функциях и области видимости.

## Страница и связующий код

Веб-страница пишется на **HTML**. Нашей нужны всего три вещи, и у каждой есть `id`, чтобы JavaScript мог её найти:

- `<input id="guess">` — поле для ввода догадки
- `<button id="submit">` — кнопка «Угадать»
- `<p id="message">` — абзац, в котором показывается ответ

Чтобы связать JavaScript со страницей, используется часть браузера под названием **DOM**, которую вы как следует изучите на уровне 1. А пока мы дадим вам небольшой кусочек **связующего кода (glue code)**, который это делает. Нажмите **«Запустить»**, введите догадку и нажмите **«Угадать»**:

О связующем коде вам нужно знать всего четыре вещи:

- **`document.querySelector("#guess")`** находит на странице элемент с `id="guess"`, чтобы мы могли сохранить его в переменную.

## Один клик — один ход

В части 2 у `playGame` сразу был весь список догадок, и она перебирала его в цикле. На странице догадки приходят **по одной** — когда игрок нажимает кнопку. Поэтому вместо цикла нам нужна функция, которая играет **один ход** и запускается при каждом клике. Назовём её `handleGuess(text)`: она принимает текст из поля и возвращает сообщение, которое нужно показать.

Но есть подвох: счётчик попыток должен **сохраняться** между кликами. Переменная, созданная внутри `handleGuess`, начиналась бы с нуля при каждом клике. Поэтому **состояние игры (game state)** живёт **снаружи** всех функций, в начале программы, где каждая функция может его видеть и менять:

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Слишком мало";
  } else if (guess > secret) {
    return "Слишком много";
  } else {
    return "Верно!";
  }
}

function validateGuess(guess) {
  if (Number.isNaN(guess)) {
    return "Введите число";
  }
  if (guess < 1 || guess > 100) {
    return "Выберите число от 1 до 100";
  }
  return "OK";
}

// Состояние игры живёт снаружи функций
let secret = 42;
let attempts = 0;

function handleGuess(text) {
  const guess = Number(text);
  const problem = validateGuess(guess);
  if (problem !== "OK") {
    return problem;
  }
  attempts++;
  return checkGuess(guess, secret);
}

console.log(handleGuess("банан"));
console.log(handleGuess("25"));
console.log(handleGuess("42"));
console.log(`Использовано попыток: ${attempts}`);
```

## Завершаем игру

Игре нужен ещё один кусочек состояния: **`gameOver`** — логическое значение (boolean), которое сначала равно `false`. Когда игрок побеждает или тратит последнюю попытку, `handleGuess` устанавливает его в `true`. В самом **начале** `handleGuess`, если `gameOver` уже `true`, функция сразу возвращает сообщение, и больше ничего не происходит:

```js
if (gameOver) {
  return "Игра уже закончилась. Нажмите «Новая игра», чтобы сыграть ещё раз.";
}
```

Сообщения о победе и проигрыше те же, что и в `playGame`: при победе показывается `Вы победили! Попыток: 3, очков: 80`, а при проигрыше — `Игра окончена! Загаданное число: 42`. Если ход не принёс ни того ни другого, показывается просто результат: `Слишком мало` или `Слишком много`.

## Начинаем новую игру

Чтобы сыграть снова, состояние нужно сбросить: новое секретное число, `attempts` обратно в `0` и `gameOver` обратно в `false`. Этим занимается `newGame(newSecret)`.

Почему секретное число передаётся параметром, а не вычисляется вызовом `randomSecret()` внутри? Это тот же приём, что и с `checkGuess(guess, secret)` в части 1: кнопка **«Новая игра»** вызывает `newGame(randomSecret())` для случайной игры, а проверки вашего упражнения могут вызвать `newGame(42)` и точно знать, какие ответы ожидать.

<Callout type="warning" title="Никакого let внутри newGame">

Внутри `newGame` пишите `secret = newSecret`, а **не** `let secret = newSecret`. С `let` вы создадите совершенно новую переменную, которая существует только внутри функции, а настоящее состояние игры снаружи так и не изменится.

</Callout>

```js
// ----- Части 1 и 2 -----
function randomSecret() {
  return Math.floor(Math.random() * 100) + 1;
}

function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Слишком мало";
  } else if (guess > secret) {
    return "Слишком много";
  } else {
    return "Верно!";
  }
}

function validateGuess(guess) {
  if (Number.isNaN(guess)) {
    return "Введите число";
  }
  if (guess < 1 || guess > 100) {
    return "Выберите число от 1 до 100";
  }
  return "OK";
}

const MAX_ATTEMPTS = 7;

function calculateScore(attempts) {
  return 100 - (attempts - 1) * 10;
}

function playGame(secret, guesses) {
  let attempts = 0;

  for (const guess of guesses) {
    const problem = validateGuess(guess);
    if (problem !== "OK") {
      console.log(`Пропуск ${guess}: ${problem}`);
      continue;
    }

    attempts++;
    const result = checkGuess(guess, secret);
    console.log(`Попытка ${attempts}: ${guess} (${result})`);

    if (result === "Верно!") {
      const score = calculateScore(attempts);
      return `Вы победили! Попыток: ${attempts}, очков: ${score}`;
    }
    if (attempts === MAX_ATTEMPTS) {
      break;
    }
  }

  return `Игра окончена! Загаданное число: ${secret}`;
}

    return problem;
  }

  attempts++;
  const result = checkGuess(guess, secret);

  if (result === "Верно!") {
    gameOver = true;
    const score = calculateScore(attempts);
    return `Вы победили! Попыток: ${attempts}, очков: ${score}`;
  }
  if (attempts === MAX_ATTEMPTS) {
    gameOver = true;
    return `Игра окончена! Загаданное число: ${secret}`;
  }
  return result;
}
```
