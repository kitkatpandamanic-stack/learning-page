Добро пожаловать в ваш первый **итоговый проект (capstone project)**! 🎯 За три части вы соберёте полноценную игру **«Угадай число»**: компьютер тайно загадывает число от 1 до 100, вы пытаетесь его угадать, а он подсказывает, больше ваше число или меньше, пока вы не найдёте ответ. К концу третьей части вы будете играть в неё на настоящей веб-странице.

Вы уже знаете всё необходимое: **переменные (variables)** и **строки (strings)** из модуля «Основы JavaScript», **сравнения** и **if/else** из модуля «Операторы и условия», **циклы (loops)** и **функции (functions)**. В этой части мы соберём «мозг» игры — функции, которые решают, что происходит после каждой попытки. Страницы пока не будет, только логика.

## Сначала план, потом код

Профессиональные разработчики редко начинают с того, что сразу пишут код. Сначала опишите игру простыми словами:

1. Компьютер загадывает **секретное число** от 1 до 100.
2. Игрок вводит **догадку**.
3. Если это не число или оно не попадает в диапазон от 1 до 100, просим ввести ещё раз.
4. Иначе отвечаем: **Слишком мало**, **Слишком много** или **Верно!**
5. Повторяем, пока игрок не выиграет или у него не закончатся попытки.

Шаги 1, 3 и 4 превратятся в маленькие функции. Шаг 5 (ходы и ограничения) — это часть 2.

| Функция                     | Её единственная задача                           |
| --------------------------- | ------------------------------------------------ |
| `randomSecret()`            | Выбрать случайное целое число от 1 до 100        |
| `validateGuess(guess)`      | Проверить, что догадка имеет смысл               |
| `checkGuess(guess, secret)` | Сравнить догадку с секретным числом              |

<Callout type="tip" title="Одна функция — одна задача">

Маленькие функции, у каждой из которых одна задача, проще читать, тестировать и исправлять. Если что-то пойдёт не так, вы сразу поймёте, в какую функцию смотреть.

</Callout>

## Проверяем догадку

Начнём с сердца игры. `checkGuess` сравнивает догадку с секретным числом и **возвращает (returns)** сообщение. Это цепочка `if...else if...else`, точно как в калькуляторе оценок:

<CodeExample output={`Слишком мало
Слишком много
Верно!`}>

```js
function checkGuess(guess, secret) {
  if (guess < secret) {
    return "Слишком мало";
  } else if (guess > secret) {
    return "Слишком много";
  } else {
    return "Верно!";
  }
}

console.log(checkGuess(30, 42));
console.log(checkGuess(80, 42));
console.log(checkGuess(42, 42));
```

</CodeExample>

Обратите внимание: секретное число — это **параметр (parameter)**, функция не выбирает его сама. Благодаря этому `checkGuess` легко тестировать: мы всегда можем вызвать её с известным секретным числом, например `42`, и точно знать, какой ответ ожидать. Со случайностью это было бы невозможно.

## Загадываем случайное число

Вы уже мельком встречали `Math.random()` в уроке про циклы while. Он возвращает случайную дробь от `0` до `1` (причём `1` **никогда** не выпадает), например `0.4237`. Чтобы превратить её в целое число от 1 до 100, нужны три шага:

1. Умножить на `100`: теперь это число от `0` до `99.999…`
2. Округлить **вниз** с помощью `Math.floor()`: теперь это целое число от `0` до `99`.
3. Прибавить `1`: теперь оно от `1` до `100`. 🎉

Вот эти шаги с несколькими «случайными» значениями, вписанными вручную, — так видно наименьший и наибольший возможный результат:

<CodeExample output={`42
43
1
100`}>

```js
console.log(Math.floor(42.37));          // округление вниз
console.log(Math.floor(0.4237 * 100) + 1);
console.log(Math.floor(0 * 100) + 1);     // наименьшее
console.log(Math.floor(0.9999 * 100) + 1); // наибольшее
```

</CodeExample>

Теперь обернём это в функцию. Результат случайный, поэтому вывести заранее известный ответ мы не можем, но можем проверить, что тысяча секретных чисел **все** попадают в диапазон от 1 до 100:

<CodeExample output="Все 1000 секретных чисел — от 1 до 100">

```js
function randomSecret() {
  return Math.floor(Math.random() * 100) + 1;
}

let allGood = true;
for (let i = 0; i < 1000; i++) {
  const secret = randomSecret();
  if (secret < 1 || secret > 100) {
    allGood = false;
  }
}

if (allGood) {
  console.log("Все 1000 секретных чисел — от 1 до 100");
}
```

</CodeExample>

<Callout type="note" title="Зачем + 1?">

Без него числа шли бы от `0` до `99`. `Math.floor` всегда округляет **вниз**, поэтому умножение на `100` никогда не даст ровно `100`. Прибавление `1` сдвигает весь диапазон на единицу вверх.

</Callout>

## Проверяем догадки на корректность

Игроки вводят догадки в поле, а всё, что введено в поле, — это **строка**, даже `"42"`. В уроке про математику вы узнали, что `Number()` превращает текст в число. Но игрок может ввести что угодно:

<CodeExample output={`42
NaN
0`}>

```js
console.log(Number("42"));
console.log(Number("банан"));
console.log(Number(""));
```

</CodeExample>

**`NaN`** означает **«Not a Number»** («не число»): это то, что получается, когда преобразование не удалось. Коварное значение, потому что **любое** сравнение с ним даёт `false`. Значит, `NaN < 1` — это `false`, и `NaN > 100` — тоже `false`, так что простая проверка диапазона его пропустит! 😱

Чтобы его поймать, понадобится новый инструмент: **`Number.isNaN(value)`**, который возвращает `true` только для `NaN`.

<CodeExample output={`false
false
true`}>

```js
const guess = Number("банан");
console.log(guess < 1);
console.log(guess > 100);
console.log(Number.isNaN(guess));
```

</CodeExample>

Теперь можно написать `validateGuess`. Она получает догадку **уже после** преобразования через `Number()` и возвращает сообщение: дружелюбное описание проблемы или `"OK"`, если с догадкой всё в порядке. Проверка на `NaN` идёт **первой**:

<CodeExample output={`Введите число
Выберите число от 1 до 100
Выберите число от 1 до 100
OK`}>

```js
function validateGuess(guess) {
  if (Number.isNaN(guess)) {
    return "Введите число";
  }
  if (guess < 1 || guess > 100) {
    return "Выберите число от 1 до 100";
  }
  return "OK";
}

console.log(validateGuess(Number("банан")));
console.log(validateGuess(Number("150")));
console.log(validateGuess(Number("")));
console.log(validateGuess(Number("42")));
```

</CodeExample>

<Callout type="warning" title="Пустое поле превращается в 0">

`Number("")` даёт `0`, а не `NaN`. Поэтому на пустую догадку игра отвечает «Выберите число от 1 до 100»: её ловит проверка диапазона, ведь `0` меньше `1`.

</Callout>

Каждый `return` сразу завершает функцию, так что, как только проблема найдена, остальные проверки пропускаются. Поэтому `else` здесь не нужен.

## Что вы построили

- План, который разбивает игру на маленькие функции, у каждой — одна задача.
- `checkGuess(guess, secret)`, которая сравнивает догадку с секретным числом. Секретное число передаётся параметром, поэтому функцию легко тестировать.
- `randomSecret()`, которая с помощью `Math.floor(Math.random() * 100) + 1` выдаёт целое число от 1 до 100.
- `validateGuess(guess)`, которая с помощью `Number.isNaN()` ловит `NaN` до проверки диапазона.
