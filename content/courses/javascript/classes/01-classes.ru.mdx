Вы уже умеете создавать объект с помощью `{ ... }`. Но что, если приложению нужны **сотни** похожих объектов: пользователи, товары, панды? Копировать одну и ту же форму объекта снова и снова долго, и легко ошибиться. **Класс** (class) — это **чертёж**: вы один раз описываете форму и поведение, а потом штампуете сколько угодно объектов.

## Ваш первый класс

<CodeExample output={`Panda { name: 'Мэй', age: 3 }
Бао`}>

```js
class Panda {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

const mei = new Panda("Мэй", 3);
const bao = new Panda("Бао", 5);

console.log(mei);
console.log(bao.name);
```

</CodeExample>

Разберём по частям:

- `class Panda { ... }` объявляет чертёж. По соглашению имена классов пишут в **PascalCase** (с заглавной буквы).
- **Конструктор** (constructor) — это особый метод, который автоматически запускается каждый раз, когда вы создаёте новый объект.
- Внутри него `this` — это новенький объект, который сейчас строится. `this.name = name` сохраняет в нём значение.
- `new Panda("Мэй", 3)` создаёт **экземпляр** (instance) — один объект, сделанный по чертежу. `mei` и `bao` — два отдельных экземпляра.

<Callout type="warning" title="Не забывайте new">

Вызвать класс без `new` не получится. Вы увидите вот такую ошибку:

```js
const oops = Panda("Мэй", 3);
// TypeError: Class constructor Panda cannot be invoked without 'new'
```

</Callout>

## Методы: что умеют объекты

Функции, написанные внутри класса, называются **методами** (methods). Обратите внимание: здесь нет ключевого слова `function` и нет запятых между методами:

<CodeExample output={`Мэй, возраст: 3
С днём рождения, Мэй! 🎂
Мэй, возраст: 4
true`}>

```js
class Panda {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  describe() {
    return `${this.name}, возраст: ${this.age}`;
  }

  haveBirthday() {
    this.age++;
    console.log(`С днём рождения, ${this.name}! 🎂`);
  }
}

const mei = new Panda("Мэй", 3);
const bao = new Panda("Бао", 5);

console.log(mei.describe());
mei.haveBirthday();
console.log(mei.describe());
console.log(mei.describe === bao.describe);
```

</CodeExample>

Внутри метода `this` — это экземпляр, у которого вы вызвали метод, точно так же, как `this` в методах объектов, которые вы уже видели. Поэтому `mei.describe()` использует данные Мэй, а `bao.describe()` — данные Бао.

Последняя строка показывает любопытную вещь: все экземпляры **делят** один и тот же метод. Он хранится в классе один раз, а не копируется в каждый объект.

## Поля: значения по умолчанию

Если каждый экземпляр должен начинать с одного и того же значения, объявите **поле** (field) в начале класса. Поля создаются до того, как выполнится тело конструктора:

<CodeExample output={`Panda { bamboo: 4, hungry: true, name: 'Мэй' }
false`}>

```js
class Panda {
  bamboo = 0;
  hungry = true;

  constructor(name) {
    this.name = name;
  }

  eat(sticks) {
    this.bamboo += sticks;
    this.hungry = this.bamboo < 10;
  }
}

const mei = new Panda("Мэй");
mei.eat(4);
console.log(mei);

mei.eat(8);
console.log(mei.hungry);
```

</CodeExample>

<Callout type="tip">

Поля делают класс понятнее: любой, кто откроет файл, сразу увидит, какие свойства есть у каждого экземпляра.

</Callout>

## Геттеры и сеттеры

**Геттер** (getter) снаружи выглядит как свойство, но при чтении запускает функцию. **Сеттер** (setter) запускает функцию, когда вы присваиваете свойству значение. Их записывают с помощью `get` и `set`:

<CodeExample output={`68
100`}>

```js
class Temperature {
  constructor(celsius) {
    this.celsius = celsius;
  }

  get fahrenheit() {
    return (this.celsius * 9) / 5 + 32;
  }

  set fahrenheit(value) {
    this.celsius = ((value - 32) * 5) / 9;
  }
}

const today = new Temperature(20);
console.log(today.fahrenheit);

today.fahrenheit = 212;
console.log(today.celsius);
```

</CodeExample>

Никаких скобок! Вы читаете `today.fahrenheit`, а не `today.fahrenheit()`. Значение каждый раз вычисляется заново, поэтому оно никогда не устаревает.

### Сеттеры с проверкой

Сеттеры отлично подходят для **защиты** данных. Выбрасывайте ошибку, когда кто-то пытается сохранить неправильное значение:

<CodeExample output={`25
Счёт не может быть отрицательным
25`}>

```js
class Player {
  constructor(name, score) {
    this.name = name;
    this.score = score; // здесь тоже срабатывает сеттер
  }

  get score() {
    return this._score;
  }

  set score(value) {
    if (value < 0) {
      throw new Error("Счёт не может быть отрицательным");
    }
    this._score = value;
  }
}

const mei = new Player("Мэй", 10);
mei.score = 25;
console.log(mei.score);

try {
  mei.score = -5;
} catch (err) {
  console.log(err.message);
}
console.log(mei.score);
```

</CodeExample>

Геттер и сеттер не могут одновременно называться `score` **и** хранить значение в `this.score` (сеттер бесконечно вызывал бы сам себя). Поэтому настоящее значение живёт в `_score`.

<Callout type="note" title="Подчёркивание — всего лишь соглашение">

Имя, начинающееся с `_`, говорит другим разработчикам: «пожалуйста, не трогайте это напрямую», но JavaScript этого не запрещает. В следующем уроке вы узнаете о по-настоящему **приватных** полях.

</Callout>

## Статические методы и свойства

Иногда значение или вспомогательная функция относится к **самому классу**, а не к какому-то отдельному экземпляру. Пометьте их словом `static`. Статические члены вы уже использовали: `Math.round()` и `Number.isInteger()` — это статические методы.

<CodeExample output={`Panda { name: 'Бао', age: 5 }
2
undefined`}>

```js
class Panda {
  static count = 0;

  constructor(name, age) {
    this.name = name;
    this.age = age;
    Panda.count++;
  }

  static fromText(text) {
    const parts = text.split(",");
    return new Panda(parts[0], Number(parts[1]));
  }
}

const mei = new Panda("Мэй", 3);
const bao = Panda.fromText("Бао,5");

console.log(bao);
console.log(Panda.count);
console.log(mei.count);
```

</CodeExample>

- `Panda.count` — один общий счётчик в классе, поэтому он считает всех созданных панд.
- `Panda.fromText()` — это **фабрика** (factory): статический метод, который создаёт экземпляр за вас.
- Экземпляры не видят статических членов, поэтому `mei.count` равно `undefined`.

Допишите класс `Rectangle` (прямоугольник):

1. Конструктор сохраняет `width` и `height`.
2. **Метод** `area()` возвращает ширину × высоту.
3. **Геттер** `perimeter` возвращает длину по всему контуру: `2 * (width + height)`.
4. **Статический** метод `square(size)` возвращает новый `Rectangle`, у которого обе стороны равны `size`.

<Hint>

Внутри класса везде используйте `this.width` и `this.height`. Фабрику можно записать так: `static square(size) { return new Rectangle(size, size); }`.

</Hint>

<Solution>

```js
class Rectangle {
  constructor(width, height) {
    this.width = width;
    this.height = height;
  }

  area() {
    return this.width * this.height;
  }

  get perimeter() {
    return 2 * (this.width + this.height);
  }

  static square(size) {
    return new Rectangle(size, size);
  }
}

const box = new Rectangle(3, 4);
console.log(box.area()); // 12
console.log(box.perimeter); // 14
console.log(Rectangle.square(5).area()); // 25
```

</Solution>

## Итоги

- **Класс** — это чертёж; `new ClassName(...)` создаёт **экземпляр**.
- **Конструктор** запускается при `new` и настраивает объект через `this`.
- **Методы** общие для всех экземпляров; **поля** задают каждому экземпляру начальное значение.
- `get` и `set` создают свойства, которые выполняют код, — это удобно для вычисляемых значений и проверок.
- Статические (`static`) члены принадлежат самому классу, как `Panda.count` или `Math.round`.
