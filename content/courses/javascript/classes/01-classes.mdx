You already know how to make an object with `{ ... }`. But what if your app needs **hundreds** of similar objects: users, products, pandas? Copying the same object shape over and over is slow and error-prone. A **class** is a **blueprint**: you describe the shape and behaviour once, then stamp out as many objects as you like.

## Your first class

<CodeExample output={`Panda { name: 'Mei', age: 3 }
Bao`}>

```js
class Panda {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

const mei = new Panda("Mei", 3);
const bao = new Panda("Bao", 5);

console.log(mei);
console.log(bao.name);
```

</CodeExample>

Let's unpack that:

- `class Panda { ... }` declares the blueprint. Class names use **PascalCase** (a capital first letter) by convention.
- The **constructor** is a special method that runs automatically every time you create a new object.
- Inside it, `this` is the brand new object being built. `this.name = name` stores a value on it.
- `new Panda("Mei", 3)` creates an **instance**: one object made from the blueprint. `mei` and `bao` are two separate instances.

<Callout type="warning" title="Don't forget new">

Calling a class without `new` doesn't work. You'll get an error like this:

```js
const oops = Panda("Mei", 3);
// TypeError: Class constructor Panda cannot be invoked without 'new'
```

</Callout>

## Methods: what objects can do

Functions written inside a class are called **methods**. Notice there's no `function` keyword and no commas between them:

<CodeExample output={`Mei is 3 years old.
Happy birthday, Mei! 🎂
Mei is 4 years old.
true`}>

```js
class Panda {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  describe() {
    return `${this.name} is ${this.age} years old.`;
  }

  haveBirthday() {
    this.age++;
    console.log(`Happy birthday, ${this.name}! 🎂`);
  }
}

const mei = new Panda("Mei", 3);
const bao = new Panda("Bao", 5);

console.log(mei.describe());
mei.haveBirthday();
console.log(mei.describe());
console.log(mei.describe === bao.describe);
```

</CodeExample>

Inside a method, `this` is the instance you called it on, just like `this` in the object methods you've already met. So `mei.describe()` uses Mei's data and `bao.describe()` uses Bao's.

The last line shows something neat: every instance **shares** the same method. It's stored once on the class, not copied into each object.

## Fields: default values

If every instance should start with the same value, declare a **field** at the top of the class. Fields are set up before the constructor body runs:

<CodeExample output={`Panda { bamboo: 4, hungry: true, name: 'Mei' }
false`}>

```js
class Panda {
  bamboo = 0;
  hungry = true;

  constructor(name) {
    this.name = name;
  }

  eat(sticks) {
    this.bamboo += sticks;
    this.hungry = this.bamboo < 10;
  }
}

const mei = new Panda("Mei");
mei.eat(4);
console.log(mei);

mei.eat(8);
console.log(mei.hungry);
```

</CodeExample>

<Callout type="tip">

Fields make a class easier to read: anyone opening the file can see at a glance which properties every instance has.

</Callout>

## Getters and setters

A **getter** looks like a property from the outside but runs a function when you read it. A **setter** runs a function when you assign to it. Write them with `get` and `set`:

<CodeExample output={`68
100`}>

```js
class Temperature {
  constructor(celsius) {
    this.celsius = celsius;
  }

  get fahrenheit() {
    return (this.celsius * 9) / 5 + 32;
  }

  set fahrenheit(value) {
    this.celsius = ((value - 32) * 5) / 9;
  }
}

const today = new Temperature(20);
console.log(today.fahrenheit);

today.fahrenheit = 212;
console.log(today.celsius);
```

</CodeExample>

No brackets! You read `today.fahrenheit`, not `today.fahrenheit()`. The value is worked out fresh each time, so it can never be out of date.

### Setters that validate

Setters are perfect for **guarding** your data. Throw an error when someone tries to store a bad value:

<CodeExample output={`25
Score can't be negative
25`}>

```js
class Player {
  constructor(name, score) {
    this.name = name;
    this.score = score; // this runs the setter too
  }

  get score() {
    return this._score;
  }

  set score(value) {
    if (value < 0) {
      throw new Error("Score can't be negative");
    }
    this._score = value;
  }
}

const mei = new Player("Mei", 10);
mei.score = 25;
console.log(mei.score);

try {
  mei.score = -5;
} catch (err) {
  console.log(err.message);
}
console.log(mei.score);
```

</CodeExample>

The getter and setter can't both be called `score` **and** store the value in `this.score` (the setter would call itself forever). So the real value lives in `_score`.

<Callout type="note" title="The underscore is only a convention">

Starting a name with `_` tells other developers "please don't touch this directly", but JavaScript doesn't enforce it. In the next lesson you'll learn about truly **private** fields.

</Callout>

## Static methods and properties

Sometimes a value or helper belongs to the **class itself**, not to any single instance. Mark it `static`. You've used statics before: `Math.round()` and `Number.isInteger()` are static methods.

<CodeExample output={`Panda { name: 'Bao', age: 5 }
2
undefined`}>

```js
class Panda {
  static count = 0;

  constructor(name, age) {
    this.name = name;
    this.age = age;
    Panda.count++;
  }

  static fromText(text) {
    const parts = text.split(",");
    return new Panda(parts[0], Number(parts[1]));
  }
}

const mei = new Panda("Mei", 3);
const bao = Panda.fromText("Bao,5");

console.log(bao);
console.log(Panda.count);
console.log(mei.count);
```

</CodeExample>

- `Panda.count` is one shared counter on the class, so it counts every panda created.
- `Panda.fromText()` is a **factory**: a static method that builds an instance for you.
- Instances don't see statics, which is why `mei.count` is `undefined`.

Finish the `Rectangle` class:

1. The constructor stores `width` and `height`.
2. An `area()` **method** returns width × height.
3. A `perimeter` **getter** returns the distance all the way round: `2 * (width + height)`.
4. A **static** `square(size)` method returns a new `Rectangle` whose sides are both `size`.

<Hint>

Use `this.width` and `this.height` everywhere inside the class. For the factory, write `static square(size) { return new Rectangle(size, size); }`.

</Hint>

<Solution>

```js
class Rectangle {
  constructor(width, height) {
    this.width = width;
    this.height = height;
  }

  area() {
    return this.width * this.height;
  }

  get perimeter() {
    return 2 * (this.width + this.height);
  }

  static square(size) {
    return new Rectangle(size, size);
  }
}

const box = new Rectangle(3, 4);
console.log(box.area()); // 12
console.log(box.perimeter); // 14
console.log(Rectangle.square(5).area()); // 25
```

</Solution>

## Recap

- A **class** is a blueprint; `new ClassName(...)` creates an **instance**.
- The **constructor** runs on `new` and sets up the object with `this`.
- **Methods** are shared by all instances; **fields** give every instance a starting value.
- `get` and `set` make properties that run code, which is great for computed values and validation.
- `static` members belong to the class itself, like `Panda.count` or `Math.round`.
